  - **Why Maintain (`maintain/`):** Snapper's role on Tamlinux is operational system maintenance and recovery readiness: creating root Btrfs checkpoints before native updates (`tam-update` runs `snapper -c root create -d "pre: Tamlinux native update"`), inspecting and comparing numbered snapshots (`/.snapshots/<N>/snapshot`), pruning old checkpoints, and feeding bootable snapshot entries to the Limine menu via `limine-snapper-sync`. While `maintain/rollback.html` covers general Btrfs Copy-on-Write theory and Home Manager generations, a dedicated `maintain/snapper.html` page teaches the concrete `snapper` tool, its configuration model, and its boot-menu integration.
- **Scope:**
  - **Beginner:** What `snapper` is (a tool for managing Btrfs subvolume snapshots with metadata and numbering), how it relates to raw `btrfs subvolume snapshot`, how `tam-update` automatically takes a `root` pre-update snapshot before native system upgrades, and how to list configs (`snapper list-configs`) and snapshots (`sudo snapper -c root list`).
  - **Intermediate:** Creating manual single or pre/post snapshot pairs (`snapper -c root create`), inspecting differences between snapshots (`snapper status`, `snapper diff`), deleting snapshots and running cleanup algorithms (`number`, `timeline`, `empty-pre-post`), and understanding how `/etc/snapper/configs/root` and `/etc/conf.d/snapper` govern retention and systemd timer behavior (`snapper-timeline.timer`, `snapper-cleanup.timer`).
  - **Expert:** On-disk layout under `/.snapshots/<N>/info.xml` and `/.snapshots/<N>/snapshot`, D-Bus daemon (`snapperd`) vs direct `--no-dbus` / `--root` operation in recovery environments, how `limine-snapper-sync` (`10-limine-snapper-sync` plugin and `limine-snapper-sync.service`) synchronizes Snapper snapshots into `/boot/limine.conf` boot entries, and the boundary between booting a read-only snapshot, rolling back `/`, and preserving excluded subvolumes (such as `/home` or `/var/log`) and external backups.
