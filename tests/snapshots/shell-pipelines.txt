Shell pipelines

Depth: beginner, intermediate, expert. Every level is shown below; follow one to
read only that depth.

A pipeline connects programs so the standard output of one command flows
directly into the standard input of the next without temporary files.

Beginner: Connecting commands with a pipe

Summary: Filter and count command output by connecting programs with the pipe
operator ( |).

Prerequisites: Basic terminal interaction and standard streams ( The Shell and
Streams).

Command sequence

  
  ps aux | grep firefox | wc -l
  

Expected output:

  
  3
  

What just happened

- ps aux prints a snapshot of every running process on the system to standard
  output.
- The pipe symbol | passes that output directly to the input of grep firefox.
- grep firefox discards all lines except those matching "firefox", and outputs
  the remaining lines.
- The second pipe passes those filtered lines to wc -l, which counts and prints
  the total number of lines.

Common pitfall

Avoid the "useless use of cat": running cat file.txt | grep pattern spawns an
unnecessary process. Instead, pass the file directly: grep pattern file.txt.

Next step

Read about managing running processes in Processes, Jobs, and Signals.

Intermediate: Redirection and Multi-Stage Filters

Summary: Combine sorting, deduplication, and file descriptors to transform
structured command data.

Worked example

Count the frequency of each login shell across all system users:

  
  cut -d: -f7 /etc/passwd | sort | uniq -c | sort -rn
  

Output shows shells ordered from most frequent to least frequent.

Completion task

Find the top 5 largest directories in /var/log. Complete the missing pipeline
step below (marked with ___):

  
  du -h /var/log 2>/dev/null | sort -hr | ___ -n 5
  

Target output: exactly 5 lines listing the largest log folders.

Verification hints

- The missing filter extracts the first few lines of a stream. Check head(1).
- 2>/dev/null redirects stderr descriptor (2) to suppress permission warnings.
- sort -hr enables human-numeric sorting (recognizing K, M, G suffixes) in
  descending order.

Expert: POSIX pipe semantics and descriptor routing

Reference: Unnamed unidirectional byte streams backed by kernel ring buffers
(default 64 KiB, configurable via F_SETPIPE_SZ). Commands in a pipeline execute
concurrently in subshells. Exit status is determined by the rightmost command
unless set -o pipefail is active in Bash.

Stream Redirection Operators

Operator  Descriptor Action             Description                             
--------  ----------------------------  ----------------------------------------
|         stdout &rarr; stdin           Connects stdout (fd 1) of left command  
                                        to stdin (fd 0) of right                
|&        stdout + stderr &rarr; stdin  Connects both stdout (1) and stderr (2) 
                                        to stdin (0)                            
> file    1 &rarr; file                 Truncates or creates file and routes    
                                        stdout                                  
>> file   1 &rarr; file (append)        Appends stdout to file                  
2>&1      2 &rarr; 1                    Duplicates stderr to current destination
                                        of stdout                               
&> file   1, 2 &rarr; file              Redirects both stdout and stderr to file
< file    file &rarr; 0                 Feeds file content into stdin           
<(cmd)    fifo/fd &rarr; arg            Process substitution: presents command  
                                        output as readable filename
