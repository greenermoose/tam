The Shell and Streams

The command shell connects you to the operating system. Tamlinux embraces the
Unix philosophy: build small programs that do one job well, and connect them
with universal text streams.

The standard streams

Every program started by the shell opens three standard communication channels,
known by their file descriptor numbers:

0 — standard input (stdin)
    The stream where the program reads its input data. By default, this is
    attached to your keyboard.

1 — standard output (stdout)
    The stream where normal program output flows. By default, this is attached
    to your terminal screen.

2 — standard error (stderr)
    The diagnostic stream where errors, warnings, and progress indicators flow,
    separate from normal output data.

Keeping error messages on stream 2 ensures that when you pipe output into
another tool, error messages are not silently swallowed or parsed as data.

Stream redirection

The shell lets you redirect streams to and from files or other streams:

Operator  Meaning                                              
--------  -----------------------------------------------------
< file    Read input from a file instead of the keyboard       
> file    Write stdout to a file, overwriting existing contents
>> file   Append stdout to the end of a file                   
2> file   Redirect only error messages (stderr) to a file      
2>&1      Merge stderr into stdout so both follow the same path

Command substitution

Command substitution runs a command inside a subshell and places its output
directly onto your command line using $(command):

  
  mkdir -p backup-$(date +%Y%m%d)
  

User aliases and the one-place-to-look principle

The shell lets you define shorthand aliases for frequently used commands. In
Tamlinux, all user aliases are consolidated in a single location: ~/.bashrc.
Rather than scattering alias configurations across system profiles and hidden
drop-in directories, standard aliases (such as hello and hi mapped to tam
welcome) live in your personal ~/.bashrc.
