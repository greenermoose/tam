The Tamlinux Ecosystem and Its Choices

Tamlinux is a resource-efficient workstation environment for laptop and desktop
computers running Linux. Linux offers many ways to build a workstation; Tamlinux
compares the alternatives at each layer of the system and chooses deliberately.
These pages explain what was considered, what was chosen, and what is still
open.

Explore the ecosystem

- Base distributions — Arch Linux today; Void Linux next, with antiX Core as the

- Lua scripting — the embedded language behind the desktop configuration.
- Carried patches — how Tamlinux carries fixes on public forks.
- Virtualization and containment — tools for clean-room testing.
- AI tooling and human agency — supervised AI assistance and public provenance.
- Sustainability and hardware longevity — keeping working computers in use.

Core principles

1. User freedom: Tamlinux's own software is licensed GPL-3.0-or-later,
   protecting your right to run, study, change, and share it.
2. Resource efficiency: event-driven, bounded work with no polling loops and no
   unnecessary resident daemons.
3. Hardware longevity: choose a graphical or terminal profile by a machine's
   capability, not its age alone.
4. Repairability: patches declare how they retire; nothing becomes permanent by
   neglect.
5. Terminal first: most things can be done from a terminal with a keyboard;
   menus and bar widgets call the same commands.
6. Offline help: this guide lives on disk and works without a network.

Learning more

The packages Tamlinux has considered, and the patches it currently carries, are
recorded in the public ecosystem registry. Use tam search <word> to find a topic
in this guide.
