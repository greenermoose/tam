System Maintenance and Reliability

A dependable workstation is one whose state is understandable, observable, and
reversible. Tamlinux structures system maintenance around five core pillars:
non-disruptive updates, instant generation rollbacks, truthful diagnostics,
progressive power management, and emergency recovery.

The five maintenance pillars

Non-disruptive updates and package lifecycle
    Understand how Linux updates binaries in place without forced restarts
    through inode unlinking, and how Tamlinux organizes software into distinct,
    manageable package tiers.

Snapshots and generation rollbacks
    Leverage Copy-on-Write (CoW) filesystem mechanics with Btrfs snapshots and
    Home Manager generation rollbacks to make any software change reversible in
    seconds.

Truthful system diagnostics and logs
    Isolate faults quickly by filtering systemd journal streams by boot, unit,
    and severity, and inspecting the kernel ring buffer with dmesg.

The progressive power ladder
    Follow the three-stage power progression from individual DPMS monitor
    blanking to RAM suspend and zero-watt S4 disk hibernation, using safe
    keyboard wake conventions.

Emergency disaster recovery
    Recover calmly from frozen graphical sessions or unbootable states using
    virtual consoles, the Magic SysRq (REISUB) sequence, and live USB chroot
    environments.

Automated inspection and health checks

The tam command provides built-in tools to inspect your machine's maintenance
readiness without modifying any system configuration:

  
  tam install inspect
  tam install inspect --check
  

These commands evaluate host facts, check Btrfs snapshot support, verify
available storage headroom, and audit privilege tools, deep-linking directly to
the relevant maintenance guides above when findings arise.
