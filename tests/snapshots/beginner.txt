The beginner's path

If you are new to Linux or to the terminal, read these pages in order. Each is
short, and none of them assumes you have read the others first.

1. The shell and streams — what the command line is, and how programs hand data
   to each other.
2. Shell pipelines — joining small commands so they do real work.
3. Processes, jobs, and signals — running things in the background, and stopping
   them cleanly.
4. The Linux filesystem hierarchy — where everything lives on disk, and why.
5. File permissions and ownership — who may read, change, and run each file.
6. The Tamlinux desktop — the graphical workstation and the shortcuts worth
   knowing.
7. Reading man pages — the built-in manual for every command.
8. Resources and performance — how to see memory, swap, and CPU use.
9. Installing and maintaining — how the system is kept healthy and up to date.
10. The Tamlinux ecosystem — the software Tamlinux is built from, and why.

When you are done, the intermediate path is the natural next step.
