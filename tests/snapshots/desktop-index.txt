The Tamlinux Desktop

Tamlinux features a keyboard-first, tiling Wayland environment designed for
maximum screen efficiency and distraction-free computing. Instead of manually
dragging and resizing windows, the desktop arranges windows into clean tiles
automatically.

Essential keybindings

The SUPER key (often labeled with a Windows or Command logo) is the primary
control key for window management:

Keybinding               Action                                                 
-----------------------  -------------------------------------------------------
SUPER + RETURN           Open a new terminal emulator                           
SUPER + Space            Open the application launcher                          
SUPER + Q                Close the active window                                
SUPER + H / J / K / L    Move focus between tiled windows (left, down, up,      
                         right)                                                 
SUPER + Shift + H/J/K/L  Swap the position of the active window                 
SUPER + F                Toggle fullscreen on the focused window                
SUPER + K                Display the quick keybindings reference                

Window layout and tiling

When you open a second window, the active area splits automatically to make
room. Windows never overlap or hide behind each other unless explicitly set to
floating mode.

To toggle floating mode for windows that require a fixed geometry (such as
calculators or file pickers), press SUPER + Shift + Space.
