Reading man pages

The man command is the traditional manual. It looks terse, but it follows a
steady rhythm once you know the sections.

The anatomy

- NAME — one line saying what it does.
- SYNOPSIS — the shape of the command.
- DESCRIPTION and OPTIONS — the details.
- EXAMPLES, FILES and SEE ALSO — how to use it and what to read next.

The numbered sections

1. User commands, such as ls and grep.
2. System calls, the kernel's interface.
3. Library functions.
4. File formats and configuration, such as fstab.
5. Overviews and conventions, such as regular expressions.
6. Administration commands and daemons.

Finding the right page

man -k (also called apropos) searches the short descriptions; whatis prints the
one-line summary. Inside a page, / searches, n repeats, and q quits.

Hyperlinked manuals with tam man

Tamlinux includes an integrated manual page viewer: tam man [SECTION] PAGE. It
automatically converts system manual pages into hyperlinked views, letting you
jump between referenced commands with Tab and Enter.

For example, view the manual page for the Tamlinux command itself: tam(1), or
explore foundational commands like ls(1) and sh(1).

Authoritative GNU Info manuals with tam info

While UNIX man pages provide quick syntax cards, the GNU Project maintains full,
book-length documentation in Texinfo format. Tamlinux includes an offline GNU
Info reader: tam info [MANUAL [NODE]].

Explore the complete system-wide library in the Info Directory catalog, or open
comprehensive manuals such as coreutils, bash, and libc.
