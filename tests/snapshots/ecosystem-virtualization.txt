Virtualization and Containment

The Tamlinux ecosystem

Building a workstation environment means testing installation and recovery on
machines that start clean, without risking a working computer. Virtual machines
and containers make that possible. Tamlinux has surveyed these tools; none is
yet a settled part of its process.

Tools considered

- QEMU (with KVM): a machine emulator and virtualizer. It can test installations
  from scratch and emulate simple graphics adapters, which is useful for
  checking software rendering without hardware acceleration.
- Docker: containers built on Linux namespaces and cgroups, useful for clean
  build environments with a known set of dependencies.
- WSL: the Windows Subsystem for Linux, which runs a Linux kernel in a
  lightweight virtual machine on Windows.
- UTM: a QEMU-based virtual machine manager for macOS.
- Tart: a command-line virtual machine runner for macOS, built on Apple's
  Virtualization framework and aimed at automation.
- OrbStack: a proprietary macOS tool for containers and Linux machines, notable
  for its efficiency.

Why it matters

A change to installation, boot, or recovery should be proven on a clean system
before it reaches a computer someone depends on. A virtual machine is the
cheapest clean system there is.
