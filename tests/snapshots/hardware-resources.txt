System Resources and Performance

Depth: beginner, intermediate, expert. Every level is shown below; follow one to
read only that depth.

Tamlinux extracts maximum responsiveness from your hardware, from modest older
laptops up to high-core workstations, with zero background telemetry and minimal
memory footprint.

Beginner: Checking memory headroom and disk capacity

Summary: Check available memory and remaining storage space using standard
terminal utilities.

Prerequisites: Basic command execution ( The Shell and Streams).

Command sequence

  
  free -h
  df -h /
  

Expected output:

  
                 total        used        free      shared  buff/cache   available
  Mem:            15Gi       4.2Gi       2.1Gi       512Mi       9.2Gi        10Gi
  Swap:          8.0Gi       1.2Gi       6.8Gi
  Filesystem      Size  Used Avail Use% Mounted on
  /dev/nvme0n1p2  466G  120G  323G  28% /
  

What just happened

- free -h prints memory metrics in human-readable units (GiB, MiB).
- The available column (10Gi) represents genuine memory headroom for new
  applications, because Linux can instantly reclaim buff/cache when required.
- df -h / reports the total capacity, consumed storage, and available space on
  the root filesystem.
- You can also run tam inspect to audit host CPU architecture, RAM, storage
  mounts, and graphics adapters in a single read-only view, or tam check
  storage_root_space to verify storage headroom against the Check Contract.

Common pitfall

Do not mistake low "free" memory for RAM exhaustion. Unused RAM is wasted RAM;
the Linux kernel intentionally uses idle memory to cache disk blocks. Always
monitor available memory.

Next step

Learn how to inspect and terminate runaway background tasks in Processes, Jobs,
and Signals.

Intermediate: CPU load diagnosis and memory profiling

Summary: Interpret 1, 5, and 15-minute load averages against logical core
counts, and profile per-process memory consumption.

Worked example

Compare instantaneous system load against hardware capacity:

  
  nproc
  uptime
  

If nproc reports 8 cores and load averages are 1.20, 0.85, 0.60, the system has
substantial spare compute headroom. Load exceeding core count indicates
processes are actively queuing for CPU time.

Completion task

List the top 5 memory-consuming processes ordered by resident set size (RSS).
Complete the missing sort flag below (marked with ___):

  
  ps -eo pid,rss,comm ___ | head -n 6
  

Target output: header row followed by the 5 largest processes currently in
physical RAM.

Verification hints

- To sort by RSS descending, pass --sort=-rss to ps.
- Check ps(1) for available column specifiers.
- Run top or btop for dynamic interactive monitoring.

Expert: Virtual memory internals, ZRAM, and kernel metrics

Reference: Virtual memory architecture: anonymous pages (heap, stack) vs
file-backed pages (page cache, mmap). Tamlinux configures ZRAM swap devices
backed by lz4/zstd in-RAM compression. Dirty page flushing is governed by
vm.dirty_ratio and vm.dirty_background_ratio in sysctl(8). Pressure Stall
Information (PSI) in /proc/pressure/{cpu,memory,io} provides leading indicators
of resource contention.

Key kernel memory metrics (/proc/meminfo)

Metric          Kernel Source      Significance                                 
--------------  -----------------  ---------------------------------------------
MemAvailable    Kernel estimate    RAM available for allocation without swapping
Active(anon)    LRU page list      Program heap/stack pages accessed recently   
Inactive(file)  LRU page list      Clean page cache pages eligible for immediate
                                   reclamation                                  
Dirty           Writeback tracker  Modified pages awaiting flush to underlying  
                                   storage                                      
ZramCompRatio   /sys/block/zram0   Effective compression ratio (uncompressed /  
                                   compressed size)                             

Manual pages

Consult system documentation: vmstat(8), free(1), top(1), sysctl(8), zramctl(8).
