Processes, Jobs, and Signals

Depth: beginner, intermediate, expert. Every level is shown below; follow one to
read only that depth.

Every running program on Tamlinux is a process with a unique identifier (PID).
The interactive shell groups running commands into jobs that you can suspend,
background, and resume.

Beginner: Controlling background jobs in the shell

Summary: Suspend a running program and move it into the background to keep your
shell prompt free.

Prerequisites: Basic shell interaction ( The Shell and Streams).

Command sequence

  
  sleep 100
  

Press Ctrl+Z, then run:

  
  bg %1
  jobs
  

Expected output:

  
  [1]+  Stopped                 sleep 100
  [1]+ sleep 100 &
  [1]+  Running                 sleep 100 &
  

What just happened

- sleep 100 started running in the foreground, monopolizing the terminal.
- Pressing Ctrl+Z sent a SIGTSTP signal, pausing the process and returning
  control to your prompt.
- bg%1 sent a SIGCONT signal to job 1, resuming execution in the background.
- jobs reported that job 1 is actively running in the background.

Common pitfall

Closing your terminal window sends a SIGHUP (hangup) signal to all child jobs,
terminating them unless they have been detached with disown or started with
nohup.

Next step

Monitor system-wide resource utilization in System Resources and Performance.

Intermediate: Process signaling and graceful termination

Summary: Locate processes by name and send polite termination signals before
resorting to unconditional kills.

Worked example

Find and politely terminate lingering background sleep processes:

  
  pgrep -l sleep
  pkill -15 sleep
  

SIGTERM (signal 15) gives applications the opportunity to save state, flush
write buffers, and clean up socket files.

Completion task

Start a heavy background compilation task with lowest CPU scheduling priority
(nice level 19) and detach it from your shell so it survives terminal closure.
Complete the missing command step below (marked with ___):

  
  nice -n 19 make &
  ___ -h %1
  

Target output: job is marked so SIGHUP will not terminate it on logout.

Verification hints

- The shell builtin to detach a job from the active session is disown.
- Use jobs -l to inspect the job number and PID.
- Use ps -o pid,ni,cmd -p <PID> to verify the nice level is 19.

Expert: POSIX process semantics and signal specifications

Reference: Process states (R: running, S: interruptible sleep, D:
uninterruptible disk sleep, Z: zombie/defunct). Zombies occur when a child
terminates and the parent has not yet invoked wait4(2) to read its exit status;
orphan processes are adopted by PID 1 (systemd or runit). Signals are
synchronous or asynchronous interrupts handled via sigaction(2).

Standard POSIX signals

Signal   Num  Action  Description                                               
-------  ---  ------  ----------------------------------------------------------
SIGHUP   1    Term    Hangup detected on controlling terminal; config reload in 
                      daemons                                                   
SIGINT   2    Term    Interrupt from keyboard (Ctrl+C)                          
SIGQUIT  3    Core    Quit from keyboard (Ctrl+\)                               
SIGKILL  9    Term    Unconditional immediate halt; uncatchable and unignorable 
SIGUSR1  10   Term    User-defined signal 1                                     
SIGSEGV  11   Core    Invalid memory reference (segmentation fault)             
SIGUSR2  12   Term    User-defined signal 2                                     
SIGPIPE  13   Term    Broken pipe: write to pipe with no readers                
SIGTERM  15   Term    Graceful termination request (default for kill and pkill) 
SIGCONT  18   Cont    Continue execution if paused                              
SIGSTOP  19   Stop    Stop process execution immediately; uncatchable and       
                      unignorable                                               
SIGTSTP  20   Stop    Terminal stop signal generated by Ctrl+Z
