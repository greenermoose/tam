Installing and maintaining Tamlinux

Tamlinux keeps your software and your settings in clear, layered pieces so that
each can be understood and reversed on its own.

The layers

1. The base system, managed by the distribution package manager.
2. User command-line tools, which can be updated independently.
3. Desktop shell plugins, each with its own version and release.

Staying healthy

Before a big change, take a snapshot so you can return to a known-good state.
tam update gathers the available updates and shows what will change before it
applies anything.

Recovery

If something goes wrong, read the diagnostics first. A truthful error message is
more useful than a guess.
