Installing and maintaining Tamlinux

Tamlinux keeps your software and your settings in clear, layered pieces so that
each can be understood and reversed on its own.

The installation framework

The installation framework provides a deliberate four-step lifecycle:

1. Inspect: tam install inspect checks host facts, architecture, package tools,
   and supported profiles without changing anything.
2. Plan: tam install plan prints exact changes, package inputs, checkpoints, and
   recovery steps before applying.
3. Apply: tam install apply executes only the reviewed plan.
4. Verify: tam install verify validates installed components, command
   resolution, and desktop integration.

The layers

1. The base system, managed by the distribution package manager.
2. User command-line tools, which can be updated independently.
3. Desktop shell plugins, each with its own version and release.

Staying healthy

Before a big change, take a snapshot so you can return to a known-good state.
tam install inspect gathers host facts and recognized capabilities before any
installation work begins. See Snapshots and generation rollbacks and
Non-disruptive updates.

Recovery and diagnostics

If something goes wrong, read the diagnostics first. A truthful error message is
more useful than a guess. Learn how to inspect logs in Truthful system
diagnostics and logs, manage system power in The progressive power ladder, and
recover from freezes in Emergency disaster recovery.
