Reading man pages

The man command is the traditional manual. It looks terse, but it follows a steady rhythm once you know the sections.

The anatomy

  • NAME — one line saying what it does.
  • SYNOPSIS — the shape of the command.
  • DESCRIPTION and OPTIONS — the details.
  • EXAMPLES, FILES and SEE ALSO — how to use it and what to read next.

The numbered sections

  1. User commands, such as ls and grep.
  2. System calls, the kernel's interface.
  3. Library calls and functions.
  4. Special files and device interfaces.
  5. File formats and configuration, such as fstab.
  6. Games and demonstrations.
  7. Miscellaneous topics and conventions, such as regular expressions.
  8. Administration commands and daemons.
  9. Kernel routines, when provided by the installed system.

Finding the right page

man -k (also called apropos) searches the short descriptions; whatis prints the one-line summary. Bare tam man opens a discovery page with Open a page, Find by keyword, and Browse a section. Lookup input is entered in the reader, results are selectable links, and the section list explains the conventional meanings. Inside a manual, / searches the current page, n repeats, ? opens navigation help, and q quits.

Hyperlinked manuals with tam man

Tamlinux includes an integrated manual page viewer: tam man [SECTION] PAGE. It automatically converts system manual pages into hyperlinked views, letting you jump between referenced commands with Tab and Enter.

For example, view the manual page for the Tamlinux command itself: tam(1), or explore foundational commands like ls(1) and sh(1).

Authoritative GNU Info manuals with tam info

While man pages provide concise reference entries, the GNU Project's Info manuals provide longer explanations organized into related nodes. Tamlinux includes an Info reader: tam info [MANUAL [NODE]].

Start with the installed Info Directory catalog. Available manuals depend on installed packages. Choose Info for a manual's linked chapters and nodes; choose Man pages for a concise command, system-call, or file-format reference. Use u for an Info manual's real parent node and Left Arrow for browsing history.
