Guide / Networking / Internet protocol stack / Internet layer

The internet layer gives packets source and destination addresses and decides which next hop carries them toward a destination across multiple networks.

What the internet layer does

When you send data across the internet, the internet layer puts an address label on each packet, like a postal address on an envelope. Routers read that label and decide where to send the packet next. This layer does not promise that every packet arrives, arrives once, or arrives in order; it focuses on getting packets from one network to another.

Why it matters

Without the internet layer, devices could only talk on the same local cable or Wi-Fi network. IP addresses and routing let packets cross many networks on the way to a distant server.

How to think about it

Think of the internet layer as the addressing and routing system for parcels. It decides which road or hub comes next, but it does not open the parcel or guarantee the recipient signs for it.

New words

IP address
A number that identifies a network interface so packets can be routed to it.
Router
A device that forwards packets between networks by choosing the next hop.

Check yourself

What does a router change when it forwards an IP packet?

It chooses the next hop and decrements the hop limit; source and destination addresses normally stay the same across routers.

How it works

The internet layer wraps transport data in an IP header containing source and destination addresses, hop limit/TTL, next-protocol field, and fragmentation or flow-related fields depending on version. Routers perform longest-prefix-match forwarding on the destination address. They do not maintain end-to-end application state; they forward each packet based on routing information. IPv4 is defined by RFC 791 and IPv6 by RFC 8200.

Advanced usage

Use structured output for scripts and inspect IPv6 routing separately, because IPv6 link-local addresses and scope rules affect next-hop selection.

Edge cases

  • Fragmentation: IPv4 routers may fragment packets unless DF is set; IPv6 routers do not fragment in flight and send Packet Too Big messages.
  • Multiple addresses: One interface can have several IPv4/IPv6 addresses with different scopes and lifetimes.
  • Policy routing: Linux can choose routes based on rules beyond destination address, such as source address or firewall marks.
