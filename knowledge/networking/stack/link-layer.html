Guide / Networking / Internet protocol stack / Link layer

The link layer moves frames across one local network using hardware addresses, before a router sends the packet toward another network.

What the link layer does

The internet layer decides where a packet should go next. The link layer handles the last local step: getting that packet across the cable, switch, or radio link to the next device. It wraps the packet in a frame with local delivery information.

Why it matters

Different links work differently. Wi-Fi, Ethernet, and mobile links have different signals and rules. The link layer hides those local details so higher layers can work over many kinds of networks.

How to think about it

If the internet layer is the road map between cities, the link layer is the local delivery truck that moves a package from one stop to the next on the current street.

Check yourself

Why is a hardware address needed if the packet already has an IP destination?

The local link delivers frames using hardware addresses; the IP destination may be on another network and require a router as the next hop.

How it works

The link layer encapsulates an IP packet in a frame with source and destination link addresses and a frame check sequence. It also defines how nodes share the medium, detect errors, and handle local delivery. In the four-layer internet model, the physical signaling details are often included in the link layer; in the OSI model, physical signaling is Layer 1 and framing/addressing is Layer 2.

Advanced usage

Detailed link output shows MTU, queueing, and driver information. Neighbor states reveal whether local resolution is fresh, stale, or failed.

Edge cases

  • MTU limits: The link MTU limits frame payload size and affects IP fragmentation or path MTU discovery.
  • Changing MACs: Privacy features and virtualization can change link-layer addresses; stale neighbor caches can cause brief delivery failures.
  • Shared media: Wi-Fi and switched Ethernet have very different collision, retry, and latency behavior despite serving the same layer role.
