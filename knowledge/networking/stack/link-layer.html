Link layer

The link layer is the part of the network stack that moves data across the local network link, such as Ethernet or Wi-Fi, using frames and hardware addresses.

What the link layer does

The internet layer decides where a packet should go next. The link layer handles the last local step: getting that packet across the cable, switch, or radio link to the next device. It wraps the packet in a frame with local delivery information.

Why it matters

Different links work differently. Wi-Fi, Ethernet, and mobile links have different signals and rules. The link layer hides those local details so higher layers can work over many kinds of networks.

How to think about it

If the internet layer is the road map between cities, the link layer is the local delivery truck that moves a package from one stop to the next on the current street.

Goal: Identify a link-layer address, a neighbor entry, and a network interface.

Before you start: Read The internet protocol stack.

Worked example

$ ip link show
$ ip neigh

ip link shows interfaces and their hardware (MAC) addresses. ip neigh shows the neighbor table, which maps local IP addresses to link-layer addresses.

What just happened

To send an IP packet on a local Ethernet or Wi-Fi network, the system needs the link-layer address of the next hop. IPv4 usually uses ARP; IPv6 uses NDP. The result is cached in the neighbor table.

Try it

Run ip -br link to list interfaces briefly. Then run ip neigh after contacting another local device to see if a neighbor entry appears.

If it goes wrong

No neighbor entry
The host may not have tried to reach that neighbor yet, or local link resolution failed. Check connectivity and interface state.
Interface is DOWN
The link layer cannot send frames until the interface is up and connected to a link.

Check yourself

What is the difference between an IP address and a MAC address?

An IP address is an internet-layer address used for routing across networks. A MAC address is a link-layer address used for delivery on the local network segment.

How it works

The link layer encapsulates an IP packet in a frame with source and destination link addresses and a frame check sequence. It also defines how nodes share the medium, detect errors, and handle local delivery. In the four-layer internet model, the physical signaling details are often included in the link layer; in the OSI model, physical signaling is Layer 1 and framing/addressing is Layer 2.

Advanced usage

$ ip -d link show
$ ip neigh show nud reachable

Detailed link output shows MTU, queueing, and driver information. Neighbor states reveal whether local resolution is fresh, stale, or failed.

Edge cases

  • MTU limits: The link MTU limits frame payload size and affects IP fragmentation or path MTU discovery.
  • Changing MACs: Privacy features and virtualization can change link-layer addresses; stale neighbor caches can cause brief delivery failures.
  • Shared media: Wi-Fi and switched Ethernet have very different collision, retry, and latency behavior despite serving the same layer role.

Check yourself

Why does the internet model group physical and data-link concerns together?

The internet model focuses on interoperable packet delivery across heterogeneous networks. Grouping local media details into one link layer keeps the model simple while allowing Ethernet, Wi-Fi, and other link technologies to carry IP packets.
