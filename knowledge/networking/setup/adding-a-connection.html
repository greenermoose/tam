Guide / Networking / Network setup / Adding a connection

A saved network profile records how a connection should be made, so a wired or Wi-Fi link can be reused instead of configured by hand each time.

A recipe, not a one-time action

When you connect to a network, the operating system can either ask a DHCP server for settings or use settings you typed in. A saved connection remembers that choice, so the next time the cable is plugged in or the Wi-Fi network is in range, the same settings return without being entered again.

Why it matters

Saving a connection avoids repeating the setup and lets several profiles coexist. A laptop can keep one profile for home and another for work; a desktop can keep a wired profile and a fallback Wi-Fi profile. Editing a profile changes future connections, so knowing how to undo a change matters.

Most home networks use DHCP: the router hands out an address, a prefix, a gateway and DNS servers. A printer, server or lab device often needs a fixed address so its address does not change.

New words

DHCP
A service that assigns an address and related settings automatically.
IP address
The number assigned to an interface; it may be leased from DHCP or set manually.
SSID
The public name of a Wi-Fi network, stored in a Wi-Fi profile.
Network interface
The device a profile is bound to, such as enp1s0.
Gateway
The router a profile uses for traffic outside the local network.

How it works

NetworkManager stores profiles as keyfiles under /etc/NetworkManager/system-connections/ or in its private D-Bus state. The settings names above are the same keys a keyfile uses, grouped into sections such as [ipv4] and [802-11-wireless]. nmcli connection add creates a profile; nmcli connection up applies it; nmcli device reapply pushes edited settings into the active connection without a full reconnect.

A DHCP lease is not a permanent address. It carries a lifetime, and the client renews it before expiry; if renewal fails the address can disappear while the cable stays connected. A manual profile has no such timer, which is why printers and servers use one.

Edge cases

  • A Wi-Fi profile without a secret can still connect through an enterprise method or a stored system secret; reading it back requires suitable permissions.
  • Setting both a manual address and ipv4.method=auto leaves the manual address unused; the method decides which values are applied.
  • Two profiles for the same interface can both have autoconnect=yes. The one with the higher autoconnect priority or the most recent activation usually wins, which can look random.
  • A VPN profile is a connection too. It adds a virtual device and its own routes rather than configuring the physical interface.
  • Changing DNS in a profile does not immediately change the running resolver; the profile must be reapplied or the connection reactivated.
