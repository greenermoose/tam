Guide / Networking / Network setup / Gateways and routing

A gateway is the next router on the path to another network. The routing table tells the kernel which gateway or interface to use for each destination.

The signpost at every crossroads

When a computer sends a packet, it asks a simple question: is the destination on my own local network? If yes, it delivers the packet directly using the destination's hardware address. If no, it hands the packet to a gateway, usually the router that connects the local network to the wider internet.

Why it matters

A machine can have a correct address and still be unable to reach the internet if it has no default route. It can also have two default routes and send traffic out the wrong one. Reading the table tells you which case you have.

How to think about it

destination on 192.168.1.0/24  --> deliver directly on enp1s0
any other destination          --> send to gateway 192.168.1.1 on enp1s0

The first rule is more specific than "any other destination", so it wins. That is the whole idea behind routing: pick the most specific matching rule.

New words

Gateway
The router that carries traffic from the local network to other networks.
Router

NAT
Translation of private addresses at the network boundary, often performed by the same router.

The number used as both the destination and the source in an IP packet.

What does the default route do?

It is the fallback path for destinations not covered by a more specific route.

How it works

Route lookup walks the relevant tables and applies longest-prefix match, then route type, metric and protocol as tie-breakers. The main table is number 254; ip rule selects which tables are consulted and in what order, which is how source-based routing sends traffic from one address out a particular interface. The source address chosen by ip route get comes from the preferred address on the outgoing interface, not from the destination.

Routing and NAT are different functions. A router forwards a packet without changing its addresses; a NAT gateway rewrites the source or destination as it crosses a boundary. A VPN adds a virtual interface and usually a more specific set of routes plus a default route with a lower metric, while leaving the physical interface's local route intact.

Advanced usage

The JSON form and the rule list show the same decision from two angles: the route that was chosen, and the tables that were eligible to supply it.

Edge cases

  • Asymmetric routing occurs when a packet leaves by one interface and the reply would leave by another. Stateful firewalls and NAT break when paths differ.
  • Equal-cost multipath installs several next hops for one prefix; the kernel chooses among them by hash, which keeps a flow on one path.
  • A default route supplied by DHCP can disappear when the lease is lost, even though manually added routes remain.
  • Router advertisements can supply a default route with a lifetime. An expired advertisement leaves the prefix reachable but removes the default route.
  • Reverse-path filtering drops packets whose source address would not be reachable through the interface they arrived on; it is a defense against spoofing that can surprise users of multiple interfaces.
