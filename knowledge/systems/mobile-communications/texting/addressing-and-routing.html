Guide / Systems and administration / Mobile communications / Texting and instant messaging / Addresses, numbers and routing

The address a person types into a text is not the same as the internal identity a carrier uses. Systems must translate the visible number into a subscriber record and then into a route to the phone's current network.

The number on the envelope

When you text someone, you type their phone number. That number is like a postal address: it tells the service who should receive the message. Inside the network, other numbers identify the subscription and the place where the phone is currently registered.

Why it matters

People keep the same phone number when they change phones or carriers. The network has to keep track of where that number currently leads, or texts would go to an old device or an old carrier.

How to think about it

Think of a forwarded letter. The name on the envelope stays the same, but the postal service looks up a current forwarding address before it delivers the letter.

If it goes wrong

You assumed the number is stored on the SIM.
The number is a public address associated with the subscription. The SIM's internal identity is different.
You expected a sender ID to be routable.
Some sender IDs are display labels only. A reply may fail or go to a different service.

Check yourself

Decide your answer before you reveal it.

Why does number portability require a lookup?

The number no longer implies one fixed carrier. A lookup finds the current serving network before the message is sent.

Is a visible sender name proof of identity?

No. It is a display field. Authentication or a separate verification system is needed to decide who actually sent a message.

How it works

3GPP numbering and addressing rules in 3GPP TS 23.003 distinguish the MSISDN used for addressing from the IMSI used inside the network. A short message gateway asks the home subscriber record where the subscriber is currently served, then forwards the message toward that system. ITU-T E.164 defines the public numbering plan; ITU-T E.212 defines the land mobile identity plan behind IMSI-style identities. Portability databases and national numbering rules decide which network currently owns a number.

Edge cases

  • Alphanumeric sender IDs can be convenient for brands and deceptive for attackers; display text is not an authenticated address.
  • International prefixes, national dialling plans and short codes are different namespaces. A number valid in one country may not route from another.
  • Address lookup can succeed while message delivery fails, for example when the serving system rejects the message or the phone cannot be paged.

Check yourself

Which distinction matters most when debugging a text sent to a number that recently changed carrier?

Separate number ownership from current subscriber state. If portability data or the home record is stale, the gateway can send the message to the wrong serving system even though the number itself is well formed.
