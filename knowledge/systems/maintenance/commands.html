Command helpers

These commands inspect hardware and session state, manage power, and control session actions.

These commands report resource usage, inspect drives and batteries, manage power profiles, and lock or end your desktop session.

Reference and safety

The source column points to the owning command implementation. Lock, logout, reboot and shutdown actions affect the live session or host and must not be tried from this sandbox.
