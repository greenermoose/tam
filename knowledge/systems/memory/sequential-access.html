Sequential access media

Sequential access media store data in an order that is read from beginning to end, or from a current position to a later one. Punch cards, paper tape, and magnetic tape are classic examples: they are simple, durable in the right conditions, and efficient for long streams, but slow when you need one small item in the middle.

Reading in order

Imagine a cassette tape with songs. To reach song five, you move past songs one through four. That is sequential access. A bookshelf is more like random access: you can go straight to the book you want. Early computer media often worked like the tape: the machine read data in sequence.

Why it matters

Sequential media shaped early computing. Programs, data, and backups were stored as ordered records. Many file formats and commands still carry that history, including tar, whose name comes from "tape archive".

Key terms

Sequential access
Accessing data in order, one item after another, rather than jumping directly to any location.
Archive
A collection of files and metadata packed into one stream or file for transport, backup, or long-term storage. An archive preserves names and structure; compression can make it smaller, but compression is separate from archiving.

From punched holes to tape archives

Goal: Understand how physical media represent bits and why tape-style archives are still useful.

Punch cards and paper tape

Punch cards and paper tape store data as patterns of holes in stiff paper or cardstock. A hole at a position means one value; no hole means another. The reader shines light or uses mechanical contacts to detect holes as the card or tape moves through. The material is the paper substrate; the technique is physical perforation. The data is durable as long as the paper is intact, but the medium is bulky, slow, and sensitive to tearing, moisture, and wear.

Magnetic tape

Magnetic tape stores data as magnetized regions on a thin plastic film coated with magnetic material. A write head changes the magnetic orientation of tiny regions as the tape passes. A read head senses those magnetic changes later. Because the tape is a long continuous ribbon, it is naturally sequential: the drive winds to the needed position and then reads or writes a stream.

Worked example: tar and tape archives

The Unix tar command creates a tape archive: a stream of file headers and file data written one after another. Even when you write a .tar file to disk, the format still looks like a tape stream. This is why tar is good for backups and streaming: it can write files in sequence without needing to jump around a lot.

$ work=$(mktemp -d)
$ mkdir -p "$work/data"
$ printf 'log entry\n' > "$work/data/log.txt"
$ tar -cf "$work/backup.tar" -C "$work/data" .
$ tar -tf "$work/backup.tar"
./
./log.txt
$ rm -rf -- "$work"

The first command creates an archive file. The second lists its contents in order. On real tape hardware, listing can mean winding through the tape until the relevant headers are read.

Try it

Run man tar and look for the word "archive". Notice how tar treats input and output as streams, which fits tape, pipes, and files.

If it goes wrong

The archive is hard to search
Sequential formats are efficient for streaming but poor for random lookups. For many small lookups, a filesystem or database is usually a better fit than a raw tape stream.
Tape is slow to restore one file
The drive may need to seek forward through the tape. Modern backup systems often keep catalogs/indexes so they know where files are.

Check yourself

Why is tar called a tape archive?

Because it was designed to write files as a sequential archive stream suitable for tape devices: file headers and data follow one after another.

How it works

Sequential media optimize throughput for long ordered reads/writes. Magnetic tape is still used for archival backup because it has high capacity per cartridge, low cost per byte, and can be stored offline. The trade-off is high access latency: reaching an arbitrary file may require seconds to minutes of winding, positioning, and tape loading. In the scaled table on Memory technology, a minute-long tape mount becomes nearly two millennia if 1 ns is one second.

Archiving vs compression

An archive packs many files into one container. Compression encodes data to use fewer bytes. tar archives; gzip, xz, or zstd compress. A .tar.gz file is an archive that has then been compressed. You can archive without compressing, or compress a single file without creating a multi-file archive.

Environmental and longevity notes

Paper media are vulnerable to humidity, mold, fire, and mechanical damage. Magnetic tape is vulnerable to magnetic fields, temperature, humidity, binder degradation, and mechanical wear. However, tape can be very durable when stored properly and kept offline, which makes it resistant to many online attack paths. It is not immune to physical disaster or media decay.
