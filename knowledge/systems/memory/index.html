Speed at a human scale

Nanoseconds and milliseconds sound similarly small, but they differ by a factor of one million. The table below rescales time so that 1 nanosecond = 1 second. Under that scale, you can feel the gap between CPU cache, RAM, SSD, disk, tape, and network-scale delays.

Actual timeIf 1 ns were 1 secondTypical memory/storage example
1 ns1 secondRoughly a fast CPU cycle or L1 cache reference.
4 ns4 secondsTypical L1 cache hit.
10 ns10 secondsTypical L2 cache hit.
40 ns40 secondsTypical L3 cache hit.
100 ns1 minute 40 secondsTypical DRAM access.
1 µs16 minutes 40 secondsFast NVMe SSD overhead or short I/O path work.
10 µs2 hours 46 minutesVery fast SSD read latency.
100 µs1 day 3 hoursTypical SSD read/write latency range.
1 ms11.6 daysFast network round trip or slow SSD operation.
10 ms115.7 daysTypical hard disk seek/access.
100 ms3.17 yearsSlow disk operation, distant network, or human-noticeable delay.
1 s31.7 yearsWaiting one second for storage is, at CPU scale, a generation.
1 minute1,902 yearsTape mount or long archival retrieval delay.

These values are representative order-of-magnitude examples, not promises for every device. Real latency depends on device model, queue depth, filesystem, cache state, and workload.

Key terms

Memory
Storage used to hold data or instructions. In everyday speech, "memory" often means fast working RAM, while "storage" means persistent disks or flash. Technically, both are memory technologies with different speed, cost, and persistence trade-offs.
Store
To write data so it can be retrieved later. A "data store" is the place where that data is kept: RAM, disk, tape, database, or archive.
Archive
A collection of files and metadata packed together for storage, transport, or backup. An archive may also be compressed, but archiving and compression are different steps. The tar command name comes from "tape archive".
Flash
A non-volatile solid-state memory technology that stores charge in cells and can be erased electrically. Flash keeps data without power, but erase/write operations wear cells over time.
