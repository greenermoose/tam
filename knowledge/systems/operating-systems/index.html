Operating Systems Reference

This page introduces different computer operating systems and why Tamlinux pays attention to them.

Tamlinux uses one operating system as its rootstock and studies others for useful ideas. Fred uses rootstock for the base operating system installed on a host beneath the Tamlinux scion. Our goal is to minimize the size of the rootstock and maximize its speed and efficiency: today Tamlinux uses Arch Linux as its rootstock, with plans to migrate to Void Linux in future versions and to explore a microkernel beyond that. You can read these pages without an internet connection. For the current and planned choices, see Choosing the Rootstock.

How to read an entry

Each system gets a short entry with the same fields where they apply:

Lineagewhether it is independent or derived from another system.
Kernel, init and C librarywhat starts the system and what programs are built against.
Packages and releasesthe package manager, and whether it ships fixed releases or rolls continuously.
Tamlinux rolewhy Tamlinux watches it.

The entries describe lasting design, not current version numbers or release dates, which change too often for an offline guide. Check a project's own site for its latest release.

Roles

A role is a research judgment, not a plan to migrate. Being listed here does not mean Tamlinux adopts a project's code or recommends it to you, and a project being active does not show that it is secure, mature or suited to your hardware.

RoleMeaning
RootstockRuns the current workstation: Arch Linux.
TargetThe first planned replacement rootstock: Void Linux with runit.
FallbackTried if the target has a showstopper: antiX Core with runit.
EvaluateA possible Linux rootstock worth comparing against the target.
Integration donorClose enough to Tamlinux that its fixes and integration work are reviewed directly.
Idea donorStudied for a specific design idea; not a candidate rootstock.
HorizonA system that is not Linux, studied for its architecture.
Tam 2.0 candidateA microkernel-based system explored as a future rootstock. Planned research only.

Reading further offline

Arch Linux publishes its wiki as optional packages, which Tamlinux does not install for you:

arch-wiki-docspages from the Arch Wiki prepared for offline browsing.
arch-wiki-litethe Arch Wiki without HTML, about a ninth of the size and readable in a terminal.

Much of the Arch Wiki applies to other distributions too. On Void Linux, the void-docs package installs the Void Handbook for offline reading. Use tam search <name> to find any system in this guide.
