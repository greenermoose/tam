Plant names used in Tamlinux

This page explains the plant-inspired names used for parts of Tamlinux.

Names for the layers

The botanical analogy names six roles. It helps describe boundaries; it is not evidence that a planned boot or distribution feature is delivered.

  • Greenhouse: The botanical name for the physical computer and its resources.
  • Pot: The botanical name for the environment that starts or contains a bootable system.
  • Nut: The name for a planned minimal bootable Tamlinux environment.
  • Rootstock: The kernel and core system software on which the Tamlinux cultivar is installed.
  • Cultivar: All the software in the Tamlinux release that allows the computer to be used effectively and efficiently by both humans and AI agents.
  • Fruit: Applications you use to get work done.

Rootstock is not a common term, but one that Fred Horch, the Tamlinux developer, made up to explain how Tamlinux works. Fred defines the rootstock to be the set of software that third-parties publish and is necessary to be installed so that the software we write can function properly. The cultivar is all the software in the Tamlinux release that allows the computer to be used effectively and efficiently by both humans and AI agents. Our goal is to minimize the size of the rootstock and maximize its speed and efficiency. Currently we are using Arch Linux as our rootstock but we plan to migrate to Void Linux in future versions of Tamlinux. Beyond that we are considering a microkernel to further reduce the code size of the rootstock and improve its performance per watt.

The minimal nut environment is a design concept, not an installed recovery guarantee. Read the actual deployment and boot procedure for the candidate.

Use the analogy carefully

Follow the glossary links at level 2 for a technical model. Firmware, a boot loader and a virtual machine are distinct mechanisms even when the analogy calls each a pot.
