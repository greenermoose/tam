Tamlinux Terminology: The Botanical Analogy

Names for the layers

The botanical analogy names six roles. It helps describe boundaries; it is not evidence that a planned boot or distribution feature is delivered.

  • Greenhouse: The botanical name for the physical computer and its resources.
  • Pot: The botanical name for the environment that starts or contains a bootable system.
  • Nut: The name for a planned minimal bootable Tamlinux environment.
  • Root-stock: The Linux distribution beneath the Tamlinux workstation.
  • Cultivar: A named variety of the Tamlinux workstation software.
  • Fruit: Applications you use to get work done.

Arch Linux is the current development base; Void Linux is planned. The minimal nut environment is a design concept, not an installed recovery guarantee. Read the actual deployment and boot procedure for the candidate.

Glossary supplies definitions at all levels; the ecosystem overview adds context.

Use the analogy carefully

Follow the glossary links at level 2 for a technical model. Firmware, a boot loader and a virtual machine are distinct mechanisms even when the analogy calls each a pot.

Verify the real boundary

Follow level 3 definitions for limits. The analogy does not establish signing, immutability, portability or a working bootstrap. Those require the actual product design and implementation evidence.
