Digital logic and binary computation

This page explains how electrical voltages represent binary numbers and how logic gates combine to perform arithmetic and store information.

At the physical level, digital computers do not manipulate numbers, words, or images directly. They switch millions or billions of microscopic transistors between conductive and non-conductive states, representing binary 1 and 0 as distinct voltage ranges. By connecting transistors into elementary logic gates, circuit designers construct arithmetic logic units (ALUs) that calculate numbers and sequential registers that store state.

Binary signals, truth tables, and logic gates

Goal: you will be able to explain how high and low voltages represent binary bits, interpret truth tables for fundamental logic gates (AND, OR, NOT, XOR), and evaluate bitwise logic in the terminal.

Why it matters: every instruction executed by your computer boils down to bitwise operations. Understanding Boolean logic clarifies how file permissions are masked, how networking subnets are filtered, and how microprocessors add, subtract, and compare data.

Before you start: open a terminal window (The Shell and Streams). The shell arithmetic expressions in this section execute purely in memory and modify no files.

New to this? In digital electronics, a bit is the smallest unit of information: either 0 or 1. Computers represent 0 as a low voltage (e.g. 0 volts / ground) and 1 as a higher voltage (e.g. +1.0 V or +3.3 V). The shell lets you test these operations directly using $(( ... )) arithmetic syntax.

Worked example: evaluate Boolean logic gates in Bash

$ a=12  # binary 1100
$ b=10  # binary 1010
$ printf "AND: %d & %d = %d\n" "$a" "$b" "$(( a & b ))"
AND: 12 & 10 = 8

$ printf "OR:  %d | %d = %d\n" "$a" "$b" "$(( a | b ))"
OR:  12 | 10 = 14

$ printf "XOR: %d ^ %d = %d\n" "$a" "$b" "$(( a ^ b ))"
XOR: 12 ^ 10 = 6

Captured on a Tamlinux workstation, 2026-11-01.

What just happened

  1. The number 12 in binary is 1100; the number 10 in binary is 1010.
  2. Bitwise AND (&): compares corresponding bits. A bit in the output is 1 only if both input bits are 1. Comparing 1100 and 1010 yields 1000 in binary, which is decimal 8.
  3. Bitwise OR (|): produces a 1 if either or both input bits are 1. Comparing 1100 and 1010 yields 1110, which is decimal 14.
  4. Bitwise XOR (Exclusive OR, ^): produces a 1 only if the input bits are different. Comparing 1100 and 1010 yields 0110, which is decimal 6.

If it goes wrong

printf: -1: invalid number
Bitwise NOT in two's complement inverts all bits including the sign bit, so ~0 evaluates to -1. This is normal signed integer behavior.

Which logic gate outputs 1 only when its two input bits are different from each other?

The XOR (Exclusive OR) gate. It outputs 1 for inputs (0,1) and (1,0), and outputs 0 for (0,0) and (1,1).

Why is the NAND gate called a "universal gate" in computer engineering?

Any possible Boolean function (including AND, OR, NOT, and XOR) can be constructed exclusively out of interconnected NAND gates.

Combinational circuits, adders, and sequential flip-flops

Goal: you will be able to distinguish combinational logic from sequential logic, trace how half and full adders perform integer addition, and understand how clock signals synchronize registers.

Mental model

Combinational Logic (Stateless / Instantaneous):
Inputs ===> [ Logic Gates (Adders, Multiplexers, Decoders, ALU) ] ===> Outputs

Sequential Logic (Stateful / Clock Synchronized):
Data In ===> [ D Flip-Flop / Register ] ===> Data Out (Holds previous value)
                     ^
Clock Pulse ---------+  (Updates only on rising edge: ___/--- )

Digital circuits divide into two fundamental classes:

  • Combinational logic: the output depends strictly and immediately on the current combination of inputs. It has no memory and no concept of past state. Examples include addition circuits, multiplexers, and decoders.
  • Sequential logic: the output depends on both current inputs and past history. It uses feedback loops to store bits, synchronized by a master clock signal. Examples include CPU registers, program counters, and RAM cells.

Worked example: the 1-bit Full Adder

Half Adder (adds 2 bits: A and B):
  Sum   = A XOR B
  Carry = A AND B

Full Adder (adds 3 bits: A, B, and Carry-In):
  Sum       = (A XOR B) XOR Carry_In
  Carry_Out = (A AND B) OR (Carry_In AND (A XOR B))

By chaining 64 full adders together (feeding the Carry-Out of bit 0 into the Carry-In of bit 1, and so forth), the processor constructs a 64-bit Ripple-Carry Adder (or a modern Carry-Lookahead Adder) capable of adding two 64-bit integers in a fraction of a nanosecond inside the Arithmetic Logic Unit (ALU).

Completion task

Complete the description of a D (Data) Flip-Flop. Fill in the missing term (marked with ___):

“A D flip-flop captures the input bit present on its D pin and copies it to the output Q pin strictly on the rising ___ of the system clock signal.”

Fill in edge (or transition). Clock-edge triggering ensures that digital circuits only update state simultaneously, preventing electrical race conditions.

Independent task

Observe how negative numbers are represented in binary using two's complement arithmetic in your shell. Compute $(( -5 )) and inspect how bits invert: $(( ~5 + 1 )).

In two's complement, to negate a number you invert all bits (NOT) and add 1. For example, 5 is ...00000101. Inverting yields ...11111010. Adding 1 produces ...11111011, which represents -5. This enables the ALU to subtract numbers using the exact same adder circuits used for addition.

How does an Arithmetic Logic Unit (ALU) perform subtraction using an addition circuit?

It uses two's complement: it inverts the second operand's bits (using XOR gates) and sets the adder's initial Carry-In bit to 1. This computes A plus (NOT B plus 1) = A minus B using the standard addition hardware.

What is a multiplexer (MUX) and how is it used in a CPU?

A multiplexer is a digital selector switch: it takes multiple data inputs and routes one selected input to the output based on control bits. CPUs use multiplexers to select which register supplies operands to the ALU.

How it works: CMOS switching physics and the ALU pipeline

Modern microprocessors are fabricated using Complementary Metal-Oxide-Semiconductor (CMOS) technology, combining two complementary types of field-effect transistors:

  1. Transistor Operation: An N-channel MOSFET conducts electricity between its source and drain when a positive voltage is applied to its gate terminal. A P-channel MOSFET conducts when zero or low voltage is applied to its gate. In a CMOS inverter, when the input is high (1), the N-MOSFET turns on and connects the output to ground (0), while the P-MOSFET is off. When the input is low (0), the P-MOSFET turns on and pulls the output up to supply voltage (1).
  2. Power Dissipation: In an ideal static state, one of the two networks is always non-conductive, so virtually zero current flows from supply to ground. Power is consumed primarily during switching transitions as load capacitances are charged and discharged: 
    P_dynamic = C_load * V_supply^2 * f_clock * alpha
    where C is capacitance, V is voltage, f is clock frequency, and alpha is switching activity. Because power scales quadratically with voltage, modern processors dynamically drop voltage alongside frequency to conserve energy.
  3. Critical Path and Propagation Delay: Every physical transistor takes a finite number of picoseconds to switch, governed by electron mobility and gate capacitance. The longest chain of combinational gates between two sequential registers is called the critical path. The propagation delay across the critical path sets the strict upper limit on maximum clock frequency: if the clock period is shorter than the critical path delay, flip-flops capture incomplete results, corrupting computation.
  4. The Arithmetic Logic Unit (ALU): The ALU is a multi-function combinational core. It accepts two N-bit operands (A and B) and a function select code from the instruction decoder (such as 001 for ADD, 010 for SUB, 100 for AND, 101 for OR, 110 for XOR, 111 for SHIFT). Internal multiplexers steer the inputs to the requested arithmetic or bitwise circuit and route the result to the output bus, updating hardware status flags (Zero Flag, Sign Flag, Carry Flag, Overflow Flag).

Why Tamlinux chose this

Understanding digital logic physics informs Tamlinux’s workstation design principles. Because dynamic power scales with switching frequency (power scales linearly with frequency), preventing unnecessary CPU wakeups saves significant energy. Operating system daemons that poll every 100 milliseconds force billions of transistors to charge and discharge gate capacitances repeatedly. Tamlinux replaces periodic polling with event-driven Linux kernel mechanisms like epoll, inotify, and Wayland compositor event loops, allowing CPU cores to remain in deep zero-power sleep states.

Edge cases and failure modes

  • Single-Event Upsets (Bit Flips): Cosmic rays or terrestrial alpha particles can deposit charge in a transistor channel, spontaneously flipping a flip-flop or SRAM bit cell without hardware defect. In mission-critical workstations, Error-Correcting Code (ECC) memory detects and corrects single-bit flips in real time using parity syndroming.
  • Subthreshold Leakage: At nanometer scale (e.g., 5 nm and below), transistors cannot shut off completely. Electrons quantum-tunnel through gate oxides, creating static leakage current even when the clock is completely stopped. Modern processors use power-gating switches to completely cut power rails to unused execution units.
  • Clock Skew: Physical variations in wire lengths distribute the clock signal to different registers at slightly different times. If clock skew exceeds the register hold time, data can race through two stages in a single clock cycle (“hold time violation”).

Why does reducing CPU core voltage yield a much greater power reduction than reducing clock frequency alone?

Dynamic power dissipation is proportional to frequency but proportional to the square of voltage (power is proportional to frequency times the square of voltage). Cutting voltage in half reduces power dissipation by a factor of four, making undervolting and dynamic voltage scaling the most potent mechanisms for lowering thermal dissipation and energy consumption.
