Free Software, Open Standards, and Efficiency

Tamlinux builds on the free software tradition and on shared desktop standards, and treats resource efficiency as a design brief rather than an afterthought.

The four essential freedoms

The Free Software Foundation describes four freedoms that users of free software have:

  • Freedom 0: to run the program as you wish, for any purpose.
  • Freedom 1: to study how the program works and change it.
  • Freedom 2: to redistribute copies to help others.
  • Freedom 3: to distribute copies of your modified versions.

Tamlinux distributes its own software under GPL-3.0-or-later. Copyleft keeps these freedoms attached to every copy and every modified version.

Guiding principles for Tamlinux

Fred Horch, the Tamlinux developer, establishes six core engineering and design principles that guide the creation of Tamlinux:

  1. One place to look: Put configuration and information where users naturally expect to find it. Rather than scattering shell aliases across multiple profile scripts, put them all in ~/.bashrc; provide tam as the single entry point for system documentation and checks.
  2. 1 way to do 15 things, not 15 ways to do 1 thing: Curate packages decisively so users escape the "fiddling trap". Provide one excellent terminal (foot) and one standard shell (bash), eliminating paralyzing choice while providing a broad suite of software for diverse tasks.
  3. Ergonomics matter: Optimize keyboard workflows and minimize keystrokes for common tasks. Design intuitive pager keys, concise CLI syntax, and quick orientation shortcuts.
  4. Consistency counts: Standardize essential keybindings and behavioral contracts so muscle memory transfers reliably across terminal, desktop, and editor.
  5. Zero tolerance policy for bugs: Uncover root causes no matter how deep into the stack it is necessary to go. Verify code with automated test suites, memory audits, and strict compiler enforcement.
  6. Gather good ideas from everywhere: Adopt the best design elements from across computing history—Unix stream purity, Plan 9 plumbing, classic Amiga responsiveness, Mac accessibility, and modern Wayland protocols.

Standards and interoperability

Tamlinux follows freedesktop.org (XDG) specifications so that its parts work with the rest of the free desktop:

  • XDG directories: configuration in ~/.config, data in ~/.local/share, and state in ~/.local/state.
  • Standard protocols: the shell talks to the compositor through standard Wayland protocols such as wlr-layer-shell and ext-workspace-v1 wherever they exist.
  • Standard formats: applications are described by .desktop files; icons and menus follow shared specifications.

Resource efficiency

Removing bloat, resident daemons, and polling loops lets Linux run faster and use less power on modern hardware, and keeps older machines in service:

  • No polling loops: work is event-driven and bounded; software sleeps until something happens.
  • No unnecessary daemons: if a feature can be an on-demand command, it should not run permanently in the background.
  • Self-reporting: tools say what they did and what failed, so problems can be diagnosed rather than guessed at.

Human direction

Tamlinux prefers deterministic tools that people direct. AI assistants help develop Tamlinux under human direction, and every public repository records how in its AI_PROVENANCE.md; see AI tooling and human agency.
