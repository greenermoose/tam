Desktop Shell: Quickshell and the Tamlinux Shell

The Tamlinux ecosystem

The desktop shell is the visible interface around your windows: the bar, menus, workspace indicators, notifications, and pop-up panels. Tamlinux keeps window management (the compositor) separate from this presentation layer and builds its own shell, the Tamlinux shell, with Quickshell and Qt Quick.

Why Quickshell

Quickshell is a toolkit for building desktop shells in QML on top of Qt Quick:

  • Declarative and reactive: QML properties bind directly to system state, so the interface updates when the state changes, without polling.
  • Layer-shell panels: bars and panels anchor to screen edges through the wlr-layer-shell protocol and reserve space for themselves.
  • Multiple monitors: a bar per output follows displays as they are connected and disconnected.

Independence from Omarchy

The Tamlinux shell began from components ported from Omarchy 4.0.4, keeping their MIT notices. Tamlinux is removing its remaining Omarchy dependencies, so that a Tamlinux desktop can be installed on a clean machine without any Omarchy software, packages, or servers.

  • Standard protocols first: a shared, compositor-neutral layer reads workspace and output facts from standard Wayland protocols such as ext-workspace-v1 and wl_output; small per-compositor adapters fill only the gaps. This is what lets the same shell move from Hyprland to Sway.
  • Shared components: plugins use a common hover tooltip and a shared version footer in their panels.
  • Copyleft: the shell is maintained publicly in the tamlinux repository under GPL-3.0-or-later.

Alternatives considered

  • Waybar: a capable, lightweight status bar, but focused on bar modules rather than rich interactive panels.
  • Astal and AGS: GTK widget frameworks scripted in TypeScript through GJS.
  • EWW: a standalone widget engine in Rust with its own configuration language, Yuck.
