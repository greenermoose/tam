The Arch Family

This page introduces Arch Linux and related versions of Linux.

Tamlinux currently uses Arch Linux as its rootstock. Rootstock is not a common term, but one that Fred Horch, the Tamlinux developer, made up to explain how Tamlinux works: it is the kernel and core system software on which the Tamlinux cultivar is installed. The cultivar is all the software in the Tamlinux release that allows the computer to be used effectively and efficiently by both humans and AI agents. Fred defines the rootstock to be the set of software that third-parties publish and is necessary to be installed so that the software we write can function properly. Our goal is to minimize the size of the rootstock and maximize its speed and efficiency. Currently we are using Arch Linux as our rootstock but we plan to migrate to Void Linux in future versions of Tamlinux. Beyond that we are considering a microkernel to further reduce the code size of the rootstock and improve its performance per watt. Related systems share some software, so their fixes can sometimes help Tamlinux too.

Arch Linux

  • Lineage: independent.
  • Kernel, init and C library: Linux, systemd, glibc.
  • Packages and releases: pacman, with packages built from short shell recipes called PKGBUILDs. Arch rolls: there are no versions of the whole system, only a continuous stream of updated packages. The Arch User Repository (AUR) holds recipes contributed by users; it is separate from the official repositories and is not vetted by them.
  • Known for: a minimal starting point that the user builds up, and the Arch Wiki, one of the most thorough Linux references.
  • Tamlinux role: rootstock. See Choosing the Rootstock for why, and why Tamlinux plans to move on.

Omarchy

  • Lineage: an opinionated Hyprland desktop installed on top of Arch Linux, with its own package repository. It is a desktop configuration rather than a separate distribution.
  • Tamlinux role: integration donor. Tamlinux began from Omarchy's shell, services, menus and commands, keeps their MIT license notices, and maintains its own copies. New Omarchy releases are reviewed for fixes that also apply to Tamlinux.

CachyOS

  • Lineage: Arch-based.
  • Known for: performance tuning: its own kernels with alternative CPU schedulers, and packages rebuilt for newer x86-64 processor feature levels.
  • Tamlinux role: idea donor for package and update experience, performance and Hyprland integration. Performance claims are checked against evidence before being adopted.

EndeavourOS

  • Lineage: Arch-based, close to plain Arch; the community successor of Antergos.
  • Known for: a graphical installer, a friendly community and documentation, while leaving the system much like Arch.
  • Tamlinux role: idea donor for installation, recovery and documentation.

Manjaro

  • Lineage: Arch-based, with its own repositories and company backing.
  • Known for: holding Arch packages back in testing branches before releasing them to its stable branch, and its hardware-detection tools.
  • Tamlinux role: idea donor for staged updates and hardware experience. Because Manjaro delays packages, Arch packages and Manjaro packages are not interchangeable.

Artix Linux

  • Lineage: Arch-based, without systemd.
  • Kernel and init: Linux, with a choice of OpenRC, runit, s6 or dinit.
  • Packages: pacman, with Artix's own repositories providing service scripts for each init system.
  • Tamlinux role: idea donor for running Arch-family packages with an init system other than systemd, which matters for the runit target. Arch packages and service files cannot be assumed to work on Artix unchanged.
