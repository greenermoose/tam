The Fedora Family

Fedora is where many changes to the Linux desktop appear first. Its family includes the main image-based desktops on Linux, and the projects that build custom images from them.

Fedora Linux

  • Lineage: a community project sponsored by Red Hat; the upstream of CentOS Stream and Red Hat Enterprise Linux.
  • Kernel, init and C library: Linux, systemd, glibc.
  • Packages and releases: RPM packages with dnf. A new release about every six months, each supported for roughly thirteen months.
  • Known for: adopting new desktop technology early, such as Wayland and PipeWire, and a thorough quality-assurance process.
  • Tamlinux role: evaluate as a conventional base, and idea donor for desktop changes and testing.

Fedora Atomic Desktops

  • Lineage: Fedora, delivered differently. Editions include Silverblue (GNOME), Kinoite (KDE Plasma) and Sway Atomic.
  • Design: the system is a read-only image updated as a whole. An update is prepared alongside the running system and takes effect at the next boot, and the previous image stays available to boot if the new one fails. Applications usually come from Flatpak, and development tools run in containers.
  • Tamlinux role: idea donor for the image life cycle. The editions are one family with several profiles, not separate bases. Changes such as dropped FUSE 2 support can break some AppImages.

Universal Blue: Bazzite and Bluefin

  • Lineage: custom images built on Fedora Atomic by the Universal Blue community and rebuilt automatically from their source repositories.
  • Bazzite targets gaming and handheld computers, with extra hardware enablement.
  • Bluefin targets developer workstations.
  • Tamlinux role: idea donors for hardware enablement and for operating workstation images, such as pinning a kernel to keep a file-system module working.

Qubes OS

  • Lineage: independent, built on the Xen hypervisor, with a Fedora-based administrative domain.
  • Design: security by compartmentalization. Work, personal browsing and untrusted files each run in their own virtual machine, called a qube, and throwaway qubes can open a risky file and then vanish.
  • Tamlinux role: idea donor for an architecture very different from a single trusted system. Comparing it needs an explicit threat model and attention to its cost in memory and workflow.
