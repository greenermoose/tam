Independent Distributions

These distributions are built from scratch rather than derived from a larger family. Each made its own choices of init system, C library and package manager, which makes them good comparisons for a minimal base. The Tamlinux target, Void Linux, is one of them.

Void Linux

  • Lineage: independent.
  • Kernel, init and C library: Linux and runit, with a choice of glibc or musl; see Init and service supervision and C standard libraries.
  • Packages and releases: rolling. XBPS installs binary packages, and xbps-src builds them from source templates in a clean environment.
  • Reading offline: the void-docs package installs the Void Handbook.
  • Tamlinux role: target. The glibc profile is evaluated first. The musl profile is evaluated separately, because some software, such as the proprietary NVIDIA driver, does not support musl.

Alpine Linux

  • Lineage: independent.
  • Kernel, init and C library: Linux, OpenRC, musl, with BusyBox for many basic commands.
  • Packages and releases: apk. Stable branches twice a year, and a rolling edge branch.
  • Known for: its very small size, which makes it a favorite base for containers.
  • Tamlinux role: evaluate, for how small a base can be and for portability.

Gentoo Linux

  • Lineage: independent.
  • Init and C library: OpenRC or systemd; glibc or musl.
  • Packages: Portage builds software from recipes called ebuilds, with USE flags to choose which features each program is built with. Gentoo now also offers binary packages, so a machine need not compile everything.
  • Tamlinux role: evaluate, as the most configurable of the major distributions. Building everything from source is slow on older hardware.

Slackware Linux

  • Lineage: independent, and the oldest Linux distribution still maintained.
  • Init: simple BSD-style startup scripts.
  • Packages: plain archives installed with pkgtools, which does not resolve dependencies for you. A stable release, and a -current development branch.
  • Tamlinux role: evaluate, as a traditional, conservative base.

Chimera Linux

  • Lineage: independent.
  • Design: the Linux kernel with core command-line tools taken from FreeBSD, the LLVM compiler toolchain and musl, the dinit service manager, and apk packages built by its own builder.
  • Tamlinux role: evaluate, and idea donor for a modern minimal base without GNU tools or systemd.

Solus

  • Lineage: independent.
  • Packages and releases: eopkg. A curated rolling release: updates are tested together and published once a week rather than as each package changes.
  • Tamlinux role: idea donor for curated, tested delivery to desktop users.

KaOS

  • Lineage: independent, with its own repositories, although it uses pacman.
  • Known for: a narrow focus on one 64-bit architecture and a Qt-based desktop. KaOS was long known for KDE Plasma; its site now names the Niri compositor with the Noctalia shell, and the Dinit init system. Read its current pages rather than older descriptions.
  • Tamlinux role: idea donor for focused Qt integration.

Adélie Linux

  • Lineage: independent, built on musl, with an interest in running on many processor architectures.
  • Tamlinux role: not yet assessed.
