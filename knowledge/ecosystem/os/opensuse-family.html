The openSUSE Family

openSUSE is a community project sponsored by SUSE. Its distributions share RPM packages managed with zypper, Btrfs as the default root file system, and Snapper snapshots that let you boot back into the system as it was before an update. Snapper is described in this guide; see Snapper snapshots.

Two openSUSE tools are useful well beyond openSUSE: openQA tests whole operating-system images automatically, including the graphical desktop, and the Open Build Service builds packages for many distributions from one source.

Tumbleweed

  • Releases: rolling, but each snapshot passes automated openQA testing before release.
  • Tamlinux role: evaluate as a tested rolling base; idea donor for openQA and the Open Build Service.

Leap

  • Releases: fixed releases built from SUSE's enterprise sources, for a stable base. Recent releases add an optional immutable mode.
  • Tamlinux role: evaluate as a stable base.

Slowroll

  • Releases: an experimental flavor between the two, which takes Tumbleweed's changes in less frequent, larger batches.
  • Tamlinux role: evaluate only once its maturity and security update pace are confirmed. It is an example of an update tier, a single source delivered at different speeds.

MicroOS and Leap Micro

  • Design: a read-only root file system changed only by transactional updates. An update is applied to a new Btrfs snapshot, which becomes active at the next boot or is thrown away if it fails.
  • Tamlinux role: idea donor for transactional updates and rollback. MicroOS is aimed at servers and containers, so it is not a desktop base.

Aeon and Kalpa

  • Design: desktops built on the MicroOS technology: Aeon with GNOME, Kalpa with KDE Plasma. The system maintains itself automatically; updates are applied in the background and take effect after a reboot, and applications come from Flatpak, with Distrobox for other software.
  • Status: Aeon has described itself as a release candidate, and Kalpa as experimental. Check their current status before relying on them.
  • Tamlinux role: idea donors for automated desktop maintenance and immutable desktop integration.
