Operating Systems Reference

Tamlinux runs on a base operating system, its root-stock, and watches many other operating systems for fixes and ideas worth bringing home. These pages describe those systems so you can read about them without a network connection or a web search. For the decision itself, which base Tamlinux uses now and which it plans to try next, read Choosing the base operating system.

How to read an entry

Each system gets a short entry with the same fields where they apply:

  • Lineage: whether it is independent or derived from another system.
  • Kernel, init and C library: what starts the system and what programs are built against.
  • Packages and releases: the package manager, and whether it ships fixed releases or rolls continuously.
  • Tamlinux role: why Tamlinux watches it.

The entries describe lasting design, not current version numbers or release dates, which change too often for an offline guide. Check a project's own site for its latest release.

Roles

A role is a research judgment, not a plan to migrate. Being listed here does not mean Tamlinux adopts a project's code or recommends it to you, and a project being active does not show that it is secure, mature or suited to your hardware.

RoleMeaning
BaseRuns the current workstation: Arch Linux.
TargetThe first planned replacement base: Void Linux with runit.
FallbackTried if the target has a showstopper: antiX Core with runit.
EvaluateA possible Linux base worth comparing against the target.
Integration donorClose enough to Tamlinux that its fixes and integration work are reviewed directly.
Idea donorStudied for a specific design idea; not a candidate base.
HorizonA system that is not Linux, studied for its architecture.
Tam 2.0 candidateA microkernel-based system explored as a future base. Planned research only.

Linux distributions

  • The Arch family — Arch Linux, Omarchy, CachyOS, EndeavourOS, Manjaro and Artix.
  • The Debian family — Debian, Ubuntu, Linux Mint, antiX, Devuan, BunsenLabs, elementary OS, Pop!_OS and Vanilla OS.
  • The Fedora family — Fedora, the Atomic desktops, Universal Blue images and Qubes OS.
  • The openSUSE family — Tumbleweed, Leap, Slowroll, MicroOS, Aeon and Kalpa.
  • Independent distributions — Void, Alpine, Gentoo, Slackware, Chimera, Solus, KaOS and Adélie.
  • Declarative distributions — NixOS and GNU Guix System.

Beyond Linux

  • The BSDs — FreeBSD, OpenBSD, NetBSD and DragonFly BSD.
  • illumos — the open descendant of Solaris: OpenIndiana, OmniOS and SmartOS.
  • Microkernel systems and Tam 2.0 — Redox OS and Fuchsia, with seL4, MINIX 3, Genode, HelenOS, GNU Hurd and QNX for comparison.
  • Other independent systems — SerenityOS, Haiku and ReactOS.

Shared environmental goals

  • Environment-minded systems and desktops — wattOS, Emmabuntüs, MiniNo, KDE Eco, Nura, /e/OS, Collapse OS and the campaigns and standards around them. None has a Tamlinux role.

Reading further offline

Arch Linux publishes its wiki as optional packages, which Tamlinux does not install for you:

  • arch-wiki-docs — pages from the Arch Wiki prepared for offline browsing.
  • arch-wiki-lite — the Arch Wiki without HTML, about a ninth of the size and readable in a terminal.

Much of the Arch Wiki applies to other distributions too. On Void Linux, the void-docs package installs the Void Handbook for offline reading. Use tam search <name> to find any system in this guide.
