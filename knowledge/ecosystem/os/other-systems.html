Other Independent Systems

These operating systems are written largely from scratch, kernel and all. None of them is a Tamlinux base or Tam 2.0 candidate; each is studied for one idea it does unusually well.

SerenityOS

  • Design: a Unix-like graphical operating system with a deliberate late-1990s desktop look, where everything, from the kernel and C library to the windowing system and applications, is written in one repository in C++. Applications are built from source rather than installed as binary packages, and its interfaces are not kept stable between versions.
  • History: its web browser grew into the separate Ladybird project, which now runs on other systems too.
  • Tamlinux role: idea donor for a cohesive desktop where every part is designed together. It is not described as a microkernel system.

Haiku

  • Design: an open-source re-creation of BeOS, focused on personal computing, with its own kernel and a desktop that responds quickly because work is spread across many threads.
  • Ideas: its file system stores searchable attributes on files, and its package manager mounts packages in place rather than unpacking them, so removing a package removes everything it brought.
  • Tamlinux role: idea donor for personal-computing design.

ReactOS

  • Design: a free operating system that aims to run Windows applications and drivers directly, by re-creating the Windows NT design. It shares much of its user-space work with Wine. It is still alpha software.
  • Tamlinux role: idea donor for compatibility engineering. Its application model is different enough that comparing it needs separate study.
