Outcome: After this path, you can assess a local model task, run a supported query and check its answer against a named Guide source.

Prerequisites: none beyond reading

Time: About 30 minutes, including checkpoints and the capstone.

If you're stuck: read the program manuals with tam man <command>, list built-in help with tam help, or search this guide with tam search -- <term>.

A local assistant is still a tool

A local model runs on your own hardware, but it does not decide what is true or what ships. You check available memory, recognize the limits, and verify any answer against a named source.

Think of the model as a fast draftsman with a library card. The draft is useful, but the cited book is where you check the claim.
