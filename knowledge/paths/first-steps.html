Two places, one path

The Guide is read in a terminal pager using keys rather than clicks. A separate shell prompt is where you type commands; the pager and the shell are different programs, so you leave one to use the other.

Think of the pager as a book with keyboard page-turning and the shell as a workbench next to it. You can step from the book to the bench and back again.

Read a command and its output

Goal: run one fixed command and distinguish the command from its output

Practice notes. hello /home/alex Documents Downloads The prompt takes a command; the next line is its output. You type only the command. hello is what printf prints. pwd answers a different question: where am I? Try printf '%s\n' hello, or type help.

What just happened

After you press Enter, the shell starts printf with the format and argument you supplied. The word hello is printed output, not text to type. The output shown in this sandbox is a sample from fixed teaching data, not a reading from your machine.

Try it

Run pwd and ls next. Predict which command answers "where am I?" and which one lists names.

If it goes wrong

If you see a continuation prompt, a quote is unfinished. Cancel that line and retype the complete command.

Check your knowledge

Answer before revealing the explanation.

Which text do you type at a shell prompt: the prompt sign, the printf command, or the printed word hello?

Type only the printf command plus the arguments '%s\n' and hello, then press Enter. The dollar sign is the shell prompt in this example; hello is the result. Shell prompts often end with a dollar sign, but not always. Sometimes they end with a slash (/) or a number sign (#) or a colon (:) or another character.

Check yourself

Answer before revealing the explanation.

Which command prints your current directory, and which creates a new empty temporary directory?

pwd prints the current directory. mktemp -d creates a new empty temporary directory and prints its path. cd changes into a directory; ls lists names.

Check yourself

Answer before revealing the explanation.

chmod prints nothing. What do you do before assuming failure?

Inspect the mode with stat, as in the permissions page. Many successful commands print nothing. An error message needs attention; silence alone is not failure.
