What cryptographic tools promise

A cryptographic hash turns data into a fixed-size fingerprint. Encryption protects confidentiality, signatures help prove who wrote a message, and key exchange lets two parties agree on a shared secret. Quantum-safe algorithms are designed for a future with large quantum computers.

Think of a hash as a tamper-evident seal: the seal does not hide the parcel, but changing the parcel changes the seal. A cipher is more like a locked box.

A hash is deterministic: identical input gives identical output. A one-character change gives an unrelated-looking digest. Try printf 'tamlinux' | sha256sum, or type help.

What just happened

The digest is a fixed-length fingerprint of the input bytes. Changing one character changes the whole digest; the sample output comes from the fixed literal string, not from a file on your machine.

Try it

Change the literal to hello and predict whether the digest changes only slightly or completely.

If it goes wrong

If your real terminal prints a different digest, confirm the exact input bytes, including any trailing newline.

Check yourself

Does a hash hide the original message?

No. A hash is a fingerprint; the message must be protected separately if confidentiality matters.

Why does modern cryptography publish its algorithms instead of keeping them secret?

By Kerckhoffs's principle, security rests solely on keeping the key secret so public scrutiny can find flaws and keys can be rotated easily.

Checkpoint

Answer these before you go on.

What happens if you reuse the same (Key, Nonce) pair in AES-GCM?

Reusing a nonce leaks the XOR of plaintexts and allows an attacker to recover the GHASH authentication key and forge future tags.

Checkpoint

Answer these before you go on.

Why can a fast hash like SHA-256 check a file download safely yet still be unsafe for storing user passwords?

Attackers can test billions of password guesses per second against fast hashes; password storage needs salted, memory-hard KDFs like Argon2id or yescrypt.

Checkpoint

Answer these before you go on.

What binds a website's domain name to its public key in HTTPS?

An X.509 certificate signed by a trusted Certificate Authority (and publicly logged in Certificate Transparency).

Checkpoint

Answer these before you go on.

Why do quantum computers break RSA and ECC in polynomial time while AES-256 remains safe?

Shor's algorithm uses the Quantum Fourier Transform to solve factoring and discrete logarithms exponentially faster, whereas Grover's algorithm only halves the effective bit-strength of unstructured symmetric search (leaving AES-256 at ~128-bit quantum security).

Reading the primitives

Use installed tools read-only to list available TLS 1.3 cipher suites, hash algorithms and SSH key exchanges. Treat a listed algorithm as an available option, not proof of what a particular connection negotiated. Post-quantum hybrid exchanges combine a classical method with a quantum-resistant one.
