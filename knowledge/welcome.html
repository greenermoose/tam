Welcome to Tamlinux

Tamlinux is a continuing Linux workstation. This offline guide helps you find your way around, use the system, understand its design, and make changes with care.

Choose what you need

  • Installing — inspect the available installation route and current limits.
  • Desktop overview — open the desktop directly.
  • Learning — choose a guided route or find a reference.
  • Using — desktop, files, shell, and workspaces.
  • Maintaining — updates, diagnostics, snapshots, and recovery.
  • Improving — development and system extension.

In the reader, Tab selects links, Enter follows one, Left Arrow goes Back, backtick opens the Guide, ? shows help, and q quits. Try the documentation lesson or go straight to Guide Search.

The desktop keybinding list is opened with SUPER + K; SUPER + RETURN opens a terminal. See the desktop guide.
