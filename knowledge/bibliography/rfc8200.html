Guide / Sources and further reading / RFC 8200: Internet Protocol, Version 6 (IPv6) Specification

This page points to the IETF specification for IPv6, the 128-bit successor to the original internet protocol.

This reference is for expert readers.

RFC 8200, by S. Deering and B. Hinden (IETF, July 2017). Defines IPv6: the 40-byte base header, traffic class and flow label, Next Header chaining, the hop limit, 128-bit addresses, extension headers, and the rule that routers do not fragment packets. It obsoletes RFC 2460.

Online IETF specification. Free. Open standard. Companion specification: RFC 791 for IPv4.
