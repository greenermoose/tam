RFC 791: Internet Protocol

This page points to the IETF specification for the Internet Protocol, the original datagram service that carries traffic across the internet.

This reference is for expert readers.

RFC 791, by J. Postel (IETF, September 1981). Defines IPv4: the 32-bit address space, the datagram header, type of service, time to live, fragmentation and reassembly, and the addressing classes later replaced by classless addressing.

Online IETF specification. Free. Open standard. Companion specification: RFC 8200 for IPv6.
