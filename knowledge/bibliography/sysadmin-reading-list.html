System Administrator Reading List

This page is a curated reading list for system administrators. It covers the practical knowledge needed to install, operate, secure, troubleshoot, and automate Linux and Unix-like systems. It also includes key references for networking, storage, security, reliability, and incident response.

How to use this list

Start with one practical Linux/Unix administration book, then add networking, security, and automation as you gain experience. Read with a test machine or virtual machine nearby: try commands, break things safely, and practice recovery. System administration is learned by doing careful, repeatable work.

A strong sysadmin foundation includes command-line skills, users and permissions, packages and updates, processes and services, logs, storage and backups, networking, security basics, shell scripting, and troubleshooting.

Core books

Linux and Unix administration

  • Evi Nemeth, Garth Snyder, Trent R. Hein, Ben Whaley, and Dan Mackin, UNIX and Linux System Administration Handbook, Addison-Wesley (recent edition). Broad, practical coverage of Unix/Linux administration across real systems.
  • Brian Ward, How Linux Works: What Every Superuser Should Know, No Starch Press (recent edition). Clear explanation of how Linux systems boot, run processes, use devices, and manage networks.
  • Michael Hausenblas, Learning Modern Linux, O'Reilly, 2022. Modern Linux concepts including containers, cgroups, systemd, observability, and cloud-era tooling.

Operations and professional practice

  • Thomas A. Limoncelli, Christina J. Hogan, and Strata R. Chalup, The Practice of System and Network Administration, Addison-Wesley (recent edition). Operations principles, service management, change management, and professional practice.
  • Betsy Beyer, Chris Jones, Jennifer Petoff, and Niall Richard Murphy (eds.), Site Reliability Engineering: How Google Runs Production Systems, O'Reilly, 2016. SRE practices: SLOs, toil, monitoring, incident response, and release engineering. Also available online.
  • Betsy Beyer, Niall Richard Murphy, David K. Rensin, Kent Kawahara, and Stephen Thorne (eds.), The Site Reliability Workbook, O'Reilly, 2018. Practical SRE implementation examples. Also available online.

Networking

  • James F. Kurose and Keith W. Ross, Computer Networking: A Top-Down Approach, Pearson (recent edition). Networking fundamentals for understanding services, DNS, HTTP, TCP/IP, and troubleshooting.
  • Craig Hunt, TCP/IP Network Administration, O'Reilly, 3rd ed., 2002. Classic practical TCP/IP administration reference; pair with newer distro and kernel documentation for current tools.

Shell, automation, and tooling

  • Arnold Robbins and Nelson H. F. Beebe, Classic Shell Scripting, O'Reilly, 2005. Portable shell scripting and Unix tool use.
  • Brendan Gregg, Systems Performance: Enterprise and the Cloud, Addison-Wesley (recent edition). Performance analysis, profiling, and Linux observability tools.
  • Brendan Gregg, BPF Performance Tools, Addison-Wesley, 2019. Advanced Linux tracing and performance diagnostics using eBPF.

Security

  • Ross J. Anderson, Security Engineering, Wiley (recent edition). Security as a systems problem: threats, controls, human factors, and failures. Also available online.
  • Simson Garfinkel, Gene Spafford, and Alan Schwartz, Practical UNIX and Internet Security, O'Reilly, 3rd ed., 2003. Older but useful security principles; supplement with current platform security guidance.
  • Lee Brotherston and Amanda Berlin, Defensive Security Handbook, O'Reilly, 2017. Practical defensive controls, monitoring, and incident readiness.

Backup, recovery, and reliability

  • W. Curtis Preston, Backup & Recovery, O'Reilly, 2007. Backup principles, restore testing, and recovery planning; supplement with modern object storage and snapshot tooling.
  • John Allspaw and Jesse Robbins, Web Operations: Keeping the Data On Time, O'Reilly, 2010. Operations culture, monitoring, deployment, and incident handling.

Key references, articles, and standards

These references are useful when you need authoritative detail, operational models, or incident-learning material.

Operational practice

  • Richard Cook, "How Complex Systems Fail," Cognitive Technologies Laboratory, 2000. Short, essential paper on failure in complex systems.
  • Gene Kim, Kevin Behr, and George Spafford, The Phoenix Project, IT Revolution Press, 2013. A narrative introduction to DevOps and flow; useful culturally, but pair with technical references.
  • Gene Kim, Jez Humble, Patrick Debois, and John Willis, The DevOps Handbook, IT Revolution Press (recent edition). Practical guidance on flow, feedback, and continuous improvement.

Linux and standards references

  • Linux man-pages. The primary reference for Linux system calls, C library interfaces, and many user-space conventions.
  • man7.org and installed man pages. Use local manual pages first when checking behavior on a specific system.
  • POSIX Shell Command Language. Authoritative shell behavior for portable scripts.
  • Filesystem Hierarchy Standard (FHS), Linux Foundation. Reference for common Linux directory layout conventions.
  • systemd documentation and journalctl manual. Service management and log inspection on systemd-based systems.

Networking and security references

  • RFC 791 (IPv4), RFC 8200 (IPv6), RFC 9293 (TCP), and RFC 768 (UDP). Core Internet protocol references.
  • RFC 8446 (TLS 1.3) and RFC 4251–4254 (SSH). Core secure transport and remote administration protocols.
  • NIST SP 800-series publications (for example SP 800-53, SP 800-61, SP 800-123). Security controls, incident handling, and server security guidance.

Preparation for senior sysadmin / SRE roles

Advanced system administration requires calm debugging, risk management, and clear communication. Aim to be comfortable with:

  • Observability: logs, metrics, traces, and performance analysis.
  • Change discipline: backups, rollback plans, maintenance windows, and tested automation.
  • Security: least privilege, patching, key management, auditing, and incident response.
  • Networking: DNS, routing, firewalls, TLS, and service debugging.
  • Automation: shell, configuration management, infrastructure as code, and repeatable builds.
  • Documentation: runbooks, postmortems, and clear handoffs.

This reference is for readers at all levels.

This reading list is a curated selection of system administration books, papers, and standards. Prefer current editions and verify commands against the documentation for the specific system you administer.

Some listed works are commercially published; check library access or official publisher pages. Some resources are freely available online, including Google SRE books, man7.org, and IETF RFCs.
