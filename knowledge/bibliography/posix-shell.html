POSIX Shell Command Language

This page points to the standard that defines how a portable shell reads, quotes, expands and splits words.

This reference is for expert readers.

Shell Command Language, in The Open Group Base Specifications Issue 8, IEEE Std 1003.1-2024. Section 2.2 defines quoting; section 2.5.3 defines the shell variable IFS; section 2.6 sets the order of word expansions; section 2.6.5 gives the field-splitting algorithm; and section 2.6.7 defines quote removal.

Online standard. Free to read. Copyright The IEEE and The Open Group. Companion reference: GNU Bash manual for the implementation used on Tamlinux.
