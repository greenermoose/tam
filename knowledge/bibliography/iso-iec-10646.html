This page points to the ISO/IEC international character coding standard.

ISO/IEC 10646 (ISO/IEC). Supports the standards-level definition of the Universal Coded Character Set and its alignment with Unicode. Use it when a claim needs an ISO/IEC source rather than a consortium publication.
