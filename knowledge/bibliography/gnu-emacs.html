Guide / Sources and further reading / GNU Emacs manuals

This page points to the official manuals for GNU Emacs and Emacs Lisp.

This reference is for expert readers.

GNU Emacs manuals, by the Free Software Foundation, for GNU Emacs 31.1. The GNU Emacs Manual and the Emacs Lisp Reference Manual cover init-file lookup order, keymaps and commands, the package system, daemon and emacsclient, batch and script modes, native compilation, and file-local variables. The same manuals are installed as Info documentation with the package.

Online at gnu.org and offline through Info when Emacs is installed. Free. GNU Free Documentation License; see the manuals' copying notice.
