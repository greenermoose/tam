ECMA-262: ECMAScript Language Specification

This page points to the ECMA-262 standard that defines the core language implemented by JavaScript engines.

This reference is for advanced readers.

ECMA-262: ECMAScript Language Specification. The current specification published by Ecma International's TC39 committee. Defines syntax, types, abstract operations and built-in objects, but not browser or Node host APIs.

Free HTML and PDF editions. Open standard.
