RFC 9293: Transmission Control Protocol

This page points to the IETF specification for TCP, the transport protocol that gives applications a reliable, ordered byte stream.

This reference is for expert readers.

RFC 9293, by T. Eddy (IETF, August 2022). Defines TCP: connection opening and closing, sequence and acknowledgement numbers, the segment format, retransmission and round-trip measurement, flow control with advertised windows, and congestion control. It obsoletes RFC 793 and consolidates later updates.

Online IETF specification. Free. Open standard. Companion protocol: RFC 768 for UDP.
