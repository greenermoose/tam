This page points to the reference manual for Vim and its differences from vi.

This reference is for expert readers.

Vim documentation, by Bram Moolenaar and contributors, for Vim 9.2. The reference manual covers vi-compatible mode and the compatible option, swap files and recovery, modelines, encoding conversion, ex mode, and the Charityware license terms. The same files are installed at /usr/share/vim/ when Vim is installed.

Online at vimhelp.org and offline with the package. Free. Vim license (Charityware, GPL-compatible); see uganda.txt in the documentation.
