RFC 768: User Datagram Protocol

This page points to the IETF specification for UDP, the transport protocol that sends independent messages without setting up a connection.

This reference is for expert readers.

RFC 768, by J. Postel (IETF, August 1980). Defines UDP: the eight-byte header of source port, destination port, length and checksum, and the datagram service built on top of the internet protocol. It carries no ordering, acknowledgement or retransmission mechanism.

Online IETF specification. Free. Open standard. Companion protocol: RFC 9293 for TCP.
