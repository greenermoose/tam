Linux man-pages

The Linux man-pages project documents the Linux kernel and GNU C library interfaces: system calls, library functions, special files, file formats, conventions, and overview pages. It is the primary reference when you need to know exactly what a Linux interface does.

What this reference is

A manual page, or "man page", is a built-in help document on Linux systems. The Linux man-pages project maintains many of the most important ones, especially pages for system calls like open(2), library functions like printf(3), and overview topics like pipe(7).

When a guide says "see stat(2)", it means: open the manual page named stat in section 2. You can read it on your computer with man 2 stat, or online at man7.org.

How to use it well

Use Linux man-pages when you need precise behavior: arguments, return values, errors, edge cases, portability notes, and related interfaces. Start with the page named in the guide, then follow its "SEE ALSO" section to nearby concepts.

Examples of common sections:

  • 1 - user commands
  • 2 - system calls
  • 3 - C library functions
  • 5 - file formats and conventions
  • 7 - overviews, topics, and conventions

Check the local page on your system first when behavior may differ by kernel or library version. The online copy is convenient, but your installed system is authoritative for that machine.

Scope, versions, and limits

The Linux man-pages project covers Linux kernel-user-space interfaces and many glibc interfaces, but it is not the only manual source on a system. Other packages install their own pages; POSIX, architecture manuals, and project documentation may be authoritative for specific standards or hardware behavior.

Read the "NOTES", "BUGS", "CONFORMING TO", and "VERSIONS" sections carefully. They often contain the portability constraints and kernel-version details that matter in real system programming. When a page and observed behavior disagree, check the kernel/libc version, the page version, and the relevant source or specification.

Useful starting points include man-pages(7), intro(2), intro(3), syscalls(2), and topic pages such as pipe(7), inode(7), and path_resolution(7).

This reference is for readers at all levels.
