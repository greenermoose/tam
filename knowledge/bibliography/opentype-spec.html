Guide / Sources and further reading / OpenType specification 1.9.1

This page points to the OpenType specification used for font tables and layout features.

This reference is for expert readers.

OpenType specification 1.9.1 (Microsoft). Supports the authoritative table layout, glyph metric fields, character-to-glyph mapping and the GSUB/GPOS shaping model. Use it for the precise semantics of OpenType tables and feature tags.
