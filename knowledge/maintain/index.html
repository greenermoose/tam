System Maintenance and Reliability

A dependable workstation is one whose state is understandable, observable, and reversible. Tamlinux structures system maintenance around non-disruptive updates, generation rollbacks, truthful diagnostics, progressive power management, emergency recovery, and reliable boot recovery.

The five maintenance pillars

Non-disruptive updates and package lifecycle
Understand how Linux updates binaries in place without forced restarts through inode unlinking, and how Tamlinux organizes software into distinct, manageable package tiers.
Snapshots and generation rollbacks
Leverage Copy-on-Write (CoW) filesystem mechanics with Btrfs snapshots and Home Manager generation rollbacks to make any software change reversible in seconds.
Truthful system diagnostics and logs
Isolate faults quickly by filtering systemd journal streams by boot, unit, and severity, and inspecting the kernel ring buffer with dmesg.
The progressive power ladder
Follow the three-stage power progression from individual DPMS monitor blanking to RAM suspend and zero-watt S4 disk hibernation, using safe keyboard wake conventions.
Emergency disaster recovery
Recover calmly from frozen graphical sessions or unbootable states using virtual consoles, the Magic SysRq (REISUB) sequence, and live USB chroot environments.
Linux boot fallbacks and rescue routes
Choose among alternate firmware paths, kernels, snapshots, virtual consoles and external rescue media by understanding which parts of boot each route still needs.
Snapper: Btrfs snapshots for system rollbacks
Use Snapper to manage Btrfs root snapshots, automatic pre-update checkpoints, and Limine boot integration via limine-snapper-sync.

Automated inspection and health checks

The tam command provides built-in, read-only tools to inspect your machine's hardware configuration and evaluate maintenance health without modifying any system state:

tam inspect
tam check

tam inspect audits host facts, architecture, DRM graphics controllers, storage mounts, and privilege escalation tools. tam check evaluates these findings against the versioned offline Check Contract (verifying Btrfs snapshot capabilities, adequate disk space headroom, and pkexec privilege tools), deep-linking directly to the relevant maintenance guides above when corrective steps are recommended.
