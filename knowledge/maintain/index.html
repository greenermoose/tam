Automated inspection and health checks

The tam command provides built-in, read-only tools to inspect your machine's hardware configuration and evaluate maintenance health without modifying any system state:

tam inspect
tam check

tam inspect audits host facts, architecture, DRM graphics controllers, storage mounts, and privilege escalation tools. tam check evaluates these findings against the versioned offline Check Contract (verifying Btrfs snapshot capabilities, adequate disk space headroom, and pkexec privilege tools), deep-linking directly to the relevant maintenance guides above when corrective steps are recommended.

The Operating system row names the installed distribution from /etc/os-release, falling back to /usr/lib/os-release, for example Arch Linux (rolling). An OS version row appears only when the distribution records a VERSION_ID. Tamlinux is a workstation environment that runs on that distribution, so it appears on its own row, Tamlinux cultivar, with its cultivar name and version (for example Incipiens 0.4.5). Tamlinux is deployed per user: the row reads the version and name from that user's ~/.config/tamlinux/version and ~/.config/tamlinux/cultivar. Run through pkexec, tam reports the user who ran it; for a user with no deployment the row says it is not deployed.

Two findings cover this identity. os_identity warns when /etc/os-release names a different distribution from /usr/lib/os-release, which is a leftover override from an earlier installation. tamlinux_version reports whether Tamlinux is deployed for the user; running as root itself is not a problem, because root has no deployment of its own.
