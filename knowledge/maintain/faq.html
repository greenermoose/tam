Maintaining FAQ

This page answers common maintenance questions before you dive into long guides.

Where do I start when something is wrong?
Record the symptom and time, then open the symptom index.
Will a rollback restore my documents?
Not necessarily. Snapshots and generations cover configured software boundaries. Documents need their own backup story. See rollback.
The machine will not boot. What do I read?
Will not boot, then boot phases and boot recovery.
A command version looks wrong after an update.
Wrong binary — check PATH and development prefixes before assuming a failed transaction.
Is SDDM required to log in?
Not on current console-first cultivars. Sign in at text login and run tam-desktop for graphics. See login routes.
