Wrong binary after an update

This page helps when a command version looks wrong after an update.

Checks

  1. Run command -v and tam --version or the tool's version flag.
  2. Distinguish a ~/.local/dev development build from a packaged generation.
  3. Read package versions and updates.

Check yourself

What should you record before changing the system?

The symptom, time, and what you have not yet measured.
