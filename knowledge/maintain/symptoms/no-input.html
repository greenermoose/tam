Keyboard or mouse dead in the GUI

This page helps when pointers or keys fail only in the graphical desktop.

Checks

  1. Confirm input on a text VT.
  2. If VT works, inspect seat/compositor/libinput paths (evdev).
  3. If VT fails too, suspect hardware, USB, or early input stack.

Check yourself

What should you record before changing the system?

The symptom, time, and what you have not yet measured.
