Guide / Programming / Application interfaces / ncurses

ncurses is a library that helps a text program draw a full-screen interface. It works out each terminal’s controls from terminfo data.

Drawing on a text screen

ncurses gives a C program a virtual screen to draw on. It then sends only the needed changes, using the right control codes for that terminal.

Why it matters

A program does not need to know every terminal's escape sequences. Terminfo describes them, and ncurses reads the description.

How to think about it

Imagine a stage manager with a script that says where each actor stands. The manager adapts the instructions to the size and shape of each theatre.

What does terminfo provide?

Terminal capability descriptions: what codes move the cursor, clear the screen and set attributes.

Why use ncursesw?

It supports wide characters such as UTF-8 text, not just single-byte characters.

How it works

ncurses keeps a desired screen and an actual screen, computes a minimal diff, and emits the capability codes needed to transform one into the other. curs_terminfo(3) loads the description selected by TERM. Incorrect TERM values produce garbled output even when the program is correct.

Edge cases and failure modes

  • Resizing requires a refresh and a fresh capabilities query.
  • Combining characters and variable-width glyphs need careful layout.
  • Some terminals advertise capabilities they implement poorly.
  • Mixing raw escape sequences with ncurses corrupts its screen model.
