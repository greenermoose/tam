Guide / Programming / Web development / Browser engines and the document object model

A browser engine turns page files into a live document that a script can inspect and change.

From file to live page

A web browser reads HTML and builds a tree of objects. That tree is the document object model, or DOM.

Why it matters

Scripts change the DOM, and the browser redraws what changed. Knowing the tree helps you understand why a selector finds one element and not another.

How to think about it

HTML starts as a shopping list; the DOM is the organised set of labelled boxes on the shelf. A script can move a box, and the display follows.

Map markup to a tree

Goal: read a sample DOM tree and name its parent-child links.

#document > main main > h1 main > p #document > main main > h1 main > p #document > main main > h1 main > p Try: cat tree.txt Type grep main tree.txt to see every line that mentions main. Try cat tree.txt, or grep main tree.txt (or type help).

What just happened

The sample tree has one document node containing main, which contains a heading and a paragraph. The browser builds a tree like this from markup. The file is a simplified sample, not a live parse of a page in your browser.

Try it

Run head -n 1 tree.txt. That root line reminds you that even a tiny page lives under a document node.

What is a DOM node?

An object in the tree representing an element, text, or the document itself.

Why can JavaScript change a page?

It changes DOM objects; the engine then recalculates layout and repaints.

How it works

The parser is tolerant: malformed markup produces a tree anyway, following the error-recovery rules in the HTML standard. A just-in-time compiler speeds up repeated JavaScript work. Touching layout properties in a loop can force repeated reflows.

Edge cases and failure modes

  • Text nodes and whitespace affect selectors and layout.
  • Shadow DOM creates separate trees with encapsulation.
  • Parser-inserted elements may appear where source did not show them.
  • Reading layout after writing style can trigger synchronous reflow.
