Guide / Programming / Web development / JavaScript and its history

JavaScript lets a web page respond to what a person does. The same language also runs in servers and desktop programs.

A language for action

JavaScript is an interpreted language whose standard is called ECMAScript. In a browser it can change the DOM after a click or key press.

Why it matters

Without it, pages would mostly be static documents. With it, they can validate input, animate and fetch new information.

How to think about it

HTML lays out the stage, CSS costumes the actors, and JavaScript gives them instructions for what to do next.

What does map do?

Calls a function for each element and returns a new array of results.

Why does JavaScript appear outside browsers?

The language standard is separate from the browser, so runtimes such as Node can host it.

How it works

An engine parses source, compiles it and executes it on an event loop. The language core says little about files or networking; host environments add those APIs. Browser APIs differ from Node APIs, even though the syntax is shared.

Edge cases and failure modes

  • this binding differs between ordinary and arrow functions.
  • Equality coercions produce surprising results; prefer strict equality.
  • Async errors need explicit rejection handling.
  • Numeric precision follows IEEE 754 doubles.
