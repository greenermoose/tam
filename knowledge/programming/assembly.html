Guide / Programming / Assembly language programming and machine code

Assembly language gives short names to the numeric instructions a processor runs. A program called an assembler turns those names into machine code.

Words for machine instructions

Machine code is made of numbers the CPU follows directly. Assembly replaces those numbers with readable names called mnemonics.

Why it matters

Reading a little assembly helps you understand compiler output, ABI calls and why a small C function may become a handful of instructions.

How to think about it

It is like a recipe written in kitchen shorthand. The shorthand is easier for a person to read, while the oven still follows the same steps.

New words

Register
A tiny, fast storage slot inside the processor.
Disassembler
A tool that turns machine code back into assembly text.

How it works

Assembly is tied to an instruction set and an assembler syntax. The GNU toolchain uses AT&T syntax by default; Intel syntax rearranges operands. Position-independent code uses RIP-relative addressing so ASLR can move a loaded program without rewriting every address.

Edge cases and failure modes

  • Extended instructions such as AVX2 depend on CPU features.
  • Hand-written assembly must preserve the ABI's callee-saved registers.
  • Disassembly cannot recover source comments or original variable names.
  • Self-modifying and data-dependent code defeat simple static reading.
