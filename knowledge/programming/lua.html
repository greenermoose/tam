Guide / Programming / Lua: a language for giving programs instructions

Lua is a small programming language that other programs can embed. On this system it helps configure desktop tools and can be driven from C.

A small language inside a bigger one

Lua is a lightweight language with a small core. A larger program can include a Lua interpreter and let you configure it with short scripts.

Why it matters

Desktop tools can expose a simple scripting language without shipping a huge runtime. You can change behaviour without rebuilding the main program.

How to think about it

Lua is like a notebook tucked into a toolbox. The toolbox does the heavy work; the notebook records short instructions you can rewrite.

Why embed Lua rather than a full language runtime?

Lua has a small core and a C API, so a host program can expose scripting cheaply.

How it works

An embedded interpreter exposes a stack-based C API. The host registers functions, loads a chunk, and calls it with arguments. Concatenation converts numbers to strings, while tables provide the main data structure for configuration.

Edge cases and failure modes

  • Bytecode is not portable across Lua versions.
  • Untrusted scripts need a restricted environment.
  • Global state shared between chunks can leak configuration between reloads.
  • Long-running chunks block the host unless explicitly yielded.
