Guide / Programming / Numbers in computers / Number systems and bases

A number system is a way to write counts with digits. Computers mostly use binary because their circuits have two stable states.

Different ways to write a count

Binary uses two digits, octal uses eight, decimal uses ten, and hexadecimal uses sixteen. They are different notations for the same value.

Why it matters

Hexadecimal is a compact way to write bit patterns, which is why memory addresses and colour values often use it.

How to think about it

It is like writing the same price in different currencies with fixed exchange rules. The amount is unchanged; only the notation changes.

Try it

Why is hex convenient for bit patterns?

One hex digit maps cleanly to four bits, so long binary strings become short.

What is endianness?

The order in which a multi-byte value's bytes are stored or transmitted.

How it works

A positional system gives each digit a weight of baseposition. Converting between bases repeatedly divides or groups digits. Endianness applies after a value has been split into bytes; little-endian stores the least significant byte first.

Edge cases and failure modes

  • Leading zeros signal octal in some languages, not decimal.
  • Signed values interpreted with the wrong width change meaning.
  • Network protocols choose a canonical byte order.
  • Unaligned multi-byte loads can be slow or invalid on some architectures.
