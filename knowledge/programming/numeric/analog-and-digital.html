Guide / Programming / Numbers in computers / Analog values and digital approximations

Analog values change smoothly, but a computer stores a finite set of numbers. Sampling and quantization turn a changing value into codes a program can keep.

From smooth to stepped

An analog value can be any value in a range. A digital system stores one of a fixed set of codes. Sampling chooses moments; quantization rounds each moment to the nearest available code.

Why it matters

Audio, temperature and light all arrive smoothly. Converters turn them into numbers software can store, send and process.

How to think about it

Reading a thermometer to the nearest degree is quantization. Looking at it once per minute is sampling. You lose detail in both steps.

What just happened

With sixteen levels the step size is about 1/15 volt. An input that sits between steps rounds to the nearest code, so coming back through a digital-to-analog converter gives a slightly different voltage. The table is sample output, not a reading from a converter.

How many distinct codes are available, and therefore how small each step is.

What happens if sampling is too slow?

High frequencies can alias, appearing as lower frequencies in the samples.

How it works

An ideal sampler takes values at regular intervals. Quantization maps each to the nearest code. Reconstruction filters smooth the stepped output back into a continuous signal. Pulse-code modulation is the common digital representation.

Edge cases and failure modes

  • Aliasing folds frequencies above half the sample rate into lower bins.
  • Dither trades a fixed pattern for less objectionable noise.
  • Non-linear codecs allocate more codes to quiet sounds.
  • Clock jitter becomes phase noise at high frequencies.
