Guide / Programming / Numbers in computers / Whole numbers in binary memory

A fixed group of bits can store a whole number. Whether negative values exist depends on how the bit patterns are interpreted.

Bit patterns as numbers

Eight bits give 256 patterns. If one pattern group is reserved for negative values, the range changes. Two's complement is the common way computers represent signed integers.

Why it matters

Adding one past the largest value wraps around. That is overflow, and it can produce a valid-looking but wrong answer.

How to think about it

Think of a car odometer with a fixed number of wheels. Past the last digit it rolls back to zero rather than growing another wheel.

What just happened

The pattern 11111011 represents -5 in eight-bit two's complement. The highest bit acts as a sign weight of -128. Adding one to the largest unsigned eight-bit value gives zero with overflow. The table is sample data, not a live calculation.

Try it

Run grep overflow bits.txt. Overflow is not an error the bits can record by themselves; the program must check for it or use a wider type.

What does the top bit mean in two's complement?

It acts as a negative weight, so patterns with that bit set represent negative values.

What is overflow?

A result outside the range the fixed bit width can represent, which wraps or is flagged.

How it works

The same bit pattern can be read as signed or unsigned; the ABI and type decide which. Two's complement makes addition and subtraction use the same hardware as unsigned values. Arbitrary precision libraries avoid fixed-width overflow at the cost of speed.

Edge cases and failure modes

  • Shifting negative signed values has language-defined behaviour.
  • Converting between signed and unsigned widths can sign-extend or truncate.
  • Sanitizers catch some signed overflow, not every wrap.
  • Serialization must agree on width and byte order.
