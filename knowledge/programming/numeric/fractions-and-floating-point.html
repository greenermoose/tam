Guide / Programming / Numbers in computers / Fractions, decimals and floating point

Computers can store fractions with a fixed decimal point, with floating point, or as exact ratios. Each choice trades range, precision and speed.

Bits below the point

In fixed point, a set number of bits sit after the point. In floating point, an exponent moves the point, much like scientific notation.

Why it matters

Fixed point is predictable but has a narrow range. Floating point covers huge and tiny values but can round in surprising ways.

How to think about it

Fixed point is a ruler marked in millimetres. Floating point is a label that says how big the marks are for this particular measurement.

Why is 0.1 not exact in binary?

Its exact value needs a repeating binary fraction, but a float has finitely many significand bits.

When might fixed point be preferable?

When the range is known and predictable rounding matters more than covering huge magnitudes.

How it works

A binary float is roughly sign × significand × 2exponent. Rounding occurs whenever the exact result needs more bits than the format holds. Overflow and underflow move results outside the representable range.

Edge cases and failure modes

  • Comparing floats for equality is fragile after arithmetic.
  • Catastrophic cancellation loses digits when nearby values are subtracted.
  • Subnormal handling varies with hardware and compiler settings.
  • Decimal types help with money but still need defined rounding rules.
