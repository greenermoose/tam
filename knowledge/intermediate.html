Intermediate path

Outcome: adapt shell examples in a scratch directory, inspect processes and resources, read available logs, and explain package ownership and snapshot boundaries.

Prerequisites: basic command-line use and comfort reading the beginner pipeline lesson.

  1. Adapt a pipeline using your own sample text in a temporary directory. Try a permission change only on a file you created there with the permissions lesson; remove the scratch directory when done.
  2. Inspect your own process list with ps and memory with free; compare the output with resource guidance.
  3. Read the logs lesson. If your system exposes user journal entries, inspect them read-only with journalctl --user -b; an empty result is possible.
  4. Read package ownership and delivery layers and snapshot boundaries. Identify which layer owns a tool before considering any change.
  5. Use Find by keyword for a command you encountered. Compare the short description with its manual page.

Self-check: explain why a scratch permission change cannot test system-wide ownership, which package manager owns a given layer according to its documentation, and what a snapshot does and does not cover. Hint: follow each layer to its owner and read the rollback scope carefully.
