Capstone

Prepare the Keep it healthy change record and add one shell failure hypothesis supported by the jobs or pipeline lesson.

Query the chosen native package owner and installed version read-only. Record the relevant process/service and log scope, proposed verification and required recovery evidence. Distinguish a wrong PATH selection from a running old process. Missing evidence keeps the transaction pending; this task does not apply an update.
