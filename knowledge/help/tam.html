Guide / Navigation Help / Using the tam guide command

This page explains how to find and read information in the Tamlinux guide.

What is the tam command for?

tam is the built-in command that opens the Tamlinux offline knowledge system—connecting this Guide, keyword search, the glossary, manual pages, Info manuals, and quick command summaries in one reader.

Why it matters

A search, a manual page, and a teaching guide each answer a different kind of question. Having one fast offline entry point lets you jump straight to the right kind of help without leaving your keyboard or needing the internet.

How to think about it

Think of tam as the front desk of a local library: whether you want a gentle lesson, a dictionary definition, or a complete technical manual, you ask at the same desk and it hands you the right shelf.

New words

Command
A program you invoke by name in a terminal.
Terminal
The text screen where the tam reader runs.

Find a guide entry

Goal: choose a tam entry point and navigate back to the Guide.

Before you start: The example displays help without changing files.

New to this? Start in the Guide; follow links with the reader and press Left Arrow to return through history. At a terminal, do not type a leading dollar sign shown as a prompt.

Try the idea in a sandbox

tam 0.69.7 (corpus 0.127.0) Try: tam --version The command reports both component versions. The reader and corpus versions can change independently. Try the command shown above (or type help).

The output is fixed teaching data; the sandbox does not inspect or alter your system.

Open and find material

  • tam show opens the guide root, and dynamic learning paths track your active topic path across pages.
  • tam show terminal/shell/pipelines?level=novice opens a topic at a supported depth.
  • tam search "permissions" searches the guide; in the reader choose Search to enter a query.
  • tam explain --level expert lists topics with that depth.
  • tam where /usr/bin/bash shows bundle or native package ownership read-only.

Use references

Open tldr pages for concise command examples, Man pages to find an installed manual by name, section, or keyword, and tam info to open the installed Info directory. The documentation lesson explains how to move among Guide, tldr, Man, and Info while keeping history.

Return to the guide with the backtick key. Press ? for help and q to leave the reader. See safe practice to try these actions without changing system state.

Try it

Open tam show and follow one link, then press Left Arrow.

If it goes wrong

If tam is not found, check whether it is installed and which command path your shell uses; do not install a copy just to complete this lesson.

Check yourself

Does tam search execute the commands it finds?

No. It searches guide content; reading a result is separate from executing an example.

What should you do when a result differs from the example?

Read the result and the relevant documentation, then check the input and prerequisites before changing anything.

Expert reference

The command and bundled corpus have independent version numbers.
