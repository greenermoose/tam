Guide / Navigation Help / Choose a starting level

This page helps you decide where to start learning.

These suggestions are not a test, and the guide does not save your answers. Press 0 to see all levels, or 1, 2, or 3 to choose one.

Novice

Choose this if you want a complete example, an explanation of each command and a safe place to try it.

Does a command that prints nothing necessarily fail?

No. Many successful commands are silent. Learn how to inspect the result and recognize error messages before changing the system.

Start at Novice (1).

Learner

Choose this if you can run commands and want to adapt them, choose between options and diagnose common failures.

A pipeline exits successfully after its producer printed an error. What might you check?

Inspect each stage and stderr. A shell can report the last command status even when an earlier stage failed. Knowing the syntax is less useful here than checking the evidence.

Start at Keep it healthy (2) or browse all topic paths.

Expert

Choose this if you want precise semantics, experiments and evidence for unfamiliar failures.

A package path is new but a running process is old. Which boundaries could explain it?

Compare the selected path, package identity and existing process mappings. Name replacement need not change an open inode. Separate mutable state, software and boot recovery before choosing an intervention.

Start at Diagnose from first principles (3) or browse all topic paths.

You do not need to answer every question to choose. Check the skills map domain by domain, or try a goal path.
