Use a second display

This recipe helps you attach a second display and check the cable path.

Steps

  1. Connect HDMI or DisplayPort with the panel powered on.
  2. Select the matching input on the panel.
  3. If the image is missing, try a known-good cable and port before changing software.
  4. Read display cables and Display and GPU.

Check yourself

What should you verify before blaming the compositor?

Panel power, input selection, and cable/port.
