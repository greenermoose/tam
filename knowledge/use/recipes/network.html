Check the network

This recipe shows read-only checks when the network seems broken.

Steps

  1. Read Networking.
  2. Note whether the link light or status shows connected.
  3. From a terminal, try a status command documented on that page or in the Network commands reference; do not change configuration yet.
  4. Separate "no link", "link but no address", and "address but no names" before changing settings.

Check yourself

Should you reorder DNS as the first step when the cable is unplugged?

No. Establish link state first.
