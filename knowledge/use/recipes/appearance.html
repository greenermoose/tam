Change appearance with an undo plan

This recipe shows how to prepare an undo plan before changing appearance.

Steps

  1. Follow Make it yours.
  2. Write the current value, the file or owner, how you will verify, and how you will restore.
  3. Practice in a temporary file first via the editor lesson.
  4. Apply a live change only when those four notes exist.

Check yourself

What four notes belong in an undo plan?

Current value, owner/file, verification, restore method.
