Open an application

This recipe shows how to open the applications menu on the packaged desktop.

Steps

  1. Press Ctrl + F12 to open the applications menu.
  2. Type part of the application name if a filter is offered, then select it.
  3. Press Meta + K if you need the full keybinding list.

Authority: packaged utilities.lua binds Ctrl + F12 to the apps menu.

Check yourself

What opens the apps menu?

Ctrl + F12, not Meta + Alt + Space.
