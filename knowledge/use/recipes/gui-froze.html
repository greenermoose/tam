Graphical desktop froze

This recipe shows a calm path when the graphical desktop stops responding.

Steps

  1. Press Ctrl + Alt + F2 (try F3 if needed) for a text virtual console.
  2. Sign in if prompted. Record the time and last action.
  3. Do not power off yet if the console works.
  4. Continue with blank screen or no input symptom pages as they match.
