Reading PDFs, documents, and printing

This page explains how to open PDF and office documents on Tamlinux and how to check available document viewers and CUPS printing safely before changing printer settings.

Opening a PDF or document file

When someone sends you a PDF form or manual, you can open it from the Files window (Meta + Shift + F) or run tam-open <file.pdf> in a terminal. Tamlinux automatically looks for an installed viewer (such as zathura, evince, or chromium).

Why it matters

Opening a read-only viewer lets you read pages, search text, and check layout without altering the original file.

How to think about it

tam-open inspects the file format itself rather than guessing blindly, then hands the document to whichever supported viewer is present on your workstation.

New words

File
A stored document such as a PDF, text note, or spreadsheet on disk.
Executable
An installed viewer or tool program available on your PATH.

Verify viewers and printer availability read-only

Goal: check which PDF viewer and print queues are active on your machine read-only before opening or printing documents.

Before you start: checking installed commands and print queue status is read-only and prints nothing to paper.

Worked example

Check which PDF viewers are currently on your PATH and whether CUPS (Common Unix Printing System) has configured queues:

$ command -v zathura evince chromium
$ lpstat -p 2>/dev/null || echo "No printer queues configured"

When a PDF viewer such as zathura or evince is installed, tam-open report.pdf launches it directly in a graphical session; if neither dedicated viewer is installed, tam-open falls back to Chromium to display the PDF.

Try it

Run command -v zathura evince chromium in your terminal to see which PDF viewer your system would pick first.

If it goes wrong

A PDF opens in the browser instead of a dedicated viewer
No dedicated viewer (zathura or evince) was found in PATH. Install one with tam-pkg-install if you prefer a keyboard-driven viewer.
Printing fails or prints nothing
Check systemctl status cups read-only and inspect lpstat -t before re-sending a print job multiple times.

Tamlinux hardens CUPS system-group ownership defaults in native system configuration; inspect printer status with lpstat before reaching for administrator privileges.

Check yourself

Answer before revealing the explanation.

In what order does tam-open look for a graphical PDF viewer?

It checks for zathura, then evince, then falls back to chromium if installed.

How can you check whether any printers are ready without printing a test page?

Run lpstat -p read-only.
