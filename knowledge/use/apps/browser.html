Opening the web browser and setting your default

This page shows how to open the web browser, start a private browsing window, and choose which installed browser handles links by default.

Opening web pages cleanly

Press Meta + Shift + B to open or focus your web browser on the Tamlinux desktop, or choose a browser from the applications menu (Ctrl + F12).

Why it matters

Knowing the browser shortcut and default setting stops links clicked inside terminals, documents, or chat tools from opening an unexpected browser.

How to think about it

The desktop tracks one preferred browser via XDG desktop handlers so any command or clicked URL asks that browser to open it.

New words

HTTP
Hypertext Transfer Protocol, the standard language web browsers use to fetch web pages (encrypted as HTTPS).
Default handler
The application that the desktop automatically launches when you open a matching file type or web link.

Launch, private mode, and check default browser

Goal: inspect the currently configured default browser read-only, open a private session, and know how Tamlinux switches defaults reversibly.

Before you start: checking tam-default-browser with no arguments is read-only. Passing a browser name updates your XDG default browser handler and can be reversed at any time by passing the previous name.

Worked example

Print the current default browser identifier and resolve its launcher command read-only without launching a window:

$ tam-default-browser
$ tam-browser-command chromium.desktop

To launch your default browser from a terminal (or open a private browsing window without leaving history in your normal profile):

$ tam-launch-browser --private

Supported defaults in tam-default-browser include chromium, chrome, brave, brave-origin, edge, firefox, and zen (for whichever browser is installed).

Try it

Run tam-default-browser in a terminal with no arguments to confirm what browser links use right now.

If it goes wrong

Switching defaults did not pick another browser
Make sure that browser is actually installed first; Menu → Setup → Defaults only shows browsers detected via tam-cmd-present.
Want to undo a default change
Re-run tam-default-browser <previous-name> or switch back from the Menu.

Tamlinux sets BROWSER to tam-launch-browser in default Bash startup configuration so terminal links open consistently.

Check yourself

Answer before revealing the explanation.

How do you inspect your current default browser without changing any settings?

Run tam-default-browser with no arguments.

What flag starts a private browser session via tam-launch-browser?

--private.
