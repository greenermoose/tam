Opening and editing text files

This page shows how to open, edit, save, and close plain text files without needing a mouse using Tamlinux's baseline editor (micro) and launcher tools.

Simple text editing with familiar keys

If you have ever edited text in a modern desktop editor, micro uses the same familiar keys: type normally to insert text, Ctrl + S saves, Ctrl + Z undoes, and Ctrl + Q quits.

Why it matters

Configuration files, daily journals, and small scripts are all plain text files. Being able to open one, change one line, and quit cleanly gets you past most routine tasks.

How to think about it

micro shows a help bar at the bottom of the window. Nothing changes in a saved file until you press Ctrl + S, and if you change your mind before saving you can quit without writing.

New words

Terminal
The text window where terminal editors such as micro run.
Plain text file
A file containing readable characters without hidden word-processor formatting.

Practice editing in a scratch file and inspect defaults

Goal: edit and save a scratch text file using micro or tam-launch-editor, and inspect which default editor Tamlinux configures.

Before you start: checking tam-default-editor is read-only. Practice saving and undoing in a fresh temporary file before opening real configuration files.

Worked example

Check your configured default editor read-only, then open a disposable temporary file inline in your current terminal:

$ tam-default-editor

$ work=$(mktemp -d)
$ printf 'first line\n' > "$work/draft.txt"
$ tam-launch-editor --inline "$work/draft.txt"
$ cat "$work/draft.txt"
$ rm -- "$work/draft.txt" && rmdir -- "$work"

Inside micro, add a line, press Ctrl + S to save, and press Ctrl + Q to exit back to the prompt. Omitting --inline launches terminal editors in their own window via tam-launch-tui (and launches graphical editors directly).

Try it

Run tam-default-editor read-only to confirm your active editor, and practice editing a throwaway temporary file before touching real dotfiles.

If it goes wrong

Pressed a wrong key in Micro before saving
Press Ctrl + Z to undo, or press Ctrl + Q and choose n at the save prompt to discard edits.
Graphical editor launched inside terminal instead of window (or vice versa)
Use tam-launch-editor --inline <path> when you want the editor inside your active shell, or omit --inline to spawn its own desktop window.

When no custom editor is selected under user state, Tamlinux falls back cleanly to micro as the baseline editor and sets EDITOR="tam-launch-editor --inline" in Bash.

What keys save and quit in Micro?

Ctrl + S saves the file and Ctrl + Q quits the editor.

What happens when you omit --inline on tam-launch-editor?

A terminal editor opens in its own desktop terminal window instead of occupying your current shell.
