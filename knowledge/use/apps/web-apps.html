Installing and removing web apps

This page explains how to install a frequently used website as its own standalone launcher in the applications menu and how to remove that launcher cleanly later.

Giving a web tool its own window

Instead of keeping ten tabs lost inside your main browser window, a web app creates a normal entry in your applications menu (Ctrl + F12) that opens one website in a clean app window with its own icon.

Why it matters

Because each web app is just a lightweight user desktop entry calling tam-launch-webapp, you can switch to it directly like any app and remove it later in seconds without leaving hidden background services behind.

How to think about it

Installing a web app writes a desktop shortcut file inside your personal user applications directory (~/.local/share/applications/); removing it deletes only that shortcut.

New words

Launcher entry
A small .desktop file telling the apps menu the name, icon, and command for an app.
Home directory
Your user folder where personal web-app shortcuts are stored under ~/.local/share/applications/.

Inspect installed web apps, install, and undo

Goal: list existing web-app desktop launchers read-only and know the exact install and removal commands.

Before you start: checking existing .desktop entries in ~/.local/share/applications/ is read-only. Installing or deleting a launcher affects only your personal desktop entries.

Worked example

List user desktop entries that launch web apps via tam-launch-webapp read-only:

$ grep -l 'tam-launch-webapp' ~/.local/share/applications/*.desktop 2>/dev/null || echo "No web apps installed"

To install a new web app interactively from the menu (Menu → Install → Web App) or directly by arguments:

$ tam-webapp-install "My App" "https://example.org" "web-browser"

To undo and remove a web app launcher by picker or exact name:

$ tam-webapp-remove "My App"

Try it

Run the read-only grep -l 'tam-launch-webapp' ~/.local/share/applications/*.desktop check in your terminal to see any web-app launchers currently in your menu.

If it goes wrong

Web app opens inside a regular tabbed window or fails to start
Verify a supported browser is configured via tam-default-browser; tam-launch-webapp runs the site using your default supported browser engine.
Created a test web app and want it gone immediately
Run tam-webapp-remove "<Name>" (or Menu → Remove → Web App) to remove the desktop entry and notify cleanup.

tam-webapp-remove scans for tam-launch-webapp launchers via shared pattern matching and prompts safely through tam-menu-select when called with no name.

Check yourself

Answer before revealing the explanation.

Where do personal web-app launcher entries live?

Under ~/.local/share/applications/ as .desktop files invoking tam-launch-webapp.

Which command reverses tam-webapp-install cleanly?

tam-webapp-remove.
