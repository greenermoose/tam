Keeping plain-text daily journals with tam-journal

This page explains tam-journal, the plain-text daily notebook tool that opens today's dated file in Micro or appends timestamped quick notes atomically without corrupting earlier entries.

Daily notes stored as ordinary files

Press Meta + Shift + J anywhere on the desktop to pop open a quick note prompt, or launch Today’s journal from the menu or clock bar widget. Every note is stored as plain UTF-8 text named by date (for example ~/Journal/2026-11-12.txt), so you can read, search, or back up your notes with ordinary tools forever.

Why it matters

Plain dated text files never lock your notes into a proprietary database and stay safe even if the power drops mid-edit.

How to think about it

tam-journal edits a durable draft under .drafts/ first, waits for you to save and close Micro (Ctrl + S, Ctrl + Q), and then commits cleanly.

New words

Lockfile
A per-day lock preventing two full-day edit sessions from overwriting each other.
Plain text file
UTF-8 text stored one file per day under ~/Journal or TAM_JOURNAL_DIR.

Capture quick notes or edit a dated entry safely

Goal: open or append to a scratch journal directory via TAM_JOURNAL_DIR and understand how tam-journal handles locks, drafts, and bundle updates.

Before you start: checking --help or --version is read-only. Test commands with TAM_JOURNAL_DIR pointing to a temporary directory before opening your real ~/Journal.

Worked example

Inspect usage and version without creating files:

$ tam-journal --help
$ tam-journal --version

Open today's file in Micro inside a private scratch folder, or append a blank timestamped note directly from the terminal:

$ work=$(mktemp -d)
$ TAM_JOURNAL_DIR="$work" tam-journal add
$ ls -la "$work"
$ rm -rf -- "$work"

Use --date YYYY-MM-DD to view or append to another calendar day. When invoked from the desktop shortcut (Meta + Shift + J), tam-launch-journal add launches tam-journal add in a floating terminal window.

Try it

Run tam-journal --help in a terminal, and check whether ~/Journal already contains any dated YYYY-MM-DD.txt entries read-only with ls ~/Journal.

If it goes wrong

Message says today is already being edited
tam-journal holds an exclusive lock on full-day edits (.YYYY-MM-DD.lock) so another window cannot clobber your unsaved work. Finish or close the existing editor session, or use tam-journal add to append a timestamped snippet.
Micro exited non-zero and left a draft behind
tam-journal preserves unsaved edits under .drafts/ and prints the exact Draft retained: path rather than discarding what you typed.

Like other tools in the native tools suite, tam-journal checks tam_bundle_guard on startup and refuses edits while a Tamlinux bundle transaction is active so journal writes cannot race recovery.

Check yourself

Answer before revealing the explanation.

What is the difference between tam-journal and tam-journal add?

Running tam-journal opens the entire day's file under an edit lock, whereas tam-journal add opens a clean blank draft and appends it under an ISO timestamp.

How do you aim tam-journal at a temporary directory for safe experiments?

Set TAM_JOURNAL_DIR to an absolute path.
