Package and update commands

These commands check installed system packages, install or remove applications through Tamlinux wrappers, check pending updates read-only, and check device firmware.

Read-only package predicates

CommandWhat it doesRisk / undoSource
tam-pkg-present <pkg...>Exit 0 when all named native packages are installedRead-onlycommands/tam-pkg-present/tam-pkg-present
tam-pkg-missing <pkg...>Print which named packages are missingRead-onlycommands/tam-pkg-missing/tam-pkg-missing
tam-pkg-drop <pkg...>Check package presence in scripts safelyRead-onlycommands/tam-pkg-drop/tam-pkg-drop
$ tam-pkg-present bash && echo "installed"
