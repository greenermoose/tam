Desktop command reference

This page collects the commands used on the everyday desktop pages, in small groups you can scan.

The lists are deliberately short. Each command is one that Tamlinux installs and that the desktop itself uses, so you can safely run it in a terminal. Commands that need administrator rights are not included here.

  • Desktop commands: screenshots, clipboard, notifications, sound, Bluetooth, displays, input, locking, and night light.

How to read a command

A line beginning with $ shows the shell prompt, not something you type. Type the text after it and press Return. Put arguments that contain spaces inside double quotes.

$ tam-notification-send "Tea is ready" "Take the kettle off the heat"

The command prints nothing when it succeeds; the notification is the result. If a command cannot do its job, it prints an error message and returns a non-zero exit status.

Before you run something

Read the whole line first. The commands on the reference page change only desktop settings: volume, brightness, clipboard behaviour, and similar. None of them install software, delete files, or ask for an administrator password. If a command you find elsewhere does ask for a password, stop and read its documentation first.
