Desktop commands

These are the commands behind the everyday desktop pages. Run them in a terminal. Each one changes a setting immediately; there is no separate save step.

Screenshots and recording

CommandWhat it does
tam-capture-screenshotChoose an area, window, or the full screen; save and copy it
tam-capture-screenshot fullscreenCapture the whole screen without the picker
tam-capture-textChoose an area and copy the text in it
tam-capture-screenrecordingChoose an area and start recording
tam-capture-screenrecording --stop-recordingStop the recording that is running
tam-capture-edit <image>Open a saved picture in the annotator
$ tam-capture-screenshot fullscreen
$ tam-capture-edit ~/Pictures/screenshot-2026-11-02_14-30-00-AbCdEf.png

Clipboard and notifications

CommandWhat it does
tam-shell clipboard toggleOpen or close the clipboard history
tam-notification-send "Headline" "Description"Show a desktop notification
tam-notification-send "Headline" "Description" --exec program argShow a notification that runs a program when clicked
tam-toggle-notification-silencingSilence notifications, or turn them back on
$ tam-notification-send "Tea is ready" "Take the kettle off the heat"
$ tam-notification-send "Guide" "Click to open" --exec tam show use/desktop/notifications

Sound

CommandWhat it does
tam-audio-output-volume raiseRaise the volume by five percent
tam-audio-output-volume lowerLower the volume by five percent
tam-audio-output-volume +10Raise the volume by ten percent
tam-audio-output-volume mute-toggleMute or unmute the output
tam-audio-output-switchSwitch to the next output device
tam-audio-output-sinkPrint the current output device name
tam-audio-input-muteMute or unmute the microphone
tam-restart-audioRestart the sound service
$ tam-audio-output-volume +10
$ tam-audio-output-sink
alsa_output.usb-C-Media_Electronics_Inc._Lenovo_USB-A_Wired_Stereo_On-Ear_Headset-00.analog-stereo

Bluetooth

CommandWhat it does
tam-bluetooth-power onTurn Bluetooth on
tam-bluetooth-power offTurn Bluetooth off and keep it off after a reboot
tam-bluetooth-power is-onPrint nothing; exit status 0 means on, 1 means off
tam-bluetooth-device pair <address>Pair and connect a device
tam-bluetooth-device connect <address>Connect a paired device
tam-bluetooth-device forget <address>Disconnect and remove a device
tam-restart-bluetoothRestart the Bluetooth service
$ tam-bluetooth-power on
$ bluetoothctl devices
$ tam-bluetooth-device connect AA:BB:CC:DD:EE:FF

The address above is an example, not a real device. Use the address printed by bluetoothctl devices.

Displays and text size

CommandWhat it does
tam-brightness-display +10%Brighten the focused screen by ten percent
tam-brightness-display 10%-Dim the focused screen by ten percent
tam-brightness-display 100%Set maximum brightness
tam-display-text-sizePrint the current text size
tam-display-text-size 14Set text size from 9 to 20
tam-display-text-size resetReturn to 12 px, scale 1.0, and a 9 pt terminal font
$ tam-display-text-size
text size: 12 px
gtk text-scaling-factor: 1.0
terminal font: 9 pt
$ tam-display-text-size 14
$ tam-display-text-size reset

Locking and idle

CommandWhat it does
tam-system-lockLock the screen now
tam-toggle-idleTurn Stay Awake on or off
tam-toggle-idle statusPrint the Stay Awake state as JSON
tam-toggle-idle stay-awakeTurn Stay Awake on
tam-toggle-idle allow-idleTurn Stay Awake off
$ tam-toggle-idle status
{"enabled":false,"class":"disabled","tooltip":"Stay Awake"}

In that output, "enabled" refers to Stay Awake, and the tooltip names the action the key would take next. Use status when you want an unambiguous answer; the words printed by stay-awake and allow-idle describe idle locking instead.

Night light

CommandWhat it does
tam-toggle-nightlightTurn the warm colour filter on or off
tam-toggle-nightlight --statusPrint whether the filter is on and its temperature
tam-restart-hyprsunsetRestart the night-light program
$ tam-toggle-nightlight --status
{"enabled":false,"temperature":null}
$ tam-toggle-nightlight
$ tam-toggle-nightlight --status
{"enabled":true,"temperature":4000}
