Turning the touchpad on or off and finding keyboard shortcuts

This page shows how to disable the touchpad while typing, adjust the keyboard light, and look up a shortcut you have forgotten.

Control input devices

Goal: you will be able to turn the touchpad off and on, change keyboard backlight, and open the full keybinding list.

Why it matters: a touchpad can be brushed by your palms while typing. Turning it off for a moment is faster than fighting the pointer. The keybinding list is the map for everything else.

Before you start: this page assumes a laptop with a touchpad and, for the backlight steps, a keyboard that has a light. A desktop computer may have neither; the commands then report that no device was found.

Find the key with a small touchpad icon, often near the function keys. Press it once to turn the touchpad off; an overlay confirms the change. Press it again to turn it back on. To see every shortcut, press Meta + K.

Worked example

  1. Press the touchpad-toggle key. The overlay says the touchpad is off.
  2. Move a finger on the touchpad. The pointer should not move.
  3. Press the same key again. The pointer works once more.
  4. If your keyboard has backlight keys, press the keyboard-brightness-up key and watch the keys get brighter.
  5. Press Meta + K to open the keybinding list, then close it with Esc.

Captured from the packaged input commands and keybindings on 2026-11-02. A desktop without a touchpad will skip the first three steps.

What just happened

  1. The touchpad key called tam-toggle-input-device touchpad.
  2. The command found the touchpad by name and told the compositor to ignore it.
  3. The disabled state is remembered, so the touchpad stays off across a reload until you turn it back on.
  4. The keybinding list is generated from the same bindings that are active now.

Try it

Ask whether this computer has a touchpad:

$ tam-hw-touchpad
$ echo $?
1

Captured on 2026-11-02 on a desktop computer. The command printed no name and exited with status 1, meaning no touchpad was found. On a laptop it prints the device name and exits with status 0.

If it goes wrong

Nothing happens when you press the touchpad key
The computer may have no touchpad, or the key may be assigned to something else. Run tam-hw-touchpad to check. If it prints a name, run tam-toggle-input-device touchpad on to turn the device back on.
The pointer still moves after you disable the touchpad
A mouse or trackpoint may be moving it. The touchpad key controls only the touchpad.
Keyboard backlight keys do nothing
Many desktop keyboards have no backlight. Laptop keys may need Fn held with the brightness key.
Letters produce the wrong characters
The keyboard layout is a system setting chosen when Tamlinux was installed. This page does not change it.

Check yourself

Decide your answer before you reveal it.

Which keys open the list of every shortcut?

Meta + K. The touchpad key is separate and controls only the touchpad.

Does turning the touchpad off last until the next reboot?

The disabled state is stored, so it lasts across a reload and a reboot until you turn the touchpad back on.

New words

Touchpad
The flat pointing surface below a laptop keyboard.
Keybinding
A key or key combination that runs an action.
Exit status
A number a command returns. Zero means success; a non-zero number means it did not do the job.
