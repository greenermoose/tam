Arranging your screens and changing brightness

What this helps with

This page shows how to change screen brightness, make text larger, and manage a second monitor.

Why it matters

A screen that is too bright is tiring, and tiny text is hard to read. A second monitor also needs to be arranged so the pointer moves between screens in the direction you expect.

How to think about it

New words

The number of pixels a screen shows, such as 1920 by 1080.

Show the same picture on two screens.

Brightness, text size, and monitors

Goal: you will be able to dim or brighten the screen, make text easier to read, and choose what a second monitor shows.

Learning path: Everyday desktop tasks — Start | ← Back | Next →

Before you start: you need a graphical session. Brightness keys usually control the built-in laptop screen. External monitors may respond only if they support a control standard called DDC.

Press the brightness-down key a few times. An overlay shows the level falling. If the screen is still too bright, open the display panel with Meta + Ctrl + D and use the brightness control for the monitor you are looking at. For larger text everywhere, run tam-display-text-size 14 in a terminal.

Worked example

  1. Press the brightness-down key. The overlay shows the new level.
  2. Press Shift with the brightness-down key to go straight to the minimum, or Shift with brightness-up for the maximum.
  3. Open a terminal with Meta + Return and run tam-display-text-size to see the current text size.
  4. Run tam-display-text-size 14 to make the shell and terminal text larger.
  5. Run tam-display-text-size reset to return to the default.
$ tam-display-text-size
text size: 12 px
gtk text-scaling-factor: 1.0
terminal font: 9 pt

Captured on 2026-11-02. Your values may differ if you or an earlier change set them.

What just happened

  1. The brightness keys changed the backlight of the screen with focus.
  2. The display panel lists each connected monitor and the controls that monitor supports.
  3. tam-display-text-size changed three related settings together: the shell, programs that use GTK, and the terminal font.
  4. reset returned all three to 12 px, a scale factor of 1.0, and a 9 pt terminal font.

Try it

Open the display panel with Meta + Ctrl + D. Find the monitor you are using, change its brightness or scale, and use the panel's apply step. If the result is wrong, use the panel's revert step before the countdown ends.

If it goes wrong

Brightness keys do nothing
The focused screen may be an external monitor without brightness control. Use the monitor's own buttons, or try the slider in the display panel. A desktop monitor may not support DDC at all.
Text is now too large or too small
Run tam-display-text-size reset, then choose a size between 9 and 20.
The second monitor shows a black screen
Check its cable and input source. Then open the display panel and confirm the monitor is enabled and positioned where you expect.
The pointer will not move to the other screen
Arrange the monitors in the display panel so their edges touch in the same order as the physical screens.

Check yourself

Decide your answer before you reveal it.

Which command makes text larger everywhere, and how do you undo it?

tam-display-text-size 14 makes it larger. tam-display-text-size reset returns to the default. Pick any size from 9 to 20.

Why might the brightness keys not dim an external monitor?

The keys control the focused screen's backlight. Many external monitors do not expose brightness over DDC, so the keys have nothing to change.
