Finding something you copied earlier

This page shows how to copy and paste, and how to get back something you copied a while ago.

Use the clipboard and its history

Goal: you will be able to copy text or a picture, paste it, and find an earlier item in the clipboard history.

Why it matters: the last thing you copied is easy to paste, but the thing before it is usually lost. Tamlinux keeps a searchable history so you can recover it without copying it again.

Before you start: you need a graphical session. The history is private to your account. Copying a password from a program that marks it as sensitive does not add it to the history.

Copy with Meta + C and paste with Meta + V. These work in the same way in a terminal, a browser, and a text editor. To see the history, press Meta + Ctrl + V. A searchable list opens. Type part of the text you want, use the Up and Down Arrow keys to choose it, then press Return to paste it.

Worked example

  1. Select a few words in any window and press Meta + C.
  2. Select different words and press Meta + C again. Now the first words are no longer the newest item.
  3. Press Meta + Ctrl + V. The clipboard manager opens with the newest item first.
  4. Type a word from the first item to filter the list.
  5. Press Return to paste the chosen item into the window you were using.

Captured from the packaged clipboard bindings and the clipboard service on 2026-11-02. The list on your computer will contain your own items.

What just happened

  1. Meta + C copied the selected text.
  2. The clipboard service recorded each new item and kept the older ones, up to 300.
  3. Meta + Ctrl + V opened the history instead of pasting the newest item.
  4. Typing filtered the list; the arrow keys moved the selection.
  5. Return copied the chosen item and pasted it into the focused window.

Try it

Copy a picture, then copy a line of text. Open the history with Meta + Ctrl + V and find the picture again. Press Alt + Return to open it in the picture annotator instead of pasting it.

If it goes wrong

The history is empty
The clipboard service records items after it starts. Copy something now with Meta + C, then open the history again.
An item you copied is missing
The program may have marked it as sensitive, as password managers do. Sensitive items are deliberately not recorded.
Paste does nothing
Click the window you want to paste into first. The paste goes to the window with focus.

Check yourself

Decide your answer before you reveal it.

Which keys open the clipboard history, and which keys paste the newest item?

Meta + Ctrl + V opens the history. Meta + V pastes the newest item without opening the list.

Why might a copied password not appear in the history?

The password manager marks it as sensitive, and the clipboard service skips sensitive items on purpose.

New words

Clipboard
A small holding place for the last thing you copied.
History
A list of earlier clipboard items, kept so you can choose an older one.
Filter
Typing words to hide list items that do not contain them.

Keys in the clipboard manager

KeyWhat it does
TypeFilter the list
Up, Down, Page Up, Page Down, Home, EndMove the selection
ReturnPaste the selected item
Shift + ReturnCopy the selected item without pasting
Alt + ReturnOpen the item: a picture in the annotator, a link in the browser, text in the editor
DeleteRemove the selected item
Shift + DeleteClear the whole history after a confirmation
EscapeClear the filter, or close the manager when the filter is empty
