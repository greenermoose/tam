Making the screen warmer at night

Toggle the blue-light color temperature filter on or off and inspect its current temperature state.

What this helps with

This page shows how to give the screen a warmer colour in the evening and how to check whether the setting is on.

Why it matters

A very blue screen late at night can feel harsh. A warmer colour is easier on the eyes and is a single key away, without changing any picture files.

How to think about it

Press Meta + Ctrl + J. The screen becomes noticeably warmer.

New words

Colour temperature
How warm or cool white light looks, measured in kelvin (K). Lower numbers look warmer.
Blue light
The cooler part of white light. A night filter reduces it.
Filter
A change applied to the whole screen without altering the files themselves.

Turn the night light on and off

Goal: you will be able to turn the warm colour filter on, turn it off, and confirm which state it is in.

Before you start: you need a graphical session. The change affects what you see on screen, not the colours saved in photos or documents.

Press Meta + Ctrl + J. The screen becomes noticeably warmer. Press the same keys again to return to normal colours. If nothing seems to happen, check the status command below; the filter has no pop-up message.

Worked example

  1. Look at a white window or this guide's background.
  2. Press Meta + Ctrl + J. The white becomes warm, like early evening light.
  3. Press Meta + Ctrl + J again. The white returns to its usual colour.
  4. Open a terminal with Meta + Return and run tam-toggle-nightlight --status.
$ tam-toggle-nightlight --status
{"enabled":false,"temperature":null}

Captured on 2026-11-02 with the filter off. When it is on, the same command reports "enabled":true and a temperature of 4000.

What just happened

  1. The key started the night-light program if it was not already running.
  2. It set the screen's colour temperature to 4000 K, which is warmer than normal daylight.
  3. Pressing it again set the temperature to 6500 K, the program's normal, unfiltered value.
  4. The status command reads the current temperature and reports whether it is below 6000 K.

Try it

Turn the filter on, then run tam-toggle-nightlight --status and confirm it reports "enabled":true and "temperature":4000. Turn it off again and confirm the values return to false and null.

If it goes wrong

Nothing changes
Run the status command. If it already says "enabled":true, the filter is on; press the keys once to turn it off and compare. Some rooms and screens make the change harder to notice.
The colours look wrong in a photo editor
Turn the filter off while you judge colours. It changes the whole screen, including programs that edit pictures.
The filter will not turn on
Run tam-toggle-nightlight in a terminal and read any error. If the night-light program is not running, the command tries to start it.

Check yourself

Decide your answer before you reveal it.

Which keys toggle the night light?

Meta + Ctrl + J. Press them again to return to normal colours.

What temperature does the filter use when it turns on?

4000 K. Turning it off sets 6500 K, which is the program's normal value.
