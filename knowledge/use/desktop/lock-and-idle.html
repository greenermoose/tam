Locking the screen and keeping it awake

Lock your workstation before stepping away, suspend cleanly, or pause automatic idle locking temporarily.

What this helps with

This page shows how to lock the screen before you walk away, how to unlock it, and how to stop it locking while a long job runs.

Why it matters

Locking protects your files and messages when you leave the computer. The opposite problem, a screen that locks during a long download or a video, is just as annoying.

How to think about it

Press Meta + Ctrl + L to lock. The screen is covered by the lock screen.

New words

Lock screen
A password prompt that covers your desktop without closing your programs.
Idle
No keyboard or pointer activity for a period of time.
Suspend
Put the computer into a low-power state and keep your work in memory.

Lock, unlock, and stay awake

Goal: you will be able to lock the screen on demand, unlock it with your password, and keep it unlocked while you are nearby.

Before you start: you need a graphical session and your login password. Locking does not close your programs; they keep running.

Press Meta + Ctrl + L to lock. The screen is covered by the lock screen. Type your password and press Return to return to your work. To stop the screen locking while you are idle, press Meta + Ctrl + I; the same keys turn normal locking back on. That toggle is silent, so use the status command on this page if you are unsure which state it is in.

Worked example

  1. Press Meta + Ctrl + L. The lock screen appears.
  2. Type your password and press Return. Your windows are as you left them.
  3. Press Meta + Ctrl + I. The toggle is silent; run tam-toggle-idle status and look for "enabled":true.
  4. Press Meta + Ctrl + I again. Run the status command once more and confirm it says "enabled":false.
  5. Open the system menu with Meta + Escape and find the Lock, Suspend, Logout, Reboot, and Shutdown entries.

What just happened

  1. Meta + Ctrl + L started the lock screen and reset the keyboard layout to its first entry.
  2. Unlocking checked your password against the same account you logged in with.
  3. Meta + Ctrl + I created a marker file that tells the desktop you want to stay awake.
  4. The marker is remembered, so Stay Awake survives a restart until you turn it off.
  5. The system menu offers actions that affect the whole computer, not just one window.

Try it

Ask whether Stay Awake is on:

$ tam-toggle-idle status
{"enabled":false,"class":"disabled","tooltip":"Stay Awake"}

Captured on 2026-11-02. Here "enabled":false means Stay Awake is off, so the normal idle behaviour applies. The tooltip names what pressing the Stay Awake key would do next.

If it goes wrong

The screen does not lock
Make sure the lock command is available and that you are in a graphical session. Run tam-system-lock in a terminal to see an error message.
The password is rejected
Use your login password, not a password manager's master password. Check the keyboard layout indicator; locking resets the layout to the first one, which may differ from the layout you were typing in.
The screen still locks while a job runs
Turn on Stay Awake with Meta + Ctrl + I before starting the job, and turn it off afterwards.
The screen never locks on its own
Your system may not have an idle lock timer configured. That is normal on some Tamlinux installations. Lock manually with Meta + Ctrl + L.

Check yourself

Decide your answer before you reveal it.

Which keys lock the screen, and which keys toggle Stay Awake?

Meta + Ctrl + L locks. Meta + Ctrl + I turns Stay Awake on or off.

Does Stay Awake stop you from choosing Suspend in the system menu?

No. Stay Awake stops the idle lock cycle. Choosing Suspend is a separate action that you start yourself.
