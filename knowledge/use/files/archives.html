Creating and opening archives (.tar.gz and .zip)

This page explains how compressed archive files bundle whole folders into one file for sharing or backup, and how to inspect their contents before unpacking them.

Packing folders into a single file

An archive stores one or more files and folders—including their subfolders and filenames—inside a single portable file such as project.tar.gz or photos.zip.

Why it matters

Checking what is inside an archive before unpacking stops dozens of unexpected files from spilling straight into your current folder.

How to think about it

Think of an archive as a packed suitcase: listing lets you peek inside at the label list without unpacking, while extracting unpacks everything into the folder you choose.

New words

Directory
A folder whose entire tree can be bundled into one archive file.
Archive file
A single container file holding one or more packed files or folders, optionally compressed to save space.

List before extracting in a scratch directory

Goal: pack a scratch folder into .tar.gz, list its entries read-only, and unpack into an isolated empty folder cleanly.

Before you start: always list an unfamiliar archive before extracting so you know whether it unpacks one clean top-level folder or loose files.

Worked example

$ work=$(mktemp -d)
$ mkdir -p "$work/src/sub" "$work/out"
$ printf 'hello\n' > "$work/src/sub/note.txt"
$ tar -czf "$work/bundle.tar.gz" -C "$work/src" sub
$ tar -tf "$work/bundle.tar.gz"
$ tar -xzf "$work/bundle.tar.gz" -C "$work/out"
$ cat "$work/out/sub/note.txt"
$ rm -f -- "$work/bundle.tar.gz" "$work/src/sub/note.txt" "$work/out/sub/note.txt"
$ rmdir -- "$work/src/sub" "$work/src" "$work/out/sub" "$work/out" "$work"

Notice the flags in tar: -c creates, -t lists contents read-only, -x extracts, -z uses gzip compression, -f names the archive file, and -C enters a target folder cleanly.

Try it

Run the scratch example above and inspect tar -tf "$work/bundle.tar.gz" output before extracting. If you work with a .zip file instead, use unzip -l file.zip to list entries and unzip file.zip -d target-dir to extract into a dedicated folder.

If it goes wrong

Files spilled loosely into your home or Downloads folder
List archives first with tar -tf or unzip -l, and create a fresh empty destination directory with mkdir before extracting.
unzip reports command not found
Some minimal environments omit unzip; bsdtar -tf file.zip or tam-open file.zip also handle zip archives cleanly.

Check yourself

Answer before revealing the explanation.

Which tar flag previews archive paths without creating any extracted files?

-t (for example tar -tf archive.tar.gz).

How do you keep a loose archive from cluttering your current directory?

Extract into a fresh empty folder using tar -xzf archive.tar.gz -C folder or unzip archive.zip -d folder.
