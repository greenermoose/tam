Finding and opening files

This page explains how to track down a file when you only know part of its name or a phrase inside it, and how to open or reveal its folder cleanly.

Where did I save that document?

Every saved file lives inside a folder inside your home directory (such as Documents, Downloads, or Pictures). You can press Meta + Shift + F to open the graphical Files window, or use search commands in a terminal to check a whole directory tree at once.

Why it matters

Knowing how to locate a file safely read-only saves you from guessing or creating duplicate copies in random folders.

How to think about it

Searching by filename checks labels on folders and files, while searching by content reads inside text files to match a phrase you remember.

New words

Path
The full folder address leading to a file, such as ~/Documents/notes.txt.
Directory
The Linux name for a folder containing files and subfolders.
File
A named stored document, script, picture, or data stream on disk.

Find by name or content in a scratch folder

Goal: distinguish searching filenames with find from searching lines inside files with grep, without modifying any real documents.

Before you start: running find and grep on normal paths you own is read-only. Practice first in a scratch directory created with mktemp -d.

Worked example

$ work=$(mktemp -d)
$ mkdir -p "$work/notes"
$ printf 'grocery list: apples\n' > "$work/notes/todo.txt"
$ find "$work" -name '*todo*'
$ grep -rn 'apples' "$work"
$ rm -- "$work/notes/todo.txt" && rmdir -- "$work/notes" "$work"

find prints matching file paths by name. grep -rn walks subfolders recursively (-r) and prints the matching path, line number (-n), and text. To open a discovered file or folder from the terminal in its default app, pass its path to tam-open <path>.

Try it

Check your own Downloads folder safely read-only by running find ~/Downloads -maxdepth 2 -type f, or press Meta + Shift + F (tam-launch-nautilus) to browse folders visually.

If it goes wrong

Permission denied scrolling past in find /
Limit your search to your home directory (find ~ ...) or target subfolder rather than scanning restricted system trees like /proc.
find prints nothing when the file is capitalized differently
Use -iname instead of -name for case-insensitive filename matching.

tam-open <path> opens directories, PDFs, images, text files, and URLs with the appropriate graphical or console handler without memorizing separate tools.

Check yourself

Answer before revealing the explanation.

When you remember a sentence inside a document but forgot its filename, which tool searches file contents?

grep -rn (or rg) searches text inside files; find -name only checks filenames.

What shortcut opens a graphical Files window on Tamlinux?

Meta + Shift + F (running tam-launch-nautilus).
