Using FAQ

This page answers common everyday questions with short, sourced replies.

How do I open a terminal?
Meta + Return. See the terminal recipe.
How do I open the applications menu?
Ctrl + F12. See open an application.
Where is the Windows or Command key?
Tamlinux calls it the Meta key. Read the Meta key.
How do I dictate text?
Hold F9 to talk, release to stop; or toggle with Meta + Ctrl + X. See voice dictation.
How do I get back to this Guide?
From a terminal, run tam hi. In the pager, backtick opens the index; Esc returns to the terminal.
The GUI froze. What first?
Ctrl + Alt + F2 for a text console. See graphical desktop froze.
