Fingerprints and FIDO2 security keys

This page explains how to register a fingerprint reader or hardware FIDO2 key so you can approve administrator prompts with a quick touch while keeping your password as fallback.

Unlocking prompts with a touch

Typing a long password many times a day can feel slow. If your laptop has a fingerprint reader, or if you carry a USB security key (FIDO2), Tamlinux can let you tap that hardware to approve permission prompts.

Why it matters

Hardware verification confirms you are physically sitting at the computer without encouraging you to choose an easy-to-guess password.

How to think about it

Fingerprints and security keys act as convenient backup keys on the same door: if your sensor is unreachable—for example when a laptop is docked with its lid closed—Tamlinux automatically falls back to asking for your password.

New words

Fingerprint authentication
Verifying your identity by scanning a registered fingerprint through fprintd.
FIDO2
A hardware token standard where tapping a physical USB or NFC key signs an authentication challenge.
PAM
Pluggable Authentication Modules, the Linux layer that decides whether a password, fingerprint, or token satisfies a prompt.

Check hardware readiness, enroll, and remove

Goal: verify whether your hardware has a supported fingerprint sensor or USB FIDO2 token before modifying PAM rules, and know the exact undo command.

Before you start: enrolling hardware changes /etc/pam.d/sudo and /etc/pam.d/polkit-1 and installs driver packages if needed. Keep your user password handy and test in a second terminal before closing the first.

Worked example

Check read-only whether a supported fingerprint reader is detected and whether PAM currently checks pam_fprintd or pam_u2f:

$ tam-hw-fingerprint && echo "fingerprint reader present" || echo "no fingerprint reader"
$ grep -E 'pam_(fprintd|u2f)\.so' /etc/pam.d/sudo /etc/pam.d/polkit-1 2>/dev/null

To enroll a fingerprint (installing fprintd and adding the clamshell lid gate), use the menu under Setup → Security → Fingerprint or run tam-setup-security-fingerprint. To register a FIDO2 key (installing libfido2 and pam-u2f, writing /etc/fido2/fido2), use tam-setup-security-fido2.

Try it

Run the read-only tam-hw-fingerprint predicate in a terminal. Notice it exits quietly with status 0 when hardware is present or 1 when none is found, without modifying configuration.

If it goes wrong

Fingerprint prompt blocks while docked with the laptop lid shut
tam-setup-security-fingerprint inserts a clamshell gate reading /proc/acpi/button/lid/*/state so closed-lid sessions skip the sensor and ask for your password directly.
Want to undo fingerprint or FIDO2 registration cleanly
Run tam-remove-security-fingerprint or tam-remove-security-fido2 (or use Menu → Remove → Security).

Screen locking uses hyprlock, which talks to fprintd directly rather than modifying lock-screen PAM files; password authentication always stays available as fallback.

Check yourself

Answer before revealing the explanation.

What happens to your normal account password after registering a FIDO2 key or fingerprint?

Your password stays enabled as fallback if the sensor is unavailable, you leave the USB key behind, or the laptop lid is closed.

Which commands cleanly remove PAM rules added by hardware authentication setup?

tam-remove-security-fingerprint and tam-remove-security-fido2.
