Windows and layouts

This page explains how Tamlinux arranges windows on screen and how you move focus among them.

What is a window layout?

A window is one app's rectangle on the screen. Tamlinux usually tiles windows side by side so they do not stack. You can also float a window so it can overlap others. Focus marks which window receives your typing.

Why it matters

Knowing focus and layout keeps you from closing the wrong window or losing one behind another.

How to think about it

Tiling is like papers laid flat on a desk; floating is like sticky notes you can stack. Workspaces are separate desks—see Organizing windows and screens.

New words

Tiling
The compositor places windows in a non-overlapping layout.
Focus
The window that receives keyboard input.

Move focus and toggle floating

Goal: you will be able to open a practice terminal, toggle floating, and close only that window.

Worked example

  1. Press Meta + Return for an empty terminal.
  2. Press Meta + T to toggle floating/tiling (tiling.lua).
  3. Press Meta + Left or Meta + Right if another window exists, to move focus.
  4. Focus the empty terminal again and press Meta + Q to close it.

Checked against packaged tiling.lua and applications.lua. Overrides can differ—confirm with Meta + K.

What just happened

  1. The launcher created a new window.
  2. Meta + T asked the compositor to change float state.
  3. Directional Meta chords move focus, not the pointer alone.

Try it

Open two empty terminals. Use Meta + arrows to move focus, then Meta + Shift + a workspace number to move one window and follow it. Return both to your starting workspace before closing the practice windows.

If it goes wrong

Focus chord does nothing
There may be no window in that direction on this workspace.
Window vanished
Check another workspace or the scratchpad (Meta + S); see workspaces.

Helpers such as tam-hyprland-window-pop, tam-hyprland-window-width, and tam-hyprland-workspace-layout-toggle implement extra layout chords from tiling.lua.

Check yourself

Which chord toggles floating versus tiling on the focused window?

Meta + T.

Does Meta + Q close every window?

No—only the focused window. Ctrl + Alt + Delete runs tam-hyprland-window-close-all for a full close.

How it works

Hyprland applies layout and focus. Packaged chords in tiling.lua call compositor dispatchers or small tam-hyprland-* helpers for behaviors that need a script. Monitor and clamshell helpers (tam-hyprland-monitor-*) belong with display setup; see Displays.

Advanced usage

Silent workspace moves use Ctrl + Alt + workspace number (follow = false). Appearance toggles for gaps and transparency live on Meta + U family chords in utilities.lua.

Edge cases

  • Fullscreen and floating change which focus targets exist.
  • Multi-monitor moves need a display in that direction.

Check yourself

Why do some layout chords call tam-hyprland-* instead of a raw dispatcher?

Those actions need extra logic beyond a single Hyprland dispatch (for example pop-out pin behavior or tiled fullscreen toggles), so a small helper owns the steps.
