Guide / Desktop and applications / Typography / Writing systems of the world

A script is a set of visible marks; a writing system is the language and rules behind them. Humans have built many different ways to connect marks to a spoken language, and this page gives you the vocabulary to compare them.

Different ways to write a word

What this is

A writing system is an agreed way of setting down a language. The writing script is the collection of marks you see on the page. English uses the Latin script. Hindi is commonly written in Devanagari. Arabic is written in the Arabic script.

Systems differ in what one mark stands for. In an alphabet, marks stand for small sounds called consonants and vowels. In a syllabary, one mark stands for a whole syllable such as "ka". In a logogram, one mark stands for a whole word.

Why it matters

Knowing the type of a system tells you what to expect when you read or type it. If vowels are not written as separate marks, a reader supplies them from context. If each mark is a syllable, a keyboard needs a different kind of layout. This is why one font and one keyboard do not fit every language.

How to think about it

Think of a recipe for turning speech into marks. One recipe lists every sound. Another lists every syllable. Another lists whole words. All three can record the same sentence; they cut it into different pieces.

Two more recipes are common. An abjad writes consonants and leaves most vowels to the reader, as Hebrew and Arabic usually do. An abugida writes consonants with a built-in vowel that a small mark can change, as Devanagari does.

If it goes wrong

You expected Kana to be an alphabet.
Kana marks map to syllables, not to single consonants and vowels. That makes it a syllabary.
You expected Quipu to have a type like the others.
Quipu is a knot-recording device whose status as writing is debated. "Debated" is the honest classification here.

General script facts apply to every desktop. Tamlinux adds language-specific font choices: its fontconfig configuration prepends Noto Naskh Arabic for Arabic language patterns, appends Noto Nastaliq Urdu for Urdu, and keeps Noto Naskh Arabic as a last-resort alias. So an Arabic paragraph and an Urdu paragraph can resolve to different installed families even though both use related scripts.

Check yourself

Decide your answer before you reveal it.

A script writes consonants and leaves most vowels unmarked. What type is it?

An abjad. Hebrew and Arabic are the usual examples. Readers supply vowels from context and from optional marks, so the same consonant skeleton can be read in more than one way.

Why is "script" the wrong word for a computer program here?

In this page a writing script is a set of written marks. A computer program is a different kind of script. The glossary keeps them separate so a link never conflates the two meanings.

How it works

Unicode and ISO/IEC 10646 assign a stable code point to each encoded character, independent of how it looks The Unicode Standard ISO/IEC 10646. A font then supplies a drawn shape for that character; two fonts can draw the same code point very differently. Encoding therefore answers "which character is this?", while a font answers "what does it look like?"

Some scripts need shaping before a glyph can be chosen. In an abugida, a consonant and a vowel sign may combine into one glyph; in Arabic, the shape of a letter depends on its position in a word. A text engine such as HarfBuzz applies those rules using tables in the font HarfBuzz manual, and a layout engine such as Pango decides which font and script run to use Pango reference. CSS exposes the same idea through font families and script-aware font selection CSS Fonts Module Level 4.

Advanced usage

These read-only commands show how a desktop resolves scripts to fonts. They query fontconfig and never change configuration:

fc-match ':lang=ar' -f '%{family}\n'
fc-match ':lang=ur' -f '%{family}\n'
fc-list :lang=he family | sort -u | head -n 5

The first two lines ask which family fontconfig would choose for Arabic and Urdu text. The third lists a few families registered for Hebrew. Differences here are expected: a writing system may be served by several installed families, and fontconfig ranks them by language Fontconfig user manual.

Edge cases

  • Quipu records information with knotted cords. Whether it records language, rather than only counts and categories, is debated; it should not be filed as a simple alphabet or syllabary.
  • Egyptian hieroglyphs mix word signs, sound signs and silent classifiers in one script. Calling the whole system a logography hides the sound signs.
  • A script and a language are not one-to-one. Latin writes English, Turkish and Vietnamese; Chinese hanzi is used for languages that are not mutually spoken-intelligible.
  • Unicode encodes characters, not every historical glyph variant. A scribe's hand-drawn form or a ligature may have no separate code point.
  • Hangul is featural and alphabetic at once. Its shapes encode articulation features, but each basic letter still represents a sound segment.
  • Missing font coverage produces boxes or fallback glyphs. That is a font problem, not evidence that the writing system lacks an encoding.

Check yourself

Why does an abugida need shaping rules but a simple alphabet often does not?

Because an abugida combines a consonant with an inherent or marked vowel, and the combination may be drawn as one glyph. A plain alphabet usually maps one letter to one glyph, so less reordering and joining is needed. Arabic adds a further case: letter shapes change with position.

If two fonts show different shapes for the same code point, which layer changed?

The font, not the writing system or the encoding. The code point still names the same character; each font supplies its own glyph outline. Script classification describes the mapping from language to characters, not the drawing style.
