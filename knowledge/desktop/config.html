Desktop Configuration and Defaults

This page explains how Tamlinux organizes desktop defaults, personal overrides, default application handlers, and session state.

What is desktop configuration?

Configuration controls how your programs look and behave. Tamlinux provides carefully tested defaults out of the box, while leaving you full control to customize applications in your home folder.

Why it matters

Separating system defaults from user overrides means system updates can refresh packaged programs without overwriting your personal themes, keybindings, or preferred web browser.

How to think about it

Tamlinux follows the XDG base directory specification. Read-only application defaults reside in system packages, while personal overrides live under ~/.config/. Session state and cache files live under ~/.local/state/ and ~/.cache/.

New words

Dotfiles
Configuration files and directories starting with a dot in your home directory, often placed under ~/.config/.
Default handler
The chosen program that automatically opens a file type or web address when clicked.
Session initialization
Setting up fresh, clean user defaults on a new account or desktop startup.

Choose your default applications safely

Goal: you will be able to query and choose your default browser, terminal, and coding agent without manually editing desktop entry files.

Worked example

  1. Check your currently configured default web browser: 
    $ tam-default-browser
chromium
  2. To change the default browser, pass the supported browser name: 
    $ tam-default-browser firefox
  3. Check your default terminal emulator: 
    $ tam-default-terminal
alacritty
  4. Inspect or select your default coding agent: 
    $ tam-default-agent

Try it

Run tam-default-terminal without arguments in your terminal. It prints the active terminal without making any modifications.

If it goes wrong

Web links open in an unexpected program
Re-run tam-default-browser with your desired browser name to refresh XDG mime associations.
Settings change broke an application configuration
Check ~/.local/state/tamlinux/ for preserved snapshots created by tam-settings-preserve.

Before modifying critical configuration keys, Tamlinux helpers use tam-settings-preserve to snapshot configuration files safely.

Check yourself

Where do personal user configuration overrides live?

Under ~/.config/ according to the XDG base directory specification.

Which command inspects and sets the default web browser?

tam-default-browser.

Configuration and session command family

CommandRole
tam-default-browserShow or set default browser for web protocols and HTML files
tam-default-terminalShow or set default terminal emulator for xdg-terminal-exec
tam-default-agentRead, select, or launch supported coding agents
tam-browser-commandResolve browser desktop entry Exec specifications into argv without executing
tam-branding-aboutEdit, reset, or transcode custom ASCII artwork for the about dialog
tam-chromium-copy-url-hostNative messaging endpoint for browser URL copy integration
tam-chromium-ytdlp-hostNative messaging endpoint for browser video download integration
tam-desktop-modeQuery or switch workspace layouts and desktop modes used by the bar
tam-session-initInitialize application defaults and user assets upon fresh session startup
tam-settings-preserveSnapshot user files and state before settings mutations to provide rollback

Desktop applications launch via standard XDG desktop files. tam-browser-command parses Exec strings according to the desktop entry specification, allowing clean invocation without shell interpolation risks.
