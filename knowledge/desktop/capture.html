Screen capture

This page explains how Tamlinux takes screenshots, records the screen, copies text from images, and optional dictation.

What is capture?

Capture means saving what you see or hear on the computer: a picture of the screen, a short video, words read from an image, or speech turned into text. The usual starting key is Print Screen (PrtSc).

Why it matters

You can show an error, keep a receipt, or grab text without retyping—without uploading anything.

How to think about it

Print Screen opens a capture tool; modifier keys change the job (region, recording, text, colour). The Capture menu gathers the same actions.

New words

Screenshot
A picture of the screen at one moment.
OCR
Reading text out of a picture into the clipboard.

Take a screenshot safely

Goal: you will be able to capture a region and find the saved file.

Worked example

  1. Press Print Screen to start tam-capture-screenshot in selection mode.
  2. Drag a box, then release. The picture is saved and copied.
  3. Open the Capture menu with Meta + Ctrl + C (tam-menu toggle capture) to see related actions.

Step-by-step practice with Print Screen lives on Taking a screenshot or recording the screen.

Try it

Capture one empty terminal window only, then paste into an editor with Meta + V. Close the practice editor without saving if you do not need the file.

If it goes wrong

Crosshair stuck
Press Print Screen or Esc to cancel, then try again.

Dictation uses voxtype when installed; chords are in voxtype.lua (Meta + Ctrl + X, F9 push-to-talk).

Check yourself

Which command does a plain Print Screen start for screenshots?

tam-capture-screenshot.
