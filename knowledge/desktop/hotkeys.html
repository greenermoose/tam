Desktop hotkeys

This page explains how keyboard shortcuts drive the Tamlinux desktop and where to look them up when you forget one.

What is a hotkey?

A hotkey is a key or chord that asks the desktop to do something: open a terminal, close a window, raise volume, or show a menu. On Tamlinux the main desktop modifier is the Meta key (often marked with a Windows logo).

Why it matters

Remembering a few chords is faster than hunting through menus, and Meta + K always shows the live list when memory fails.

How to think about it

Think of Meta chords as talking to the room (the desktop), while Control chords usually talk to the app inside the focused window.

New words

Meta
The primary desktop modifier key.
Keybinding
A recorded mapping from a chord to an action.

Find and try a packaged binding

Goal: you will be able to open the keybindings list and identify a safe practice chord.

Worked example

  1. Press Meta + K to open keybindings via tam-menu-keybindings.
  2. Find Meta + Return (terminal) under application bindings.
  3. Press Meta + Return to open an empty terminal, then Meta + Q to close only that window after you confirm it has focus.

Actions follow the packaged binding files; personal overrides in your config can differ. Check Meta + K on your machine.

What just happened

  1. The keybindings UI lists what this session will run.
  2. Meta + Return starts the terminal launcher.
  3. Meta + Q closes the focused window only.

Try it

From Meta + K, find the binding that toggles the top bar (Meta + Shift + Space). Toggle once, then toggle back. Leave other windows alone.

If it goes wrong

A chord does nothing
Open Meta + K and confirm the chord is listed. Overrides or a grabbed key in another app can steal it.
Wrong window closed
Focus the empty practice window first; Meta + Q always targets focus.

Packaged chords live under binding files such as applications.lua, tiling.lua, utilities.lua, clipboard.lua, media.lua, and optional voxtype.lua. See the expert section for paths.

Check yourself

Which chord opens the live keybindings list?

Meta + K, which runs tam-menu-keybindings.

Why check Meta + K instead of memorizing only this page?

Your machine may carry personal overrides; Meta + K shows what this session will actually run.

How it works

Product defaults ship in the tamlinux repository under desktop/session/hypr/tamlinux/bindings/. The session loads those Lua files; tam-menu-keybindings reads the effective map for the UI. Do not treat ~/.config/hypr/ alone as the product source of truth.

Advanced usage

Related menus: tam-menu-tmux-keybindings (Meta + Shift + K) and tam-menu-herdr-keybindings (Meta + Ctrl + K). Capture opens with Meta + Ctrl + C via tam-menu toggle capture.

Edge cases

  • Layer-shell panels need clipboard chords that target the focused surface; see comments in clipboard.lua.
  • Hardware media keys are marked locked so they work on the lock screen where appropriate.

Check yourself

Where should a documentation claim about a default chord cite its source?

The packaged file under desktop/session/hypr/tamlinux/bindings/ in the product repository (for example tiling.lua), not a remembered live config alone.
