Desktop Theming and Appearance

This page explains how Tamlinux coordinates color themes, wallpaper backgrounds, terminal colors, and font installation.

What is desktop theming?

Theming controls the visual style of your desktop: the color palette used by windows, the background wallpaper on your monitors, and the typography of text.

Why it matters

A cohesive color theme makes text easy to read in all lighting conditions. High-quality monospace fonts reduce strain when reading code and terminal logs.

How to think about it

Tamlinux applies a single active palette across the compositor, the top bar, terminal emulators, and text editors. Switching themes updates these parts together rather than requiring separate adjustments.

New words

Palette
A coordinated set of foreground, background, and accent colors used across desktop applications.
Font family
A collection of related type designs with varying weights and styles, such as monospace or sans-serif.
Wallpaper
The background image displayed behind windows across your desktop workspaces.

Preview themes and manage fonts safely

Goal: you will be able to switch wallpapers and understand how fonts and color themes are managed.

Worked example

  1. Open the background switcher with Meta + Ctrl + Space (or run tam-menu toggle background) to select from available wallpapers.
  2. Open the theme switcher menu with Meta + Shift + T (or run tam-menu toggle theme) to preview and select from available system themes.
  3. Install a curated monospace font package using the font installer: 
    $ tam-install-font "JetBrains Mono" ttf-jetbrains-mono "JetBrains Mono"

Try it

Inspect available font families on your system by running fc-list : family | sort -u | head -n 15 in your terminal. This is a read-only query.

If it goes wrong

Terminal colors do not match the desktop theme
Run tam-theme-refresh or re-apply your theme with tam-theme-switcher to broadcast updated color escape codes to running terminals.
A new font does not appear in application lists
Refresh the font cache by running fc-cache -f.

Tamlinux stores user background selections and active theme states under standard XDG state directories.

Check yourself

What command installs a font package and selects its family?

tam-install-font.

Which chord opens the desktop background switcher?

Meta + Ctrl + Space.

Theming and font command family

CommandRole
tam-install-fontInstall an Arch font package and set the active family across desktop defaults
tam-theme-switcherInteractive theme selection menu
tam-theme-bg-setSet active desktop wallpaper image
tam-theme-bg-nextCycle to the next available background wallpaper
tam-theme-colors-from-alacrittyGenerate a theme's colors.toml from its alacritty.toml palette directory

Themes and font definitions trace directly to declarative templates in the product checkout. When switching themes, Tamlinux reloads live Wayland surfaces and notifies running terminal emulators via standard OSC color escape codes.
