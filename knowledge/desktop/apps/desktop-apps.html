Desktop Application Suites: KDE and GNOME

This page introduces programs for everyday work, such as reading documents and looking at pictures.

You can use programs to organize documents, view pictures, play media, and edit text. This page looks at programs from KDE and GNOME, two projects that make free desktop software.

What the applications must fit

The survey judged applications against the planned platform, not the current Arch and Hyprland desktop:

The planned basethe target Void base runs runit and seatd without systemd, so applications must work without systemd user sessions or logind.
The planned desktopSway with the Quickshell-based Tamlinux shell, keyboard-driven and tiling. Applications should accept server-side decorations and avoid background polling.

Key findings

Toolkit alignmentthe Tamlinux shell is built on Qt Quick, so KDE applications share the Qt 6 runtime already in memory; GNOME applications bring a second toolkit.
Window decorationsKDE applications support server-side decorations, leaving window frames to Sway. Libadwaita applications draw their own header bars.
systemd couplingcore KDE Frameworks libraries do not require systemd. Several GNOME applications expect logind or systemd user services.
Background servicesboth projects ship file indexers (Baloo in KDE, Tracker in GNOME) and heavy personal-information databases (Akonadi, Evolution Data Server). Baloo can be switched off in its configuration file; Tracker is more tightly bound to GNOME's core applications.

Recommended candidates

Okulardocument viewer for PDF, EPUB, PostScript, DjVu, and more.
Katetext and code editor with a language-server client and Git integration.
Dolphinfile manager, with Baloo indexing turned off.
KCalc, Filelight, and Arkcalculator, disk-usage visualizer, and archive manager.
KDE Connectphone integration that runs without the Plasma desktop.

Settings, menus, and similar desktop surfaces are better served by the Tamlinux shell itself than by either suite, since KDE System Settings and GNOME Settings are tied to their own desktops.

The full survey is desktop-application-suites.md in the ecosystem registry.
