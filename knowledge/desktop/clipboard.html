Clipboard

This page explains how copy and paste work across apps on Tamlinux, including clipboard history.

What is the clipboard?

The clipboard holds the last thing you copied so you can paste it elsewhere. Tamlinux also keeps a short history of earlier items.

Why it matters

One set of chords works in terminals and graphical apps, so you do not relearn copy/paste per program.

How to think about it

Meta + C copies; Meta + V pastes; Meta + Ctrl + V opens history.

New words

Clipboard
Holding place for the latest copy.

Copy, paste, and recover an older item

Goal: you will be able to paste an earlier clipboard entry from history.

Worked example

  1. Copy two different short phrases with Meta + C.
  2. Press Meta + Ctrl + V to open clipboard history.
  3. Select the older phrase and press Return to paste it.

Full practice steps are on Finding something you copied earlier. Chords are implemented in clipboard.lua.

Try it

Copy a screenshot (see Screen capture), then paste into an editor with Meta + V.

Check yourself

Which chord opens clipboard history?

Meta + Ctrl + V.

Binding source

Universal clipboard shortcuts are defined in desktop/session/hypr/tamlinux/bindings/clipboard.lua. They send explicit modifier chords into the focused surface, including layer-shell panels, instead of relying on a virtual keyboard alone.
