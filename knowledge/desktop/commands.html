Guide / Desktop and applications / Desktop commands

Command helpers

These are the commands behind the everyday desktop pages. They adjust settings and controls in your session.

Use the command reference

Goal: read a command and predict its effect before trying its simulated example.

A command reference groups small controls by the job they perform. The examples are simulations, so you can inspect the command and its sample result without changing your desktop.

These are the commands behind the everyday desktop pages. Run them in a terminal. Each one changes a setting immediately; there is no separate save step.

Screenshots and recording

CommandWhat it does
tam-capture-screenshotChoose an area, window, or the full screen; save and copy it
tam-capture-screenshot fullscreenCapture the whole screen without the picker
tam-capture-textChoose an area and copy the text in it
tam-capture-screenrecordingChoose an area and start recording
tam-capture-screenrecording --stop-recordingStop the recording that is running
tam-capture-edit <image>Open a saved picture in the annotator
Try: tam-capture-screenshot fullscreen Read the command after the prompt; do not type the prompt. The sandbox uses sample data and cannot change the host. Try tam-capture-screenshot fullscreen (or type help).

The output is fixed teaching data; no desktop setting or system package changes.

Locking and idle

CommandWhat it does
tam-system-lockLock the screen now
tam-toggle-idleTurn Stay Awake on or off
tam-toggle-idle statusPrint the Stay Awake state as JSON
tam-toggle-idle stay-awakeTurn Stay Awake on
tam-toggle-idle allow-idleTurn Stay Awake off
{"enabled":false,"class":"disabled","tooltip":"Stay Awake"} Try: tam-toggle-idle status Read the command after the prompt; do not type the prompt. The sandbox uses sample data and cannot change the host. Try tam-toggle-idle status (or type help).

In that output, "enabled" refers to Stay Awake, and the tooltip names the action the key would take next. Use status when you want an unambiguous answer; the words printed by stay-awake and allow-idle describe idle locking instead.

Reference and safety

The reference tables list packaged Tamlinux helpers and their effects. Some commands change live session state; confirm the target and save work before using them outside this simulated lesson.
