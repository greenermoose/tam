The start menu (tam-start)

The start command (installed as tam-start) opens a keyboard-driven menu after you sign in at a text console so you can choose what to run next.

Choosing what to do from a text screen

When you sign in at a plain text terminal instead of a graphical login screen, you are at a shell prompt. Running tam-start (or start) shows a numbered or lettered list of activities you can launch right away. Opening the menu never starts graphics by itself; you stay in text mode until you pick the graphical desktop.

You can use the menu to:

  • Start the Tamlinux graphical desktop (tam-desktop).
  • Open this offline Guide, the Keyword Index, the Glossary, Manual Pages, Info Manuals, or TLDR pages.
  • Start a terminal AI assistant if one is installed.
  • Run quick system checks such as live power usage (tam-meter top) or boot timing (tam-boot).

Keys inside the menu

KeyWhat it does
Up / DownMove the highlight between items
Enter or RightStart the highlighted item
a–zStart the item with that shortcut letter
Space or Page DownMove to the next page of items
` (backtick) or Page UpMove to the previous page of items
Home / EndJump to the first or last item
Esc, Backspace, or DeleteLeave the menu and return to the shell

Checking which activities are available

tam-start reads its menu from a catalog file (menu.json) and checks whether each item's command is present on your PATH. You can inspect the catalog from any terminal without opening the interactive screen.

$ tam-start --check
 ✗ [a] Start graphical desktop shell (tam-desktop)
 ✗ [b] Tamlinux Guide (tam)
 ✗ [c] Keyword Index (tam)
 ✗ [d] Glossary (tam)
 ✗ [e] Manual Pages (tam)
 ✗ [f] Info Manuals (tam)
 ✗ [g] TLDR Pages (tam)
 ✗ [h] Claude Code (claude)
 ✗ [i] Codex (codex)
 ✓ [j] Antigravity CLI (agy)
 ✗ [k] OpenCode (opencode)
 ✗ [l] Grok CLI (grok)
 ✗ [m] See what's using power (tam-meter)
 ✗ [n] Explain this boot (tam-boot)

1/14 activities installed on this system.
v0.3.0

The --list option prints the full table with each item's shortcut letter, internal ID, exact command, installation status, and description:

$ tam-start --list
Letter   ID               Command                   Installed  Description
──────────────────────────────────────────────────────────────────────────────────────────
a        desktop          tam-desktop               no         Leave the text shell and start the Tamlinux Hyprland desktop
b        tam-guide        tam show                  no         Browse the offline Tamlinux knowledge guide in the terminal pager
...

--list and --check are read-only queries: they never activate a pending system switch and never launch an interactive screen.

Check yourself

Decide your answer before you reveal it.

If you open tam-start on a text console and decide you just want a shell prompt, what happens?

Press Esc, Backspace, or Delete. The menu restores the terminal and returns to your shell without starting the graphical desktop.

Implementation, bundle activation, and options

start is a pure C program linked only against libtam and libc, with no Python runtime dependency. In the workstation layout it is installed as tam-start.

OptionBehavior
--listPrint the catalog table (letter, ID, argv, PATH check, description) and exit
--checkPrint per-activity availability, installed count, and version
--version, -VPrint start <version> and exit
--help, -hPrint usage summary and exit

When invoked as tam-start in interactive mode (without --list or --check), it runs tam-bundle session-activate to finish any prepared bundle switch before drawing the menu. If the active target changes, it re-executes tam-start so the menu reflects the newly active version. Before loading menu.json, it also checks tam_bundle_guard and exits with a recovery message if a bundle switch is in progress or needs attention.

Interactive mode requires a TTY on both standard input and standard output; otherwise it exits with an error. Selecting an item restores terminal attributes before running the chosen command.
