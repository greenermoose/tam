The Tamlinux Desktop

This page introduces the screen where you open and arrange your programs.

The examples describe the standard Tamlinux desktop. Your own changes may make some keys behave differently. Press SUPER and K together to see the keys available on your computer.

Open a window and recover your place

Goal: you will be able to open an empty terminal, change its layout and return to your starting window.

Why it matters: knowing how to recover focus makes a keyboard-driven desktop less disorienting.

Before you start: save work in existing windows and read Welcome. Practice only with a new empty terminal.

SUPER is usually the key with a Windows logo. A plus sign means hold the keys together, not type a plus. Terminal commands and desktop shortcuts are different: these keys go to the desktop.

Worked example

  1. Note your current window and workspace.
  2. Press SUPER+RETURN to request a new terminal.
  3. With that empty terminal focused, press SUPER+T to toggle floating/tiling. Press it again to undo.
  4. Press SUPER+W to close only that empty terminal.

This walkthrough is checked against the packaged bindings, not a claim that a GUI acceptance test was performed in your session.

What just happened

  1. The terminal launcher opened an application.
  2. The compositor changed the focused window's layout mode.
  3. The close request applied to the focused window. Focus matters before closing.

Try it

Open two empty terminals. Use SUPER+Left/Right/Up/Down to move focus in the corresponding direction when another window is there. Identify the focused window before closing either. Keep real work untouched.

If it goes wrong

A shortcut does nothing
Check SUPER+K and your compositor/overrides. A directional focus request needs a window in that direction.
A window seems missing
Check the workspace and fullscreen/floating state before launching another copy.

New words

Focus
The window receiving keyboard input.
Tiling
Layout where the compositor arranges windows; floating windows and other modes can overlap them.

Check yourself

Decide before revealing the explanation.

Which window does SUPER+W close?

The currently focused window receives the close request. Check focus and save work first; practice with an empty terminal.

Does tiling mean windows can never overlap?

No. Floating windows and other modes can overlap; fullscreen and application behavior also affect what is visible.
