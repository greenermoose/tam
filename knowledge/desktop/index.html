The Tamlinux Graphical Desktop

This page explains the graphical desktop where you can use your keyboard, mouse, or voice to control your computer. "Graphical" means that your computer is in a mode that allows it to draw any sort of shape on a screen, not just rows of text. Computer "graphics" refers to drawing pixels (short for "picture elements," or dots of light) on a screen.

When you first boot up Tamlinux you arrive in a command line interface (CLI) text-only shell where you can type commands and send them to your computer. From a CLI shell, the tam-desktop command opens a graphical shell (also called a graphical user interface or GUI shell) that this guide calls the Tamlinux desktop.

To switch from the Tamlinux desktop to a text-only "virtual terminal," you can press and hold the Ctrl key, then press and hold the Alt key, and then press F2 or another function key (Ctrl + Alt + F2, Ctrl + Alt + F3, etc.). These text-only virtual terminals (VTs) are numbered tty2, tty3, etc. (TTY stands for "TeleTYpe", which was how computers printed output before monitor technology was available.) Sometimes switching to a different tty is necessary for recovery if your graphical desktop is not responding or you need to troubleshoot a serious problem.

Navigating your desktop

The examples below describe the standard Tamlinux desktop and keybindings. You may change your settings to make your keys behave differently. A keybinding is a short-hand way to give a command to your computer by pressing a key or combination of keys.

The Meta key (on many keyboards it has a Windows logo on it) is your super power in the Tamlinux desktop. Here are three keybindings to try.

  • Meta + Space opens your application launcher.
  • Meta + Return opens a terminal window.
  • Meta + K lists every keybinding.

Open a window and recover your place

Goal: you will be able to open an empty terminal, change its layout and return to your starting window.

Why it matters: knowing how to recover focus makes a keyboard-driven desktop less disorienting.

Before you start: save work in existing windows and read Welcome. Practice only with a new empty terminal.

Meta is usually the key with a Windows logo. A plus sign means hold the keys together, not type a plus. Terminal commands and desktop shortcuts are different: these keys go to the desktop.

Worked example

  1. Note your current window and workspace.
  2. Press Meta + Return to request a new terminal.
  3. With that empty terminal focused, press Meta + T to toggle floating/tiling. Press it again to undo.
  4. Press Meta + W to close only that empty terminal.

This walkthrough is checked against the packaged bindings, not a claim that a GUI acceptance test was performed in your session.

What just happened

  1. The terminal launcher opened an application.
  2. The compositor changed the focused window's layout mode.
  3. The close request applied to the focused window. Focus matters before closing.

Try it

Open two empty terminals. Use Meta + Left/Right/Up/Down to move focus in the corresponding direction when another window is there. Identify the focused window before closing either. Keep real work untouched.

If it goes wrong

A shortcut does nothing
Check Meta + K and your compositor/overrides. A directional focus request needs a window in that direction.
A window seems missing
Check the workspace and fullscreen/floating state before launching another copy.

New words

Focus
The window receiving keyboard input.
Tiling
Layout where the compositor arranges windows; floating windows and other modes can overlap them.

Check yourself

Decide before revealing the explanation.

Which window does Meta + W close?

The currently focused window receives the close request. Check focus and save work first; practice with an empty terminal.

Does tiling mean windows can never overlap?

No. Floating windows and other modes can overlap; fullscreen and application behavior also affect what is visible.
