The Tamlinux Desktop

Tamlinux features a keyboard-first, tiling Wayland environment designed for maximum screen efficiency and distraction-free computing. Instead of manually dragging and resizing windows, the desktop arranges windows into clean tiles automatically.

Essential keybindings

The SUPER key (often labeled with a Windows or Command logo) is the primary control key for window management:

KeybindingAction
SUPER + RETURNOpen a new terminal emulator
SUPER + SpaceOpen the application launcher
SUPER + QClose the active window
SUPER + H / J / K / LMove focus between tiled windows (left, down, up, right)
SUPER + Shift + H/J/K/LSwap the position of the active window
SUPER + FToggle fullscreen on the focused window
SUPER + KDisplay the quick keybindings reference

Window layout and tiling

When you open a second window, the active area splits automatically to make room. Windows never overlap or hide behind each other unless explicitly set to floating mode.

To toggle floating mode for windows that require a fixed geometry (such as calculators or file pickers), press SUPER + Shift + Space.
