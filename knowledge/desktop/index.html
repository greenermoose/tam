The Tamlinux Graphical Desktop

This page explains the graphical desktop where you can use your keyboard, mouse, or voice to control your computer.

What is the graphical desktop?

"Graphical" means your computer can draw shapes on a screen, not only rows of text. When you first boot Tamlinux you arrive in a text-only shell. From there, tam-desktop opens the graphical Tamlinux desktop.

The Meta key (often marked with a Windows logo) is the main command key for the desktop. Meta + Space opens the system menu; Meta + Return opens a terminal; Meta + K lists keybindings.

Why it matters

Knowing a few desktop chords lets you open tools and recover focus without hunting through menus, which keeps a keyboard-driven desktop usable.

How to think about it

Think of Meta as the desktop's command key: it talks to the window manager about windows and workspaces, while Control usually talks to the program inside a window.

New words

Open a window and recover your place

Goal: you will be able to open an empty terminal, change its layout and return to your starting window.

Before you start: save work in existing windows and read Welcome. Practice only with a new empty terminal.

Meta is usually the key with a Windows logo. A plus sign means hold the keys together, not type a plus. These keys go to the desktop, not into the terminal text.

Worked example

  1. Note your current window and workspace.
  2. Press Meta + Return to request a new terminal.
  3. With that empty terminal focused, press Meta + T to toggle floating/tiling. Press it again to undo.
  4. Press Meta + Q to close only that empty terminal.

This walkthrough is checked against the packaged bindings, not a claim that a GUI acceptance test was performed in your session.

What just happened

  1. The terminal launcher opened an application.
  2. The compositor changed the focused window's layout mode.
  3. The close request applied to the focused window. Focus matters before closing.

Try it

Open two empty terminals. Use Meta + Left/Right/Up/Down to move focus when another window is there. Identify the focused window before closing either. Keep real work untouched.

If it goes wrong

A shortcut does nothing
Check Meta + K and your overrides. A directional focus request needs a window in that direction.
A window seems missing
Check the workspace and fullscreen/floating state before launching another copy.

Ctrl + Alt + F2 and other function keys switch to text virtual terminals for recovery when the graphical session is stuck.

Check yourself

Which window does Meta + Q close?

The currently focused window. Check focus and save work first; practice with an empty terminal.

Does tiling mean windows can never overlap?

No. Floating windows and other modes can overlap.
