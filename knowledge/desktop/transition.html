Coming from Mac or Windows

This page orients people who know macOS or Windows to the Tamlinux graphical desktop.

What stays familiar?

You still have windows, a keyboard, a pointer, and a place for the time of day. Tamlinux boots first to text; the graphical desktop starts when you ask for it. The special desktop key is called Meta—on many keyboards it is the key with a Windows logo (not Command on a Mac keyboard unless you remap).

Why it matters

A few renamed ideas (Meta instead of Super/Win, tiling instead of overlapping cascades) prevent early frustration.

How to think about it

Imagine the desktop as a keyboard-first workshop: Meta chords run the shop; the top bar is the status shelf; workspaces are extra desks.

New words

Meta
Desktop command key on Tamlinux.
Tiling
Windows share the screen without stacking by default.

Survive the first session

Goal: you will be able to open the menu, open a terminal, list keybindings, and close a practice window.

Worked example

  1. Press Meta + Space for the Tamlinux menu, then Escape to dismiss it.
  2. Press Meta + Return for a terminal.
  3. Press Meta + K to browse keybindings.
  4. Focus the empty terminal and press Meta + Q to close it.

These chords come from packaged utilities.lua and applications.lua. On a Mac keyboard, confirm which physical key sends Meta.

What just happened

  1. Menus and launchers are keyboard-reachable without a Windows-style Start glyph hunt.
  2. Keybindings are discoverable live, not only in this guide.

Try it

Open the file manager with Meta + F, then close it with Meta + Q after you focus it. Leave any real work windows untouched.

If it goes wrong

Meta seems dead
You may be pressing Command/Option instead. See The Meta key.
I want overlapping windows
Toggle floating with Meta + T on the focused window; see Windows and layouts.

How it works

The graphical session is Hyprland plus the Tamlinux shell. Packaged defaults are cultivar files; user overrides belong under personal config and must not be cited as product defaults.

Advanced usage

Text consoles remain available for recovery (for example Ctrl + Alt + F2) when the graphical session misbehaves—see the desktop hub.

Edge cases

  • External Mac keyboards may need remapping before Meta matches muscle memory.
  • Preinstalled application chords in applications.lua can be disabled when those apps are absent.

Tamlinux behavior is defined by its packaged bindings and modules; other desktops' manuals describe different systems.
