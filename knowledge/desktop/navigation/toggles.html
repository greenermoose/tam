The Tamlinux Desktop

What is a toggle?

A toggle is an on/off switch for a desktop behavior—such as keeping the screen awake during a presentation, warming display colors at night, or silencing pop-up notifications—without digging through a large settings program.

Why it matters

Quick toggles prevent the machine from sleeping mid-task or interrupting you with alerts while you focus.

How to think about it

Think of toggles like wall switches in a room: flipping one turns a single behavior on or off immediately, and flipping it again puts it back the way it was.

New words

Idle
Time with no input after which the session may dim, lock, or sleep.
Night light
Warmer display colours for evening use.

Find the toggle menu

Goal: you will be able to open the Toggle menu and recognize idle versus night-light controls.

Try the idea in a sandbox

Sample: Meta + U toggles gaps; repeat to restore the previous state Try: tam-menu-keybindings A toggle changes state each time it is pressed. Press the same chord again to return to the earlier state. Try the command shown above (or type help).

The output is fixed teaching data; the sandbox does not inspect or alter your system.

Try it

Open and dismiss the Toggle menu once. Do not disable idle on a laptop you will leave unattended.

If it goes wrong

A setting stayed off or on unexpectedly
Check the explicit read-only status subcommand when supported (such as tam-toggle-idle status or tam-toggle-nightlight --status) before pressing the toggle chord again.
Toggle menu does not appear
Inspect packaged keybindings with Meta + K to see whether a local override rebound Meta + Ctrl + O.

Check yourself

Which chord opens the Toggle menu in packaged bindings?

Meta + Ctrl + O.
