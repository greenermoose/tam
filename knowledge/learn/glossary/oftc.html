OFTC (Open and Free Technology Community)

Non-profit IRC network hosting Debian, kernel, and free-software project channels.

Novice definition

OFTC is a major IRC chat network used by Debian, QEMU, and Linux kernel communities.

Learner definition

OFTC provides public chat rooms for free-software contributors alongside Libera.Chat.

Expert definition

SPI-associated IRC network (irc.oftc.net) serving Debian, Linux kernel subsystems, and LLVM.
