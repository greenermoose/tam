SPI - Serial Peripheral Interface

A fast four-wire bus for chips.

Novice definition

SPI is a simple high-speed connection used by flash chips, displays, and sensors.

Learner definition

Serial Peripheral Interface uses clock, data-in, data-out, and chip-select lines in a master-slave arrangement.

Expert definition

SPI is a synchronous full-duplex serial bus with mode-dependent clock polarity and phase, selected slaves, and no built-in addressing.
