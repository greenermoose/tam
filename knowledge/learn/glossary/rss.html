RSS (Resident Set Size)

Amount of physical RAM currently held by a process (excluding swapped-out pages).

Novice definition

RSS shows how much actual physical RAM a running program is taking up right now.

Learner definition

Reported by ps, top, and tam-meter, RSS includes shared libraries mapped into the process (unlike PSS).

Expert definition

Per-process resident physical page count (VmRSS in /proc//status), summing private pages plus full shared pages.
