Paging

Moving memory in fixed-size pages between RAM and storage.

Novice definition

Paging is the system's way of shuffling memory pages to disk when RAM gets tight.

Learner definition

Paging maps virtual pages to physical frames and moves selected pages to swap under memory pressure.

Expert definition

Paging is demand-based virtual memory with page tables, page faults, and replacement, distinct from whole-process swapping.
