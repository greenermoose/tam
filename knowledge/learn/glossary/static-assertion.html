Static assertion

A compile-time check that must be true.

Novice definition

A static assertion is a check the compiler makes while building, before the program ever runs.

Learner definition

A static assertion fails compilation when a constant condition is false, catching errors early.

Expert definition

A static assertion is a compile-time constraint evaluated during translation, such as C11 _Static_assert or C++ static_assert.
