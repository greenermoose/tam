Hexadecimal

A number system that uses sixteen digits.

Novice definition

Hexadecimal is counting with sixteen symbols, 0 to 9 and A to F, used as a short way to write binary.

Learner definition

One hexadecimal digit represents four bits, so two digits represent one byte, as in the address 7fff.

Expert definition

Hexadecimal is base-16 notation using 0-9 and A-F; it is common for addresses, colors, and byte dumps because it aligns with nibbles.
