BHT (Brassard-Hoyer-Tapp algorithm)

Quantum algorithm finding hash collisions in O(2^(n/3)) time.

Novice definition

BHT is a quantum computer algorithm that searches for hash collisions faster than normal computers.

Learner definition

BHT lowers collision resistance of an n-bit hash from 2^(n/2) to 2^(n/3), which is why 256-bit hashes remain strong.

Expert definition

Quantum collision-finding algorithm using Grover search over a precomputed table, achieving O(2^(n/3)) query complexity (ignoring quantum RAM cost).
