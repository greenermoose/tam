Filesystem

A filesystem is a way for a computer to organize and find stored information.

Beginner definition

A way to organize and find files and directories.

Intermediate definition

Linux joins available filesystems into one directory tree at mount points.

Expert definition

A filesystem provides operations and storage semantics for objects; virtual filesystems can expose kernel interfaces rather than ordinary stored files.
