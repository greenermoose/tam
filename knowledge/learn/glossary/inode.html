Inode

A filesystem record describing a file.

Novice definition

An inode is the hidden record that stores a file's size, owner, permissions, and where its data lives.

Learner definition

An inode holds metadata and data block references; a directory maps names to inode numbers.

Expert definition

An inode is a filesystem object containing mode, ownership, timestamps, link count, and extent or block mappings, addressed by inode number.
