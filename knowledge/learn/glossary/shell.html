Shell

A shell is a program that reads the instructions you type and asks the computer to carry them out.

Beginner definition

A program that reads commands you type and asks the system to carry them out.

Intermediate definition

A shell can start programs, connect their input and output, and run its own built-in commands.

Expert definition

The shell parses and expands command text before executing it; quoting changes how it interprets characters and forms arguments.
