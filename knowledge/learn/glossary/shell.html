Shell

A shell is a program that reads the instructions you type and asks the computer to carry them out.

Novice definition

A program that reads commands you type and asks the system to carry them out. On Tamlinux the usual interactive shell is Bash. You meet it in a terminal window or on a text console. The Guide is a separate program you reopen with tam hi.

Learner definition

A shell can start programs, connect their input and output with pipes and redirections, and run its own built-in commands such as cd. Pipelines and jobs are shell skills; see pipelines and jobs.

Expert definition

The shell parses and expands command text before executing it; quoting changes how it interprets characters and forms arguments. Exit status, descriptor inheritance and job control are shell semantics layered on kernel processes.
