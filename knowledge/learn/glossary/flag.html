Flag

An option that is either on or off.

Novice definition

A flag is a command option with no value, like --help, that turns a behavior on.

Learner definition

A flag is a boolean option whose presence enables or disables a feature.

Expert definition

A flag is a zero-argument option or status bit, often represented as a boolean field in a parser or register.
