HDD - Hard Disk Drive

Storage that uses spinning magnetic disks.

Novice definition

An HDD is a traditional hard drive that stores data on spinning platters.

Learner definition

A hard disk drive uses rotating platters and moving heads to read and write magnetic data.

Expert definition

An HDD is an electromechanical block device with platters, spindle, actuator, and head assembly addressed by CHS or LBA.
