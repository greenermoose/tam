KGDB (Kernel GNU Debugger)

Linux kernel source-level debugger operating over a serial port or network.

Novice definition

KGDB lets kernel developers attach a debugger over a serial cable to inspect a frozen Linux kernel.

Learner definition

KGDB uses a UART serial console (kgdboc) so a second machine can step through kernel code.

Expert definition

In-kernel GDB stub (kernel/debug/gdbstub.c) communicating over RS-232/UART via kgdboc.
