CAA (Certification Authority Authorization)

DNS record specifying which Certificate Authorities are allowed to issue TLS certificates for a domain.

Novice definition

A CAA record is a DNS note saying 'only these trusted authorities may issue security certificates for my domain'.

Learner definition

RFC 8659 requires public CAs to check a domain's CAA DNS record before signing a TLS certificate.

Expert definition

DNS resource record type 257 (RFC 8659) restricting issuance via issue, issuewild, and iodef tags.
