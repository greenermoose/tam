PDF (Portable Document Format)

Fixed-layout document format (ISO 32000) preserving fonts, pages, and vector graphics.

Novice definition

PDF is the standard document format that looks the same on every computer and printer.

Learner definition

On Linux, lightweight viewers like zathura or browsers open PDFs, and cups-pdf/print dialogs generate them.

Expert definition

ISO 32000-2 object-stream document format embedding PostScript/PDF vector operators, CFF/TrueType fonts, and XMP metadata.
