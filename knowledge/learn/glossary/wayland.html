Wayland

Wayland is the modern protocol Linux desktops use to draw windows on the screen.

Beginner definition

Wayland is a set of rules that lets applications talk to a compositor program that owns the screen. Each window is a surface; the compositor places those surfaces and sends keyboard and pointer events. Tamlinux uses Wayland through its compositor.

Intermediate definition

Wayland replaces the older X11 display model for most new Linux desktops. Clients speak Wayland protocols; a compositor implements them and may also speak extensions for screenshots, layer panels, or input methods. Debugging often separates client faults from compositor faults.

Expert definition

A display-server protocol and ecosystem in which a compositor owns outputs and mediates client surfaces and input; Tamlinux sessions use Wayland compositors.
