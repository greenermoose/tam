EOF (End of File)

Condition indicating no more bytes are available from a file, pipe, or input stream.

Novice definition

EOF means 'end of file'—the signal that a file or input stream has no more data to read.

Learner definition

In a terminal, pressing Ctrl+D on an empty line signals EOF to the running program; in pipelines, closing the write end sends EOF to the reader.

Expert definition

End-of-file condition returned by read(2) == 0 (or stdio EOF == -1), not a character stored in files.
