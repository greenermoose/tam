Procfs

A virtual filesystem that exposes process and kernel information.

Novice definition

Procfs is the special /proc folder where the kernel reports running processes and system settings.

Learner definition

Procfs exposes process state, kernel parameters, and some device information as readable files.

Expert definition

Procfs is a pseudo-filesystem whose files are generated on access and whose writes can change kernel tunables or process behavior.
