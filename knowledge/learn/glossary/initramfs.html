Initramfs

A small temporary filesystem used during early boot.

Novice definition

An initramfs is a temporary startup filesystem that helps the kernel find and mount the real system.

Learner definition

The initial RAM filesystem provides drivers and scripts needed to assemble storage, decrypt volumes, and mount the root filesystem.

Expert definition

An initramfs is a cpio archive loaded into a tmpfs, executed by the kernel as early user space before the real root is mounted.
