BPU (Branch Prediction Unit)

CPU frontend hardware that guesses which way conditional branches will go before they resolve.

Novice definition

The BPU is the part of a CPU that guesses which path an 'if' statement will take so the pipeline stays full.

Learner definition

Modern BPUs use TAGE predictors and branch target buffers; mispredictions flush the pipeline, and speculative leaks led to IBRS/Retpoline.

Expert definition

Microarchitectural frontend predictor (BHT, BTB, RAS, TAGE) driving speculative instruction fetch.
