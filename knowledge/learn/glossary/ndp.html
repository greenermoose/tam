NDP (Neighbor Discovery Protocol)

IPv6 protocol using ICMPv6 for address resolution, router discovery, and link-layer mapping.

Novice definition

NDP is how IPv6 devices find each other and their router on a local network.

Learner definition

Replacing IPv4 ARP, NDP relies on ICMPv6 Neighbor Solicitation/Advertisement packets that firewalls must allow for IPv6 to work.

Expert definition

IETF RFC 4861 ICMPv6 types 133-137 handling SLAAC, DAD, and link-layer resolution; blocking ICMPv6 breaks IPv6.
