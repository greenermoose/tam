Keysym

A keysym is the symbolic meaning a keyboard layout gives to a key, such as a, A, Return or BackSpace.

Novice definition

A keysym is a name for what a key should mean. Pressing the same key with Shift gives a different keysym, so the layout can change meaning without changing the hardware.

Learner definition

XKB turns a keycode and modifier state into a keysym. Letters use their character value, so a is 0x0061 and A is 0x0041. Named keys use values in a private range, so BackSpace is 0xFF08 and Return is 0xFF0D. A terminal emulator then decides which bytes represent that keysym.

Expert definition

Keysyms are 32-bit values defined in xkbcommon-keysyms.h and the older X11/keysymdef.h. Values below 0x100 coincide with Latin-1, 0x01000100 and above carry Unicode, and 0xFF00 to 0xFFFF hold function keys, cursor keys and modifiers. XKB keymaps can map one keycode to several keysyms per shift level and can attach actions such as SetMods. A keysym is not a character: BackSpace has no printable form, and dead_acute starts a compose sequence. The xkbcli how-to-type tool shows which keycode and modifiers produce a requested keysym.
