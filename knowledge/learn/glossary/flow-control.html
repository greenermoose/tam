Flow Control

Flow control is a mechanism preventing a fast sender from overrunning a slow receiver with data.

Novice definition

A signaling agreement between two connected devices that tells the sender to pause whenever the receiver's memory buffer gets full, preventing data from being dropped or lost.

Learner definition

Pacing mechanisms implemented in hardware or software. Hardware flow control uses dedicated physical lines (RTS/CTS or DTR/DSR) for immediate pauses; software flow control transmits special in-band control characters (ASCII XON and XOFF) inside the data stream.

Expert definition

Rate-matching mechanisms operating at link or transport layers. In asynchronous serial interfaces, hardware flow control gates the UART FIFO transmission registers, eliminating overrun errors and avoiding latency induced by software packet retransmissions.
