Raw mode

Terminal input mode that sends every keystroke immediately to the program without kernel line editing.

Novice definition

Raw mode turns off normal line editing so a program—like a text editor or pager—receives every key the instant you press it.

Learner definition

In raw mode (ICANON and ECHO disabled), the program must decode arrow-key escape sequences and draw its own screen updates.

Expert definition

Non-canonical termios mode (cfmakeraw): disables ICANON, ECHO, ISIG, IEXTEN, ICRNL, IXON, and OPOST so raw bytes pass unmodified between PTY and application.
