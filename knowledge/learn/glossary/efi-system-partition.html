EFI System Partition

The special partition that holds boot firmware files.

Novice definition

The EFI System Partition is a small disk partition where the firmware looks for boot programs.

Learner definition

The EFI System Partition is a FAT-formatted partition, usually mounted at /boot/efi, holding EFI applications and boot loaders.

Expert definition

The EFI System Partition is a FAT32 partition identified by a GPT type GUID, containing vendor directories and EFI executables loaded by firmware.
