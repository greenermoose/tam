FLIT (Flow Control Unit)

Fixed-size packet unit used in modern high-speed interconnects (PCIe 6.0, CXL, NoCs).

Novice definition

A FLIT is a fixed-size data chunk used by ultra-fast buses like PCIe 6.0 to move data with low latency.

Learner definition

Fixed-size FLITs simplify framing, PAM-4 error correction, and credit-based flow control.

Expert definition

Fixed-length link-layer frame (e.g., 256-byte PCIe 6.0 FLIT with integrated CRC and FEC) replacing variable-length TLP framing.
