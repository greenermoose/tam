EPUB (Electronic Publication)

Open reflowable e-book format built from zipped XHTML, CSS, and metadata.

Novice definition

EPUB is an open e-book format whose text reflows neatly to fit any screen size.

Learner definition

Unlike fixed-page PDFs, EPUB files adapt font size and line wrapping dynamically.

Expert definition

W3C/IDPF ZIP container (application/epub+zip) bundling OPF spine, XHTML content documents, and CSS.
