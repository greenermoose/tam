Glob

Filename pattern matching using wildcards.

Novice definition

A glob is a pattern like *.txt that the shell expands into matching file names.

Learner definition

Globbing expands patterns containing *, ?, and brackets into sorted pathnames, subject to shell options.

Expert definition

A glob is a pathname pattern expanded by the shell or glob library, with bracket expressions, character classes, and locale-aware collation.
