AEAD - Authenticated Encryption with Associated Data

Encryption that protects both secrecy and tampering in a single construction.

Novice definition

AEAD locks a message so no one can read it and seals it so any tampering is immediately caught.

Learner definition

AEAD algorithms such as AES-GCM and ChaCha20-Poly1305 output ciphertext plus an authentication tag, also authenticating unencrypted headers (associated data).

Expert definition

Symmetric encryption achieving both IND-CPA and INT-CTXT (together IND-CCA3 / AE security) over plaintext, nonce, key, and unencrypted associated data AAD.
