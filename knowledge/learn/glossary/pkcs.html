PKCS (Public-Key Cryptography Standards)

Series of foundational standards (such as PKCS#1 RSA, PKCS#8 keys, PKCS#11 tokens).

Novice definition

PKCS is a numbered series of standards that define how public-key algorithms, key files, and hardware tokens work.

Learner definition

Common standards include PKCS#1 (RSA), PKCS#8 (private key file format), and PKCS#11 (hardware security token API).

Expert definition

RSA Laboratories / IETF standards family: PKCS#1 (RFC 8017), PKCS#5 (RFC 8018), PKCS#8 (RFC 5958), PKCS#11 (OASIS), PKCS#12 (RFC 7292).
