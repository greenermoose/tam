Idle

A state where the system has no recent input.

Novice definition

Idle means the computer has not been used for a while, so it may dim or lock.

Learner definition

Idle is a period without input or activity, used to trigger dimming, locking, suspend, or screen blanking.

Expert definition

Idle detection combines input timers, inhibitors, and compositor idle protocols to drive power and lock policy.
