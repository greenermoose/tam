SNI (Server Name Indication)

TLS extension sending the target hostname in ClientHello so one IP can host many HTTPS sites.

Novice definition

SNI tells a web server which website name you are visiting at the very start of an HTTPS connection.

Learner definition

Because SNI is sent in plaintext ClientHello (unless Encrypted ClientHello is used), network observers can see the hostname.

Expert definition

RFC 6066 TLS server_name extension in ClientHello enabling virtual hosting before certificate selection.
