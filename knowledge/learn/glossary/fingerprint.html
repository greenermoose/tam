Fingerprint

A short value that identifies a key or person.

Novice definition

A fingerprint is a short code that identifies a key or a person's biometric trait.

Learner definition

A key fingerprint is a hash of a public key, used to compare keys out of band.

Expert definition

A fingerprint is a cryptographic digest of key material, displayed in grouped hex or base64 to detect substitution; biometric fingerprints are separate pattern-matching data.
