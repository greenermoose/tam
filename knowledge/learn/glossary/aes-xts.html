AES-XTS (XEX-based Tweaked-Codebook with Ciphertext Stealing)

Disk-encryption block mode using sector-number tweaks without expanding sector size.

Novice definition

AES-XTS is the encryption mode designed for hard drives and SSDs so each disk sector encrypts independently.

Learner definition

Part of AES variants, AES-XTS is the default cipher mode for LUKS2 full-disk encryption.

Expert definition

IEEE P1619 XTS-AES: uses two AES keys (data key and tweak key) to encrypt fixed-size storage sectors with sector-index tweaks and ciphertext stealing.
