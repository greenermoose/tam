Shared library

A library loaded by programs at runtime.

Novice definition

A shared library is a library stored once and used by many programs while they run.

Learner definition

A shared library is a dynamically linked object, such as a .so file, mapped into processes and resolved by the dynamic loader.

Expert definition

A shared library is an ELF shared object with a soname, dynamic symbol table, and position-independent code, loaded by ld.so.
