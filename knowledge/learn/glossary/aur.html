AUR (Arch User Repository)

Community-maintained repository of PKGBUILD scripts for building extra Arch Linux packages.

Novice definition

The AUR is a community collection of recipes (PKGBUILDs) for software not in Arch's official package repositories.

Learner definition

AUR packages are built locally with makepkg; always read a PKGBUILD before building because AUR recipes are community-submitted.

Expert definition

Community-driven Arch Linux PKGBUILD/SRCINFO repository outside official signed binary repos.
