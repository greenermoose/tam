DLE (Data Link Escape, 0x10)

ASCII 0x10 control character (Ctrl+P) historically used to escape binary framing bytes.

Novice definition

DLE is a control byte (0x10) used in older serial links to mark that the next byte is raw data, not a command.

Learner definition

Part of the C0 control codes, DLE (Ctrl+P) also acts as previous-history in Readline.

Expert definition

ASCII 0x10 (DLE). Byte-stuffing escape in BISYNC/PPP-like framing; in interactive shells it corresponds to Ctrl+P.
