Firewall

Software or hardware that filters network traffic.

Novice definition

A firewall is a guard that allows or blocks network connections according to rules.

Learner definition

A firewall inspects packets or flows and applies policy using addresses, ports, protocols, and connection state.

Expert definition

A firewall is a packet-filtering or stateful inspection system, often using nftables or eBPF, with zones, chains, and verdicts.
