GPT

The modern disk partition table format.

Novice definition

GPT is the modern map of partitions on a disk, replacing the old MBR map.

Learner definition

GUID Partition Table stores partition entries with GUIDs, CRC protection, and a backup header.

Expert definition

GPT is a 64-bit LBA partition table with a protective MBR, primary and backup headers, and 128-byte entries protected by CRC32.
