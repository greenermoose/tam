OS

The software that manages a computer's hardware and programs.

Novice definition

An OS is the main software that runs the computer and lets you use programs.

Learner definition

An operating system manages processes, memory, files, devices, and users, and provides services to applications.

Expert definition

An operating system is a privileged kernel plus system services and interfaces that virtualize hardware and enforce isolation and policy.
