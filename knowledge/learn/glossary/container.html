Container

An isolated group of processes sharing the host kernel.

Novice definition

A container is a packaged program and its files that runs isolated on a computer without simulating a whole machine.

Learner definition

A container uses namespaces, cgroups, and filesystem layers to isolate processes while sharing the host kernel.

Expert definition

A container is an OCI-style process bundle with namespaced views, cgroup limits, capabilities, and layered root filesystem, not a full virtual machine.
