Unit

A named object managed by systemd.

Novice definition

A unit is one thing systemd knows how to manage, such as a service, mount, or timer.

Learner definition

A systemd unit is a configuration file describing a resource, its dependencies, and how to start or stop it.

Expert definition

A unit is a systemd object identified by name and type, with sections for dependencies, execution, installation, and resource control.
