GCC (GNU Compiler Collection)

Standard open-source C/C++ compiler suite on Linux.

Novice definition

GCC is the main open-source compiler on Linux that turns C and C++ source code into runnable programs.

Learner definition

Tamlinux compiles C11 components with GCC (or Clang) using strict warnings and optional AddressSanitizer.

Expert definition

GNU Compiler Collection supporting C11, C++, Ada, Go, and multi-target optimization (-O2, -fsanitize=address,undefined).
