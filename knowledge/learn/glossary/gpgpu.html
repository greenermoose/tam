GPGPU (General-Purpose Computing on GPUs)

Using graphics processors for non-graphics parallel workloads such as AI, science, and hashing.

Novice definition

GPGPU means using a graphics card's thousands of small cores for general math—like running local AI models—instead of just drawing pixels.

Learner definition

APIs like Vulkan Compute, OpenCL, ROCm, and CUDA expose GPU SIMT cores for matrix math and parallel workloads.

Expert definition

Compute-shader / kernel dispatch on GPU SIMT hardware exploiting high memory bandwidth and ALU density.
