Decoupled versioning

Versioning the command and corpus separately.

Novice definition

Decoupled versioning means the tam program and its documentation can have different version numbers.

Learner definition

Decoupled versioning lets the C command and the knowledge corpus change independently, with each reporting its own version.

Expert definition

Decoupled versioning separates the command binary ABI and release cadence from the corpus content version, resolved dynamically from the knowledge root.
