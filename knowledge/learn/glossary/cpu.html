CPU - Central Processing Unit

The processor that executes instructions.

Novice definition

The CPU is the main chip that carries out the instructions of a program.

Learner definition

The CPU fetches, decodes, and executes instructions, using registers, caches, and arithmetic units.

Expert definition

A central processing unit is an instruction-stream processor containing control logic, ALUs, registers, and a memory hierarchy interface.
