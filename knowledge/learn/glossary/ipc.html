IPC

Ways for processes to communicate.

Novice definition

IPC is how separate programs exchange data, such as through pipes, sockets, or shared memory.

Learner definition

Inter-process communication includes pipes, sockets, message queues, shared memory, and signals.

Expert definition

IPC is a set of kernel-mediated mechanisms for data exchange and synchronization between processes, with namespace and permission boundaries.
