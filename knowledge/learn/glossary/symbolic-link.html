Symbolic link

A file that points to another path.

Novice definition

A symbolic link is a shortcut that contains the name of another file or folder.

Learner definition

A symlink stores a path that the kernel resolves when the link is accessed; it can point across filesystems or dangle.

Expert definition

A symbolic link is an inode of type symlink whose data is a pathname interpreted relative to the link's directory or as absolute.
