RAM - Random-Access Memory

Fast working memory that loses its contents when power is off.

Novice definition

RAM is the computer's short-term workspace where running programs and open files live.

Learner definition

Random-access memory holds code and data for the CPU; it is volatile and much faster than storage.

Expert definition

RAM is volatile semiconductor memory addressed by the processor, typically DRAM, holding the active working set and kernel structures.
