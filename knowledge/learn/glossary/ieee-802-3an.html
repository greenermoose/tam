IEEE 802.3an (10GBASE-T)

10 Gigabit Ethernet standard over twisted-pair copper cabling.

Novice definition

IEEE 802.3an is the standard that allows 10-gigabit network speeds over standard copper Ethernet cables.

Learner definition

Using multi-level signaling and strong error correction, 10GBASE-T pushes 10 Gbps up to 100 meters over Cat 6A twisted-pair cable.

Expert definition

IEEE Std 802.3an-2006 (Clause 55) specifies 10GBASE-T physical layer using PAM-16 modulation, Tomlinson-Harashima precoding, and (2048, 1723) LDPC forward error correction at 800 MBaud across four pairs.
