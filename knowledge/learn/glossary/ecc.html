ECC - Error-Correcting Code

Error-correcting code that detects and fixes some memory errors.

Novice definition

ECC is extra checking data that lets memory find and correct small errors instead of crashing.

Learner definition

Error-correcting code adds redundant bits so memory can detect and often correct single-bit errors.

Expert definition

ECC is a coding scheme, commonly SECDED for memory, that adds parity or Hamming bits to detect and correct errors within a code word.
