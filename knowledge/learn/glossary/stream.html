Stream

A stream is information a program reads or writes in order.

Beginner definition

Bytes a program reads or writes in order.

Intermediate definition

Programs expose standard input, output and error streams; a pipeline usually connects output to another input.

Expert definition

A stream supplies an ordered byte interface; Linux pipes preserve byte order without preserving message boundaries.
