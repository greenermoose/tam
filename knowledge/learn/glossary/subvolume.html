Subvolume

A separately managed tree inside Btrfs.

Novice definition

A subvolume is a section of a Btrfs filesystem that can be snapshotted and managed on its own.

Learner definition

A Btrfs subvolume is an independently snapshottable directory tree with its own inode namespace and quota accounting.

Expert definition

A subvolume is a Btrfs root object with a subvolume ID, referenced by path or ID, supporting snapshots, quotas, and send/receive.
