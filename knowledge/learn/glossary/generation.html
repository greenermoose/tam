Generation

A generation is a recorded selection of software and settings.

Beginner definition

A recorded selection of managed software and configuration. Selecting an earlier one does not automatically restore your documents.

Intermediate definition

A Home Manager generation selects a built configuration and its package references. A retained generation can support software recovery, while mutable settings, native packages and boot files need separate consideration.

Expert definition

Generation identity alone is insufficient to establish a Tamlinux candidate. The recorded assembly, component revisions, retained outputs and matching generation tie software return to known selection; mutable and native recovery stay explicit.
