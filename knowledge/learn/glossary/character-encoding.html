Character encoding

A rule that maps characters to numbers.

Novice definition

A character encoding is the code that tells a computer which number stands for which letter or symbol.

Learner definition

Character encoding maps text characters to code points and then to stored bytes, so the same bytes can mean different text under different encodings.

Expert definition

A character encoding is a mapping between an abstract character repertoire and a sequence of code units, often combined with a transfer encoding such as UTF-8.
