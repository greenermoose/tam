Exit status

A number a program returns to say whether it succeeded.

Novice definition

An exit status is the number a command leaves behind, usually 0 for success and nonzero for failure.

Learner definition

The exit status is an eight-bit wait status value; shells test it with $? and use it to branch.

Expert definition

An exit status is the low eight bits of a process wait status, with 0 conventionally success and nonzero failure, interpreted by wait and shell conditionals.
