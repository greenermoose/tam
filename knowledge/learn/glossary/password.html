Password

A secret word or phrase used to log in.

Novice definition

A password is the secret you type to prove your identity.

Learner definition

A password is a shared secret verified by hashing or a challenge-response protocol.

Expert definition

A password is a knowledge factor processed through a salted password hash such as Argon2, bcrypt, or yescrypt, never stored in clear text.
