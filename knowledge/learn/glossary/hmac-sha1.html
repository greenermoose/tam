HMAC-SHA1

Keyed-hash message authentication code built on SHA-1.

Novice definition

HMAC-SHA1 is an older integrity-check tag used in legacy SSH and Kerberos connections.

Learner definition

Although HMAC-SHA1 is more resilient than raw SHA-1, modern SSH and TLS prefer HMAC-SHA256 or AEAD ciphers.

Expert definition

RFC 2104 HMAC instantiated with SHA-1 (160-bit output); deprecated in favor of SHA-2 / AEAD.
