Carried patch

A local fix kept until upstream includes it.

Novice definition

A carried patch is a fix Tamlinux applies to a package while waiting for the original project to release it.

Learner definition

A carried patch is published on a public fork, built as a local package, and retired when upstream includes the fix.

Expert definition

A carried patch is a source change with recorded provenance, a public fork branch, a local PKGBUILD, and an automatic retirement condition tied to upstream version.
