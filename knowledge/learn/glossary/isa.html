ISA

The instruction set a processor understands.

Novice definition

The ISA is the vocabulary of instructions a CPU family can run, such as x86 or ARM.

Learner definition

The instruction set architecture defines instructions, registers, addressing, and visible behavior that software can rely on.

Expert definition

An instruction set architecture is the hardware-software contract specifying instructions, registers, memory model, privilege levels, and encodings.
