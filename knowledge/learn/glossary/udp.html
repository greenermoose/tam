UDP - User Datagram Protocol

A simple, connectionless transport protocol.

Novice definition

UDP is a fast, no-frills way to send network messages without guaranteeing delivery.

Learner definition

User Datagram Protocol sends datagrams with ports and checksums but no ordering or retransmission.

Expert definition

UDP is a connectionless datagram transport with a 16-bit length and checksum, used by DNS, QUIC, and real-time traffic.
