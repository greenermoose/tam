Namespace

A kernel feature that gives processes isolated views of the system.

Novice definition

A namespace is a separate view of something like processes, networking, or files, used to isolate programs.

Learner definition

Linux namespaces isolate PID, mount, network, user, IPC, UTS, cgroup, and time resources for containers.

Expert definition

A namespace is a kernel object that virtualizes a global resource identifier space, with per-namespace membership and clone or unshare flags.
