Swap

Disk space used as overflow memory.

Novice definition

Swap is space on disk the system uses when RAM is full, or to move inactive memory out of the way.

Learner definition

Swap stores memory pages on a block device or file so the kernel can reclaim RAM; it is much slower than RAM.

Expert definition

Swap is a backing store for anonymous pages, implemented as a swap file or partition with page-sized slots and reclaim policies.
