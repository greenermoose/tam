libc

The standard C library.

Novice definition

libc is the basic library that gives C programs file, memory, string, and system-call functions.

Learner definition

The C library implements the standard C runtime and often the system-call wrappers used by many languages.

Expert definition

libc is the userspace C runtime providing ISO C functions, POSIX interfaces, startup code, and syscall stubs; glibc and musl are common implementations.
