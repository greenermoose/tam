Nounset

A shell option that rejects undefined variables.

Novice definition

Nounset is a shell setting that makes using an unset variable an error.

Learner definition

set -u enables nounset, causing expansion of an unset variable to fail instead of becoming empty.

Expert definition

nounset is a POSIX shell option that diagnoses unset parameter expansion, except for $@, $*, and ${name:-default} forms.
