Disk thrashing

Excessive paging that leaves little time for real work.

Novice definition

Disk thrashing is when a computer spends so much time swapping memory to disk that it barely gets anything done.

Learner definition

Thrashing occurs when the working set exceeds RAM and the system repeatedly evicts and reloads pages.

Expert definition

Thrashing is a pathological reclaim state with high page-fault and I/O rates, low useful throughput, and often unstable latency.
