Parity

Parity is an error-detection check bit added to data to ensure an even or odd count of 1s.

Novice definition

A simple check bit attached to the end of a group of data bits. In even parity, the extra bit is set so that the total number of 1s in the transmission is always an even number; if a single bit flips during transmission, the receiver notices that the count is odd and flags an error.

Learner definition

A single-bit error-detection scheme calculated by summing data bits modulo 2. While parity catches any odd number of bit errors (such as a single bit flip), any even number of corrupted bits (such as two simultaneous flips) cancels out and escapes undetected.

Expert definition

A linear block code with minimum Hamming distance d_min = 2. Parity bits provide single-error detection with zero correction capability; extending parity across orthogonal dimensions forms product codes and multi-dimensional ECC syndroming matrices.
