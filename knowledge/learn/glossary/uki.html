UKI

A single bootable file containing kernel, initramfs, and command line.

Novice definition

A UKI packs the kernel and its startup files into one signed file the firmware can verify and boot.

Learner definition

A Unified Kernel Image embeds kernel, initramfs, command line, and optionally splash or microcode into one PE executable.

Expert definition

A UKI is a PE/COFF executable with kernel and initramfs sections, an embedded command line, and optional signatures verified by firmware or the bootloader.
