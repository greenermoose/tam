JSON (JavaScript Object Notation)

Lightweight human- and machine-readable data format using key-value objects and arrays.

Novice definition

JSON is a popular, readable text format for storing structured data and settings using curly braces and key-value pairs.

Learner definition

tam's index.json, Waybar/Hyprland IPC output (hyprctl -j), and LUKS2 headers use JSON.

Expert definition

RFC 8259 text serialization format supporting objects, arrays, strings, numbers, booleans, and null.
