RFC 5280 (X.509 PKI Profile)

IETF standard profiling X.509 v3 certificates and revocation lists.

Novice definition

RFC 5280 is the internet rulebook for how digital security certificates are formatted and checked.

Learner definition

It defines X.509 v3 certificate extensions—such as Subject Alternative Name (SAN) for hostnames—and how browsers validate certificate chains.

Expert definition

IETF RFC 5280 (2008) specifies X.509 v3 certificate and v2 CRL syntax in ASN.1 DER, path validation algorithms, key usage constraints, and Name Constraints.
