GNOME

Major open-source Linux desktop environment built on GTK and Mutter.

Novice definition

GNOME is one of the two largest Linux desktop environments, known for its clean, minimalist layout.

Learner definition

GNOME uses the GTK toolkit and Mutter Wayland compositor; many Linux apps follow GNOME HIG conventions.

Expert definition

GNU Network Object Model Environment: GTK/libadwaita desktop stack with Mutter Wayland compositor and D-Bus session services.
