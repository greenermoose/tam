REPL (Read-Eval-Print Loop)

Interactive prompt that reads an expression, evaluates it, prints the result, and repeats.

Novice definition

A REPL is an interactive prompt—like Python or Lua mode—where you type one command, see the answer right away, and type the next.

Learner definition

REPLs run inside a terminal and often use Readline or raw-mode line editing to support history and arrow keys.

Expert definition

Read-Eval-Print Loop: interactive language shell cycling through input parsing, AST/bytecode evaluation, output formatting, and prompt redisplay.
