RIP (Instruction Pointer Register)

64-bit x86_64 CPU register holding the memory address of the next instruction to execute.

Novice definition

RIP is the CPU's bookmark register that tracks which instruction in memory it is about to run next.

Learner definition

PIE executables use RIP-relative addressing ([rip + offset]) to access global data cleanly from any load address.

Expert definition

x86_64 64-bit Instruction Pointer; supports PC-relative memory operands natively in 64-bit mode.
