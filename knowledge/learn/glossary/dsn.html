DSN (Device Serial Number)

Optional PCIe extended capability providing a unique 64-bit hardware identifier.

Novice definition

A DSN is a unique serial number built into a PCIe card or chip.

Learner definition

Linux exposes PCIe DSN capabilities via lspci -vv for hardware inventory and diagnostics.

Expert definition

PCIe Extended Capability ID 0x0003 exposing a 64-bit EUI-64 identifier.
