Firmware

Software stored on a device that controls it at a low level.

Novice definition

Firmware is the built-in software that starts a device and tells its chips how to behave.

Learner definition

Firmware is persistent low-level software stored in flash or ROM, running before the operating system or inside a device.

Expert definition

Firmware is device-resident code and data, often updatable, that initializes hardware and exposes a stable interface to higher layers.
