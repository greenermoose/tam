ELF (Executable and Linkable Format)

Standard binary file format on Linux for executables, shared libraries (.so), object files, and core dumps.

Novice definition

ELF is the standard file format Linux uses for compiled programs and shared libraries.

Learner definition

Object files (.o), executables, and .so libraries are all ELF files; inspect them with readelf, objdump, or file.

Expert definition

System V ABI binary format (header 0x7F 'ELF', program headers for kernel loader, section headers for linkers).
