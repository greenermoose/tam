OCSP (Online Certificate Status Protocol)

Protocol for checking whether an X.509 TLS certificate has been revoked.

Novice definition

OCSP lets your browser ask a certificate authority whether a website's security certificate was canceled early.

Learner definition

OCSP stapling lets the web server attach a fresh signed status proof in the TLS handshake, protecting user privacy.

Expert definition

RFC 6960 request/response protocol returning good/revoked/unknown status; largely superseded by OCSP stapling and CRLite.
