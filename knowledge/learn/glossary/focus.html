Keyboard focus

Beginner definition

The window selected to receive keyboard input.

Intermediate definition

The selected window receives application input; compositor shortcuts may be handled before the application sees them.

Expert definition

A compositor/input-routing state, distinct from visibility, stacking and workspace membership. Verify the target before an action such as closing a window.
