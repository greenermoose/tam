IMC (Integrated Memory Controller)

Circuitry inside a modern CPU that talks directly to DDR4/DDR5 RAM modules.

Novice definition

The IMC is the part of the processor that reads and writes directly to your computer's RAM sticks.

Learner definition

Moving the memory controller from the old motherboard northbridge onto the CPU die dramatically cut RAM latency.

Expert definition

On-die DRAM scheduler and PHY driving DDR4/DDR5 command/address/data buses and ECC scrubbing.
