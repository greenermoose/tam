GPL-3.0 (GNU General Public License v3)

Strong copyleft open-source license ensuring modified versions remain free and open.

Novice definition

GPL-3.0 is the open-source license used by Tamlinux tools: anyone can use, study, and share changes as long as changes stay open under the same license.

Learner definition

Unlike permissive MIT/BSD licenses, GPL-3.0 requires distributed derivatives to provide source code and installation rights.

Expert definition

FSF GNU General Public License version 3 (copyleft, patent grant, anti-tivoization provisions).
