SIMT (Single Instruction, Multiple Threads)

GPU execution model running groups of threads (warps/wavefronts) in lockstep.

Novice definition

SIMT is how GPUs run thousands of tiny shader threads at once by sharing one instruction stream across a group.

Learner definition

Unlike CPU SIMD, each SIMT thread keeps its own registers and program counter, though branch divergence slows the group.

Expert definition

GPU execution model (NVIDIA warps of 32, AMD wavefronts of 32/64) mapping scalar threads onto wide vector ALUs.
