L3 cache (Level 3 / Last-Level Cache)

Large on-die SRAM cache shared across CPU cores to reduce main-RAM accesses.

Novice definition

L3 is a larger shared pool of fast on-chip memory that all CPU cores can read from before going out to RAM.

Learner definition

Part of CPU caches, L3 (often 16-96+ MiB) speeds up inter-core sharing and large working sets.

Expert definition

Shared Last-Level Cache (LLC) sliced across ring/mesh interconnects, tracking coherence directories for multi-core MESI.
