CTAP2 (Client to Authenticator Protocol 2)

FIDO2 protocol for communication between a computer/browser and a hardware security key.

Novice definition

CTAP2 is the language your computer uses to talk to a USB or NFC security key when you log in with a passkey.

Learner definition

Working alongside WebAuthn, CTAP2 supports PIN verification, resident passkeys, and biometric confirmation on FIDO2 tokens.

Expert definition

FIDO Alliance CBOR-encoded protocol over USB HID, NFC, or BLE between a host client and a FIDO2 roaming authenticator.
