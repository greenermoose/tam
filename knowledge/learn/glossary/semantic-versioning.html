Semantic versioning

A version-number convention with meaning.

Novice definition

Semantic versioning is a rule for version numbers where the first number means a breaking change and the last means a small fix.

Learner definition

SemVer uses MAJOR.MINOR.PATCH to signal incompatible, compatible-feature, and bug-fix changes.

Expert definition

Semantic Versioning is a specification with precedence rules, pre-release and build metadata, and compatibility promises for public APIs.
