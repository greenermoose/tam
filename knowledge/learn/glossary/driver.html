Driver

Software that lets the kernel control a device.

Novice definition

A driver is the code that teaches the operating system how to talk to a particular piece of hardware.

Learner definition

A device driver translates kernel interfaces into device-specific commands and handles interrupts and DMA.

Expert definition

A driver is a kernel module or built-in subsystem implementing a device's register interface, interrupt handling, power management, and bus protocol.
