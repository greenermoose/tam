evdev (event device)

evdev (Event Device) is the Linux kernel subsystem and device interface that delivers input events from hardware to applications.

Novice definition

The Linux system that receives button presses, mouse movements, and touches from your hardware and sends them as uniform messages to your desktop.

Learner definition

The Linux generic input event interface exposing character devices at /dev/input/event*. It standardizes diverse hardware protocols into uniform struct input_event streams (keystrokes, relative pointer motions, absolute coordinates) consumed by libraries like libevdev and libinput.

Expert definition

The kernel-level input event subsystem defined in linux/input.h that packages events into type, code, and value tuples with microsecond timestamps. It provides ioctl query mechanisms (EVIOCGBIT, EVIOCGRAB), multi-touch slot tracking, and companion virtual device synthesis via uinput. Read The Linux Input Subsystem and evdev for architecture and examples.
