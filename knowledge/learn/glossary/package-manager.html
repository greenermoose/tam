Package manager

Software that installs, updates, and removes packages.

Novice definition

A package manager is the tool that finds, installs, and upgrades software for you.

Learner definition

A package manager resolves dependencies, downloads packages, verifies signatures, and records installed files.

Expert definition

A package manager is a transaction system over a package database, with dependency solving, provenance, file ownership, and rollback or hooks.
