Rescue environment

A working tool environment for repairing another system.

Novice definition

A rescue environment is a separate working system you can use to inspect or fix a broken installation.

Learner definition

A rescue environment provides a shell, storage tools, and drivers independent of the installed system.

Expert definition

A rescue environment is an independently booted userspace with sufficient drivers and tools to mount, inspect, repair, or reinstall the target system.
