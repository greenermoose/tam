Root user

The all-powerful administrative account.

Novice definition

The root user is the superuser account that can change anything on the system.

Learner definition

Root is UID 0, bypassing most permission checks and owning the system administration role.

Expert definition

Root is the privileged account with UID 0 and full capabilities, subject to kernel protections such as capabilities and lockdown.
