QEMU (Quick Emulator)

Open-source machine emulator and virtualizer paired with KVM on Linux.

Novice definition

QEMU is the standard open-source program for running virtual computers on Linux.

Learner definition

Combined with KVM, QEMU runs x86_64 VMs near native speed; on its own (TCG), it can emulate ARM64 or RISC-V CPUs.

Expert definition

Userspace VMM and dynamic binary translator (TCG) providing virtio devices, snapshots, and KVM acceleration.
