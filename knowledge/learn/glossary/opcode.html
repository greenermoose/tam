Opcode

The part of an instruction that names the operation.

Novice definition

An opcode is the code that tells the CPU which operation to do, such as add or jump.

Learner definition

An opcode selects the instruction's operation; the remaining bits usually encode operands or addressing modes.

Expert definition

An opcode is the primary operation field of an instruction word, decoded by the control unit or microcode.
