RAPL (Running Average Power Limit)

Intel/AMD CPU hardware counters and power-capping interface exposed by Linux powercap.

Novice definition

RAPL is a built-in energy meter inside modern Intel and AMD processors that reports how many watts the CPU is using.

Learner definition

Linux exposes RAPL counters under /sys/class/powercap/intel-rapl/ (readable by root or tam-meter) for energy profiling.

Expert definition

MSR-based energy-counter and PL1/PL2 power-limit architecture exposed via Linux powercap sysfs.
