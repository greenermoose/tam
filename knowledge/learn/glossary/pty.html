PTY (Pseudoterminal)

Kernel pair of virtual character devices connecting a terminal emulator to a shell or program.

Novice definition

A PTY (pseudoterminal) is a software pipe that acts like a real terminal so graphical terminal windows can run shell programs.

Learner definition

A PTY has two ends: the primary (master) held by the terminal emulator or SSH, and the secondary (slave, /dev/pts/N) used by the shell.

Expert definition

Unix98 pseudoterminal pair (/dev/ptmx primary, /dev/pts/N secondary) managed by the kernel TTY line discipline, forwarding bytes, window-size ioctls (TIOCSWINSZ), and job-control signals.
