Target

A systemd unit that groups other units into a state.

Novice definition

A target is a systemd grouping that brings the system to a particular state, such as graphical login.

Learner definition

A systemd target is a synchronization point that pulls in other units, replacing traditional runlevels.

Expert definition

A target is a passive systemd unit used for ordering and grouping, with wants and requires dependencies rather than its own process.
