DWARF (Debugging With Attributed Record Formats)

Standard debugging-information format embedded in ELF binaries mapping machine code to source lines.

Novice definition

DWARF is the extra map inside debug builds that lets crash reports and debuggers show exact C file names and line numbers.

Learner definition

Compiling with -g embeds DWARF sections (.debug_info, .debug_line) inside ELF binaries for GDB and AddressSanitizer stack traces.

Expert definition

ELF debugging standard (DWARF v4/v5) encoding type trees, variable locations, and CFI unwind tables.
