ARX (Add-Rotate-XOR)

Cipher design paradigm using only modular addition, bit rotation, and XOR.

Novice definition

ARX is a simple, fast way to build encryption algorithms (like ChaCha20) using basic math operations that CPUs do in constant time.

Learner definition

ARX ciphers avoid lookup tables, making them naturally resistant to cache-timing side-channel attacks in software.

Expert definition

Add-Rotate-XOR construction (used in ChaCha20, BLAKE2/3, SipHash) relying on non-linear carry propagation in modular addition.
