NAND (NOT-AND)

The flash memory technology used in SSDs and memory cards.

Novice definition

NAND is the type of flash chip that stores data in SSDs, USB drives, and phones.

Learner definition

NAND flash stores charge in cells and is written in pages but erased in larger blocks.

Expert definition

NAND flash is a floating-gate or charge-trap non-volatile memory organized in blocks and pages, with endurance limits and bad-block management.
