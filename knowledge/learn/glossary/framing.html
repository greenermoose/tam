Framing

Wrapping data in a structure with boundaries.

Novice definition

Framing is how network data is packaged with a start and end so the receiver knows where one message stops.

Learner definition

Framing delimits units at a protocol layer, using length fields, flags, or timing.

Expert definition

Framing is the encapsulation and boundary mechanism of a protocol data unit, including headers, trailers, escaping, and error detection.
