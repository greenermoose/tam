WOTS (Winternitz One-Time Signature)

Hash-chain one-time signature used as a leaf primitive in XMSS, LMS, and SLH-DSA.

Novice definition

WOTS is a simple quantum-safe signature method built solely from hash chains that can only sign one message per key.

Learner definition

Stateful hash signatures (XMSS, LMS) and stateless SLH-DSA stack Merkle trees on top of WOTS+ one-time keys.

Expert definition

Hash-based one-time signature trading chain length (Winternitz parameter w) against signature size via iterative hashing.
