CPU caches (L1, L2, L3)

Multi-level on-chip SRAM hierarchy (L1, L2, L3) bridging fast cores and slower RAM.

Novice definition

Modern processors keep three tiny, super-fast memory layers (L1, L2, and L3) right on the chip so they do not wait on main RAM.

Learner definition

Each level trades size for speed: L1 is fastest and smallest per core; L2 is mid-sized; L3 is largest and shared across cores.

Expert definition

Inclusive/non-inclusive SRAM hierarchy with 64-byte cache lines and MESI coherence across L1, L2, and L3.
