HTTP - Hypertext Transfer Protocol

The protocol behind web pages.

Novice definition

HTTP is the language a browser and web server use to request and send pages.

Learner definition

Hypertext Transfer Protocol is a request-response application protocol with methods, headers, status codes, and bodies.

Expert definition

HTTP is a stateless application protocol, now typically HTTP/2 or HTTP/3, with semantics defined separately from its wire framing.
