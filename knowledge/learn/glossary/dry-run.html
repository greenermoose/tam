Dry run

A rehearsal that reports what would happen without changing anything.

Novice definition

A dry run shows what a command would do without actually doing it.

Learner definition

A dry run executes planning and validation but suppresses destructive or persistent effects.

Expert definition

A dry run is a mode that performs resolution and reports intended transactions while withholding commits or writes.
