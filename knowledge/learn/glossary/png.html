PNG

A common lossless image file format.

Novice definition

PNG is a picture file format that keeps every pixel exactly, often used for screenshots and logos.

Learner definition

Portable Network Graphics is a lossless raster format with alpha transparency and DEFLATE compression.

Expert definition

PNG is a chunked, CRC-protected raster format with IHDR, IDAT, and IEND chunks, filtering, and DEFLATE compression, supporting alpha and color types.
