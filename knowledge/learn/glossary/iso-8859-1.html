ISO 8859-1 (Latin-1)

8-bit single-byte character encoding for Western European languages.

Novice definition

ISO 8859-1 is an older 8-bit text encoding that fits 256 characters into one byte each, before UTF-8 became standard.

Learner definition

Latin-1 extends ASCII into bytes 0xA0-0xFF for Western European letters and leaves 0x80-0x9F reserved for C1 control codes.

Expert definition

ISO/IEC 8859-1:1998 maps 0x00-0x7F to ASCII and 0xA0-0xFF to Latin-1 characters (the first 256 Unicode code points). Its 0x80-0x9F C1 range conflicts with UTF-8 continuation bytes, so UTF-8 terminals reject bare 0x9B CSI.
