CR (Carriage Return, 0x0D)

ASCII 0x0D control character (Ctrl+M, '\r') returning the cursor to column 1.

Novice definition

CR is the Carriage Return byte (0x0D) sent when you press Enter, moving the cursor back to the start of the line.

Learner definition

Part of the C0 control codes, CR (0x0D) is identical to Ctrl+M in legacy encoding and is usually translated to LF by ICRNL.

Expert definition

ASCII 0x0D (CR, '\r', Ctrl+M). Moves cursor to column 1 of the current row; Enter emits 0x0D, which termios ICRNL converts to 0x0A in cooked mode.
