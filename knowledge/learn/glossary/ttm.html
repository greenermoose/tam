TTM (Translation Table Manager)

Linux kernel DRM memory manager for discrete-GPU VRAM and system-RAM buffer placement.

Novice definition

TTM is the Linux kernel component that decides which graphics buffers live in fast GPU video RAM versus system RAM.

Learner definition

Drivers like amdgpu and nouveau use TTM to migrate buffers across PCIe as GPU memory fills.

Expert definition

Kernel DRM buffer-object memory manager (drivers/gpu/drm/ttm/) handling VRAM/GTT placement, eviction, and fences.
