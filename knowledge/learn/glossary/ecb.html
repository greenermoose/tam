ECB (Electronic Codebook)

Simplest block-cipher mode encrypting each block independently, leaking data patterns.

Novice definition

ECB is a basic encryption mode that turns identical input blocks into identical output, which leaks patterns and should not be used for data.

Learner definition

Because ECB has no randomness or chaining, encrypting an image in ECB leaves its silhouette visible.

Expert definition

Deterministic block mode C_i = E_K(P_i); fails IND-CPA security for any message longer than one block.
