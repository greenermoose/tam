FIDL (Fuchsia Interface Definition Language)

Strongly typed IPC schema language used by the Fuchsia Zircon microkernel.

Novice definition

FIDL is the message-format language used by the Fuchsia microkernel so isolated system services can talk safely.

Learner definition

Microkernels rely on formal IPC schemas like FIDL to pass structured messages and capability handles between processes.

Expert definition

Fuchsia binary wire format and IDL compiling channel/handle IPC bindings for C++, Rust, and Go.
