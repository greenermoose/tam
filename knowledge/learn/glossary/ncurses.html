ncurses

A library for building terminal user interfaces.

Novice definition

ncurses is the toolkit that lets programs draw menus and windows in a text terminal.

Learner definition

ncurses provides terminal-independent screen drawing, input handling, and color using terminfo.

Expert definition

ncurses is a curses implementation with windows, pads, panels, mouse support, and terminfo-driven capability abstraction.
