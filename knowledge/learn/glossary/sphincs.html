SPHINCS+ (SLH-DSA)

Stateless hash-based post-quantum signature standardized as NIST FIPS 205 (SLH-DSA).

Novice definition

SPHINCS+ is a quantum-safe signature scheme that relies only on hash functions and needs no state tracking.

Learner definition

Standardized by NIST as SLH-DSA (FIPS 205), SPHINCS+ combines WOTS+ hypertrees with FORS.

Expert definition

NIST FIPS 205 stateless hash-based signature; larger signatures and slower signing than ML-DSA, but minimal security assumptions.
