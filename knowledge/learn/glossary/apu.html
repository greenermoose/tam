APU (Accelerated Processing Unit)

Processor package combining CPU cores and an integrated GPU on the same die or package.

Novice definition

An APU is a chip (like many AMD laptop processors) that combines both the main CPU and the graphics chip together.

Learner definition

Because CPU and GPU share system RAM in an APU, power and memory bandwidth are tightly coupled.

Expert definition

AMD term for heterogeneous CPU+iGPU processor sharing unified system memory and coherent Infinity Fabric.
