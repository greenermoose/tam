Unicode

A standard that assigns a number to every written character.

Novice definition

Unicode is the master list of characters used by modern computers, covering languages and symbols from around the world.

Learner definition

Unicode assigns each character a code point, such as U+0041 for A, and leaves the byte encoding to formats such as UTF-8.

Expert definition

Unicode is a coded character set and standard maintained by the Unicode Consortium; code points range from U+0000 to U+10FFFF.
