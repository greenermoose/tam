OSC (Operating System Command)

ESC ] sequence used for window titles, clipboard access, hyperlinks, and palette queries.

Novice definition

OSC is a terminal command starting with Escape and ] that changes things outside the text grid, like the window title or clipboard.

Learner definition

OSC sequences carry a numeric code and payload terminated by BEL (0x07) or ST (ESC \); for example, OSC 52 interacts with the clipboard.

Expert definition

ECMA-48 Operating System Command (7-bit ESC ] / 0x1B 0x5D, 8-bit 0x9D) terminated by String Terminator (ESC \) or BEL. Untrusted OSC output poses security risks if unrestricted.
