RPM (RPM Package Manager)

Binary package format (.rpm) and tool used by Fedora, RHEL, and openSUSE.

Novice definition

RPM is the software package format used by Fedora, Red Hat, and openSUSE Linux.

Learner definition

Tamlinux uses Arch's pacman (.pkg.tar.zst) and never installs .rpm files directly.

Expert definition

Cpio-backed package format with spec-file builds, consumed by dnf/zypper; distinct from Arch pacman and Debian .deb.
