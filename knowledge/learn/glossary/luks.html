LUKS - Linux Unified Key Setup

The standard Linux disk-encryption format.

Novice definition

LUKS is the usual way Linux encrypts a whole disk or partition.

Learner definition

Linux Unified Key Setup stores encryption metadata and multiple key slots in a header, unlocked by passphrases or keys.

Expert definition

LUKS is a disk-format specification with a header, key slots, PBKDF, and dm-crypt mapping; LUKS2 adds JSON metadata and Argon2.
