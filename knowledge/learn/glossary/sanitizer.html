Sanitizer

A compiler instrumentation tool that detects runtime defects, memory errors, and undefined behavior.

Novice definition

A sanitizer is an automatic inspector added to a program while it is being built, checking for hidden bugs and invalid actions as the program runs.

Learner definition

A sanitizer adds lightweight diagnostic code into compiled binaries to trap memory corruptions, race conditions, or undefined operations (such as integer overflows or invalid pointer arithmetic) at the exact moment they occur.

Expert definition

A compiler sanitizer (such as ASan, UBSan, TSan, or MSan) performs compile-time code instrumentation paired with a dedicated runtime library to detect specification violations, concurrency bugs, and undefined behavior with minimal execution slowdown compared to traditional binary translation.
