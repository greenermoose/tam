AMD-V (AMD Virtualization)

Hardware virtualization extensions (SVM) in AMD x86_64 processors.

Novice definition

AMD-V is a built-in feature on AMD processors that lets virtual machines run at near-native speed.

Learner definition

Known as SVM in Linux /proc/cpuinfo, AMD-V provides hardware-assisted guest isolation for KVM and QEMU.

Expert definition

AMD64 Secure Virtual Machine (SVM) ISA extension (VMRUN, nested page tables / RVI) used by KVM.
