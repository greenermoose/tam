ACPI - Advanced Configuration and Power Interface

A standard for power and hardware configuration.

Novice definition

ACPI is the firmware standard that tells the operating system how to manage power, sleep, and hardware details.

Learner definition

Advanced Configuration and Power Interface provides tables and control methods for power states, devices, and events.

Expert definition

ACPI is a platform interface with firmware tables, AML bytecode, and fixed or general-purpose events for power and configuration management.
