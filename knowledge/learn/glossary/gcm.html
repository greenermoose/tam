GCM (Galois/Counter Mode)

Widely used AEAD cipher mode combining CTR encryption with GHASH authentication.

Novice definition

GCM is a fast encryption mode that both hides your data and proves it has not been tampered with.

Learner definition

AES-GCM pairs CTR mode encryption with GF(2^128) polynomial authentication (GHASH) in a single pass.

Expert definition

NIST SP 800-38D AEAD mode combining AES-CTR with universal hashing (GHASH) over GF(2^128); requires strict nonce uniqueness.
