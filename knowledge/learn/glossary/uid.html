UID

The number that identifies a user.

Novice definition

A UID is the number the system uses internally to identify your user account.

Learner definition

A user ID is a numeric identity used in credentials and file ownership; UID 0 is root.

Expert definition

A UID is a kernel credential field in the user namespace, mapped to a host ID and used for ownership and permission checks.
