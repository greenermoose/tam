C89 (ANSI C)

First standardized version of C, published by ANSI in 1989.

Novice definition

C89 was the first official standard for the C programming language, published in 1989.

Learner definition

Part of the C standards family, C89 introduced function prototypes, void pointers, and standard headers.

Expert definition

ANSI X3.159-1989, ratified essentially unchanged by ISO as C90 (ISO/IEC 9899:1990).
