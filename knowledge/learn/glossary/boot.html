Boot

The process of starting a computer.

Novice definition

To boot is to start a computer and bring its operating system into working order.

Learner definition

Booting runs firmware, loads a bootloader and kernel, mounts the root filesystem, and starts user space.

Expert definition

Boot is the staged transition from firmware initialization through kernel decompression, device probing, initramfs handoff, and init execution.
