GNU - GNU's Not Unix

A free-software project and operating-system effort.

Novice definition

GNU is the project that created many of the standard tools Linux uses, such as bash and the C library.

Learner definition

GNU is a free-software project founded by Richard Stallman, providing tools, libraries, and the GPL.

Expert definition

GNU is the recursive acronym for GNU's Not Unix, a project producing a Unix-compatible free software system whose tools combine with the Linux kernel.
