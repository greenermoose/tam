Profile

A named set of installed software and links.

Novice definition

A profile is a named collection of programs and settings that the system can switch between.

Learner definition

A Nix or Home Manager profile is a generation of links to store paths, with a current symlink and previous generations retained.

Expert definition

A profile is a mutable symlink to a generation of immutable store paths, managed by nix-env or Home Manager and switched atomically.
