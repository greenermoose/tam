KDC (Key Distribution Center)

Trusted authentication server (as in Kerberos) that issues session keys and tickets.

Novice definition

A KDC is a central login server that hands out temporary digital tickets so users and services trust each other.

Learner definition

In Kerberos, the KDC combines the Authentication Server (issuing TGTs) and Ticket Granting Server.

Expert definition

Trusted third party in symmetric-key authentication (Kerberos, RFC 4120) holding long-term keys to broker session keys.
