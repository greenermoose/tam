TLB - Translation Lookaside Buffer

A cache of address translations.

Novice definition

The TLB is a small, fast table that remembers recent virtual-to-physical address translations.

Learner definition

The translation lookaside buffer caches page-table entries so the MMU does not walk memory for every access.

Expert definition

A TLB is an associative cache of virtual-to-physical mappings and permission bits, with invalidation on context or page-table changes.
