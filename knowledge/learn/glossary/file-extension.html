File extension

The suffix that hints at a file's format.

Novice definition

A file extension is the letters after the dot in a name, like .txt, that suggest what kind of file it is.

Learner definition

An extension is a naming convention, not proof of format; programs use it to choose default handlers.

Expert definition

A file extension is a suffix metadata convention interpreted by desktop environments and applications, not by the filesystem itself.
