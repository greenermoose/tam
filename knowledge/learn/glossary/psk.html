PSK (Pre-Shared Key)

Secret key shared out-of-band before communication, used in Wi-Fi WPA2/3 and TLS 1.3 resumption.

Novice definition

A pre-shared key (PSK) is a secret password or key known by both sides ahead of time, like a Wi-Fi password.

Learner definition

TLS 1.3 uses PSKs for session resumption, and WPA2-PSK derives Wi-Fi keys from the network passphrase.

Expert definition

Symmetric secret established prior to protocol run; in TLS 1.3 (RFC 8446) PSK-ECDHE preserves forward secrecy.
