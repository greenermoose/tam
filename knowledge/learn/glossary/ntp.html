NTP (Network Time Protocol)

Protocol for synchronizing system clocks over a network, critical for TLS, Kerberos, and logs.

Novice definition

NTP keeps your computer's clock accurate over the internet so security certificates and log timestamps stay valid.

Learner definition

Kerberos tickets, X.509 certificate expiration, and RPKI/DNSSEC signatures all fail if the system clock drifts; NTS adds TLS authentication to NTP.

Expert definition

RFC 5905 UDP port 123 hierarchical stratum clock-synchronization protocol (with RFC 8915 NTS authentication).
