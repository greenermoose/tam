UPI (Ultra Path Interconnect)

Intel multi-socket cache-coherent processor interconnect replacing QPI.

Novice definition

UPI is the high-speed bridge connecting two physical Intel server CPUs on the same motherboard so they share memory.

Learner definition

Analogous to AMD Infinity Fabric across sockets, UPI carries cache-coherence traffic in multi-CPU servers.

Expert definition

Intel point-to-point coherent link (10.4-20+ GT/s) linking multi-socket Xeon dies.
