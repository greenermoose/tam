Theme

A coordinated set of appearance settings.

Novice definition

A theme is a set of colors, fonts, and shapes that changes how the desktop looks.

Learner definition

A theme packages visual tokens and assets for widgets, windows, icons, and terminals.

Expert definition

A theme is a token set and asset bundle consumed by toolkits and compositors, with variants, inheritance, and contrast requirements.
