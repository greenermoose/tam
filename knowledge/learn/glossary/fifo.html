FIFO - First-In, First-Out

A first-in, first-out queue.

Novice definition

A FIFO is a line where the first item to arrive is the first one served.

Learner definition

First-in, first-out buffering preserves order between a producer and consumer that run at different rates.

Expert definition

A FIFO is an ordered queue or hardware buffer with head and tail pointers, used for elastic buffering and flow control.
