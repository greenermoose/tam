Side-channel attack

Learning secrets from timing, power, sound, or cache behavior instead of breaking math directly.

Novice definition

Instead of picking a combination lock, an eavesdropper listens to how long each dial click takes to guess the numbers.

Learner definition

If a password check or cryptographic routine runs faster on a partial match, an attacker measuring response times can deduce secrets byte by byte—which is why security code uses constant-time comparisons.

Expert definition

Information leakage through physical or microarchitectural observables (execution time, CPU cache lines, speculative execution as in Spectre/Meltdown, EM emanations, or differential power analysis) outside the abstract mathematical model.
