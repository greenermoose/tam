PEM (Privacy-Enhanced Mail format)

Base64 text encoding with -----BEGIN ...----- headers for certificates and cryptographic keys.

Novice definition

PEM is the common text format for security certificates and keys, recognizable by its '-----BEGIN CERTIFICATE-----' lines.

Learner definition

PEM wraps binary DER/ASN.1 data in Base64 with ASCII armor so keys can be stored in plain text files.

Expert definition

RFC 7468 textual encoding of Base64-wrapped ASN.1 DER objects (X.509 certificates, PKCS#8 private keys, CSRs).
