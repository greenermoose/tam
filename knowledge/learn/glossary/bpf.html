BPF / eBPF (Berkeley Packet Filter)

In-kernel sandboxed bytecode VM for safe packet filtering, tracing, and security enforcement.

Novice definition

eBPF lets Linux run tiny, verified helper programs safely inside the kernel for networking, firewalls, and performance tracing.

Learner definition

Tools like tcpdump, nftables/XDP, and systemd sandboxing (RestrictAddressFamilies) rely on classic BPF or extended eBPF.

Expert definition

In-kernel register-based VM verified statically by the kernel verifier for bounded loops and memory safety before JIT compilation.
