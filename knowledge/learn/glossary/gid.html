GID - Group Identifier

The number that identifies a group.

Novice definition

A GID is the number the system uses internally to identify a group of users.

Learner definition

A group ID is a numeric identity used for group ownership and supplementary group membership.

Expert definition

A GID is a credential field in the user namespace, with primary and supplementary groups affecting access checks.
