BKZ (Block Korkine-Zolotarev)

Lattice basis-reduction algorithm used to estimate the security of post-quantum lattice cryptography.

Novice definition

BKZ is an algorithm researchers use to test how hard it is to break lattice-based post-quantum encryption.

Learner definition

Stronger than LLL, BKZ reduces blocks of lattice vectors of size beta to search for short vectors.

Expert definition

Schnorr-Euchner blockwise lattice reduction algorithm; the core cryptanalytic benchmark for sizing ML-KEM and ML-DSA parameters.
