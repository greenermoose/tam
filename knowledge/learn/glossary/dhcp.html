DHCP - Dynamic Host Configuration Protocol

The protocol that hands out network settings automatically.

Novice definition

DHCP is how a computer gets an IP address and other settings when it joins a network.

Learner definition

Dynamic Host Configuration Protocol leases addresses and supplies gateway, DNS, and other options.

Expert definition

DHCP is a BOOTP-derived client-server protocol with discover, offer, request, and acknowledge messages, leases, and relay agents.
