Motherboard

The main circuit board that connects computer components.

Novice definition

The motherboard is the large board that holds the CPU, memory slots, and connectors for other parts.

Learner definition

The motherboard carries sockets, memory slots, chipset links, firmware, and expansion connectors.

Expert definition

A motherboard is a printed circuit board integrating CPU socket, memory channels, chipset, firmware ROM, power delivery, and I/O connectors.
