CLI

A text-based command interface.

Novice definition

A CLI is the way to control a computer by typing commands in a terminal.

Learner definition

A command-line interface reads commands, arguments, and options from a shell or program prompt.

Expert definition

A CLI is a text-oriented interface with a parser, standard streams, exit status, and often readline editing and completion.
