LUKS2 (Linux Unified Key Setup version 2)

Modern Linux disk-encryption header format supporting Argon2id, integrity tags, and TPM2.

Novice definition

LUKS2 is the current Linux standard for full-disk encryption, protecting your files with a passphrase or hardware key.

Learner definition

Compared to LUKS1, LUKS2 adds JSON metadata, redundant headers, Argon2id key derivation, and hardware token slots (TPM2/FIDO2).

Expert definition

cryptsetup/dm-crypt format v2: dual 16 KiB binary+JSON headers, up to 32 keyslots, Argon2id KDF, and optional dm-integrity AEAD.
