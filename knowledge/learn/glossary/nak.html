NAK (Negative Acknowledge, 0x15)

ASCII 0x15 control character (Ctrl+U) indicating a transmission error or line kill.

Novice definition

NAK is a signal meaning 'that message had an error, send it again'; in shells, Ctrl+U erases the current line.

Learner definition

Part of the C0 control codes, NAK (0x15) is used for error retransmission in serial protocols and VKILL in termios.

Expert definition

ASCII 0x15 (NAK, Ctrl+U). Signals corrupt frame in XMODEM/ARQ protocols; default VKILL character in Linux termios.
