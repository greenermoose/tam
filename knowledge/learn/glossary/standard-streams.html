Standard streams

The three default input and output channels of a program.

Novice definition

The standard streams are the normal places a program reads input, writes output, and reports errors.

Learner definition

Standard input, output, and error are file descriptors 0, 1, and 2, often attached to a terminal or redirected.

Expert definition

The standard streams are the conventional file descriptors 0, 1, and 2 for stdin, stdout, and stderr, inherited across exec and redirected by the shell.
