Deploy

Deploy means delivering a recorded Tamlinux software assembly onto a machine through the packaging tools, not by copying a checkout by hand.

Novice definition

On Tamlinux, software reaches the session through a recorded assembly using tools such as tam-deploy. That keeps versions traceable. Copying files from a development checkout into the live system is not the supported delivery path.

Learner definition

Deployment switches Home Manager generations tied to a locked package assembly. Stage moves (Test, Run, Release) follow the developer's word and recorded digests. Diagnosis of wrong binaries starts with path resolution and assembly status, not with rebuilding from memory.

Expert definition

The Tamlinux delivery action that activates a recorded package assembly into the user environment via the deploy tooling.
