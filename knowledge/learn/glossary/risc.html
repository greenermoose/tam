RISC

A processor design style with simple, regular instructions.

Novice definition

RISC is a design where the CPU uses a small set of simple instructions that run quickly.

Learner definition

Reduced instruction set computing favors fixed-length encodings, load-store memory access, and many registers.

Expert definition

RISC is an ISA philosophy optimizing simple decoded instructions, pipelining, and compiler-generated sequences rather than complex microcoded operations.
