Keycode

A keycode is a number that identifies a key to software, after the keyboard's own scancode has been translated.

Novice definition

A keycode is the computer's number for a key. It is not the character the key types. Software uses the number plus the modifier keys to decide what the key means.

Learner definition

The name is used for two different numbering schemes. The Linux kernel calls KEY_A keycode 30 and KEY_H keycode 35; this is the number in an input_event from evdev. XKB, X11 and Wayland use the same event number plus 8, so the same keys are keycode 38 and 43. A terminal receives the second kind. Always say which numbering you mean.

Expert definition

The kernel keycode space is defined by linux/input-event-codes.h; KEY_A is 30 and the maximum is above 255. X11 and Wayland keycodes are offset by 8 to preserve the historical X11 range, so wl_keyboard.key is the evdev code plus 8. XKB maps that number through the active keymap to a keysym. Remapping can happen at any level: setkeycodes changes kernel keycodes, udev hardware databases and XKB options change the layout, and a compositor can rewrite events before a client sees them.
