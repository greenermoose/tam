Variable

A named place that holds a value.

Novice definition

A variable is a name that stores a value your program or shell can use later.

Learner definition

A variable binds a name to a value in a scope; shells store strings, while compiled languages have typed storage.

Expert definition

A variable is a named storage location with a type, lifetime, and scope, or in shell a name expanded to a string.
