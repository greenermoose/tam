HMAC-SHA256

Keyed-hash message authentication code using SHA-256.

Novice definition

HMAC-SHA256 combines a secret key with SHA-256 to prove a message came from someone who knows the key.

Learner definition

Widely used in SSH, TLS, JWT (HS256), and HKDF, HMAC-SHA256 provides 256-bit authentication security.

Expert definition

RFC 2104 / RFC 4868 keyed hash H((K' XOR opad) || H((K' XOR ipad) || m)) with SHA-256.
