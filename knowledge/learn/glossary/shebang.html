Shebang

The first line of a script that names its interpreter.

Novice definition

A shebang is the #! line at the top of a script that tells the system which program should run it.

Learner definition

The shebang is a kernel-recognized prefix that selects an interpreter and optional argument when executing a file.

Expert definition

A shebang is the two-byte magic 0x23 0x21 followed by an interpreter path, parsed by execve for script execution.
