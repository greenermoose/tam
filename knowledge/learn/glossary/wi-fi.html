Wi-Fi

The common wireless local-network technology.

Novice definition

Wi-Fi is the radio technology that connects devices to a network without cables.

Learner definition

Wi-Fi is the IEEE 802.11 family, using radio channels, association, authentication, and encryption.

Expert definition

Wi-Fi is a set of 802.11 PHY and MAC standards with OFDM, MIMO, channel access, roaming, and WPA security.
