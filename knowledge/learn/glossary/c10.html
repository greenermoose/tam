C10 (Deepest CPU Package C-state)

Deepest idle power-saving state on modern Intel CPUs, cutting core and ring voltages.

Novice definition

C10 is the deepest sleep state a laptop processor enters between keystrokes to save battery.

Learner definition

Tools like powertop check whether a laptop reaches PC10 (Package C10); noisy interrupts or ASPM issues can block it.

Expert definition

Intel Package C-state PC10 (S0ix prerequisite) gating core, LLC, and ring clocks/power rails when all cores reside in CC6/CC7+.
