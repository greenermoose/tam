Alt Mode

A USB-C mode that carries another protocol.

Novice definition

Alt Mode lets a USB-C port carry video or other signals instead of just USB data.

Learner definition

USB-C Alternate Mode reconfigures high-speed lanes for DisplayPort, Thunderbolt, HDMI, or other protocols.

Expert definition

Alt Mode is a USB Type-C configuration negotiated through PD structured vendor-defined messages, remapping SBU and high-speed lanes.
