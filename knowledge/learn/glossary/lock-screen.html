Lock screen

A screen that blocks access until you authenticate.

Novice definition

The lock screen hides your desktop and asks for your password or key before letting you back in.

Learner definition

A lock screen locks the session and mediates authentication before revealing the desktop.

Expert definition

A lock screen is a session-lock client using PAM, compositor locking protocols, and secure input grab to prevent access and injection.
