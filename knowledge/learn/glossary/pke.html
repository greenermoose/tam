PKE (Public-Key Encryption)

Asymmetric encryption where a public key encrypts messages and only the matching private key decrypts.

Novice definition

Public-key encryption lets anyone lock a message with your public key so only your private key can open it.

Learner definition

In practice, PKE or KEMs encrypt a short symmetric session key rather than bulk data (hybrid encryption).

Expert definition

Asymmetric triple (KeyGen, Enc, Dec); modern post-quantum protocols replace direct PKE with IND-CCA2 KEMs.
