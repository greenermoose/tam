GDB (GNU Debugger)

Standard command-line debugger for inspecting C/C++ crashes, breakpoints, and core dumps.

Novice definition

GDB is a tool for stepping through a running program line by line or inspecting why it crashed.

Learner definition

Using DWARF debug info, gdb prints backtraces (bt) from core dumps or live processes.

Expert definition

GNU Project source-level debugger using ptrace(2) and DWARF symbols to inspect registers, memory, and threads.
