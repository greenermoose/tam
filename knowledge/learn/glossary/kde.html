KDE (K Desktop Environment / Plasma)

Major open-source Linux community and Plasma desktop environment built on Qt.

Novice definition

KDE is a major open-source Linux community best known for the customizable Plasma desktop and Qt apps.

Learner definition

Built on Qt and KWin, KDE Frameworks also provide libraries used across Linux desktops.

Expert definition

KDE e.V. ecosystem producing Plasma Desktop, KWin Wayland compositor, and Qt-based KDE Frameworks.
