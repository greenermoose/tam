BMI2 (Bit Manipulation Instruction Set 2)

x86_64 bit-level instructions (PDEP, PEXT, MULX) part of the x86-64-v3 feature level.

Novice definition

BMI2 adds fast CPU instructions for extracting and rearranging individual bits inside numbers.

Learner definition

Used by compilers when targeting -march=native or x86-64-v3 on Haswell+ Intel and Zen+ AMD CPUs.

Expert definition

x86_64 ISA extension introducing PEXT, PDEP, BZHI, MULX, and RORX for single-cycle bitfield manipulation.
