Cache line

The fixed-size block moved into a cache.

Novice definition

A cache line is the chunk of memory, usually 64 bytes, that a cache loads at one time.

Learner definition

A cache line is the unit of transfer and coherence between memory and cache; accessing one byte fetches the whole line.

Expert definition

A cache line is the aligned block size used by a cache, commonly 64 bytes on x86, with tag, state, and valid bits.
