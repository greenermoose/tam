Guide / Learning Tamlinux / Glossary / Dependency

Dependency

Something a program needs in order to run or build.

Novice definition

A dependency is another piece of software that a program needs to work.

Learner definition

A dependency is a package or library required at build or runtime, often version-constrained.

Expert definition

A dependency is a declared edge in a package or build graph, with version ranges, optional features, and resolution semantics.
