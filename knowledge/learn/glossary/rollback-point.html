Rollback point

A known-good state you can return to.

Novice definition

A rollback point is the saved state you go back to if a change goes wrong.

Learner definition

A rollback point records the previous Home Manager generation and, for privileged steps, a Snapper snapshot.

Expert definition

A rollback point is a recorded recovery boundary pairing a Home Manager generation with a Snapper snapshot when boot, login, disk, firmware, or package removal is involved.
