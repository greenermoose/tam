SOH (Start of Heading, 0x01)

ASCII 0x01 control character (Ctrl+A).

Novice definition

SOH is an old teletype control code (byte 0x01) that marked the start of a message header; today Ctrl+A sends this byte.

Learner definition

Part of the C0 control codes, SOH (Ctrl+A) moves to the start of the line in Readline and serves as the screen prefix key.

Expert definition

ASCII 0x01 (SOH). Originally framed packet headers in serial protocols (such as XMODEM); in interactive shells it is bound by Readline to beginning-of-line.
