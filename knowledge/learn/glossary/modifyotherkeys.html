modifyOtherKeys

xterm extension that encodes modified keys as CSI 27 ; modifier ; code ~.

Novice definition

modifyOtherKeys is a terminal setting that lets programs tell apart key combos like Ctrl+I and Tab.

Learner definition

In legacy terminals, Ctrl+I and Tab send the same 0x09 byte; modifyOtherKeys reports modified chords unambiguously as CSI 27 ; mod ; code ~.

Expert definition

xterm CSI > 4 ; level m protocol (levels 1 and 2) encoding modified keys that lack distinct ASCII/CSI forms as ESC [ 27 ; modifier ; keycode ~.
