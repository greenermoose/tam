Forward secrecy

A property ensuring that stealing a long-term key later cannot decrypt past recorded traffic.

Novice definition

Forward secrecy means every connection creates a temporary throwaway key and erases it afterwards, so stolen server keys cannot unlock yesterday's conversations.

Learner definition

Protocols like TLS 1.3 and SSH achieve forward secrecy by running an ephemeral Diffie-Hellman key exchange for each session rather than encrypting with a static key.

Expert definition

Protocol security property where compromise of long-term authentication keys does not compromise session keys derived from earlier ephemeral key-exchange transcripts.
