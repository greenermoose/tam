MESI (Modified, Exclusive, Shared, Invalid)

Classic 4-state cache-coherence protocol keeping multi-core CPU caches consistent.

Novice definition

MESI is the traffic-rule system that keeps multiple CPU cores from reading stale copies of the same memory.

Learner definition

Each 64-byte cache line is tagged Modified, Exclusive, Shared, or Invalid so writes by one core invalidate copies in others.

Expert definition

Snooping/directory cache-coherence protocol (with MOESI/MESIF variants) ensuring single-writer/multiple-reader memory consistency.
