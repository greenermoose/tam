ROBOT (Return Of Bleichenbacher's Oracle Threat)

Padding-oracle attack against RSA PKCS#1 v1.5 encryption in TLS.

Novice definition

ROBOT is a flaw in old RSA key-transport encryption that lets attackers slowly decrypt TLS traffic if a server leaks padding errors.

Learner definition

TLS 1.3 completely removes static RSA key transport in favor of ephemeral Diffie-Hellman (ECDHE) with forward secrecy.

Expert definition

Adaptive chosen-ciphertext attack on PKCS#1 v1.5 RSA key transport; eliminated by TLS 1.3's removal of RSA key exchange.
