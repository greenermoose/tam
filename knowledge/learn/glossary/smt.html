SMT (Simultaneous Multithreading)

Hardware feature allowing one physical CPU core to run two instruction threads concurrently.

Novice definition

SMT (often called Hyper-Threading) lets each physical CPU core act like two virtual CPUs to keep idle units busy.

Learner definition

Because SMT threads share L1/L2 caches and branch predictors, security-sensitive setups sometimes weigh SMT against side-channel risks.

Expert definition

Superscalar pipeline sharing across architectural thread contexts (2-way on x86_64); shares execution ports, TLB, and L1/L2 caches.
