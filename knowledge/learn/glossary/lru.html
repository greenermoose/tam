LRU (Least Recently Used)

Cache or memory-page replacement policy evicting items that have gone unused the longest.

Novice definition

LRU ('Least Recently Used') is a cleanup rule that pushes out the oldest unused items first when memory fills up.

Learner definition

The Linux kernel tracks active and inactive LRU lists to decide which cold memory pages to swap to zram or disk.

Expert definition

Kernel page-reclaim policy (MGLRU / multi-gen LRU in modern Linux) approximating optimal eviction by recency.
