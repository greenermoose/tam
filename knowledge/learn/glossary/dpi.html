DPI

Dots per inch, a measure of print or pixel density.

Novice definition

DPI tells how densely dots are packed, often used to describe mouse sensitivity or print quality.

Learner definition

Dots per inch counts addressable dots over one inch; for screens it is often conflated with pixels per inch.

Expert definition

DPI is a spatial density metric used for printing and input sensitivity; display density is more precisely PPI.
