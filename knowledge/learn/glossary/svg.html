SVG (Scalable Vector Graphics)

XML-based vector image format that scales cleanly to any screen DPI without pixelation.

Novice definition

SVG is an image format made of math shapes instead of pixels, so icons stay razor-sharp at any zoom or monitor size.

Learner definition

Linux icon themes and desktop widgets use SVG so HiDPI scaling stays crisp.

Expert definition

W3C XML vector graphics format (paths, Bezier curves, gradients) rasterized at target DPI by librsvg/QtSvg.
