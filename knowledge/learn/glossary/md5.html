MD5 (Message Digest 5)

Obsolete 128-bit hash function completely broken for cryptographic collision resistance.

Novice definition

MD5 is an old 128-bit file fingerprint algorithm that is no longer safe for security because attackers can create fake matches.

Learner definition

Never use MD5 for passwords, signatures, or download verification; use SHA-256 or BLAKE3 instead.

Expert definition

RFC 1321 128-bit Merkle-Damgard hash; collisions can be generated in seconds (Wang et al. 2004).
