VFIO (Virtual Function I/O)

Linux kernel framework for safely passing physical PCIe devices (like GPUs) to userspace or VMs.

Novice definition

VFIO lets a virtual machine take direct control of a physical graphics card or network card safely.

Learner definition

Using the IOMMU for memory isolation, vfio-pci unbinds a host driver so QEMU/KVM can use the device directly.

Expert definition

Kernel IOMMU-backed userspace device-assignment framework exposing /dev/vfio/groupN to QEMU/SPDK/DPDK.
