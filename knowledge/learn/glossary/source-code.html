Source code

Human-readable instructions for a program.

Novice definition

Source code is the text a programmer writes to tell a computer what to do.

Learner definition

Source code is written in a programming language and must be compiled, assembled, or interpreted before execution.

Expert definition

Source code is the human-authored representation of a program, translated by a toolchain into machine code or bytecode.
