TOML (Tom's Obvious Minimal Language)

Human-friendly INI-like configuration format with explicit types and tables.

Novice definition

TOML is a clean, easy-to-read settings file format used by many modern Linux tools like Cargo, Alacritty, and themes.

Learner definition

TOML avoids YAML's indentation pitfalls by using explicit [section] headers and key = value pairs.

Expert definition

TOML v1.0 specification supporting typed scalars, arrays, inline tables, and [table] headers.
