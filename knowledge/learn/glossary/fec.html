FEC

Extra data that lets a receiver correct errors without retransmission.

Novice definition

FEC is a way of sending extra information so the receiver can repair some damaged data.

Learner definition

Forward error correction adds redundant symbols so corrupted bits or packets can be corrected at the receiver.

Expert definition

FEC is a channel-coding technique that trades bandwidth for error resilience, using block or convolutional codes and decoding at the receiver.
