NUL (Null character, 0x00)

ASCII 0x00 byte, used as a C string terminator and padding character.

Novice definition

NUL is the zero byte (0x00), used in C and Linux to mark the end of a piece of text.

Learner definition

Part of the C0 control codes, NUL (Ctrl+@) is ignored by terminals as padding and marks string endings in C.

Expert definition

ASCII 0x00 (NUL). Cannot appear inside POSIX filenames or C strings; terminals ignore it on output.
