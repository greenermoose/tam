CSP (Content Security Policy)

HTTP response header restricting which scripts, styles, and origins a browser may load.

Novice definition

CSP is a website security rulebook sent to your browser to block unauthorized scripts and cross-site attacks.

Learner definition

By disabling inline scripts and restricting script-src origins, CSP limits the damage of XSS vulnerabilities.

Expert definition

HTTP Content-Security-Policy header enforcing origin allowlists, nonces/hashes, and frame-ancestors restrictions in browsers.
