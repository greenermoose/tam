SVM (Secure Virtual Machine)

Technical architecture name for AMD-V hardware virtualization.

Novice definition

SVM is the Linux flag name for AMD's hardware virtualization feature.

Learner definition

Check grep -E 'vmx|svm' /proc/cpuinfo to confirm KVM hardware virtualization is enabled in BIOS/UEFI.

Expert definition

AMD64 Secure Virtual Machine extension (CPUID Fn8000_0001_ECX[2]) exposing VMRUN/VMLOAD/VMSAVE and VMCB.
