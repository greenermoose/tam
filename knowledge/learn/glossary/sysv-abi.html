System V ABI (SVID)

Unix standard defining ELF binaries, calling conventions, and core system interfaces.

Novice definition

SVID (System V Interface Definition) is a classic Unix specification that standardized how Linux and Unix programs call functions and libraries.

Learner definition

The x86_64 System V ABI defines register arguments (rdi, rsi, rdx, rcx, r8, r9) and ELF linking rules.

Expert definition

AT&T System V Interface Definition and psABI (x86-64-psABI) governing calling conventions, stack alignment, and ELF.
