ACL - Access Control List

A list of fine-grained permissions.

Novice definition

An ACL is a detailed permission list that says exactly who may read or change a file.

Learner definition

An access control list grants or denies operations to named users, groups, or entries beyond owner-group-other bits.

Expert definition

An ACL is an ordered set of access-control entries with tags, permissions, and mask semantics, stored in filesystem extended attributes.
