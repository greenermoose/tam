SSH-2 (Secure Shell version 2)

Modern Secure Shell protocol (RFC 4251-4254) replacing vulnerable SSH-1.

Novice definition

SSH-2 is the modern, secure version of the SSH protocol used for encrypted remote logins and file transfers.

Learner definition

Defined in RFC 4251-4254, SSH-2 separates transport encryption, user authentication, and multiplexed channels.

Expert definition

IETF Secure Shell protocol v2 (RFC 4251-4254); SSH-1 was deprecated due to CRC-32 compensation-attack detector flaws.
