Filesystem hierarchy (FHS)

The standard layout of Linux directories.

Novice definition

The filesystem hierarchy is the conventional arrangement of folders such as /etc, /home, and /usr.

Learner definition

The Filesystem Hierarchy Standard defines where programs, configuration, variable data, and user files belong.

Expert definition

The FHS specifies top-level directories and their purposes; modern systems extend it with /run, /sys, and /proc pseudo-filesystems.
