Git

The most widely used version-control system.

Novice definition

Git is the tool that tracks changes to source code and lets people collaborate.

Learner definition

Git is a distributed version-control system storing snapshots in a content-addressed object database.

Expert definition

Git is a distributed DAG-based VCS with SHA-1 or SHA-256 object IDs, refs, index, packfiles, and a staging area.
