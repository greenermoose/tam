Process

A process is a running instance of a program.

Novice definition

A running program instance. Each process has a number (PID). Closing a window usually ends that program's processes; starting the program again creates new ones.

Learner definition

A running instance with its own execution state, credentials and resources; a shell pipeline can start several. Signals and job control act on processes you own; see jobs.

Expert definition

A kernel-managed execution/resource context, possibly containing multiple threads. Inspect identity, credentials, descriptors and lifecycle rather than equating an executable path with a running instance. Existence checks are not health checks.
