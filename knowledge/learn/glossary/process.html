Process

A process is a running instance of a program.

Beginner definition

A running program instance.

Intermediate definition

A running instance with its own execution state, credentials and resources; a shell pipeline can start several.

Expert definition

A kernel-managed execution/resource context, possibly containing multiple threads. Inspect identity, credentials, descriptors and lifecycle rather than equating an executable path with a running instance.
