Block device

A device accessed in fixed-size blocks.

Novice definition

A block device is storage the system reads and writes in chunks, such as a disk or partition.

Learner definition

Block devices expose random-access fixed-size blocks and support buffering, partitioning, and filesystems.

Expert definition

A block device is a kernel device with a request queue and block-oriented address space, represented by a device node and major/minor numbers.
