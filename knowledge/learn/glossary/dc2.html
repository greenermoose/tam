DC2 (Device Control 2, 0x12)

ASCII 0x12 control character (Ctrl+R) reserved for device control.

Novice definition

DC2 is a general-purpose device control byte (0x12); in a shell, Ctrl+R sends this byte to search command history.

Learner definition

Part of the C0 control codes, DC2 (Ctrl+R) was unassigned by ASCII for device-specific use.

Expert definition

ASCII 0x12 (DC2, Ctrl+R). Bound by Readline to reverse-i-search.
