SIMD (Single Instruction, Multiple Data)

Parallel execution technique applying one CPU instruction to a vector of data elements at once.

Novice definition

SIMD lets a processor do the same math on 4, 8, or 16 numbers in one step instead of one by one.

Learner definition

SSE, AVX, AVX2, and ARM NEON are SIMD extensions that speed up graphics, audio, hashing, and AI.

Expert definition

Flynn's taxonomy data-parallel execution over wide vector registers (128-bit XMM, 256-bit YMM, 512-bit ZMM).
