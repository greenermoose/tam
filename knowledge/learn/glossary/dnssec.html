DNSSEC (Domain Name System Security Extensions)

Cryptographic signatures on DNS records to prevent spoofing and cache poisoning.

Novice definition

DNSSEC adds digital signatures to domain name lookups so attackers cannot fake which server a name points to.

Learner definition

DNSSEC enables trusted SSHFP records (SSH host-key fingerprints in DNS) and DANE/TLSA records.

Expert definition

IETF RFC 4033-4035 chain of trust from the DNS root using DNSKEY, DS, RRSIG, and NSEC/NSEC3 records.
