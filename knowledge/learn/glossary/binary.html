Binary

A number system that uses only 0 and 1.

Novice definition

Binary is counting with only two digits, which matches the on-and-off states inside computers.

Learner definition

Binary represents values as sums of powers of two, so 1011 means 8 + 0 + 2 + 1.

Expert definition

Binary is base-2 positional notation; each digit is a coefficient of a power of two and maps directly to a bit.
