TUI (Text User Interface)

Full-screen interactive program that draws menus, panes, and forms inside a terminal.

Novice definition

A TUI is a full-screen app that runs inside a terminal window using text, borders, and keyboard shortcuts instead of mouse-driven graphics.

Learner definition

Unlike a simple command-line tool that prints lines and exits, a TUI (like tam or htop) switches the terminal to raw mode and draws via ncurses or escape sequences.

Expert definition

Text User Interface: an application using alternate screen buffers, raw/cbreak termios modes, terminfo/ECMA-48 cursor addressing, and event loops to render interactive layouts in a TTY.
