PIE (Position-Independent Executable)

Compiled executable whose machine code can load at any random virtual address for ASLR.

Novice definition

A PIE program is compiled so Linux can place it at a different random memory address every time it starts.

Learner definition

Modern GCC and Clang enable -fPIE -pie by default so ASLR protects the main program binary as well as libraries.

Expert definition

ELF ET_DYN executable using PC-relative addressing and GOT/PLT indirection so the kernel randomizes its base load address.
