PKCE (Proof Key for Code Exchange)

OAuth 2.0 / OIDC extension preventing authorization-code interception attacks.

Novice definition

PKCE is a security check that ensures only the app that started a login request can finish it.

Learner definition

Required for public/CLI OAuth 2.0 and OIDC clients, PKCE binds the authorization code to a per-request SHA-256 challenge.

Expert definition

IETF RFC 7636: client generates high-entropy code_verifier, sends SHA256(code_verifier) as code_challenge, and proves possession at token exchange.
