UTF-8

The most common byte encoding for Unicode text.

Novice definition

UTF-8 is a way of storing Unicode text as bytes that stays compatible with ASCII for plain English.

Learner definition

UTF-8 encodes each Unicode code point in one to four bytes; ASCII text is unchanged, which helped UTF-8 replace older encodings.

Expert definition

UTF-8 is a variable-width Unicode transformation format that preserves ASCII and uses continuation bytes with leading-bit length markers.
