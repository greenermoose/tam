DEFLATE

Lossless compression algorithm combining LZ77 and Huffman coding (used in gzip, PNG, and HTTP).

Novice definition

DEFLATE is a classic lossless compression method used inside .zip files, .gz files, PNG images, and web traffic.

Learner definition

Standardized in RFC 1951, DEFLATE powers zlib/gzip; combining compression with secrets over TLS enables CRIME/BREACH side-channels.

Expert definition

RFC 1951 LZ77 sliding-window + Huffman entropy codec.
