KVM (Kernel-based Virtual Machine)

Linux kernel hypervisor turning Linux into a Type-1 hypervisor using Intel VMX or AMD SVM.

Novice definition

KVM is the virtualization engine built into the Linux kernel that lets virtual machines run at near-native speed.

Learner definition

Exposed via /dev/kvm, KVM handles CPU/memory virtualization while QEMU emulates disks, displays, and devices.

Expert definition

Linux kernel module (kvm-intel / kvm-amd) exposing ioctls for hardware-assisted vCPU execution and EPT/NPT paging.
