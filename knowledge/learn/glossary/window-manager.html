Window manager

Software that places and controls windows.

Novice definition

A window manager is the part of the desktop that decides where windows go and how you move or resize them.

Learner definition

A window manager manages window geometry, focus, decorations, and stacking or tiling policy.

Expert definition

A window manager is an X11 or Wayland client/server component implementing window lifecycle, focus, layout, and compositor integration.
