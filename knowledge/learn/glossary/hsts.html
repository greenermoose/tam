HSTS (HTTP Strict Transport Security)

HTTP response header instructing browsers to connect only over HTTPS.

Novice definition

HSTS tells your browser 'never visit this website over unencrypted HTTP again; always use HTTPS'.

Learner definition

RFC 6797 Strict-Transport-Security prevents SSL-stripping downgrade attacks on subsequent visits.

Expert definition

HTTP Strict-Transport-Security header (max-age, includeSubDomains, preload) forcing client-side HTTP->HTTPS upgrade and blocking certificate-warning bypass.
