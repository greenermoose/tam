OCR (Optical Character Recognition)

Software that reads text out of screenshots or scanned images into copyable characters.

Novice definition

OCR turns text inside a picture or screenshot into real text you can copy and paste.

Learner definition

Tamlinux screenshot capture integrates OCR (via tesseract) so you can grab text directly from any region of the screen.

Expert definition

Image-to-text recognition pipeline (binarization, layout segmentation, LSTM/Tesseract) invoked on screen-region captures.
