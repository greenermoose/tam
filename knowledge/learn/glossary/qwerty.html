QWERTY

Standard Latin keyboard layout named after its top-left six letter keys.

Novice definition

QWERTY is the standard keyboard layout used on most English keyboards, named for the first six keys in the top letter row.

Learner definition

Tamlinux bindings use logical keysyms or keycodes so home-row navigation works cleanly on QWERTY.

Expert definition

ANSI/ISO standard alphanumeric key layout originating from 1870s Sholes typewriters.
