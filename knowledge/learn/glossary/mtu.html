MTU (Maximum Transmission Unit)

Largest network packet payload size (typically 1500 bytes on Ethernet) sent without fragmentation.

Novice definition

MTU is the maximum size of a single network packet—like the weight limit on a single shipping box.

Learner definition

VPNs and tunnels reduce effective MTU below 1500 bytes, so firewalls must allow ICMP 'Packet Too Big' for Path MTU Discovery.

Expert definition

Layer-3 maximum IP datagram size per link (1500 B Ethernet, 1280 B IPv6 minimum); PMTUD relies on ICMPv6 Type 2.
