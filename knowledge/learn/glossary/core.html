Core

An independent processing unit inside a CPU.

Novice definition

A core is one complete processor inside a CPU chip; a multi-core CPU has several working in parallel.

Learner definition

A core contains its own execution units and registers, and multiple cores share caches and memory.

Expert definition

A core is an independent instruction-execution pipeline with architectural state, often sharing last-level cache and interconnect.
