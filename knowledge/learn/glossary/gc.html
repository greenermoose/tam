GC (Garbage Collection)

Automatic memory management that frees unreachable objects on the heap.

Novice definition

Garbage collection is an automatic cleanup system in languages like JavaScript, Python, or Lua that frees unused memory.

Learner definition

C11 has no GC (requiring explicit free()), whereas Lua, QML, and Nix's store GC reclaim unused objects automatically.

Expert definition

Tracing (mark-sweep, generational) or reference-counting reclamation; in Nix, nix-collect-garbage prunes unreachable store paths.
