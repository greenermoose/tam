Symmetric encryption

Scrambling and unscrambling data with the same shared secret key.

Novice definition

Symmetric encryption uses one secret key both to lock a message and to unlock it, like a house key shared between two trusted people.

Learner definition

Symmetric ciphers such as AES and ChaCha20 use a single shared secret key for fast bulk encryption of files, disks, and network streams.

Expert definition

Secret-key encryption built from pseudorandom permutations (PRPs) or pseudorandom functions (PRFs), typically composed with a MAC into an AEAD construction.
