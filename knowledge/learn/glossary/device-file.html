Device file

A file that represents a hardware device.

Novice definition

A device file is a special file in /dev that lets programs talk to hardware.

Learner definition

Device files are character or block special files whose major and minor numbers select a kernel driver.

Expert definition

A device file is a filesystem node of type character or block special, mapping VFS operations to a driver's file_operations.
