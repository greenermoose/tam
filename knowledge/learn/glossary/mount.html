Mount

To attach a filesystem to the directory tree.

Novice definition

To mount is to make a storage device or filesystem available at a folder.

Learner definition

Mounting attaches a filesystem at a mount point so its files appear in the directory hierarchy.

Expert definition

A mount binds a filesystem instance and options into a mount namespace at a path, establishing the visible directory tree.
