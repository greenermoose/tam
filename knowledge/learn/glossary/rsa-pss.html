RSA-PSS (Probabilistic Signature Scheme)

Modern randomized RSA signature padding with tight security proof (RFC 8017).

Novice definition

RSA-PSS is the modern, safest way to create digital signatures with RSA.

Learner definition

TLS 1.3 requires RSA-PSS for RSA certificate signatures instead of legacy deterministic PKCS#1 v1.5.

Expert definition

RFC 8017 randomized RSA signature encoding using salt + MGF1, provably EUF-CMA in the random oracle model.
