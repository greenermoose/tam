Home directory

The folder that holds one user's personal files.

Novice definition

Your home directory is your personal folder, where your documents, settings, and downloads usually live.

Learner definition

A home directory is the per-user starting directory, often under /home, holding personal files and user configuration.

Expert definition

A home directory is a user-owned directory referenced by passwd and HOME, with XDG subdirectories for documents, cache, and config.
