Quickshell

Qt6/QML Wayland shell toolkit used by Tamlinux for its top bar and desktop plugins.

Novice definition

Quickshell is the program that draws Tamlinux's top bar and desktop widgets using QML.

Learner definition

Tamlinux's fred.* plugins run inside Quickshell using QML (Launch.qml) over Wayland layer-shell.

Expert definition

Qt6/QML toolkit exposing Wayland wlr-layer-shell, Hyprland IPC, PipeWire, and MPRIS bindings.
