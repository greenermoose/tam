CHERI (Capability Hardware Enhanced RISC Instructions)

Hardware architecture extending pointers with unforgeable bounds and permission capabilities.

Novice definition

CHERI is a research CPU design where every memory pointer carries built-in bounds so buffer overflows are caught in hardware.

Learner definition

Developed by Cambridge and ARM (Morello), CHERI enforces spatial memory safety for C/C++ code at the instruction level.

Expert definition

Capability-based ISA extension adding tagged 128-bit fat pointers (base, length, permissions) checked on every dereference.
