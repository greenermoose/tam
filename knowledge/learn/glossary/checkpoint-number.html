Checkpoint number

A Snapper identifier within one configuration.

Novice definition

A checkpoint number is the label Snapper gives a snapshot inside one configuration.

Learner definition

A Snapper checkpoint number identifies a snapshot within a configuration, not across all configurations.

Expert definition

A checkpoint number is a per-configuration Snapper sequence identifier used with the configuration name to address a snapshot unambiguously.
