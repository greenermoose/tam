LZ4

Extremely fast lossless compression algorithm ideal for zram swap and initramfs.

Novice definition

LZ4 is a super-fast data compression format that shrinks memory pages in zram without slowing down your computer.

Learner definition

Tamlinux uses LZ4/zstd for fast compression where CPU latency matters more than squeezing out the last few percent of size.

Expert definition

Byte-oriented LZ77-family lossless codec achieving multi-GB/s decompression speeds; standard in zram and Linux initramfs.
