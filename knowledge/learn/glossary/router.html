Router

A device that forwards packets between networks.

Novice definition

A router is the box that connects networks and decides where to send each packet.

Learner definition

A router forwards packets using a routing table and rewrites link-layer headers for the next hop.

Expert definition

A router is a network-layer forwarding device with a FIB, adjacency table, and control plane that computes routes.
