Vector graphics

Images described by shapes and lines rather than pixels.

Novice definition

Vector graphics are pictures made from math shapes, so they stay sharp when enlarged.

Learner definition

Vector graphics store geometry such as paths and curves, rendered at the target resolution.

Expert definition

Vector graphics represent geometry with paths, Bézier curves, strokes, and fills, rasterized only at output time.
