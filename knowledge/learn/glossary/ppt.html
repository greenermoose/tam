PPT (Probabilistic Polynomial-Time)

Standard theoretical model of an efficient attacker with polynomial runtime and random coins.

Novice definition

In cryptography proofs, PPT describes any realistic attacker using ordinary computers with bounded time.

Learner definition

Classical cryptographic security definitions prove that no PPT adversary can break a scheme with non-negligible probability.

Expert definition

Randomized Turing machine running in time poly(lambda) in the security parameter; contrasted with QPT (quantum polynomial-time).
