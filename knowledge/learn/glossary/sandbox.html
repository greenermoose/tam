Sandbox

An isolated environment that limits what a program can do.

Novice definition

A sandbox is a safe box where a program can run without damaging the rest of the system.

Learner definition

A sandbox restricts files, network, and privileges using namespaces, seccomp, capabilities, or similar mechanisms.

Expert definition

A sandbox is a confinement boundary combining kernel mechanisms such as namespaces, seccomp-bpf, mount isolation, and capability dropping.
