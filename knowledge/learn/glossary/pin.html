Pin

To fix software to an exact version.

Novice definition

To pin is to lock a program to one exact version so it does not change unexpectedly.

Learner definition

A pin constrains a dependency or package to a specific version or source.

Expert definition

A pin is a version or source constraint enforced by a manifest, lockfile, or package-manager rule to make builds reproducible.
