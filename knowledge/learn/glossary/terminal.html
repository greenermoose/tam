Terminal

A terminal is a place where you can type instructions and read the replies.

Beginner definition

A place where you can type commands and read text responses.

Intermediate definition

A terminal connects you to a shell or another text program. A desktop terminal window and a text console are different ways to use one.

Expert definition

Terminal applications typically use a pseudo-terminal; Linux virtual consoles use a different kernel-managed interface. Both present text input and output to programs.
