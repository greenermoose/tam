PCS (Post-Compromise Security)

Property where a messaging session heals and regains secrecy after a temporary key leak.

Novice definition

Post-Compromise Security means that even if someone steals your current chat key, future messages become private again once new keys ratchet forward.

Learner definition

Alongside forward secrecy (protecting past messages), Signal's Double Ratchet provides PCS by mixing fresh Diffie-Hellman outputs.

Expert definition

Self-healing key-ratcheting property (future secrecy) achieved via asymmetric DH ratcheting after state compromise.
