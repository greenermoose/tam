PAM-5 (5-level Pulse-Amplitude Modulation)

Signaling using five voltage levels (-2, -1, 0, +1, +2) in 1000BASE-T Gigabit Ethernet.

Novice definition

PAM-5 uses five voltage levels on each twisted pair so standard Gigabit Ethernet cables can carry 1 Gbps.

Learner definition

Part of PAM modulation, PAM-5 combines 4-level trellis coding with a 0 V level for idle/control.

Expert definition

IEEE 802.3ab 1000BASE-T 5-level modulation at 125 MBaud across 4 full-duplex pairs (2 bits/symbol net).
