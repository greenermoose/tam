ISO/IEC 9899 (C standard)

International standard series defining the C programming language.

Novice definition

ISO/IEC 9899 is the official international rulebook for the C programming language.

Learner definition

Published in editions such as C90, C99, C11, C17, and C23, ISO/IEC 9899 defines C syntax, standard headers, and portable behavior across compilers.

Expert definition

Joint ISO/IEC standard (SC22/WG14) specifying the C abstract machine, memory model, standard library, and undefined behavior. Tamlinux targets ISO/IEC 9899:2011 (C11) for core native tools.
