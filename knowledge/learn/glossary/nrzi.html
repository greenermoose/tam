NRZI (Non-Return-to-Zero Inverted)

Differential line coding encoding bits as presence or absence of a voltage transition.

Novice definition

NRZI encodes 0s and 1s by whether the wire voltage flips or stays steady at each beat.

Learner definition

USB 1.x/2.0 uses NRZI with bit-stuffing so long streams of identical bits still keep the receiver clock synced.

Expert definition

Transition-encoded binary line code (used in USB 2.0 and 100BASE-FX) where 0 causes a transition and 1 holds level (or vice versa).
