Hibernation

Saving memory to disk and powering off.

Novice definition

Hibernation writes everything in memory to disk so the computer can turn off and resume later.

Learner definition

Hibernation saves RAM to swap or a hibernation image, then restores it on boot.

Expert definition

Hibernation is a power transition writing a snapshot of memory to persistent storage and resuming through a restore kernel or firmware path.
