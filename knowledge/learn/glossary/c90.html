C90 (ISO C90)

First ISO/IEC standard for C (ISO/IEC 9899:1990), equivalent to C89.

Novice definition

C90 is the 1990 international version of the original C89 language standard.

Learner definition

Part of the C standards family; C89 and C90 refer to the same language specification.

Expert definition

ISO/IEC 9899:1990, adopting ANSI X3.159-1989 with ISO section numbering.
