Hypervisor

Software that runs virtual machines.

Novice definition

A hypervisor is the layer that lets several operating systems share one physical computer safely.

Learner definition

A hypervisor creates and runs virtual machines by virtualizing CPU, memory, and devices.

Expert definition

A hypervisor is a virtual machine monitor using hardware virtualization, shadow or nested page tables, and device emulation or passthrough.
