XMSS (eXtended Merkle Signature Scheme)

Stateful hash-based post-quantum signature scheme (RFC 8391).

Novice definition

XMSS is a quantum-safe digital signature scheme built entirely from hash functions, requiring careful tracking of which key index was used.

Learner definition

Standardized in RFC 8391 and NIST SP 800-208, XMSS is used for firmware signing where state can be strictly maintained.

Expert definition

RFC 8391 stateful Merkle-tree signature over WOTS+ with bitmasks; reusing a one-time leaf state leaks the secret key.
