Version control

Software that tracks changes to files over time.

Novice definition

Version control is the system that remembers every change to a project so you can compare or undo it.

Learner definition

Version control records snapshots or deltas, branches, and history so teams can collaborate and revert.

Expert definition

Version control is a content-addressed or delta-based history system with commits, refs, merges, and conflict resolution.
