SECDED (Single-Error Correction, Double-Error Detection)

Classic Hamming-based ECC code that fixes 1-bit errors and flags 2-bit errors.

Novice definition

SECDED is the math used in ECC RAM: it automatically fixes any single flipped bit and raises an alarm if two bits flip.

Learner definition

By adding 8 parity bits to every 64 data bits (72-bit ECC DIMMs), SECDED protects RAM against cosmic-ray bit flips.

Expert definition

Extended Hamming (72,64) linear block code with minimum distance d=4, correcting 1-bit errors and detecting 2-bit errors.
