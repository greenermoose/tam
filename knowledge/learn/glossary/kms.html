KMS

Kernel-based display mode setting.

Novice definition

KMS is the modern way Linux sets a screen's resolution and refresh rate inside the kernel.

Learner definition

Kernel Mode Setting configures display controllers, connectors, and planes through DRM instead of user-space drivers.

Expert definition

KMS is the DRM atomic or legacy API for CRTCs, encoders, connectors, planes, and framebuffers, enabling flicker-free modesets.
