AES variants (AES-128, AES-256, AES-CTR, AES-NI, AES-XTS)

Key sizes, block modes, and hardware acceleration for the Advanced Encryption Standard.

Novice definition

AES is the standard modern cipher; different suffixes name its key length (128 or 256 bits), how it handles long data, or CPU speedups.

Learner definition

The AES family includes AES-128, AES-256, AES-CTR, AES-XTS, and AES-NI.

Expert definition

AES (FIPS 197) 128-bit block cipher family: key sizes (AES-128, AES-256), modes (AES-CTR, AES-XTS, GCM), and x86 hardware instructions (AES-NI).
