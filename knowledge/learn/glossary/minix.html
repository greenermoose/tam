MINIX

Educational Unix-like microkernel OS created by Andrew Tanenbaum that inspired Linux and modern microkernels.

Novice definition

MINIX is a small teaching operating system whose design inspired Linus Torvalds to write Linux.

Learner definition

MINIX 3 evolved into a fault-isolated microkernel where crashed drivers automatically restart without crashing the OS.

Expert definition

Tanenbaum's POSIX-compatible microkernel (MINIX 1-3) featuring isolated userspace device servers and reincarnation server.
