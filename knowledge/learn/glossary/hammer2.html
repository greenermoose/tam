HAMMER2

Default copy-on-write clustering filesystem of DragonFly BSD.

Novice definition

HAMMER2 is the modern snapshot-capable filesystem built for DragonFly BSD.

Learner definition

Like Btrfs and ZFS, HAMMER2 uses copy-on-write trees, block checksums, and instant snapshots.

Expert definition

DragonFly BSD CoW filesystem supporting lockless read paths, LZ4/zlib compression, and multi-master mirroring.
