RADV (AMD Radeon Vulkan Mesa Driver)

Open-source userspace Vulkan graphics driver for AMD GPUs in Mesa.

Novice definition

RADV is the open-source Linux Vulkan driver for AMD Radeon graphics cards.

Learner definition

Paired with the kernel amdgpu driver and ACO shader compiler, RADV powers Vulkan rendering on AMD hardware.

Expert definition

Mesa Vulkan ICD for AMD GCN/RDNA GPUs using ACO/LLVM shader compilation over amdgpu DRM.
