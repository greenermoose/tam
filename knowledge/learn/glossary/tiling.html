Tiling

Tiling is a way of arranging windows on a screen so they fit together.

Beginner definition

A layout where the desktop arranges windows for you.

Intermediate definition

A compositor layout mode that arranges tiled windows; floating windows and other modes can overlap.

Expert definition

A layout policy, not an invariant that all surfaces are non-overlapping. Floating, fullscreen, layer surfaces and application constraints affect the final scene.
