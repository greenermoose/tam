Hash

A fixed-size value derived from data.

Novice definition

A hash is a short code made from data, useful for finding things quickly or checking whether data changed.

Learner definition

A hash function maps arbitrary input to a fixed-size value; good hashes are deterministic and hard to invert.

Expert definition

A hash is the output of a compression function with preimage, collision, and avalanche properties, used in tables, integrity, and signatures.
