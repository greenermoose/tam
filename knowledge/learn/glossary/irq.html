IRQ

A signal that asks the processor to handle an event.

Novice definition

An IRQ is a hardware interrupt, a tap on the CPU's shoulder to say a device needs attention.

Learner definition

An interrupt request line or message tells the CPU to run a handler for a device event.

Expert definition

An IRQ is an interrupt request delivered by line, MSI, or MSI-X, carrying a vector that selects a handler and priority.
