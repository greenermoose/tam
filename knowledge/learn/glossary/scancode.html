Scancode

A scancode is a keyboard's own number for a physical key, before the computer decides which letter that key should produce.

Novice definition

A scancode names a key by its position on the keyboard, not by the character printed on it. The same scancode can become a on one layout and something else on another.

Learner definition

A scancode is a hardware report code. A PS/2 keyboard sends set-1 make and break codes, such as 0x1E for the a key; a USB keyboard sends a HID usage code, such as 0x04 for the same key. Linux translates either form into its own keycode, so programs rarely see the original scancode.

Expert definition

Scancodes are device-protocol dependent. The i8042 controller delivers PS/2 set-1 bytes (make 0x1E, break 0x9E); atkbd translates them to Linux keycodes. USB HID keyboards send usage IDs in report descriptors, and usbhid translates those. On a 2.6 or later kernel, showkey -s does not show raw hardware bytes: the kernel translates keycodes back to scancodes, so the output is reconstructed rather than captured at the wire. The kernel documentation describes the translation tables under Documentation/input/.
