Line discipline

Kernel software layer between a TTY/PTY driver and user programs that handles line editing and signals.

Novice definition

The line discipline is the kernel's built-in helper that makes Backspace, Enter, and Ctrl+C work in a basic terminal.

Learner definition

Linux's N_TTY line discipline sits between the hardware or PTY driver and your shell, translating Ctrl+C to SIGINT and buffering lines in canonical mode.

Expert definition

Kernel TTY line discipline (default N_TTY in drivers/tty/n_tty.c) configured via termios ioctls; handles input/output byte translations (ICRNL, ONLCR), canonical buffering, and ISIG signal generation.
