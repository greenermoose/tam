DC3 (Device Control 3 / XOFF, 0x13)

ASCII 0x13 control character (Ctrl+S), used as XOFF to pause terminal output.

Novice definition

DC3 (Ctrl+S) is the 'pause output' code that freezes scrolling in a terminal until you press Ctrl+Q.

Learner definition

Part of the C0 control codes, DC3 acts as XOFF in software flow control (IXON).

Expert definition

ASCII 0x13 (DC3 / XOFF, Ctrl+S). Suspends TTY output in the kernel line discipline when IXON is set.
