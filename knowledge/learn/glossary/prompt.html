Prompt

Beginner definition

Text that shows the shell is ready for you to type a command.

Intermediate definition

A prompt can show your user name or current directory. Examples often use $; do not type that symbol when it represents the prompt.

Expert definition

Prompt appearance is configured by the shell and is not a reliable security or privilege check.
