Embedded interpreter

An interpreter built into another program.

Novice definition

An embedded interpreter is a scripting language engine running inside a larger application.

Learner definition

An embedded interpreter exposes an API so a host program can evaluate scripts and share data with them.

Expert definition

An embedded interpreter is a language runtime linked into a host process, with embedding APIs, value conversion, sandboxing, and lifecycle management.
