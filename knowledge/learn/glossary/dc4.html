DC4 (Device Control 4, 0x14)

ASCII 0x14 control character (Ctrl+T) reserved for device control.

Novice definition

DC4 is a general-purpose device control byte (0x14); Ctrl+T sends this byte.

Learner definition

Part of the C0 control codes, DC4 (Ctrl+T) was reserved for hardware-specific control.

Expert definition

ASCII 0x14 (DC4, Ctrl+T). Bound by Readline to transpose-chars.
