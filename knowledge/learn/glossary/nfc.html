NFC (Near Field Communication)

Short-range (few centimeters) wireless protocol at 13.56 MHz used for security keys and tap cards.

Novice definition

NFC is very short-range wireless communication used when you tap a security key or card against a reader.

Learner definition

Many FIDO2 hardware keys support NFC alongside USB-C so you can authenticate on laptops and phones.

Expert definition

ISO/IEC 14443 / 18092 13.56 MHz inductive-coupled RF standard supporting CTAP2/FIDO2 authenticators.
