Buffer

A temporary holding area for data.

Novice definition

A buffer is a waiting area where data is held briefly while it moves between parts of a computer.

Learner definition

A buffer smooths differences in speed between a producer and consumer, such as disk reads and program input.

Expert definition

A buffer is a bounded memory region with producer and consumer indices, used for I/O, streaming, and flow control; it may be in kernel, user, or device memory.
