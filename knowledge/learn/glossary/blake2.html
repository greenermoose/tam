BLAKE2

Fast, secure cryptographic hash function family (BLAKE2b, BLAKE2s) built on ChaCha-like ARX rounds.

Novice definition

BLAKE2 is a modern cryptographic hash function that is faster than SHA-256 on CPUs while remaining highly secure.

Learner definition

Specified in RFC 7693, BLAKE2b (64-bit) and BLAKE2s (32-bit) are used in WireGuard, Argon2, and ZFS.

Expert definition

RFC 7693 HAIFA-based ARX hash derived from BLAKE (SHA-3 finalist); supports built-in keying, salting, and personalization.
