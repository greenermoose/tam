SI (Shift In, 0x0F)

ASCII 0x0F control character selecting the standard G0 character set.

Novice definition

SI is a control byte (0x0F) that switches a terminal back from special line-drawing symbols to normal letters.

Learner definition

Part of the C0 control codes, SI (0x0F) restores the G0 character set after Shift Out (SO, 0x0E) drew box graphics.

Expert definition

ASCII 0x0F (SI, Ctrl+O). Invokes G0 into GL in ISO 2022 / VT100 character-set switching, recovering normal ASCII after stray binary output triggers SO (0x0E).
