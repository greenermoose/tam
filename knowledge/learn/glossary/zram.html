ZRAM

A compressed RAM disk used as swap or temporary storage.

Novice definition

ZRAM is a compressed area in memory that acts like a fast disk, often used as swap.

Learner definition

ZRAM creates a block device backed by compressed RAM, reducing swap I/O at the cost of CPU time.

Expert definition

ZRAM is a compressed block device using zsmalloc or similar allocators, with per-device compression, writeback, and memory accounting.
