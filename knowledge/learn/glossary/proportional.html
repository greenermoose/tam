Proportional

A font whose characters have different widths.

Novice definition

A proportional font gives narrow letters less space and wide letters more, like normal printed text.

Learner definition

Proportional fonts vary glyph advance widths to improve readability in running text.

Expert definition

A proportional font uses per-glyph metrics and kerning, requiring shaping for correct spacing.
