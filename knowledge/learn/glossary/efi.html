EFI

The firmware interface that replaced the legacy BIOS.

Novice definition

EFI is the modern startup system that finds and launches the operating system.

Learner definition

Extensible Firmware Interface defines boot services, runtime services, and executable images loaded from an EFI System Partition.

Expert definition

EFI is the interface specification underlying UEFI, with protocols, handles, events, and PE/COFF executable images.
