ASLR (Address Space Layout Randomization)

Kernel security mitigation that randomizes process memory addresses on each launch.

Novice definition

ASLR shuffles where a program's code and data sit in memory each time it runs, making memory bugs much harder to exploit.

Learner definition

Paired with PIE (Position-Independent Executables), ASLR prevents attackers from predicting fixed function or stack addresses.

Expert definition

Kernel virtual-memory randomization of stack, heap, mmap base, and PIE executable mappings (/proc/sys/kernel/randomize_va_space).
