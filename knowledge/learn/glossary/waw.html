WAW (Write-After-Write hazard)

Pipeline data hazard where two instructions write to the same register; eliminated by register renaming.

Novice definition

A WAW hazard happens when two instructions write to the same register and could finish out of order if the CPU did not rename them.

Learner definition

Out-of-order CPUs avoid false WAW and WAR dependencies by mapping architectural registers onto a larger physical register file.

Expert definition

Output-dependence pipeline hazard (I2 writes R before I1 finishes writing R), resolved statically/dynamically via Tomasulo register renaming.
