XDP (eXpress Data Path)

High-speed eBPF hook processing network packets in the NIC driver before kernel sk_buff allocation.

Novice definition

XDP lets Linux drop or forward bad network packets right as they arrive from the network card, before the OS does extra work.

Learner definition

Used for DDoS mitigation and ultra-fast firewalls alongside nftables.

Expert definition

Kernel eBPF hook at the earliest RX driver ring stage returning XDP_DROP, XDP_PASS, XDP_TX, or XDP_REDIRECT.
