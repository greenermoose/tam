Root filesystem

The filesystem mounted at the top of the system tree.

Novice definition

The root filesystem is the main storage area mounted at slash that holds the operating system.

Learner definition

The root filesystem contains /etc, /usr, and other essential directories; it is mounted during boot.

Expert definition

The root filesystem is the mount at / supplying the initial hierarchy and init, often from a partition, subvolume, or network image.
