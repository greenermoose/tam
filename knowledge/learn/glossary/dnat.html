DNAT (Destination Network Address Translation)

Firewall rule rewriting a packet's destination IP address or port (port forwarding).

Novice definition

DNAT is a firewall rule that redirects incoming network traffic to a different port or internal computer.

Learner definition

In nftables, DNAT is commonly used in prerouting chains to forward incoming ports to a container or local service.

Expert definition

Netfilter/nftables stateful translation rewriting destination IP:port on initial packets and reversing it on conntrack reply traffic.
