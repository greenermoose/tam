RFC 5869 (HKDF)

IETF specification for HMAC-based Extract-and-Expand Key Derivation Function.

Novice definition

RFC 5869 defines a standard method for turning one shared secret into multiple safe encryption keys.

Learner definition

HKDF uses two steps—Extract and Expand—built on HMAC to derive independent session keys in protocols like TLS 1.3.

Expert definition

IETF RFC 5869 (Krawczyk & Eronen, 2010) specifies HKDF-Extract(salt, IKM) -> PRK and HKDF-Expand(PRK, info, L) -> OKM using an underlying HMAC hash function.
