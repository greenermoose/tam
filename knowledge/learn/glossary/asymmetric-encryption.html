Asymmetric encryption

Encryption that uses a public key to lock data and a separate private key to unlock it.

Novice definition

Asymmetric encryption uses two linked keys: anyone can use your public key to lock a message for you, but only your private key can open it.

Learner definition

Public-key cryptography avoids pre-sharing a secret key over an untrusted network by separating the public encryption key from the private decryption key.

Expert definition

Public-key encryption (PKE) or key encapsulation (KEM) based on trapdoor one-way functions or hard algebraic/lattice problems, typically used to establish symmetric session keys.
