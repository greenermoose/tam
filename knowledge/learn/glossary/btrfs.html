Btrfs

Btrfs is a Linux filesystem that can take snapshots of directories for rollback.

Novice definition

A filesystem is how the computer organizes files on a disk. Btrfs supports subvolumes and snapshots, which Tamlinux uses with Snapper so you can roll back some kinds of change. Not every file is covered by a snapshot; personal documents may need separate backup.

Learner definition

Btrfs provides copy-on-write snapshots, subvolumes, and checksums. Snapper typically manages snapshot timelines on selected subvolumes. Rollback restores filesystem state at that boundary; Home Manager generations and mutable user files are separate recovery domains.

Expert definition

A copy-on-write Linux filesystem used on Tamlinux for snapshot-backed recovery boundaries via Snapper.
