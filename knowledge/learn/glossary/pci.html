PCI - Peripheral Component Interconnect

An older standard bus for expansion cards.

Novice definition

PCI is an older slot type inside computers for adding cards such as network or sound cards.

Learner definition

Peripheral Component Interconnect is a parallel bus with configuration space and shared address, data, and control lines.

Expert definition

PCI is a parallel expansion bus defining configuration space, bus-mastering, interrupts, and memory or I/O windows.
