C0 control codes (ASCII 0x00-0x1F)

The 32 ASCII control characters (0x00-0x1F) used for line control, signaling, and framing.

Novice definition

C0 control codes are the first 32 invisible characters in ASCII (bytes 0 to 31), used for actions like Newline, Tab, Backspace, and Escape.

Learner definition

Every C0 code can be typed with Ctrl+letter (for example, Ctrl+C is ETX 0x03, Ctrl+J is LF 0x0A). The kernel line discipline and terminal interpret them differently.

Expert definition

ECMA-48 / ASCII C0 set (0x00-0x1F): NUL, SOH, STX, ETX, EOT, ENQ, ACK, BEL, BS, HT, LF, FF, CR, SI, DLE, DC1, DC2, DC3, DC4, NAK, SYN, ETB, CAN, SUB.
