Clone

A full copy of a repository.

Novice definition

A clone is a copy of a project's repository, including its history, that you can work in.

Learner definition

Cloning copies a remote repository's objects and refs into a new local repository.

Expert definition

A Git clone transfers reachable objects and refs, configures a remote, and checks out a working tree.
