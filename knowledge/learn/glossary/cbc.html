CBC (Cipher Block Chaining)

Classic block-cipher mode that XORs each plaintext block with the previous ciphertext block.

Novice definition

CBC is an older encryption mode that chains data blocks together so identical blocks do not encrypt the same way.

Learner definition

CBC requires padding and a separate MAC (Encrypt-then-MAC) to avoid padding-oracle attacks; modern protocols prefer AEAD modes.

Expert definition

Block cipher mode C_i = E_K(P_i XOR C_{i-1}) with C_0 = IV; vulnerable to padding oracles if unauthenticated.
