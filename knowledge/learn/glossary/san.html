SAN (Subject Alternative Name)

X.509 certificate extension listing all hostnames or IP addresses valid for a TLS certificate.

Novice definition

The SAN list inside a website's security certificate names every domain (like example.com and www.example.com) that the certificate covers.

Learner definition

Modern browsers ignore the legacy Common Name (CN) and require the hostname to match a SAN dNSName entry (RFC 5280).

Expert definition

X.509 v3 extension OID 2.5.29.17 (RFC 5280) carrying dNSName, iPAddress, and URI GeneralNames.
