SEV-SNP (Secure Encrypted Virtualization - Secure Nested Paging)

AMD hardware confidential-computing feature isolating VM memory from the host hypervisor.

Novice definition

SEV-SNP is an AMD CPU feature that encrypts a virtual machine's memory so even the host server cannot read it.

Learner definition

Used in cloud confidential computing alongside Intel TDX, SEV-SNP adds integrity protection against hypervisor page remapping.

Expert definition

AMD EPYC confidential-VM extension encrypting guest RAM with per-ASID AES keys and enforcing Reverse Map Table (RMP) page ownership.
