L1 cache (Level 1 cache)

Fastest, smallest on-core CPU cache split into instruction (L1i) and data (L1d).

Novice definition

L1 is the fastest, closest scratchpad memory inside each CPU core, holding the exact bytes the core is using right now.

Learner definition

Part of CPU caches, L1 typically holds 32-64 KiB per core and responds in ~4 CPU cycles.

Expert definition

Split Harvard-style per-core SRAM (L1i + L1d), virtually indexed and physically tagged (VIPT) for zero-wait TLB lookup.
