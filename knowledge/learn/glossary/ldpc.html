LDPC (Low-Density Parity-Check)

Modern capacity-approaching forward error-correction code used in Wi-Fi, 10GBASE-T, and SSDs.

Novice definition

LDPC is an advanced error-correction code that lets high-speed Wi-Fi, Ethernet, and SSDs recover data cleanly from noisy signals.

Learner definition

LDPC uses sparse parity-check matrices and iterative decoding to approach the Shannon channel limit.

Expert definition

Linear error-correcting code with sparse bipartite Tanner graph decoded via belief propagation; used in IEEE 802.3an, Wi-Fi 6/7, and NAND flash.
