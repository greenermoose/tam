SSHFP (SSH Fingerprint DNS Record)

DNS resource record storing an SSH server's public-key fingerprint, secured by DNSSEC.

Novice definition

SSHFP lets a domain publish its SSH server fingerprint in DNS so your SSH client can verify it automatically.

Learner definition

Enabled with VerifyHostKeyDNS yes, SSHFP avoids blind Trust On First Use when DNSSEC is valid.

Expert definition

RFC 4255 / RFC 6594 DNS record type 44 encoding algorithm, SHA-256 fingerprint type, and host-key digest.
