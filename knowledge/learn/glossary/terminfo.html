Terminfo (terminal information)

A database of terminal capabilities.

Novice definition

Terminfo is the reference book that tells programs what a particular terminal can do.

Learner definition

Terminfo describes cursor movement, colors, and control strings for terminal types.

Expert definition

Terminfo is a compiled capability database with string, numeric, and boolean fields, queried by ncurses and tput.
