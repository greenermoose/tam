Daemon

A background program that runs without a terminal.

Novice definition

A daemon is a program that keeps running in the background, such as a print or network service.

Learner definition

A daemon detaches from the controlling terminal and runs continuously, often started by the init system.

Expert definition

A daemon is a background process, traditionally double-forked and setsid-separated from its terminal, supervised by an init system in modern practice.
