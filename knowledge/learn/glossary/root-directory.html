Root directory

The top of a filesystem's directory tree.

Novice definition

The root directory is the very top folder, written as a slash, that contains everything else.

Learner definition

The root directory is the base of a mounted filesystem hierarchy; the system root is /.

Expert definition

The root directory is the directory inode at the base of a mount, denoted /, from which all paths descend.
