AES-CTR (AES Counter Mode)

Stream-cipher mode turning AES into a parallelizable keystream via an incrementing counter.

Novice definition

AES-CTR turns the AES block cipher into a fast stream of secret bytes by encrypting a counting number for each chunk.

Learner definition

Part of AES variants; CTR mode requires a unique nonce per message and pairs with a MAC (as in AES-GCM).

Expert definition

AES in Counter mode: XORs plaintext blocks with AES_K(nonce || counter); parallelizable and requires no padding, but catastrophic if a (key, nonce) pair repeats.
