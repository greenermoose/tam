NOR (NOR gate / NOR flash)

Universal logic gate (NOT-OR) and non-volatile flash memory type used for UEFI/BIOS firmware.

Novice definition

NOR is both a fundamental logic gate (output is 1 only if all inputs are 0) and the reliable flash chip that stores motherboard firmware.

Learner definition

Unlike high-density NAND flash in SSDs, SPI NOR flash supports byte-random reads for early boot code.

Expert definition

Universal Boolean gate ~(A | B) and XIP-capable floating-gate/charge-trap flash used for BIOS/UEFI SPI chips.
