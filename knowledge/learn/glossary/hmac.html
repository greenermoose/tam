HMAC - Hash-based Message Authentication Code

A standard way to build a secret-key message authentication tag from a hash function.

Novice definition

HMAC mixes a secret key into a hash function twice so that only people with the key can create or check the seal.

Learner definition

HMAC combines a cryptographic hash such as SHA-256 with a secret key in a nested construction that resists length-extension attacks.

Expert definition

RFC 2104 construction H((K' XOR opad) || H((K' XOR ipad) || m)), provably a PRF when the underlying compression function is a dual-PRF.
