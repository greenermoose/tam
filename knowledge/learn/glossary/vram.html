VRAM - Video Random-Access Memory

Memory used by a graphics processor.

Novice definition

VRAM is the memory a graphics card uses to store images and textures.

Learner definition

Video RAM is dedicated memory attached to the GPU, holding framebuffers, textures, and shader data.

Expert definition

VRAM is graphics-dedicated memory, often GDDR or HBM, with high bandwidth and GPU-specific access patterns.
