Network interface

A named connection point for network traffic.

Novice definition

A network interface is the part of the system that sends and receives network data, such as Wi-Fi or Ethernet.

Learner definition

A network interface is a kernel device with a name, link state, addresses, and queues, such as wlan0 or eth0.

Expert definition

A network interface is a net_device with driver operations, queues, address assignment, and participation in routing and neighbor tables.
