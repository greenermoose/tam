Context switch

Changing which task the processor is running.

Novice definition

A context switch is when the CPU stops one task and starts another, saving the first one's place.

Learner definition

A context switch saves a thread's registers and state and restores another's, adding overhead.

Expert definition

A context switch is a scheduler transition that saves and restores architectural and kernel state, flushes or tags address-space state, and perturbs caches and TLBs.
