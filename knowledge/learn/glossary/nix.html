Nix

Nix is a package manager that installs software into immutable store paths and can reproduce exact environments.

Novice definition

Nix places each package build in a unique directory under the Nix store. Tamlinux uses Nix and Home Manager to deliver recorded assemblies of workstation software. Rolling back a generation restores that assembly; it does not by itself restore every personal file.

Learner definition

Nix evaluates declarative expressions to store paths addressed by cryptographic hashes. Flakes and lock files pin inputs. Tamlinux packaging records assemblies in the packages repository; deploy tools switch generations without rebuilding when promoting stages.

Expert definition

A purely functional package manager and store; Tamlinux assemblies pin Nix-built outputs for reproducible delivery.
