XBPS (X Binary Package System)

Fast independent package manager created for Void Linux.

Novice definition

XBPS is the package manager Void Linux uses to install and update software.

Learner definition

Known for speed and clean C implementation, XBPS powers Void's rolling-release repository.

Expert definition

Void Linux's custom binary package manager (xbps-install, xbps-query, xbps-src).
