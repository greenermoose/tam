Interpreter

A program that runs source code directly.

Novice definition

An interpreter reads a program and performs its instructions without building a separate machine-code file.

Learner definition

An interpreter executes source or bytecode, managing parsing, state, and runtime services itself.

Expert definition

An interpreter is an execution engine that evaluates a program representation, often with bytecode dispatch or abstract syntax tree walking.
