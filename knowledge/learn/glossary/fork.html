Fork

A personal copy of someone else's repository.

Novice definition

A fork is your own copy of another person's project, often used to propose changes.

Learner definition

A fork is a server-side copy of a repository under another account, tracked as a separate remote.

Expert definition

A fork is an independent repository with shared history but separate refs and permissions, used for pull requests.
