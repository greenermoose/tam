Root-stock

Beginner definition

The Linux distribution beneath the Tamlinux workstation.

Intermediate definition

Arch Linux is the current development base; Void Linux is a planned pilot, not a proved deployment.

Expert definition

The base distribution owns its native kernel, libraries, service manager and package layer. Portability of the cultivar requires validation rather than analogy.
