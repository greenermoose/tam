BREACH

Side-channel attack recovering secrets from compressed HTTPS HTTP responses.

Novice definition

BREACH is an attack that guesses secrets on web pages by watching how much smaller HTTP compression makes the encrypted response.

Learner definition

Unlike CRIME (TLS-level compression), BREACH targets HTTP gzip/deflate compression when attacker input and secrets share a response.

Expert definition

Compression-ratio side-channel against HTTP response compression over TLS; TLS 1.3 removes TLS-layer compression, while HTTP compression requires per-request CSRF masking.
