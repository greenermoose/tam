TCP - Transmission Control Protocol

A reliable, ordered network transport protocol.

Novice definition

TCP is the protocol that makes sure data arrives complete and in order, used by web pages and file transfers.

Learner definition

Transmission Control Protocol provides connection setup, sequencing, acknowledgments, retransmission, and flow control.

Expert definition

TCP is a reliable byte-stream transport with a three-way handshake, sliding window, congestion control, and full-duplex connections.
