Script

A program written for an interpreter.

Novice definition

A script is a small program, often in a shell or Python, that a program reads and runs line by line.

Learner definition

A script is an executable text file interpreted at runtime rather than compiled ahead of time.

Expert definition

A script is a source file whose shebang or invocation selects an interpreter, with execution semantics defined by that language.
