Compiler

A program that translates source code into another form.

Novice definition

A compiler turns the code a person wrote into a program the computer can run.

Learner definition

A compiler translates a source language into machine code or an intermediate representation, with parsing, optimization, and code generation.

Expert definition

A compiler is a program that performs lexical, syntactic, and semantic analysis and lowers a source language to a target representation or executable.
