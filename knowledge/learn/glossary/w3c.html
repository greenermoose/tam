W3C (World Wide Web Consortium)

International standards organization for web technologies such as HTML, CSS, SVG, and WCAG.

Novice definition

W3C is the main organization that writes the open standards for web pages, including HTML and SVG.

Learner definition

W3C publishes recommendations for web markup, styling, vector graphics, and accessibility guidelines.

Expert definition

World Wide Web Consortium, founded in 1994, maintaining open web standards (HTML, CSS, SVG, WCAG, WebAuthn).
