FORS (Forest of Random Subsets)

Few-time hash-based signature scheme used inside SPHINCS+ / SLH-DSA.

Novice definition

FORS is a building block inside stateless hash-based post-quantum signatures (SLH-DSA).

Learner definition

Unlike one-time WOTS+ keys, FORS can safely sign a few messages per leaf inside the SPHINCS+ hypertree.

Expert definition

Stateless few-time signature over k Merkle trees of height a, authenticating message digests in FIPS 205 (SLH-DSA).
