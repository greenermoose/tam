Sudo

A tool for running one command as another user.

Novice definition

Sudo lets an allowed user run a command as root without logging in as root.

Learner definition

sudo checks policy, authenticates the user, and executes a command with elevated credentials.

Expert definition

sudo is a setuid policy executor using sudoers rules, PAM authentication, and timestamp caching to run commands as another principal.
