Retirement

Removing a temporary patch once it is no longer needed.

Novice definition

Retirement is deleting a carried patch and its local package after the official software includes the fix.

Learner definition

Retirement removes the local repository files, hook, and status files when upstream ships the patched version.

Expert definition

Retirement is the automated teardown of a carried patch's build artifacts, repository entry, guard hook, and status after vercmp confirms the upstream fix.
