Option

A setting that changes how a command behaves.

Novice definition

An option is a choice you add to a command, usually starting with a dash, to change what it does.

Learner definition

An option is a command-line argument that selects a mode or supplies a setting, often parsed by getopt or a library.

Expert definition

An option is a named or positional command parameter interpreted by the program, distinct from the operands it acts on.
