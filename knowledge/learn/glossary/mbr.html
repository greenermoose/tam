MBR

The old disk partition table format.

Novice definition

MBR is the traditional partition map at the start of a disk, limited to four primary partitions.

Learner definition

The Master Boot Record holds boot code and a partition table for disks using legacy BIOS boot.

Expert definition

MBR is a 512-byte sector with boot code, four 16-byte partition entries, and a 0x55AA signature, using CHS and 32-bit LBA fields.
