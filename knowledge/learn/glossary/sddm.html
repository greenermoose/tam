SDDM (Simple Desktop Display Manager)

Modern QML-based graphical login manager for Wayland and X11 sessions.

Novice definition

SDDM is the graphical login screen where you type your password to start your Tamlinux desktop session.

Learner definition

SDDM authenticates via PAM, opens a logind session, and launches Hyprland on Wayland.

Expert definition

Qt/QML display manager (sddm.service) delegating authentication to PAM and launching Wayland/X11 user sessions.
