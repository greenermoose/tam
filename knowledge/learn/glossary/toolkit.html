Toolkit

A library for building graphical interfaces.

Novice definition

A toolkit is a set of programming tools and widgets for making windows and buttons.

Learner definition

A GUI toolkit provides widgets, layout, input handling, and rendering abstractions for applications.

Expert definition

A toolkit is a widget and rendering library such as GTK or Qt, with theme engines, accessibility interfaces, and compositor integration.
