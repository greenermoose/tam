Lockfile

A file that records exact dependency versions.

Novice definition

A lockfile is a saved list of the exact versions a project used, so builds can be repeated.

Learner definition

A lockfile records resolved dependency versions and hashes, overriding looser manifest ranges.

Expert definition

A lockfile is a generated, machine-readable resolution graph with versions, sources, and integrity hashes for reproducible installs.
