Home Manager

Home Manager is the Nix tool that builds a user's configuration and programs into a generation you can switch or roll back.

Beginner definition

Home Manager takes a declarative description of user software and settings and builds a generation. Tamlinux delivers much of the workstation through Home Manager generations. Switching generations changes the linked programs; mutable files you edited by hand may need separate recovery.

Intermediate definition

Home Manager is a Nix-based project that manages per-user profiles. Each generation is an immutable closure. Tamlinux deployment ties product assemblies to these generations; always identify the generation and assembly evidence before a rollback.

Expert definition

The Nix-based user environment manager that produces switchable generations used by Tamlinux workstation delivery.
