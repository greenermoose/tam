CRC-32 (32-bit Cyclic Redundancy Check)

Standard 32-bit polynomial error-detecting code used in Ethernet, PNG, ZIP, and themes.

Novice definition

CRC-32 is a fast 32-bit checksum that catches accidental bit flips in files, PNG images, and network frames.

Learner definition

Unlike SHA-256, CRC-32 is built to detect transmission noise, not malicious tampering.

Expert definition

32-bit GF(2) polynomial remainder (IEEE 802.3 0xEDB88320 or Castagnoli 0x82F63B78) detecting all <=32-bit burst errors.
