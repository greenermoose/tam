Pot

In the Tamlinux plant analogy, a pot is the environment that starts or contains a system.

Beginner definition

The botanical name for the environment that starts or contains a bootable system.

Intermediate definition

The analogy can refer to firmware, a boot loader or a virtual machine envelope.

Expert definition

A conceptual boot/containment role. Those mechanisms have different interfaces and failure boundaries; the analogy does not make them interchangeable.
