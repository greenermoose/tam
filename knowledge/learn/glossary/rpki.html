RPKI (Resource Public Key Infrastructure)

Cryptographic framework verifying which autonomous systems may announce IP address prefixes over BGP.

Novice definition

RPKI is a security system that helps internet routers check whether a network actually owns the IP addresses it claims.

Learner definition

By signing Route Origin Authorizations (ROAs), RPKI prevents accidental or malicious BGP route hijacks.

Expert definition

RFC 6480 PKI binding IP/ASN allocations to Route Origin Authorizations (ROAs) for BGP Origin Validation.
