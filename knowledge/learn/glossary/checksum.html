Checksum

A short value used to detect changes in data.

Novice definition

A checksum is a fingerprint calculated from data so you can tell if it was damaged or altered.

Learner definition

A checksum is a fixed-size value computed from a message; recomputing it reveals accidental corruption.

Expert definition

A checksum is a redundancy code, such as a sum, CRC, or cryptographic hash, used to detect errors or verify integrity.
