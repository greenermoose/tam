XNU (X is Not Unix)

Hybrid kernel powering macOS and iOS, combining Mach IPC, BSD layers, and I/O Kit.

Novice definition

XNU is the hybrid kernel at the heart of macOS and iOS.

Learner definition

XNU blends a Mach microkernel core with FreeBSD networking/POSIX layers in a single kernel address space for speed.

Expert definition

Apple hybrid kernel integrating Mach 3.0 tasks/ports, BSD VFS/networking, and C++ I/O Kit drivers.
