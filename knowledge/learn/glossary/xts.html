XTS (XEX-based Tweaked-Codebook with Ciphertext Stealing)

Block-cipher mode tailored for sector-level disk encryption.

Novice definition

XTS is an encryption mode built for hard drives and SSDs so any sector can be read or written in any order.

Learner definition

Used by LUKS2 (aes-xts-plain64), XTS derives a per-sector tweak from the sector number.

Expert definition

IEEE 1619 tweaked-codebook mode; provides confidentiality for fixed-size storage blocks without ciphertext expansion (no authentication tag).
