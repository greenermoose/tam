iGPU

Graphics built into the processor.

Novice definition

An iGPU is graphics hardware built into the CPU chip, sharing system memory.

Learner definition

Integrated graphics uses part of the processor and system RAM instead of a separate card.

Expert definition

An integrated GPU is a GPU block on the CPU die or package sharing the memory controller and often the last-level cache.
