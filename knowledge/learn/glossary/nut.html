Nut

Beginner definition

The name for a planned minimal bootable Tamlinux environment.

Intermediate definition

The public design describes a small kernel/initramfs or UKI environment for inspection and preparation; do not assume it is installed.

Expert definition

A proposed minimal boot/recovery layer, not a claim that a signed immutable image or a working network bootstrap is delivered. Consult the actual boot configuration and current product plan.
