QUIC

Encrypted, multiplexed UDP transport protocol (RFC 9000) underlying HTTP/3.

Novice definition

QUIC is a modern, fast replacement for TCP built on UDP with TLS 1.3 encryption always turned on.

Learner definition

Used by HTTP/3, QUIC eliminates head-of-line blocking between streams and supports connection migration across Wi-Fi and cellular.

Expert definition

IETF RFC 9000 / 9001 UDP transport integrating TLS 1.3 handshake, independent stream multiplexing, and 0-RTT/1-RTT setup.
