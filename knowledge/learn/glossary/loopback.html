Loopback

A virtual interface that sends traffic back to the same machine.

Novice definition

Loopback is the fake network connection a computer uses to talk to itself, usually at 127.0.0.1.

Learner definition

The loopback interface has 127.0.0.1/8 for IPv4 and ::1/128 for IPv6 and never leaves the host.

Expert definition

Loopback is a local-only interface whose packets are routed internally, used for IPC over sockets and service binding.
