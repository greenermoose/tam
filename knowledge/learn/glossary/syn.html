SYN (Synchronous Idle, 0x16)

ASCII 0x16 control character (Ctrl+V) used for clock synchronization and literal quoting.

Novice definition

SYN is a control byte (0x16) used to keep older serial links in sync; in shells, Ctrl+V lets you type the next key literally.

Learner definition

Part of the C0 control codes, SYN (0x16) is mapped to VLNEXT (literal next) in the Linux line discipline.

Expert definition

ASCII 0x16 (SYN, Ctrl+V). Maintains bit/byte sync in synchronous serial links; default VLNEXT in termios.
