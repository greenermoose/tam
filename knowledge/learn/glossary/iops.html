IOPS (Input/Output Operations Per Second)

Storage benchmark measuring how many individual read/write requests a drive completes per second.

Novice definition

IOPS measures how many tiny file operations an SSD can handle every second—crucial for snappy OS responsiveness.

Learner definition

NVMe SSDs reach hundreds of thousands of random 4K IOPS, whereas spinning HDDs manage only ~100 IOPS.

Expert definition

Storage request rate (typically 4 KiB random queue-depth benchmarks); distinct from sequential MB/s throughput.
