Static library

A library copied into a program when it is built.

Novice definition

A static library is a collection of code that gets copied into each program that uses it.

Learner definition

A static library is an archive of object files, such as a .a file, linked directly into the executable.

Expert definition

A static library is an ar archive of relocatable objects, with members selected and relocated by the linker into the output image.
