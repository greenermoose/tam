Cultivar

In Tamlinux, a cultivar is all the software in the Tamlinux release that allows the computer to be used effectively and efficiently by both humans and AI agents.

Beginner definition

A named variety of the Tamlinux workstation software. The cultivar is installed on top of the rootstock, which is the kernel and core system software that third-parties publish and is necessary to be installed so that the software we write can function properly. Rootstock is not a common term, but one that Fred Horch, the Tamlinux developer, made up to explain how Tamlinux works. Our goal is to minimize the size of the rootstock and maximize its speed and efficiency.

Intermediate definition

The Tamlinux desktop and tool suite composed above the rootstock. Currently we are using Arch Linux as our rootstock, but we plan to migrate to Void Linux in future versions of Tamlinux. Beyond that, we are considering a microkernel to further reduce the code size of the rootstock and improve its performance per watt.

Expert definition

The product configuration and packages selected for a workstation; component versions and installed cultivar metadata answer different identity questions.
