Make

A classic build automation tool.

Novice definition

Make is a program that runs the steps needed to build software, rebuilding only what changed.

Learner definition

Make reads a Makefile of targets, prerequisites, and recipes and updates targets when dependencies are newer.

Expert definition

GNU Make is a dependency-driven build tool with pattern rules, variables, and timestamp or phony target semantics.
