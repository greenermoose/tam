LMDE (Linux Mint Debian Edition)

Linux Mint variant built directly on Debian Stable rather than Ubuntu.

Novice definition

LMDE is a version of Linux Mint based directly on Debian instead of Ubuntu.

Learner definition

Mint maintains LMDE as an independent Debian-based fallback alongside its main Ubuntu-based edition.

Expert definition

Debian-stable-tracked distribution using Cinnamon desktop and Mint tooling.
