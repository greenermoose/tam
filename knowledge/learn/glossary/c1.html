C1 (8-bit Control Characters)

Control character range 0x80-0x9F in 8-bit encodings, including single-byte CSI (0x9B).

Novice definition

C1 is a set of 8-bit control codes (bytes 0x80 to 0x9F) from older terminals that UTF-8 terminals no longer treat as commands.

Learner definition

In ISO 8859-1, bytes 0x80-0x9F are 8-bit shortcuts for ESC sequences (such as 0x9B for ESC [). In UTF-8, those bytes are invalid as standalone controls.

Expert definition

ECMA-48 / ISO 2022 C1 set (0x80-0x9F), equivalent to 7-bit ESC + 0x40-0x5F (e.g., 0x8F = SS3, 0x9B = CSI, 0x9D = OSC, 0x9C = ST). Disabled in UTF-8 mode to avoid colliding with multibyte sequences.
