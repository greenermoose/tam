Assembler

A program that translates assembly language into machine code.

Novice definition

An assembler turns human-readable assembly instructions into the binary instructions a CPU runs.

Learner definition

An assembler maps mnemonics and operands to instruction encodings, resolving labels and relocations.

Expert definition

An assembler is a language translator for an instruction set, producing object files with sections, symbols, and relocation records.
