Library

Reusable code that programs can call.

Novice definition

A library is a collection of ready-made code that programs use instead of writing everything themselves.

Learner definition

A library provides functions or objects linked into or loaded by a program, either statically or dynamically.

Expert definition

A library is a collection of compiled objects and symbols with a defined interface, packaged as an archive or shared object.
