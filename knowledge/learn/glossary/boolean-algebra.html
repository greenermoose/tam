Boolean algebra

The mathematics of true and false values.

Novice definition

Boolean algebra is a way of calculating with yes-or-no values using AND, OR, and NOT.

Learner definition

Boolean algebra defines rules for combining binary variables; it is the basis for logic circuits and program conditions.

Expert definition

Boolean algebra is a complemented distributive lattice over the values 0 and 1, with operations AND, OR, and NOT satisfying De Morgan laws and absorption.
