Permission mode

A mode describes who is allowed to read, change, or run stored information.

Beginner definition

Permission bits that say who can read, write or execute a file.

Intermediate definition

Owner, group and other rwx bits plus special bits; directory execute permits search.

Expert definition

The permission component of st_mode, distinct from file type; credentials, ACLs, mount options and security policy also affect access.
