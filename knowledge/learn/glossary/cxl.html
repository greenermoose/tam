CXL (Compute Express Link)

High-speed cache-coherent interconnect layered over PCIe 5.0/6.0 for memory and accelerators.

Novice definition

CXL is a modern high-speed expansion standard built on PCIe that lets CPUs share memory directly with accelerators and memory expanders.

Learner definition

Running over PCIe physical lanes with low-latency FLITs and CRC error detection, CXL supports Type 1/2/3 devices.

Expert definition

Cache-coherent protocol suite (CXL.io, CXL.cache, CXL.mem) over PCIe 5.0+ physical layer using 528-bit FLITs.
