Encryption

Scrambling data so only authorized people can read it.

Novice definition

Encryption turns readable data into a secret code that can be unlocked with the right key.

Learner definition

Encryption uses a cipher and key to make data confidential; decryption reverses it with the correct key.

Expert definition

Encryption is a reversible cryptographic transformation providing confidentiality, with authenticated modes also protecting integrity.
