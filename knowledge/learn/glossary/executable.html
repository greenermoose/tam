Executable

A file the computer can run as a program.

Novice definition

An executable is a file that contains a program the system can start.

Learner definition

An executable is a binary or script with execute permission and a recognized format, loaded by the kernel or interpreter.

Expert definition

An executable is an ELF or other loadable image with an entry point and segments, or a script whose interpreter is invoked by the kernel.
