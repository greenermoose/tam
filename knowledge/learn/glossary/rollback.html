Rollback

A rollback is a return to an earlier working state using a recovery procedure.

Beginner definition

Returning to a known earlier software state using its recovery procedure.

Intermediate definition

The recovery layer must match the change: native packages, a recorded product assembly or a user-tool selection.

Expert definition

An immutable generation does not capture all mutable data or boot state. A complete recovery contract records those boundaries separately.
