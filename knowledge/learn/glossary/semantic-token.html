Semantic token

A named design value such as surface or accent.

Novice definition

A semantic token is a named style choice, like background or warning, that themes can change consistently.

Learner definition

Semantic tokens map meaning to design values so components do not hard-code colors or spacing.

Expert definition

A semantic token is an abstract design variable with roles, aliases, and resolved values, enabling theming and accessibility across components.
