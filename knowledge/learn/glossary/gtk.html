GTK (GIMP Toolkit)

Cross-platform C widget toolkit widely used by GNOME and Linux desktop applications.

Novice definition

GTK is a popular software toolkit for drawing buttons, menus, and windows on Linux.

Learner definition

GTK3 and GTK4 apps read theme settings from ~/.config/gtk-3.0/ and gtk-4.0/ or gsettings.

Expert definition

LGPL C object-oriented GUI toolkit (GLib/GObject, Cairo/GSK, Pango) supporting native Wayland and X11 backends.
