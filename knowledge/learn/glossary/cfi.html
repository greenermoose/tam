CFI (Control-Flow Integrity)

Compiler and hardware mitigation that stops attackers from redirecting indirect jumps or returns.

Novice definition

CFI is a safety check that makes sure a program only jumps to valid code locations, blocking common memory-hijack attacks.

Learner definition

Compilers like Clang/GCC and hardware features (Intel CET, ARM PAC/BTI) enforce CFI on indirect calls and return addresses.

Expert definition

Forward-edge (indirect call target table) and backward-edge (shadow stack) enforcement restricting control-flow transfers to the static CFG.
