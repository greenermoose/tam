File

A file is a named place to keep information, such as a document or picture.

Beginner definition

A named place to keep information, such as a text document or picture.

Intermediate definition

A file can hold text, program code or other data; a file name is found through a directory.

Expert definition

A regular file is one kind of filesystem object. Other kinds include directories, symbolic links and device files.
