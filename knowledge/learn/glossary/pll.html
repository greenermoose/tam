PLL (Phase-Locked Loop)

Feedback circuit synchronizing an oscillator's frequency and phase to a reference clock.

Novice definition

A PLL is a timing circuit that locks a fast internal clock steadily to a slower reference crystal.

Learner definition

CPUs, GPUs, DisplayPort transmitters, and CDR receivers all use PLLs to multiply and stabilize clock frequencies.

Expert definition

Closed-loop control system (phase detector, loop filter, VCO, divider) synthesizing low-jitter GHz clocks.
