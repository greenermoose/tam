ECMA-48

International standard for terminal control functions and ANSI escape sequences.

Novice definition

ECMA-48 is the shared rulebook that tells terminals how to move the cursor, change text colors, and encode special keys.

Learner definition

ECMA-48 (also published as ISO/IEC 6429) defines the escape-sequence grammar—such as CSI and SGR codes—used by Linux consoles and terminal emulators.

Expert definition

Ecma International standard ECMA-48 (5th ed., 1991; ISO/IEC 6429:1992) specifies C0/C1 control characters, 7-bit (ESC [) and 8-bit (0x9B) CSI introducers, parameter bytes (0x30-0x3F), intermediate bytes (0x20-0x2F), and final bytes (0x40-0x7E).
