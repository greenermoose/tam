NRZ (Non-Return-to-Zero)

Binary line coding holding high/low voltage for the entire bit period without returning to zero.

Novice definition

NRZ is the simplest wire signal: stay high for 1 and stay low for 0 across each bit tick.

Learner definition

Because long runs of 1s or 0s in raw NRZ have no transitions for clock recovery, links add 8b/10b or scrambling.

Expert definition

2-level baseband line code (PAM-2) requiring scrambling or block coding (8b/10b, 64b/66b) to bound run length and DC wander.
