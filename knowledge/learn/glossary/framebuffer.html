Framebuffer

A framebuffer is a region of computer memory that holds the color values for every pixel displayed on a screen.

Beginner definition

A digital canvas stored in memory where each dot (pixel) on your monitor is represented by a set of numbers that describe its color and brightness.

Intermediate definition

A contiguous block of memory allocated in system RAM or dedicated Video RAM (VRAM) that is continuously scanned by display hardware to generate video signals for an external monitor. Linux exposes basic framebuffers through the /dev/fb0 device and modern DRM framebuffers.

Expert definition

A structured memory surface configured with horizontal resolution, vertical resolution, color depth, pixel format (such as XRGB8888), and stride (pitch). In modern composited desktops, applications render into private off-screen buffers that the Wayland compositor composites into a primary scanout framebuffer presented to display timing controllers.
