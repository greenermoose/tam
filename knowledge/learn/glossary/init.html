Init

The first user-space program that starts system services.

Novice definition

Init is the first ordinary program the kernel starts; it brings up the rest of the system.

Learner definition

Init runs as process 1, adopts orphaned processes, and starts service management or system initialization.

Expert definition

Init is the user-space process with PID 1 that mounts remaining filesystems, starts services, and reaps orphaned children.
