SHA-1

Legacy 160-bit cryptographic hash function broken against collision attacks.

Novice definition

SHA-1 is an older 160-bit digital fingerprint algorithm that is no longer safe for security signatures.

Learner definition

Part of SHA algorithms; SHA-1 has practical collision attacks and is rejected for modern TLS and SSH.

Expert definition

160-bit Merkle-Damgard hash (FIPS 180-4); collision resistance broken (SHAttered 2017, chosen-prefix 2020), retained only for legacy non-security checksums.
