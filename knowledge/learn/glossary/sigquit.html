SIGQUIT (Quit signal)

Signal (3) sent by Ctrl+\ to terminate a process and produce a core dump.

Novice definition

SIGQUIT is a stronger quit signal (sent with Ctrl+\) that stops a program and can save a crash snapshot for debugging.

Learner definition

Part of Unix signals, SIGQUIT (3) is triggered by VQUIT (Ctrl+\) in the terminal line discipline.

Expert definition

POSIX signal 3 (SIGQUIT); default action is termination with core dump (subject to RLIMIT_CORE and systemd-coredump).
