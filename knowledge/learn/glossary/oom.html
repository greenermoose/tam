OOM (Out of Memory)

Condition when system RAM and swap are exhausted, forcing the kernel OOM killer to terminate a process.

Novice definition

OOM ('Out of Memory') happens when programs use up all RAM and swap, forcing Linux to close a memory-hungry app to save the system.

Learner definition

zram and systemd-oomd (using PSI memory pressure) prevent hard OOM freezes before the kernel OOM killer strikes.

Expert definition

Kernel memory exhaustion triggering page-allocator OOM killer (mm/oom_kill.c) ranked by oom_score, or proactive userspace systemd-oomd.
