SCI (Software Carbon Intensity)

Metric defined by ISO/IEC 21031 measuring carbon emissions per functional unit of software.

Novice definition

SCI is a score estimating how many grams of CO2 a software task causes for each unit of work it performs.

Learner definition

See ISO/IEC 21031 for the standard formula combining energy, grid intensity, and hardware.

Expert definition

ISO/IEC 21031 rate metric SCI = ((E * I) + M) / R encouraging energy efficiency, carbon-aware scheduling, and hardware longevity.
