LMS (Leighton-Micali Signature)

Stateful hash-based post-quantum signature scheme (RFC 8554 / NIST SP 800-208).

Novice definition

LMS is a quantum-safe signature method using hash trees, often used to verify firmware updates.

Learner definition

Paired with HSS (Hierarchical Signature System), LMS is standardized in RFC 8554 and NIST SP 800-208.

Expert definition

RFC 8554 stateful Merkle-tree signature using LM-OTS one-time keys; faster verification than XMSS at the cost of state management.
