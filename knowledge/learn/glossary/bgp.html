BGP (Border Gateway Protocol)

Core routing protocol connecting independent networks (autonomous systems) across the internet.

Novice definition

BGP is the internet's postal routing system that tells major networks which path sends traffic to each IP address.

Learner definition

Because classic BGP trusts announcements, RPKI adds cryptographic origin validation to prevent route hijacking.

Expert definition

Path-vector inter-domain routing protocol (RFC 4271) over TCP port 179 exchanging AS_PATH and NLRI prefixes.
