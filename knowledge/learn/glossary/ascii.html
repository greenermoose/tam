ASCII - American Standard Code for Information Interchange

A seven-bit character encoding for basic English text.

Novice definition

ASCII is an old character code that gives numbers to letters, digits, punctuation, and control keys.

Learner definition

ASCII defines 128 code points in seven bits, including English letters, digits, punctuation, and control characters.

Expert definition

ASCII is a seven-bit character set standardized in ANSI X3.4; it remains a subset of Unicode and UTF-8.
