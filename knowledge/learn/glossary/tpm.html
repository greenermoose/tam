TPM

A chip that stores cryptographic keys and measurements.

Novice definition

A TPM is a small security chip that keeps keys safe and helps prove the computer started correctly.

Learner definition

A Trusted Platform Module provides sealed keys, random numbers, and platform measurements for secure boot and disk encryption.

Expert definition

A TPM is an isolated cryptographic processor implementing PCRs, sealed objects, attestation identities, and a restricted command set.
