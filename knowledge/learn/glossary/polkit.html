Polkit

A framework for authorizing privileged desktop actions.

Novice definition

Polkit is the system that decides whether a user may perform an administrative action, often prompting for a password.

Learner definition

PolicyKit authorizes D-Bus and system actions through subjects, actions, rules, and authentication agents.

Expert definition

polkit is an authorization framework with actions, implicit and explicit rules, subjects, and authority-backed authentication.
