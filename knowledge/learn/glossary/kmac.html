KMAC (Keccak Message Authentication Code)

Variable-length MAC and PRF built directly on SHA-3/cSHAKE (NIST SP 800-185).

Novice definition

KMAC is a modern message authentication tag built directly on the SHA-3 sponge design.

Learner definition

Unlike HMAC (which wraps a hash twice), KMAC absorbs the key directly into the Keccak sponge.

Expert definition

NIST SP 800-185 keyed XOF/MAC (KMAC128, KMAC256) parameterized by cSHAKE with domain separation.
