Serial Communication

Serial communication is transmitting data sequentially one bit at a time over a single wire or channel.

Novice definition

Sending information like a line of cars on a single-lane road: each bit follows directly behind the previous one. Because it requires fewer wires and avoids timing mix-ups between wires, serial communication is used in nearly all modern computer connections, including USB, PCIe, and internet cables.

Learner definition

A data transmission method where bits of a byte or word travel sequentially along a single conductor or differential pair. It completely avoids inter-signal clock skew, enabling modern serial standards (PCIe, SATA, USB 4) to run at gigahertz frequencies that parallel buses cannot achieve.

Expert definition

High-speed point-to-point signaling implemented via Serializer/Deserializer (SerDes) architectures. Data streams incorporate embedded clocking through Clock Data Recovery (CDR) and transition-dense line encodings, allowing multi-gigabit throughput across single differential pairs.
