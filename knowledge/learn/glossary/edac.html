EDAC (Error Detection and Correction)

Linux kernel subsystem that logs and reports hardware memory (ECC) and bus errors.

Novice definition

EDAC is the Linux system that watches for and logs hardware memory errors on ECC-capable computers.

Learner definition

Check /sys/devices/system/edac/mc/ to see whether your memory controller tracks corrected or uncorrected ECC errors.

Expert definition

Linux kernel EDAC driver framework (drivers/edac/) reading memory-controller scrubbing and SECDED/Chipkill error counters.
