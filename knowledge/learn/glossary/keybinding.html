Keybinding

A key or key combination that runs an action.

Novice definition

A keybinding is a shortcut, like Meta+Enter, that tells the desktop to do something.

Learner definition

A keybinding maps a key event or chord to an action in a compositor or application.

Expert definition

A keybinding is a configured mapping from modifiers and keysyms or keycodes to a command, with grab and repeat semantics.
