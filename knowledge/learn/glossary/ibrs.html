IBRS (Indirect Branch Restricted Speculation)

CPU hardware mitigation restricting speculative indirect-branch prediction across privilege levels.

Novice definition

IBRS is a CPU security feature that stops one program or user mode from tricking the processor's branch predictor inside the kernel.

Learner definition

Used alongside Retpoline to mitigate Spectre v2, Enhanced IBRS (eIBRS) enforces isolation in hardware.

Expert definition

x86 MSR_IA32_SPEC_CTRL bit 0 preventing lower-privilege branch target buffer (BTB) entries from controlling kernel speculative execution.
