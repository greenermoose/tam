STX (Start of Text, 0x02)

ASCII 0x02 control character (Ctrl+B).

Novice definition

STX is an old serial control code (byte 0x02) that marked the start of message text; today Ctrl+B sends this byte.

Learner definition

Part of the C0 control codes, STX (Ctrl+B) is used as the default prefix key in tmux.

Expert definition

ASCII 0x02 (STX). Paired with ETX (0x03) for serial frame delimiting; in terminal multiplexers it is intercepted by tmux as its default prefix.
