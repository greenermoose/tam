Windows NT (New Technology kernel)

Hybrid kernel architecture underlying all modern Microsoft Windows versions.

Novice definition

Windows NT is the core operating system architecture behind modern Windows.

Learner definition

Designed as a layered hybrid kernel with a Hardware Abstraction Layer (HAL) and executive subsystems, NT contrasts with Linux's monolithic kernel.

Expert definition

Microsoft NT kernel architecture (ntoskrnl.exe) using object manager, IRP-based I/O, and hybrid microkernel-inspired executive.
