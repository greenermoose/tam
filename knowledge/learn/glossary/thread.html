Thread

A sequence of instructions that can run independently.

Novice definition

A thread is one path of execution inside a program, like a separate task the CPU can switch to.

Learner definition

A thread is a schedulable unit of execution with its own registers and stack, sharing memory with other threads in a process.

Expert definition

A thread is a kernel or user scheduling entity with an instruction pointer, stack, register context, and shared address space.
