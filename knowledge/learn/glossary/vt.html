VT (Virtual Terminal / Virtual Console)

Kernel-provided text console (tty1-ttyN) or historical DEC Video Terminal.

Novice definition

A VT (virtual terminal) is one of Linux's built-in full-screen text consoles you can switch to with Ctrl+Alt+F1..F6.

Learner definition

In Linux, VT refers to the kernel's virtual console subsystem (/dev/tty1..tty63); historically, it also refers to DEC's VT100/VT220 hardware terminals.

Expert definition

Linux kernel Virtual Terminal subsystem (drivers/tty/vt/) multiplexing physical keyboard (evdev/kbd) and display (fbcon/drm) across /dev/ttyN sessions via ioctl VT_ACTIVATE.
