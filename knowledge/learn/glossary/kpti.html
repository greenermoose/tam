KPTI (Kernel Page-Table Isolation)

Kernel mitigation against Meltdown that unmaps kernel memory while user programs run.

Novice definition

KPTI hides the Linux kernel's memory map whenever normal apps are running so speculative CPU bugs cannot peek at kernel secrets.

Learner definition

Introduced to mitigate Meltdown (CVE-2017-5754), KPTI separates user and kernel page tables at the cost of extra TLB flushes.

Expert definition

Linux x86_64 page-table split (formerly KAISER) keeping only minimal trampoline mappings in user CR3.
