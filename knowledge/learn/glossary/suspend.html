Suspend

A low-power sleep state that keeps memory alive.

Novice definition

Suspend puts the computer to sleep quickly; it wakes when you press a key or open the lid.

Learner definition

Suspend saves state in RAM and powers down most devices, resuming through firmware and kernel wake paths.

Expert definition

Suspend is an ACPI sleep state such as S3 or s2idle, preserving RAM while gating clocks and devices, with wake-source configuration.
