DRM

The Linux kernel subsystem for graphics devices.

Novice definition

DRM is the part of Linux that talks to graphics cards and manages displays.

Learner definition

Direct Rendering Manager provides GPU device nodes, memory management, command submission, and mode setting.

Expert definition

DRM is a kernel subsystem with GEM/TTM memory objects, render nodes, atomic modesetting, and driver-specific ioctls.
