PRF (Pseudorandom Function)

Keyed deterministic function whose outputs are indistinguishable from a truly random function.

Novice definition

A PRF is a keyed math function that turns inputs into outputs that look completely random to anyone without the key.

Learner definition

HMAC and HKDF act as PRFs to derive session keys and authentication tags safely.

Expert definition

Keyed family F_K: {0,1}^n -> {0,1}^m computationally indistinguishable from a uniform random function to any PPT oracle adversary.
