Store path

The immutable path where Nix keeps a build result.

Novice definition

A store path is the folder in /nix/store where Nix keeps one built package or file.

Learner definition

A Nix store path contains a content hash and package name, such as /nix/store/hash-name, and is read-only after creation.

Expert definition

A store path is a content-addressed directory under the Nix store whose hash derives from its inputs and outputs, making it immutable and shareable.
