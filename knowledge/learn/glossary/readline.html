Readline

A library for editable command-line input.

Novice definition

Readline is the library that gives shells and other programs line editing, history, and completion.

Learner definition

GNU Readline provides terminal line editing, history, and programmable completion for interactive programs.

Expert definition

Readline is a line-editing library using terminfo and keymaps, with Emacs and vi modes, history expansion, and completion hooks.
