Fetch

To retrieve an instruction or data.

Novice definition

To fetch is to go get the next instruction or piece of data the computer needs.

Learner definition

Fetch reads an instruction from the address in the program counter, or reads data from memory or cache.

Expert definition

Fetch is the front-end pipeline stage that reads instruction bytes through the MMU and cache hierarchy and advances the program counter.
