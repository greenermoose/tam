TPM 2.0 (Trusted Platform Module 2.0)

Hardware security chip specification (ISO/IEC 11889) for key sealing and measured boot.

Novice definition

TPM 2.0 is the modern version of the security chip on your motherboard that can seal disk-encryption keys to safe boot states.

Learner definition

systemd-cryptenroll --tpm2-device=auto binds LUKS2 unlock keys to TPM 2.0 PCR measurements.

Expert definition

TCG TPM Library Specification 2.0 (ISO/IEC 11889): algorithm-agile successor to TPM 1.2 supporting SHA-256 PCRs, ECC, and policy sessions.
