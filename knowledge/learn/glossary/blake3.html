BLAKE3

Tree-structured, SIMD-parallelizable cryptographic hash function.

Novice definition

BLAKE3 is an ultra-fast modern hash function designed to use all CPU cores and SIMD lanes at once.

Learner definition

Built as a Merkle tree over BLAKE2s-derived chunks, BLAKE3 achieves multi-gigabyte-per-second hashing on modern CPUs.

Expert definition

Single-algorithm Merkle-tree hash/KDF/XOF using 7-round BLAKE2s compression over 1 KiB chunks for SIMD and multithreaded parallelism.
