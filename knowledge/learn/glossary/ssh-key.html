SSH key

A cryptographic key used for secure remote login.

Novice definition

An SSH key is a digital key that lets you log in to another computer without typing a password.

Learner definition

An SSH key pair has a private key kept locally and a public key installed on servers for authentication.

Expert definition

An SSH key is a public-key credential, commonly Ed25519 or RSA, used in SSH user or host authentication and signing.
