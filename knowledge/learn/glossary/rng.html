RNG (Random Number Generator)

Hardware or software source producing unpredictable or statistical random numbers.

Novice definition

An RNG is anything that produces unpredictable numbers, from dice rolls to CPU noise circuits.

Learner definition

Hardware TRNGs gather physical entropy, while cryptographic software uses a CSPRNG for keys.

Expert definition

Encompasses physical TRNGs (ring-oscillator jitter, RDRAND) and algorithmic PRNGs/CSPRNGs; only CSPRNGs are valid for key generation.
