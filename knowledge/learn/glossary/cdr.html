CDR (Clock and Data Recovery)

Receiver circuit extracting both timing clock and data bits from a single high-speed serial stream.

Novice definition

CDR lets a high-speed cable (like USB or DisplayPort) send data without needing a separate clock wire.

Learner definition

Using a PLL locked to signal transitions, CDR recovers the bit clock from 8b/10b or 128b/132b encoded streams.

Expert definition

Phase-locked / bang-bang receiver loop tracking bit-cell center from embedded transitions in serdes links.
