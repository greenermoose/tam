URL (Uniform Resource Locator)

Standardized web or resource address specifying scheme, host, and path.

Novice definition

A URL is the full address of a web page or online file, like https://example.com/page.

Learner definition

Defined by RFC 3986, a URL includes a scheme (https://, file://, flake:), authority, path, and optional query.

Expert definition

RFC 3986 / WHATWG Uniform Resource Locator identifying network or local resources by scheme and hierarchical path.
