ENQ (Enquiry, 0x05)

ASCII 0x05 control character (Ctrl+E).

Novice definition

ENQ is an old teletype code (byte 0x05) asking the other machine 'who are you?'; today Ctrl+E sends this byte.

Learner definition

Part of the C0 control codes, ENQ (Ctrl+E) jumps to the end of the line in Readline.

Expert definition

ASCII 0x05 (ENQ). Historically triggered a terminal answerback string; in modern shells it is bound to end-of-line.
