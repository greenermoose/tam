MMU - Memory Management Unit

The hardware that translates virtual addresses to physical memory.

Novice definition

The MMU is the part of the processor that maps the addresses a program uses to real memory locations.

Learner definition

The memory management unit translates virtual addresses through page tables and enforces memory access permissions.

Expert definition

A memory management unit is an address-translation and protection unit, often including a TLB and page-table walker.
