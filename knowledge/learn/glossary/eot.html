EOT (End of Transmission, 0x04)

ASCII 0x04 control character (Ctrl+D), signaling end-of-file in terminals.

Novice definition

EOT is the byte (0x04) sent when you press Ctrl+D to tell a terminal program you are done typing.

Learner definition

Part of the C0 control codes, EOT is mapped to VEOF in canonical mode, causing read() to return 0 bytes (EOF).

Expert definition

ASCII 0x04 (EOT). Under ICANON, VEOF (0x04) flushes the input line without a newline; on an empty line it yields a zero-byte read (EOF).
