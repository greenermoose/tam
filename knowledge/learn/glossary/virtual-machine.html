Virtual machine

A software-defined computer.

Novice definition

A virtual machine is a computer simulated by software, with its own operating system and virtual hardware.

Learner definition

A virtual machine runs a guest OS on virtual CPUs, memory, and devices provided by a hypervisor.

Expert definition

A virtual machine is an isolated guest execution environment with virtualized privileged state, memory mappings, and device model.
