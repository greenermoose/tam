TDX (Trust Domain Extensions)

Intel hardware confidential-computing technology isolating guest VMs from the host OS.

Novice definition

Intel TDX is a CPU feature that runs a virtual machine inside a hardware-encrypted enclave hidden from the host.

Learner definition

Comparable to AMD SEV-SNP, TDX pairs memory encryption with remote attestation of the guest boot state.

Expert definition

Intel Trust Domain Extensions using MKTME memory encryption and a CPU-attested TDX module to isolate Trust Domains.
