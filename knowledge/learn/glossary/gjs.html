GJS (GNOME JavaScript)

JavaScript runtime bindings for GNOME/GTK/GObject introspection.

Novice definition

GJS lets developers write GNOME extensions and desktop widgets in JavaScript.

Learner definition

Powered by SpiderMonkey and GObject Introspection, GJS underlies GNOME Shell extensions and AGS.

Expert definition

GNOME JavaScript engine embedding Mozilla SpiderMonkey with libgirepository bindings.
