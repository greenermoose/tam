Capability

A fine-grained permission a process can hold.

Novice definition

A capability is a specific permission, such as the ability to bind a low network port, without being fully root.

Learner definition

Linux capabilities split root privilege into named bits that can be granted to processes and files.

Expert definition

A capability is a per-thread credential bit in the Linux capability sets permitted, effective, inheritable, bounding, and ambient, checked by the kernel.
