Baud Rate

Baud rate is the speed at which a communication channel changes electrical signal states.

Novice definition

How many times per second the electrical signal on a communication line changes its state or voltage, measured in baud. If each signal change represents one single bit, the baud rate is the same as the bit rate; if each change carries multiple bits, bit rate is higher than baud rate.

Learner definition

The symbol transmission rate of a physical communication channel (symbols per second). In binary baseband signaling (like standard RS-232 UART), one symbol equals one bit, so 115200 baud equals 115200 bits per second. In multi-level modulation schemes (like PAM-4 or QAM), each symbol carries multiple bits.

Expert definition

The modulation rate S of a channel, constrained by Nyquist's theorem (S ≤ 2B where B is channel analog bandwidth). Symbol transitions dictate line clock recovery and transmission line frequency characteristics.
