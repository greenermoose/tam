CSPRNG (Cryptographically Secure Pseudorandom Number Generator)

Random-number generator whose output is unpredictable even if past outputs are observed.

Novice definition

A CSPRNG is a special random-number generator strong enough to create secret encryption keys and passwords.

Learner definition

On Linux, getrandom(2) and /dev/urandom provide a kernel CSPRNG seeded from hardware entropy.

Expert definition

Deterministic generator satisfying next-bit unpredictability and backtracking resistance; Linux uses ChaCha20-based DRBG seeded via BLAKE2s entropy pool.
