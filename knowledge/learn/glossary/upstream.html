Upstream

The original project that software comes from.

Novice definition

Upstream is the original source of a program, before a distro or vendor changes it.

Learner definition

Upstream refers to the original maintainers and repository from which downstream packages are derived.

Expert definition

Upstream is the authoritative source project and release stream against which patches, bugs, and versions are compared.
