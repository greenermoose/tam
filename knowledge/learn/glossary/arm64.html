ARM64 (AArch64)

64-bit ARM processor architecture used in modern servers, phones, and Apple Silicon.

Novice definition

ARM64 is the 64-bit version of the power-efficient ARM processor family.

Learner definition

While Tamlinux currently targets x86_64 (AMD64), Linux and C11 codebases keep ARM64 portability in mind.

Expert definition

ARMv8-A / ARMv9-A 64-bit execution state (AArch64) with 31 general-purpose 64-bit registers and fixed 32-bit instruction encoding.
