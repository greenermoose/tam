JIT (Just-In-Time compilation)

Compiling bytecode or scripts into native machine code at runtime for speed.

Novice definition

JIT compilation translates script or bytecode into fast native CPU instructions right while a program is running.

Learner definition

LuaJIT, JavaScript V8, and the kernel eBPF JIT all use runtime code generation (often with W^X memory protection).

Expert definition

Dynamic runtime translation from IR/bytecode to native ISA with trace/method compilation and inline caching.
