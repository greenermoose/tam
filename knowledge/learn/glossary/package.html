Package

A package is a named collection of software that can be installed and managed.

Beginner definition

A manager's named unit of software.

Intermediate definition

A manager tracks package contents and versions; identifying the selected executable still requires checking PATH and wrappers.

Expert definition

A package identity is distinct from a running process and from an assembly pin. Recovery should name the manager, immutable outputs and any mutable state.
