Package

A package is a named collection of software that can be installed and managed.

Novice definition

A named unit of software that a package manager can install, upgrade or remove. On Tamlinux you may meet native Arch packages and Nix-built Tamlinux assemblies. Asking which manager owns a file is safer than guessing.

Learner definition

A manager tracks package contents and versions; identifying the selected executable still requires checking PATH and wrappers. Development installs under ~/.local/dev can hide packaged binaries. See package versions.

Expert definition

A package identity is distinct from a running process and from an assembly pin. Recovery should name the manager, immutable outputs and any mutable state. Deployed Tamlinux software should arrive through a recorded assembly, not an untracked copy from a checkout.
