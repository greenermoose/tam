IDE - Integrated Development Environment

A program that combines coding, building, and debugging tools.

Novice definition

An IDE is an all-in-one app for writing, running, and fixing code.

Learner definition

An integrated development environment combines an editor, build integration, debugger, and project navigation.

Expert definition

An IDE is an integrated tooling environment with language services, build and debug adapters, version-control integration, and workspace state.
