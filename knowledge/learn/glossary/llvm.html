LLVM

Modular compiler infrastructure powering Clang, Rust, Zig, and Mesa shader compilers.

Novice definition

LLVM is a modern toolkit of compiler building blocks behind Clang, Rust, and many GPU shader compilers.

Learner definition

LLVM uses a shared Intermediate Representation (IR) so different front-end languages can share optimizers and CPU backends.

Expert definition

Modular SSA-based compiler framework (LLVM IR, opt passes, LLD linker, libFuzzer, Sanitizers).
