DIMM - Dual In-Line Memory Module

A memory module that plugs into a motherboard.

Novice definition

A DIMM is a small board holding memory chips that you plug into a computer's memory slot.

Learner definition

A dual in-line memory module packages DRAM chips with contacts on both sides for a memory channel.

Expert definition

A DIMM is a printed circuit module with DRAM devices, SPD data, and edge contacts, installed in a parallel memory channel.
