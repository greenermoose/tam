SRAM

A fast memory technology that holds bits in circuits.

Novice definition

SRAM is very fast memory used in caches; it keeps a bit stable as long as power is on.

Learner definition

Static RAM stores each bit in a bistable transistor circuit, needing no refresh and trading density for speed.

Expert definition

SRAM is volatile memory built from cross-coupled inverters; it is used for caches, registers, and small on-chip buffers.
