FUSE (Filesystem in Userspace)

Linux kernel module allowing unprivileged programs to implement custom filesystems in userspace.

Novice definition

FUSE lets regular programs—like sshfs or archive mounters—act like disk drives without adding code to the Linux kernel.

Learner definition

The /dev/fuse device forwards VFS calls from the kernel to a userspace daemon.

Expert definition

Kernel VFS proxy (fs/fuse/) forwarding file operations over /dev/fuse to userspace handlers.
