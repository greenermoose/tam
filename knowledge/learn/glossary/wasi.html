WASI (WebAssembly System Interface)

Capability-based POSIX-like system interface for sandboxed WebAssembly modules.

Novice definition

WASI is a safe boundary that lets sandboxed WebAssembly programs read only the exact files or folders you grant them.

Learner definition

Unlike traditional Linux processes that inherit a user's full permissions, WASI uses capability-based file descriptors.

Expert definition

Bytecode Alliance capability-oriented syscall ABI for Wasm runtimes (Preview 1/Preview 2 Component Model).
