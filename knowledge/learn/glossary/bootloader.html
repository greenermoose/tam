Bootloader

A small program that starts the operating system.

Novice definition

A bootloader is the first program that runs after firmware and loads the operating system kernel.

Learner definition

A bootloader locates, loads, and starts a kernel, often offering a menu and passing boot parameters.

Expert definition

A bootloader is a chain-loaded program that initializes the environment, loads kernel and initramfs images, and transfers control with a defined boot protocol.
