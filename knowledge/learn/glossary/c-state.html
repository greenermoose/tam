C-state

A processor power-saving state.

Novice definition

A C-state is a low-power sleep mode a CPU enters when it has nothing to do.

Learner definition

C-states range from C0, fully active, to deeper states that gate clocks and power while increasing wake latency.

Expert definition

C-states are ACPI processor idle states with entry and exit latency, residency, and wake behavior, selected by the cpuidle governor.
