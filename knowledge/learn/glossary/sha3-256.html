SHA3-256

256-bit hash function from the NIST FIPS 202 SHA-3 family.

Novice definition

SHA3-256 is the 256-bit member of the SHA-3 hash family.

Learner definition

Part of SHA algorithms, SHA3-256 produces a 256-bit digest using the Keccak sponge.

Expert definition

FIPS 202 SHA3-256 with rate r=1088 bits and capacity c=512 bits over Keccak-f[1600].
