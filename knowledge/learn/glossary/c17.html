C17 (ISO C17)

2018 bug-fix revision of the C11 programming language standard.

Novice definition

C17 is a minor 2018 update to C11 that fixed wording bugs without adding new language features.

Learner definition

Part of the C standards family, C17 clarifies C11 defect reports while keeping the same syntax and library.

Expert definition

ISO/IEC 9899:2018 (informally C17/C18); technical corrigenda and defect-report resolutions over C11.
