POODLE (Padding Oracle On Downgraded Legacy Encryption)

2014 padding-oracle attack against SSL 3.0 CBC mode.

Novice definition

POODLE was an attack on outdated SSL 3.0 encryption that forced its permanent retirement.

Learner definition

Attackers downgraded TLS to SSL 3.0 and used CBC padding errors to decrypt bytes one at a time.

Expert definition

CBC padding oracle exploiting unauthenticated padding bytes in SSL 3.0; mitigated by disabling SSL 3.0 and using TLS_FALLBACK_SCSV / TLS 1.3.
