Fontconfig

The Linux library that finds and configures fonts.

Novice definition

Fontconfig is the system that picks which font to use for text and lets you set font preferences.

Learner definition

Fontconfig matches font patterns to installed families and applies configuration rules for substitution and rendering.

Expert definition

Fontconfig is a font configuration and matching library using patterns, rules, caches, and XML configuration under /etc/fonts.
