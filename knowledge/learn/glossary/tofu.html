TOFU (Trust On First Use)

Security model that accepts an unverified key on first connection and alerts if it ever changes later.

Novice definition

Trust On First Use means saving a server's fingerprint the very first time you connect and warning you if it changes next time.

Learner definition

SSH uses TOFU by default via ~/.ssh/known_hosts, though DNSSEC SSHFP or out-of-band fingerprints verify the first connection.

Expert definition

Leap-of-faith key-pinning model; vulnerable to active MITM on initial contact but detects subsequent key substitution.
