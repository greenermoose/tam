Truth table

A table listing every input combination and its output.

Novice definition

A truth table shows what a logic circuit or condition does for every possible yes-or-no input.

Learner definition

A truth table enumerates all input combinations for a Boolean function and the resulting output, making behavior easy to check.

Expert definition

A truth table is an exhaustive tabulation of a Boolean function over its domain, with 2^n rows for n binary inputs.
