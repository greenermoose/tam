Bus

A shared pathway that carries data or control signals.

Novice definition

A bus is a set of wires or a link that lets computer parts exchange information.

Learner definition

A bus carries addresses, data, and control signals between components; modern systems use point-to-point links and fabrics.

Expert definition

A bus is a shared or switched interconnect with arbitration, protocol, width, and timing rules for transferring transactions.
