SSH (Secure Shell)

Encrypted network protocol for remote terminal logins, tunneling, and file transfers.

Novice definition

SSH is a secure tool for logging into another computer's terminal over a network without anyone else seeing your password or commands.

Learner definition

Using public-key authentication and encrypted channels (RFC 4251-4254), SSH replaces unencrypted telnet and rsh.

Expert definition

Secure Shell protocol (TCP port 22, OpenSSH) providing authenticated key exchange, encrypted transport, and multiplexed shell/SFTP/port-forwarding channels.
