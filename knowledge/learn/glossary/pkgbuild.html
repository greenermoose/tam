PKGBUILD

Bash build recipe script used by Arch Linux makepkg to compile and package software.

Novice definition

A PKGBUILD is a short recipe file that tells Arch Linux how to download, compile, and package a program.

Learner definition

makepkg reads PKGBUILD (metadata, source URLs, sha256sums, build(), package()) to produce a .pkg.tar.zst package.

Expert definition

Arch Linux shell-script package specification consumed by makepkg(8) to generate deterministic pacman archives.
