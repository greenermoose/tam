Kernel module

A piece of kernel code that can be loaded at runtime.

Novice definition

A kernel module is a driver or feature that can be added to the running kernel without rebooting.

Learner definition

A loadable kernel module extends the kernel with drivers or subsystems and runs in kernel space.

Expert definition

A kernel module is an ELF object loaded by the kernel, resolving symbols against the kernel and running with kernel privileges.
