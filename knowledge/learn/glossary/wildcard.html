Wildcard

A pattern character that matches other characters.

Novice definition

A wildcard is a stand-in symbol like * that matches any text in a name.

Learner definition

A wildcard is a metacharacter in filename patterns, expanded by the shell or matched by a tool.

Expert definition

A wildcard is a pattern token with language-specific matching rules, such as shell globbing or regular-expression quantifiers.
