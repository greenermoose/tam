PBKDF2 (Password-Based Key Derivation Function 2)

Older CPU-iterative key-derivation function (RFC 8018) now superseded by memory-hard Argon2id.

Novice definition

PBKDF2 is an older method for turning a password into an encryption key by repeating a hash thousands of times.

Learner definition

Because PBKDF2 uses almost no RAM, GPUs can crack it much faster than memory-hard Argon2id.

Expert definition

RFC 8018 PKCS#5 v2.1 iterative HMAC/PRF construction; lacks memory-hardness, retained mainly for legacy FIPS compatibility.
