SONAME (Shared Object Name)

Embedded ELF dynamic tag specifying a shared library's ABI-compatible major name (e.g., libc.so.6).

Novice definition

A SONAME is the versioned name inside a Linux shared library that tells programs which compatible release they need.

Learner definition

When a library breaks its ABI, its SONAME bumps (e.g., libfoo.so.1 -> libfoo.so.2), requiring dependent packages to rebuild.

Expert definition

ELF DT_SONAME dynamic section string recorded into DT_NEEDED of linked executables by ld.
