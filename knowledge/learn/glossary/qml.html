QML (Qt Modeling Language)

Declarative UI language used by Qt 6 and Quickshell for Tamlinux desktop bars and plugins.

Novice definition

QML is a clean, readable layout language used to build Tamlinux's top bar, widgets, and desktop plugins.

Learner definition

Tamlinux plugins run inside Quickshell using QML (Launch.qml), combining declarative UI properties with JavaScript expressions.

Expert definition

Qt 6 declarative reactive UI language compiled/interpreted by QtQuick over OpenGL/Vulkan/EGL Wayland layer-shell surfaces.
