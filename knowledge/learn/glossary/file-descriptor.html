File descriptor

A small number that identifies an open file or stream.

Novice definition

A file descriptor is the ticket number a program uses to refer to an open file, pipe, or socket.

Learner definition

A file descriptor is a per-process integer indexing the kernel's open-file table, with flags and a file offset.

Expert definition

A file descriptor is a process-local handle into the file table, referring to an open file description shared across dup and fork.
