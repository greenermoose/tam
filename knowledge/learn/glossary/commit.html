Commit

A saved snapshot in version control.

Novice definition

A commit is a saved point in a project's history, with a message explaining the change.

Learner definition

A commit records a tree, parent commits, author, timestamp, and message in a version-control system.

Expert definition

A commit is an immutable object in a Merkle DAG, identified by a content hash, with tree, parents, author, committer, and message.
