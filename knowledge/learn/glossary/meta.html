Meta key

The Meta key is the primary modifier key used to control the Tamlinux desktop and its windows.

Beginner definition

The keyboard modifier key (often showing a Windows logo or Apple ⌘) that commands the desktop environment, window layout, and menus.

Intermediate definition

A modifier key introduced at the Stanford AI Lab in 1970 and adopted by MIT and Emacs. On Tamlinux, Meta controls the compositor, tiling, and workspaces without conflicting with application-level Control or Alt shortcuts, replacing the vendor name "Windows key" and the Linux X11 convention "Super key."

Expert definition

The logical modifier corresponding to Linux kernel evdev KEY_LEFTMETA (125) and modifier mask Mod4, dispatched by Wayland compositors for window management actions. Read The Meta key and desktop modifiers for complete hardware mapping and history.
