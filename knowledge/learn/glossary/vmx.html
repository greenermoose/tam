VMX (Virtual Machine Extensions)

Intel VT-x hardware virtualization instruction-set extensions.

Novice definition

VMX is the Linux flag name for Intel's built-in processor support for running virtual machines.

Learner definition

When vmx appears in /proc/cpuinfo, KVM can accelerate guest operating systems directly on the CPU.

Expert definition

Intel VT-x VMX architecture (VMXON, VMLAUNCH, VMRESUME, EPT) isolating guest execution via VMCS.
