L2 cache (Level 2 cache)

Mid-tier per-core (or cluster-shared) CPU cache backing L1.

Novice definition

L2 is the second-fastest memory layer inside a CPU core, holding data that did not fit in L1.

Learner definition

Part of CPU caches, L2 is typically 512 KiB to 2 MiB per core with ~12-15 cycle latency.

Expert definition

Unified instruction/data SRAM cache per core (or Efficiency cluster) absorbing L1 misses before L3/fabric traffic.
