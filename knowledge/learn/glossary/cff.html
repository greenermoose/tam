CFF (Compact Font Format)

Compact outline font format used inside OpenType (.otf) fonts with cubic Bezier curves.

Novice definition

CFF is the compact outline format inside .otf OpenType fonts that draws smooth letter curves.

Learner definition

TrueType (.ttf) uses quadratic curves, whereas CFF/OpenType (.otf) uses PostScript cubic Bezier curves.

Expert definition

Adobe Type 2 charstring outline table ('CFF ' / 'CFF2') embedded in SFNT OpenType containers, rasterized by FreeType.
