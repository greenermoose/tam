API - Application Programming Interface

A defined way for software to call another piece of software.

Novice definition

An API is the set of commands and rules one program offers to another.

Learner definition

An application programming interface specifies functions, types, and behavior that callers can rely on.

Expert definition

An API is a source-level contract of names, signatures, types, and semantics, distinct from the binary ABI that implements it.
