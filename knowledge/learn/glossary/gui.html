GUI

A graphical user interface.

Novice definition

A GUI is the visual way to use a computer with windows, icons, and a mouse.

Learner definition

A graphical user interface presents controls as windows, widgets, and pointer or touch input.

Expert definition

A GUI is an event-driven visual interface built from a display protocol, toolkit, compositor, and accessibility layer.
