ZFS (Zettabyte File System)

Copy-on-write transactional filesystem and volume manager with end-to-end data checksums.

Novice definition

ZFS is an advanced filesystem famous for self-healing data checksums, snapshots, and built-in RAID.

Learner definition

Originating on Solaris and now OpenZFS (on BSD and out-of-tree Linux), ZFS shares many CoW ideas with in-tree Btrfs.

Expert definition

Copy-on-write pooled storage filesystem with Merkle-tree block checksums, RAID-Z, and ARC caching (CDDL-licensed).
