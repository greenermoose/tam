Assembly (Tamlinux)

A recorded bundle of packages and revisions delivered together.

Novice definition

On Tamlinux, an assembly is the recorded set of software versions that belong together for one release.

Learner definition

A Tamlinux assembly records the exact package revisions and build inputs selected from tamlinux-packages, so a deployment can be verified and reproduced.

Expert definition

A Tamlinux assembly is a cryptographic bill of materials pinned from the tamlinux-packages flake, selected by tam-deploy and tied to a Home Manager generation; it is not a checkout or copied payload.
