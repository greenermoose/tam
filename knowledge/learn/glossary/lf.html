LF (Line Feed, 0x0A)

ASCII 0x0A control character (Ctrl+J, '\n') used as the Unix newline.

Novice definition

LF is the Line Feed byte (0x0A) that ends lines in Linux and Unix text files.

Learner definition

Part of the C0 control codes, LF (0x0A) moves down one line; the line discipline translates CR to LF on input (ICRNL) and LF to CR+LF on output.

Expert definition

ASCII 0x0A (LF, '\n', Ctrl+J). Standard POSIX line terminator; ONLCR in termios OPOST maps LF to CR+LF for terminal display.
