CSS (Cascading Style Sheets)

Style-sheet language controlling colors, fonts, and layout in browsers, GTK themes, and Waybar.

Novice definition

CSS is the styling language that sets colors, spacing, and fonts on web pages and many Linux desktop bars.

Learner definition

Both GTK themes and Waybar/Wofi use CSS files to style widgets and apply theme palettes.

Expert definition

W3C declarative styling language (selectors, cascade, box model) adopted by web engines and GTK's CSS engine.
