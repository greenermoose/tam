DCS (Device Control String)

ESC P ... ESC \ sequence for terminal capability queries and device-level protocols.

Novice definition

DCS is a special terminal message starting with Escape and P used by programs to ask the terminal what features it supports.

Learner definition

A Device Control String wraps a structured payload between ESC P and the string terminator ESC \, such as XTGETTCAP terminfo queries.

Expert definition

ECMA-48 Device Control String (7-bit ESC P / 0x1B 0x50, 8-bit 0x90) terminated by ST (ESC \ / 0x9C), used for Sixel graphics, DECRQSS, and XTGETTCAP.
