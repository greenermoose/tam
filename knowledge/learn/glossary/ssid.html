SSID - Service Set Identifier

The name of a Wi-Fi network.

Novice definition

An SSID is the name you see when choosing a Wi-Fi network.

Learner definition

The service set identifier labels a wireless network; multiple access points can share one SSID.

Expert definition

An SSID is an 802.11 network name carried in beacon and probe frames, up to 32 octets, often paired with BSSID and security settings.
