BIOS

The traditional firmware interface on PCs.

Novice definition

BIOS is the old startup firmware that checks hardware and begins booting the operating system.

Learner definition

The Basic Input/Output System initializes hardware and loads a boot sector, using legacy real-mode services.

Expert definition

BIOS is the legacy PC firmware interface with interrupt services and a boot process later superseded by UEFI.
