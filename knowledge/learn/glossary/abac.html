ABAC (Attribute-Based Access Control)

Fine-grained access-control model evaluating attributes of user, resource, action, and environment.

Novice definition

ABAC decides access using context details—like who you are, what file you want, and whether you are logged in locally.

Learner definition

Polkit rules and OPA policies implement ABAC by checking session locality, unit names, and user attributes.

Expert definition

Policy model evaluating Boolean predicates over subject, object, action, and environmental attributes via PEP/PDP.
