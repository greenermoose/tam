CSI (Control Sequence Introducer)

ESC [ (or 0x9B) prefix starting ECMA-48 parameterized terminal control sequences.

Novice definition

CSI is a two-byte signal (Escape followed by [) that starts most terminal commands for cursor keys, colors, and screen control.

Learner definition

Defined by ECMA-48, a CSI sequence carries numeric parameters separated by semicolons and ends with a final byte such as A, H, m, or ~.

Expert definition

ECMA-48 Control Sequence Introducer: 7-bit ESC [ (0x1B 0x5B) or 8-bit 0x9B, followed by 0x30-0x3F parameter bytes, 0x20-0x2F intermediate bytes, and a 0x40-0x7E final byte.
