AGS (Aylur's GTK Shell)

JavaScript/TypeScript widget framework over GTK3/GTK4 for building Wayland desktop shells.

Novice definition

AGS is a toolkit for building custom Linux desktop bars and widgets using JavaScript on top of GTK.

Learner definition

Tamlinux chose Quickshell (QML/Qt6) over AGS/EWW for its desktop bar and plugin system.

Expert definition

Astal/GJS-based Wayland shell framework binding GTK layer-shell surfaces to reactive TypeScript/JS widgets.
