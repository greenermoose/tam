dGPU - Discrete Graphics Processing Unit

A separate graphics processor with its own memory.

Novice definition

A dGPU is a graphics chip on its own card or chip package, separate from the main processor.

Learner definition

A discrete GPU has dedicated VRAM and cooling, offering more performance than integrated graphics.

Expert definition

A discrete graphics processing unit is a separate GPU device with its own memory and power delivery, linked by PCIe or another fabric.
