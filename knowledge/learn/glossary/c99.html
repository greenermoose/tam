C99 (ISO C99)

1999 C standard adding stdint.h, inline functions, and designated initializers.

Novice definition

C99 is the 1999 update to the C language that added exact-size integers and single-line // comments.

Learner definition

Part of the C standards family, C99 added <stdint.h>, <stdbool.h>, inline functions, and compound literals.

Expert definition

ISO/IEC 9899:1999; introduced restrict, VLAs, flexible array members, and IEEE 754 Annex F floating-point support.
