DSP (Digital Signal Processor / Processing)

Specialized math processing (or dedicated chip) for filtering, equalizing, and decoding continuous signals.

Novice definition

DSP is specialized fast math used to clean up audio, radio, and high-speed cable signals.

Learner definition

Modern Ethernet, Wi-Fi, and PAM-4 serdes links rely on DSP chips to cancel echo, crosstalk, and dispersion.

Expert definition

Digital Signal Processing / processor architecture with single-cycle MAC units for FIR/IIR filtering, FFTs, and equalization.
