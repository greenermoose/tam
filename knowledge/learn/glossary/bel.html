BEL (Bell, 0x07)

ASCII 0x07 control character (Ctrl+G) triggering an alert and terminating OSC sequences.

Novice definition

BEL is the byte (0x07) that originally rang a teletype bell and now triggers a visual flash or beep in terminals.

Learner definition

Part of the C0 control codes, BEL (0x07) is also accepted by xterm-compatible terminals as a terminator for OSC sequences.

Expert definition

ASCII 0x07 (BEL, Ctrl+G). Sounds/flashes the terminal alert and serves as the legacy single-byte terminator for OSC sequences alongside ST (ESC \).
