DAG (Directed Acyclic Graph)

Dependency graph with one-way arrows and no circular loops, used by Nix, Git, and build tools.

Novice definition

A DAG is a flowchart of steps or dependencies that always moves forward and never loops back on itself.

Learner definition

Nix store paths, Git commit history, and Make build targets all form DAGs so build order is unambiguous.

Expert definition

Directed graph G=(V,E) admitting a topological ordering; guarantees termination in dependency resolution and Merkle histories.
