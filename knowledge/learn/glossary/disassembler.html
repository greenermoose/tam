Disassembler

A tool that turns machine code back into assembly.

Novice definition

A disassembler shows the assembly instructions hidden inside a compiled program.

Learner definition

A disassembler reads binary machine code and prints equivalent assembly mnemonics and operands.

Expert definition

A disassembler performs instruction decoding and control-flow recovery, producing assembly with addresses and often symbols, without reconstructing source.
