Program

A program is a set of instructions a computer can follow.

Beginner definition

A set of instructions a computer can run to do a task.

Intermediate definition

A program stored on disk is different from a process: a process is an instance that is running.

Expert definition

A program can consist of an executable and other files; multiple processes can run the same program independently.
