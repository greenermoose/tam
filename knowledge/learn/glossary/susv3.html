SUSv3 (Single UNIX Specification v3)

2001 unified standard combining POSIX.1-2001 and the Single UNIX Specification.

Novice definition

SUSv3 is a standard that ensures Unix-like operating systems share the same core commands and programming interfaces.

Learner definition

Compiling with _XOPEN_SOURCE=600 selects SUSv3 / POSIX.1-2001 interfaces such as termios and standard directory functions.

Expert definition

Single UNIX Specification Version 3 (IEEE Std 1003.1-2001 / ISO/IEC 9945:2002). Unifies POSIX.1, POSIX.2, and X/Open Portability Guide; requested in glibc/musl via _XOPEN_SOURCE=600.
