DMA - Direct Memory Access

Hardware that moves data without the CPU copying it.

Novice definition

DMA lets a device transfer data directly to or from memory while the CPU does other work.

Learner definition

Direct memory access uses a controller to move blocks between devices and RAM, raising throughput and reducing CPU load.

Expert definition

DMA is a bus-mastering or programmed I/O mechanism that transfers data between memory and peripherals using addresses and completion interrupts.
