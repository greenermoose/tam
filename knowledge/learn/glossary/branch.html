Branch

A movable line of development.

Novice definition

A branch is a separate line of work in a project, such as a feature or release line.

Learner definition

A branch is a named reference to a commit that advances as new commits are added.

Expert definition

A branch is a mutable ref pointing to a commit, providing a movable head for a line of history; Git branches are not separate directories.
