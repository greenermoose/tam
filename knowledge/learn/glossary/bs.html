BS (Backspace, 0x08)

ASCII 0x08 control character (Ctrl+H) moving the cursor one column left.

Novice definition

BS is the byte (0x08) that moves the terminal cursor one space to the left; Ctrl+H also sends it.

Learner definition

Part of the C0 control codes, BS (0x08) often collides with Backspace keybindings because modern terminals send DEL (0x7F) for Backspace.

Expert definition

ASCII 0x08 (BS, Ctrl+H). Moves the active cursor left by one column without erasing; terminfo kbs distinguishes whether the Backspace key emits 0x08 or 0x7F.
