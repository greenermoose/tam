Kitty keyboard protocol

Modern terminal key-reporting protocol using CSI code ; modifier u.

Novice definition

The Kitty keyboard protocol is a modern way for terminals to report exact key presses, releases, and modifier combos without old ASCII collisions.

Learner definition

Supported by foot and Kitty, it uses CSI u sequences so editors can distinguish Esc from Ctrl+[ and detect key-release events.

Expert definition

Progressive enhancement protocol (enabled via CSI > flags u, queried via CSI ? u) encoding keys as CSI unicode-key-code : alternate ; modifiers : event-type ; text u.
