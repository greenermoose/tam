QR code (Quick Response code)

2D matrix barcode with built-in Reed-Solomon error correction.

Novice definition

A QR code is a square black-and-white grid barcode that phone cameras can read even if part of it is smudged.

Learner definition

QR codes use Reed-Solomon error correction (7% to 30% recovery) so links or Wi-Fi credentials scan reliably.

Expert definition

ISO/IEC 18004 2D matrix symbology with finder patterns, timing tracks, and Reed-Solomon GF(2^8) FEC.
