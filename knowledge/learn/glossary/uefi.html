UEFI

UEFI is the modern firmware interface that starts when you turn the computer on, before Linux runs.

Beginner definition

UEFI (Unified Extensible Firmware Interface) replaces older BIOS firmware on most PCs. It initializes hardware and loads a bootloader from the EFI System Partition. Tamlinux boot teaching starts at this firmware step.

Intermediate definition

UEFI provides boot entries, Secure Boot hooks, and runtime services. The firmware selects an EFI application such as a bootloader; that program then loads a kernel or unified kernel image. Evidence for early failure often lives in firmware setup screens and EFI variables, not in Linux logs yet.

Expert definition

The platform firmware interface that performs early hardware init and loads EFI boot applications before the operating system.
