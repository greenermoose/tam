Monospace

A font whose characters have equal width.

Novice definition

A monospace font gives every letter the same width, which lines up code and tables neatly.

Learner definition

Monospace fonts use uniform advance widths, making columns align in terminals and source code.

Expert definition

A monospace font has equal horizontal metrics for all glyphs, often with programming ligatures and careful ambiguity design.
