Secure Boot

A firmware feature that verifies boot software signatures.

Novice definition

Secure Boot makes the computer refuse to start software that is not signed by a trusted key.

Learner definition

UEFI Secure Boot validates signatures on bootloaders and kernels against firmware key databases.

Expert definition

Secure Boot is a UEFI verification chain using PK, KEK, db, and dbx, with shim and machine-owner keys extending trust to Linux.
