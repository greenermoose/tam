Errexit

A shell option that stops after a failed command.

Novice definition

Errexit is a shell setting that makes a script quit when a command fails.

Learner definition

set -e enables errexit, exiting on an unhandled nonzero command status, with important exceptions in conditions and pipelines.

Expert definition

errexit is a POSIX shell option with nontrivial suppression rules in conditionals, &&/|| lists, pipelines, and subshells.
