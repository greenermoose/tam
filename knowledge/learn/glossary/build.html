Build

The process of turning source into runnable software.

Novice definition

To build is to take source code and produce a program or package.

Learner definition

A build runs configuration, compilation, linking, and packaging steps, often orchestrated by a build system.

Expert definition

A build is a reproducible or incremental derivation of artifacts from sources, inputs, and toolchain under declared rules.
