MAC - Message Authentication Code

A short tag made with a secret key to prove a message was not altered.

Novice definition

A MAC is a tamper-evident seal created with a shared secret key so the receiver knows the message is genuine and unchanged.

Learner definition

Unlike a plain hash, a MAC requires a secret key to compute and verify, preventing an attacker from forging a matching tag for a modified message.

Expert definition

A keyed algorithm (Tag, Verify) satisfying existential unforgeability under chosen-message attack (EUF-CMA), instantiated via HMAC, CMAC, GMAC, or Poly1305.
