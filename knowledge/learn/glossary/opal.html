Opal (TCG Opal Self-Encrypting Drive)

Trusted Computing Group standard for hardware-accelerated encryption inside NVMe and SATA SSDs.

Novice definition

TCG Opal is a standard for SSDs that encrypt data inside the drive's own controller chip.

Learner definition

While LUKS2 supports Opal hardware offload, software dm-crypt AES-XTS is often preferred because drive firmware cannot be audited.

Expert definition

TCG Storage Architecture Core / Opal SSC 2.0 specification for hardware self-encrypting drives (SEDs).
