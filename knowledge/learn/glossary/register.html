Register

A tiny, very fast storage location inside a processor.

Novice definition

A register is a small slot inside the CPU that holds a value the processor is working on right now.

Learner definition

Registers are the fastest storage in a CPU and hold operands, addresses, and control state for instructions.

Expert definition

A register is a fixed-width storage element in the processor's register file or control unit, named by the instruction set architecture.
