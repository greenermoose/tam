ASN.1 (Abstract Syntax Notation One)

Interface description language used to encode X.509 certificates and cryptographic keys.

Novice definition

ASN.1 is a structured data format used inside digital security certificates and cryptographic keys.

Learner definition

X.509 certificates and PKCS keys are defined in ASN.1 and serialized into bytes using DER (Distinguished Encoding Rules).

Expert definition

ITU-T X.680 / X.690 schema and TLV encoding (BER/DER) underpinning X.509, OCSP, and PKCS structures.
