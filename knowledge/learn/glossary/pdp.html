PDP (Policy Decision Point)

Access-control component that evaluates authorization policies and returns permit or deny.

Novice definition

A PDP is the 'rulebook judge' in an access-control system that decides whether a user's request is allowed.

Learner definition

In ABAC and XACML/OPA architectures, the Policy Enforcement Point (PEP) intercepts requests and asks the PDP.

Expert definition

Authorization architecture component (RFC 2904 / XACML) evaluating subject, resource, action, and environment attributes.
