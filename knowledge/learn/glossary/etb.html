ETB (End of Transmission Block, 0x17)

ASCII 0x17 control character (Ctrl+W) marking a data block boundary or word erase.

Novice definition

ETB is a control byte (0x17) that marked the end of a data block; in shells, Ctrl+W erases the previous word.

Learner definition

Part of the C0 control codes, ETB (0x17) is mapped to VWERASE in the kernel line discipline.

Expert definition

ASCII 0x17 (ETB, Ctrl+W). Marks intermediate block boundaries in serial framing; default VWERASE in Linux termios.
