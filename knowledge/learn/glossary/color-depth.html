Color depth

The number of bits used to describe a pixel's color.

Novice definition

Color depth is how many shades of color a pixel can store, such as 8 bits per channel.

Learner definition

Color depth is the bit allocation per pixel or channel, determining the number of representable colors.

Expert definition

Color depth is the bit precision of color components and alpha, often 24-bit true color or 30/36/48-bit deep color.
