Compositor

A compositor is the program that draws windows on the screen and decides where they go.

Novice definition

On a Wayland desktop, the compositor combines application windows into the image you see, handles focus, and reads key and pointer events. Tamlinux currently uses Hyprland as its compositor. If the compositor fails, windows may freeze or the screen may go blank even though text consoles still work.

Learner definition

A Wayland compositor implements the server side of Wayland, manages outputs via KMS/DRM, and schedules clients. It is distinct from the shell (panels and menus) and from individual applications. Blank-screen diagnosis asks whether the compositor process, its session, or a client failed.

Expert definition

The Wayland display server process that composites client surfaces onto outputs and dispatches input; Hyprland is Tamlinux's current compositor.
