NVMe - Non-Volatile Memory Express

A fast protocol for storage over PCIe.

Novice definition

NVMe is the modern language SSDs use to talk to a computer over PCIe, making them very fast.

Learner definition

NVM Express is a command protocol designed for non-volatile memory over PCIe, with deep queues and low overhead.

Expert definition

NVMe is a scalable host-controller interface and command set for non-volatile memory, using queue pairs and PCIe transport.
