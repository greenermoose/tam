RISC-V - Reduced Instruction Set Computing V

An open processor instruction set.

Novice definition

RISC-V is a free, open instruction set that anyone can use to design processors.

Learner definition

RISC-V is a modular RISC ISA with a small base and optional extensions, developed openly.

Expert definition

RISC-V is an open, extensible ISA with base integer variants and standard extensions, specified without licensing restrictions.
