HTML (HyperText Markup Language)

Standard markup language for web pages and tam's offline knowledge corpus.

Novice definition

HTML is the tag-based file format used for web pages and also for the pages in Tamlinux's offline guide.

Learner definition

tam renders semantic HTML pages (<section data-level>, <dl>, <pre>) directly into terminal text.

Expert definition

WHATWG/W3C markup language; tam's knowledge corpus uses a strict semantic HTML5 subset validated by tools/build-index.py.
