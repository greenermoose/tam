AVX (Advanced Vector Extensions)

256-bit SIMD instruction-set extension for x86_64 processors.

Novice definition

AVX lets an x86_64 CPU process 256 bits of numbers in a single instruction for faster math, media, and AI.

Learner definition

Older laptops may lack AVX or AVX2, which is why Tamlinux builds baseline binaries for generic x86_64 unless tuned locally.

Expert definition

Intel/AMD 256-bit YMM vector ISA extension (Sandy Bridge / Bulldozer onward); see also AVX2.
