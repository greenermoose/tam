CISC - Complex Instruction Set Computing

A processor design style with rich, complex instructions.

Novice definition

CISC is a design where the CPU understands many complex instructions that each do a lot of work.

Learner definition

Complex instruction set computing uses variable-length instructions and memory operands to reduce program size.

Expert definition

CISC is an ISA philosophy with rich addressing modes and multi-step instructions, often decoded into micro-operations internally.
