Clean-room testing

Testing in a fresh, uncontaminated environment.

Novice definition

Clean-room testing means checking software on a fresh system with no leftover settings or files.

Learner definition

Clean-room testing builds or installs from scratch in an isolated environment to catch hidden dependencies.

Expert definition

Clean-room testing reproduces the target environment from declared inputs, excluding developer state, caches, and unrecorded host artifacts.
