Rootstock

In Tamlinux, rootstock means the kernel and core system software on which the cultivar software depends.

Beginner definition

Rootstock is not a common term, but one that Fred made up to explain how Tamlinux works. Fred defines the rootstock to be the set of software that third-parties publish and is necessary to be installed so that the software he writes can function properly. The cultivar is the software in the Tamlinux release that depends on the rootstock to allow the computer to be used effectively and efficiently by both humans and AI agents. The goal is to minimize the size of the rootstock and maximize its speed and efficiency.

Intermediate definition

Currently your system uses Arch Linux as the rootstock, but Fred plans to migrate to Void Linux in future versions. Beyond that, he is considering a microkernel to further reduce the code size of the rootstock and improve its performance per watt.

Expert definition

The rootstock provides hardware drivers, kernel services, and core system libraries under its native package manager (such as pacman on Arch or xbps on Void). The Tamlinux cultivar layer installs on this foundation without modifying distribution files under /usr. Minimizing rootstock code size and isolating runtime components improves security, hardware longevity, and performance per watt.
