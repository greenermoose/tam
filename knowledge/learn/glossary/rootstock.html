Rootstock

In Tamlinux, rootstock means the kernel and core system software on which the Tamlinux cultivar is installed.

Beginner definition

Rootstock is not a common term, but one that Fred Horch, the Tamlinux developer, made up to explain how Tamlinux works. Fred defines the rootstock to be the set of software that third-parties publish and is necessary to be installed so that the software we write can function properly. The Tamlinux cultivar is all the software in the Tamlinux release that allows the computer to be used effectively and efficiently by both humans and AI agents. Our goal is to minimize the size of the rootstock and maximize its speed and efficiency.

Intermediate definition

Currently we are using Arch Linux as our rootstock, but we plan to migrate to Void Linux in future versions of Tamlinux. Beyond that, we are considering a microkernel to further reduce the code size of the rootstock and improve its performance per watt.

Expert definition

The rootstock provides hardware drivers, kernel services, and core system libraries under its native package manager (such as pacman on Arch or xbps on Void). The Tamlinux cultivar layer is composed above this foundation without modifying distribution files under /usr. Minimizing rootstock code size and isolating runtime components improves security, hardware longevity, and performance per watt.
