Development prefix

A user-owned directory for test installs.

Novice definition

A development prefix is a folder in your home where you can install test builds without root.

Learner definition

The development prefix is typically ~/.local/dev, placed first on PATH for development builds and removed after deployment.

Expert definition

A development prefix is an unprivileged install root with its own bin, lib, and generation layout, used for testing and uninstalled after the pinned release is deployed.
