DSO (Digital Storage Oscilloscope)

Bench test instrument that samples and graphs electrical waveforms over time.

Novice definition

A DSO (digital oscilloscope) is a test tool with a screen that draws electrical voltage waves so engineers can inspect signals.

Learner definition

Used in hardware diagnostics to inspect UART baud rates, I2C edges, power-rail ripple, and differential signaling.

Expert definition

ADC-based waveform capture instrument triggering on edge/protocol events with GS/s sampling.
