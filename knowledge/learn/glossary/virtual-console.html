Virtual console

Beginner definition

A Linux kernel terminal surface, often showing a text login. It is different from a terminal window inside the desktop and may be unavailable during a display or kernel fault.

Intermediate definition

A virtual console has a device such as /dev/tty2 and can host a login service. A terminal emulator typically uses a pseudo-terminal such as /dev/pts/0; that number does not identify the graphical console.

Expert definition

Console switching, keyboard input, framebuffer or display-driver state, kernel responsiveness and login-service availability are separate dependencies. A switch request does not prove that rendering or authentication will work.
