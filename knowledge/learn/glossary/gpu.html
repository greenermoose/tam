GPU

A GPU (Graphics Processing Unit) is a specialized electronic chip designed to process and draw images on a computer screen.

Beginner definition

A dedicated processor that handles drawing windows, images, video, and fonts on your computer screen so that the main processor (CPU) does not slow down.

Intermediate definition

A massively parallel processor featuring hundreds or thousands of execution cores designed for high-throughput arithmetic. GPUs excel at operations where the same mathematical calculation is applied across millions of pixels or vertices simultaneously.

Expert definition

A high-throughput SIMD/SIMT (Single Instruction, Multiple Data / Threads) coprocessor paired with high-bandwidth memory (GDDR or HBM). Modern operating systems interact with GPUs through kernel-level direct rendering managers (such as Linux DRM/KMS) and user-space drivers implementing standard APIs like Vulkan, OpenGL, and compute kernels.
