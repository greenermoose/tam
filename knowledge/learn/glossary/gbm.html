GBM (Generic Buffer Management)

Mesa API for allocating GPU scanout and rendering buffers directly on Linux DRM devices.

Novice definition

GBM is the Linux graphics helper that allocates screen buffers directly in GPU memory without needing X11.

Learner definition

Wayland compositors use GBM alongside DRM/KMS and EGL to present frames with zero-copy page flips.

Expert definition

Mesa libgbm API allocating DMA-BUF-backed gbm_bo / gbm_surface objects for KMS scanout and EGL.
