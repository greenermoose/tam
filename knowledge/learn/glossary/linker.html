Linker

A program that combines object files into an executable or library.

Novice definition

A linker joins compiled pieces and libraries into one finished program.

Learner definition

The linker resolves symbols, lays out sections, applies relocations, and produces an executable or shared object.

Expert definition

A linker performs symbol resolution and relocation, combining input sections into output segments according to a linker script or default layout.
