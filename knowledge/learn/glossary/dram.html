DRAM

The common type of main memory that needs refreshing.

Novice definition

DRAM is the memory chip technology used for most computer RAM; it stores each bit as a tiny charge that must be refreshed.

Learner definition

Dynamic RAM stores bits in capacitors and refreshes them continuously; it is dense and inexpensive but slower than SRAM.

Expert definition

DRAM is volatile memory using capacitive storage and sense amplifiers, organized in banks, rows, and columns with periodic refresh.
