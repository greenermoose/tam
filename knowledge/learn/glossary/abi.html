ABI

The binary rules for calling and representing data.

Novice definition

An ABI is the low-level agreement about how compiled programs pass data and call each other.

Learner definition

An application binary interface defines calling conventions, register use, data layout, and symbol mangling for a platform.

Expert definition

An ABI specifies the machine-level contract: calling convention, stack layout, object format, syscall numbers, and type sizes.
