IOMMU (Input-Output Memory Management Unit)

Hardware unit translating and isolating DMA addresses from PCIe devices (Intel VT-d / AMD-Vi).

Novice definition

An IOMMU is a security gatekeeper that stops plugged-in devices (like Thunderbolt docks or GPUs) from reading random system RAM.

Learner definition

IOMMU protects against DMA attacks and allows VFIO to pass a physical GPU safely into a virtual machine.

Expert definition

Hardware DMA remapping engine (Intel VT-d / AMD-Vi) enforcing per-device IOVA page tables and interrupt remapping.
