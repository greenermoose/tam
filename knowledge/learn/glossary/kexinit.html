KEXINIT (SSH Key Exchange Initialization)

Initial SSH_MSG_KEXINIT packet advertising supported ciphers, MACs, and key-exchange algorithms.

Novice definition

KEXINIT is the first algorithm menu an SSH client and server send each other to pick compatible encryption.

Learner definition

Defined in RFC 4253, both sides exchange SSH_MSG_KEXINIT lists and pick the first mutually supported algorithm.

Expert definition

SSH transport packet type 20 (RFC 4253) containing cookie, kex_algorithms, server_host_key_algorithms, encryption, MAC, and compression lists.
