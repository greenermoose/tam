Hard link

A second name for the same file.

Novice definition

A hard link is another name for the same file, so both names lead to the same data.

Learner definition

A hard link is a directory entry pointing to an existing inode, increasing its link count; it cannot cross filesystems.

Expert definition

A hard link is a directory entry binding a name to an inode, with link count and unlink semantics; all links are equal.
