TOCTOU (Time-of-Check to Time-of-Use)

Race-condition bug where a resource changes between checking its permissions/state and using it.

Novice definition

TOCTOU is a timing bug where a file or permission changes in the split second between checking it and opening it.

Learner definition

On Linux, opening files with O_NOFOLLOW and descriptor-relative syscalls (openat) prevents symlink TOCTOU races.

Expert definition

Time-of-Check to Time-of-Use race condition (CWE-367); mitigated via dirfd-anchored openat(2)/renameat2(2) and atomic O_CREAT|O_EXCL.
