Distro

A distro (distribution) is a complete Linux operating system assembled from a kernel, system utilities, package manager, and applications.

Beginner definition

Short for distribution: a complete Linux operating system built by assembling the Linux kernel with libraries and programs.

Intermediate definition

Distributions package a kernel, C library, init system, package manager, and desktop or server software into an integrated system. In Tamlinux, the operating system beneath the Tamlinux cultivar is called the rootstock rather than a distro.

Expert definition

Distributions define packaging standards, release cadences, and service supervision. While distro describes independent Linux distributions in general, Tamlinux specifically uses rootstock to describe third-party system software it installs upon.
