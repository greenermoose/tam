Touchscreen

A display that senses touch.

Novice definition

A touchscreen is a screen you can control by touching it directly.

Learner definition

A touchscreen combines a display with a digitizer that reports touch coordinates and gestures.

Expert definition

A touchscreen is an input device using capacitive, resistive, or optical sensing, with axes, pressure, and multitouch event protocols.
