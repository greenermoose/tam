HT (Horizontal Tab, 0x09)

ASCII 0x09 control character (Ctrl+I), advancing to the next tab stop.

Novice definition

HT is the Tab character (byte 0x09), which jumps the cursor forward to the next tab column.

Learner definition

Part of the C0 control codes, HT (0x09) is identical to Ctrl+I in legacy terminal encoding.

Expert definition

ASCII 0x09 (HT, '\t', Ctrl+I). Advances the cursor to the next 8-column hardware/software tab stop unless overridden by OPOST tab expansion.
