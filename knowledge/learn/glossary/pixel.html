Pixel

One small dot in a digital image.

Novice definition

A pixel is one tiny colored dot that makes up a picture on a screen.

Learner definition

A pixel is the smallest addressable picture element in a raster image or framebuffer.

Expert definition

A pixel is a sample in a raster grid with color components and possibly alpha, stored in a defined pixel format.
