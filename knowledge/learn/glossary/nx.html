NX (No-Execute / XD bit)

CPU memory-protection feature marking data pages (stack, heap) non-executable.

Novice definition

NX (No-Execute) is a CPU safety rule that stops the computer from running data—like text or images—as program code.

Learner definition

Combined with W^X (Write XOR Execute) and ASLR, NX prevents classic stack-buffer-overflow shellcode execution.

Expert definition

x86_64 page-table PTE bit 63 (NXE in IA32_EFER) raising #PF on instruction fetch from non-executable pages.
