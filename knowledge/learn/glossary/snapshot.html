Snapshot

A snapshot records the state of stored information at a particular time.

Beginner definition

A saved state of a filesystem subvolume. It can help recover an earlier file, but a copy on the same drive does not protect against loss of that drive.

Intermediate definition

A Btrfs snapshot initially shares file extents with its source subvolume. Later changes can diverge. A snapshot does not recursively include nested subvolumes or separately mounted filesystems.

Expert definition

A snapshot is itself a subvolume with an initial shared extent set and independent identity. Read-only flags, mount selection, excluded subvolumes and application consistency define its recovery boundary; independent backups remain necessary.
