SDP (Service Discovery Protocol / Session Description Protocol)

Bluetooth service-lookup protocol (or streaming Session Description Protocol).

Novice definition

In Bluetooth, SDP is how your laptop asks headphones 'which features (like audio or microphone) do you support?'.

Learner definition

SDP also refers to Session Description Protocol in media streaming; context indicates Bluetooth vs. RTP/WebRTC.

Expert definition

Bluetooth L2CAP PSM 1 Service Discovery Protocol (UUID attribute records) or IETF RFC 8866 Session Description Protocol.
