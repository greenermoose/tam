Pipe

A connection that sends one program's output into another's input.

Novice definition

A pipe connects two commands so the first one's output becomes the second one's input.

Learner definition

A pipe is a unidirectional kernel buffer between processes, created by pipe or a shell | operator.

Expert definition

A pipe is an anonymous inode-backed IPC channel with read and write ends, buffering bytes and signaling EOF when writers close.
