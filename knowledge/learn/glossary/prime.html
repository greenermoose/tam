PRIME (Linux GPU Buffer Sharing)

Linux DRM/DMA-BUF mechanism for sharing rendered frames between an iGPU and dGPU.

Novice definition

PRIME lets a laptop with two graphics chips (integrated + discrete) render a game on the fast GPU and show it on the built-in screen.

Learner definition

Using DMA-BUF file descriptors, PRIME passes frames from a discrete GPU to the integrated GPU's display controller.

Expert definition

Linux DRM buffer-sharing framework (drm_gem_prime_handle_to_fd) enabling zero-copy cross-GPU scanout.
