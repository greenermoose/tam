OPA (Open Policy Agent)

General-purpose policy engine evaluating authorization rules written in Rego.

Novice definition

OPA is a tool that checks 'is this action allowed?' rules separately from the main application code.

Learner definition

In Policy-Based Access Control (PBAC), a Policy Enforcement Point queries OPA as a Policy Decision Point (PDP).

Expert definition

CNCF policy engine evaluating declarative Rego policies over structured JSON input as a decoupled PDP.
