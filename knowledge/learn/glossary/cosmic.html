COSMIC

Rust-based Wayland desktop environment developed by System76.

Novice definition

COSMIC is a modern open-source Linux desktop environment written in Rust by System76.

Learner definition

Built on iced and smithay (Wayland), COSMIC offers built-in tiling and theming.

Expert definition

System76's Rust Wayland compositor (cosmic-comp) and desktop suite using smithay and libcosmic.
