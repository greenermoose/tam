PID

A process ID is a number used to identify a running program.

Beginner definition

A number identifying a process.

Intermediate definition

A process identifier in a PID namespace; it can be reused after that process exits.

Expert definition

A numeric identifier whose meaning depends on namespace and time. A separate existence check does not eliminate reuse races; stable handles and lifecycle owners can matter.
