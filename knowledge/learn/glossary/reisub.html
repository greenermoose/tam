REISUB (Magic SysRq emergency reboot)

Safe 6-key kernel Magic SysRq sequence to sync disks and reboot a frozen Linux system.

Novice definition

REISUB is an emergency keyboard sequence (Alt+SysRq + R-E-I-S-U-B) that cleanly saves your disks and restarts a frozen Linux PC.

Learner definition

Each letter sends a direct kernel command: unRaw keyboard, tErminate processes, kIll remaining, Sync disks, Unmount read-only, reBoot.

Expert definition

Linux kernel Magic SysRq sequence enabled via sysctl kernel.sysrq; prevents filesystem corruption compared to holding the power button.
