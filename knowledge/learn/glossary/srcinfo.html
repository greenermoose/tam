.SRCINFO

Machine-readable key-value metadata file generated from a PKGBUILD for the AUR.

Novice definition

.SRCINFO is a plain-text summary generated from a PKGBUILD so package tools can read dependencies without running Bash.

Learner definition

Generated via makepkg --printsrcinfo, .SRCINFO lets AUR helpers inspect versions and dependencies safely.

Expert definition

Static INI-like metadata projection of a PKGBUILD required by AUR Git repositories.
