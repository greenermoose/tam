HID (Human Interface Device)

USB and Bluetooth device class for keyboards, mice, touchpads, and FIDO2 keys.

Novice definition

HID is the standard Plug-and-Play protocol that keyboards, mice, and security keys use to talk to Linux.

Learner definition

The kernel hid-generic driver translates HID reports into evdev input events, while FIDO2 keys use /dev/hidraw*.

Expert definition

USB-IF / Bluetooth SIG device class using descriptor-defined report packets; Linux exposes input via usbhid/uhid and raw packets via hidraw.
