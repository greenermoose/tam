RS256 (RSA PKCS#1 v1.5 with SHA-256)

JWS/JWT algorithm identifier for asymmetric RSA signatures using SHA-256.

Novice definition

RS256 is a token-signing method where an auth server signs with a private key and services verify with a public key.

Learner definition

Used in OIDC and JWTs, RS256 lets multiple services verify tokens without sharing a signing secret.

Expert definition

RFC 7518 JWA identifier for RSASSA-PKCS1-v1_5 using SHA-256.
