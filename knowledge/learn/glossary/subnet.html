Subnet

A smaller network carved out of a larger address range.

Novice definition

A subnet is a section of a network, defined by an address and a prefix, that devices can reach directly.

Learner definition

A subnet is an IP address range sharing a prefix length; hosts use it with a netmask to decide local versus routed destinations.

Expert definition

A subnet is a prefix-defined set of addresses; CIDR notation and longest-prefix matching determine routing and on-link scope.
