Bundle

A bundle is all the files of one version of some software, with a name, a version and a fingerprint, installed and removed as one unit.

Novice definition

A complete set of files for one version of a program, kept together so it can be installed, checked and swapped back as one thing.

Learner definition

In tam-bundle, a directory holding a built tree plus two text records: BUNDLE (name, version, hash, sources) and MANIFEST (every path with its mode and SHA-256 hash). Its id is name-version- followed by twelve hash characters.

Expert definition

A content-addressed file set: the bundle hash is SHA-256 over the identity record without its build time, followed by the file list, so identical inputs give an identical id. Unlike a Nix store path it is installed as real files and carries no dependency closure; native needs are only checked.
