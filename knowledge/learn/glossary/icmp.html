ICMP

A network protocol for control and error messages.

Novice definition

ICMP is the network's built-in messaging system for errors and tests like ping.

Learner definition

Internet Control Message Protocol carries error and diagnostic messages for IP, including echo, unreachable, and time exceeded.

Expert definition

ICMP is a network-layer control protocol with typed messages and checksums; ICMPv6 also carries neighbor discovery and router advertisement.
