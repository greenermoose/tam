SIGTERM (Terminate signal)

Default polite termination signal (15) sent by kill.

Novice definition

SIGTERM is the polite 'please shut down' signal sent by the kill command.

Learner definition

Part of Unix signals, SIGTERM (15) lets a program save state and close files before exiting.

Expert definition

POSIX signal 15 (SIGTERM); default signal for kill(1) and systemd service stops before escalating to SIGKILL.
