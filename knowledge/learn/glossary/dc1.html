DC1 (Device Control 1 / XON, 0x11)

ASCII 0x11 control character (Ctrl+Q), used as XON to resume paused terminal output.

Novice definition

DC1 (Ctrl+Q) is the 'resume output' code that unfreezes a terminal paused by Ctrl+S.

Learner definition

Part of the C0 control codes, DC1 acts as XON in software flow control (IXON).

Expert definition

ASCII 0x11 (DC1 / XON, Ctrl+Q). Resumes TTY output suspended by DC3 (XOFF) when IXON is enabled in termios.
