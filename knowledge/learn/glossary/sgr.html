SGR (Select Graphic Rendition)

ECMA-48 CSI ... m sequence controlling terminal text colors and attributes.

Novice definition

SGR is the terminal command that turns text bold, underlined, or colored.

Learner definition

An SGR sequence looks like ESC [ 31 m (red text) or ESC [ 0 m (reset all attributes); terminfo's sgr0 capability emits the reset.

Expert definition

ECMA-48 Select Graphic Rendition (CSI Ps ... m, final byte 0x6D). Supports standard 8/16 colors (30-37, 90-97), 256-color (38;5;n), and 24-bit truecolor (38;2;r;g;b).
