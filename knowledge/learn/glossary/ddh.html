DDH (Decisional Diffie-Hellman)

Hardness assumption that g^(ab) looks indistinguishable from a random group element given g^a and g^b.

Novice definition

DDH is a stronger version of the Diffie-Hellman math assumption: the shared secret looks completely random to outsiders.

Learner definition

Key exchanges like X25519 rely on DDH-like assumptions so shared secrets can be fed directly into key derivation.

Expert definition

Assumption that (g, g^a, g^b, g^(ab)) is computationally indistinguishable from (g, g^a, g^b, g^c) in prime-order groups.
