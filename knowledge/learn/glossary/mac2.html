MAC2 (WireGuard DoS-mitigation cookie)

WireGuard handshake field carrying a rate-limiting cookie under heavy packet-flood load.

Novice definition

MAC2 is a anti-flooding token in WireGuard VPN handshakes that keeps a server responsive during denial-of-service attacks.

Learner definition

When under load, a WireGuard responder replies with a cookie-reply message that the client echoes in mac2.

Expert definition

WireGuard 16-byte XChaCha20-Poly1305 cookie tag authenticating client IP ownership before expensive Curve25519 DH.
