BMC (Baseboard Management Controller)

Dedicated service processor on server motherboards for out-of-band power, fans, and console.

Novice definition

A BMC is a tiny independent computer built onto server motherboards to monitor temperatures and turn the server on remotely.

Learner definition

Running even when the main CPU is powered off, a BMC exposes IPMI or Redfish management over a dedicated network port.

Expert definition

Embedded microcontroller on server boards interfacing with sensors, PSUs, and serial-over-LAN independently of the host OS.
