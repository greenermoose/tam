TLS

The encryption protocol that secures network connections.

Novice definition

TLS is the lock icon technology that encrypts web and other network traffic.

Learner definition

Transport Layer Security negotiates keys and encrypts application data, using certificates for authentication.

Expert definition

TLS is a record-layer protocol with handshake, key schedule, AEAD ciphers, and certificate-based authentication, succeeding SSL.
