Machine code

Machine code is the binary instructions a processor can execute directly.

Novice definition

The raw binary bytes a microprocessor reads and runs. High-level languages such as C are translated into machine code before the CPU can follow them. Assembly language is a human-readable spelling of those same operations.

Learner definition

Machine code is a sequence of opcodes and operands in a specific instruction set (for example x86-64 or ARM64). An assembler maps mnemonics to those bytes one-to-one; a compiler may rearrange higher-level source before emitting them. Tools such as objdump show both the hex bytes and the assembly form. See Assembly language programming and machine code.

Expert definition

Encoded instruction bytes for a particular ISA and execution mode, fetched and decoded by the processor pipeline. Encoding, alignment and calling conventions are ABI and microarchitecture concerns; the same program source can produce different machine code across targets and optimization levels.
