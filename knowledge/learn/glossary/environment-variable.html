Environment variable

A named value passed from a parent process to its children.

Novice definition

An environment variable is a setting such as HOME or PATH that programs inherit when they start.

Learner definition

Environment variables are key-value strings in a process environment, read by libraries and programs for configuration.

Expert definition

An environment variable is an entry in the process environment block, inherited across exec and exposed through getenv and environ.
