DHE (Ephemeral Diffie-Hellman)

Diffie-Hellman key exchange using fresh temporary keys per session for forward secrecy.

Novice definition

DHE creates a brand-new temporary shared secret for every connection so past traffic stays safe even if a server key leaks later.

Learner definition

Modern TLS 1.3 requires ephemeral key exchange (ECDHE or finite-field DHE) to guarantee forward secrecy.

Expert definition

Finite-field ephemeral Diffie-Hellman (RFC 7919); largely superseded by elliptic-curve ECDHE (X25519, P-256) for speed.
