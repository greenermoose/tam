Canonical mode (cooked mode)

Default terminal input mode where the kernel buffers and edits a full line before sending it.

Novice definition

Canonical mode is the normal terminal typing mode where Backspace works and the program only receives your text after you press Enter.

Learner definition

Controlled by the ICANON flag in termios, canonical mode lets the kernel line discipline handle Backspace, Ctrl+U, and Enter.

Expert definition

POSIX termios ICANON mode: the kernel TTY line discipline buffers input up to NL/EOF/EOL, processes ERASE/KILL/WERASE locally, and delivers complete lines on read().
