Cache

A small, fast copy of data kept close to the processor.

Novice definition

A cache is a quick-access store that keeps recently used data so the computer does not have to fetch it from slow memory.

Learner definition

A cache copies frequently used memory or disk data into faster storage and relies on locality to reduce latency.

Expert definition

A cache is a bounded, associative store that exploits temporal and spatial locality, with tag, index, replacement, and coherence metadata.
