CAN (Cancel, 0x18)

ASCII 0x18 control character (Ctrl+X) that cancels an in-progress escape sequence.

Novice definition

CAN is a control byte (0x18) that tells a terminal to abort whatever escape sequence it was reading.

Learner definition

Part of the C0 control codes, CAN (0x18) aborts an incomplete CSI or ESC sequence in ECMA-48 terminals.

Expert definition

ASCII 0x18 (CAN, Ctrl+X). ECMA-48 cancel character: immediately aborts an active escape/control sequence without executing it.
