NOVA (NOVA Microhypervisor)

Capability-based microhypervisor separating virtualization control from small kernel mechanisms.

Novice definition

NOVA is a tiny, security-focused microkernel designed specifically to run isolated virtual machines safely.

Learner definition

By keeping device emulation out of the privileged kernel, NOVA shrinks the virtualization trusted computing base.

Expert definition

OS-oriented capability microhypervisor (Steinberg & Kauer) offloading VMM policy to userspace.
