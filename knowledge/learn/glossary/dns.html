DNS - Domain Name System

The system that turns names into IP addresses.

Novice definition

DNS is the internet's phone book: it looks up a name such as example.com and returns an address.

Learner definition

The Domain Name System resolves hierarchical names to addresses and other records through recursive and authoritative servers.

Expert definition

DNS is a distributed hierarchical database with resource records, delegation, caching, and transport over UDP or TCP, secured by DNSSEC.
