Socket

A software endpoint for network communication.

Novice definition

A socket is the handle a program uses to send and receive network data.

Learner definition

A socket is a kernel object representing an endpoint, with address family, type, protocol, and connection state.

Expert definition

A socket is a file-like abstraction over a transport endpoint, with send and receive buffers, options, and a protocol-specific state machine.
