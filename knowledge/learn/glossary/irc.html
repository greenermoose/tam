IRC (Internet Relay Chat)

Classic real-time text chat protocol used by Linux distributions and open-source developer channels.

Novice definition

IRC is a lightweight, decades-old text chat system still used by many Linux and open-source communities.

Learner definition

Networks like Libera.Chat and OFTC host official channels for Arch, Debian, kernel, and compositor developers.

Expert definition

RFC 1459 / IRCv3 plain-text TCP/TLS channel chat protocol.
