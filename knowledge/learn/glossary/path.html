Path

A path is a name that tells a computer where to find stored information.

Beginner definition

A name that tells the system how to find a file or directory.

Intermediate definition

An absolute path begins with /; a relative path is interpreted from the current directory.

Expert definition

Path resolution follows directory entries and may follow symbolic links; the same object can have more than one name.
