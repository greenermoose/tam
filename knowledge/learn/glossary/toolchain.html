Toolchain

The set of tools used to build software.

Novice definition

A toolchain is the collection of programs that turn source code into a working program.

Learner definition

A toolchain includes a compiler, assembler, linker, libraries, and build tools for a target platform.

Expert definition

A toolchain is a coordinated set of binutils, compiler, libc, and build tools with a target triple, sysroot, and ABI.
