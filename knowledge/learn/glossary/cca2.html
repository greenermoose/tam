CCA2 (Adaptive Chosen-Ciphertext Attack)

Security model where an attacker can query a decryption oracle both before and after seeing a challenge ciphertext.

Novice definition

CCA2 is a strict test for encryption: it stays safe even if an attacker can trick a system into decrypting modified messages.

Learner definition

IND-CCA2 security is required for modern public-key encryption and KEMs so malleability or padding oracles cannot break keys.

Expert definition

Adaptive chosen-ciphertext attack model; see IND-CCA2.
