C11

A version of the C programming language standard.

Novice definition

C11 is a modern version of the C language, adding features such as threads and safer bounds-checked functions.

Learner definition

ISO C11, published in 2011, adds atomics, threads, anonymous structs, and optional bounds-checking interfaces.

Expert definition

C11 is ISO/IEC 9899:2011, including _Atomic, _Thread_local, generic selection, static assertions, and Annex K optional bounds-checked APIs.
