POSIX

The standard that defines Unix-like interfaces.

Novice definition

POSIX is the standard that says how Unix-like systems should behave, so programs can move between them.

Learner definition

POSIX specifies shell, system-call, and C-library interfaces for portable Unix-like software.

Expert definition

POSIX is the IEEE 1003 family of standards defining process, file, shell, thread, and real-time interfaces.
