UV (Ultraviolet / Undervoltage)

Ultraviolet light (in optics/sensors) or undervoltage (power-rail fault).

Novice definition

UV stands for ultraviolet light in optics/biometrics, or undervoltage when a power supply drops too low.

Learner definition

Check page context: hardware diagnostics use UV for ESD/undervoltage, while optical topics refer to ultraviolet wavelengths.

Expert definition

Context-dependent acronym: ultraviolet electromagnetic band (10-400 nm) or undervoltage lockout (UVLO).
