SIGKILL (Kill signal)

Uncatchable signal (9) that immediately terminates a process in the kernel.

Novice definition

SIGKILL is the forced 'stop immediately' signal used when a frozen program ignores normal requests to quit.

Learner definition

Part of Unix signals, SIGKILL (9) cannot be caught or ignored, so the program gets no chance to save unsaved work.

Expert definition

POSIX signal 9 (SIGKILL); handled directly by the kernel scheduler without delivering a signal handler to userspace.
