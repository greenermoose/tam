PCR (Platform Configuration Register)

Tamper-evident TPM register storing cryptographic measurements of boot stages.

Novice definition

A PCR is a special locked counter inside the TPM security chip that records a fingerprint of every step during startup.

Learner definition

LUKS2 + TPM2 auto-unlock seals the disk key to specific PCR values (like PCR 7 for Secure Boot state) so tampering blocks unlock.

Expert definition

TPM 2.0 append-only hash register updated via PCR_Extend(H(old || new)); policies bind keys to expected SHA-256 PCR digests.
