SIGINT (Interrupt signal)

Signal (2) sent by Ctrl+C to interrupt a foreground terminal process.

Novice definition

SIGINT is the 'interrupt' signal sent when you press Ctrl+C to ask a running command to stop.

Learner definition

Part of Unix signals, SIGINT (2) can be caught by programs to clean up temporary files before exiting.

Expert definition

POSIX signal 2 (SIGINT), generated by the N_TTY line discipline upon receiving VINTR (0x03) when ISIG is set.
