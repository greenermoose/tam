ALPN (Application-Layer Protocol Negotiation)

TLS extension that negotiates the application protocol (such as h2 or http/1.1) during the handshake.

Novice definition

ALPN lets a browser and server agree on whether to speak HTTP/2 or HTTP/1.1 during the initial TLS security handshake.

Learner definition

RFC 7301 ALPN avoids an extra network round trip by carrying the protocol list inside the TLS ClientHello.

Expert definition

TLS extension (RFC 7301) carried in ClientHello/EncryptedExtensions to select the inner application protocol before application data flows.
