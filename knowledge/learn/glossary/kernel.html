Kernel

A kernel is the central software that helps programs use a computer and its hardware.

Novice definition

The central part of an operating system that manages hardware and helps programs use it. On Tamlinux today that central part is the Linux kernel. When you run a program, the kernel gives it a process identity, memory, and controlled access to disks, network and displays. See Kernel and processes.

Learner definition

The Linux kernel manages resources such as memory, processes and devices, and offers services to programs through system calls. Drivers may load as modules but still run with kernel privilege on a monolithic design. Faults in a driver can affect the whole machine; separate program faults from kernel or hardware faults with evidence.

Expert definition

Programs request kernel services through system calls; drivers and kernel subsystems mediate access to hardware and other resources. Process existence is not health; mapped executables can outlive on-disk replacements. Design trade-offs between monolithic and microkernel systems are compared in kernels.
