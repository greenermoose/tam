HS256 (HMAC with SHA-256)

JWS/JWT algorithm identifier for symmetric HMAC-SHA256 signatures.

Novice definition

HS256 is a token-signing method where both the sender and verifier share the same secret key.

Learner definition

In JWT/JWS, HS256 uses symmetric HMAC-SHA256, whereas RS256 uses asymmetric RSA signatures.

Expert definition

RFC 7518 JWA identifier for HMAC using SHA-256; requires strict algorithm pinning to avoid alg=none or RS256->HS256 confusion.
