Palette

A chosen set of colors.

Novice definition

A palette is the set of colors a design or image uses.

Learner definition

A palette is a bounded color set, often indexed or generated from semantic roles.

Expert definition

A palette is a color collection with defined roles and values, sometimes quantized or mapped through a color space and theme engine.
