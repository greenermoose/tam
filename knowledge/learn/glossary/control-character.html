Control character

A control character is a code that tells a terminal or a program to do something rather than print a visible symbol.

Novice definition

Control characters are the codes produced by chords such as Ctrl + C and Ctrl + H. Some move the cursor, some send a signal to stop a program, and some are ordinary data that a program interprets for itself.

Learner definition

In ASCII, codes 0x00 to 0x1F and 0x7F are control characters. Holding Ctrl and pressing a letter normally clears bits 5 and 6 of the letter's code, so Ctrl + A is 0x01, Ctrl + H is 0x08, and Ctrl + M is 0x0D. The byte alone does not say what will happen: the terminal, the kernel's line discipline and the receiving program each assign meanings.

Expert definition

The C0 controls are named in ascii(7): NUL, SOH, STX, ETX, EOT, ENQ, ACK, BEL, BS, HT, LF, VT, FF, CR, SO, SI, DLE, DC1, DC2, DC3, DC4, NAK, SYN, ETB, CAN, EM, SUB, ESC, FS, GS, RS, US, followed by DEL at 0x7F. A terminal may treat BS, HT, LF, VT, FF, CR, SO, SI, CAN, SUB, ESC and DEL as commands; the line discipline may treat INTR, QUIT and SUSP as signal requests; and a program may treat any remaining byte as data. 0x08 and 0x7F both mean backspace in different conventions, which is why they collide. In UTF-8, the 8-bit C1 range is encoded as 0xC2 0x80 to 0xC2 0x9F, so a raw 0x9B byte is not valid UTF-8 and modern terminals use ESC [ instead.
