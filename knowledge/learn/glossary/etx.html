ETX (End of Text, 0x03)

ASCII 0x03 control character (Ctrl+C), triggering SIGINT in terminals.

Novice definition

ETX is the byte (0x03) sent when you press Ctrl+C to cancel a running terminal command.

Learner definition

Part of the C0 control codes, ETX is mapped by default to VINTR in the line discipline to send SIGINT.

Expert definition

ASCII 0x03 (ETX). When ISIG is enabled in termios, the kernel TTY line discipline translates 0x03 (VINTR) into SIGINT for the foreground process group.
