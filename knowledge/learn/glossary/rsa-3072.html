RSA-3072

RSA public-key cryptography using a 3072-bit modulus (~128-bit classical security).

Novice definition

RSA-3072 is a high-strength RSA key size (3072 bits) giving about the same classical security as a 128-bit symmetric key.

Learner definition

NIST recommends 3072-bit RSA for 128-bit classical security, though elliptic curves (P-256, Ed25519) achieve this with much smaller keys.

Expert definition

RSA modulus N = pq of 3072 bits (~128-bit GNFS classical security; broken by quantum Shor's algorithm).
