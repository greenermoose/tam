Port

A numbered endpoint for network communication.

Novice definition

A port is a numbered door on a computer that a particular network service listens on.

Learner definition

A transport port identifies a service endpoint within a host, such as TCP 443 for HTTPS.

Expert definition

A port is a 16-bit transport-layer demultiplexing identifier in TCP or UDP, paired with an address and protocol.
