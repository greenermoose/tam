EEPROM - Electrically Erasable Programmable Read-Only Memory

Small rewritable non-volatile memory.

Novice definition

EEPROM is a tiny memory chip that keeps settings when the power is off and can be rewritten electrically.

Learner definition

Electrically erasable programmable ROM stores small configuration data and supports byte-level rewrites.

Expert definition

EEPROM is floating-gate non-volatile memory with electrically erasable cells, often used for SPD, firmware settings, and device descriptors.
