Fallback route

A startup path that avoids a failed component.

Novice definition

A fallback route is a backup way to start the computer when the normal path does not work.

Learner definition

A fallback route changes or bypasses part of the boot chain, such as using an older kernel or external loader.

Expert definition

A fallback route is an alternate boot path selected by firmware, bootloader, or an external image to bypass a failed kernel, initramfs, or configuration.
