Desktop environment

A complete graphical desktop built from several components.

Novice definition

A desktop environment is the full graphical workspace, including panels, settings, file manager, and apps.

Learner definition

A desktop environment bundles a window manager or compositor, shell, settings, and utilities with a consistent interface.

Expert definition

A desktop environment is an integrated session stack of compositor, shell, settings daemons, portal services, and applications sharing a design system.
