Bracketed paste

Terminal mode that wraps pasted text in ESC [ 200 ~ and ESC [ 201 ~ markers.

Novice definition

Bracketed paste tells your editor or shell 'this text was pasted, not typed', so pasted newlines do not accidentally run commands.

Learner definition

Enabled with CSI ? 2004 h, bracketed paste wraps clipboard text in ESC [ 200 ~ ... ESC [ 201 ~ so applications treat pasted bytes as literal text.

Expert definition

xterm DECSET 2004 mode: instructs the terminal emulator to bracket pasted payloads with CSI 200 ~ and CSI 201 ~, mitigating command-injection from multi-line clipboard contents.
