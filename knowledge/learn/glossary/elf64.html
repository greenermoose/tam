ELF64

64-bit variant of the Linux Executable and Linkable Format.

Novice definition

ELF64 is the 64-bit version of Linux's compiled program format.

Learner definition

On x86_64 and ARM64 Tamlinux systems, all native binaries and libraries use ELF64.

Expert definition

64-bit ELF class (EI_CLASS = ELFCLASS64) with 64-bit virtual addresses and Elf64_Phdr/Elf64_Shdr tables.
