ROM - Read-Only Memory

Memory that keeps its contents without power.

Novice definition

ROM is memory that holds permanent startup code and cannot be changed by ordinary programs.

Learner definition

Read-only memory retains data without power; firmware often lives in flash ROM that can be updated.

Expert definition

ROM is non-volatile memory whose contents are fixed at manufacture or rewritten only by special operations, such as mask ROM or flash.
