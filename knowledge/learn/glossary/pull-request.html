Pull request

A request to merge changes into another branch.

Novice definition

A pull request is a proposal to add your changes to a project, where others can review them.

Learner definition

A pull request compares a source branch with a target branch and hosts review, checks, and merge.

Expert definition

A pull request is a forge-level review object referencing commits and refs, with mergeability, checks, and discussion.
