EGL (Embedded-System Graphics Library)

Khronos interface connecting OpenGL ES / OpenGL rendering contexts to Wayland or DRM surfaces.

Novice definition

EGL is the glue layer that lets 3D graphics programs draw into Wayland windows on Linux.

Learner definition

Wayland compositors (like Hyprland) and Qt/Quickshell use EGL over GBM/DMA-BUF instead of legacy X11 GLX.

Expert definition

Khronos native platform interface binding OpenGL/ES contexts to wl_egl_window or GBM surfaces via EGLImage/DMA-BUF.
