AddressSanitizer (ASan)

A fast compiler-based tool that detects memory safety errors in compiled programs.

Novice definition

AddressSanitizer is a helper built into the compiler that spots memory mistakes — like reading past the end of a list or using deleted information — and stops the program immediately with an exact explanation.

Learner definition

AddressSanitizer instruments memory allocations and pointer dereferences at compile time using shadow memory and poisoned redzones to catch buffer overflows, use-after-free, and double-free errors with low runtime overhead (~2×).

Expert definition

AddressSanitizer (ASan) maps one-eighth of the virtual address space to shadow memory, inserts redzones around heap, stack, and global variables, and inlines direct address-validity checks before memory instructions, catching spatial and temporal memory violations at runtime.
