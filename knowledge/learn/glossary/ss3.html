SS3 (Single Shift 3)

ESC O (or 0x8F) prefix used for unparameterized function keys and application cursor keys.

Novice definition

SS3 is a short two-byte prefix (Escape followed by O) that terminals send for keys like F1-F4 or arrow keys in application mode.

Learner definition

Unlike CSI sequences, SS3 sequences carry no numeric parameters—just a single character after ESC O, such as ESC O P for F1.

Expert definition

ECMA-48 Single Shift Three (7-bit ESC O / 0x1B 0x4F, 8-bit 0x8F). Repurposed by DEC VT terminals and xterm for application cursor keys (DECCKM) and PF1-PF4 (F1-F4).
