PAM

A modular framework for authentication.

Novice definition

PAM is the plug-in system Linux uses to check passwords and other login factors.

Learner definition

Pluggable Authentication Modules stack modules for auth, account, password, and session management.

Expert definition

PAM is a shared-library framework with typed module stacks, control flags, and service-specific configuration under /etc/pam.d.
