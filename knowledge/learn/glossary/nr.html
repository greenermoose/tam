NR (New Radio / Non-Return)

5G New Radio cellular standard (or Non-Return in signaling).

Novice definition

5G NR ('New Radio') is the modern 5G wireless standard using OFDM and LDPC error correction.

Learner definition

3GPP 5G NR uses LDPC for data channels and polar codes for control channels.

Expert definition

3GPP Release 15+ 5G New Radio air interface (FR1 sub-6 GHz and FR2 mmWave).
