Repository

A organized store of software or version history.

Novice definition

A repository is a collection of software packages or a store of a project's file history.

Learner definition

A repository can be a package source or a version-control database; both provide named, retrievable content.

Expert definition

A repository is either a signed package index with metadata and artifacts or a Git object database with refs, commits, and reachability rules.
