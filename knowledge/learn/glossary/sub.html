SUB (Substitute, 0x1A)

ASCII 0x1A control character (Ctrl+Z) that aborts escape sequences and triggers SIGTSTP.

Novice definition

SUB is the byte (0x1A) sent when you press Ctrl+Z to pause a running terminal program.

Learner definition

Part of the C0 control codes, SUB (0x1A) triggers SIGTSTP via VSUSP in the line discipline and cancels active escape sequences.

Expert definition

ASCII 0x1A (SUB, Ctrl+Z). ECMA-48 replacement/abort character; default VSUSP in termios, sending SIGTSTP when ISIG is enabled.
