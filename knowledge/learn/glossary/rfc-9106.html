RFC 9106 (Argon2)

IETF specification for the Argon2 memory-hard password-hashing function.

Novice definition

RFC 9106 is the internet standard for Argon2, a modern way to scramble passwords so attackers cannot guess them quickly.

Learner definition

Argon2id requires large amounts of RAM as well as CPU time, making brute-force attacks on GPUs or custom chips expensive.

Expert definition

IETF RFC 9106 (2021) specifies Argon2d (data-dependent), Argon2i (data-independent), and Argon2id (hybrid), with configurable memory cost (m), time cost (t), and parallelism (p).
