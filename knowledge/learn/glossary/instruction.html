Instruction

A single operation a processor can perform.

Novice definition

An instruction is one step in a program, such as add two numbers or load a value from memory.

Learner definition

An instruction is a machine-code operation with an opcode and operands, fetched and executed by the CPU.

Expert definition

An instruction is an ISA-defined operation encoding, including opcode, operand specifiers, and addressing modes.
