HTTPS - Hypertext Transfer Protocol Secure

HTTP protected by TLS.

Novice definition

HTTPS is the secure version of web traffic, encrypted so others cannot read or change it.

Learner definition

HTTPS is HTTP over TLS, providing confidentiality, integrity, and server authentication via certificates.

Expert definition

HTTPS is HTTP transported over TLS, with SNI, ALPN, certificate validation, and optional client authentication.
