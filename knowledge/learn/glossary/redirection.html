Redirection

Changing where a command's input or output goes.

Novice definition

Redirection sends a command's output to a file or takes input from a file instead of the terminal.

Learner definition

Redirection changes file descriptors before exec, connecting stdin, stdout, or stderr to files, pipes, or devices.

Expert definition

Redirection is shell syntax that opens files, duplicates descriptors with dup2, and arranges them before the command runs.
