Userspace

Everything outside the kernel.

Novice definition

Userspace is all the ordinary programs and libraries that run outside the kernel.

Learner definition

User space is the unprivileged execution environment where applications run and request kernel services through system calls.

Expert definition

User space is the processor privilege ring or address region hosting non-kernel code, isolated from kernel memory by the MMU.
