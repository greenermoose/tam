Immutable

Unable to be changed after it is created.

Novice definition

Immutable means something cannot be changed in place; a new version must be made instead.

Learner definition

An immutable store path or image is read-only, so changes create a new object rather than editing the old one.

Expert definition

Immutability is a property of content-addressed or read-only state where identity and bytes are bound, enabling safe sharing, rollback, and verification.
