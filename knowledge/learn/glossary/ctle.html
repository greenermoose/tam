CTLE (Continuous Time Linear Equalizer)

Analog receiver filter boosting attenuated high-frequency edges on long copper links.

Novice definition

CTLE is a signal-sharpening filter inside high-speed receivers (like PCIe or DisplayPort) that restores blurred cable signals.

Learner definition

Because copper cables muffle fast edges more than slow ones, CTLE amplifies high frequencies before sampling.

Expert definition

High-pass peaking analog equalizer compensating channel skin-effect/dielectric insertion loss prior to DFE.
