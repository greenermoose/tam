System call

A request from a program to the kernel.

Novice definition

A system call is how an ordinary program asks the kernel to do something it is not allowed to do itself, such as read a file.

Learner definition

A system call is a controlled entry into the kernel that provides files, memory, processes, networking, and other services.

Expert definition

A system call is an ABI-defined kernel entry point invoked by a trap or special instruction, with a number, arguments, and return convention.
