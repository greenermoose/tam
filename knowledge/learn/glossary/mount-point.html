Mount point

The directory where a filesystem appears.

Novice definition

A mount point is the folder you look inside to see the files on a mounted device.

Learner definition

A mount point is the existing directory at which a filesystem is attached, hiding the directory's previous contents.

Expert definition

A mount point is a path in a mount namespace where a mount is grafted, with propagation and overmount semantics.
