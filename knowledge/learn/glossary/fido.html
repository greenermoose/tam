FIDO

A standard for phishing-resistant authentication.

Novice definition

FIDO is a modern login standard that uses a security key or device instead of a password.

Learner definition

FIDO defines public-key credentials and user-presence checks, including U2F and FIDO2/WebAuthn.

Expert definition

FIDO is an alliance specification family for origin-bound public-key credentials, CTAP authenticators, and WebAuthn ceremonies.
