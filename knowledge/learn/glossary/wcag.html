WCAG (Web Content Accessibility Guidelines)

W3C guidelines for accessible text contrast and readable interfaces.

Novice definition

WCAG is a set of guidelines for making text and interfaces easy to read, including for people with low vision.

Learner definition

Terminal and desktop themes use WCAG contrast ratios—4.5:1 for AA normal text and 7:1 for AAA—to keep text legible.

Expert definition

W3C Web Content Accessibility Guidelines (2.1/2.2) define relative luminance L and contrast ratio (L1 + 0.05) / (L2 + 0.05) thresholds for AA and AAA conformance.
