AMOLED (Active-Matrix Organic Light-Emitting Diode)

Self-emissive OLED display using an active thin-film transistor backplane per pixel.

Novice definition

AMOLED is a type of OLED screen where each pixel lights itself up and is switched individually for deep blacks.

Learner definition

Common on laptops and phones, AMOLED panels turn off black pixels completely, saving power on dark themes.

Expert definition

Active-matrix OLED using LTPS/LTPO TFT pixel circuits to drive organic emitters with near-infinite static contrast.
