XML (eXtensible Markup Language)

Structured tag-based data format used by Fontconfig, SVG, and D-Bus introspection.

Novice definition

XML is a structured text format using <tags> to store settings, such as Linux font-matching rules.

Learner definition

Fontconfig (~/.config/fontconfig/fonts.conf) and SVG icons are written in XML.

Expert definition

W3C hierarchical markup specification used in Fontconfig, D-Bus XML, Wayland protocol definitions, and SVG.
