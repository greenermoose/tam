DDR4 (Double Data Rate 4 SDRAM)

Fourth-generation mainstream system RAM standard (1.2 V, 64-bit channels).

Novice definition

DDR4 is the widely used generation of system RAM in laptops and desktops from roughly 2014 to 2022.

Learner definition

Unlike DDR5, standard consumer DDR4 lacks on-die ECC unless server ECC RDIMMs/UDIMMs are used.

Expert definition

JEDEC JESD79-4 synchronous DRAM at 1.2 V, 1600-3200 MT/s, 8n prefetch, and 64-bit (+8-bit optional ECC) channels.
