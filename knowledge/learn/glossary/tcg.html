TCG (Tiny Code Generator)

QEMU's cross-architecture dynamic binary translator for emulating foreign CPUs without KVM.

Novice definition

TCG is the part of QEMU that translates instructions on the fly so an x86 PC can run ARM or RISC-V software.

Learner definition

TCG is slower than hardware KVM virtualization, but works across completely different CPU architectures.

Expert definition

QEMU's JIT backend translating guest machine code to TCG IR and then to host native instructions.
