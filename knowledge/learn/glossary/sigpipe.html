SIGPIPE (Broken Pipe signal)

Signal (13) sent when a process writes to a pipe or socket whose reader has closed.

Novice definition

SIGPIPE stops a program when the next program in a pipeline (like head) closes early and stops reading.

Learner definition

Part of Unix signals, SIGPIPE (13) cleanly stops producers like yes | head -n 5 without printing an error.

Expert definition

POSIX signal 13 (SIGPIPE), raised on write(2) to a pipe/FIFO/socket with no open read descriptors (or EPIPE if ignored/masked).
