x86

The processor family used by most desktop PCs.

Novice definition

x86 is the family of processors that runs most Windows and Linux desktop computers.

Learner definition

x86 is the Intel 8086-derived instruction set family, now including 64-bit extensions.

Expert definition

x86 is a variable-length CISC ISA with legacy segmentation, paging, and privilege rings, extended by AMD64 and many vector features.
