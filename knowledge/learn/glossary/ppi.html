PPI - Pixels Per Inch

Pixels per inch, a measure of screen density.

Novice definition

PPI is how many pixels fit in one inch of a screen, which affects how sharp text looks.

Learner definition

Pixels per inch is physical pixel density, calculated from resolution and panel size.

Expert definition

PPI is the ratio of pixel count to physical length, while CSS reference pixels and scaling decouple logical sizes from density.
