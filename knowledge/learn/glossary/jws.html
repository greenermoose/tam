JWS (JSON Web Signature)

Standard compact format for digitally signed or MAC-protected JSON payloads (RFC 7515).

Novice definition

JWS is a compact text format for attaching a digital signature to a JSON message.

Learner definition

JWT tokens are usually encoded as a JWS: three Base64URL parts (header.payload.signature) separated by dots.

Expert definition

IETF RFC 7515 signed-payload container supporting symmetric (HS256) and asymmetric (RS256, ES256, EdDSA) algorithms.
