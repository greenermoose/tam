IP address

A numeric address that identifies a network host.

Novice definition

An IP address is the number that identifies a computer on a network, like a postal address for data.

Learner definition

An IP address is an IPv4 or IPv6 address assigned to an interface, used for routing and endpoint identification.

Expert definition

An IP address is a network-layer identifier with prefix and scope; IPv4 uses 32 bits and IPv6 uses 128 bits, often with temporary or link-local variants.
