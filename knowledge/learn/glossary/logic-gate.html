Logic gate

A circuit that performs a basic logical operation.

Novice definition

A logic gate is a tiny decision circuit that combines yes-or-no signals, such as AND, OR, and NOT.

Learner definition

Logic gates implement Boolean operations on bits; combining them builds adders, registers, and processors.

Expert definition

A logic gate is a physical or abstract Boolean function, usually implemented with transistors and characterized by its truth table and propagation delay.
