LLM (Large Language Model)

Neural-network model trained on text to answer questions, summarize, and assist with code.

Novice definition

An LLM is an AI text model—like the local models tam can optionally ask via Ollama—that generates answers from prompts.

Learner definition

In Tamlinux, LLMs are strictly opt-in and run locally via Ollama (tam ask) rather than silently sending data to the cloud.

Expert definition

Transformer-based autoregressive language model; tam invokes local Ollama HTTP endpoints only on explicit user action.
