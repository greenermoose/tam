Protocol

An agreed set of rules for communication.

Novice definition

A protocol is the shared language two programs or devices use to exchange data.

Learner definition

A protocol defines message formats, timing, and state transitions for communication between peers.

Expert definition

A protocol is a formal specification of syntax, semantics, and state machine behavior, often layered and versioned.
