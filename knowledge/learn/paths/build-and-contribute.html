Capstone

Build and run a small program in a fresh temporary directory, make a small change to its source, and build and run it again. Then propose a source correction: name the repository and files, a test that detects the problem, and a verification and handoff. Do not modify the live system.

This example requires an installed C compiler. Paste the whole block in a shell; it removes only the two files it creates and then the empty directory.

if task_dir=$(mktemp -d); then
    printf '%s\n' '#include <stdio.h>' 'int main(void) { return puts("hello") < 0; }' > "$task_dir/hello.c"
    if cc "$task_dir/hello.c" -o "$task_dir/hello"; then
        "$task_dir/hello"
        printf '%s\n' '#include <stdio.h>' 'int main(void) { return puts("hello tam") < 0; }' > "$task_dir/hello.c"
        if cc "$task_dir/hello.c" -o "$task_dir/hello"; then
            "$task_dir/hello"
        else
            printf '%s\n' 'Second compilation failed.'
        fi
    else
        printf '%s\n' 'Compilation failed.'
    fi
    rm -- "$task_dir/hello.c"
    if [ -f "$task_dir/hello" ]; then rm -- "$task_dir/hello"; fi
    rmdir -- "$task_dir"
else
    printf '%s\n' 'Could not create a temporary directory.'
fi

On success the first build prints hello; after the source change, the second prints hello tam.

Captured on Arch Linux, 2026-10-27. If compilation fails, read its error. If cleanup fails, inspect the retained directory; do not recursively delete unexpected files. For an illustrative documentation correction, identify the owning source file, claim the required paths, and use a rendering or link check as verification. Follow the repository's instructions before committing or submitting anything.
