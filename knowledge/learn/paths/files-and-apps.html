Files and applications

These guides show how Tamlinux organizes your home directory, USB drives, permissions, and graphical or terminal applications.

Stage 1: Locate, read, and check files

Start by learning where personal documents sit, how to search inside text safely read-only, and how file owners work.

Check yourself

Should you save everyday documents in /tmp?

No. /tmp is for temporary scratch data and may be cleared across reboots; store lasting work under your home directory.

Stage 2: Launch and inspect apps

Open apps from menus or a terminal so diagnostic output is visible if something fails to start.

Check yourself

Why launch a misbehaving graphical program from a terminal once?

The terminal shows standard error messages that a menu launcher hides.
