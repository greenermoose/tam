Files and applications

This path shows where files live, how to find and move them safely, and how to open or install the applications that use them. It starts with the home folder and a temporary practice directory.

Practice in temporary folders and on copies. A move, extraction or removal is hard to undo once it succeeds, so read the listing before you act on real documents.

Checkpoint

Answer these before you go on.

Should everyday documents be saved in /tmp?

No. /tmp is scratch space and may be cleared across reboots. Lasting work belongs under your home directory.

chmod printed nothing. Did it fail?

Not necessarily. Many successful commands are silent. Inspect the mode with stat -c '%A %a %n' FILE before assuming failure.

Checkpoint

Answer these before you go on.

What must you do before unplugging a USB stick?

Unmount or eject it, and wait for the desktop to confirm. Pulling it while writes are pending can corrupt the filesystem.

Why list an archive before extracting it?

The listing shows the paths it contains, so you can choose a target folder and notice unexpected absolute paths or entries before they land.

Why launch a misbehaving graphical program from a terminal once?

The terminal shows standard error messages that a menu launcher hides.

Which command reports configured printer queues?

lpstat -p. If it prints nothing, no queue is configured yet.

When converting a photo or clip, what should you protect?

The original. Write the converted copy to a new file name and check it before replacing anything.

How do you undo a web app installation?

Remove it with tam-webapp-remove "NAME", using the same name you installed it with.

Checkpoint

Answer these before you go on.

Where does tam-journal store a day's entry?

In a plain UTF-8 file named by date, for example ~/Journal/2026-11-12.txt, or under TAM_JOURNAL_DIR when that is set.

What does tam-file-select return when you cancel the dialog?

Exit status 1. Status 0 means at least one path was printed, and 2 means the chooser could not open.

Capstone: Pack, inspect, unpack and verify a folder

In a fresh temporary directory, create a small folder with one text file. Pack it into a .tar.gz, list the archive before extracting, extract it into a second folder, and compare the extracted file with the original. Then remove everything you made.

These commands touch only a new temporary directory. The archive stores the folder name, so extraction into a separate output folder keeps the two copies apart.

$ work=$(mktemp -d)
$ mkdir -p "$work/src/sub" "$work/out"
$ printf 'hello\n' > "$work/src/sub/note.txt"
$ tar -czf "$work/bundle.tar.gz" -C "$work/src" sub
$ tar -tzf "$work/bundle.tar.gz"
sub/
sub/note.txt
$ tar -xzf "$work/bundle.tar.gz" -C "$work/out"
$ cat "$work/out/sub/note.txt"
hello

Captured on Arch Linux, 2026-11-13. The listing confirms the archive holds sub/ and sub/note.txt; the final cat confirms the extracted copy is readable.

$ cmp "$work/src/sub/note.txt" "$work/out/sub/note.txt" && echo "same contents"
same contents
$ rm -rf -- "$work"

cmp prints nothing and exits 0 when the files match, so the echoed line is the check. Removing the temporary directory is safe because it holds only the practice copy. If the archive listing shows an unexpected path, stop before extracting and inspect it; do not extract over real folders.
