Settle in from macOS or Windows

These readings help you find your way around Tamlinux if you have used another computer system.

Stage 1: Find your way around

Find your way around: Follow the desktop orientation and identify the launcher and terminal on the installation you are using.

Coming from Windows or macOS: the key with the Windows logo or Command symbol is the Meta key here. Meta + Return opens a terminal; Ctrl + F12 opens the apps menu; Meta + Space opens the Tamlinux menu. Exact chords live in Meta + K.

Check yourself

Should you assume another operating system uses the same shortcuts here?

No. Check the current Tamlinux bindings and any local overrides. Meta replaces the Windows/Command role for desktop chords.

Stage 2: Everyday jobs without a terminal

Start with screenshots, the clipboard, and sound.

Check yourself

You copied something earlier and have since copied other text. Where is the earlier item?

In the clipboard history, which Meta + Ctrl + V opens. The current clipboard holds only the most recent copy.

Stage 3: Find help

Find help: Open a Guide topic, follow a link and use history to return.

Check yourself

Does the Guide history key change a system setting?

No. It navigates the reader; it does not change the desktop configuration.

Stage 4: Organize windows

Organize windows: Read the workspace lesson and practice with empty windows only.

Check yourself

Is a workspace the same thing as a file directory?

No. A workspace organizes windows; a directory holds filesystem entries.

Stage 5: Find files and names

Read filesystem basics and First steps. A folder is called a directory; a path is its address. Work in the temporary directory used by the linked lesson.

Check yourself

Does moving a window to another workspace move its files?

No. Workspaces organize windows; files remain in their filesystem locations.

Capstone

Orient yourself without changing settings: find the terminal, open the Guide, follow one topic and return; identify how your installation moves between workspaces, and explain the path to a temporary file. Use empty windows if you practice.

Open a terminal using the current desktop binding, run tam show, follow a Guide link and use Left Arrow to go back. Consult the current workspace bindings and use empty practice windows. Close those windows when finished; the actual keys can differ with local overrides.
