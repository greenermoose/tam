Everyday desktop tasks

This path covers the desktop jobs you do most days without opening a terminal first: capture, clipboard, notifications, sound, Bluetooth, screens, input comfort, locking and night light.

Each step uses the packaged desktop controls, so you can undo it from the same menu or chord. The read-only status commands are safe; connecting a device or changing a display affects only your current session.

Stage 1: Capture and share

  1. Taking a screenshot or recording the screen — capture a region, copy text from it, or record a short clip.
  2. Finding something you copied earlier — copy, paste, and recover an earlier item.
  3. Reading and dismissing notifications — dismiss a pop-up, open history, and silence alerts.

Checkpoint

Answer these before you go on.

Does copying text to the clipboard save it permanently?

No. The clipboard holds a temporary selection until it is replaced or cleared. Save important text in a real file.

If notifications are silenced, can you still read an earlier message?

Yes. Silencing stops new pop-ups; the message is still recorded in history, which Meta + Shift + H opens.

Stage 2: Sound and wireless devices

  1. Changing the volume and choosing speakers or headphones — raise, lower and mute sound, and switch outputs.
  2. Connecting Bluetooth headphones or a mouse — pair, connect, and remove a device.

Checkpoint

Answer these before you go on.

Which command prints the current audio output sink?

tam-audio-output-sink. The audio panel is Meta + Ctrl + A.

Why does a paired device not need pairing mode every time?

Pairing exchanges and stores a key, which the computer and device reuse when they connect later.

Stage 3: Screens and their hardware

  1. Arranging your screens and changing brightness — brightness, text size, monitor arrangement and mirroring.
  2. Displays and Monitors — how panels, scaling and multi-head layouts work underneath.

Checkpoint

Answer these before you go on.

Why adjust scaling or brightness from the desktop controls before editing configuration files?

The controls are reversible and take effect immediately, so you can confirm legibility and undo without risking session startup files.

Which command reports the current text size?

tam-display-text-size. It prints the text size, scaling factor and terminal font.

Stage 4: Input, locking and night light

  1. Turning the touchpad on or off and finding keyboard shortcuts — touchpad, keyboard backlight and the keybinding lookup.
  2. Input Devices — how keyboards, pointing devices and touchscreens reach the desktop.
  3. Locking the screen and keeping it awake — lock, unlock, and pause idle locking for a long job.
  4. Making the screen warmer at night — turn the blue-light filter on and off and check its state.

Checkpoint

Answer these before you go on.

Which chord locks the screen, and which pauses idle locking?

Meta + Ctrl + L locks; Meta + Ctrl + I toggles Stay Awake. The Stay Awake toggle is silent, so confirm it with tam-toggle-idle status.

In tam-toggle-idle status, what does "enabled":false mean?

Stay Awake is off, so normal idle behaviour applies. It does not mean the status command failed.

Capstone: Set up an evening of work, then put it back

Record the current display, audio, night-light and idle state. Turn night light on, capture and paste a screenshot, lock and unlock the screen, then turn night light off. Finish by comparing the four recorded values with the current ones.

Run these four read-only commands first and write down what each prints. They only report state.

$ tam-display-text-size
text size: 12 px
gtk text-scaling-factor: 1.0
terminal font: 9 pt
$ tam-audio-output-sink
alsa_output.pci-0000_05_00.1.hdmi-stereo-extra1
$ tam-toggle-nightlight --status
{"enabled":false,"temperature":null}
$ tam-toggle-idle status
{"enabled":false,"class":"disabled","tooltip":"Stay Awake"}

Captured on an Arch Linux workstation, 2026-11-13. Your values will differ with your hardware and settings.

  1. Press Meta + Ctrl + J to turn night light on. Run tam-toggle-nightlight --status again; the filter should now report "enabled":true.
  2. Press Print Screen, drag a box around one empty window, and release. The picture is saved and copied.
  3. Press Meta + Ctrl + V to open clipboard history, choose the screenshot, and paste it into a scratch editor. Close the editor without saving.
  4. Press Meta + Ctrl + L, type your login password, and press Return. Your windows return as they were.
  5. Press Meta + Ctrl + J again to turn night light off, and confirm the status reports "enabled":false.

Run the four commands once more. The display, audio and idle values should match what you wrote down, and night light should be off. If a value changed, use the same desktop control to restore it; nothing here needs a file edit. If tam-toggle-nightlight --status reports an error, check that you are in a graphical session.
