People and security

These guides explain how ordinary user accounts stay separated from system changes, how secrets work, and why signed updates matter.

Stage 1: Identity and secrets

Learn the boundary between your daily account and privileged operations, and how passwords, keys, and lock screens protect stored data.

Check yourself

Why run daily work as an unprivileged user rather than root?

Mistakes or buggy programs running under your user account cannot silently rewrite system-wide binaries or boot files.

Stage 2: Privileges and trusted software

Understand when privilege prompts appear, what hardware security protects, and how rollback boundaries safeguard updates.

Check yourself

Should you paste arbitrary commands with sudo without knowing what files they touch?

No. Privileged commands can alter system files and boot state; verify ownership and a rollback point first.
