Make it yours

This page explains how to change settings to make your computer work better for you.

Stage 1: Review current settings

Your desktop: Read the desktop orientation and choose a setting, such as a keybinding, you want to change.

Press Meta + K and note the current chord for the action you care about. Write the old binding, the file or menu that owns it, how you will verify a change, and how you will restore the old binding. Prefer a reversible theme or empty practice binding before editing live workflow keys.

For reversible everyday settings, practice with text size and screen brightness, the night light, and sound output. Each page names its undo step.

Check yourself

Why inspect existing bindings before assigning a new key?

An existing binding or local override may already own that key. Meta + K is the packaged inventory.

Stage 2: Practice editing

Practice editing: Work through the editor lesson in its scratch file.

Check yourself

Why practice in a temporary file before editing configuration?

It lets you learn saving and undo without affecting your real settings.

Stage 3: Identify ownership

Identify ownership: Read the editor configuration lesson and identify the setting owner and how to undo a proposed change.

Check yourself

Does a packaged default necessarily describe a local override?

No. The active configuration and local overrides need separate inspection.

Capstone

Practice changing and saving a temporary note and validating a scratch configuration in the editor lesson. Choose one real workflow to customize, identify the configuration owner and current value, and record a verification and way to undo it. Apply a personal change only if you have identified those details and want that change; otherwise leave it as a plan.

For a proposed editor setting, first identify the active configuration file and its current value. Write the desired setting, how to verify it and how to restore that value. If the file or owner is unknown, stop at the note and investigate before editing. If you choose to change it, verify the resulting behavior and restore the previous value if it is not what you intended.
