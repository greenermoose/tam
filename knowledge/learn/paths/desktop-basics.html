Desktop basics

This path teaches the keyboard-first Tamlinux desktop from the Meta key outward: windows, workspaces, the top bar, screen capture and voice. It assumes you can already log in and see the graphical desktop.

Every exercise uses empty practice windows, so no work is at risk. Do not close, move or capture a window that holds something you have not saved.

Stage 1: Meet the desktop and its command key

  1. The Tamlinux Desktop — what the graphical desktop is, and how to open a terminal and recover your place.
  2. The Meta key — find the key and use it for the system menu, the keybindings list and a practice terminal.
  3. Desktop hotkeys — open the live keybindings list and try one safe chord.

Checkpoint

Answer these before you go on.

Which chord opens the live keybindings list?

Meta + K, which runs tam-menu-keybindings. Check it on your own machine because personal overrides can change a chord.

Which window does Meta + Q close?

Only the focused window. Confirm focus and save work first; practice with an empty terminal.

Stage 2: Arrange windows and workspaces

  1. Windows and layouts — move focus, toggle floating, and tell tiling from overlapping windows.
  2. Organizing windows and screens — switch workspaces, move one window, and return both to where they started.

Checkpoint

Answer these before you go on.

Which chord toggles floating and tiling for the focused window?

Meta + T. Press it again to undo. Check Meta + K if your overrides differ.

Is switching workspace the same as moving a window to another workspace?

No. A switch changes the workspace you are viewing; a move changes which workspace holds the focused window.

Stage 3: Read the bar and its controls

  1. The top bar — hide and show the bar and open one of its modules.
  2. Desktop toggles — find the idle, night light and silence switches.
  3. Notifications — dismiss a pop-up, open history, and silence new alerts.

Checkpoint

Answer these before you go on.

Which chord hides or shows the top bar?

Meta + Shift + Space. Toggle it back so the bar is visible when you finish.

If notifications are silenced, is a message lost?

No. It is recorded in history, which Meta + Shift + H opens.

Stage 4: Copy and capture

  1. Clipboard — copy and paste with Meta, then recover an earlier item from history.
  2. Screen capture — start a screenshot and find the saved picture.

Checkpoint

Answer these before you go on.

Does copying text to the clipboard save it permanently?

No. The clipboard holds a temporary selection until it is replaced or cleared. Save important text in a real file.

Which command does a plain Print Screen start?

tam-capture-screenshot in selection mode. The Capture menu is Meta + Ctrl + C.

Stage 5: Arrive from another system and use voice

  1. Coming from Mac or Windows — find where familiar actions moved.
  2. Voice dictation — start and stop dictation into the focused window.
  3. Shell voice commands — see how a transcript reaches the prompt without running.

Checkpoint

Answer these before you go on.

Does a dictated shell command run automatically?

No. The transcript is inserted at the prompt for you to read, edit and submit yourself.

Which modifier belongs to the desktop rather than the focused application?

Meta. Control usually acts inside the focused program, while Meta chords manage windows, workspaces and menus.

Capstone: Set up, capture and leave a clean desktop

Record your starting workspace, then open two empty terminals. Float one with Meta + T and tile it back. Move the other to workspace 2 with Meta + Shift + 2 and follow it. Hide and show the top bar once. Take a screenshot of one empty terminal with Print Screen, paste it into a scratch editor with Meta + V, and close the editor without saving. Return to your starting workspace and close both practice terminals after confirming focus.

The bindings below are checked against the packaged session definitions; live behaviour on your keyboard still needs your own confirmation. If a chord does nothing, open Meta + K and compare.

  1. Note the workspace number shown in the bar. That number is your undo target.
  2. Press Meta + Return twice to open two empty terminals.
  3. Focus one terminal and press Meta + T. It floats. Press Meta + T again so it tiles.
  4. Focus the other terminal and press Meta + Shift + 2. You move to workspace 2 with it.
  5. Press Meta + Shift + Space to hide the bar, then the same chord to show it.
  6. Press Print Screen, drag a box around the empty terminal, and release. The picture is saved and copied.
  7. Open a scratch editor, press Meta + V, and close the editor without saving. The screenshot stays in the clipboard history at Meta + Ctrl + V.
  8. Return to your starting workspace with Meta + its number. Focus each practice terminal and press Meta + Q.

You are finished when the bar is visible, both practice windows are gone, and you are back on the workspace you recorded. A screenshot exists in the capture tool's saved location and in clipboard history. If the windows followed you instead of staying on workspace 2, you switched workspaces instead of moving the window; return, focus the window, and repeat the move chord.
