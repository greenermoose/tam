Systems programming in C11

These guides explain why Tamlinux core utilities target portable ISO C11, how compilation and linking produce native binaries, and how sanitizers catch memory bugs during development.

Check yourself

Why pair C11 source with AddressSanitizer and UndefinedBehaviorSanitizer in tests?

Compiler warnings catch static issues at build time, while ASan and UBSan trap out-of-bounds accesses, use-after-free bugs, and undefined behavior during test runs.
