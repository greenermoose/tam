Work with AI locally

Gain: Assess a local model task, run a supported query and check its answer against a source.

For you if: You can use a terminal and want to understand the cost and limits of local inference.

Levels: Intermediate (2) to Expert (3); allow three reading sessions.

Stage 1: Check headroom

Check headroom: Read the memory-bandwidth and inference lesson. Note the model size and available resources before running anything.

Check yourself

Why is model file size not the whole memory budget?

Runtime state, context and the operating system also need memory.

Stage 2: Observe resources

Observe resources: Read how to inspect memory and load. Identify a baseline and a comparable workload.

Check yourself

Does a high memory number alone establish thrashing?

No. Compare available memory, pressure and workload behavior; a single value is insufficient.

Stage 3: Understand limits

Understand limits: Read the quantization and context discussion. If two suitable local models are already available, compare the same question with tam ask --model MODEL --pipe "what is a pipeline", replacing MODEL with each actual name. Record the model, timing and answer quality; leave the comparison pending if prerequisites are missing.

Check yourself

Is theoretical bandwidth a promise of tokens per second?

No. Model architecture, computation, memory access and overhead also matter.

Capstone

Record available memory and identify a locally available model and running local server. If they are available and you choose to run inference, ask tam ask --pipe "what is a pipeline" and compare the answer with its named Guide source. Record the model, workload and limits. Do not download a model or start a service as part of this exercise; if either is unavailable, leave the query pending.

With an already running local server and its required model available, this source-checking example returned:

$ tam ask --pipe "what is a pipeline"
A pipeline passes a stream of bytes from one program to another, allowing the output of one program to be used as input for another.
