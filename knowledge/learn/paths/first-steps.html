1. Open a terminal for entering commands

A terminal is where you can type instructions and read replies. Each instruction is called a command. A program called a shell reads those instructions.

If you are using the Tamlinux graphical desktop, press and hold the Meta key then press the Return key (Meta + Return) to open a terminal. (The Meta key often has a Windows logo and the Return key is often labeled Enter.) If you are using a text-only terminal (as you will be if you have just booted your computer and have not yet started the Tamlinux desktop), you can type instructions there already.

Press Esc to leave this guide and return to the terminal where you can type commands. To get back to this page from a terminal, type tam hi, press the Return (or Enter) key, then follow the First steps link from the Welcome page.

A shell prompt is the text that shows where the computer is waiting for your instruction. Your shell prompt may look different from the $ in the example below. Type only the text after the $, then press your return key.

Try it: command and output

Here's an example for you to try. This is how most terminal command examples work: you see a shell prompt ($ in this case), followed by the command you need to type. Then you see the output of the command.

If you can, open another terminal so you can try this command. If you can't, read on and try it later in a terminal. Type the command and then press your return key (marked either Return or Enter on your keyboard). Then you should see the output of the command. In this example, the expected output is "hello".

    $ printf '%s\n' hello
    hello

The above example was tested using the bash shell from Arch Linux on 2026-10-21. Your results may vary.

Note that the example shows both the command you type and the output we expect the computer to display. When you try examples of commands to use in a terminal, just type the command. Do not type hello; that is the expected output. The shell command printf prints text; the argument '%s\n' tells it to print each supplied word on a new line. Include the single quotes (') and spaces when you type your command.

To make your life easier, you can copy and paste text into a terminal using Tamlinux's Meta + C and Meta + V shortcuts. For short examples, you can type everything yourself. But for longer examples, it's easier to select text, copy it, and then paste it into the terminal.

Check your knowledge

Answer before revealing the explanation.

In the terminal command example above, which text do you type: the leading dollar sign, the printf command, or the output hello?

Type only the printf command plus the arguments '%s\n' and hello, then press Enter. The dollar sign is the shell prompt in this example; hello is the result. Shell prompts often end with a dollar sign, but not always. Sometimes they end with a slash (/) or a number sign (#) or a colon (:) or another character.

2. See where you are and make a safe place

Leave the Guide with Esc so you can type in the terminal. Keep that terminal open: later steps depend on the directory you choose here.

Ask the shell where you are, list names in that place, then create a temporary practice directory and enter it:

$ pwd
/home/alex
$ ls
Documents  Downloads
$ work=$(mktemp -d)
$ cd "$work"
$ pwd
/tmp/tmp.AbCdEfGh

Captured on Arch Linux, 2026-11-02. Your home path and listing will differ; mktemp -d always prints a new empty directory under /tmp.

Read Filesystem basics for names and directories, then continue.

Check yourself

Answer before revealing the explanation.

Which command prints your current directory, and which creates a new empty temporary directory?

pwd prints the current directory. mktemp -d creates a new empty temporary directory and prints its path. cd changes into a directory; ls lists names.

Capstone: Make and inspect a tiny report

In a fresh temporary directory, create colours.txt with red, blue, red on separate lines. Count whole lines equal to red. Create ready.txt containing ready and make it readable and writable only by you. Inspect its numeric mode. Remove these two files and the temporary directory when done, then reopen Welcome and find this path again.

For this section, make a new temporary directory and enter it. These commands print nothing when they succeed. Run the first line on its own; if it reports an error, stop. Run the second line and stop if it reports an error too. Keep this terminal open while you work through the section.

work=$(mktemp -d)
cd "$work"

$ printf '%s\n' red blue red > colours.txt
$ grep '^red$' colours.txt | wc -l
2
$ printf '%s\n' ready > ready.txt
$ chmod 600 ready.txt
$ stat -c '%a %n' ready.txt
600 ready.txt

Captured on Arch Linux, 2026-10-27. The count is 2 and the file mode is 600. These verify different things: stream filtering and file access.

rm -- colours.txt ready.txt
cd /tmp
rmdir -- "$work"

In a separate terminal command, run tam hi, select Paths by Goal, then First steps. If your result differed, return to the pipeline or permissions example before trying again.
