Finding and navigating documentation

This page explains how to find information in the guide and return to it later.

Find and return

Goal: find a guide topic, follow a reference and return to your starting page.

Why it matters: Different sources answer different questions; the reader remembers how you reached them.

Before you start: The following actions only navigate the reader.

New to this? Start in the Guide; follow links with the reader and press Left Arrow to return through history. At a terminal, do not type a leading dollar sign shown as a prompt.

Worked example

Follow Search this guide, then select and follow Start a Guide search. Type streams and press Enter. Select a result with Tab or ], then press Enter to open it. Press Left Arrow to return to the results. This return follows the pages you visited, not necessarily the page's parent.

Outcome: find a guide topic, open a system manual, and return to the page you were reading. No shell or system changes are required.

Choose a source

  • Guide: curated explanations about Tamlinux and Linux concepts. Use Search this guide or Topics.
  • tldr: concise, example-first command cheat sheets. Use Browse or search tldr pages for practical command invocations.
  • Man: complete command and system interface references. Use Find or open a man page; keyword lookup depends on the installed man database.
  • Info: linked manuals and tutorials when installed. Open the Info directory to browse available manuals.

Move without losing your place

  1. Open a topic from Guide Search or a link.
  2. Use the location row at the top to follow Guide or a parent location.
  3. Open a Man or Info reference from its link.
  4. Use Left Arrow to return to the previous page. In Info, u follows the manual's Up link.
  5. Use backtick (`) to open the Guide index; Left Arrow can return to the page you were reading.
  6. Press h for help. Escape cancels a prompt; outside a prompt, Escape or q quits.

The location row describes where a page belongs; the reader's history remembers the pages you visited. An Info manual's Up link leads to its own parent topic.

See Reading man pages, the tam command guide, or practice the navigation.

Try it

Search for a different topic, then use the backtick key to find the Guide root.

If it goes wrong

If a manual or Info entry is missing, it may not be installed. Return to the Guide and choose another available source.

Check yourself

Does a page's parent necessarily equal the previous history entry?

No. The parent is its place in the Guide; history records the path you followed.

What should you do when a result differs from the example?

Read the result and the relevant documentation, then check the input and prerequisites before changing anything.
