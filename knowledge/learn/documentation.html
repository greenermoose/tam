Finding and navigating documentation

This page explains how to find information in the guide and return to it later.

What kinds of documentation exist?

Tamlinux offers several places to look things up. Each answers a different kind of question.

  • Guide: curated explanations about Tamlinux and Linux concepts. Use Search this guide or Topics.
  • tldr: concise, example-first command cheat sheets. Use Browse or search tldr pages.
  • Man: complete command and system interface references. Use Find or open a man page.
  • Info: linked manuals when installed. Open the Info directory to browse them.

Why it matters

Different sources answer different questions. Knowing which to open first saves time, and the reader's history remembers how you reached a page so you can return.

How to think about it

Think of the Guide as a map of ideas, tldr as a quick recipe card, man as the full specification for an installed tool, and Info as a book with its own chapter links. The location row describes where a page belongs; history records the path you walked.

Find a topic and return

Goal: find a guide topic, follow a reference, and return to your starting page without losing your place.

Learning path: Healthy diagnostics — Start | ← Back | Next →

Before you start: these actions only navigate the reader. No shell or system changes are required.

Start in the Guide; follow links with the reader and press Left Arrow to return through history. At a terminal, do not type a leading dollar sign shown as a prompt.

Worked example

Follow Search this guide, then select and follow Start a Guide search. Type streams and press Enter. Select a result with Tab or ], then press Enter to open it. Press Left Arrow to return to the results. This return follows the pages you visited, not necessarily the page's parent.

Outcome: you found a guide topic, opened it, and returned through history.

What just happened

  1. Search listed matching guide pages.
  2. Opening a result pushed a new history entry.
  3. Left Arrow walked back through that history; the page's parent link is a separate map.

Try it

Search for a different topic, then use the backtick key (`) to open the Guide index. Use Left Arrow if you want to return to the page you were reading.

If it goes wrong

A manual or Info entry is missing
It may not be installed. Return to the Guide and choose another available source.
You feel lost after several jumps
Use the location row for the page's place in the Guide, or Left Arrow for the path you actually followed. Press h for reader help.

See Reading man pages, the tam command guide, or practice the navigation.

Check yourself

Does a page's parent necessarily equal the previous history entry?

No. The parent is its place in the Guide; history records the path you followed.

What should you do when a result differs from the example?

Read the result and the relevant documentation, then check the input and prerequisites before changing anything.
