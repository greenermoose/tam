Safe practice and self-checks

Use temporary files in a directory you own. These exercises read or change only that scratch directory; they do not require privilege, package changes, boot changes, or recovery actions.

Exercise: navigate documentation

  1. Open Guide Search and search for streams.
  2. Open a result and follow its breadcrumb parent.
  3. Open Man pages, look up printf, then press Left Arrow.

Check: you can name which action returned through history and which key opens the Guide root. Hint: history and Guide are separate actions.

Exercise: a read-only pipeline

scratch=$(mktemp -d)
echo pear > "$scratch/fruit.txt"
echo apple >> "$scratch/fruit.txt"
echo pear >> "$scratch/fruit.txt"
sort "$scratch/fruit.txt" | uniq -c
rm -r -- "$scratch"

The temporary directory is removed at the end. Expect the counts to show one apple and two pears; spacing can vary by implementation.

Check: explain which command reads the file, which sorts its lines, and why uniq follows sort. If output differs, inspect the file before changing the commands.
