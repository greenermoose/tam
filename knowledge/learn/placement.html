Choose a starting level

Choose where to start today. This is a reading suggestion, not an exam or a permanent label. Press 0 to compare all levels; press 1, 2 or 3 whenever your needs change. No score or learning history is stored.

Beginner

For you if: You want a complete example, an explanation of each command and a safe place to try it.

Does a command that prints nothing necessarily fail?

No. Many successful commands are silent. Learn how to inspect the result and recognize error messages before changing the system.

Start at Beginner (1).

Intermediate

For you if: You can run commands and want to adapt them, choose between options and diagnose common failures.

A pipeline exits successfully after its producer printed an error. What might you check?

Inspect each stage and stderr. A shell can report the last command status even when an earlier stage failed. Knowing the syntax is less useful here than checking the evidence.

Start at Intermediate (2).

Expert

For you if: You want precise semantics, experiments and evidence for unfamiliar failures.

A package path is new but a running process is old. Which boundaries could explain it?

Compare the selected path, package identity and existing process mappings. Name replacement need not change an open inode. Separate mutable state, software and boot recovery before choosing an intervention.

Start at Expert (3).
