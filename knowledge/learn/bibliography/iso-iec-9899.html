ISO/IEC 9899: Programming Languages — C

This page points to the ISO/IEC 9899 standard family defining the C programming language.

This reference is for expert readers.

ISO/IEC 9899 (editions 1990, 1999, 2011, 2018, 2024). Defines the C language syntax, memory model, standard library headers, and undefined behavior rules. Tamlinux targets C11 (ISO/IEC 9899:2011) for portable systems code.

Published ISO standard. Paid specification; committee working drafts are publicly available online.
