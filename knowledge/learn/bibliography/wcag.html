WCAG: Web Content Accessibility Guidelines

This page points to the W3C accessibility guidelines used for text contrast and readability standards.

This reference is for expert readers.

Web Content Accessibility Guidelines (WCAG) 2.1 / 2.2 (W3C). Defines relative luminance formulas and minimum contrast ratios (4.5:1 for AA normal text, 7:1 for AAA) applied to terminal and desktop themes.

Online W3C Recommendation. Free. Open standard.
