RFC 9106: Argon2 Memory-Hard Function for Password Hashing

This page points to the IETF specification for the Argon2 password-hashing and key-derivation function.

This reference is for expert readers.

RFC 9106, by A. Biryukov, D. Dinu, D. Khovratovich, and S. Josefsson (IETF, 2021). Defines Argon2d, Argon2i, and the recommended hybrid Argon2id for password hashing and LUKS2 key derivation.

Online IETF specification. Free. Open standard.
