ISO/IEC 21031: Software Carbon Intensity (SCI) Specification

This page points to the international standard for measuring the carbon intensity of software systems.

This reference is for expert readers.

ISO/IEC 21031:2024, Information technology — Software Carbon Intensity (SCI) specification (originating from the Green Software Foundation). Defines how to score software carbon emissions per functional unit by combining operational energy emissions and embodied hardware emissions.

Published ISO standard / open Green Software Foundation specification.
