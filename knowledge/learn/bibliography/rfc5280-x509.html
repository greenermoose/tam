RFC 5280: Internet X.509 Public Key Infrastructure Certificate and CRL Profile

This page points to the IETF specification profiling X.509 certificates for the internet.

This reference is for expert readers.

RFC 5280, by D. Cooper et al. (IETF, 2008). Defines X.509 v3 certificate fields, Subject Alternative Name (SAN) extensions, path validation, and Certificate Revocation Lists (CRLs).

Online IETF specification. Free. Open standard.
