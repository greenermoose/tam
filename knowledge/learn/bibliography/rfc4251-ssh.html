RFC 4251–4254: The Secure Shell (SSH) Protocol Architecture

This page points to the IETF specifications defining the Secure Shell (SSH) transport, user authentication, and connection layers.

This reference is for expert readers.

RFC 4251 (SSH Architecture), RFC 4252 (User Authentication), RFC 4253 (Transport Layer), and RFC 4254 (Connection Protocol), edited by Tatu Ylonen and Chris Lonvick (IETF, 2006).

Online IETF specifications. Free. Open standard.
