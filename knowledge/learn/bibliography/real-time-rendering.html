Real-Time Rendering

This page points to the authoritative textbook on computer graphics architecture and the rendering pipeline.

This reference is for intermediate readers and experts.

Real-Time Rendering, by Tomas Akenine-Möller, Eric Haines, Naty Hoffman, Angelo Pesce, Michał Iwanicki, and Sébastien Hillaire. Comprehensive treatment of the graphics rendering pipeline, GPU architecture, shaders, rasterization, lighting, and spatial data structures.
