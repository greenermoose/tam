RFC 8446: The Transport Layer Security (TLS) Protocol Version 1.3

This page points to the Internet Engineering Task Force specification for TLS 1.3.

This reference is for expert readers.

RFC 8446: The Transport Layer Security (TLS) Protocol Version 1.3, by Eric Rescorla (IETF, 2018). Defines the 1-RTT and 0-RTT handshakes, HKDF key schedule, AEAD record protection, and removal of legacy RSA key transport and static ciphers.

Online IETF specification. Free. Open standard.
