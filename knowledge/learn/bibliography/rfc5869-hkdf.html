RFC 5869: HMAC-based Extract-and-Expand Key Derivation Function (HKDF)

This page points to the IETF specification defining HKDF.

This reference is for expert readers.

RFC 5869, by H. Krawczyk and P. Eronen (IETF, 2010). Defines the two-stage Extract-and-Expand key derivation construction built on HMAC, used in TLS 1.3 and modern cryptographic protocols.

Online IETF specification. Free. Open standard.
