ECMA-48: Control Functions for Coded Character Sets

This page points to the Ecma International standard defining terminal control functions and escape-sequence syntax.

This reference is for expert readers.

ECMA-48 (5th edition, June 1991; equivalent to ISO/IEC 6429:1992). Defines C0 and C1 control sets, Control Sequence Introducer (CSI) grammar, parameter/intermediate/final byte ranges, and Select Graphic Rendition (SGR) parameters.

Online PDF specification. Free. Open standard.
