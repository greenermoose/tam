Using the tam guide command

The tam command includes offline guide and documentation readers. Use this page to choose an entry point; implementation and development details remain in The tam command.

Open and find material

  • tam show opens the guide root.
  • tam show shell/pipelines?level=beginner opens a topic at a supported depth.
  • tam search "permissions" searches the guide; in the reader choose Search to enter a query.
  • tam explain --level expert lists topics with that depth.

Use references

Open tldr pages for concise command examples, Man pages to find an installed manual by name, section, or keyword, and tam info to open the installed Info directory. The documentation lesson explains how to move among Guide, tldr, Man, and Info while keeping history.

Return to the guide with the backtick key. Press ? for help and q to leave the reader. See safe practice to try these actions without changing system state.
