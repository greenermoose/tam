The beginner's path

Outcome: navigate the guide, find and read files, understand a simple stream pipeline, open Man and Info documentation, and return to the guide. No prior terminal experience is assumed.

Prerequisites: a working Tamlinux session and a terminal. You may skip any step that is not useful for your current task.

  1. Read Welcome and how to navigate this guide.
  2. Open the desktop overview, then the shell and streams.
  3. Read where files live. Use pwd and ls to inspect your current directory.
  4. Follow the pipeline lesson. Use the temporary-file example in safe practice.
  5. Open Man pages, find printf, then browse the installed Info directory. Use Left Arrow to return.

Self-check: explain where a command reads input and writes output, name the key that opens Guide, and distinguish history Back from Info's u (Up). If unsure, revisit the links above.

Next: continue with the intermediate route, repeat a topic at another available depth, or go directly to Using.
