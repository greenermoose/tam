Beginner path

Gain: Navigate the desktop and Guide, then complete a small file task.

For you if: You want complete examples and explanations before trying a close variation.

Levels: starts and finishes at Beginner (1); allow about three reading sessions. Choose another level whenever needed.

Stage 1: Orientation

  1. Welcome: learn the Guide keys.
  2. Desktop: practice with an empty terminal.

Check yourself

Decide before revealing the explanation.

Which key returns to the Guide index?

The backtick key inside the pager; Esc leaves for the terminal.

Stage 2: Files and streams

  1. Permissions: work in the temporary directory.
  2. Pipelines: predict before running.

Check yourself

Decide before revealing the explanation.

What does a silent chmod tell you?

Silence alone is not failure. Inspect the resulting mode and any error status.

Stage 3: One complete task

  1. First steps: finish its capstone and cleanup.

Check yourself

Decide before revealing the explanation.

Why practice in a fresh temporary directory?

It gives the exercise a bounded set of files and a specific cleanup, without using real documents.

Capstone

Repeat the First steps capstone from memory: count red lines, inspect a private file mode, clean up and return to Welcome.

Use a fresh temporary directory. Write red, blue, red to colours.txt; filter whole red lines and count them. Create ready.txt, apply mode 600 and inspect it with stat. The captured First steps solution gives count 2 and mode 600. Remove those two files, leave and remove the temporary directory, then reopen Welcome.
