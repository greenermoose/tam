Installing Tamlinux

This page explains what you can do today to prepare a computer for Tamlinux.

The guide does not yet provide a complete procedure for installing Tamlinux from scratch. Today, tam inspect can read supported information about a computer without changing it. The planned install commands are not available yet.

Tamlinux is installed on a rootstock, which is the kernel and core system software on which the Tamlinux cultivar is installed. The cultivar is all the software in the Tamlinux release that allows the computer to be used effectively and efficiently by both humans and AI agents. Rootstock is not a common term, but one that Fred Horch, the Tamlinux developer, made up to explain how Tamlinux works: Fred defines the rootstock to be the set of software that third-parties publish and is necessary to be installed so that the software we write can function properly. Our goal is to minimize the size of the rootstock and maximize its speed and efficiency. Currently we are using Arch Linux as our rootstock but we plan to migrate to Void Linux in future versions of Tamlinux. Beyond that we are considering a microkernel to further reduce the code size of the rootstock and improve its performance per watt.

Before you begin

  1. Review the system architecture and its current-versus-planned choices.
  2. Read the topics catalog for host inspection and the relevant manual pages.
  3. Use tam inspect to see detected host facts. It does not install or configure the system.

Do not treat the planned tam install plan, apply, or verify commands as available. For changes to an installed system, begin with Maintaining; for development, see Improving.
