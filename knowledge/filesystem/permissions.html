File Permissions and Ownership

Every file and directory on Linux has an owner user, an owner group, and a set of permission mode bits that govern read, write, and execute rights.

Beginner: Making a script executable

Summary: Grant execution permissions to a shell script using symbolic chmod.

Prerequisites: Filesystem navigation and directory layout (The Linux Filesystem Hierarchy).

Command sequence

ls -l backup.sh
chmod +x backup.sh
ls -l backup.sh

Expected output:

-rw-r--r-- 1 fred fred 142 Oct 14 08:00 backup.sh
-rwxr-xr-x 1 fred fred 142 Oct 14 08:00 backup.sh

What just happened

  • ls -l displayed the initial file mode: readable and writable by the user (rw-), readable by group (r--) and others (r--).
  • chmod +x added the executable bit (x) to all three tiers: user, group, and others.
  • The script can now be directly executed from the command line: ./backup.sh.

Common pitfall

Never run chmod 777 to resolve access errors. Granting universal write access creates severe security vulnerabilities. For directories, the execute bit (x) is required to traverse (enter) the directory.

Intermediate: Numeric octal modes and group collaboration

Summary: Calculate octal permission masks and configure shared directory collaboration with group sticky bits.

Worked example

Lock down private SSH credentials so only your user account can read them:

chmod 700 ~/.ssh
chmod 600 ~/.ssh/id_ed25519

Directory mode 700 gives rwx------; file mode 600 gives rw-------, preventing unauthorized access by other local users.

Completion task

Configure a collaboration folder /srv/team so that any newly created files automatically inherit the group ownership of the directory (SetGID). Complete the missing octal mode below (marked with ___):

sudo chgrp developers /srv/team
sudo chmod ___ /srv/team

Target output: directory permissions show drwxrwsr-x (SetGID bit 2000 combined with 775 permissions).

Verification hints

  • The SetGID octal value is 2000. Add 2000 + 775 = 2775.
  • Inspect with ls -ld /srv/team to verify the group execute bit shows lowercase s.
  • Use umask(1) to set default creation masks for new files.

Expert: POSIX inode mode representation and attributes

Reference: The 16-bit st_mode field in stat(2) encodes file type (regular, directory, symlink, fifo, socket, block, char) in the top 4 bits, special flags (SUID 04000, SGID 02000, Sticky 01000) in the next 3 bits, and standard 9-bit rwx permissions in the lower 9 bits. Hard links share the identical inode number; symlinks are independent pointer files.
