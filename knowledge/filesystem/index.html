The Linux Filesystem Hierarchy

Linux organizes all files and storage devices into a single unified tree beginning at root (/). This structure follows the Filesystem Hierarchy Standard (FHS).

Key directories

DirectoryPurpose
/The root of the overall directory hierarchy
/homeUser personal directories and settings (~/.config, ~/.local)
/etcHost-specific system configuration files in plain text
/usrSecondary hierarchy for user utilities, libraries, and assets
/varVariable runtime state, service data, and system logs (/var/log)
/tmpTemporary files cleared on system restart
/procVirtual filesystem exposing kernel and process state metrics
/sysVirtual filesystem exposing kernel device and driver trees
/devDevice node representations for physical hardware and pseudo-devices

Virtual filesystems: /proc and /sys

The files inside /proc and /sys take zero disk space. They are direct windows into kernel memory. For instance, reading /proc/cpuinfo queries processor features directly from the kernel, and reading /proc/meminfo checks current memory metrics.

Inspecting disk and space usage

Two essential commands give quick visibility into filesystem usage:

df -h (disk free)
Shows disk usage, capacity, and mount points across all mounted filesystems in human-readable units.
du -sh path (disk usage)
Calculates the total disk space consumed by a directory and its contents.
