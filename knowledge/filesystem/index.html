Files and folders

This page explains how a computer stores and organizes documents and other information.

What are files and folders?

A file holds information, such as a document or picture. A folder, also called a directory, can hold files and other folders. A path is the name that tells the computer where to find one.

Linux arranges folders inside other folders, starting at the root folder, written /. A path such as /home/alex starts at that root and names the folder alex inside home.

Why it matters

Reading a path before running a command helps you understand what the command will affect, so you do not change the wrong file by accident.

How to think about it

Think of the filesystem as a filing cabinet. Drawers are folders, papers are files, and the path is the address written on the outside of a drawer so you can find the right one.

New words

File
A named collection of information the computer can store and retrieve.
Directory
A folder that can contain files and other directories.
Path
The address that names a location in the folder tree.

Finding your place

Goal: distinguish a file, directory and path, and identify common parts of the filesystem.

Before you start: open a terminal. This example only reads a directory name.

New to this? The dollar sign represents your prompt. Type the command after it, then press Enter.

Worked example

$ ls -d /tmp
/tmp

Captured on Arch Linux, 2026-10-27. ls displays files and folders; -d asks it to display the named directory itself, rather than list its contents.

What just happened

  1. You asked ls to name the directory /tmp.
  2. The command printed that path, confirming the directory exists for you.
  3. No files were created or deleted.

Key directories

DirectoryPurpose
/The root folder containing the rest of the folder tree
/homePersonal folders for users
/etcSystem settings for this computer
/usrPrograms and supporting files
/varChanging system data, including logs
/tmpTemporary files
/procInformation about running programs and the system
/sysInformation and controls for devices and the system
/devSpecial entries programs use to access devices

/proc and /sys are virtual filesystems: their entries provide information from the kernel. They are not ordinary stored files.

Try it

Use ls -d /proc to inspect another named directory. Compare its purpose in the table; the command does not show its contents.

If it goes wrong

No such file or directory
Check spelling. Start again from a path you know exists, such as /tmp.
Permission denied
Read the message. Do not add privilege merely to make an unfamiliar example work.

Check yourself

What is the difference between a directory and a path?

A directory organizes entries; a path names a location in the hierarchy.

Are /proc entries necessarily ordinary stored files?

No. They expose interfaces and information provided by the kernel.
