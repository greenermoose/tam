Files and folders

This page explains how a computer stores and organizes documents and other information.

A file holds information, such as a document or picture. A folder, also called a directory, can hold files and other folders. A path is the name that tells the computer where to find one.

Linux arranges folders inside other folders, starting at the root folder, written /. A path such as /home/alex starts at that root and names the folder alex inside home.

Finding your place

Goal: distinguish a file, directory and path, and identify common parts of the filesystem.

Why it matters: reading a path before running a command helps you understand what it will affect.

Before you start: open a terminal. This example only reads a directory name.

New to this? The dollar sign represents your prompt. Type the command after it, then press Enter.

Worked example

$ ls -d /tmp
/tmp

Captured on Arch Linux, 2026-10-27. ls displays files and folders; -d asks it to display the named directory itself, rather than list its contents. Here it finds /tmp.

Key directories

DirectoryPurpose
/The root folder containing the rest of the folder tree
/homePersonal folders for users
/etcSystem settings for this computer
/usrPrograms and supporting files
/varChanging system data, including logs (records of events)
/tmpTemporary files; cleanup depends on system configuration
/procInformation about running programs and the system
/sysInformation and controls for devices and the system
/devSpecial entries programs use to access devices

Virtual filesystems: /proc and /sys

/proc and /sys are virtual filesystems: their entries provide information and controls from the kernel, the core of the operating system. They are not ordinary stored files. For instance, reading /proc/cpuinfo queries processor features directly from the kernel, and reading /proc/meminfo checks current memory metrics.

Inspecting disk and space usage

Two essential commands give quick visibility into filesystem usage:

df -h (disk free)
Shows space used and available on attached filesystems in easy-to-read units. It also shows where each one appears in the folder tree.
du -sh path (disk usage)
Estimates the disk space used by the named folder and its contents. Replace path with the folder you want to inspect.

Try it

Use ls -d /proc to inspect another named directory. Compare its purpose in the table; the command does not show its contents.

If it goes wrong

If a path is absent or access is denied, read the message and check its spelling and permissions. Do not add privilege merely to make an unfamiliar example work.

Check yourself

What is the difference between a directory and a path?

A directory organizes entries; a path names a location in the hierarchy.

Are /proc entries necessarily ordinary stored files?

No. They expose interfaces and information provided by the kernel.
