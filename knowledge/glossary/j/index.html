Glossary definitions for technical terms and acronyms beginning with J.

JavaScriptJavaScript: The language that makes web pages interactive and also runs in servers.
JEDECJEDEC is an organization that develops standards for semiconductor devices.
JIT (Just-In-Time compilation)JIT: Compiling bytecode or scripts into native machine code at runtime for speed.
Job (shell)Shell job: learning reference and next steps
JournalJournal: A log of events or pending changes.
JSON (JavaScript Object Notation)JSON: Lightweight human- and machine-readable data format using key-value objects and arrays.
JWS (JSON Web Signature)JWS: Standard compact format for digitally signed or MAC-protected JSON payloads (RFC 7515).
JWT (JSON Web Token)JWT: Compact, URL-safe token format carrying signed identity claims between services (RFC 7519).
