JavaScript

JavaScript is the language browsers use to make pages respond to people and to change a page after it loads.

When you click a button, fill a form, or see a menu open on a web page, JavaScript is often the code that notices and reacts. It can also ask another computer for fresh information without reloading the page.

JavaScript stores values in variables, groups them in objects and arrays, and describes actions in functions. The same code runs in a browser and in Node.js, but each environment offers different services around the language.

Is JavaScript the same language as Java?

No. The name was chosen for marketing reasons in the 1990s. Java is a separate language with a different type system and runtime; JavaScript is defined by ECMAScript and runs mainly in browsers and Node.js.

The language is defined by ECMA-262 under the name ECMAScript. Engines such as V8, SpiderMonkey and JavaScriptCore parse, compile and optimize it; the host supplies APIs such as the DOM or Node's filesystem. Values are dynamically typed and objects use prototypes.
