Guide / Glossary A–Z / Terms beginning with J / JMAP (JSON Meta Application Protocol)

JMAP is a modern mail access API that lets a client read and submit mail with JSON messages over HTTPS.

The letters stand for JSON Meta Application Protocol. JMAP is a way for an email app to ask a mail service for messages, folders and changes using the same sort of structured text that many web APIs use.

JMAP works over HTTPS and defines objects such as Email, Mailbox and EmailSubmission. A client uses methods like Email/query and a single continuity token for synchronization. It is designed for web and mobile clients that prefer normal HTTP request and response patterns.

RFC 8620 defines the core JMAP protocol and RFC 8621 defines its mail features. JMAP can submit a message through EmailSubmission/set, but it does not replace SMTP between servers: the submission service still hands the message into the mail system. JMAP is an alternative to IMAP for client-to-server access, not an MTA protocol.
