Guide / Glossary A–Z / Terms beginning with N / Number portability

Number portability: the ability to keep a phone number when changing mobile carrier.

Number portability lets a person change carrier without changing their phone number. The number stays, while the route behind it changes.

Because of portability, a network must look up the current serving carrier before it sends a text.

Portability databases and national rules decide which network currently owns a number. A well-formed E.164 number is therefore not enough to determine a route.
