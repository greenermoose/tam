Guide / Glossary A–Z / Terms beginning with N / Nerd Fonts

Nerd Fonts are programming fonts patched to include extra icons used by terminal tools and status bars.

Terminal tools use little symbols for folders, git status and programming languages. Nerd Fonts add those pictures to popular coding fonts so the symbols appear instead of empty boxes.

The project patches fonts such as JetBrains Mono and Fira Code with icon sets from Font Awesome, Material Design Icons and Powerline. Family names often end in 'Nerd Font' or 'Nerd Font Mono'. A terminal or status bar must use one of those families; otherwise icon code points render as tofu.

Patching adds glyphs at selected Private Use Area code points, which are not standardized across icon sets, so tools must use the same mapping the font provides. Many variants include proportional and monospaced versions, with the Mono variants forcing icons to one cell width to preserve terminal columns. Fontconfig can assign these families through aliases, and fc-list identifies installed variants.
