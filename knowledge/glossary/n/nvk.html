NVK (NVIDIA Open-Source Vulkan Mesa Driver)

The open-source userspace Vulkan graphics driver for NVIDIA GPUs in Mesa.

Graphics cards need translator software called drivers so games and apps can talk to the hardware. For a long time, NVIDIA’s best gaming support on Linux required a closed-source driver from NVIDIA itself. NVK is a community-built, open-source driver inside Linux’s Mesa graphics stack that lets modern NVIDIA cards run Vulkan apps and games without proprietary code.

Sitting in userspace as a Mesa Vulkan Installable Client Driver (ICD), NVK pairs with the Linux kernel’s nouveau (and emerging Rust-based nova) DRM drivers—similar to how RADV pairs with amdgpu for AMD GPUs. Unlike the older open-source OpenGL driver nvc0, NVK targets Vulkan 1.3+ on Turing (RTX 20-series) and newer GPUs, using the Zink translation layer when OpenGL apps need a modern path, and avoiding out-of-tree kernel module rebuilds on kernel upgrades.

What is the difference between NVK and nouveau?

Nouveau is primarily the in-kernel DRM/KMS driver (plus older Gallium OpenGL code) that manages GPU memory, display outputs, and command submission. NVK is the modern userspace Vulkan driver in Mesa that translates Vulkan API calls into GPU commands submitted through nouveau (or nova).

Implemented in Mesa for NVIDIA Turing (TU10x) and newer architectures that rely on NVIDIA’s GSP (GPU System Processor) firmware for hardware initialization and power management, NVK replaces Mesa’s legacy TGSI/NIR-to-nv50_ir backend with NAK, a Rust-written SSA shader compiler targeting NVIDIA’s SM75+ ISA. It communicates via the upstream nouveau DRM UAPI (using modern VM_BIND virtual memory management and DRM_SYNCOBJ synchronization) and is designed to transition cleanly onto the nova Rust DRM driver. Because Turing+ GSP firmware handles clock reclocking, NVK avoids the manual power-management bottleneck that limited performance on older Kepler/Maxwell/Pascal cards in nouveau.
