Guide / Glossary A–Z / Terms beginning with N / Normalization

Normalization is a way of arranging tables so each fact is stored in one place.

Instead of writing a customer address on every order, you store it once and link each order to the customer.

Normal forms are a sequence of rules. First normal form removes repeating groups; higher forms remove different kinds of dependence on keys.

Normalization reduces update anomalies but can add joins. Denormalization deliberately restores some duplication when read patterns or analytics make joins too costly.
