Guide / Glossary A–Z / Terms beginning with N / Normalization

Normalization is a way of arranging database tables so each fact is stored in one place.

In a database, instead of writing a customer address on every order, you store it once and link each order to the customer. If the address changes, you edit one row rather than thousands. That is the point of normalization.

Normal forms are a sequence of rules. First normal form removes repeating groups; the higher forms remove different kinds of dependence on keys. A designer chooses a target form from the update patterns and the cost of joining tables back together.

Normalization reduces insert, update and delete anomalies but can add joins. Denormalization deliberately restores some duplication when read patterns or analytics make joins too costly. The word also appears in text processing for Unicode normalization, which is a different operation that puts equivalent character sequences into one agreed form; see Unicode normalization.
