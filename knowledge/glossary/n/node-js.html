Guide / Glossary A–Z / Terms beginning with N / Node.js

Node.js is a program that runs JavaScript on a computer without a browser and supplies files, processes and network services.

A browser gives JavaScript a page to work on. Node.js gives it a command line, files and the ability to answer network requests, so the same language can build a server.

You run a file with node app.js. The process object exposes arguments and environment values. Node supports both CommonJS require() and standard import/export modules.

Name one thing a browser supplies that Node does not, and one thing Node supplies that a browser does not.

A browser supplies a document tree and user input events. Node supplies listening network sockets and filesystem access. Both share the JavaScript language and an event loop.

Node embeds V8 and adds libuv plus JavaScript service code. Its event loop handles asynchronous filesystem and network work while user callbacks run one at a time. Built-in modules are named with the node: prefix, such as node:http and node:crypto.
