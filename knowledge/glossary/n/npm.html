npm

npm is the package manager most JavaScript projects use to install reusable code and run named project scripts.

If a project needs a helper someone else wrote, npm can fetch it and remember which version you chose. It also runs shortcuts such as npm run start.

package.json names the project, lists dependencies and defines scripts. npm install writes the exact resolved tree to package-lock.json, so a later install can repeat the same versions.

Why commit package-lock.json as well as package.json?

package.json states acceptable version ranges; the lockfile records the exact versions installed. Without it, a teammate or deployment can resolve different dependencies and ship different code.

npm resolves a dependency graph from a public or private registry using semantic version ranges. The lockfile pins transitive versions; scripts run at install and lifecycle points can execute code. A software bill of materials helps review what a project really includes.
