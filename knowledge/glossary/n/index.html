Terms beginning with N

Glossary definitions for technical terms and acronyms beginning with N.

Explore

  • NAK (Negative Acknowledge, 0x15) — NAK: ASCII 0x15 control character (Ctrl+U) indicating a transmission error or line kill.
  • Namespace — Namespace: A kernel feature that gives processes isolated views of the system.
  • NAND (NOT-AND) — NAND: The flash memory technology used in SSDs and memory cards.
  • NAT - Network Address Translation — NAT: Rewriting network addresses as packets pass through.
  • ncurses (new curses) — ncurses: A library for building terminal user interfaces.
  • NDP (Neighbor Discovery Protocol) — NDP: IPv6 protocol using ICMPv6 for address resolution, router discovery, and link-layer mapping.
  • Network interface — Network interface: A named connection point for network traffic.
  • NFC (Near Field Communication) — NFC: Short-range (few centimeters) wireless protocol at 13.56 MHz used for security keys and tap cards.
  • NIST P-256 (secp256r1) — NIST P-256: Widely used 256-bit elliptic curve for digital signatures and key exchange.
  • Nix — Nix: Nix is a package manager that installs software into immutable store paths and can reproduce exact environments.
  • NOR (NOR gate / NOR flash) — NOR: Universal logic gate (NOT-OR) and non-volatile flash memory type used for UEFI/BIOS firmware.
  • Notification — Notification: A short message from an application.
  • Nounset — Nounset: A shell option that rejects undefined variables.
  • NOVA (NOVA Microhypervisor) — NOVA: Capability-based microhypervisor separating virtualization control from small kernel mechanisms.
  • NR (New Radio / Non-Return) — NR: 5G New Radio cellular standard (or Non-Return in signaling).
  • NRZ (Non-Return-to-Zero) — NRZ: Binary line coding holding high/low voltage for the entire bit period without returning to zero.
  • NRZI (Non-Return-to-Zero Inverted) — NRZI: Differential line coding encoding bits as presence or absence of a voltage transition.
  • NT (Windows New Technology) — Windows NT: Hybrid kernel architecture underlying all modern Microsoft Windows versions.
  • NTP (Network Time Protocol) — NTP: Protocol for synchronizing system clocks over a network, critical for TLS, Kerberos, and logs.
  • NTT (Number Theoretic Transform) — NTT: Fast Fourier Transform over finite fields used to multiply polynomials in lattice cryptography.
  • NUL (Null character, 0x00) — NUL: ASCII 0x00 byte, used as a C string terminator and padding character.
  • Nut — Nut: learning reference and next steps
  • NVK (NVIDIA Open-Source Vulkan Mesa Driver) — NVK: Open-source userspace Vulkan driver for NVIDIA GPUs in Mesa.
  • NVMe - Non-Volatile Memory Express — NVMe: A fast protocol for storage over PCIe.
  • NX (No-Execute / XD bit) — NX: CPU memory-protection feature marking data pages (stack, heap) non-executable.
