Guide / Glossary A–Z / Terms beginning with N

Glossary definitions for technical terms and acronyms beginning with N.

Explore

NAK (Negative Acknowledge, 0x15)NAK: ASCII 0x15 control character (Ctrl+U) indicating a transmission error or line kill.
NamespaceNamespace: A kernel feature that gives processes isolated views of the system.
NaN (not a number)A floating-point value that marks an undefined or unrepresentable result.
NAND (NOT-AND)NAND: The flash memory technology used in SSDs and memory cards.
NAT (Network Address Translation)NAT: Rewriting network addresses as packets pass through.
Natural scrollingNatural scrolling: A touchpad or mouse-wheel direction setting where moving fingers downward pushes page content downward, like a touchscreen.
ncurses (new curses)ncurses: A library for building terminal user interfaces.
NDP (Neighbor Discovery Protocol)NDP: IPv6 protocol using ICMPv6 for address resolution, router discovery, and link-layer mapping.
Network interfaceNetwork interface: A named connection point for network traffic.
NFC (Near Field Communication)NFC: Short-range (few centimeters) wireless protocol at 13.56 MHz used for security keys and tap cards.
Night lightNight light: A display color-temperature filter that reduces blue light in the evening to make the screen warmer and easier on the eyes.
NIST (National Institute of Standards and Technology)NIST (National Institute of Standards and Technology): U.S. agency that develops measurement standards, technology guidance and public standards such as FIPS.
NIST P-256 (secp256r1)NIST P-256: Widely used 256-bit elliptic curve for digital signatures and key exchange.
NixNix: Nix is a package manager that installs software into immutable store paths and can reproduce exact environments.
Node.jsNode.js: A runtime that runs JavaScript outside a browser with files, processes and network services.
NOR (NOR gate / NOR flash)NOR: Universal logic gate (NOT-OR) and non-volatile flash memory type used for UEFI/BIOS firmware.
NormalizationNormalization: organizing tables to reduce duplicated data and anomalous updates.
NoSQLNoSQL: a family of data stores that do not require a fixed relational table schema.
NotificationNotification: A short message from an application.
NounsetNounset: A shell option that rejects undefined variables.
NOVA (NOVA Microhypervisor)NOVA: Capability-based microhypervisor separating virtualization control from small kernel mechanisms.
npmnpm: The package manager that installs, records and runs reusable JavaScript project code.
NR (New Radio)NR (New Radio): the 5G radio technology used between a phone and a cell site.
NRZ (Non-Return-to-Zero)NRZ: Binary line coding holding high/low voltage for the entire bit period without returning to zero.
NRZI (Non-Return-to-Zero Inverted)NRZI: Differential line coding encoding bits as presence or absence of a voltage transition.
NSEC (Next Secure)NSEC: a DNSSEC record that proves a name or record type does not exist by naming the next existing name in a signed zone.
NSS (Name Service Switch)NSS: the Name Service Switch, a glibc mechanism that decides which sources provide names such as users, hosts, and services.
NT (Windows New Technology)Windows NT: Hybrid kernel architecture underlying all modern Microsoft Windows versions.
NTP (Network Time Protocol)NTP: Protocol for synchronizing system clocks over a network, critical for TLS, Kerberos, and logs.
NTT (Number Theoretic Transform)NTT: Fast Fourier Transform over finite fields used to multiply polynomials in lattice cryptography.
NUL (Null character, 0x00)NUL: ASCII 0x00 byte, used as a C string terminator and padding character.
Number portabilityNumber portability: the ability to keep a phone number when changing mobile carrier.
NV12A semi-planar 8-bit 4:2:0 video layout.
NVK (NVIDIA Open-Source Vulkan Mesa Driver)NVK: Open-source userspace Vulkan driver for NVIDIA GPUs in Mesa.
NVMe (Non-Volatile Memory Express)NVMe: A fast protocol for storage over PCIe.
NX (No-Execute / XD bit)NX: CPU memory-protection feature marking data pages (stack, heap) non-executable.
NXDOMAIN (Non-Existent Domain)NXDOMAIN: a DNS response code meaning the queried domain name does not exist.
Nyquist criterionA signal must be sampled more than twice as fast as its highest frequency to be recoverable.
