Guide / Glossary A–Z / Terms beginning with N / Named instance

A named instance is a predefined setting of a variable font, such as Bold or Condensed Italic.

A variable font has sliders, but most people just want familiar options like Regular or Bold. Named instances are those ready-made settings, so a user can pick a style without knowing the axis values.

Applications list named instances in font menus, and CSS can select them through ordinary font-weight or font-stretch values. Designers also export a static font from a chosen instance for software without variable-font support.

Named instances are declared in the fvar table with a subfamily name ID, a flags field and coordinates for each axis; flags can mark hidden or preferred instances. Coordinates outside an axis range are invalid. Exporting a static instance resolves designspace rules and axis limits, dropping variant tables such as gvar.
