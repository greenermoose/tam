Nut

In the Tamlinux plant analogy, a nut is a planned small environment that can start a computer.

In Tamlinux’s plant-themed naming, a “nut” is the name for a compact, self-contained startup environment—like a seed that holds just enough to get a computer running. The idea is a tiny system meant only to boot, inspect what is on the machine, and prepare the next step, rather than a full everyday desktop.

The public design describes a small kernel/initramfs or Unified Kernel Image (UKI) environment for inspection and preparation, contrasting with a full installed desktop system. Because it is a planned design concept rather than an already-shipped component, do not assume a nut image is present on an existing Tamlinux system; check the actual boot entries and current documentation before relying on it.

Should you assume a Tamlinux system already has a Nut boot environment installed?

No. Nut is a planned minimal bootable environment in the Tamlinux design, not a guaranteed installed artifact—always verify the actual boot configuration and current product plan.

In architectural terms, Nut designates a proposed minimal boot/recovery layer (scoped as a small kernel/initramfs or UKI) rather than a claim that a signed immutable image or working network bootstrap is currently delivered. When evaluating or troubleshooting boot behavior, treat Nut strictly as a design-level term and consult the live bootloader configuration, installed UKIs or initramfs images, and current project plan for what is actually built and deployed.
