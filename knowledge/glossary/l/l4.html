L4 (L4 microkernel family)

A family of minimal, high-performance operating system kernels—including seL4—that keep only core isolation and messaging inside the kernel.

In most operating systems, device drivers, filesystems, and networking all live inside one giant, all-powerful core, so a bug in one driver can crash the entire machine. L4 takes the opposite approach—like an apartment building with locked units and a tiny security desk in the lobby. The kernel only checks badges and passes messages; drivers and filesystems run outside as separate programs, so a fault in one cannot corrupt the rest.

Unlike first-generation microkernels such as Mach, which suffered from slow message passing, L4 achieves high speed and is used in hypervisors, security enclaves, and high-assurance embedded systems. Modern seL4 goes further by mathematically proving in machine-checked proofs that its C code matches its security specification.

Why did L4 succeed where earlier microkernels like Mach struggled with performance?

Early microkernels copied data repeatedly and used complex messaging paths across kernel boundaries. L4 redesigned inter-process communication around fast register-based message passing and minimal kernel abstractions, cutting context-switch and messaging overhead by an order of magnitude.

Descending from Jochen Liedtke’s minimality principle (a concept belongs in the kernel only if moving it out prevents implementing required functionality), the second-generation L4 lineage (L4Ka::Pistachio, Fiasco.OC, OKL4, seL4) shrinks the trusted computing base to address spaces, threads, and synchronous IPC. seL4 replaces ambient authority with capability-based access control (CSpaces and CNodes), delegates physical memory allocation to user space via Untyped objects so the kernel never allocates dynamically, and provides Isabelle/HOL proofs of functional correctness and information-flow non-interference—trading off driver porting effort, IPC marshaling costs for high-throughput I/O, and multicore contention on shared endpoints.
