Guide / Glossary A–Z / Terms beginning with L / LSB (Least Significant Bit)

The LSB (Least Significant Bit) is the lowest-value bit in a binary number—representing 1 (2^0)—and in many serial protocols it is the first bit sent over the wire.

In everyday base-10 numbers like 347, the rightmost digit (7) is the ones place—changing it only shifts the total by 1, whereas changing the leftmost digit shifts it by hundreds. Binary numbers work the same way using 0s and 1s: the rightmost bit is the ones place, called the Least Significant Bit. Checking whether that single bit is 0 or 1 immediately tells you whether a whole number is even or odd.

In C and shell scripting, testing (x & 1) isolates the LSB to check parity or read bit 0 of a hardware status register. On the wire, standard UART serial (such as RS-232) transmits each byte LSB-first right after the start bit, whereas SPI devices often default to MSB-first unless configured otherwise. Watch out for capitalization: lowercase lsb or LSB in bit-numbering means Least Significant Bit, whereas in Linux packaging discussions LSB can also refer to the historical Linux Standard Base.

If you send the ASCII letter 'A' (0x41, binary 01000001) over a standard 8N1 UART line, which data bit arrives first after the start bit?

The 1 bit at position 0 (the LSB) arrives first, followed by five 0 bits, a 1 bit, and a final 0 bit before the stop bit. Because UART transmits LSB-first, logic analyzers and oscilloscope decoders read the waveform in reverse order compared to written binary notation.

Bit 0 carries weight 2^0 in unsigned and two’s-complement representations; in IEEE 754 floating-point, flipping the LSB of the significand shifts the value by 1 ULP (unit in the last place). Do not confuse bit transmission order with byte endianness: little-endian CPUs store the least significant byte at the lowest memory address, while bit numbering within a byte or register can follow either LSB-0 (standard in x86/ARM) or MSB-0 (used in some PowerPC/network RFC diagrams). IEEE 802.3 Ethernet and UART transmit each octet LSB-first on the physical medium, whereas I2C transmits MSB-first.
