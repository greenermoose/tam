Guide / Glossary A–Z / Terms beginning with L / Ligature

A ligature is one glyph that visually combines two or more letters, such as fi or fl.

When the letters f and i appear together, the dot of the i can collide with the f's top curve. A font often draws them as a single joined shape. That joined shape is a ligature.

Standard ligatures such as fi, fl and ff are enabled by the OpenType liga feature; discretionary ones use dlig. Ligatures do not change the underlying text: copying it still gives the original letters. Some programming fonts offer coding ligatures for symbols such as =>, which can be disabled if they confuse readers.

Ligatures are GSUB substitution lookups, commonly type 4, with component glyph records that shapers use to build cluster maps. HarfBuzz applies required ligatures (rlig) for scripts such as Arabic regardless of user settings, while optional ones depend on feature toggles. A ligature can span several glyphs, so editors use the shaper's cluster map for selection and caret placement.
