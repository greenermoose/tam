LMDE (Linux Mint Debian Edition)

Linux Mint Debian Edition (LMDE), a variant of the Linux Mint desktop distribution built directly on Debian Stable rather than Ubuntu.

Most people know Linux Mint as a friendly desktop system built on top of Ubuntu, which itself is built on Debian. LMDE skips the Ubuntu step in the middle and builds the same familiar Mint desktop directly on Debian. The Mint team maintains it as a backup plan and an alternative for users who prefer Debian’s slower, steady pace.

While standard Linux Mint follows Ubuntu’s Long Term Support (LTS) releases every two years and uses Ubuntu’s package repositories, LMDE tracks Debian Stable and pairs it with Mint’s Cinnamon desktop, Update Manager, and configuration tools. As a result, LMDE uses Debian’s apt sources and release cadence directly, with fewer Ubuntu-specific PPAs or hardware enablement (HWE) kernels.

What is the main practical difference between standard Linux Mint and LMDE?

Standard Linux Mint is based on Ubuntu LTS, whereas LMDE is based directly on Debian Stable. Both ship the Cinnamon desktop and Mint tools, but LMDE draws its underlying packages and security updates from Debian rather than Ubuntu, and serves as Mint’s independent fallback if Ubuntu ever diverges too far.

LMDE provides a Debian-Stable-tracked base combined with Linux Mint’s Cinnamon desktop environment, XApps, and Mint-specific APT repository overlays, bypassing Ubuntu’s archive, Snap integration, and HWE kernel tracks. Package resolution relies on Debian’s release cycle with selective Mint-maintained backports and artwork/tooling packages pinned via APT preferences, which means Ubuntu PPAs are generally incompatible and newer hardware support depends on Debian Backports kernels rather than Ubuntu HWE.
