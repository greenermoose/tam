Guide / Glossary A–Z / Terms beginning with L / loca

The loca table is an index that tells a renderer where each glyph's outline begins in the glyf table.

If all the letter shapes are stored together in one long list, the renderer needs a table of contents to find each one. loca is that table of contents for TrueType outlines. Empty glyphs point to the same place twice.

Each entry is an offset into glyf; the length of a glyph's data is the difference between consecutive offsets. The table's format, short or long offsets, is declared in head.indexToLocFormat.

Short offsets are unsigned 16-bit values divided by two, allowing glyf sizes up to about 128 KB; long offsets are 32-bit values for larger fonts. The table has numGlyphs + 1 entries, with the last giving total glyph-data length. Validators check that offsets are monotonic and word-aligned; CFF-based OpenType fonts have no loca table.
