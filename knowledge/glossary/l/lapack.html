LAPACK (Linear Algebra Package)

LAPACK solves larger matrix problems using the small operations supplied by BLAS.

If BLAS provides the basic steps for working with lists and grids of numbers, LAPACK combines those steps into answers such as solving an equation or finding the main directions in a set of data.

Common LAPACK jobs include solving systems of linear equations, least-squares fitting, eigenproblems and matrix factorizations such as LU, QR, Cholesky and SVD. A program can call the same routine names on different machines and get tuned behaviour from the underlying BLAS. Choosing a routine means knowing the matrix shape and properties: symmetric, positive definite, dense or banded.

Why does it matter whether a matrix is symmetric or positive definite?

Special properties allow faster, more stable factorizations such as Cholesky instead of a general LU decomposition. Using the wrong routine can waste work or produce unreliable answers.

LAPACK routine names encode data type, matrix property and operation, for example DSYEV for a double symmetric eigenproblem. Blocked algorithms use level-3 BLAS so that most work happens on cached tiles. ScaLAPACK extends the model to distributed memory. Numerical behaviour depends on pivoting, condition number and scaling; a correct factorization can still amplify input error for an ill-conditioned matrix.
