Guide / Glossary A–Z / Terms beginning with L / LLVM

A modular compiler infrastructure that provides shared optimization and code-generation tools for languages such as C, C++, Rust, Zig, and Mesa GPU shaders.

Building a compiler from scratch for every programming language and every kind of processor chip would take enormous effort. LLVM solves this by providing a shared workshop of middle-stage tools: different languages translate their code into LLVM’s common format, and LLVM handles speeding up that code and translating it for x86, ARM, or graphics chips.

Instead of each compiler reinventing optimizers and CPU backends, front ends like clang (C/C++), rustc (Rust), and zig emit LLVM Intermediate Representation (IR). On Linux, LLVM also powers Mesa’s llvmpipe and radeonsi shader compilers, plus the lld linker and lldb debugger. Knowing whether a package builds with GCC or LLVM/Clang helps when reading compiler flags, sanitizer options, or Link-Time Optimization (LTO) settings.

How does LLVM’s Intermediate Representation (IR) reduce duplicate work across programming languages and CPU architectures?

Each language front end only needs to translate source code into LLVM IR once, and each hardware backend only needs to translate LLVM IR to machine code once. Language-independent optimizations run on the shared IR in the middle, so improvements benefit every language and target architecture together.

LLVM is organized as a library-based compiler framework centered on a strongly typed, infinite-register Static Single Assignment (SSA) Intermediate Representation (LLVM IR), represented in memory, human-readable .ll text, or compact .bc bitcode. The opt pass manager runs target-independent and target-aware analyses and transforms (such as SROA, GVN, loop vectorization, and ThinLTO cross-module inlining) before SelectionDAG or GlobalISel lowers IR to machine instructions. The broader LLVM project also ships lld, compiler-rt, and instrumentation runtimes for AddressSanitizer (ASan), UndefinedBehaviorSanitizer (UBSan), and libFuzzer.
