Guide / Glossary A–Z / Terms beginning with L / Lockfile

A generated file that records the exact versions and checksums of every software dependency resolved for a project.

Software projects rarely stand alone—they depend on dozens of helper libraries that themselves update over time. A manifest file says roughly which helpers a project wants, while a lockfile writes down the exact version of every helper that was actually installed, like a precise recipe card so another computer can recreate the exact same setup later.

Tools such as Cargo.lock, package-lock.json, flake.lock, and poetry.lock pin transitive dependencies that a manifest (Cargo.toml, package.json, flake.nix) leaves as ranges or floating inputs. For applications and reproducible environments, committing the lockfile to version control ensures every developer and build server gets identical inputs; note that this is different from a runtime .lock or .pid file used to prevent two processes from writing to the same resource at once.

Why do projects keep both a manifest file and a lockfile instead of putting exact versions only in the manifest?

The manifest expresses the human-authored constraints and direct dependencies, while the lockfile records the complete resolved graph including indirect (transitive) dependencies and integrity hashes. Keeping them separate lets developers declare flexible ranges for direct packages while still guaranteeing identical, reproducible builds across machines.

A dependency lockfile serializes the full resolved directed acyclic graph (DAG) of direct and transitive packages—capturing exact version identifiers, source URIs or git revisions, and cryptographic content hashes (such as SHA-256 or SRI digests). By bypassing the SAT/PubGrub solver during routine builds, lockfiles guarantee deterministic fetches and detect upstream tampering or silent re-tagging when hashes mismatch. In Nix flakes (flake.lock) or language package managers, updating a single input selectively re-solves affected subgraphs while holding unrelated pins fixed.
