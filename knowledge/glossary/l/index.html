Terms beginning with L

Glossary definitions for technical terms and acronyms beginning with L.

Explore

  • L1 cache (Level 1 cache) — L1 cache: Fastest, smallest on-core CPU cache split into instruction (L1i) and data (L1d).
  • L2 cache (Level 2 cache) — L2 cache: Mid-tier per-core (or cluster-shared) CPU cache backing L1.
  • L3 cache (Level 3 / Last-Level Cache) — L3 cache: Large on-die SRAM cache shared across CPU cores to reduce main-RAM accesses.
  • L4 (L4 microkernel family) — L4: Family of minimal, high-performance second-generation microkernels (including seL4).
  • Latency — Latency: The delay before data arrives.
  • Lattice — Lattice: A regular grid of points in many dimensions used to build quantum-safe cryptography.
  • LCD - Liquid-Crystal Display — LCD: A flat display that controls light with liquid crystals.
  • LDPC (Low-Density Parity-Check) — LDPC: Modern capacity-approaching forward error-correction code used in Wi-Fi, 10GBASE-T, and SSDs.
  • Least privilege — Least privilege: Giving every user, program, or process only the minimum rights needed for its job.
  • LF (Line Feed, 0x0A) — LF: ASCII 0x0A control character (Ctrl+J, '\n') used as the Unix newline.
  • libc (C standard library) — libc: The standard C library.
  • libncursesw (wide-character new curses library) — libncursesw: The wide-character version of ncurses.
  • Library — Library: Reusable code that programs can call.
  • Limine — Limine: Limine is the bootloader Tamlinux uses to present boot choices and load the Linux kernel.
  • Line discipline — Line discipline: Kernel software layer between a TTY/PTY driver and user programs that handles line editing and signals.
  • Linker — Linker: A program that combines object files into an executable or library.
  • LK201 (DEC Keyboard) — LK201: 1983 DEC terminal keyboard whose layout and key codes shaped VT220 escape sequences.
  • LLL (Lenstra-Lenstra-Lovasz) — LLL: Polynomial-time lattice basis-reduction algorithm.
  • LLM (Large Language Model) — LLM: Neural-network model trained on text to answer questions, summarize, and assist with code.
  • LLVM — LLVM: Modular compiler infrastructure powering Clang, Rust, Zig, and Mesa shader compilers.
  • LMDE (Linux Mint Debian Edition) — LMDE: Linux Mint variant built directly on Debian Stable rather than Ubuntu.
  • LMS (Leighton-Micali Signature) — LMS: Stateful hash-based post-quantum signature scheme (RFC 8554 / NIST SP 800-208).
  • Lock screen — Lock screen: A screen that blocks access until you authenticate.
  • Lockfile — Lockfile: A file that records exact dependency versions.
  • Log — Log: A record of events written by software.
  • Logic gate — Logic gate: A circuit that performs a basic logical operation.
  • Loopback — Loopback: A virtual interface that sends traffic back to the same machine.
  • LR (Long Reach / Link Register) — LR: 10 km single-mode fiber optic standard (e.g., 10GBASE-LR), or ARM Link Register.
  • LRU (Least Recently Used) — LRU: Cache or memory-page replacement policy evicting items that have gone unused the longest.
  • LSB (Least Significant Bit) — LSB: Lowest-value bit (2^0) in a binary number, or first bit transmitted in UART serial.
  • LUKS - Linux Unified Key Setup — LUKS: The standard Linux disk-encryption format.
  • LUKS2 (Linux Unified Key Setup version 2) — LUKS2: Modern Linux disk-encryption header format supporting Argon2id, integrity tags, and TPM2.
  • Luminance — Luminance: The brightness of light emitted or reflected.
  • LZ4 — LZ4: Extremely fast lossless compression algorithm ideal for zram swap and initramfs.
