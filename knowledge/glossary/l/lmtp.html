Guide / Glossary A–Z / Terms beginning with L / LMTP (Local Mail Transfer Protocol)

LMTP is a variant of SMTP used for the final handoff into a mailbox system.

The letters stand for Local Mail Transfer Protocol. It is like handing a letter directly to the final pigeonhole clerk instead of sending it through another sorting office.

LMTP looks similar to SMTP but reports the result for each recipient separately. That matters when one message has several local recipients and one mailbox is full or unknown.

LMTP is defined in RFC 2033 and intentionally has no queueing: the caller remains responsible for retrying. It is commonly used between an MTA and an MDA or message store. LMTP is a final-delivery protocol, not a replacement for SMTP relay between domains.
