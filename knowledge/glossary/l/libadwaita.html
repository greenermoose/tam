Guide / Glossary A–Z / Terms beginning with L / libadwaita

libadwaita is a library built on GTK that supplies GNOME-style widgets and application patterns.

GNOME applications often use libadwaita for header bars, preferences windows and layouts that adapt to narrow screens. It adds a consistent style on top of GTK's basic widgets.

libadwaita provides components such as view switchers, status pages, clamp containers and style classes. GTK handles the lower-level drawing and events; libadwaita shapes them into GNOME's interface guidelines.

libadwaita versions track GNOME releases and may require a recent GTK. Its adaptive widgets respond to available width rather than only to a device name. It is a toolkit-layer library, not part of the compositor or display protocol.
