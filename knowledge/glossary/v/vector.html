Vector

A vector is an ordered list of numbers that is handled as one thing.

A wind report with speed and direction is two numbers that belong together. A colour with red, green and blue amounts is another. Each is a vector: order matters because the first number means something different from the second.

Vectors can be added by adding matching entries, or scaled by multiplying every entry. A linear algebra dot product multiplies matching entries of two equal-length vectors and adds the products. A matrix can transform a vector into another vector, which is how graphics code rotates or scales points.

Are two vectors with the same numbers in a different order the same?

No. A vector is ordered. The list [3, 1] and the list [1, 3] can describe different positions, directions or colour mixtures.

In mathematics a vector is an element of a vector space; coordinates depend on a chosen basis. In programs the word often means a contiguous array of numbers, which may also be called a vector in BLAS. Stride describes the gap between successive elements in memory: a stride of one is contiguous, while a larger stride can cost cache efficiency. SIMD registers operate on a small fixed number of lanes at once.
