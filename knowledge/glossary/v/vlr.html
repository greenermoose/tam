Guide / Glossary A–Z / Terms beginning with V / VLR (Visitor Location Register)

VLR (Visitor Location Register): the temporary subscriber record held by the network a phone is currently visiting.

A VLR is a temporary record in the network a phone is using right now. It holds enough information to serve the subscriber without asking the home network for every step.

When a phone moves into a new area, the visited network creates or updates a visitor record. The old record can be removed once it is no longer needed.

3GPP TS 29.002 defines VLR procedures with the HLR and MSC. A VLR is about mobility state, not about storing the content of text messages.
