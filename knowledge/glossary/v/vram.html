Guide / Glossary A–Z / Terms beginning with V / VRAM (Video Random-Access Memory)

VRAM (Video Random-Access Memory) is high-speed memory dedicated to a graphics processor for storing images, textures, and rendering data.

Just as your main processor uses system RAM as a workbench for open apps, a graphics card needs its own ultra-fast workbench right next to the graphics chip. VRAM holds the 3D models, textures, and finished frames ready to be shown on your monitor. If a game or video editor needs more VRAM than the card has, performance drops sharply because the computer has to shuttle data back and forth from slower main memory.

Discrete GPUs use dedicated GDDR or HBM VRAM soldered onto the graphics card, whereas integrated GPUs (APUs) share system DDR/LPDDR memory—sometimes with a fixed BIOS carve-out plus dynamic allocation via the kernel’s DRM/TTM or GEM memory managers. Under Linux, you can inspect VRAM usage with tools like nvtop, radeontop, or nvidia-smi, and notice that Wayland compositors, browser tabs, and local AI models all compete for the same VRAM pool.

Why does exceeding a discrete GPU’s VRAM capacity hurt frame rates far more than simply having slightly slower VRAM?

When VRAM fills up, the GPU driver must evict textures or buffers across the PCIe bus into host system RAM (or swap). PCIe bandwidth is an order of magnitude lower—and latency much higher—than on-card GDDR/HBM, causing frame stalls while the GPU waits for spilled buffers.

VRAM architectures (GDDR6/6X/7 and HBM2e/3) prioritize wide memory buses and high aggregate bandwidth (hundreds to thousands of GB/s) over low single-word latency, matching the massively parallel coalesced access patterns of GPU warps/wavefronts. In the Linux DRM subsystem, TTM/GEM manages buffer objects (BOs) across device-local VRAM, GTT (Graphics Translation Table) aperture mappings over PCIe, and CPU-visible BARs. Enabling Resizable BAR (ReBAR) exposes the full VRAM aperture to the CPU rather than a 256 MiB window, reducing staging copies for uploads while still requiring explicit cache/synchronization fences (dma_fence).
