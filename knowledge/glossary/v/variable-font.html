Guide / Glossary A–Z / Terms beginning with V / Variable font

A variable font is one font file that can produce many styles by changing settings called axes.

Instead of downloading a separate file for regular, bold and condensed, one variable font can supply all of them. You move a slider to get the style you want. The letters change smoothly between the extremes.

Variable fonts reduce downloads and let a designer choose an in-between weight that no static file provides. Common axes control weight, width, slant and optical size. Applications expose them through font menus or CSS properties, and a named instance offers familiar presets.

The fvar table declares axes with minimum, default and maximum coordinates and defines named instances; avar can remap values. TrueType outlines vary through gvar deltas and metrics through HVAR and VVAR, while CFF2 uses VarStore deltas. Interpolation is linear between masters, so axis extremes must share compatible point counts and contour order.
