Guide / Glossary A–Z / Terms beginning with V / VoLTE (Voice over Long-Term Evolution)

VoLTE (Voice over Long-Term Evolution): carrying voice calls as IP packets over an LTE data connection using IMS.

VoLTE is a phone call carried over the 4G data network instead of the older circuit-switched voice network. It uses the same internet-style service platform as RCS.

If VoLTE is unavailable, a phone may fall back to older voice service. That fallback is about the call path, not about ordinary short texts.

3GPP TS 23.228 and TS 24.229 define the IMS architecture and SIP procedures used by VoLTE. QoS marking and codec negotiation distinguish the call from best-effort internet traffic.
