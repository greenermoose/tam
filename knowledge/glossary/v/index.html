Terms beginning with V

Glossary definitions for technical terms and acronyms beginning with V.

Explore

VA-APIA programming interface for accelerated video processing.
VariableVariable: A named place that holds a value.
VCSEL (Vertical-Cavity Surface-Emitting Laser)VCSEL: Low-cost semiconductor laser emitting vertically from the wafer surface, used in short-reach multimode fiber.
Vector graphicsVector graphics: Images described by shapes and lines rather than pixels.
Version controlVersion control: Software that tracks changes to files over time.
VESA - Video Electronics Standards AssociationVESA: The standards body behind many display interfaces.
VFIO (Virtual Function I/O)VFIO: Linux kernel framework for safely passing physical PCIe devices (like GPUs) to userspace or VMs.
VFS (Virtual File System)VFS: Linux kernel abstraction layer giving all filesystems (ext4, Btrfs, procfs, FUSE) one uniform API.
VGA - Video Graphics ArrayVGA: An old analog video connector and mode.
Video codecA method or program for encoding or decoding video.
Video color rangeThe numeric range used for image component values.
Video compressionRepresenting video with fewer bits.
Video hardware decodingUsing dedicated hardware to decode compressed video.
Video4Linux2 (V4L2)A Linux interface for video capture and other media devices.
Virtual consoleVirtual console: definition and recovery boundary at each level
Virtual machineVirtual machine: A software-defined computer.
VLSI (Very-Large-Scale Integration)VLSI: Fabrication of microchips packing millions to billions of transistors onto one silicon die.
VMX (Virtual Machine Extensions)VMX: Intel VT-x hardware virtualization instruction-set extensions.
VoltageVoltage: electrical pressure that pushes electric charges through a conductor
VPN - Virtual Private NetworkVPN: A private tunnel over a public network.
VRAM - Video Random-Access MemoryVRAM: Memory used by a graphics processor.
VRM (Voltage Regulator Module)VRM: Multi-phase DC-DC buck converter on a motherboard stepping 12 V/20 V down to ~1 V for the CPU/GPU.
VT (Virtual Terminal / Virtual Console)VT: Kernel-provided text console (tty1-ttyN) or historical DEC Video Terminal.
VT102 (DEC Video Terminal)VT102: 1982 DEC hardware terminal whose escape sequences shaped the Linux console.
VT220 (DEC Video Terminal)VT220: 1983 DEC terminal that introduced 8-bit C1 controls and numeric function-key sequences.
VTE (Virtual Terminal Emulator library)VTE: GTK widget library powering GNOME Terminal and several Linux terminal emulators.
