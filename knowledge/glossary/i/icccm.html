Guide / Glossary A–Z / Terms beginning with I / ICCCM

ICCCM is a set of conventions that help X11 applications and window managers cooperate.

The X protocol does not define everything about an ordinary window. These conventions say how a window asks to be closed, which window has focus and how selections such as copied text are shared.

ICCCM properties are values stored on windows, such as a name, size hints or a protocol list. A window manager reads them to decorate or place a window; applications read them to learn about state. EWMH extends these conventions for modern desktops.

The Inter-Client Communication Conventions Manual covers properties, selections, focus, colour maps and window manager behaviour. It is convention rather than core protocol: clients and window managers must both implement it for predictable results.
