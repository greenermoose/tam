Guide / Glossary A–Z / Terms beginning with I / IMAP (Internet Message Access Protocol)

IMAP is a mail access protocol that keeps messages on the server and lets a client work with folders and flags there.

The letters stand for Internet Message Access Protocol. Instead of taking letters home, the client reads them in the server's filing cabinet and leaves marks such as read or flagged beside them.

IMAP supports server-side folders, message flags, partial fetches and search. A client can show a message header first and download the body only when needed. The IDLE extension lets a connected client hear about new mail without repeatedly polling.

RFC 3501 defined IMAP4rev1 and is obsolete; RFC 9051 defines IMAP4rev2. IMAP synchronizes metadata with the server but does not change how servers transfer mail to one another: that remains SMTP. IMAP normally uses implicit TLS on port 993; RFC 8314 treats cleartext access as obsolete.
