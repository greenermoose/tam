Guide / Glossary A–Z / Terms beginning with I / IP (Internet Protocol)

IP (Internet Protocol) is the rule set that carries data across the internet in small addressed units. It says how a unit is labelled and where it should go, but it does not promise delivery or manage a conversation.

Think of IP as the addressing and routing part of the internet. A message is split into packets, each carrying the address of its destination. Routers read those addresses and pass each packet onward. The packets may take different paths and arrive out of order.

IP is a protocol, not an address. An IP address names an endpoint; IP is the agreement about how packets are formatted and forwarded. TCP and UDP sit above IP and give applications different ways to use that packet service. IP itself is best effort: it can drop, delay or reorder a packet without telling the sender.

RFC 791 defines IPv4: a 32-bit address field, a datagram header, a time-to-live limit and fragmentation with reassembly. RFC 8200 defines IPv6 with a 128-bit address space and a simpler header. ICMP reports errors and reaches for diagnostics beside the protocol. Wording that calls an address or a network connection simply "IP" is shorthand; the precise sense is usually an IP address, the protocol family, or a product name.
