Guide / Glossary A–Z / Terms beginning with I / IMEI (International Mobile Equipment Identity)

IMEI (International Mobile Equipment Identity): the identifier of the phone hardware itself, separate from the subscription.

An IMEI names the phone, not the person or the mobile plan. It stays with the hardware when the SIM is removed.

If a phone is lost, an owner may report its IMEI so a carrier can block the device. That does not cancel the subscription, which is controlled through the SIM or account.

3GPP TS 23.003 covers equipment identities. An IMEI includes a type allocation code and a serial number. It is not an authentication secret and should not be treated as proof that a particular person is using the phone.
