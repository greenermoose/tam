IPv6 (Internet Protocol version 6)

The modern addressing system of the internet, which writes each device's number as hexadecimal groups such as 2001:db8::1.

IPv6 is the newer way of giving devices addresses. Its addresses are much longer than IPv4 addresses, so there is room for every device to have its own without sharing. An address looks like 2001:db8::1: groups of letters and numbers separated by colons, where :: stands for a run of zeros. Your computer still uses the address the same way — to receive data addressed to it and to send replies back.

New words

IP address
The number that identifies a device on a network.
NDP (Neighbor Discovery Protocol)
The IPv6 method for finding neighbours and routers on the local link.
ICMPv6
The control and error messages that IPv6 relies on for basic operation.
Prefix length
The number of leading bits that name the network rather than the device.

An IPv6 address is 128 bits, written as eight 16-bit groups in hexadecimal. A group of zeros can be left out, and one :: may replace a continuous run of zero groups: 2001:db8:0:0:0:0:0:1 becomes 2001:db8::1. The loopback address is ::1. A normal local network uses a /64 prefix. Addresses beginning fe80:: are link-local and need a scope suffix on Linux, such as fe80::1%enp1s0, because the same prefix can exist on several interfaces. A device can configure its own global address from a router advertisement (SLAAC) or receive one from DHCPv6; it finds neighbours with NDP instead of ARP, and there is no broadcast.

Why does fe80::1 need an interface name such as %enp1s0 after it?

Link-local addresses are valid only on one link, and every interface can use the same fe80::/10 prefix. The scope suffix tells the kernel which interface to send on, so the address is unambiguous when a machine has two network cards.

IPv6 is specified in RFC 8200. Its base header is a fixed 40 bytes: version, traffic class, flow label, 16-bit payload length, an 8-bit Next Header that chains optional extension headers (routing, fragmentation, authentication, encapsulation), an 8-bit hop limit, and two 128-bit addresses. There is no header checksum and no in-path fragmentation; links must carry at least 1280 bytes and senders discover the path MTU through ICMPv6 "Packet Too Big" messages. ICMPv6 (Next Header 58) is mandatory, carrying Neighbor Solicitation/Advertisement and Router Advertisement for NDP, multicast group management, and errors. Address types include global unicast, unique local fc00::/7, link-local fe80::/10, multicast ff00::/8, and anycast; an interface identifier may be derived from EUI-64 or randomized under RFC 8981 privacy extensions. Solicited-node multicast replaces broadcast for address resolution. Dual-stack hosts run both families, and transition mechanisms such as tunnels and NAT64 bridge to IPv4.
