IRC (Internet Relay Chat)

Classic real-time text chat protocol used by Linux distributions and open-source developer communities.

IRC is a straightforward, text-only group chat system that has been connecting programmers and Linux users since the late 1980s. You pick a nickname, connect to a network, and join topic-based rooms called channels—such as #linux or a specific project’s support room—where messages appear live without heavy web interfaces, ads, or algorithms.

In open-source ecosystems, networks such as Libera.Chat and OFTC host official channels for Linux distributions, the kernel, and desktop projects. Channels start with # (or ##), users are identified by a nick and hostmask (nick!user@host), and clients range from terminal tools like irssi and weechat to GUI apps. Unlike modern chat apps, standard IRC does not store offline history on the server for you, so regulars often keep a bouncer (like znc or soju) running on an always-on host to stay connected and replay missed messages.

Why do many IRC users run a bouncer instead of just closing and reopening their IRC client?

Classic IRC only delivers messages to clients that are actively connected at the moment a line is sent. A bouncer stays logged in continuously on an always-on host, logs channel traffic while your laptop is asleep, and replays the backlog when you reconnect.

Rooted in RFC 1459 and RFC 2812, IRC is a line-oriented, stateful client-server and server-server spanning-tree protocol over TCP/TLS (commonly port 6697 for TLS). Messages follow [:prefix] COMMAND [params...] [:trailing]\r\n with a traditional 512-byte line limit, which exposes classic edge cases such as nick collisions, netsplits (when inter-server links drop and partition channel state), and lack of built-in message persistence or end-to-end encryption. Modern IRCv3 extensions address several of these gaps via capability negotiation (CAP LS 302), SASL authentication, message tags (@time=...), chathistory, and bouncer-friendly specs while remaining backward-compatible with legacy clients.
