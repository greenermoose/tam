iGPU - Integrated Graphics Processing Unit

Graphics processing hardware built into the same chip or package as the CPU, sharing system memory.

Instead of using a separate, dedicated graphics card with its own memory, an iGPU is graphics circuitry built right into the main processor. Because it shares the computer’s main RAM and power budget, it keeps laptops thin, cool, and quiet while handling everyday displays, web browsing, and video smoothly.

Integrated graphics (such as Intel UHD/Arc or AMD Radeon graphics in an APU) uses system RAM instead of dedicated VRAM, so total memory capacity and dual-channel RAM speed directly affect graphics performance. On Linux, iGPUs rely on open-source kernel drivers (i915/xe or amdgpu) exposed under /dev/dri/renderD*; laptops with a second discrete GPU use hybrid graphics to keep desktop rendering on the low-power iGPU.

Why does upgrading a laptop from single-channel to dual-channel RAM often improve iGPU performance?

An iGPU has no dedicated video memory, so it competes with the CPU for system RAM bandwidth; dual-channel RAM doubles that memory bandwidth.

An iGPU resides on the CPU die or package, sharing the coherent memory controller, interconnect fabric, and often the last-level cache (LLC). This unified memory architecture enables zero-copy CPU–GPU buffer sharing via Linux DMA-BUF (PRIME) without PCIe copy overhead, at the cost of memory-bandwidth contention and shared thermal/TDP headroom where heavy GPU loads throttle CPU boost clocks. In Linux DRM/KMS, GEM/TTM buffer objects are backed by system pages (and stolen/carveout regions) rather than discrete VRAM.
