Guide / Glossary A–Z / Terms beginning with I / IV (Initialization Vector)

A non-secret, unpredictable or unique starting value fed into a symmetric cipher so encrypting the same message twice yields different ciphertext.

An initialization vector is a fresh random starting value mixed into an encryption step so that encrypting the same file or message twice never produces identical scrambled output.

An IV does not need to be kept secret—it is stored or sent alongside the ciphertext—but reusing an IV with the same key can completely break stream ciphers and AEAD modes like AES-GCM.

What goes wrong if a cipher reuses the exact same IV and key for two different messages?

Identical plaintext blocks produce identical ciphertext patterns, and in modes like CTR or GCM, IV/nonce reuse leaks the XOR of plaintexts and can destroy authentication.

Depending on the mode of operation, an IV must be unpredictable (CBC) or strictly unique per key (CTR, GCM, ChaCha20-Poly1305, where it is called a nonce); disk encryption like LUKS/XTS derives per-sector IVs (e.g. plain64) from sector numbers.
