Terms beginning with I

Glossary definitions for technical terms and acronyms beginning with I.

Explore

  • I2C - Inter-Integrated Circuit — I2C: A two-wire bus for small chips and sensors.
  • IBRS (Indirect Branch Restricted Speculation) — IBRS: CPU hardware mitigation restricting speculative indirect-branch prediction across privilege levels.
  • ICMP - Internet Control Message Protocol — ICMP: A network protocol for control and error messages.
  • IDE - Integrated Development Environment — IDE: A program that combines coding, building, and debugging tools.
  • Idle — Idle: A state where the system has no recent input.
  • IEEE 802.3an (10GBASE-T) — IEEE 802.3an: 10 Gigabit Ethernet standard over twisted-pair copper cabling.
  • IETF (Internet Engineering Task Force) — IETF: Open international standards organization that develops and maintains core internet protocols.
  • IFP (Integer Factorization Problem) — IFP: Math problem of factoring a large composite number N = pq into its prime factors, underlying RSA.
  • iGPU - Integrated Graphics Processing Unit — iGPU: Graphics built into the processor.
  • IMC (Integrated Memory Controller) — IMC: Circuitry inside a modern CPU that talks directly to DDR4/DDR5 RAM modules.
  • Immutable — Immutable: Unable to be changed after it is created.
  • IND-CCA2 (Indistinguishability under Adaptive Chosen-Ciphertext Attack) — IND-CCA2: Gold-standard security property for public-key encryption and KEMs.
  • IND-CPA (Indistinguishability under Chosen-Plaintext Attack) — IND-CPA: Baseline semantic security property against passive eavesdroppers who can choose plaintexts.
  • Init — Init: The first user-space program that starts system services.
  • Initramfs (initial RAM filesystem) — Initramfs: A small temporary filesystem used during early boot.
  • Inode — Inode: A filesystem record describing a file.
  • Instruction — Instruction: A single operation a processor can perform.
  • INT-CTXT (Integrity of Ciphertext) — INT-CTXT: Security property ensuring an attacker cannot forge a valid new ciphertext.
  • Integrated circuit — Integrated circuit: A complete circuit built on a single piece of semiconductor.
  • Interpreter — Interpreter: A program that runs source code directly.
  • IOMMU (Input-Output Memory Management Unit) — IOMMU: Hardware unit translating and isolating DMA addresses from PCIe devices (Intel VT-d / AMD-Vi).
  • IOPS (Input/Output Operations Per Second) — IOPS: Storage benchmark measuring how many individual read/write requests a drive completes per second.
  • IP address — IP address: A numeric address that identifies a network host.
  • IPC - Inter-Process Communication — IPC: Ways for processes to communicate.
  • IRC (Internet Relay Chat) — IRC: Classic real-time text chat protocol used by Linux distributions and open-source developer channels.
  • IRQ - Interrupt Request — IRQ: A signal that asks the processor to handle an event.
  • ISA - Instruction Set Architecture — ISA: The instruction set a processor understands.
  • ISI (Inter-Symbol Interference) — ISI: Signal distortion where one transmitted pulse smears into neighboring bit slots.
  • ISO 8859-1 (Latin-1) — ISO 8859-1: 8-bit single-byte character encoding for Western European languages.
  • ISO/IEC 21031 (Software Carbon Intensity) — ISO/IEC 21031: International standard for measuring software carbon intensity (SCI).
  • ISO/IEC 9899 (C standard) — ISO/IEC 9899: International standard series defining the C programming language.
