Terms beginning with I

Glossary definitions for technical terms and acronyms beginning with I.

Explore

I2C - Inter-Integrated CircuitI2C: A two-wire bus for small chips and sensors.
I420A three-plane 8-bit 4:2:0 video layout.
IBRS (Indirect Branch Restricted Speculation)IBRS: CPU hardware mitigation restricting speculative indirect-branch prediction across privilege levels.
ICMP - Internet Control Message ProtocolICMP: A network protocol for control and error messages.
IDE - Integrated Development EnvironmentIDE: A program that combines coding, building, and debugging tools.
IdleIdle: A state where the system has no recent input.
IEC 61000-4-2IEC 61000-4-2 is a standard for testing equipment against electrostatic discharge.
IEEE (Institute of Electrical and Electronics Engineers)IEEE: Professional association whose standards cover Ethernet, Wi-Fi, floating-point arithmetic and POSIX.
IEEE 754The standard that defines binary and decimal floating-point formats and arithmetic.
IEEE 802.3an (10GBASE-T)IEEE 802.3an: 10 Gigabit Ethernet standard over twisted-pair copper cabling.
IETF (Internet Engineering Task Force)IETF: Open international standards organization that develops and maintains core internet protocols.
IFP (Integer Factorization Problem)IFP: Math problem of factoring a large composite number N = pq into its prime factors, underlying RSA.
IFS (Internal Field Separator)IFS: the shell variable that holds the characters used as separators when text is split into words.
iGPU - Integrated Graphics Processing UnitiGPU: Graphics built into the processor.
IMC (Integrated Memory Controller)IMC: Circuitry inside a modern CPU that talks directly to DDR4/DDR5 RAM modules.
ImmutableImmutable: Unable to be changed after it is created.
IND-CCA2 (Indistinguishability under Adaptive Chosen-Ciphertext Attack)IND-CCA2: Gold-standard security property for public-key encryption and KEMs.
IND-CPA (Indistinguishability under Chosen-Plaintext Attack)IND-CPA: Baseline semantic security property against passive eavesdroppers who can choose plaintexts.
InitInit: The first user-space program that starts system services.
Initramfs (initial RAM filesystem)Initramfs: A small temporary filesystem used during early boot.
InodeInode: A filesystem record describing a file.
InstructionInstruction: A single operation a processor can perform.
INT-CTXT (Integrity of Ciphertext)INT-CTXT: Security property ensuring an attacker cannot forge a valid new ciphertext.
Integrated circuitIntegrated circuit: A complete circuit built on a single piece of semiconductor.
InterpreterInterpreter: A program that runs source code directly.
IOMMU (Input-Output Memory Management Unit)IOMMU: Hardware unit translating and isolating DMA addresses from PCIe devices (Intel VT-d / AMD-Vi).
IOPS (Input/Output Operations Per Second)IOPS: Storage benchmark measuring how many individual read/write requests a drive completes per second.
IP addressIP address: A numeric address that identifies a network host.
IPC - Inter-Process CommunicationIPC: Ways for processes to communicate.
IPv4 (Internet Protocol version 4)IPv4: The original 32-bit internet protocol that addresses devices with four decimal groups.
IPv6 (Internet Protocol version 6)IPv6: The 128-bit internet protocol with hexadecimal addresses, neighbor discovery and no address exhaustion.
IRC (Internet Relay Chat)IRC: Classic real-time text chat protocol used by Linux distributions and open-source developer channels.
IRQ - Interrupt RequestIRQ: A signal that asks the processor to handle an event.
ISA - Instruction Set ArchitectureISA: The instruction set a processor understands.
ISI (Inter-Symbol Interference)ISI: Signal distortion where one transmitted pulse smears into neighboring bit slots.
ISO (International Organization for Standardization)ISO: International federation of national standards bodies that publishes worldwide technical, industrial, and computing standards.
ISO 8859-1 (Latin-1)ISO 8859-1: 8-bit single-byte character encoding for Western European languages.
ISO/IEC 21031 (Software Carbon Intensity)ISO/IEC 21031: International standard for measuring software carbon intensity (SCI).
ISO/IEC 9899 (C standard)ISO/IEC 9899: International standard series defining the C programming language.
IV (Initialization Vector)IV (Initialization Vector): A non-secret, unpredictable or unique starting value fed into a symmetric cipher so encrypting the same message twice yields different ciphertext.
