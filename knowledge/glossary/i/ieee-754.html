IEEE 754

IEEE 754 is the standard that makes floating-point arithmetic behave consistently across computers.

Different machines could once round numbers in different ways, so the same program gave different answers. IEEE 754 defines the bit layouts and the rules for arithmetic, which lets results travel between systems.

The familiar formats are binary32, often called float, and binary64, often called double. Each stores a sign, an exponent and a significand. The standard also defines rounding modes, infinity, NaN, subnormal values and exception flags such as divide by zero and inexact. Decimal formats are defined as well, for work that needs exact decimal digits.

Does IEEE 754 make 0.1 exact?

No. It makes the approximation and its behaviour predictable. One tenth has a repeating binary expansion, so a finite binary format must round it.

The 2008 revision added decimal formats and the fusedMultiplyAdd operation; the 2019 revision added binary16 and binary128 as storage and interchange formats. Normal binary values use an implicit leading one in the significand. Exponent fields of all zeros and all ones encode subnormals, zero, infinity and NaNs. Required operations round correctly under the active rounding mode, but expression contraction, library implementations and transcendental functions can still cause cross-platform differences.
