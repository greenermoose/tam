Guide / Glossary A–Z / Terms beginning with I / IMSI (International Mobile Subscriber Identity)

IMSI (International Mobile Subscriber Identity): the permanent internal identifier of a mobile subscription.

An IMSI is the number a mobile network uses internally to name a subscription. It is different from the phone number other people text.

The home network uses the IMSI to find the subscriber record. When a person roams, the visited network asks the home network about that subscription.

ITU-T E.212 defines the land mobile identity plan; 3GPP TS 23.003 applies it to mobile networks. An IMSI contains a mobile country code, mobile network code and subscriber identity. 5G systems conceal the permanent identifier over the air to reduce tracking.
