Guide / Glossary A–Z / Terms beginning with I / IndexedDB

IndexedDB is browser storage for larger amounts of structured data, used by offline and local-first web apps.

It is a small database inside the browser, separate from cookies and simple key-value storage.

IndexedDB uses databases, object stores, keys and indexes. Requests are asynchronous, so code waits for results with events or promises.

Transactions are scoped to object stores and end when the task finishes. Storage quotas, version upgrades and private browsing modes affect reliability.
