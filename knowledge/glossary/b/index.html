Terms beginning with B

Glossary definitions for technical terms and acronyms beginning with B.

Explore

BacklightBacklight: The light source behind an LCD panel.
BandgapBandgap: A bandgap is the energy step an electron must climb before it can move freely and carry current in a semiconductor.
BandwidthBandwidth: The maximum rate data can flow.
Baud RateBaud Rate: the speed at which a communication channel changes electrical signal states
BBR (Bottleneck Bandwidth and Round-trip propagation time)BBR: a TCP congestion control algorithm that estimates bottleneck bandwidth and round-trip time instead of relying mainly on packet loss.
BEAST (Browser Exploit Against SSL/TLS)BEAST: 2011 chosen-plaintext attack against predictable IVs in TLS 1.0 CBC mode.
BEL (Bell, 0x07)BEL: ASCII 0x07 control character (Ctrl+G) triggering an alert and terminating OSC sequences.
BER - Bit Error RateBER: The rate at which bits are received incorrectly.
BGP (Border Gateway Protocol)BGP: Core routing protocol connecting independent networks (autonomous systems) across the internet.
BHT (Brassard-Hoyer-Tapp algorithm)BHT: Quantum algorithm finding hash collisions in O(2^(n/3)) time.
BinaryBinary: A number system that uses only 0 and 1.
BIOS - Basic Input/Output SystemBIOS: The traditional firmware interface on PCs.
Bit (binary digit)Bit: The smallest unit of digital information.
Bit flipBit flip: An unintended change of a single binary digit from 0 to 1 or from 1 to 0 in memory, storage, or a transmission link.
Bit RateBit Rate: the number of binary bits transferred per unit of time across a communication link
BKZ (Block Korkine-Zolotarev)BKZ: Lattice basis-reduction algorithm used to estimate the security of post-quantum lattice cryptography.
BLAKE2BLAKE2: Fast, secure cryptographic hash function family (BLAKE2b, BLAKE2s) built on ChaCha-like ARX rounds.
BLAKE3BLAKE3: Tree-structured, SIMD-parallelizable cryptographic hash function.
BLE (Bluetooth Low Energy)BLE: Bluetooth Low Energy, a low-power wireless protocol for short-range devices and sensors.
Block deviceBlock device: A device accessed in fixed-size blocks.
Blue lightBlue light: The short-wavelength, cool-toned part of visible white light emitted strongly by modern LED-backlit screens.
BMC (Baseboard Management Controller)BMC: Dedicated service processor on server motherboards for out-of-band power, fans, and console.
BMI2 (Bit Manipulation Instruction Set 2)BMI2: x86_64 bit-level instructions (PDEP, PEXT, MULX) part of the x86-64-v3 feature level.
BOM (Bill of Materials / Byte Order Mark)BOM: Inventory of software/hardware components (SBOM) or Unicode U+FEFF Byte Order Mark.
BonjourBonjour: Apple's name for its zero-configuration networking implementation, compatible with Avahi.
Boolean algebraBoolean algebra: The mathematics of true and false values.
BootBoot: The process of starting a computer.
BootloaderBootloader: A small program that starts the operating system.
BPF / eBPF (Berkeley Packet Filter)BPF: In-kernel sandboxed bytecode VM for safe packet filtering, tracing, and security enforcement.
BPU (Branch Prediction Unit)BPU: CPU frontend hardware that guesses which way conditional branches will go before they resolve.
Bracketed pasteBracketed paste: Terminal mode that wraps pasted text in ESC [ 200 ~ and ESC [ 201 ~ markers.
BranchBranch: A movable line of development.
BREACHBREACH: Side-channel attack recovering secrets from compressed HTTPS HTTP responses.
BS (Backspace, 0x08)BS: ASCII 0x08 control character (Ctrl+H) moving the cursor one column left.
BSD (Berkeley Software Distribution)BSD: Family of open-source Unix operating systems (FreeBSD, OpenBSD, NetBSD, DragonFly BSD) and permissive licenses.
BT.2020An ITU recommendation for ultra-high-definition television parameters.
BT.601An ITU recommendation for digital standard-definition television.
BT.709An ITU recommendation defining parameters for high-definition television.
Btrfs (B-tree filesystem)Btrfs: Btrfs is a Linux filesystem that can take snapshots of directories for rollback.
BudBud: the initial, minimal Tamlinux package used to grow the rest of the scion
BufferBuffer: A temporary holding area for data.
BuildBuild: The process of turning source into runnable software.
BundleBundle: learning reference and next steps
BusBus: A shared pathway that carries data or control signals.
ByteByte: A group of eight bits treated as one unit.
