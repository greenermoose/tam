Guide / Glossary A–Z / Terms beginning with B / Bud

In the Tamlinux botanical analogy, a bud is the initial, minimal Tamlinux package installed on a rootstock and used to install (or “grow”) the rest of the Tamlinux scion.

In gardening, a bud is a compact, dormant shoot—and in bud grafting, a single bud inserted into a rootstock grows into the whole upper plant. In Tamlinux, the bud is the smallest initial Tamlinux package you install onto a rootstock first. Once the bud is in place, you use it to grow the rest of the Tamlinux scion.

Rather than shipping a full desktop or tool suite all at once, Tamlinux starts with a minimal bud package on the rootstock. Today Tamlinux is transitioning from the earlier native bootstrap package (tam-nut / tam-bundle) to tam-bud and source installs under /usr/lib/tamlinux/. The tam guide and the rest of the Tamlinux scion are installed from the bud, not included inside it.

Does the bud contain the whole Tamlinux desktop and help corpus?

No. The bud is the minimal starting package placed on the rootstock; you use it to install and grow the full Tamlinux scion.

In Tamlinux’s layered delivery model, the bud is the minimal native package on the rootstock that provides initial host inspection and bootstrap tooling (such as tam-bud) to grow, roll back, or inspect the scion without pulling in the full desktop upfront. Check the active rootstock package database (for example, pacman -Q tam-nut on Arch-based builds) to verify what bud package is actually installed on a given host.
