Guide / Glossary A–Z / Terms beginning with B / Big-O notation

A mathematical notation that describes an upper bound on how an algorithm's cost grows as input size grows.

Big-O is a way to talk about how much slower or more memory-hungry a program gets when the input gets bigger. It ignores small details and focuses on the growth pattern.

O(n) means cost grows at most linearly with input size n, O(n^2) quadratically, and O(n log n) slightly faster than quadratic. Constants and lower-order terms are ignored: 3n + 10 is O(n).

Formally, f(n) is O(g(n)) if there exist constants c > 0 and n0 such that f(n) <= c*g(n) for all n >= n0. Big-O gives an asymptotic upper bound; related notations are Ω (lower bound), Θ (tight bound), o (strict upper), and ω (strict lower).
