Bit (binary digit)

A bit (short for binary digit) is the smallest unit of digital information, representing one of two possible values: 0 or 1.

Think of a bit like a single light switch that can only be off (0) or on (1), or a simple yes-or-no answer. One bit by itself cannot hold much—just a single choice—but when computers group millions or billions of bits together, they can represent numbers, words, music, and entire operating systems.

In computing, bits are almost always grouped into 8-bit bytes (256 possible values, 0–255), which is why a single ASCII character takes one byte and CPU registers are sized in powers of two (32-bit, 64-bit). In Linux permissions, individual bits act as independent flags: the three permission bits for owner, group, and others (read = 4, write = 2, execute = 1) are combined with bitwise OR. Similarly, network speeds are quoted in bits per second (Mbps), while file sizes are quoted in bytes (MiB).

How many distinct values can 4 bits represent, and why?

Sixteen (2⁴ = 16, from 0000 to 1111, or 0 to 15). Each added bit doubles the number of possible combinations because it can be either 0 or 1 independently of the previous bits.

Information-theoretically, one bit (shannon) is the entropy of a uniform binary random variable (H = −∑ pᵢ log₂ pᵢ = 1 when p = 0.5). Physically, bits are realized as bistable voltage levels in CMOS logic gates, charge on DRAM capacitors, floating-gate/charge-trap thresholds in NAND flash (which store 1–4 bits per cell as SLC/MLC/TLC/QLC by partitioning voltage windows), or magnetic/optical states. At the ISA and kernel level, bit-level operations—shifts, masks, population count (POPCNT), and atomic test-and-set instructions—manipulate bitfields and lock flags without byte-level branching.
