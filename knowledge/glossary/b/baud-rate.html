Baud Rate

The rate at which a communication channel changes its signal state, measured in symbols per second.

Imagine flashing a flashlight to send a message: how many times per second you switch the light is the baud rate. If each flash only means “0” or “1,” then the baud rate equals the number of bits per second. But if you use four different brightness levels per flash, each flash carries two bits at once, so you send twice as many bits per second without flashing any faster.

Baud rate measures symbols per second, whereas bit rate measures bits per second. On a classic RS-232 or TTL UART serial console (such as /dev/ttyUSB0 or /dev/ttyS0), each symbol is a simple high/low voltage level representing 1 bit, so 115200 baud equals 115200 bps (roughly 11.5 KB/s after 8N1 start/stop framing). By contrast, high-speed links like 1000BASE-T Ethernet or PCIe Gen 6 use multi-level modulation (PAM-5, PAM-4) to pack multiple bits into each symbol.

Why does a 115200 baud 8N1 serial port transfer at most about 11,520 bytes per second instead of 14,400?

In 8N1 framing, every 8-bit byte requires 1 start bit and 1 stop bit (10 bits total on the wire). Dividing 115,200 bits/s by 10 bits/byte yields 11,520 bytes/s.

The symbol/modulation rate S (baud) is bounded by the Nyquist ISI-free limit S ≤ 2B for an ideal low-pass channel of analog bandwidth B Hz. Raising bit rate R = S · log₂(M) via M-ary modulation (e.g., PAM-4, QAM-64) avoids widening B but shrinks noise margin (SNR per symbol), requiring forward error correction (FEC) and equalization. On asynchronous UARTs without a shared clock line, both ends must match baud rate within ~2–3% so sampling at the center of each bit cell does not drift across a 10-bit frame.
