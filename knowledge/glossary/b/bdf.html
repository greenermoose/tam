Guide / Glossary A–Z / Terms beginning with B / BDF (Bitmap Distribution Format)

BDF is a plain-text format that stores bitmap fonts as rows of pixels for each glyph.

Before fonts were drawn from mathematical curves, many were stored as fixed grids of dots, one grid per letter. BDF is one such format: a readable text file listing each letter's width, height and pixel pattern. It is easy to inspect with an ordinary text editor.

A BDF file begins with global properties such as font name, point size, ascent and descent, followed by a STARTCHAR/ENDCHAR block per glyph containing a BITMAP of hexadecimal rows. Because each glyph is a fixed pixel grid, BDF fonts are sharp only at their designed size. They are mainly of historical interest, though they can be converted to PCF with bdftopcf.

BDF comes from the X Window System bitmap distribution standard and stores glyphs as binary bitmaps encoded as hexadecimal text, with FONTBOUNDINGBOX, PIXEL_SIZE and RESOLUTION_X/RESOLUTION_Y metadata plus per-character SWIDTH/DWIDTH scaling values. Modern desktop text stacks prefer scalable outlines. Bitmap fonts remain in the Linux kernel console, built into lib/fonts/, and in PSF fonts loaded by setfont; BDF itself is not loaded by the kernel.
