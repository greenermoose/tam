Guide / Glossary A–Z / Terms beginning with B / Bundler

A bundler is a tool that follows your code's imports and combines them into files a browser can load efficiently.

A project may be split into dozens of small files. A bundler gathers them into a few files for the finished site, much like packing parts into one box before posting it.

You give the tool an entry file and an output folder. It resolves imports, applies transforms and can emit a source map that points generated code back to your original files.

Why test the production bundle and not only the development server?

Development servers may skip optimization, use different module resolution and expose different error messages. Only the built output is what visitors receive, so it is the artifact that needs verification.

A bundler builds a module graph, applies tree shaking to drop unreachable exports, and can split code into chunks loaded on demand. Long-term caching works best when changed files get versioned names. Build output must be tested because development servers can behave differently.
