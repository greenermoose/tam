Guide / Glossary A-Z / Terms beginning with B / BLAS (Basic Linear Algebra Subprograms)

A named set of routines for common matrix and vector operations.

Computers often add, multiply and combine large lists of numbers. BLAS gives those jobs standard names, so a program can ask for a well-known operation instead of writing its own loop.

Routines are grouped by level. Level 1 works on vectors, such as a dot product. Level 2 works on a matrix and a vector. Level 3 works on matrix-matrix operations such as GEMM. Level 3 usually runs fastest because it reuses each loaded value many times. Many libraries implement the same interface with machine-specific tuning.

Why is matrix-matrix multiplication usually faster than many matrix-vector calls?

It has more work per byte loaded from memory. A tuned kernel can block and reuse tiles of both matrices, while repeated matrix-vector calls stream one matrix again each time.

The specification defines names such as SGEMM, DGEMM, ZGEMM and DDOT, where the prefix gives the data type. It defines the interface and semantics, not a single implementation. OpenBLAS, BLIS, MKL and vendor libraries choose blocking, packing, threading and instruction sets. Layout, leading dimension, transpose flags and fused multiply-add use affect results and performance; implementations may not be bit-identical.
