Boolean algebra

The mathematics of true and false values, forming the rules behind digital circuits and program logic.

Everyday decisions often come down to yes-or-no checks: “Is the door locked?” or “Is it raining AND do I have an umbrella?” Boolean algebra is a simple system of rules for combining those true-or-false answers using words like AND, OR, and NOT. Computers use it because every tiny switch inside a processor is either on or off, so complex behavior is built by chaining simple true-or-false rules together.

In programming and shell scripting, Boolean expressions control if branches, loops, and grep or find filters, while bitwise operators apply the same rules across each bit of a number or permission mask. Notice the difference between logical operators (&&, ||) that short-circuit once the outcome is known and bitwise operators (&, |) that evaluate every bit.

Why does A && B skip evaluating B when A is false?

In Boolean AND, both inputs must be true for the result to be true. Once A is false, the overall expression can never be true regardless of B, so short-circuit evaluation skips B—which avoids unnecessary work and prevents errors like dividing by zero or dereferencing null.

Formally, a Boolean algebra is a complemented distributive lattice (B, ∧, ∨, ¬, 0, 1)—in the two-element case B = {0, 1}—satisfying commutativity, associativity, distributivity, identity, complementation, and absorption, from which De Morgan’s laws (¬(a ∧ b) = ¬a ∨ ¬b) follow. In hardware synthesis and compiler optimization, Boolean functions are minimized via Karnaugh maps, Quine–McCluskey, or SAT/BDD representations; however, standard two-valued Boolean algebra does not model propagation delay, hazards (glitches from unequal gate paths), or tri-state/unknown (X, Z) states, which require multi-valued logics such as IEEE 1164 (std_logic).
