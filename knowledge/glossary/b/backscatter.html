Guide / Glossary A–Z / Terms beginning with B / Backscatter

Backscatter is unwanted bounce mail caused by someone using your address as a forged sender.

If a forger writes your address on the outside of a message that cannot be delivered, the failure notice comes back to you instead of the forger. You did not send the original message, but you receive the complaint.

Bounces go to the SMTP envelope sender, not necessarily the visible From: header. Filters can reject forged mail during the SMTP conversation so that the receiving server never generates a bounce to an innocent party.

Backscatter is a consequence of RFC 5321 bounce handling combined with spoofed envelope senders. Sender authentication and reputation reduce it, but no single check removes it. Callback verification can make the problem worse by probing addresses and leaking validity.
