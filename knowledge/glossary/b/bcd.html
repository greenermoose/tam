Guide / Glossary A-Z / Terms beginning with B / BCD (binary-coded decimal)

A way of writing decimal digits using bits, one digit at a time.

Ordinary binary stores the whole number 42 as one value. BCD stores the digit 4 and the digit 2 separately. That keeps the familiar decimal digits, even though the storage is still made of bits.

In packed BCD, each decimal digit uses four bits, so one byte holds two digits. The number 42 is stored as 0100 0010. Codes 1010 through 1111 are unused in straightforward BCD. Decimal arithmetic hardware uses correction steps after addition so each nibble stays a valid digit.

Why not just use ordinary binary for money?

Binary cannot represent one tenth exactly. BCD or another decimal format can keep decimal amounts exact when the rules say how to round, which matters for totals and invoices.

IEEE 754 also defines decimal floating-point formats with decimal coefficients and exponents; these differ from simple packed BCD but share the goal of exact decimal digits. BCD uses more bits than binary for the same range because six of the sixteen nibble patterns are wasted. It remains in financial systems, calculators and some real-time clocks. Conversion must define sign, scale and validation of unused codes.
