Guide / Glossary A–Z / Terms beginning with B / Browser API

A browser API is a built-in service that lets page script do jobs the browser controls, such as reacting to a click or requesting data.

JavaScript by itself can calculate. Browser APIs are the extra doors the browser opens: listen for a click, remember a setting, or ask a server for news.

Common families include events (addEventListener), network requests (fetch and WebSocket), storage (localStorage), timers (setTimeout) and background work (Web Worker). Each has rules about permissions and origins.

Why is fetch more useful than a plain calculation for a web app?

A calculation uses data already in the page. fetch asks another computer for new data and returns a promise, so the page can show fresh information without a full reload.

Browser APIs are specified with Web IDL interfaces and enforced by the browser's permission model. Calls cross from script into native browser code; results return through the event loop as tasks or promises. The same-origin policy governs which responses script may read.
