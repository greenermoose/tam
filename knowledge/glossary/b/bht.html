BHT (Brassard-Hoyer-Tapp algorithm)

BHT (Brassard–Høyer–Tapp) is a quantum algorithm that finds two different inputs producing the same hash output faster than classical computers can.

A cryptographic hash acts like a unique digital fingerprint for a file or message. Finding two different files with the exact same fingerprint—a collision—is normally so slow that no regular computer can do it for strong hashes. BHT is a recipe for a future quantum computer that speeds up that search by combining a pre-made list of fingerprints with a quantum search trick, though modern 256-bit hashes are still large enough to stay safe against it.

Classically, the birthday attack finds an n-bit hash collision in about 2^(n/2) evaluations, so a 256-bit hash like SHA-256 gives 128 bits of collision security. BHT lowers the query count to O(2^(n/3))—about 2^85 operations for a 256-bit hash—by storing 2^(n/3) random hash pairs and running Grover’s search for a match. Because 2^85 quantum operations plus massive quantum memory remains impractical, standards like NIST post-quantum guidance still treat 256-bit hashes (SHA-256, SHA3-256, BLAKE2b-256) as collision-resistant.

Why does BHT not break SHA-256 in practice even though it reduces security from 2^128 to 2^85?

Two reasons: 2^85 sequential quantum operations is still astronomically expensive, and BHT requires O(2^(n/3))—about 2^85 entries—of fast, coherent quantum RAM (qRAM) to query the precomputed table in superposition, which is widely considered harder to build than the quantum processor itself.

BHT (1997) balances classical precomputation and amplitude amplification: sample a set L of size k = 2^(n/3) distinct inputs, store (x, H(x)) in quantum-accessible memory, then run Grover’s algorithm over the remaining domain to find x′ ∉ L with H(x′) ∈ H(L), yielding O(2^(n/3)) queries and O(2^(n/3)) qRAM. Under realistic hardware cost models that charge for memory size and circuit depth (the AT or DW cost metrics of Bernstein and Jaques–Schanck), qRAM access overhead erases the asymptotic speedup; classical parallel rho-methods (van Oorschot–Wiener) or space-efficient quantum collision algorithms (Chailloux–Naya-Plasencia–Schrottenloher, O(2^(2n/5)) time with small memory) dominate actual cryptanalytic cost estimates.
