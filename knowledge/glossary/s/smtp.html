Guide / Glossary A–Z / Terms beginning with S / SMTP (Simple Mail Transfer Protocol)

SMTP is the protocol that moves a mail message from a client to a submission server and from one mail server to the next.

The letters stand for Simple Mail Transfer Protocol. It is the language two mail programs use when one hands a message to the other, rather like a courier passing a parcel to the next depot.

A client sends commands such as MAIL FROM, RCPT TO and DATA. The envelope names come from those commands; the visible From: line is part of the message. Modern SMTP uses EHLO to advertise extensions. Port 25 is used for server-to-server relay, while port 587 or 465 is normal for submission.

RFC 5321 defines the modern SMTP transfer model: envelope identities, reply codes, queueing and store-and-forward relaying. SMTP is a push protocol for transfer, not for reading a mailbox. Extensions such as SMTPUTF8 and STARTTLS negotiate added capabilities during the EHLO conversation.
