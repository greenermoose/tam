ScionScion: the Tamlinux software that can install on a rootstock and bear fruit
SCP (Short-Circuit Protection)SCP: Fast power-supply cutoff triggered when output impedance drops near zero.
ScreenshotScreenshot: A capture of what is on screen.
ScriptScript: A program written for an interpreter.
SDDM (Simple Desktop Display Manager)SDDM: Modern QML-based graphical login manager for Wayland and X11 sessions.
SDP (Service Discovery Protocol / Session Description Protocol)SDP: Bluetooth service-lookup protocol (or streaming Session Description Protocol).
SECDED (Single-Error Correction, Double-Error Detection)SECDED: Classic Hamming-based ECC code that fixes 1-bit errors and flags 2-bit errors.
Secure BootSecure Boot: A firmware feature that verifies boot software signatures.
Semantic tokenSemantic token: A named design value such as surface or accent.
Semantic versioningSemantic versioning: A version-number convention with meaning.
SemiconductorSemiconductor: a material whose electrical conductivity can be controlled and switched
Sender IDSender ID: the name or number displayed as the sender of a message, which is not by itself proof of identity.
Serial CommunicationSerial Communication: transmitting data sequentially one bit at a time over a single wire or channel
Server-side rendering (SSR)SSR: Building page markup on a server before sending it to a browser.
ServiceService: A background program managed by the system.
SessionSession: The active working environment started for a logged-in user, encompassing their shell or graphical desktop and user services.
SEV-SNP (Secure Encrypted Virtualization - Secure Nested Paging)SEV-SNP: AMD hardware confidential-computing feature isolating VM memory from the host hypervisor.
SGR (Select Graphic Rendition)SGR: ECMA-48 CSI ... m sequence controlling terminal text colors and attributes.
SHA algorithms (SHA-1, SHA-2, SHA-256, SHA-3, SHA3-256, SHA384)SHA algorithms: NIST-standardized family of cryptographic hash functions.
SHA-1SHA-1: Legacy 160-bit cryptographic hash function broken against collision attacks.
SHA-2SHA-2: Family of 224/256/384/512-bit cryptographic hash functions (FIPS 180-4).
SHA-256SHA-256: 256-bit member of the SHA-2 cryptographic hash family.
SHA-3SHA-3: Sponge-based cryptographic hash family (Keccak) standardized in NIST FIPS 202.
SHA-384SHA-384: Truncated 384-bit variant of SHA-512 in the SHA-2 family.
SHA-512SHA-512: 512-bit member of the SHA-2 cryptographic hash family.
SHA3-256SHA3-256: 256-bit hash function from the NIST FIPS 202 SHA-3 family.
ShardingSharding: splitting a data set across several independent databases or nodes.
Shared libraryShared library: A library loaded by programs at runtime.
Shared memoryShared memory: Memory that two processes can access, used by Wayland clients to pass image buffers.
ShebangShebang: The first line of a script that names its interpreter.
ShellShell: a plain definition and further detail
Short codeShort code: a special short phone number used by a service, campaign or emergency system.
SI (Shift In, 0x0F)SI: ASCII 0x0F control character selecting the standard G0 character set.
Side-channel attackSide-channel attack: Learning secrets from timing, power, sound, or cache behavior instead of breaking math directly.
SIDH (Supersingular Isogeny Diffie-Hellman)SIDH: Broken isogeny-based key exchange protocol (broken classically in 2022).
SIGINT (Interrupt signal)SIGINT: Signal (2) sent by Ctrl+C to interrupt a foreground terminal process.
SIGKILL (Kill signal)SIGKILL: Uncatchable signal (9) that immediately terminates a process in the kernel.
SignalSignal: learning reference and next steps
Signal ProtocolSignal Protocol: a family of cryptographic protocols for asynchronous end-to-end encrypted messaging.
SignificandThe digit part of a number in scientific notation or floating point.
SIGPIPE (Broken Pipe signal)SIGPIPE: Signal (13) sent when a process writes to a pipe or socket whose reader has closed.
SIGQUIT (Quit signal)SIGQUIT: Signal (3) sent by Ctrl+\ to terminate a process and produce a core dump.
SIGSTOP (Stop signal)SIGSTOP: Uncatchable signal (19) that pauses a process until SIGCONT is sent.
SIGTERM (Terminate signal)SIGTERM: Default polite termination signal (15) sent by kill.
SIGTSTP (Terminal Stop signal)SIGTSTP: Catchable signal (20) sent by Ctrl+Z to suspend a foreground job.
SIKE (Supersingular Isogeny Key Encapsulation)SIKE: Broken post-quantum KEM built on SIDH.
SIM (Subscriber Identity Module)SIM (Subscriber Identity Module): the secure card or embedded module that holds a mobile subscription identity and its secret key.
SIM swapSIM swap: transferring a phone number to a different SIM or eSIM, either legitimately or by fraudulent account takeover.
SIMD (Single Instruction, Multiple Data)SIMD: Parallel execution technique applying one CPU instruction to a vector of data elements at once.
SIMT (Single Instruction, Multiple Threads)SIMT: GPU execution model running groups of threads (warps/wavefronts) in lockstep.
Single-page application (SPA)SPA: A web app that loads one page and updates its contents with script instead of full reloads.
SMD (Surface-Mount Device)SMD: Electronic component soldered flat onto PCB pads rather than through drilled holes.
Smishing (SMS phishing)Smishing (SMS phishing): a deceptive text message that tries to make a reader reveal secrets or open a harmful link.
SMPP (Short Message Peer-to-Peer)SMPP (Short Message Peer-to-Peer): a protocol used by applications to submit short messages to and receive them from a message centre.
SMPS (Switched-Mode Power Supply)SMPS: High-efficiency power converter using fast-switching transistors and inductors instead of linear heat dissipation.
SMS (Short Message Service)SMS (Short Message Service): the carrier service that carries short text messages through a store-and-forward centre.
SMSC (Short Message Service Center)SMSC (Short Message Service Center): the system that stores and forwards short messages until they can be delivered.
SMT (Simultaneous Multithreading)SMT: Hardware feature allowing one physical CPU core to run two instruction threads concurrently.
SMTP (Simple Mail Transfer Protocol)SMTP (Simple Mail Transfer Protocol): the protocol used to submit and relay email between mail servers.
SMTPUTF8 (SMTP UTF-8)SMTPUTF8 (SMTP UTF-8): the SMTP extension for internationalised addresses and UTF-8 header text.
SnapshotSnapshot: definition and recovery boundary at each level
SNI (Server Name Indication)SNI: TLS extension sending the target hostname in ClientHello so one IP can host many HTTPS sites.
SNR (Signal-to-Noise Ratio)SNR: The strength of a signal compared with background noise.
SoC (System on a Chip)SoC: A chip that combines a processor and other major components.
SocketSocket: A software endpoint for network communication.
SOH (Start of Heading, 0x01)SOH: ASCII 0x01 control character (Ctrl+A).
SONAME (Shared Object Name)SONAME: Embedded ELF dynamic tag specifying a shared library's ABI-compatible major name (e.g., libc.so.6).
SONOS (Silicon-Oxide-Nitride-Oxide-Silicon)SONOS: A charge-trap non-volatile memory cell that stores charge in a nitride layer.
Sorting algorithmAn algorithm that arranges items into a defined order, such as numeric or lexicographic order.
Source codeSource code: Human-readable instructions for a program.
Space complexityA measure of how much memory an algorithm needs as the size of its input grows.
SpamSpam: unsolicited bulk email, often sent to many recipients without their consent.
SPF (Sender Policy Framework)SPF (Sender Policy Framework): a DNS TXT record that authorises hosts to send mail for a domain.
SPHINCS+ (SLH-DSA)SPHINCS+: Stateless hash-based post-quantum signature standardized as NIST FIPS 205 (SLH-DSA).
SPI (Serial Peripheral Interface)SPI: A fast four-wire bus for chips.
SPN (Substitution-Permutation Network)SPN: Block-cipher architecture alternating non-linear byte substitutions (S-boxes) and bit permutations.
SQL (Structured Query Language)SQL: A language for asking relational databases for rows and changing them.
SQL injectionSQL injection: A flaw where input changes the meaning of a database query.
SQLiteSQLite: A small embedded relational database that keeps a whole database in one file.
SRAM (Static Random-Access Memory)SRAM: A fast memory technology that holds bits in circuits.
SRS (Sender Rewriting Scheme)SRS (Sender Rewriting Scheme): rewrites the envelope sender so forwarding does not break SPF.
SS3 (Single Shift 3)SS3: ESC O (or 0x8F) prefix used for unparameterized function keys and application cursor keys.
SS7 (Signalling System No. 7)SS7 (Signalling System No. 7): the carrier signalling architecture used to set up calls, query subscriber records and support roaming.
SSD (Solid-State Drive)SSD: Storage with no moving parts.
SSH (Secure Shell)SSH: Encrypted network protocol for remote terminal logins, tunneling, and file transfers.
SSH keySSH key: A cryptographic key used for secure remote login.
SSH-2 (Secure Shell version 2)SSH-2: Modern Secure Shell protocol (RFC 4251-4254) replacing vulnerable SSH-1.
SSHFP (SSH Fingerprint DNS Record)SSHFP: DNS resource record storing an SSH server's public-key fingerprint, secured by DNSSEC.
SSID (Service Set Identifier)SSID: The name of a Wi-Fi network.
Stack traceStack trace: The list of function calls that led to an error.
Standard definition (SD)A group of television image formats with less detail than high definition.
Standard streamsStandard streams: The three default input and output channels of a program.
STARTTLS (Start Transport Layer Security)STARTTLS (Start Transport Layer Security): an SMTP command that upgrades an existing connection to TLS.
Static assertionStatic assertion: A compile-time check that must be true.
Static libraryStatic library: A library copied into a program when it is built.
Store pathStore path: The immutable path where Nix keeps a build result.
Strain reliefStrain relief: A flexible sleeve or collar where a cable meets a rigid connector plug to prevent sharp bending from breaking internal wires.

SubnetSubnet: A smaller network carved out of a larger address range.
SubnormalA floating-point value too small to use the normal implicit leading bit.
SubvolumeSubvolume: A separately managed tree inside Btrfs.
Sudo (superuser do)Sudo: A tool for running one command as another user.
SurfaceFlingerSurfaceFlinger: The Android system service that combines application surfaces for display.

SUSv3 (Single UNIX Specification v3)SUSv3: 2001 unified standard combining POSIX.1-2001 and the Single UNIX Specification.
SVG (Scalable Vector Graphics)SVG: XML-based vector image format that scales cleanly to any screen DPI without pixelation.
SVID (Serial Voltage Identification)SVID: Intel high-speed serial bus between a CPU and its VRM to request dynamic voltage changes.
SVM (Secure Virtual Machine)SVM: Technical architecture name for AMD-V hardware virtualization.
SwapSwap: Disk space used as overflow memory.
Symbolic linkSymbolic link: A file that points to another path.
Symmetric encryptionSymmetric encryption: Scrambling and unscrambling data with the same shared secret key.
SYN (Synchronous Idle, 0x16)SYN: ASCII 0x16 control character (Ctrl+V) used for clock synchronization and literal quoting.
Sysfs (system filesystem)Sysfs: A virtual filesystem that exposes kernel objects.
System callSystem call: A request from a program to the kernel.
System V ABI (SVID)System V ABI / SVID: Unix standard defining ELF binaries, calling conventions, and core system interfaces.
systemdsystemd: systemd is the program that starts and supervises most services after the Linux kernel finishes early boot on current Tamlinux systems.
