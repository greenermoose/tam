SUSE / openSUSE

SUSE and openSUSE are a long-standing German Linux distribution family known for RPM packaging, the Zypper package manager, the YaST administration tool, and early adoption of Btrfs with Snapper.

Linux comes in several major “families,” much like different car makers that share the same basic engine design. SUSE (the enterprise version) and openSUSE (the community version) are one of the oldest and most influential families. Even if you use a different Linux system, you may still benefit from their work—for example, they created the Snapper snapshot tool used by Tamlinux.

openSUSE comes in two main flavors: Leap, a traditional fixed-release system aligned with SUSE Linux Enterprise (SLE) for long-term stability, and Tumbleweed, a heavily tested rolling release that delivers continuously updated packages. Both use zypper over RPM packages and configure Btrfs root subvolumes with Snapper out of the box so system updates automatically create before-and-after rollback points.

What is the practical difference between openSUSE Leap and openSUSE Tumbleweed?

Leap follows a fixed release cycle with conservative updates for stability, whereas Tumbleweed is a rolling release that continuously ships newer kernels and packages after automated openQA testing.

The SUSE ecosystem spans SUSE Linux Enterprise (SLE), openSUSE Leap, and openSUSE Tumbleweed, built around RPM, libzypp/zypper (featuring a SAT solver for dependency resolution), and the Open Build Service (OBS) for reproducible multi-distro package builds. Tumbleweed gates every snapshot through openQA, an automated OS-level UI and boot test harness. SUSE also pioneered transactional, immutable-root updates via transactional-update (used in openSUSE MicroOS/Aeon), which applies RPM changes into a new Btrfs snapshot without mutating the running root, complemented by snapper for pre/post zypp lifecycle hooks.
