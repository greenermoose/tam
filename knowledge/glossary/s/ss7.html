Guide / Glossary A–Z / Terms beginning with S / SS7 (Signalling System No. 7)

SS7 (Signalling System No. 7): the carrier signalling architecture used to set up calls, query subscriber records and support roaming.

SS7 is the set of systems mobile networks use to exchange control information. It helps one carrier ask another where a subscriber is.

When a text arrives for a roaming subscriber, signalling systems help find the serving network. The message itself is carried by a separate service path.

3GPP TS 29.002 defines MAP procedures over the SS7 protocol stack in GSM and UMTS networks. 5G core networks use service-based interfaces instead of classic SS7 transport, but the subscriber-lookup role remains conceptually similar.
