Guide / Glossary A–Z / Terms beginning with S / Sender ID

Sender ID: the name or number displayed as the sender of a message, which is not by itself proof of identity.

The sender ID is the name or number shown at the top of a text. It tells you who the message claims to be from.

A familiar name can be spoofed, so verify a sensitive request through an official app or a saved phone number.

SMS and SMPP carry originating address fields that can include alphanumeric sender IDs. The standard does not cryptographically authenticate those fields, so a display label is a claim, not proof.
