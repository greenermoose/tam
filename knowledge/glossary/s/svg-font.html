Guide / Glossary A–Z / Terms beginning with S / SVG font

SVG fonts were a way to embed glyph outlines directly in an SVG document; the feature is now deprecated in favor of OpenType fonts.

An early version of SVG let a drawing carry its own letter shapes as paths. That feature is obsolete; modern SVG documents rely on ordinary font files instead. Old examples may still show the tag.

SVG fonts were implemented in some browsers but never consistently, and SVG 2 removed them. Do not confuse them with SVG-in-OpenType color fonts, which use the OpenType SVG table to store color artwork inside a normal font file. The two features share a name but not a design.

The old font element defined glyph paths, advances and family names inside the document without a separate font file. Browser support was uneven and accessibility and search suffered. The modern SVG OpenType table stores SVG documents per glyph with an index mapping glyph IDs to fragments; many renderers decline it, so COLR/CPAL is generally preferred.
