Guide / Glossary A–Z / Terms beginning with S / Stem hint

A stem hint tells a renderer how wide a letter's main stroke should be when drawn at small pixel sizes.

Thin letter strokes can vanish or change thickness on a low-resolution screen. A stem hint is a note in the font that says 'keep this stroke about this wide', so letters stay even. It is part of the font, not a screen setting.

TrueType hinting programs snap stems to pixel boundaries using control values that depend on size; CFF fonts declare stem widths and alignment zones that the hinter applies automatically. Too much snapping distorts curves, so designers tune hinting separately for small and large sizes.

In CFF, Type 2 charstrings use hstem and vstem operators with relative widths, sometimes masked with hstemhm and vstemhm when hints live in a separate mask. FreeType's CFF hinter resolves conflicts between stems and blue zones. TrueType has no declarative stem operator: bytecode using the control value table and delta instructions produces the equivalent behavior.
