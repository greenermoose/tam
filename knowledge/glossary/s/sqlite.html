Guide / Glossary A–Z / Terms beginning with S / SQLite

SQLite is a small relational database engine that lives inside an application and keeps its data in one file.

It needs no server process: the program opens the file and reads or writes tables directly.

SQLite fits local apps, tests and small sites with one writer. It supports SQL, indexes and transactions, but concurrent writers are serialized by file locks.

The library implements a relational engine, a page cache and either a rollback journal or a write-ahead log inside a portable single-file format. Its scope is deliberately embedded, so networking, roles and central backup remain application or deployment concerns.
