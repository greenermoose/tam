Guide / Glossary A–Z / Terms beginning with S / STARTTLS (Start Transport Layer Security)

STARTTLS is a command that turns an existing cleartext mail connection into an encrypted TLS connection.

The name means Start Transport Layer Security. The client and server first talk in the open, agree to upgrade, and then continue the conversation inside an encrypted channel.

In SMTP the server advertises STARTTLS in its EHLO reply. The client sends the command, performs a TLS handshake, then starts a fresh EHLO. If the upgrade fails and the client continues in cleartext, a network attacker may have interfered, so policy matters.

RFC 3207 defines the SMTP upgrade. RFC 8314 says cleartext only is obsolete and prefers implicit TLS for submission and mail access. For server-to-server relay, MTA-STS or DANE can require TLS rather than merely offer it.
