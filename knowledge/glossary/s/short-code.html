Guide / Glossary A–Z / Terms beginning with S / Short code

Short code: a special short phone number used by a service, campaign or emergency system.

A short code is a short number such as a five-digit service address. It is easier to remember than a full phone number.

Some short codes receive texts for a campaign or alert service. Others are used for carrier menus.

Short codes are assigned nationally or by carriers and are not a global namespace. A short code valid in one country may not route in another, and the visible code does not authenticate the sender.
