Guide / Glossary A–Z / Terms beginning with S / setfont

setfont is a command-line tool that loads a bitmap font into a Linux text console.

On a plain Linux text console you can change the letters' appearance with setfont. It loads a font file into the console so the characters you see are drawn differently. The change affects the console you run it on.

setfont loads PSF fonts, and also .cp and raw formats, using kbd's kfont_load_fonts(). It can set an alternate font for high-intensity video attributes. The setting lasts only for that console unless a boot script or service reapplies it.

The tool writes through ioctl(KDFONTOP) with KD_FONT_OP_SET or SET_TALL; SET_DEFAULT restores the kernel font. The kernel path runs vt_ioctl.c to vt.c and then fbcon's fbcon_set_font, with charcounts of 256 or 512 glyphs. Console fonts replaced this way are bitmaps: no shaping or outline scaling is available, unlike userspace consoles.
