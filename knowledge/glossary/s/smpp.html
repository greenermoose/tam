Guide / Glossary A–Z / Terms beginning with S / SMPP (Short Message Peer-to-Peer)

SMPP (Short Message Peer-to-Peer): a protocol used by applications to submit short messages to and receive them from a message centre.

SMPP is a language used by businesses and service providers to hand short messages to a message centre. It is not the radio protocol a phone uses to send a text.

A service that sends appointment reminders may use SMPP to submit many messages at once and receive status reports back.

The SMPP specification defines bind operations, submit and deliver PDUs, message identifiers and delivery receipts. Version 5.0 is the published specification; older versions remain in deployments. SMPP carries sender fields that are not cryptographically authenticated by itself.
