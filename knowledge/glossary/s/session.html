Guide / Glossary A–Z / Terms beginning with S / Session

The active working environment started for a logged-in user, encompassing their shell or graphical desktop and user services.

A session is everything running for you from the moment you sign in until you log out—your open windows, shell, background helpers, and settings.

Linux tracks each login as a numbered session (inspectable with loginctl) tied to a seat and either a text TTY or a graphical Wayland compositor.

What happens to programs started inside your graphical session when you log out?

The session manager (such as UWSM and systemd-logind) terminates the compositor and session-scoped user units so no stray desktop processes linger.

systemd-logind registers sessions via pam_systemd, assigns XDG_SESSION_ID and XDG_SESSION_TYPE (tty/wayland), manages seat device access through logind/seatd, and bounds user services under user@UID.service.
