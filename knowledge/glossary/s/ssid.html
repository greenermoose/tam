Guide / Glossary A–Z / Terms beginning with S / SSID - Service Set Identifier

The human-readable name that identifies a Wi-Fi wireless network.

When you open your laptop’s Wi-Fi menu and see names like HomeWiFi or CafeGuest, each of those names is an SSID. It is simply the sign on the door telling your device which wireless network to join.

On Linux, tools like nmcli device wifi list or iwctl scan for nearby SSIDs. Multiple physical access points in an office or campus often broadcast the exact same SSID so your device can roam between them, while each radio actually has its own hardware MAC address (called a BSSID). Hiding an SSID stops it from appearing in simple menus, but devices still broadcast the name when probing for saved networks.

If two Wi-Fi routers in a building share the same SSID, how does your device tell their individual radios apart?

Each radio has a unique BSSID (its wireless MAC address), which lets the Wi-Fi driver pick the strongest access point and roam between them under the same network name.

In IEEE 802.11, the SSID Information Element (Element ID 0) is a variable-length octet string of 0–32 bytes carried in Beacon, Probe Request, Probe Response, and Association frames. It is an opaque byte sequence rather than strictly UTF-8, and a 0-length SSID represents a wildcard probe or suppressed ("hidden") SSID in beacons. Because 802.11 management frames were historically unencrypted, passive sniffers can capture an SSID from client Probe Requests or Association frames even when beacons omit it.
