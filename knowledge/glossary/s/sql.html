Guide / Glossary A–Z / Terms beginning with S / SQL (Structured Query Language)

SQL is the language used to ask a relational database for information and to add, change or remove rows.

A database keeps information in tables, a bit like a spreadsheet with named columns. SQL is how you ask a question such as 'show me the orders for this person'.

SELECT reads rows, INSERT adds them, UPDATE changes them and DELETE removes them. A WHERE clause narrows which rows are affected. Values should be passed as parameters, not pasted into query text.

Why does parameterizing a query prevent SQL injection?

A parameter is sent as a value separate from the SQL text, so the database cannot interpret it as an operator or extra statement. Concatenating input into the text lets input change the query's meaning.

SQL supports joins, aggregates, constraints and transactions with atomicity, consistency, isolation and durability. Indexes speed reads at the cost of extra writes. Query planners choose access paths; an execution plan is the evidence when a query is slow.
