Symbolic link

A symbolic link (or symlink) is a special file whose contents are a text path pointing to another file or directory.

A symbolic link works like a signpost or desktop shortcut. Instead of holding a second copy of a document or folder, it simply holds the directions to where the real item lives. If you open the shortcut, the system follows the directions to the target; if the target is moved or deleted, the signpost still exists, but now it points to nowhere.

You create a symbolic link with ln -s TARGET LINK_NAME, and ls -l shows l as the first character plus link -> target. Unlike a hard link—which shares the exact same underlying file data (inode) and cannot cross filesystems or link directories—a symlink has its own inode, can point across different filesystems, and can point to a directory or even a path that does not exist yet (a “dangling” or broken symlink). Deleting a symlink removes only the link itself, leaving the target untouched.

If you run ln -s report.txt /tmp/link.txt while in /home/alex, why might /tmp/link.txt be broken?

A relative symlink target is resolved relative to the directory containing the symlink (/tmp), not the working directory where ln was run. So /tmp/link.txt looks for /tmp/report.txt rather than /home/alex/report.txt.

At the VFS layer, a symbolic link is an inode of type S_IFLNK whose payload is an uninterpreted byte string (short targets fit inline in the inode as “fast symlinks”, while longer paths occupy a data block). During pathname lookup (path_lookupat), the kernel expands symlinks up to MAXSYMLINKS (40 on Linux) before returning ELOOP to prevent cyclic graphs. open(..., O_NOFOLLOW) refuses to traverse a trailing symlink (ELOOP), lstat() inspects the link’s own inode rather than following it, and O_PATH allows opening a symlink file descriptor for *at() operations. Security-wise, fs.protected_symlinks in /proc/sys/fs blocks following symlinks in world-writable sticky directories (such as /tmp) unless owned by the follower or directory owner, mitigating classic TOCTOU symlink-planting attacks.
