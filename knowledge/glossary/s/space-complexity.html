Guide / Glossary A–Z / Terms beginning with S / Space complexity

A measure of how much memory an algorithm needs as the size of its input grows.

Space complexity tells you whether an algorithm needs a little extra memory or a lot more memory as the input gets bigger.

It is often described with Big-O notation. Some analyses count total space including input; others count auxiliary space, the extra memory beyond the input itself.

Space analysis includes auxiliary data structures, recursion stack depth, allocator overhead, and sometimes output space depending on convention. In-place algorithms aim for O(1) auxiliary space, but may still have cache or mutation trade-offs.
