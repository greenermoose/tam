Guide / Glossary A–Z / Terms beginning with S / SMS (Short Message Service)

SMS (Short Message Service): the carrier service that carries short text messages through a store-and-forward centre.

SMS is the service that carries short written messages between phones. A service keeps the message until the receiver can get it, so the two people do not have to be online at the same time.

When you send a short text, your phone hands it to a message centre. The centre stores it, finds the receiver, and tries again if the first attempt fails. A receipt can report that handoff, but it does not prove that a person read the words.

3GPP TS 23.040 defines the service. One short message carries a 140-octet user payload: about 160 GSM 7-bit characters or 67 UCS2 characters. Longer text uses concatenated segments with a user-data header. Base SMS has no standard application-layer end-to-end content encryption.
