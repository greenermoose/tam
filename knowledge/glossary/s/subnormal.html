Guide / Glossary A-Z / Terms beginning with S / Subnormal

A subnormal is a very small floating-point value stored without the usual leading digit.

Ordinary floating-point numbers keep a leading 1 bit that does not need to be stored. When a number is too small for that trick, the format can still represent it by giving up the hidden bit. Those tiny values are called subnormal.

Subnormals fill the gap between zero and the smallest normal value. Without them, a calculation that falls below the normal range would jump straight to zero. With them, values fade out gradually. They are sometimes called denormals in older documentation.

Why not just make the exponent range bigger?

The exponent field has a fixed number of bits. Some of its patterns are reserved for zero, infinity and NaN, and the smallest exponent is already in use. Subnormals extend the low end without widening the field.

For IEEE 754 binary formats, a normal value is (-1)^s times 1.f times 2^(e-bias). A subnormal uses e=0, a nonzero fraction field, and an effective leading zero, so its value is (-1)^s times 0.f times 2^(1-bias). This gives gradual underflow but fewer significant bits as values shrink. Some processors handle subnormals much more slowly than normal values, which can create large performance surprises in inner loops.
