Guide / Glossary A–Z / Terms beginning with S / SMTPUTF8 (SMTP UTF-8)

SMTPUTF8 is an SMTP extension that allows internationalised email addresses and UTF-8 text in message headers.

The name means SMTP with UTF-8 support. Without it, classic email rules expect addresses and header text to stay within a narrow ASCII character set. This extension lets names written in other scripts travel through mail servers.

A client sees SMTPUTF8 in the server's EHLO response and may then use it on the MAIL FROM and RCPT TO commands. Header fields can carry UTF-8 directly instead of relying on encoded words in every position.

RFC 6531 defines the extension and RFC 6532 covers UTF-8 header field syntax. Support must be advertised end to end; if any hop lacks it, the message needs downgrading or will be rejected. SMTPUTF8 is part of email address internationalization, often abbreviated EAI.
