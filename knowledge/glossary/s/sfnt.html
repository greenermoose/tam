Guide / Glossary A–Z / Terms beginning with S / SFNT

SFNT is the container format that holds the tables of a modern font file.

Font files such as .ttf and .otf are really packages made of named parts: one lists the letters, another their spacing, another their names. The packaging scheme is called SFNT.

An SFNT file starts with a table directory of four-byte tags and offsets; each table holds one kind of data, such as cmap, glyf, CFF , hmtx or name. TrueType, OpenType and WOFF all use this structure, which lets tools add tables without breaking older readers.

The directory holds searchRange, entrySelector and rangeShift values derived from the table count; offsets are 32-bit and tables are padded to four-byte boundaries. The raw version tag is 0x00010000 for TrueType and 'OTTO' for CFF outlines; WOFF wraps the same tables with compression and a different header. TTX converts an SFNT to a readable listing.
