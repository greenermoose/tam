Guide / Glossary A–Z / Terms beginning with S / SIM swap

SIM swap: transferring a phone number to a different SIM or eSIM, either legitimately or by fraudulent account takeover.

A SIM swap moves a subscription to different phone hardware. It is useful when a phone is lost, but criminals can abuse the same process.

If an attacker swaps a victim's number, texted codes can arrive on the attacker's phone. The code looks valid because the network genuinely moved the subscription.

Strong carrier proof of identity and transfer notifications reduce the risk. Services should not treat control of a phone number as the only factor for a sensitive action.
