Guide / Glossary A–Z / Terms beginning with S / Schema

A schema is the plan that says what a database contains and how its pieces fit together.

A schema is like the labelled form before you fill it in: it says which boxes exist and what kind of answer belongs in each.

A CREATE TABLE statement is part of a schema. Changing a schema later is a migration, and existing data must still satisfy the new rules.

Schemas may be logical or physical. The logical schema describes relations and constraints; the physical schema describes indexes, partitions and storage parameters.
