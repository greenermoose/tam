Guide / Glossary A–Z / Terms beginning with S / Sorting algorithm

An algorithm that arranges items into a defined order, such as numeric or lexicographic order.

It puts things in order, like sorting names alphabetically or numbers from smallest to largest.

Common choices include insertion sort, merge sort, quicksort, heapsort, and Timsort. They differ in speed, memory use, stability, and worst-case behavior.

Comparison sorts have an Ω(n log n) worst-case comparison lower bound; non-comparison sorts like radix/counting sort can beat this under key-structure assumptions. Practical choice also depends on cache behavior, stability, allocation, and data size.
