Signal Protocol: a family of cryptographic protocols for asynchronous end-to-end encrypted messaging.

The Signal Protocol is a set of rules devices use to protect chat messages so that only the people in the conversation can read them.

Each message gets a new key. That means stealing one key does not reveal all the older messages.

Signal's specifications describe X3DH for session setup, the Double Ratchet for per-message keys, Sesame for multi-device sessions and PQXDH for hybrid post-quantum key establishment.
