Guide / Glossary A–Z / Terms beginning with S / Shared memory

Shared memory is a region of memory that more than one process can read or write.

Instead of copying a whole picture through a message, an application can paint into shared memory and tell the compositor where to find it. Both processes see the same pixels.

On Wayland, the wl_shm protocol lets a client create a memory-backed pool and attach part of it to a surface. It is a simple path for CPU-drawn buffers; GPU rendering often uses DMA-BUF instead.

A Linux shared-memory file descriptor is passed over the Wayland socket. The client maps it, writes pixels and commits a buffer; the compositor maps or copies from the same region and sends a release event when finished. Correct lifetime and damage tracking avoid reusing a buffer still presented on screen.
