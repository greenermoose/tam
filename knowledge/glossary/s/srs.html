Guide / Glossary A–Z / Terms beginning with S / SRS (Sender Rewriting Scheme)

SRS changes the envelope sender when a message is forwarded so the forwarding domain becomes responsible for it.

The letters stand for Sender Rewriting Scheme. If a letter is sent on to a new address, the forwarding service puts its own return address on the outside and keeps a coded note about the original sender.

An SRS address uses an SRS0 or SRS1 local part containing a timestamp, the original sender and a hash. If the forwarded message bounces, the forwarding service can decode the address and pass the bounce back to the original sender.

SRS addresses the SPF breakage described in RFC 7208 appendix D.2; it is not an IETF standard. Rewriting the envelope sender helps SPF, but the new domain will usually not align with the original From: domain under DMARC. DKIM may still align if the signature survives, and ARC may preserve the earlier result.
