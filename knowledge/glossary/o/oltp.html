Guide / Glossary A–Z / Terms beginning with O / OLTP (Online Transaction Processing)

OLTP (Online Transaction Processing) describes the many small operations an application performs while people use it. The first two letters, O and L, form Online; T stands for Transaction and P for Processing.

Online means the work happens while a user is waiting, not later in a batch. Transaction means one request is treated as a complete unit, such as placing an order. Processing is the database reading or writing the few rows that request needs. Checking one account balance or changing one address is OLTP.

OLTP workloads need fast indexed point lookups and reliable transactions. Many users act at once, so each request touches little data but must finish quickly and leave consistent results. The guarantees are the same ACID properties described elsewhere.

OLTP systems are usually normalized and write-heavy. "Online" means interactive and latency-sensitive, not necessarily exposed on the public web. Short transactions, row lookups and indexes serve requests; locks or multiversion concurrency control keep overlapping work safe. Long analytical scans can disturb latency, so reporting is often moved to a replica or warehouse for OLAP.
