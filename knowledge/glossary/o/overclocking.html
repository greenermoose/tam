Guide / Glossary A–Z / Terms beginning with O / Overclocking

Running a hardware component faster than its default rated speed, usually to gain performance at the cost of more heat, power use, or reduced stability.

Overclocking means telling a CPU, GPU, memory, or display to run faster than its normal setting. It can make some tasks faster, but it can also make the computer hotter, noisier, less stable, or use more power.

A clock speed is measured in hertz (Hz). Overclocking increases that rate, sometimes with a higher voltage to keep signals stable. Modern CPUs and GPUs already boost above base clocks when power and temperature allow, so manual overclocking may give less headroom than it used to. Risks include crashes, data corruption in extreme cases, thermal throttling, shortened component lifespan, and voided warranties depending on vendor policy.

Overclocking shifts a component outside vendor-validated operating points by increasing frequency, voltage, power limits, or timing aggressiveness. Stability depends on silicon quality (binning), voltage/frequency curves, thermal dissipation, VRM capability, and workload characteristics. Validation requires stress testing, error detection (WHEA/MCE logs, memory errors, rendering artifacts), and monitoring for throttling. The inverse practice, undervolting, can reduce power/heat while preserving performance if stability margins allow.
