Guide / Glossary A–Z / Terms beginning with O / OTF (OpenType Font)

OTF is the file extension for OpenType fonts, which can store outlines, layout features and rich typographic data.

An .otf file is a font package. It holds the shapes of letters and the rules that make them work together, and it can be used across Linux, macOS and Windows.

In practice .otf often means an OpenType font with CFF cubic outlines while .ttf usually means TrueType quadratic outlines; both are OpenType containers and can carry the same layout features. OpenType also supports color glyphs, small caps, ligatures and variable fonts. Fontconfig finds OTF files the same way it finds TTF files.

An OTF is an SFNT container with a table directory of four-byte tags; common tables include head, hhea, maxp, hmtx, cmap, name, post, OS/2 and either CFF or glyf. CFF charstrings use the Type 2 stack machine with subroutines; TrueType glyphs use glyf plus loca. The extension itself guarantees no particular outline format.
