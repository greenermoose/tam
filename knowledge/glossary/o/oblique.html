Guide / Glossary A–Z / Terms beginning with O / Oblique

An oblique style is a slanted version of an upright font, without the redrawn shapes of a true italic.

If the computer simply tilts an upright letter, the result is oblique. It leans like italic, but the letter shapes have not been redesigned, so it looks more mechanical.

True italics often change letterforms, while obliques keep the same outlines with a shear applied. CSS font-style: oblique 10deg requests a slant of about ten degrees. Fontconfig treats italic and oblique as nearby slants, so a missing oblique may resolve to an italic face.

OpenType records post.italicAngle as the negative angle of the slant and sets italic bits in head.macStyle and OS/2.fsSelection; there is no separate oblique flag. Variable fonts use the slnt axis for continuous shear and ital for a designed italic, and both can be present. Synthetic slanting distorts stroke weight and counters and may break hinting.
