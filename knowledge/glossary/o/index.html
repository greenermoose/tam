Guide / Glossary A–Z / Terms beginning with O

Glossary definitions for technical terms and acronyms beginning with O.

Explore

OAuth (Open Authorization)OAuth: an open standard that lets an app use another service on your behalf without receiving your password.
Object file (.o)Object file (.o): An intermediate compiled binary file containing machine code and symbol tables for one source file before linking.
Object storeObject store: storage that keeps whole objects with metadata, addressed by a key rather than a path hierarchy.
ObliqueOblique: A slanted style produced by tilting an upright font design.
OCP (Over-Current Protection)OCP: Power-supply safeguard that cuts or limits current before wires or chips overheat.
OCR (Optical Character Recognition)OCR: Software that reads text out of screenshots or scanned images into copyable characters.
OCSP (Online Certificate Status Protocol)OCSP: Protocol for checking whether an X.509 TLS certificate has been revoked.
OFDM (Orthogonal Frequency-Division Multiplexing)OFDM: Multi-carrier modulation splitting a wideband radio channel into many overlapping orthogonal subcarriers.
OFTC (Open and Free Technology Community)OFTC: Non-profit IRC network hosting Debian, kernel, and free-software project channels.
OIDC (OpenID Connect)OIDC: Identity layer on top of OAuth 2.0 providing signed ID tokens for user authentication.
OLAP (Online Analytical Processing)OLAP: Online Analytical Processing, the read-heavy work of summarizing large data sets.
Oldstyle figuresOldstyle figures: Digits designed with varying heights and forms like lowercase letters.
OLED (Organic Light-Emitting Diode)OLED: A display whose pixels emit their own light.
OLTP (Online Transaction Processing)OLTP: Online Transaction Processing, the short, frequent reads and writes that run an application.
OOM (Out of Memory)OOM: Condition when system RAM and swap are exhausted, forcing the kernel OOM killer to terminate a process.
OPA (Open Policy Agent)OPA: General-purpose policy engine evaluating authorization rules written in Rego.
Opal (TCG Opal Self-Encrypting Drive)Opal: Trusted Computing Group standard for hardware-accelerated encryption inside NVMe and SATA SSDs.
Opcode (operation code)Opcode: The part of an instruction that names the operation.
OpenTypeOpenType: A scalable font format that pairs outlines with layout tables for shaping, languages and color.
Operating systemOperating system: a plain definition and further detail
Operator (vi)Operator (vi): A vi command that performs an action (such as delete, change, or yank) over the range of text selected by a following motion.
OptionOption: A setting that changes how a command behaves.
OrchardOrchard: A group of computers running Tamlinux together, such as a workstation and laptops managed as a fleet.
OSC (Operating System Command)OSC: ESC ] sequence used for window titles, clipboard access, hyperlinks, and palette queries.
OTF (OpenType Font)OTF: An OpenType font file, commonly using CFF cubic outlines.
OTP (One-Time Password)OTP (One-Time Password): a code valid for one login or one action, often delivered by text or an authenticator app.
OTT (Over-The-Top)OTT (Over-The-Top): a service delivered over the public internet rather than operated as part of the carrier's own messaging service.
Outline fontOutline font: A font that stores glyphs as scalable curves rather than fixed pixels.
OverclockingRunning a hardware component faster than its default rated speed, usually for more performance at the cost of heat, power, or stability.
OverflowA result too large for the number format chosen to hold it.
OVP (Over-Voltage Protection)OVP: Circuit safeguard that shuts down or clamps power when voltage exceeds safe limits.
