Guide / Glossary A–Z / Terms beginning with O / Object store

An object store keeps files and their metadata as objects in buckets, addressed by keys.

It is less like folders on a disk and more like a vast set of labelled boxes.

Object stores are common behind data lakes and backups. They scale horizontally and are accessed over HTTP APIs.

Object stores do not offer ordinary file semantics such as cheap rename or partial in-place writes. Listing prefixes and small-object counts can dominate cost and latency.
