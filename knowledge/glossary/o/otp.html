Guide / Glossary A–Z / Terms beginning with O / OTP (One-Time Password)

OTP (One-Time Password): a code valid for one login or one action, often delivered by text or an authenticator app.

An OTP is a short code that works once. A service uses it to check that a person can receive a message at a known number or device.

A code by text is convenient but can be stolen through SIM swap, forwarding or a convincing phone call. A code generated inside an app avoids some of those paths.

NIST SP 800-63B classifies SMS and voice out-of-band authenticators as not phishing-resistant. For high-value actions, prefer phishing-resistant authenticators with non-exportable keys and bind approval to the original session.
