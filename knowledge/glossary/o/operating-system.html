Operating system

An operating system is the software that helps a computer run programs and use its hardware.

The software that helps a computer run programs and use its hardware.

An operating system includes a kernel and supporting software; a Linux distribution assembles these with other tools.

It manages processes, memory, files, devices, and users. The boundary depends on context: a kernel alone is not the complete user-facing software environment normally called an operating system.
