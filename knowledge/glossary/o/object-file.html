Object file (.o)

An intermediate compiled binary file containing machine code and symbol tables for one source file before linking.

When a C compiler builds a program made of several source files, it first translates each source file into its own building-block file—an object file ending in .o—before joining them into the final program.

Compiling each .c file to a .o file lets Make rebuild only the files you edited and then quickly relink all .o files into the final executable.

Why can you not run a .o object file directly as a finished program?

Because an object file still has unresolved references to functions in other object files and libraries; the linker must combine them into an executable first.

On Linux, relocatable object files use the ELF ET_REL format, containing .text, .data, .rodata, symbol tables (.symtab), and relocation entries (.rela.*) resolved by the static or dynamic linker.
