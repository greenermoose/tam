Guide / Glossary A–Z / Terms beginning with O / Outline font

An outline font stores each glyph as mathematical curves that can be scaled to any size.

Instead of a fixed grid of dots, an outline font describes a letter with curves and straight lines. The computer redraws it at whatever size you need, so the letter stays smooth both on screen and in print.

Common outline formats are TrueType (.ttf, quadratic curves), CFF/OpenType (.otf, cubic curves) and variable fonts based on either. Web fonts wrap outlines in WOFF or WOFF2. Before an outline can appear on screen it must undergo rasterization, with hinting and antialiasing applied at the target size.

Outlines are contours in font units scaled by head.unitsPerEm. TrueType stores them in glyf with quadratic Béziers and hinting bytecode; CFF stores Type 2 charstrings with cubic Béziers and declarative hints. FreeType loads outlines, a shaper supplies positioned glyph IDs, and the rasterizer produces coverage masks. Color outline fonts add COLR/CPAL layers.
