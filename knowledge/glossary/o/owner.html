Owner

An owner is the user recorded as responsible for a piece of stored information.

Novice definition

The user recorded as owning a file.

Learner definition

The identity used to select owner permission bits; file-group identity selects a separate class.

Expert definition

An inode records user and group identifiers. Access evaluation also depends on the process credentials and applicable policy; ownership alone is not an access guarantee.
