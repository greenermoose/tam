Gateway

A gateway is the router on a local network that forwards traffic bound for other networks, such as the internet.

Think of your home or office network like a neighborhood cul-de-sac. If you want to deliver a letter to a house on the same street, you can walk straight to their door. If the address is in another city, you drop the letter in the neighborhood mailbox so the postal service can carry it out. On a network, the gateway is that exit point: whenever your computer needs to reach a website or server outside your local network, it hands the packets to the gateway.

On Linux, you can inspect your active gateway with ip route, where the line starting with default via ... names the default gateway IP and outgoing interface. A machine can have specific static routes to nearby subnets via one router and a default gateway for everything else. If your local Wi-Fi or Ethernet connects fine to nearby devices (like a printer or NAS) but cannot reach external websites, a missing or unreachable default gateway—or a DNS failure—is a primary suspect.

Why does a computer only send traffic to the default gateway when the destination IP is outside its local subnet?

For hosts on the same subnet, the operating system resolves the destination’s MAC address directly with ARP (or NDP for IPv6) and delivers frames on the local link. Only destinations that do not match any more-specific local route fall back to the default gateway.

In IPv4/IPv6 routing tables, a gateway is the Layer 3 next-hop address used for longest-prefix-match routes that are off-link; the kernel resolves the gateway’s link-layer address via ARP/NDP and encapsulates packets with the gateway’s MAC while preserving the original destination IP. Beyond basic forwarding, residential and edge gateways commonly perform stateful NAT (masquerading), DHCP/RA service, and firewalling, while multi-homed Linux hosts use policy routing (ip rule / multiple routing tables) or Equal-Cost Multi-Path (ECMP) to avoid asymmetric routing and reverse-path filtering (rp_filter) drops.
