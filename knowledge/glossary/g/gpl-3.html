GPL-3.0 (GNU General Public License v3)

A strong copyleft free-software license that guarantees anyone who receives a program can use, study, modify, and share it—and that modified versions keep those same freedoms.

GPL-3.0 is the open-source license used by Tamlinux tools: it works like a “pay it forward” rule for software. Anyone is free to use the program, look at how it was built, and change it, as long as anyone who shares their updated version gives others the same rights and access to the source code.

Unlike permissive licenses such as MIT or BSD—which allow someone to take open code and ship a closed, proprietary product—GPL-3.0 requires any distributed derivative work to be licensed under GPL-3.0 with its full corresponding source available. Note that copyleft triggers on distribution (conveying binaries to others), not private or internal use. GPL-3.0 also includes an explicit patent grant from contributors and closes the “tivoization” loophole by requiring consumer devices to allow users to install modified versions of the software.

If a company modifies a GPL-3.0 tool for its own internal servers and never distributes it outside, must it publish its changes?

No. GPL-3.0 obligations apply when you convey (distribute) the software or modified versions to others. Running modified code privately—or even offering a web service over a network—does not trigger GPL-3.0 source distribution (unlike AGPL-3.0).

Published by the Free Software Foundation in 2007, GPL-3.0 (SPDX: GPL-3.0-only or GPL-3.0-or-later) addresses compatibility and hardware-lockdown gaps in GPL-2.0. Section 6 defines “Installation Information” for User Products: if a device uses cryptographic signing or firmware locks to reject user-modified binaries, those keys or procedures must be provided unless the device’s ROM cannot be updated by anyone. Section 11 grants an explicit downstream patent license and terminates rights for patent aggressors, while Section 7 permits a bounded set of additional terms (e.g., warranty disclaimers, trademark restrictions, and Apache-2.0 compatibility) that GPL-2.0 lacked—making GPL-3.0 compatible with Apache-2.0 while remaining incompatible with strict GPL-2.0-only codebases such as the Linux kernel.
