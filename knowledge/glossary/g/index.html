Terms beginning with G

Glossary definitions for technical terms and acronyms beginning with G.

Explore

  • Gamma — Gamma: A curve that relates stored values to displayed brightness.
  • Gateway — Gateway: The router that connects a local network to other networks.
  • GBM (Generic Buffer Management) — GBM: Mesa API for allocating GPU scanout and rendering buffers directly on Linux DRM devices.
  • GC (Garbage Collection) — GC: Automatic memory management that frees unreachable objects on the heap.
  • GCC (GNU Compiler Collection) — GCC: Standard open-source C/C++ compiler suite on Linux.
  • GCM (Galois/Counter Mode) — GCM: Widely used AEAD cipher mode combining CTR encryption with GHASH authentication.
  • GDB (GNU Debugger) — GDB: Standard command-line debugger for inspecting C/C++ crashes, breakpoints, and core dumps.
  • Generation — Generation: definition and recovery boundary at each level
  • GF (Galois Field / Finite Field) — GF: Finite mathematical field (such as GF(2^128)) used in AES, GCM, and error-correcting codes.
  • GHASH — GHASH: Polynomial universal hash function over GF(2^128) used for authentication in AES-GCM.
  • GID - Group Identifier — GID: The number that identifies a group.
  • Git — Git: The most widely used version-control system.
  • GJS (GNOME JavaScript) — GJS: JavaScript runtime bindings for GNOME/GTK/GObject introspection.
  • Glob — Glob: Filename pattern matching using wildcards.
  • Glyph — Glyph: The drawn shape of a character.
  • GNOME — GNOME: Major open-source Linux desktop environment built on GTK and Mutter.
  • GNU - GNU's Not Unix — GNU: A free-software project and operating-system effort.
  • GPGPU (General-Purpose Computing on GPUs) — GPGPU: Using graphics processors for non-graphics parallel workloads such as AI, science, and hashing.
  • GPIO - General-Purpose Input/Output — GPIO: A general-purpose pin a computer can read or drive.
  • GPL-3.0 (GNU General Public License v3) — GPL-3.0: Strong copyleft open-source license ensuring modified versions remain free and open.
  • GPT - GUID Partition Table — GPT: The modern disk partition table format.
  • GPU - Graphics Processing Unit — GPU: a plain definition and further detail
  • Greenhouse — Greenhouse: learning reference and next steps
  • GTK (GIMP Toolkit) — GTK: Cross-platform C widget toolkit widely used by GNOME and Linux desktop applications.
  • GUI - Graphical User Interface — GUI: A graphical user interface.
