Guide / Glossary A–Z / Terms beginning with G / Grapheme cluster

A grapheme cluster is a group of code points that software keeps together because readers see them as one character.

An emoji showing a person with a skin tone is stored as more than one number, but you see and delete it as one symbol. That group is a grapheme cluster. A plain letter can also be a cluster of just one code point.

Unicode defines cluster boundaries in UAX #29 so editors can move a cursor sensibly through text with accents, Indic vowel signs and emoji ZWJ sequences. Counting clusters gives an answer closer to 'how many characters do I see' than counting code points or bytes, though scripts and fonts can complicate the visual result.

Extended grapheme clusters extend older rules to cover emoji modifiers, tag sequences and ZWJ sequences, using properties such as Grapheme_Cluster_Break and Extended_Pictographic. Shaping does not preserve one-to-one mapping: a ligature glyph can span several clusters while one cluster may shape into multiple glyphs, so hit-testing must use the shaper's cluster map.
