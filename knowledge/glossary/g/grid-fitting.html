Guide / Glossary A–Z / Terms beginning with G / Grid fitting

Grid fitting is the process of nudging glyph outlines so they line up cleanly with screen pixels.

At small sizes a letter's thin strokes can land between pixels and look blurry. Grid fitting shifts the outlines so strokes sit on whole pixels, making small text crisper, although it can slightly change the letter's shape.

TrueType fonts can include hinting bytecode executed by FreeType's interpreter; CFF fonts use declarative stem and blue-zone hints handled automatically. Grid fitting matters most at small pixel sizes; at large sizes plain antialiasing often looks better. Too much adjustment makes curved letters look uneven.

The interpreter works in fixed-point coordinates relative to pixels per em, snapping stems to whole pixels and aligning flat features to blue zones. Instructions can test points, move them and control dropout protection for thin strokes. Because hinting changes outline geometry, advance widths are also adjusted; subpixel rendering often uses a lighter mode to preserve LCD color filtering.
