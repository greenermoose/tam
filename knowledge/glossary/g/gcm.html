GCM (Galois/Counter Mode)

GCM (Galois/Counter Mode) is a widely used authenticated encryption mode that both scrambles data for confidentiality and attaches an integrity tag to detect tampering.

When you send private information over the internet, hiding the text is only half the job—you also need to know nobody silently changed a few letters along the way. GCM combines both jobs in one fast step: it locks your message so outsiders cannot read it, and adds a tamper-evident seal so the receiver immediately knows if even a single bit was altered in transit.

Most commonly seen as AES-GCM in TLS 1.3, WireGuard-adjacent standards, SSH, and disk/file encryption, GCM pairs Counter (CTR) mode encryption with a polynomial authenticator (GHASH) in a single pass. Because CTR mode turns AES into a stream cipher, both encryption and authentication run in parallel and take advantage of hardware acceleration (such as AES-NI and PCLMULQDQ on x86_64 CPUs). Crucially, every message encrypted with the same key must use a unique nonce (initialization vector).

Why is reusing a nonce with the same key catastrophic in AES-GCM?

Reusing a nonce repeats the exact same CTR keystream, allowing an attacker to XOR two ciphertexts to cancel the keystream and recover plaintext—and in GCM it also leaks the GHASH authentication key, enabling forged messages.

Specified in NIST SP 800-38D, GCM is an AEAD construction combining AES-CTR (with a 96-bit recommended IV/nonce and 32-bit block counter) with universal hashing (GHASH) over the finite field GF(2^128) using the irreducible polynomial x^128 + x^7 + x^2 + x + 1, producing an authentication tag up to 128 bits. A single nonce reuse (the “forbidden attack”) leaks the secret hash subkey H = E_K(0^128) via polynomial root-finding over GF(2^128), breaking authenticity for all past and future messages under that key. Because random 96-bit nonces hit birthday-bound collision risks after ~2^32 messages, high-volume protocols use deterministic counters, key rotation, or nonce-misuse-resistant variants like AES-GCM-SIV (RFC 8452).
