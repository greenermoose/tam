Guide / Glossary A–Z / Terms beginning with G / Glyph

The specific visual shape drawn for a character, symbol, or combination of characters in a font.

A letter like a is an idea, while a glyph is the actual picture of that a drawn on your screen. Different fonts draw the same letter with different glyphs—some with curly tails, some straight—and two letters such as f and i may be merged into one combined shape.

Characters (code points) and glyphs are not one-to-one: one character can map to different glyphs depending on style, weight or small caps, while ligatures and complex scripts combine several code points into one glyph or reorder them visually. When a face lacks a glyph, fallback searches other fonts or shows a placeholder box called tofu. A shaper returns glyph IDs and positions before rasterization.

Why can copying a joined fi ligature from a document still give you the two letters f and i?

The stored text holds two code points; the font substituted one glyph only for visual rendering.

In OpenType and TrueType fonts a glyph is an outline (quadratic Béziers in glyf, cubic in CFF/CFF2), a bitmap strike, or color layers (COLR/CPAL), addressed by an integer Glyph ID. HarfBuzz maps code points to nominal IDs through cmap, applies GSUB substitutions and GPOS positioning, then FreeType hints and rasterizes the result. Ligatures can make one glyph represent several code points, so cluster maps matter for editing.
