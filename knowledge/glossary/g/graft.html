Graft

The process of attaching Tamlinux's scion onto an underlying rootstock operating system.

In horticulture, grafting joins a desired branch onto sturdy roots. In Tamlinux, grafting means attaching Tamlinux's own desktop, commands, and documentation onto a host operating system so both work together as one workstation.

On Tamlinux, grafting separates what the base distribution supplies (kernel, drivers, core libraries) from what Tamlinux builds and owns. Understanding the graft boundary helps you trace whether a file comes from the rootstock package manager or from a Tamlinux source install.

Why does Tamlinux describe installation as grafting onto a rootstock?

Because Tamlinux layers its own tools and desktop (the scion) onto an existing base Linux system (the rootstock) while keeping ownership boundaries clear.

Grafting decouples cultivar delivery under /usr/lib/tamlinux/ from the rootstock's native package database (pacman on Arch Linux), allowing future rootstock transitions without rewriting the scion's user-facing contracts.
