GNOME

A major open-source Linux desktop environment known for its clean, distraction-free interface and built on GTK and the Mutter compositor.

GNOME is a complete graphical desktop for Linux—handling your login screen, top bar, app launcher, settings, and built-in apps like Files and Terminal. It aims for a simple, uncluttered layout where you can focus on one task at a time and switch between workspaces easily.

GNOME is built around the GTK widget toolkit, libadwaita styling, and the Mutter Wayland compositor, and its apps follow the GNOME Human Interface Guidelines (HIG) for consistent shortcuts and layouts. Unlike modular window-manager setups where you assemble a bar, launcher, and compositor separately, GNOME ships an integrated shell that can be customized via GNOME Extensions (written in GJS) and gsettings/dconf.

What is the difference between GNOME and GTK?

GTK is the underlying UI toolkit used to draw buttons, windows, and widgets—many non-GNOME apps and desktops use GTK too. GNOME is the full desktop environment (compositor, shell, settings daemon, and core apps) built on top of GTK.

Originally standing for GNU Network Object Model Environment, modern GNOME centers on gnome-shell (running inside Mutter’s Wayland compositor process via Clutter/Cogl and GJS), gnome-session coordinated with systemd user units, and D-Bus session services (xdg-desktop-portal-gnome, gsd-* settings daemons, and dconf). Because extensions run in-process inside gnome-shell rather than out-of-process over Wayland protocols, an uncaught JS error or memory leak in an extension can destabilize the compositor session itself.
