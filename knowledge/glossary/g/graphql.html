Guide / Glossary A–Z / Terms beginning with G / GraphQL

GraphQL lets a client ask an API for exactly the named fields it needs.

It is like ordering from a menu with checkboxes instead of accepting a fixed set meal.

A GraphQL schema defines types; queries read data and mutations change it. Resolvers fetch values from databases or other services.

GraphQL is not itself a database. Careful field authorization, query depth limits and resolver batching prevent expensive or leaky requests.
