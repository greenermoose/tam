Guide / Glossary A–Z / Terms beginning with G / Graph database

A graph database stores things as nodes and the links between them as edges.

It is a map of people and friendships: the connections are as important as the people.

Queries traverse relationships, which makes linked data and recommendation questions natural to express.

Graph stores index nodes and edges for fast traversal. Some support ACID transactions; distributed graphs must balance traversal locality against partitioning.
