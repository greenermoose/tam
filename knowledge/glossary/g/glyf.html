Guide / Glossary A–Z / Terms beginning with G / glyf

The glyf table is where a TrueType font keeps the actual outlines of its glyphs.

A glyph stored in glyf is described as a set of curves and straight lines. The computer can scale those curves to any size, which is why TrueType letters stay sharp when you zoom in. Empty glyphs take no space in the table.

The table stores quadratic Bézier control points plus flags, with contours marked by the last point of each contour. Composite glyphs are built from simpler ones by referencing component glyph IDs and transforms, saving space for accented letters. The companion loca table gives each glyph's offset into glyf.

Points are integers in font units scaled by head.unitsPerEm; the on-curve/off-curve flag pattern implies quadratic control points, and implied midpoints are generated between consecutive off-curve points. The table may include TrueType hinting bytecode executed by the interpreter. Variable fonts pair glyf with gvar deltas indexed by glyph ID and axis coordinates; CFF-based OpenType fonts use CFF/CFF2 instead.
