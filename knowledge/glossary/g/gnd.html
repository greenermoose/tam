GND (Ground)

The common zero-volt reference point in an electrical circuit that provides the return path for current and a shared baseline for signals.

Ground (GND) is the shared zero-volt baseline in an electrical circuit. Just as height is measured from sea level, voltages on wires are measured relative to ground.

Two devices connected by a signal wire (such as UART or RS-232) must share a common ground reference so both sides agree on what counts as 0 volts versus a high logic level.

What happens if you connect TX and RX between two serial devices without connecting GND?

Without a shared ground reference, the two sides disagree on voltage levels and received data becomes garbled or completely unreadable.

Signal ground provides the return current path and reference potential for single-ended interfaces; separating signal ground from chassis/earth ground prevents ground loops and common-mode noise.
