Guide / Glossary A–Z / Terms beginning with E / Embedded font

An embedded font is included inside a document rather than relying on a font installed on the reader's system.

If you send a poster to someone who lacks the font you used, the layout can change. Embedding puts font data inside the document, so the recipient sees the intended letter shapes even without installing anything. This is common for PDFs and forms.

PDF and some office formats embed font subsets containing only the glyphs actually used, which keeps files small. Embedding supports documents that must look identical on every machine, such as invoices and signed forms. Licences matter: a font's terms must permit embedding, and some restrict it to preview or print.

PDF stores embedded font programs as FontFile streams with descriptors and encodings; subsetting is marked by a subset prefix in the font name and by glyph remapping through a Differences array or CIDToGIDMap. OpenType fonts in PDFs may use CFF or TrueType outlines, and variable fonts are usually instanced to a static face first. fontTools applies the same glyph-closure idea for web documents.
