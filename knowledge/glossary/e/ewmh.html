Guide / Glossary A–Z / Terms beginning with E / EWMH

EWMH is a collection of X11 window properties that desktops use to agree on workspaces and window state.

Workspaces, task lists and "always on top" behaviour are not part of the basic X protocol. These hints give applications and window managers a shared language for them.

EWMH extends ICCCM. A panel can read the list of desktops and the current desktop from root-window properties; an application can request a state such as fullscreen. Without shared hints, each desktop would invent its own behaviour.

Extended Window Manager Hints define atom names, properties and client messages. They cover desktop geometry, window types, states, struts and active-window tracking. They remain X11 conventions; Wayland compositors use protocol objects and extensions instead.
