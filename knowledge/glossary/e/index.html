Terms beginning with E

Glossary definitions for technical terms and acronyms beginning with E.

Explore

  • EAP (Extensible Authentication Protocol) — EAP: Authentication framework used in enterprise Wi-Fi (802.1X / WPA-Enterprise) and VPNs.
  • ECB (Electronic Codebook) — ECB: Simplest block-cipher mode encrypting each block independently, leaking data patterns.
  • ECC - Error-Correcting Code — ECC: Error-correcting code that detects and fixes some memory errors.
  • ECDLP (Elliptic Curve Discrete Logarithm Problem) — ECDLP: Discrete logarithm problem over elliptic-curve point groups, enabling compact keys.
  • ECMA-48 — ECMA-48: International standard for terminal control functions and ANSI escape sequences.
  • EDAC (Error Detection and Correction) — EDAC: Linux kernel subsystem that logs and reports hardware memory (ECC) and bus errors.
  • EDID - Extended Display Identification Data — EDID: a plain definition and further detail
  • EEPROM - Electrically Erasable Programmable Read-Only Memory — EEPROM: Small rewritable non-volatile memory.
  • EFI - Extensible Firmware Interface — EFI: The firmware interface that replaced the legacy BIOS.
  • EFI System Partition — EFI System Partition: The special partition that holds boot firmware files.
  • EGL (Embedded-System Graphics Library) — EGL: Khronos interface connecting OpenGL ES / OpenGL rendering contexts to Wayland or DRM surfaces.
  • EIA-232 (RS-232) — EIA-232: Formal Electronic Industries Alliance name for the RS-232 serial standard.
  • EIRP (Effective Isotropic Radiated Power) — EIRP: Measure of total radiated radio power combining transmitter output and antenna gain.
  • Electromagnetic Wave — Electromagnetic Wave: propagating oscillations of electric and magnetic fields that travel through space
  • Electron — Electron: An electron is a tiny negatively charged particle that moves in atoms and in electric circuits.
  • ELF (Executable and Linkable Format) — ELF: Standard binary file format on Linux for executables, shared libraries (.so), object files, and core dumps.
  • ELF64 — ELF64: 64-bit variant of the Linux Executable and Linkable Format.
  • Embedded interpreter — Embedded interpreter: An interpreter built into another program.
  • EMI (Electromagnetic Interference) — EMI: Unwanted electrical noise radiated or conducted between circuits and cables.
  • Encryption — Encryption: Scrambling data so only authorized people can read it.
  • ENQ (Enquiry, 0x05) — ENQ: ASCII 0x05 control character (Ctrl+E).
  • Environment variable — Environment variable: A named value passed from a parent process to its children.
  • EOF (End of File) — EOF: Condition indicating no more bytes are available from a file, pipe, or input stream.
  • EOT (End of Transmission, 0x04) — EOT: ASCII 0x04 control character (Ctrl+D), signaling end-of-file in terminals.
  • EPUB (Electronic Publication) — EPUB: Open reflowable e-book format built from zipped XHTML, CSS, and metadata.
  • Errexit — Errexit: A shell option that stops after a failed command.
  • ESD - Electrostatic Discharge — ESD: A sudden static-electric discharge that can damage electronics.
  • ESR (Equivalent Series Resistance) — ESR: Internal resistive loss inside a capacitor that limits ripple filtering and causes heating.
  • ETB (End of Transmission Block, 0x17) — ETB: ASCII 0x17 control character (Ctrl+W) marking a data block boundary or word erase.
  • Ethernet — Ethernet: The standard wired local-network technology.
  • ETX (End of Text, 0x03) — ETX: ASCII 0x03 control character (Ctrl+C), triggering SIGINT in terminals.
  • EUF-CMA (Existential Unforgeability under Chosen-Message Attack) — EUF-CMA: Standard security definition for digital signatures and MACs.
  • evdev (event device) — evdev: learning reference, kernel input event subsystem, and device interface
  • EWW (Elkowar's Wacky Widgets) — EWW: Rust-based widget system configured in a Lisp-like Yuck language for Wayland/X11 bars.
  • Executable — Executable: A file the computer can run as a program.
  • Execute — Execute: To carry out an instruction or program.
  • Exit status — Exit status: A number a program returns to say whether it succeeded.
