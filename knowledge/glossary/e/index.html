Guide / Glossary A–Z / Terms beginning with E

Glossary definitions for technical terms and acronyms beginning with E.

Explore

EAP (Extensible Authentication Protocol)EAP: Authentication framework used in enterprise Wi-Fi (802.1X / WPA-Enterprise) and VPNs.
ECB (Electronic Codebook)ECB: Simplest block-cipher mode encrypting each block independently, leaking data patterns.
ECC - Error-Correcting CodeECC: Error-correcting code that detects and fixes some memory errors.
ECDLP (Elliptic Curve Discrete Logarithm Problem)ECDLP: Discrete logarithm problem over elliptic-curve point groups, enabling compact keys.
ECH (Encrypted Client Hello)ECH: TLS extension that encrypts the ClientHello, including SNI, to hide the destination hostname from passive observers.
ECMA-48ECMA-48: International standard for terminal control functions and ANSI escape sequences.
ECMAScriptECMAScript: The standard that defines the core JavaScript language.
EDAC (Error Detection and Correction)EDAC: Linux kernel subsystem that logs and reports hardware memory (ECC) and bus errors.
EDID - Extended Display Identification DataEDID: a plain definition and further detail
EDNS0 (Extension Mechanisms for DNS 0)EDNS0: DNS extension mechanism that uses an OPT record to carry larger UDP sizes and extended flags.
EEPROM - Electrically Erasable Programmable Read-Only MemoryEEPROM: Small rewritable non-volatile memory.
EFI - Extensible Firmware InterfaceEFI: The firmware interface that replaced the legacy BIOS.
EFI System PartitionEFI System Partition: The special partition that holds boot firmware files.
EGL (Embedded-System Graphics Library)EGL: Khronos interface connecting OpenGL ES / OpenGL rendering contexts to Wayland or DRM surfaces.
EIA-232 (RS-232)EIA-232: Formal Electronic Industries Alliance name for the RS-232 serial standard.
EIRP (Effective Isotropic Radiated Power)EIRP: Measure of total radiated radio power combining transmitter output and antenna gain.
Electromagnetic WaveElectromagnetic Wave: propagating oscillations of electric and magnetic fields that travel through space
ElectronElectron: An electron is a tiny negatively charged particle that moves in atoms and in electric circuits.
Electron frameworkElectron framework: A toolkit that packages a Chromium page and Node.js as a desktop application.
ELF (Executable and Linkable Format)ELF: Standard binary file format on Linux for executables, shared libraries (.so), object files, and core dumps.
ELF64ELF64: 64-bit variant of the Linux Executable and Linkable Format.
Embedded interpreterEmbedded interpreter: An interpreter built into another program.
EMI (Electromagnetic Interference)EMI: Unwanted electrical noise radiated or conducted between circuits and cables.
EncryptionEncryption: Scrambling data so only authorized people can read it.
EndiannessThe order in which bytes of a multi-byte value are stored in memory.
ENQ (Enquiry, 0x05)ENQ: ASCII 0x05 control character (Ctrl+E).
Enumeration (hardware)Enumeration (hardware): The startup process where the operating system detects a newly plugged-in device, reads its IDs, and loads the matching driver.
Environment variableEnvironment variable: A named value passed from a parent process to its children.
EOF (End of File)EOF: Condition indicating no more bytes are available from a file, pipe, or input stream.
EOT (End of Transmission, 0x04)EOT: ASCII 0x04 control character (Ctrl+D), signaling end-of-file in terminals.
EPUB (Electronic Publication)EPUB: Open reflowable e-book format built from zipped XHTML, CSS, and metadata.
ErrexitErrexit: A shell option that stops after a failed command.
Escape sequenceEscape sequence: A sequence of bytes beginning with the Escape byte (0x1B) used by terminals to encode special keys and formatting commands.
ESD - Electrostatic DischargeESD: A sudden static-electric discharge that can damage electronics.
ESR (Equivalent Series Resistance)ESR: Internal resistive loss inside a capacitor that limits ripple filtering and causes heating.
ETB (End of Transmission Block, 0x17)ETB: ASCII 0x17 control character (Ctrl+W) marking a data block boundary or word erase.
EthernetEthernet: The standard wired local-network technology.
ETX (End of Text, 0x03)ETX: ASCII 0x03 control character (Ctrl+C), triggering SIGINT in terminals.
EUF-CMA (Existential Unforgeability under Chosen-Message Attack)EUF-CMA: Standard security definition for digital signatures and MACs.
evdev (event device)evdev: learning reference, kernel input event subsystem, and device interface
Event loopEvent loop: The mechanism that runs one task at a time and takes the next when the current one finishes.
EWW (Elkowar's Wacky Widgets)EWW: Rust-based widget system configured in a Lisp-like Yuck language for Wayland/X11 bars.
ExecutableExecutable: A file the computer can run as a program.
ExecuteExecute: To carry out an instruction or program.
Exit statusExit status: A number a program returns to say whether it succeeded.
ExponentThe part of a number that says how many times a base is multiplied by itself.
