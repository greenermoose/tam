Guide / Glossary A–Z / Terms beginning with E / ENQ (Enquiry, 0x05)

Enquiry (ASCII 0x05), an early communications control character traditionally used to request identification or status, and today commonly typed as Ctrl+E.

Long before modern screens, teletype machines used invisible control codes to coordinate over phone lines. ENQ was the “who are you?” code asking the remote machine to send back its name; on today’s keyboards, pressing Ctrl+E sends that same byte, which shells usually use to jump to the end of the line.

As one of the C0 control codes, byte 0x05 is no longer interpreted by Linux terminals as a hardware status request. Instead, interactive line editors like GNU Readline (used by Bash) bind Ctrl+E to end-of-line, complementing Ctrl+A (0x01, start of line).

Why does pressing Ctrl+E move the cursor to the end of the line in Bash instead of querying a terminal name?

The terminal sends byte 0x05 to the foreground program, and Readline maps that byte to its Emacs-style end-of-line editing command rather than an answerback trigger.

Defined as ASCII 0x05 (ENQ, Ctrl+E), the code originally triggered a terminal’s programmable answerback string in serial and X3.64 workflows—a behavior that became a security hazard when untrusted text could inject ENQ to spoof user input. Modern terminal emulators either disable answerback by default or leave it empty, allowing the byte to pass transparently through the TTY line discipline to applications.
