Guide / Glossary A–Z / Terms beginning with E / ESMTP (Extended Simple Mail Transfer Protocol)

ESMTP is SMTP with extra capabilities that the client and server negotiate at the start of a session.

The letters stand for Extended Simple Mail Transfer Protocol. Instead of assuming every server can do the same things, the client asks what extensions are available and uses only the ones both sides support.

A client greets with EHLO instead of the older HELO. The server replies with a list of extensions such as STARTTLS, 8BITMIME or SMTPUTF8. Each extension may add commands, parameters or reply behaviour.

RFC 1869 introduced the extension framework and is historical; the current capability registry is maintained by IANA. ESMTP is not a separate transfer system: it is the normal way modern SMTP negotiates optional features without breaking older servers.
