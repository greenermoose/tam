evdev (event device)

evdev (Event Device) is the Linux kernel subsystem and device interface that delivers input events from hardware to applications.

Keyboards, mice, touchpads, and game controllers all speak different hardware dialects. evdev acts as a universal translator inside Linux, turning all those different button presses and movements into uniform messages that your desktop and apps can understand.

evdev exposes character devices at /dev/input/event*, standardizing diverse hardware protocols into uniform struct input_event streams (keystrokes, relative pointer motion, absolute touch coordinates) consumed by libevdev, libinput, and Wayland compositors. You can inspect live events with evtest or libinput debug-events. Unlike older class-specific nodes such as /dev/input/mouse*, evdev handles every input device type through one interface.

Why do modern Wayland compositors read /dev/input/event* through libinput instead of talking directly to USB or PS/2 drivers?

evdev hides hardware-specific protocols behind one consistent event stream, and libinput builds on it to provide pointer acceleration, palm rejection, and tap-to-click uniformly across devices.

Defined in linux/input.h, evdev packages events into struct input_event records containing a Y2038-safe timestamp, type (EV_KEY, EV_REL, EV_ABS, EV_SYN), code, and value. Atomic multi-axis updates are delimited by SYN_REPORT; multi-touch hardware uses Type B slots (ABS_MT_SLOT, ABS_MT_TRACKING_ID). Key ioctls include EVIOCGBIT (capability bitmasks), EVIOCGABS (axis bounds), and EVIOCGRAB (exclusive grab). If userspace falls behind and the kernel ring buffer overflows, evdev emits SYN_DROPPED so consumers resynchronize state; virtual devices can be injected via /dev/uinput. Read The Linux Input Subsystem and evdev for architecture and examples.
