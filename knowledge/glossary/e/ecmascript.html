ECMAScript is the written standard that says what the core JavaScript language means.

Think of ECMAScript as a rulebook. JavaScript is what people write and run; the rulebook says how the language's words and punctuation should behave.

A major revision in 2015, often called ES6, added modules, classes, arrow functions and promises. Later yearly editions add smaller, agreed features. A browser reports which edition it supports.

Why can two browsers support the same ECMAScript edition but still differ?

The standard covers the language core, not rendering, storage or browser APIs. Engines can also ship different feature sets, and each browser adds its own host services around the language.

Ecma International's TC39 committee develops ECMA-262 through staged proposals. The specification defines syntax, types, abstract operations and built-in objects, but not browser windows, files or network sockets. Those belong to host environments.
