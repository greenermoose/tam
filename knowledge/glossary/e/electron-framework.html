Guide / Glossary A–Z / Terms beginning with E / Electron framework

Electron is a framework that puts a web interface in its own desktop window and adds Node.js services behind it.

An Electron app looks like a normal program with an icon and a window, but its interface is built with the same HTML, CSS and JavaScript used on the web.

Electron runs a main process with Node privileges and renderer processes that display pages. Code uses named messages between them instead of giving page script direct filesystem access.

When is a plain web page a better choice than Electron?

When browser access, small downloads and central updates matter. Electron earns its cost when offline local files or deep desktop integration are required and the team will maintain a bundled browser engine.

Electron bundles Chromium and Node, so updates carry a browser engine as well as app code. The main and renderer processes form a security boundary; untrusted content in a renderer with Node integration enabled can become local code execution. Packaging tools produce platform installers and update channels.
