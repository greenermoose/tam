EPUB (Electronic Publication)

Electronic Publication: an open, reflowable e-book format built from zipped web pages, stylesheets, and metadata.

A PDF is like a printed page photographed onto your screen—if you zoom in on a phone, you end up scrolling sideways. An EPUB book works more like a responsive web page: the text automatically wraps and resizes to fit your phone, tablet, or e-reader comfortably.

Because an EPUB file is actually a standard ZIP archive containing HTML and CSS files, you can inspect or extract it with unzip, and read it on Linux with viewers like Foliate, Calibre, or Okular. Unlike PDFs, EPUBs let readers change fonts, margins, and dark-mode colors cleanly, though fixed-layout EPUBs exist for comics and textbooks.

Why can you inspect the contents of an unencrypted EPUB file using standard ZIP tools?

The EPUB specification packages all chapters, images, stylesheets, and navigation metadata inside a standard ZIP container (with an uncompressed mimetype file first), so tools like unzip can list and extract them directly.

Standardized by the W3C (EPUB 3.3, MIME type application/epub+zip), the Open Container Format (OCF) requires an uncompressed mimetype entry as the first file in the ZIP archive, followed by META-INF/container.xml pointing to the Open Packaging Format (OPF) XML manifest and spine. Content documents use XHTML5 (with optional CSS, SVG, MathML, and Media Overlays), while navigation relies on an HTML nav document replacing EPUB 2’s NCX.
