Guide / Glossary A–Z / Terms beginning with E / EOT (End of Transmission, 0x04)

End of Transmission (ASCII 0x04), a control character that marks the end of input—most familiarly sent by Ctrl+D in a terminal.

When a command waits for you to type lines of text, Enter finishes one line. Ctrl+D sends the EOT code, telling the program you are completely finished typing—like saying 'over and out' on a radio. The same acronym also names an obsolete web font format, described below.

EOT (0x04) is part of the C0 control codes and maps to the terminal's eof setting in canonical line mode. On an empty line it delivers zero bytes, meaning end of file; after typed characters it flushes them without a newline. In typography, EOT also means Embedded OpenType, a compressed web font format from the early web that browsers have largely dropped in favor of WOFF. The two meanings are unrelated.

What happens if you type hello and press Ctrl+D without pressing Enter?

The terminal flushes hello without a trailing newline; a second Ctrl+D on the empty line signals end of file.

In canonical mode ICANON, the VEOF control character (default 0x04) makes the TTY line discipline wake a pending read(2) with the current buffer and discard the EOT byte; an empty buffer yields a zero-length read. In raw mode the byte reaches the application unchanged. Embedded OpenType, the other EOT, wrapped OpenType outlines with MicroType Express compression and used a different license-checking model; modern web fonts prefer WOFF or WOFF2.
