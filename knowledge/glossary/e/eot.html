Guide / Glossary A–Z / Terms beginning with E / EOT (End of Transmission, 0x04)

End of Transmission (ASCII 0x04), a control character that marks the end of input—most familiarly sent by pressing Ctrl+D in a Linux terminal.

When you run a command in a terminal and it waits for you to type lines of text, pressing Enter only finishes one line. Pressing Ctrl+D sends the EOT (“End of Transmission”) code, telling the program that you are completely finished typing—like saying “over and out” on a radio.

Part of the C0 control codes, EOT (0x04) is mapped by default to the terminal’s eof setting in canonical line mode. If you press Ctrl+D on an empty line, the program receives zero bytes (EOF); if you press it after typing characters without pressing Enter, it flushes those characters immediately to the program.

What happens if you type hello and immediately press Ctrl+D without pressing Enter first?

The terminal flushes hello to the program right away without a trailing newline; you must press Ctrl+D a second time on the now-empty buffer to actually signal EOF.

In termios canonical mode (ICANON), the VEOF control character (defaulting to ASCII 0x04, EOT) causes the TTY line discipline to wake any pending read(2) with the current line buffer and discard the VEOF byte itself. When the buffer is empty, read(2) returns 0, yielding EOF; in raw/non-canonical mode (-icanon), 0x04 is passed literally to the application without special handling.
