EEPROM - Electrically Erasable Programmable Read-Only Memory

EEPROM (Electrically Erasable Programmable Read-Only Memory) is a small, rewritable non-volatile memory chip that keeps data when power is turned off.

EEPROM works like a tiny digital sticky note soldered onto a circuit board. Unlike regular RAM—which forgets everything as soon as you unplug the computer—EEPROM holds onto small pieces of information such as a monitor’s model details or a network card’s hardware address, and can be updated electronically without removing the chip.

Unlike NAND or NOR flash, which must be erased in large blocks, EEPROM supports byte-level or small-page rewrites over simple buses like I2C or SPI. Because its capacity is usually only kilobytes, hardware uses it for configuration data—such as RAM SPD timings (readable on Linux with decode-dimms via at24/ee1004 drivers) or MAC addresses—rather than bulk storage.

Why shouldn’t firmware or a driver write to an EEPROM continuously in a tight loop?

Each EEPROM cell has a finite write-endurance limit (typically 100,000 to 1,000,000 erase/write cycles), so constant updates will physically wear out the memory cells.

EEPROM uses floating-gate (FLOTOX) or SONOS cells programmed and erased via Fowler–Nordheim tunneling. Typical I2C devices (addresses 0x50–0x57) accept single-byte or small page-buffer writes (16–64 bytes) followed by an internal ~5 ms write cycle (t_WR) during which the chip NAKs bus polls; hardware write-protect (WP) pins guard calibration tables and SPD records against accidental overwrites.
