Escape sequence

A sequence of bytes beginning with the Escape byte (0x1B) used by terminals to encode special keys and formatting commands.

Because keyboards have more keys than plain letters, terminals send a special Escape signal followed by extra characters to represent arrow keys, function keys, or color changes.

When you press Up Arrow in a terminal, the terminal sends three bytes (ESC, [, A) rather than one. Programs decode these sequences using terminfo or parser state machines.

Why does pressing the Escape key alone sometimes feel slightly delayed in older terminal programs?

Because the program pauses briefly to check whether more bytes follow Escape as part of a multi-byte escape sequence.

ECMA-48 escape sequences begin with 0x1B (ESC) and dispatch into CSI (ESC [), OSC (ESC ]), SS3 (ESC O), DCS (ESC P), or two-byte Fe/Fp/Fs sequences; modern terminals can disambiguate keys via the Kitty keyboard protocol.
