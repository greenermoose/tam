Guide / Glossary A–Z / Terms beginning with U / Units per em

Units per em is the number of equal design units used to measure a font's outlines and metrics.

A font designer works on an invisible grid inside the design square. Every letter coordinate and spacing value is a count on that grid. The grid size is the units-per-em value.

OpenType fonts commonly use 1000 units per em and TrueType often uses 2048; both are only scales. A stem of 80 units means 8% of the em in a 1000-unit font. Rasterizers convert these integers to pixels using the requested size and apply hinting at small sizes.

head.unitsPerEm records the value; TrueType requires a power of two, while CFF fonts typically use 1000. hmtx advances, hhea metrics and glyph coordinates all share the same scale, so changing the value without rescaling every number would distort the font. Variable-font deltas in gvar are also expressed in these units.
