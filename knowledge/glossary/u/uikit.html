Guide / Glossary A–Z / Terms beginning with U / UIKit

UIKit is the iOS framework that supplies views, controls and touch event handling to applications.

An iOS app shows one main interface at a time. UIKit still manages a hierarchy of views, so buttons, lists and navigation screens all have a place in the interface.

View controllers manage screens, UIView objects draw content, and touch events travel through the view hierarchy. Core Animation composites the resulting layers. SwiftUI offers a declarative alternative on top of the same platform.

UIKit runs an application event loop on the main thread and uses responder chain semantics related to AppKit. It integrates lifecycle, accessibility and system gestures. Although a phone rarely shows overlapping application windows, task switching and system overlays still require composition.
