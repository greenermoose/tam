Guide / Glossary A–Z / Terms beginning with U / Unicode

The universal text standard that assigns a unique number to every written character, symbol and emoji across the world's writing systems.

Early computers agreed on numbers only for English letters and a few marks, so documents in other languages often turned into garbled symbols. Unicode gives every character—from Latin and Cyrillic letters to kanji, symbols and emoji—a permanent ID number that all devices share.

Unicode separates a code point (an abstract number such as U+0041 for A) from an encoding (how that number becomes bytes, most often UTF-8). One visible character can combine several code points, such as a letter plus a combining accent or an emoji with a skin-tone modifier; that unit is a grapheme cluster. A font maps the numbers to glyphs.

Why can moving a cursor over é treat it as two units instead of one?

It can be one precomposed code point or e followed by a combining accent; naive counting sees two code points where a reader sees one character.

Maintained by the Unicode Consortium and synchronized with ISO/IEC 10646, Unicode defines 1,114,112 code points from U+0000 to U+10FFFF in 17 planes, excluding the surrogate range reserved for UTF-16. It also specifies normalization forms for canonical and compatibility equivalence, the Bidirectional Algorithm for mixed direction text, and UAX #29 grapheme boundaries. Linux pathnames are opaque bytes, usually UTF-8 without normalization.
