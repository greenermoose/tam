Guide / Glossary A–Z / Terms beginning with U / UDM (Unified Data Management)

UDM (Unified Data Management): the 5G core function that manages subscriber identity, credentials and access authorisation data.

UDM is the 5G subscriber data store. It holds the identifiers and credentials the core network needs to decide whether a device may join.

When a 5G phone registers, the core uses UDM data to identify the subscription and derive authentication material.

3GPP TS 23.501 places UDM in the 5G core; TS 33.501 defines 5G authentication. UDM works with AUSF and stores concealed permanent identity material rather than sending it openly over the air.
