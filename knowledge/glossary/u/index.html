Terms beginning with U

Glossary definitions for technical terms and acronyms beginning with U.

Explore

  • UART - Universal Asynchronous Receiver-Transmitter — UART: A simple serial port circuit.
  • UDP - User Datagram Protocol — UDP: A simple, connectionless transport protocol.
  • UEFI - Unified Extensible Firmware Interface — UEFI: UEFI is the modern firmware interface that starts when you turn the computer on, before Linux runs.
  • UHBR (Ultra High Bit Rate) — UHBR: DisplayPort 2.0/2.1 link rates (10, 13.5, and 20 Gbps per lane) using 128b/132b encoding.
  • UID - User Identifier — UID: The number that identifies a user.
  • UKI - Unified Kernel Image — UKI: A single bootable file containing kernel, initramfs, and command line.
  • Unicode — Unicode: A standard that assigns a number to every written character.
  • Unit — Unit: A named object managed by systemd.
  • Unix — Unix: Influential 1970s Bell Labs operating system whose pipes, files, and POSIX design shaped Linux and BSD.
  • Unix signals (SIGINT, SIGTERM, SIGKILL, SIGSTOP, SIGQUIT, SIGTSTP, SIGPIPE) — Unix signals: Asynchronous kernel notifications sent to processes to interrupt, pause, or terminate them.
  • UPI (Ultra Path Interconnect) — UPI: Intel multi-socket cache-coherent processor interconnect replacing QPI.
  • Upstream — Upstream: The original project that software comes from.
  • URL (Uniform Resource Locator) — URL: Standardized web or resource address specifying scheme, host, and path.
  • USB - Universal Serial Bus — USB: A standard for connecting devices to a computer.
  • USB-C (USB Type-C) — USB-C: Reversible 24-pin physical connector supporting USB data, USB-PD power, and DisplayPort Alt Mode.
  • USB-PD (USB Power Delivery) — USB-PD: Protocol negotiating variable voltages (5 V to 48 V) and up to 240 W over USB-C CC pins.
  • USB4 — USB4: 40-80 Gbps tunneled USB architecture based on Thunderbolt 3, carrying PCIe, DisplayPort, and USB 3.
  • Userspace — Userspace: Everything outside the kernel.
  • UTF-8 - Unicode Transformation Format (8-bit) — UTF-8: The most common byte encoding for Unicode text.
  • UV (Ultraviolet / Undervoltage) — UV: Ultraviolet light (in optics/sensors) or undervoltage (power-rail fault).
