Guide / Glossary A–Z / Terms beginning with U

Glossary definitions for technical terms and acronyms beginning with U.

Explore

UART (Universal Asynchronous Receiver-Transmitter)UART: A simple serial port circuit.
UDM (Unified Data Management)UDM (Unified Data Management): the 5G core function that manages subscriber identity, credentials and access authorisation data.
UDP (User Datagram Protocol)UDP: A simple, connectionless transport protocol.
UEFI (Unified Extensible Firmware Interface)UEFI: UEFI is the modern firmware interface that starts when you turn the computer on, before Linux runs.
UFW (Uncomplicated Firewall)UFW (Uncomplicated Firewall): A simplified command-line frontend for managing Linux packet-filtering rules, historically used on many desktops before direct nftables policies.
UHBR (Ultra High Bit Rate)UHBR: DisplayPort 2.0/2.1 link rates (10, 13.5, and 20 Gbps per lane) using 128b/132b encoding.
UID (User Identifier)UID: The number that identifies a user.
UIKitUIKit: The iOS framework for views, view controllers and touch event handling.
UKI (Unified Kernel Image)UKI: A single bootable file containing kernel, initramfs, and command line.
Ultra-high definition (UHD)Video formats with more picture samples than common HD formats.
UnderflowA result too small in magnitude for the number format to hold normally.
UnicodeUnicode: A standard that assigns a number to every written character.
UnitUnit: A named object managed by systemd.
UnixUnix: Influential Bell Labs operating system family and design tradition, spanning System V, BSD, commercial Unix, and Unix-like systems such as Linux and macOS.
Unix signals (SIGINT, SIGTERM, SIGKILL, SIGSTOP, SIGQUIT, SIGTSTP, SIGPIPE)Unix signals: Asynchronous kernel notifications sent to processes to interrupt, pause, or terminate them.
UPI (Ultra Path Interconnect)UPI: Intel multi-socket cache-coherent processor interconnect replacing QPI.
UpstreamUpstream: The original project that software comes from.
URL (Uniform Resource Locator)URL: Standardized web or resource address specifying scheme, host, and path.
USB (Universal Serial Bus)USB: A standard for connecting devices to a computer.
USB-C (USB Type-C)USB-C: Reversible 24-pin physical connector supporting USB data, USB-PD power, and DisplayPort Alt Mode.
USB-PD (USB Power Delivery)USB-PD: Protocol negotiating variable voltages (5 V to 48 V) and up to 240 W over USB-C CC pins.
USB4USB4: 40-80 Gbps tunneled USB architecture based on Thunderbolt 3, carrying PCIe, DisplayPort, and USB 3.
User spaceUser space: the unprivileged part of an operating system where ordinary programs run outside the kernel
USSD (Unstructured Supplementary Service Data)USSD (Unstructured Supplementary Service Data): a session-based carrier menu service reached by dialling a short code.
UTF-8 (Unicode Transformation Format, 8-bit)UTF-8: The most common byte encoding for Unicode text.
UV (Ultraviolet / Undervoltage)UV: Ultraviolet light (in optics/sensors) or undervoltage (power-rail fault).
UWSM (Universal Wayland Session Manager)UWSM (Universal Wayland Session Manager): A session manager that starts a Wayland compositor inside proper systemd user units and environment slices.
