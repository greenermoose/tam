UKI - Unified Kernel Image

A single bootable executable file that bundles the Linux kernel, initial RAM disk (initramfs), and kernel command line together.

Normally, starting Linux requires the bootloader to gather several separate pieces from disk—the kernel, a helper filesystem with early drivers, and a list of startup options—before the system can boot. A Unified Kernel Image packs all of those pieces into one self-contained file. Because everything is in one package, the computer’s firmware can check a single digital signature to verify that none of the startup pieces were tampered with.

On UEFI systems, a UKI is a PE/COFF binary stored on the EFI System Partition (often under EFI/Linux/) that UEFI firmware or systemd-boot can execute directly via the kernel’s EFI stub. Because the kernel command line and initramfs are embedded inside the signed image rather than read from mutable bootloader config files, Secure Boot covers the entire early-boot payload. Tools like ukify build UKIs and optionally include CPU microcode, os-release metadata, and a splash image.

Why does signing a UKI close a Secure Boot gap that signing only the kernel binary leaves open?

If only the kernel binary is signed, an attacker with write access to an unencrypted boot partition could still modify the initramfs or kernel command line (for example, adding init=/bin/sh). Bundling and signing them together in a UKI ensures the firmware rejects any tampered component.

A UKI conforms to the UAPI Unified Kernel Image specification as a PE/COFF image linking the Linux EFI stub with named sections: .linux (kernel), .initrd (cpio initramfs, optionally preceded by early microcode), .cmdline, .osrel, .uname, .sbat (UEFI SBAT revocation metadata), and optional .pcrsig / .pcrpkey for TPM 2.0 measured-boot PCR 11 policies. Unlike traditional BLS entries, runtime parameter overrides are blocked when Secure Boot is active (systemd-stub ignores external LoadOptions). Multi-profile UKIs can embed .profile sections for recovery or alternative boot targets while sharing the signed kernel and initrd payloads.
