Guide / Glossary A–Z / Terms beginning with U / Unit interval

A unit interval is a length unit written ui in CSS. One unit interval equals the size of the user interface font, so controls can grow with the reader's font setting.

Stylesheets use units such as pixels and ems to say how big something is. The ui unit is another choice: it follows the font that the operating system uses for interface labels. If a person makes interface text larger, spacing written in unit intervals grows too.

The unit interval is related to em, which follows the font size of the element itself, and to rem, which follows the root font size. 1ui takes the user interface font metric, while 1em depends on where the declaration sits in the document. Both are font-relative; neither is a fixed pixel count.

CSS defines ui alongside other font-relative lengths. Because the reference is the user interface font, a widget toolkit or system theme can change the computed size without changing the stylesheet. Here "UI" means this unit, not a UI (User Interface); context and the ui suffix disambiguate the two senses.
