Guide / Glossary A–Z / Terms beginning with U / UI (User Interface)

UI (User Interface) is everything a person uses to interact with a program: the words, controls, feedback and layout that turn an action into a result.

A command line, a text menu and a set of buttons are all user interfaces. The interface is the part you meet; the program's internal work happens behind it. Good interfaces make the next action and the result of the last action easy to see.

A GUI (Graphical User Interface) is one kind of UI that uses windows, icons and pointing. A TUI (Text User Interface) uses characters in a terminal, and a CLI (Command-Line Interface) uses typed commands. When a page says "UI" without naming one of these, it usually means the interface in general, not necessarily a graphical one. Labels in a UI can change between releases, while stable IDs used in configuration do not.

Interface design separates presentation from state: a toolkit draws widgets, an event loop delivers input, and the application updates model state. Accessibility depends on exposing that state through names, roles and focus order rather than relying on pixels alone. The same distinction matters in Linux desktop environments: the shell, toolkit and application each own part of the visible interface.
