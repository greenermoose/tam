Guide / Glossary A–Z / Terms beginning with U / Unix

An influential operating system family and design tradition that began at Bell Labs in the late 1960s. Its ideas—files, processes, pipes, small tools, and portable C code—shaped BSD, System V, commercial Unix systems, Linux, and macOS.

Unix started as a research operating system at Bell Labs, built by Ken Thompson, Dennis Ritchie, and others. It became famous for simple, powerful ideas: keep programs small, let them work together, and treat many things as files. Over time, different groups made their own Unix systems. Some were called "Unix-like" because they followed the same style, while others were officially certified as UNIX. Today, when you use Linux or macOS, you are using systems deeply influenced by Unix history.

Unix history is easiest to understand as a family tree with two major early branches: AT&T's System V line and Berkeley's BSD line. Modern systems inherited features from both, and standards like POSIX helped them work in similar ways.

Is Linux a Unix?

Linux is Unix-like: it follows many Unix/POSIX conventions and design ideas, but it was written independently and is not generally marketed as a certified "UNIX" operating system. "UNIX" as a certification/trademark is managed by The Open Group.

Unix history is a lineage of code, interfaces, and standards rather than a single product. Research Unix (early editions through Version 7, and later research editions 8 through 10) established core abstractions: hierarchical filesystem, processes, pipes, shell, and C as the implementation language. The post-V7 split produced two dominant traditions: AT&T System V and UC Berkeley's BSD. The "Unix wars" and vendor fragmentation drove standardization: POSIX (IEEE/ISO), X/Open, and later the Single UNIX Specification (SUS) under The Open Group, which controls the UNIX trademark for compliant systems.

System V and BSD in technical terms

System V Release 4 (SVR4) was a major convergence point, combining AT&T System V, BSD, SunOS, and Xenix features. Many practical differences that users once learned—init systems, printing, packaging, some IPC interfaces, device naming conventions—were historically SysV vs BSD markers, though modern systems have mixed and evolved them. BSD's enduring technical contributions include the sockets API and TCP/IP implementation in 4.2BSD, the fast filesystem (FFS), and a coherent base-system development model.

macOS and UNIX

macOS is related to Unix in both lineage and certification. Apple’s modern operating system descends from NeXTSTEP/OPENSTEP. Its core, Darwin, combines the XNU kernel (Mach + BSD-derived components + I/O Kit) with a userland that includes substantial BSD-derived code. Apple also submits macOS for The Open Group’s Single UNIX Specification compliance; macOS (starting with Mac OS X 10.5 Leopard on Intel) is a certified UNIX 03 system. iOS, iPadOS, watchOS, and tvOS share Darwin/XNU foundations but are not marketed as separately certified UNIX desktop/server operating systems in the same way macOS is.

Trade-offs and care

  • Trademark vs design: "UNIX" (all caps) is a certification/trademark; "Unix-like" describes behavior/design without certification.
  • Lineage vs compatibility: a system can inherit BSD code and still have its own kernel or userland behavior.
  • Standards do not erase differences: POSIX/SUS improve portability, but filesystems, service managers, packaging, security frameworks, and kernel interfaces still differ.
