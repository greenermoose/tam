Guide / Glossary A–Z / Terms beginning with U / UWSM (Universal Wayland Session Manager)

A session manager that starts a Wayland compositor inside proper systemd user units and environment slices.

UWSM is a helper that launches your graphical desktop cleanly under systemd so background services, audio, and environment variables all start and stop in the right order.

On Tamlinux, starting the graphical desktop runs Hyprland through UWSM, which exports session environment variables to systemd user services and cleans them up when you log out.

Why does Tamlinux start Hyprland through UWSM instead of running Hyprland directly from a shell?

UWSM integrates the Wayland compositor with systemd user units, ensuring services receive the right display environment and shut down cleanly on logout.

UWSM wraps compositor startup into graphical-session.target and app-graphical.slice cgroup units, managing WAYLAND_DISPLAY and XDG_CURRENT_DESKTOP propagation and preventing lingering user daemons across session restarts.
