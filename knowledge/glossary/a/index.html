Terms beginning with A

Glossary definitions for technical terms and acronyms beginning with A.

Explore

AAD (Additional Authenticated Data)AAD: Plaintext metadata (such as packet headers) integrity-protected by an AEAD cipher without being encrypted.
ABAC (Attribute-Based Access Control)ABAC: Fine-grained access-control model evaluating attributes of user, resource, action, and environment.
ABI - Application Binary InterfaceABI: The binary rules for calling and representing data.
AC - Alternating CurrentAC: Electric current that reverses direction.
ACK (Acknowledge, 0x06)ACK: ASCII 0x06 control character and general protocol acknowledgment signal.
ACL - Access Control ListACL: A list of fine-grained permissions.
ACPI - Advanced Configuration and Power InterfaceACPI: A standard for power and hardware configuration.
AdapterAdapter: A device that connects different interfaces or supplies power.
AddressSanitizer (ASan)AddressSanitizer: A fast compiler-based memory error detector for C and C++.
AEAD - Authenticated Encryption with Associated DataAEAD: Encryption that protects both secrecy and tampering in a single construction.
AES variants (AES-128, AES-256, AES-CTR, AES-NI, AES-XTS)AES variants: Key sizes, block modes, and hardware acceleration for the Advanced Encryption Standard.
AES-128AES-128: Advanced Encryption Standard using a 128-bit key and 10 rounds.
AES-256AES-256: Advanced Encryption Standard using a 256-bit key and 14 rounds.
AES-CTR (AES Counter Mode)AES-CTR: Stream-cipher mode turning AES into a parallelizable keystream via an incrementing counter.
AES-GCM-SIVAES-GCM-SIV: nonce-misuse-resistant AEAD construction that combines AES-GCM-like performance with synthetic IV derivation.
AES-NI (AES New Instructions)AES-NI: x86_64 CPU instruction-set extension accelerating AES encryption in constant time.
AES-XTS (XEX-based Tweaked-Codebook with Ciphertext Stealing)AES-XTS: Disk-encryption block mode using sector-number tweaks without expanding sector size.
AGS (Aylur's GTK Shell)AGS: JavaScript/TypeScript widget framework over GTK3/GTK4 for building Wayland desktop shells.
AI - Artificial IntelligenceAI: Software that performs tasks associated with human intelligence.
AIEE (American Institute of Electrical Engineers)AIEE: Historical US electrical-engineering society that merged with IRE in 1963 to form IEEE.
AllowlistAllowlist: A list of things that are explicitly permitted.
ALPN (Application-Layer Protocol Negotiation)ALPN: TLS extension that negotiates the application protocol (such as h2 or http/1.1) during the handshake.
Alt ModeAlt Mode: A USB-C mode that carries another protocol.
ALU - Arithmetic Logic UnitALU: The part of a processor that does arithmetic and logic.
AMD-V (AMD Virtualization)AMD-V: Hardware virtualization extensions (SVM) in AMD x86_64 processors.
AMD64 (Advanced Micro Devices 64-bit)AMD64: The 64-bit extension of x86.
AMOLED (Active-Matrix Organic Light-Emitting Diode)AMOLED: Self-emissive OLED display using an active thin-film transistor backplane per pixel.
Analog videoVideo represented by continuously varying electrical signals.
ANSI (American National Standards Institute)ANSI: US standards body whose X3.64 terminal standard popularized escape sequences.
Anti-aliasingAnti-aliasing: Softening jagged edges by blending colors.
ANV (Intel Vulkan Mesa Driver)ANV: Open-source userspace Vulkan graphics driver for Intel GPUs in Mesa.
API - Application Programming InterfaceAPI: A defined way for software to call another piece of software.
APIC - Advanced Programmable Interrupt ControllerAPIC: An interrupt controller used in modern PCs.
APU (Accelerated Processing Unit)APU: Processor package combining CPU cores and an integrated GPU on the same die or package.
ArgumentArgument: a plain definition and further detail
ARM - Advanced RISC MachinesARM: A processor family common in phones and small computers.
ARM64 (AArch64)ARM64: 64-bit ARM processor architecture used in modern servers, phones, and Apple Silicon.
ARP (Address Resolution Protocol)ARP: the protocol that maps an IPv4 address on the local link to a hardware (MAC) address.
ARQ (Automatic Repeat Request)ARQ: Error-control protocol that detects corrupt frames and requests retransmission.
ARX (Add-Rotate-XOR)ARX: Cipher design paradigm using only modular addition, bit rotation, and XOR.
ASCII - American Standard Code for Information InterchangeASCII: A seven-bit character encoding for basic English text.
ASIC (Application-Specific Integrated Circuit)ASIC: Custom silicon chip engineered for one dedicated task rather than general-purpose computing.
ASLR (Address Space Layout Randomization)ASLR: Kernel security mitigation that randomizes process memory addresses on each launch.
ASN.1 (Abstract Syntax Notation One)ASN.1: Interface description language used to encode X.509 certificates and cryptographic keys.
ASPM (Active State Power Management)ASPM: PCIe power-saving mechanism putting idle links into low-power L0s/L1 states.
AssemblerAssembler: A program that translates assembly language into machine code.
Assembly (Tamlinux)Assembly (Tamlinux): A recorded bundle of packages and revisions delivered together.
Asymmetric encryptionAsymmetric encryption: Encryption that uses a public key to lock data and a separate private key to unlock it.
ATX (Advanced Technology eXtended)ATX: Standard desktop motherboard and power-supply form factor and connector specification.
AUR (Arch User Repository)AUR: Community-maintained repository of PKGBUILD scripts for building extra Arch Linux packages.
AuthenticationAuthentication: Proving who you are.
AuthorizationAuthorization: Deciding what an authenticated identity is allowed to read, change, or execute.
AV1A video compression format developed by the Alliance for Open Media.
AvahiAvahi: the Linux implementation of zero-configuration networking, publishing and discovering local services.
AVX (Advanced Vector Extensions)AVX: 256-bit SIMD instruction-set extension for x86_64 processors.
AVX2 (Advanced Vector Extensions 2)AVX2: 256-bit integer SIMD and FMA extension on x86_64 (Haswell / Excavator and newer).
AWG (American Wire Gauge)AWG: Standardized wire-diameter numbering system where smaller numbers mean thicker copper.
