Guide / Glossary A–Z / Terms beginning with A / Alt Mode

A USB-C operating mode that repurposes high-speed USB-C wires to carry another protocol such as DisplayPort or Thunderbolt.

USB-C describes the oval plug shape, not a single type of signal. Alt Mode lets a USB-C port and cable switch some of their internal wires from carrying normal USB file transfers to carrying a monitor signal like DisplayPort or HDMI. That is why one USB-C port can drive a display while another charging-only or data-only USB-C port cannot, even though the plug fits both.

DisplayPort Alt Mode sends native GPU video directly over USB-C without software compression, so monitors appear on Linux as standard DRM/KMS outputs (like DP-1) and work even in UEFI/BIOS menus—unlike USB-A DisplayLink dongles that compress video over regular USB packets and need special drivers. Using Alt Mode requires both a port wired to the GPU (often marked with a DisplayPort or lightning icon) and a full-featured USB-C data/video cable rather than a charging-only cable.

Why can a USB-C monitor work on one laptop’s USB-C port but show no signal on another laptop’s USB-C port?

The USB-C connector shape does not guarantee video output. Only ports wired to the GPU and supporting DisplayPort (or Thunderbolt) Alt Mode can reassign high-speed lanes to carry native video; data-only or charging-only ports lack those video connections.

USB Type-C Alternate Mode is negotiated over the Configuration Channel (CC) pin using USB Power Delivery (USB PD) Structured Vendor-Defined Messages (VDMs)—Discover Identity, Discover SVIDs, Discover Modes, and Enter Mode—keyed by a Standard or Vendor ID (such as 0xFF01 for VESA DisplayPort Alt Mode). Entering DP Alt Mode remaps the four SuperSpeed differential pairs (TX1/RX1, TX2/RX2) into four unidirectional DP lanes (leaving only USB 2.0 on D+/D-) or two DP lanes plus one USB 3.x lane, while the SBU1/SBU2 sideband pins carry the DisplayPort AUX_CH.
