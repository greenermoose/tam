Guide / Glossary A–Z / Terms beginning with A / AppKit

AppKit is the macOS framework that supplies windows, views, controls and event handling to applications.

A macOS application creates windows with AppKit and fills them with standard controls such as buttons and menus. AppKit turns clicks and key presses into actions your code can handle.

NSWindow owns a window, NSView objects draw its content, and the responder chain passes events through views until one handles them. Drawing and presentation use Quartz and Core Animation.

AppKit is the desktop application framework in Cocoa. It integrates menus, document architecture, accessibility, drag and drop, and the macOS event loop. SwiftUI can wrap AppKit views where a declarative interface needs AppKit behaviour.
