APU (Accelerated Processing Unit)

A processor chip that combines general-purpose CPU cores and an integrated graphics processor (GPU) on the same package, sharing system memory.

Many desktop PCs have two separate main chips: a CPU for everyday thinking and a large graphics card for games and video. An APU puts both onto a single chip, which is why laptops and compact PCs can be thin, quiet, and power-efficient without needing a separate graphics card.

Because an APU’s CPU and GPU share the same system RAM instead of using dedicated VRAM on a graphics card, two things matter in Linux: first, faster dual-channel RAM noticeably boosts graphics performance; second, the firmware (UEFI/BIOS) reserves a slice of RAM for the GPU (often called UMA frame buffer size), though the Linux amdgpu driver can dynamically allocate additional system memory via GTT (Graphics Translation Table) as needed.

Why does upgrading a laptop with an APU from single-channel to dual-channel RAM often improve 3D graphics frame rates?

The integrated GPU has no dedicated VRAM and shares system memory with the CPU; dual-channel RAM doubles memory bandwidth, relieving the shared memory bottleneck.

“APU” (Accelerated Processing Unit) is AMD’s term for a heterogeneous CPU+iGPU SoC in which Zen CPU complexes and RDNA/Vega GPU compute units communicate over a coherent Infinity Fabric interconnect and share unified DRAM controllers. Because CPU and GPU share a physical memory pool and page-table coherent fabric (supporting IOMMUv2 / Heterogeneous Memory Management and shared virtual memory in ROCm), zero-copy buffer sharing avoids PCIe DMA transfers, though GPU workloads compete directly with CPU cores for LLC/DRAM bandwidth and thermal TDP headroom (managed via STAPM/PPT power-budgeting in SMU firmware).
