Guide / Glossary A–Z / Terms beginning with A / Apache Parquet

Parquet stores data by column rather than by row, which helps analytics that read a few columns from many rows.

If a report needs only "city" from a million records, a columnar file can skip every other column.

Parquet is common in data lakes and read by engines such as Spark, DuckDB and pandas-backed tools.

Column statistics, compression and nested encodings reduce I/O. Row groups set the unit of reading and predicate pushdown; many tiny files still hurt performance.
