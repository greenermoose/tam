Guide / Glossary A–Z / Terms beginning with A / Algorithm

A precise, step-by-step procedure for solving a problem or performing a computation.

An algorithm is a clear set of instructions for getting something done. A recipe, a sorting method, and a search procedure can all be algorithms if they are precise enough to follow.

In computing, algorithms take input, follow defined steps, and produce output. Different algorithms can solve the same problem with different trade-offs in speed, memory, simplicity, and correctness guarantees. See Algorithm analysis for how to compare them.

Algorithm design and analysis considers correctness, termination, complexity (time/space), adversarial inputs, and model assumptions (RAM, bit, I/O, parallel). Practical choice also depends on constants, cache behavior, implementation complexity, and numerical or security properties.
