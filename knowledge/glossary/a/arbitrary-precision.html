Arbitrary precision

A way of storing numbers that uses more memory when the value gets larger.

An eight-bit counter stops making sense above 255. An arbitrary-precision number adds more storage as needed, like writing another column when a sum grows past 9.

Python integers are arbitrary precision, so 2**100 works without a special type. In C, a fixed uint64_t wraps at 2^64. The trade-off is cost: arbitrary-precision operations allocate memory and run many machine-word steps, while fixed-width values fit in registers and are much faster.

Is arbitrary precision the same as arbitrary accuracy?

No. It removes the fixed limit on integer size. A rational or decimal type still needs rules for division and rounding, and measured values can still be uncertain.

Libraries such as GMP represent a big integer as an array of machine words plus a sign and length. Addition and multiplication are schoolbook algorithms for small sizes and Karatsuba or FFT-based multiplication for large ones. Fixed-width arithmetic still matters at the edges: byte order, sign extension and language-defined overflow behaviour apply when data crosses into a native type. Arbitrary-precision floating point also exists, but its precision must be chosen and carried explicitly.
