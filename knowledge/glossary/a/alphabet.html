Guide / Glossary A–Z / Terms beginning with A / Alphabet

A writing system in which each sign stands for a sound of the language rather than a word or syllable.

The Latin letters you are reading now form an alphabet: a small set of signs that can be combined to spell any word. Each letter names a sound, the order is learned by heart, and the same set can write many languages. Chinese characters are not an alphabet.

A true alphabet gives consonants and vowels comparable status. That distinguishes it from an abjad, which mainly writes consonants, and an abugida, whose consonant signs carry an inherent vowel. Latin, Greek, Cyrillic and Hangul are alphabets, though Hangul groups its letters into syllable blocks when written. Unicode assigns each letter a code point and a font maps it to a glyph.

Why is Hangul described as alphabetic even though it is written in blocks?

Its basic signs represent individual sounds; the blocks are a way of grouping those signs into syllables.

Alphabetic writing developed from Egyptian and Proto-Sinaitic prototypes through Phoenician; Greek added dedicated vowel letters. Unicode encodes letters in script blocks, often as case pairs, and treats casing, accent handling and locale collation as separate operations. An alphabet of roughly 20 to 40 letters needs only a few hundred glyphs, unlike the tens of thousands needed for a logographic script.
