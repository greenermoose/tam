ALU - Arithmetic Logic Unit

Arithmetic Logic Unit: the part of a processor core that performs integer arithmetic and bitwise logic operations.

If a processor is like a busy workshop, the ALU is the workbench calculator where the actual math and comparisons happen. Whenever a program adds two numbers, checks whether one score is higher than another, or flips individual on/off bits, the CPU sends those inputs into the ALU and gets back the answer along with simple status clues like “the result was zero.”

Inside a CPU core, the ALU handles integer addition, subtraction, bit shifts, and bitwise logic (AND, OR, XOR) under the direction of instruction decoding—contrasting with the Floating-Point Unit (FPU) and SIMD/vector units that handle decimal math and parallel array operations. When a program checks if (a == b), the CPU typically uses the ALU to subtract or XOR the values and inspect the resulting status flags before deciding whether to branch.

When a program runs a comparison like if (x == y), how does the ALU participate?

The ALU commonly computes x - y (or x XOR y) and updates the processor’s status flags without needing to save the difference. If the Zero flag is set, the conditional branch instruction knows the two values are equal.

An ALU is a combinational logic block—typically built from carry-lookahead or parallel-prefix (e.g., Kogge-Stone) adders, barrel shifters, and muxed bitwise gates—that outputs an integer result and updates condition flags (ZF, CF, SF/NF, OF/VF in x86_64 RFLAGS or ARM64 NZCV), distinguishing unsigned carry (CF) from signed two’s-complement overflow (OF). Modern superscalar out-of-order cores dispatch simple 1-cycle integer ops across multiple parallel ALU execution ports, while separate address-generation units (AGUs) and pipelined multipliers/dividers handle memory offsets and multi-cycle math.
