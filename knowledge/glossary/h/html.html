HTML (HyperText Markup Language)

HTML (HyperText Markup Language) is the standard markup language for web pages and tam’s offline knowledge corpus.

HTML is a plain text file with simple labels (“tags”) wrapped around words—marking a title as a heading, items as a bullet list, or a phrase as a clickable link. A web browser, or tam in your terminal, reads those labels so it knows how to organize and display the page cleanly instead of showing one flat wall of text.

HTML separates document structure (<h1>, <p>, <dl>, <pre>) from presentation (CSS in browsers, or terminal layout in tam). Using semantic tags such as <section data-level>, <nav>, and <details> lets tools index pages, filter explanations by skill level, and support screen readers, whereas generic <div> elements carry no meaning on their own.

Why does tam’s knowledge corpus use tags like <h1>, <dl>, and <section data-level> instead of raw terminal formatting?

Semantic tags describe what each piece of content is rather than how it looks on one screen. That lets tam render the same HTML file cleanly in any terminal width, filter by skill level, and index it reliably.

Defined by the WHATWG HTML Living Standard, HTML5 specifies an error-tolerant tokenization and tree-construction state machine (including implicit end-tag rules for elements like <p> and <li>, plus foreign-content rules for SVG/MathML). Because text/html is not XML-strict, tools must either use an HTML5-compliant parser or enforce a clean subset. In tam’s knowledge corpus, pages adhere to a strict semantic HTML5 subset validated by tools/build-index.py, using UTF-8 punctuation directly and structuring skill levels with data-level attributes.
