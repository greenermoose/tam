Terms beginning with H

Glossary definitions for technical terms and acronyms beginning with H.

Explore

H.264 (AVC)A widely used video compression standard.
HAIFA (HAsh Iterative FrAmework)HAIFA: Cryptographic hash construction adding salt and bit-counter inputs to prevent length-extension and multi-target attacks.
Half DuplexHalf Duplex: a bidirectional channel where only one party can transmit at any given moment
Halting problemHalting problem: The provably unsolvable problem of deciding whether an arbitrary program will eventually finish or run forever.
HAMMER2HAMMER2: Default copy-on-write clustering filesystem of DragonFly BSD.
Hard linkHard link: A second name for the same file.
HashHash: A fixed-size value derived from data.
HBR (High Bit Rate)HBR: DisplayPort 2.7 Gbps per-lane link rate.
HBR2 (High Bit Rate 2)HBR2: DisplayPort 1.2 5.4 Gbps per-lane link rate supporting 4K at 60 Hz.
HBR3 (High Bit Rate 3)HBR3: DisplayPort 1.3/1.4 8.1 Gbps per-lane link rate supporting 4K 120 Hz or 8K with DSC.
HDD - Hard Disk DriveHDD: Storage that uses spinning magnetic disks.
HDMI - High-Definition Multimedia InterfaceHDMI: a plain definition and further detail
HDR - High Dynamic RangeHDR: A display mode with a wider range of brightness and color.
HeadroomHeadroom: Extra capacity kept in reserve.
HexadecimalHexadecimal: A number system that uses sixteen digits.
HibernationHibernation: Saving memory to disk and powering off.
HID (Human Interface Device)HID: USB and Bluetooth device class for keyboards, mice, touchpads, and FIDO2 keys.
High definition (HD)A group of video formats with more picture detail than standard definition.
HMAC - Hash-based Message Authentication CodeHMAC: A standard way to build a secret-key message authentication tag from a hash function.
HMAC-SHA1HMAC-SHA1: Keyed-hash message authentication code built on SHA-1.
HMAC-SHA256HMAC-SHA256: Keyed-hash message authentication code using SHA-256.
Home directoryHome directory: The folder that holds one user's personal files.
Home ManagerHome Manager: Home Manager is the Nix tool that builds a user's configuration and programs into a generation you can switch or roll back.
HostHost: the physical computer hardware on which a rootstock is installed
HPD (Hot Plug Detect)HPD: Physical signal pin on HDMI/DisplayPort alerting the GPU when a monitor connects, disconnects, or requests attention.
HQC (Hamming Quasi-Cyclic)HQC: Code-based post-quantum key encapsulation mechanism selected by NIST as a backup to ML-KEM.
HRU (Harrison-Ruzzo-Ullman model)HRU: Classic formal access-control model proving that general safety verification is undecidable.
HS256 (HMAC with SHA-256)HS256: JWS/JWT algorithm identifier for symmetric HMAC-SHA256 signatures.
HSP (Hidden Subgroup Problem)HSP: Algebraic problem generalized by Shor's algorithm to break RSA, Diffie-Hellman, and ECC on quantum computers.
HSTS (HTTP Strict Transport Security)HSTS: HTTP response header instructing browsers to connect only over HTTPS.
HT (Horizontal Tab, 0x09)HT: ASCII 0x09 control character (Ctrl+I), advancing to the next tab stop.
HTML (HyperText Markup Language)HTML: Standard markup language for web pages and tam's offline knowledge corpus.
HTTP - Hypertext Transfer ProtocolHTTP: The protocol behind web pages.
HTTPS - Hypertext Transfer Protocol SecureHTTPS: HTTP protected by TLS.
HueThe aspect of a color described by names such as red, green or blue.
HypervisorHypervisor: Software that runs virtual machines.
HyprlandHyprland: Hyprland is the tiling Wayland compositor Tamlinux uses today for its graphical desktop.
