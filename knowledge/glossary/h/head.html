Guide / Glossary A–Z / Terms beginning with H / head (Font Header Table)

The head table is the mandatory OpenType table that records a font's global header values.

Every scalable font has a header that says how the font is measured and how to interpret its coordinates. That header is the head table. It is small, but tools consult it before reading almost anything else.

Among other fields, head stores units per em, creation and modification dates, the bounding box of all glyphs, the index of the missing-glyph character and flags describing direction. Tools such as TTX display it when inspecting a font file.

The table is 54 bytes long and begins with a fixed version number and magicNumber 0x5F0F3CF5, used to detect corruption. indexToLocFormat says whether loca offsets are short or long; glyphDataFormat is normally zero. The flags record baseline direction and left-to-right override. Timestamps count seconds since 1904 in the Mac epoch.
