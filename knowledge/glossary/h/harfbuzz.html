Guide / Glossary A–Z / Terms beginning with H / HarfBuzz

HarfBuzz is the library that works out which glyphs to draw and where to place them for a run of text.

Typing the letters f and i does not always draw two separate letters; many fonts join them into one shape. HarfBuzz is the part of the text system that decides these joins and spacings before anything is drawn on screen.

HarfBuzz reads a font's OpenType tables, applies script-specific rules for Arabic, Indic and other complex scripts, and returns glyph IDs with positions and cluster values. Toolkits and browsers use it underneath Pango, Firefox and Chrome. It does not choose the font or rasterize glyphs: Fontconfig and FreeType handle those steps.

Shaping buffers items with script, direction, language and font, then runs GSUB and GPOS lookups in feature order (ccmp, liga, calt, kern, mark, mkmk and others). It supports vertical layout, variable-font coordinates and legacy Graphite and AAT shapers. Output cluster values map positioned glyphs back to input ranges so editors can hit-test; fallback runs must be shaped separately.
