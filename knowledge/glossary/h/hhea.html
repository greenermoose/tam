Guide / Glossary A–Z / Terms beginning with H / hhea (Horizontal Header Table)

The hhea table stores a font's global horizontal metrics used to lay out lines of text.

Before a program can place a line of text it needs to know how tall the letters are and how much space to leave between lines. The hhea table supplies those numbers in the font's own units.

Important fields include ascent, descent, line gap, maximum advance width and the number of horizontal metrics in hmtx. Applications commonly use hhea ascent and descent to compute line height, though OS/2 typo metrics may give better results for mixed fonts and web pages.

The table is 36 bytes long; numberOfHMetrics says how many entries hmtx holds, with the last advance reused for remaining glyphs. ascent, descent and lineGap are font-unit values relative to the baseline, and advanceWidthMax supports overflow checks. Disagreements between hhea and OS/2 metrics cause different line heights in browsers and desktop toolkits.
