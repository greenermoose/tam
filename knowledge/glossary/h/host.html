Guide / Glossary A–Z / Terms beginning with H / Host

In Tamlinux, a host is the physical computer hardware on which a rootstock is installed.

Your host is the actual physical machine—the box or laptop, processor, memory, storage, screen, keyboard, and power supply. You install a rootstock (the base operating system) onto the host, then install the Tamlinux bud onto the rootstock, and use the bud to grow the full Tamlinux scion.

Separating the host (physical hardware) from the software layers running on it makes it easier to talk about moving a Tamlinux setup to another computer or diagnosing whether a problem is hardware-related or software-related. Different hosts have different processors, graphics adapters, displays, and power envelopes, which tam inspect can report.

If you install Tamlinux on a different laptop, does the host change?

Yes. The host is the physical hardware—its CPU, RAM, storage, display, and power—so moving to a different machine means running on a new host.

Within the Tamlinux model, “host” denotes the underlying physical platform (compute, volatile memory, block storage, I/O buses, firmware, and power/thermal envelope). It is distinct from the rootstock OS, the bud bootstrap package, and the Tamlinux scion; hardware compatibility still depends on rootstock kernel drivers, firmware, and validated platform targets.
