Guide / Glossary A–Z / Terms beginning with H / hmtx (Horizontal Metrics Table)

The hmtx table records how much horizontal space each glyph takes and where its outline starts.

Every letter occupies a certain width, even the blank space after it. hmtx tells the renderer that width, so the next letter starts in the right place. Two fonts can draw the same letter at different widths.

Each entry has an advance width and a left side bearing in font units. Uniform advances across the basic Latin glyphs make a font monospace; varying advances make it proportional. Kerning and GPOS adjustments change the gap between particular pairs beyond these base values.

The hhea.numberOfHMetrics field gives the number of full (advance, side bearing) pairs; trailing glyphs use the last advance with individual left side bearings listed after them. Values are scaled by units per em and pixels per em before rasterization, and variable fonts apply HVAR deltas. CFF fonts keep hmtx as the SFNT-level metric table while outline widths live in charstrings.
