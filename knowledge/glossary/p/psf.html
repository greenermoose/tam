Guide / Glossary A–Z / Terms beginning with P / PSF (PC Screen Font)

PSF is a binary font format used for the fixed-size bitmap fonts of the Linux text console.

When you change the font of a text console, the file you load is often a PSF file. It contains a small grid of pixels for each character, stored compactly as a binary file. Each size needs its own file.

setfont loads PSF fonts, and also .cp and raw formats, using kbd's kfont_load_fonts(). Kernel console fonts have 256 or 512 characters and a fixed cell size. PSF cannot scale, so it is chosen for the deterministic grain of a text console.

PSF files begin with a magic number (1 or 2), a mode word and a character-size byte; version 2 adds a header with character count and an optional Unicode table. Bitmap data is packed rows of pixels. setfont passes it through KDFONTOP with KD_FONT_OP_SET, SET_TALL or SET_DEFAULT via vt_ioctl.c, vt.c and fbcon; KMScon does not use this path.
