Plugin

A modular extension that adds a widget, status readout, or capability to a host application without modifying its core code.

A plugin is a small add-on piece—such as a clock, weather readout, or battery meter—that plugs into the desktop bar to add a feature without rebuilding the whole desktop.

On Tamlinux, bar plugins (such as fred.clock, fred.sysinfo, and fred.weather) live in tamlinux/desktop/plugins/ and follow a strict security model with bounded inputs and closed environments.

Why build bar widgets as plugins rather than one monolithic desktop program?

Plugins isolate each feature's state and permissions so individual widgets can be enabled, updated, or debugged independently.

Tamlinux Quickshell plugins are QML modules loaded via a manifest contract, executing external probes through a single hardened Launch.qml helper with closed environment variables, timeouts, and descriptor-relative cache writes.
