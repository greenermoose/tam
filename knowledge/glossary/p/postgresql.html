Guide / Glossary A–Z / Terms beginning with P / PostgreSQL

PostgreSQL is a client/server relational database that owns its data in a server-managed directory and answers SQL requests from clients.

A separate server program keeps the records. Applications connect to it rather than opening a database file themselves.

PostgreSQL provides schemas, roles, indexes, transactions, backups and replication. It suits applications where several users or programs share the same data.

Its storage uses multiversion concurrency control and a write-ahead log. A planner chooses query plans from statistics, extensions add types and functions, and partitioning spreads very large tables while connection limits and vacuum maintenance shape operations.
