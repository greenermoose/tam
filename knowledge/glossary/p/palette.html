Guide / Glossary A–Z / Terms beginning with P / Palette

A palette is a curated set of colors used to keep an image, user interface, or theme visually consistent.

Think of a palette like the small tray of paint colors an artist mixes before starting a painting. Instead of picking a brand-new random shade every time you draw a button or an icon, a design picks a small set of matching colors ahead of time. That way everything on your screen—windows, text, and highlights—looks cohesive and stays easy to read.

In desktop theming and UI design, a palette assigns semantic roles—such as background, surface, foreground text, accent, and warning—so switching between light and dark themes updates every app consistently. In image formats like PNG or GIF, an indexed palette (color lookup table) stores a fixed list of colors (often up to 256) and lets each pixel store a small index instead of full RGB values, shrinking file size.

Why does a theme palette define roles like “surface” and “accent” instead of just naming “blue” and “gray”?

Role-based names decouple meaning from appearance. When you switch from a light theme to a dark theme, “surface” and “foreground” can swap lightness automatically without rewriting every widget’s styling.

Palette design spans both colorimetry and data representation. UI theme engines (such as Material You/Monet, Base16, or CSS custom-property systems) generate perceptually uniform tonal ramps in spaces like OKLCH or HCT so contrast ratios meet WCAG AA/AAA targets across dynamic accent shifts. In raster graphics, palette quantization algorithms (median cut, octree, NeuQuant) map 24-bit sRGB pixels into a 1–8 bit CLUT with optional Floyd–Steinberg dithering to trade quantization banding for high-frequency spatial noise; on the web and desktop, mismatched ICC profiles or unmanaged sRGB/Display P3 conversions can shift palette colors across monitors.
