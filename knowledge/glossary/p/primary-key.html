Guide / Glossary A–Z / Terms beginning with P / Primary key

A primary key gives every row in a table a unique, stable identity.

It is like a library card number: two books can share a title, but not the same card number.

A primary key must be unique and not null. Other tables can refer to it with a foreign key.

Many engines store rows in primary-key order, so key choice affects locality, insert cost and secondary index size. Surrogate keys and natural keys make different trade-offs.
