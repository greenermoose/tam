Guide / Glossary A-Z / Terms beginning with P / Pulse-code modulation (PCM)

PCM records a signal as a regular series of numeric samples.

When a microphone is sampled, each moment becomes a number. Keeping those numbers in order is pulse-code modulation. It is the straightforward digital form that many other audio formats start from.

The three main choices are sample rate, bit depth and channel layout. Compact Disc audio uses 44,100 samples per second, 16 bits per sample and two channels. The data rate before any compression is 44,100 times 16 times 2 bits per second, about 1.41 Mbit/s. Formats such as WAV and AIFF can carry PCM; MP3 and AAC usually encode it in a compressed form.

Is PCM the same as a WAV file?

No. PCM is a way of representing samples. WAV is a container that can carry PCM and other encodings. A file extension does not by itself guarantee which one is inside.

Samples may be stored as unsigned offsets from a mid-level code or as signed two's complement values; 16-bit audio commonly uses signed samples. Channel interleaving, byte order and padding are part of the container rules. PCM is uncompressed in the sense that each sample is coded directly, though quantization in the converter already altered the signal. Lossless codecs can reconstruct PCM exactly; lossy codecs cannot.
