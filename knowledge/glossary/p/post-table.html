Guide / Glossary A–Z / Terms beginning with P / post (PostScript Table)

The post table stores PostScript-compatible information for a font, including glyph names and sometimes hinting data.

Some font data is kept for compatibility with older PostScript software. The post table is one such place: it gives letters their traditional names and a few extra typographic values such as underline position.

Version 2.0 stores glyph names as Pascal strings plus an index; version 3.0 omits names to save space, which is common in modern fonts. The table also records italic angle, underline position and thickness, and a fixed-pitch flag used to identify monospaced fonts.

Format 1.0 includes a 32-byte Type 1 font matrix and standard glyph-name indices and can carry a Type 1 hint program; format 2.0 holds custom names with a maximum of 32,767 entries; format 3.0 has no names. Tools such as TTX show them, but shaping engines work with glyph IDs from cmap and GSUB/GPOS instead.
