PTY (Pseudoterminal)

A PTY (pseudoterminal) is a pair of virtual character devices provided by the kernel that lets a graphical terminal emulator, SSH server, or multiplexer act like a physical text terminal for a shell or command-line program.

Long ago, people used physical keyboard-and-screen machines called terminals plugged into a computer’s serial port. Today, when you open a terminal window on your desktop, there is no physical serial cable—so the operating system creates a pretend (“pseudo”) terminal in software. Your terminal window sits on one end passing keystrokes in and drawing characters out, while the shell on the other end behaves just as if it were talking to a real hardware terminal.

A PTY has two connected halves: the primary (historically “master”) side held by the terminal emulator, sshd, or tmux, and the secondary (historically “slave”, appearing as /dev/pts/N) attached to the shell’s standard input, output, and error. Because programs like vim, less, and sudo check isatty() and query terminal dimensions, running a command over a plain pipe or non-interactive ssh host cmd (without -t) behaves differently from running it inside a PTY.

Check: why does ls --color=auto output colors in your terminal window, but plain uncolored text when piped into cat?

ls checks whether standard output is a TTY/PTY via isatty(); inside a terminal window it is connected to a /dev/pts/N PTY, whereas in a pipeline it is connected to an anonymous pipe, so --color=auto disables ANSI color codes.

On Linux, Unix98 PTYs are allocated by opening /dev/ptmx (or the devpts instance’s ptmx), which returns a primary file descriptor and creates a corresponding /dev/pts/N node unlocked via grantpt()/unlockpt() (implemented via TIOCSPTLCK). Bytes written to either side pass through the kernel TTY line discipline (N_TTY by default), which handles canonical buffering, echo, and translating control characters (such as ^C and ^Z) into SIGINT/SIGTSTP for the foreground process group. Window resizes propagate via ioctl(TIOCSWINSZ) followed by SIGWINCH. Note that PTYs have no out-of-band channel for structured data, and legacy TIOCSTI ioctl injection has been restricted/disabled (dev.tty.legacy_tiocsti) in modern kernels to prevent sandbox escapes.
