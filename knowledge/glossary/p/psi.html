PSI (Pressure Stall Information)

PSI (Pressure Stall Information) is a set of Linux kernel metrics under /proc/pressure/ that measures how much time tasks spend waiting for CPU, memory, or I/O.

Traditional meters tell you how busy a resource is—like “CPU is 90% used”—but they do not tell you whether anything is actually stuck waiting. PSI is Linux’s slowdown meter: it measures how often programs are forced to pause because there is not enough memory, processor time, or disk speed available. When PSI numbers climb, the system is genuinely bogged down rather than merely doing useful work efficiently.

Reading /proc/pressure/cpu, /proc/pressure/memory, and /proc/pressure/io shows some (at least one runnable task was stalled) and full (all non-idle tasks were stalled simultaneously, indicating severe contention) over 10-, 60-, and 300-second windows. Services like systemd-oomd monitor memory PSI (including per-cgroup memory.pressure) to terminate runaway processes before thrashing freezes the desktop.

Check: why is high memory full pressure more alarming than high memory some pressure?

some means at least one task is waiting on memory while others may still be making progress, whereas full means every runnable task on the system (or cgroup) is simultaneously stalled waiting for memory reclaim or swap.

Implemented in kernel/sched/psi.c, PSI tracks per-task stall states (PSI_MEMSTALL, PSI_IOSTALL, PSI_CPU_SOME, etc.) per CPU and aggregates them at a fixed 2-second sampling tick into exponentially weighted moving averages (avg10, avg60, avg300) plus monotonic microsecond total counters. Note that CPU has no full line at the root level (since a runnable task is using the CPU whenever it is not idle), though per-cgroup cpu.pressure can report full when CPU bandwidth throttling (cpu.max) stalls the entire cgroup. Processes can also register unprivileged poll()/epoll() triggers by writing a threshold and window (e.g., some 150000 1000000) to a pressure file, enabling low-overhead userspace OOM and workload-shedding daemons.
