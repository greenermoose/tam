Guide / Glossary A–Z / Terms beginning with P / PostScript

PostScript is a page description language that describes text and graphics with scalable curves and coordinates.

Instead of sending a printer a grid of pixels, a computer can send a small program that says 'draw this letter with these curves'. PostScript is that kind of language, which is why printed output stays sharp at any size.

Adobe introduced PostScript in the 1980s; it underpinned desktop publishing and laser printers. Its Type 1 and Type 3 font formats stored outlines as cubic Bézier curves, and its imaging model influenced PDF and the CFF tables used in OpenType.

PostScript is a stack-based language with operators for paths, fills, strokes, transformations and font dictionaries. Text is drawn by selecting a font, setting a matrix and showing glyph names or character codes. Type 1 fonts use hinted charstrings with a private dictionary; Type 3 fonts can contain arbitrary procedures per glyph. PDF adopted the imaging model with a different file structure.
