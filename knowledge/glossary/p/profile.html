Profile

A named set of installed software and links.

Instead of dumping every program into one shared pile, a profile keeps a named, self-contained list of which programs and settings are active right now. Think of it like a saved loadout: you can switch to a new loadout, and if something breaks, switch right back to the previous one.

A Nix or Home Manager profile is a numbered generation of symlinks to immutable packages in the store, with a current symlink pointing to the active generation. Because previous generations remain on disk until garbage-collected, you can roll back without rebuilding or redownloading.

Why can switching back to an older Nix or Home Manager profile happen almost instantly?

Previous generations are still kept in the Nix store. Rolling back only updates a symbolic link to point to an earlier generation’s tree of links rather than reinstalling files.

A profile is a mutable symlink chain (e.g., profile → profile-<N>-link → /nix/store/<hash>-...) referencing an immutable buildEnv or activation tree. Generation switches update the target atomically via rename(2) on a temporary symlink, avoiding half-upgraded states; however, already-running processes keep their open inodes until restarted. Profiles also act as garbage-collection roots for nix-collect-garbage, so deleting old generations is required before unreferenced store paths can be reclaimed.
