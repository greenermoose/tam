Guide / Glossary A–Z / Terms beginning with P

Glossary definitions for technical terms and acronyms beginning with P.

Explore

P-N JunctionP-N Junction: the boundary inside a semiconductor between positive-hole and negative-electron regions
PackagePackage: learning reference and next steps
Package managerPackage manager: Software that installs, updates, and removes packages.
Packed pixel formatAn image layout that interleaves components in memory.
PacketPacket: A small unit of network data.
pacmanpacman: The native package manager of Arch Linux, used on Arch-based Tamlinux to install, query, and update rootstock software.
PagingPaging: Moving memory in fixed-size pages between RAM and storage.
PairingPairing: Setting up two devices to trust each other.
PALA family of analog color television systems.
PalettePalette: A chosen set of colors.
PAM - Pluggable Authentication ModulesPAM: A modular framework for authentication.
PAM modulation (PAM-2, PAM-4, PAM-5)PAM modulation: Pulse-Amplitude Modulation encoding 1 or more bits per electrical voltage level.
PAM-2 (NRZ / 2-level Pulse-Amplitude Modulation)PAM-2: Binary baseband signaling using two voltage levels (1 bit per symbol).
PAM-4 (4-level Pulse-Amplitude Modulation)PAM-4: Signaling using four voltage levels to carry 2 bits per symbol (00, 01, 10, 11).
PAM-5 (5-level Pulse-Amplitude Modulation)PAM-5: Signaling using five voltage levels (-2, -1, 0, +1, +2) in 1000BASE-T Gigabit Ethernet.
Parallel CommunicationParallel Communication: transmitting multiple bits simultaneously across separate physical wires
ParityParity: an error-detection check bit added to data to ensure an even or odd count of 1s
PartitionPartition: A defined section of a storage device.
PassphrasePassphrase: A longer password made of words.
PasswordPassword: A secret word or phrase used to log in.
PatchPatch: A small change applied to software.
PathPath: a plain definition and further detail
Path claimPath claim: A recorded reservation of specific files or directories in a shared Git checkout so concurrent contributors do not overwrite each other.
PayloadPayload: The actual useful user or application data carried inside a network packet, frame, or file container, separate from headers and check bits.
PBKDF2 (Password-Based Key Derivation Function 2)PBKDF2: Older CPU-iterative key-derivation function (RFC 8018) now superseded by memory-hard Argon2id.
PCAP (Projected Capacitive Touch)PCAP: Multi-touch capacitive screen technology sensing finger capacitance through glass.
PCB - Printed Circuit BoardPCB: A board that holds and connects electronic components.
PCI - Peripheral Component InterconnectPCI: An older standard bus for expansion cards.
PCI-SIG (PCI Special Interest Group)PCI-SIG: Industry consortium maintaining the PCI Express (PCIe) specification.
PCIe - Peripheral Component Interconnect ExpressPCIe: The modern high-speed expansion link.
PCR (Platform Configuration Register)PCR: Tamper-evident TPM register storing cryptographic measurements of boot stages.
PCS (Post-Compromise Security)PCS: Property where a messaging session heals and regains secrecy after a temporary key leak.
PDF (Portable Document Format)PDF: Fixed-layout document format (ISO 32000) preserving fonts, pages, and vector graphics.
PDP (Policy Decision Point)PDP: Access-control component that evaluates authorization policies and returns permit or deny.
PEM (Privacy-Enhanced Mail format)PEM: Base64 text encoding with -----BEGIN ...----- headers for certificates and cryptographic keys.
PFC (Power Factor Correction)PFC: Power-supply stage shaping AC input current into a smooth sine wave in phase with voltage.
PhotonPhoton: A photon is a tiny packet of light energy.
PID - Process IdentifierPID: learning reference and next steps
PIE (Position-Independent Executable)PIE: Compiled executable whose machine code can load at any random virtual address for ASLR.
PinPin: To fix software to an exact version.
PingPing: A tool that tests whether a host responds.
PipePipe: A connection that sends one program's output into another's input.
PipeWirePipeWire: The modern Linux multimedia server that routes audio and video streams between applications and hardware.
Pixel (picture element)Pixel: One small dot in a digital image.
Pixel formatA description of how an image stores its samples.
PKCE (Proof Key for Code Exchange)PKCE: OAuth 2.0 / OIDC extension preventing authorization-code interception attacks.
PKCS (Public-Key Cryptography Standards)PKCS: Series of foundational standards (such as PKCS#1 RSA, PKCS#8 keys, PKCS#11 tokens).
PKE (Public-Key Encryption)PKE: Asymmetric encryption where a public key encrypts messages and only the matching private key decrypts.
PKGBUILDPKGBUILD: Bash build recipe script used by Arch Linux makepkg to compile and package software.
Planar pixel formatAn image layout that stores components in separate regions of memory.
PLL (Phase-Locked Loop)PLL: Feedback circuit synchronizing an oscillator's frequency and phase to a reference clock.
PluginPlugin: A modular extension that adds a widget, status readout, or capability to a host application without modifying its core code.
PNG - Portable Network GraphicsPNG: A common lossless image file format.
Pointer accelerationPointer acceleration: A setting that scales how far the on-screen cursor travels based on how fast you move your mouse or finger.
Polkit (PolicyKit)Polkit: A framework for authorizing privileged desktop actions.
POODLE (Padding Oracle On Downgraded Legacy Encryption)POODLE: 2014 padding-oracle attack against SSL 3.0 CBC mode.
PortPort: A numbered endpoint for network communication.
POSIX - Portable Operating System InterfacePOSIX: The standard that defines Unix-like interfaces.
Post-quantum cryptographyPost-quantum cryptography: Classical algorithms designed to resist attacks by both ordinary and quantum computers.
PostgreSQLPostgreSQL: A client/server relational database with strong SQL, extensions and transactional reliability.
PPI - Pixels Per InchPPI: Pixels per inch, a measure of screen density.
PPT (Probabilistic Polynomial-Time)PPT: Standard theoretical model of an efficient attacker with polynomial runtime and random coins.
PrecisionHow many digits a number format carries, distinct from how accurate the value is.
Prefix keyPrefix key: A key combination pressed first to tell a program that the very next keystroke is a command rather than ordinary input.
PRF (Pseudorandom Function)PRF: Keyed deterministic function whose outputs are indistinguishable from a truly random function.
Primary keyPrimary key: a column or set of columns that uniquely identifies each row in a table.
PRIME (Linux GPU Buffer Sharing)PRIME: Linux DRM/DMA-BUF mechanism for sharing rendered frames between an iGPU and dGPU.
PrivilegePrivilege: Special permission to do something restricted.
ProcessProcess: learning reference and next steps
Procfs (process filesystem)Procfs: A virtual filesystem that exposes process and kernel information.
ProfileProfile: A named set of installed software and links.
ProgramProgram: a plain definition and further detail
PromisePromise: An object that stands for a result that will arrive later.
PromptPrompt: a plain definition and further detail
ProportionalProportional: A font whose characters have different widths.
ProtocolProtocol: An agreed set of rules for communication.
ProvenanceProvenance: The documented origin and authorship history of a change, build, or AI-assisted contribution.
PSI (Pressure Stall Information)PSI: Linux kernel metrics (/proc/pressure/*) measuring time tasks spend waiting for CPU, memory, or I/O.
PSK (Pre-Shared Key)PSK: Secret key shared out-of-band before communication, used in Wi-Fi WPA2/3 and TLS 1.3 resumption.
PTY (Pseudoterminal)PTY: Kernel pair of virtual character devices connecting a terminal emulator to a shell or program.
Pull requestPull request: A request to merge changes into another branch.
Pulse-code modulation (PCM)A digital representation made of one numeric code per sample at a fixed rate.
PVC (Polyvinyl Chloride)PVC: Common flexible plastic insulation jacket used on standard electrical and network cables.
PWM - Pulse-Width ModulationPWM: Rapid switching used to control average power.
