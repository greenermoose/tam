Guide / Glossary A–Z / Terms beginning with P / Proportional figures

Proportional figures are digits that take different widths according to their shapes.

In many fonts the digit 1 is narrow and the digit 8 is wide. Numbers set that way look natural in a sentence, unlike a table where every digit gets the same box. They are the usual default in text fonts.

Proportional figures are enabled with the OpenType pnum feature; tabular figures use tnum. Proportional digits usually have lining height, matching capitals, but some fonts also offer oldstyle shapes with mixed heights.

The pnum and tnum tags select different glyphs or advances in the same font; lnum and onum independently choose lining or oldstyle shapes, so four combinations are possible. Spreadsheet-like layouts need tabular figures so decimal points stay aligned. Shapers apply these features per run, and mixing fonts with different numeral widths can still misalign columns.
