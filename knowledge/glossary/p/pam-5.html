PAM-5 (5-level Pulse-Amplitude Modulation)

PAM-5 is a five-level signaling method used in 1000BASE-T Gigabit Ethernet to carry data across standard copper twisted-pair cables.

Standard network cables have four pairs of wires inside, and Gigabit Ethernet needed a way to push 1,000 megabits per second through older office wiring without making the signal too fast for the cable to handle. PAM-5 solves this by using five voltage steps—two positive, zero, and two negative—on every wire pair at the same time. That extra variety lets the cable carry far more information per second while keeping the electrical speed gentle enough for everyday Ethernet cables.

Part of PAM modulation, PAM-5 is the physical-layer encoding behind 1000BASE-T Gigabit Ethernet over Cat 5e/Cat 6 twisted-pair cabling. Rather than sending in only one direction per pair like 100BASE-TX, 1000BASE-T sends and receives simultaneously on all four wire pairs using echo cancellation. Four of the five voltage levels carry data via trellis coding, while the fifth (0 V) is used for idle, framing, and error-correction redundancy.

If PAM-5 has five voltage levels, why doesn’t it encode more than 2 net data bits per symbol on each pair?

A 5-level symbol could hold slightly over 2.3 bits in theory, but 1000BASE-T reserves the extra state capacity for 4D trellis-coded modulation (forward error correction) and idle/control signaling, leaving 2 net data bits per symbol per pair.

Defined in IEEE 802.3ab (1000BASE-T), PAM-5 transmits symbols at 125 MBaud simultaneously across all four twisted pairs in full duplex using hybrid circuits and adaptive digital echo/NEXT/FEXT cancellers. Each pair steps across {-2, -1, 0, +1, +2} nominal voltage levels; an 8-state 4-dimensional Trellis-Coded Modulation (TCM) encoder maps 8 data bits plus 1 convolutional redundancy bit into four 5-level symbols per baud (250 Mbps net per pair, 1 Gbps aggregate). The coding gain (~6 dB) offsets the tighter level spacing over 100 m of Category 5/5e UTP cabling.
