Prefix key

A key combination pressed first to tell a program that the very next keystroke is a command rather than ordinary input.

A prefix key is like knocking before speaking: pressing it tells a program such as tmux or Emacs to treat your next keypress as a command instead of typing that letter.

For example, tmux uses a prefix key (default Ctrl + B) before window-splitting keys so those keys remain free for programs running inside the terminal.

Why do terminal multiplexers like tmux use a prefix key?

So single-key shortcuts for splitting panes or switching windows do not steal ordinary letters or Ctrl chords from the programs running inside the panes.

A prefix key transitions an input state machine into a one-shot command keymap; after dispatching the subsequent key (or timing out/canceling), input returns to the default pass-through state.
