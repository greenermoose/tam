Guide / Glossary A–Z / Terms beginning with P / Promise

A promise is a JavaScript object that represents a result which is not ready yet but will either succeed or fail later.

A promise is like a receipt for a parcel. You do not have the parcel now, but the receipt gives you a way to be told when it arrives.

A promise starts pending, then becomes fulfilled with a value or rejected with a reason. await pauses the surrounding async function until that happens; catch handles a rejection.

Does await pause the whole program?

No. It pauses only the async function that contains it. The event loop continues with other work and resumes that function when the promise settles.

Promise reactions are microtasks queued after the current script and before the next task. Promise combinators such as all, race and allSettled express different waiting rules. An unhandled rejection is reported by the runtime and should be caught at a boundary.
