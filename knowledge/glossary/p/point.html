Guide / Glossary A–Z / Terms beginning with P / point (pt)

A point is a traditional unit of type size, defined as one seventy-second of an inch.

When a document says 12 point it is describing the size of the font, roughly how tall the letters are designed to be. A larger point number means larger text, though two fonts at the same number can still look different.

In print, 72 points make one inch; CSS also defines 1pt as 1/72 inch, but screen layout usually uses pixels so text stays readable across display densities. Cap height and x-height explain why equally sized fonts look different. Printers historically used points to describe both type size and leading.

The traditional printer's point was redefined to about 0.353 mm so that 72 pt equals exactly one inch; the older value was about 0.376 mm. SFNT fonts convert point size to pixels per em using pointSize * dpi / 72, and FreeType scales font units by that value divided by units per em. CSS anchors absolute lengths to 96 CSS pixels per inch rather than physical inches.
