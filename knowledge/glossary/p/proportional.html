Proportional

A proportional font is a typeface in which each character takes up only as much horizontal width as its shape needs, rather than every character having the same fixed width.

Compare the letters “i” and “w” in a book or on a website: “i” is narrow and “w” is wide. Proportional fonts give each letter its natural breathing room, which makes paragraphs smooth and easy to read—just like printed books and newspapers. By contrast, fixed-width (monospace) fonts force every letter into the same size box, which is useful for lining up columns of code or numbers.

Desktop interfaces, documents, and web pages use proportional fonts (sans-serif or serif) for prose because variable character widths let words flow naturally and fit more text comfortably on a line. Terminals and code editors avoid proportional fonts because vertical alignment of indentation, tables, and ASCII art breaks when “i” and “m” have different widths.

Check: why do financial tables in a proportional font often misalign unless “tabular figures” are enabled?

Many proportional fonts give digits like 1 narrower advance widths than 8, so numbers in a column drift out of alignment. Tabular (lining) figures override this by giving all digits 0–9 an identical advance width.

In OpenType and TrueType fonts, each glyph defines an advance width and left sidebearing in the hmtx table, measured in font design units (typically 1000 or 2048 UPM). Beyond per-glyph advance widths, proportional text rendering relies on shaping engines (such as HarfBuzz) to apply GPOS pair-adjustment kerning (for pairs like “AV” or “To”) and GSUB ligatures or contextual alternates. Proportional fonts can still expose fixed-width numerals via the OpenType tnum (tabular figures) feature, contrasting with pnum (proportional figures).
