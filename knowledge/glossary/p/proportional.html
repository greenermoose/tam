Guide / Glossary A–Z / Terms beginning with P / Proportional

A proportional font is a typeface in which each character takes only as much horizontal width as its shape needs.

Compare the letters i and w in a book: i is narrow and w is wide. Proportional fonts give each letter its natural space, which makes paragraphs flow smoothly. By contrast, monospace fonts force every letter into the same box to align columns of code or numbers.

Documents, interfaces and web pages use proportional fonts for prose because variable widths let words pack comfortably. Terminals and code editors avoid them because indentation, tables and ASCII art break when i and m differ in width. Many proportional fonts still offer fixed-width tabular digits for columns.

Why do financial tables in a proportional font often misalign unless tabular figures are enabled?

Digits such as 1 and 8 can have different advances, so columns drift; tabular figures give all digits the same width.

Each glyph has an advance width and left side bearing in hmtx, measured in units per em, commonly 1000 or 2048. Shapers apply GPOS pair kerning for combinations such as AV and GSUB ligatures or contextual alternates. OpenType features tnum and pnum choose tabular or proportional numerals independently of the rest of the font.
