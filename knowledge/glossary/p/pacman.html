Guide / Glossary A–Z / Terms beginning with P / pacman

The native package manager of Arch Linux, used on Arch-based Tamlinux to install, query, and update rootstock software.

pacman is the software manager built into Arch Linux. On Tamlinux, pacman installs and updates the underlying Linux system and third-party applications from official repositories.

Read-only pacman queries such as pacman -Q (installed packages) and pacman -Qo (which package owns a file) require no privileges; installing or upgrading packages modifies the root filesystem and requires privilege.

Which pacman flag queries what is already installed without changing the system?

Uppercase -Q queries the local package database read-only and never modifies installed files.

pacman operates on compressed tar archives with .PKGINFO and .MTREE metadata, resolves dependency graphs against signed sync databases in /var/lib/pacman/sync/, and executes libalpm transactions with hook support.
