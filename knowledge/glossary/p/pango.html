Guide / Glossary A–Z / Terms beginning with P / Pango

Pango is a library that measures and lays out text so applications can draw paragraphs correctly.

When an application wraps a sentence onto several lines, something has to decide where each line ends. Pango does that job for many Linux applications, using the fonts available on the system and the rules of each language.

Pango uses Fontconfig to choose fonts, HarfBuzz to shape complex scripts, and FreeType or Cairo to rasterize glyphs. It handles line breaking, bidirectional text, attributes such as bold and underline, and mixed-font runs. GTK applications rely on it for labels and text entries.

Pango builds a layout from a context with a font map; items are split by script, direction, language and font, then shaped into runs with cluster mappings. It implements Unicode line breaking and the Bidirectional Algorithm, applies font variants and per-run fallback, and exposes results to Cairo or GTK render nodes. After a font change it invalidates layouts so shaping is redone.
