Payload

The actual useful user or application data carried inside a network packet, frame, or file container, separate from headers and check bits.

A payload is the real letter inside an envelope—distinct from the address, stamp, and tracking barcode written on the outside.

In networking and storage protocols, headers and checksums wrap the payload so the link knows where to deliver it and whether any bits were damaged along the way.

What is the difference between a frame's total size and its payload size?

The total size includes protocol headers, framing markers, and error-check trailers; the payload is only the useful data carried inside.

Protocol encapsulation nests upper-layer PDUs as the payload of lower-layer frames (e.g., HTTP inside TLS inside TCP inside IP inside Ethernet), bounded by the link's MTU minus cumulative header overhead.
