Guide / Glossary A–Z / Terms beginning with R / Row

A row is one complete entry in a database table.

If a table is a list of library books, one row is one book with its title, author and year.

SQL retrieves rows with SELECT. A primary key gives each row a stable identity.

A row corresponds to a tuple in the relational model. SQL rows may contain NULL, and a result set has no guaranteed order without ORDER BY.
