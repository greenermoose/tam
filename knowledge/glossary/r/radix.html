Guide / Glossary A-Z / Terms beginning with R / Radix (base)

The radix is how many different digit values a number system has.

We usually count with ten digits, from 0 to 9, so our radix is ten. Binary has two digits, 0 and 1, so its radix is two. The radix tells you when to carry to the next column.

In a positional system, each column is worth the radix times the column to its right. Decimal columns are 1, 10, 100; binary columns are 1, 2, 4, 8; hexadecimal columns are 1, 16, 256. The numeral 101010 in base 2 and 2a in base 16 both mean 42. Radix describes the written form, not a different quantity.

What is the largest single digit in base 8?

7. Digits run from 0 up to one less than the radix. Just as decimal stops at 9 before carrying, octal stops at 7 before carrying.

For radix b, a numeral's value is the sum over digits d_i of d_i times b^i. Fraction columns to the right of the point use negative powers: b^-1, b^-2 and so on. A rational number has a terminating expansion in base b only when the denominator's prime factors all divide b. That is why 1/2 terminates in both decimal and binary but 1/10 terminates only in decimal. Radix is also called base, though base is the more common word for prefixes such as 0x.
