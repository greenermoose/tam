Guide / Glossary A–Z / Terms beginning with R / RADV (AMD Radeon Vulkan Mesa Driver)

The open-source userspace Vulkan graphics driver for AMD Radeon GPUs, developed as part of the Mesa project.

When a game or 3D app draws graphics on an AMD video card, it speaks a graphics language called Vulkan. RADV is the open-source translator on Linux that turns those Vulkan requests into instructions your AMD graphics card can run, without needing proprietary drivers.

RADV runs in userspace as a Mesa Vulkan ICD (Installable Client Driver) and pairs with the Linux kernel’s amdgpu DRM driver for memory management and command submission. You can confirm it is active with vulkaninfo --summary, and it uses the ACO shader compiler by default for fast shader compilation and smooth frame pacing.

Why does RADV still need the kernel amdgpu driver if RADV implements Vulkan in userspace?

User space drivers cannot safely manage GPU page tables, allocate shared VRAM/GTT buffers, or submit hardware ring commands directly; the kernel amdgpu DRM driver arbitrates hardware access and process isolation.

RADV (libvulkan_radeon.so) targets AMD GCN and RDNA GPUs, lowering SPIR-V through NIR into ACO (an SSA-based, register-pressure-aware compiler) or LLVM to emit AMDGPU ISA. Key technical details include graphics-pipeline-library (GPL) compilation vs. fossilize shader caches to curb stutter, DRM syncobj timeline semaphores for explicit synchronization under Wayland, and AMD_VULKAN_ICD/RADV_PERFTEST overrides when coexisting with AMDVLK.
