Guide / Glossary A–Z / Terms beginning with R / RNG (Random Number Generator)

A hardware circuit or software algorithm that produces numbers that appear unpredictable or statistically uniform.

Computers are built to follow exact rules, which makes it surprisingly hard for them to invent a truly unpredictable number. A random number generator solves this—either by measuring tiny, chaotic physical events inside the chip (like electronic noise) or by running math formulas that scramble a starting value so the output looks like coin flips or dice rolls.

In practice, RNGs split into two distinct uses: statistical simulation (games, Monte Carlo sampling, reproducible tests) and security (encryption keys, session tokens, nonces). Simulations often use fast non-cryptographic PRNGs seeded deterministically so runs can be repeated, whereas Linux security tools read from kernel entropy sources via getrandom(2) or /dev/urandom, which run a cryptographically secure PRNG (CSPRNG) seeded by hardware timing and noise.

Why should you never use a standard simulation PRNG (like rand() or Mersenne Twister) to generate SSH keys or session tokens?

Non-cryptographic PRNGs aim for statistical distribution and speed, not secrecy. Observing a small sequence of outputs lets an attacker reconstruct the internal state and predict every past and future number.

True random number generators (TRNGs) harvest physical entropy—such as ring-oscillator phase jitter, thermal noise, or interrupt timing—which must pass continuous health tests (for example, NIST SP 800-90B repetition-count and adaptive-proportion checks) before conditioning. In the Linux kernel, entropy feeds a BLAKE2s-based pool that seeds per-CPU ChaCha20 CSPRNGs; once initialized after boot, /dev/urandom and getrandom(2) never block and provide backtracking resistance via periodic reseeding. Hardware instructions like x86 RDRAND (DRBG) and RDSEED (entropy source) accelerate seeding, though kernels mix them with independent timing jitter rather than trusting a single silicon source.
