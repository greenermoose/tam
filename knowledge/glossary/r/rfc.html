RFC (Request for Comments)

Numbered technical document series published by the IETF and partner streams to specify internet protocols and practices.

An RFC is a numbered, free-to-read technical document that defines how an internet rule or protocol works so software written by different people can work together.

Despite the historical name "Request for Comments," published RFCs are never edited after release; changes happen by publishing a newer RFC that updates or obsoletes the older one. Most protocol RFCs come from the IETF. See The IETF and how RFCs work.

Archival publication series managed under RFC 9280 across four streams (IETF, IAB, IRTF, Independent). Each RFC carries an immutable number and a status category—Standards Track (Proposed Standard or Internet Standard), Best Current Practice (BCP), Informational, Experimental, or Historic—with forward/backward Updates and Obsoletes links. See The IETF and how RFCs work.
