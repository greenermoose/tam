Root directory

The top-most directory in a filesystem tree, written as /, from which every other file and folder descends.

Think of all the folders on a Linux computer as an upside-down family tree. At the very top sits one single starting folder called the root directory, written simply as a forward slash (/). Every document, app, and USB drive you open lives somewhere underneath that single top folder.

Unlike Windows, which gives each drive its own letter (C:\, D:\), Linux places everything under a single root directory / and attaches extra drives or partitions at subdirectories called mount points (such as /home or /mnt/usb). Do not confuse the root directory (/) with the root user’s home directory (/root).

What is the difference between / and /root on a Linux system?

/ is the root directory at the top of the entire filesystem hierarchy, whereas /root is a subdirectory inside it that serves as the personal home directory for the administrative root account.

In POSIX and the Linux Virtual File System (VFS), a filesystem’s root directory is the base directory inode of a mounted superblock, while the system root / is the fs_struct.root dentry/vfsmount pair inherited by processes. Path resolution starting with / anchors lookup at the calling process’s current root rather than the global namespace root—a mechanism leveraged by chroot(2), pivot_root(2), and mount namespaces (CLONE_NEWNS) to isolate containers with distinct root trees while sharing a single kernel.
