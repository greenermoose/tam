Guide / Glossary A–Z / Terms beginning with R

Glossary definitions for technical terms and acronyms beginning with R.

Explore

Radix (base)The number of digit values a positional number system uses.
RADV (AMD Radeon Vulkan Mesa Driver)RADV: Open-source userspace Vulkan graphics driver for AMD GPUs in Mesa.
RAID - Redundant Array of Independent DisksRAID: Combining disks for speed, capacity, or redundancy.
RAM - Random-Access MemoryRAM: Fast working memory that loses its contents when power is off.
RAN (Radio Access Network)RAN (Radio Access Network): the part of a mobile network that talks to phones over radio and manages handover.
RAPL (Running Average Power Limit)RAPL: Intel/AMD CPU hardware counters and power-capping interface exposed by Linux powercap.
Raster graphicsRaster graphics: Images made of a grid of pixels.
RasterizationRasterization: a plain definition and further detail
Raw modeRaw mode: Terminal input mode that sends every keystroke immediately to the program without kernel line editing.
RBAC (Role-Based Access Control)RBAC: Access-control model assigning permissions to named roles rather than individual users.
RBR (Reduced Bit Rate)RBR: DisplayPort 1.62 Gbps per-lane link rate.
RC4 (Rivest Cipher 4)RC4: Obsolete stream cipher with severe statistical biases, banned from TLS and WEP.
RCS (Rich Communication Services)RCS (Rich Communication Services): a carrier chat service over IMS with capability discovery, group chat, file transfer and rich content.
RCS Universal ProfileRCS Universal Profile: the GSMA feature baseline that lets different carriers and clients offer interoperable RCS services.
ReadlineReadline: A library for editable command-line input.
RedirectionRedirection: Changing where a command's input or output goes.
Refresh rateRefresh rate: How many times per second a display redraws.
RegisterRegister: A tiny, very fast storage location inside a processor.
Regular expressionRegular expression: A compact pattern for matching text.
REISUB (Magic SysRq emergency reboot)REISUB: Safe 6-key kernel Magic SysRq sequence to sync disks and reboot a frozen Linux system.
REPL (Read-Eval-Print Loop)REPL: Interactive prompt that reads an expression, evaluates it, prints the result, and repeats.
ReplicationReplication: keeping copies of the same data on more than one database node.
RepositoryRepository: A organized store of software or version history.
Rescue environmentRescue environment: A working tool environment for repairing another system.
ResolutionResolution: The number of pixels in an image or display.
REST (Representational State Transfer)REST: A style for web APIs that names resources with URLs and uses HTTP methods to act on them.
RetirementRetirement: Removing a temporary patch once it is no longer needed.
Retrieval practiceRetrieval practice: A learning technique where you actively recall an answer from memory before checking the solution.
RF - Radio FrequencyRF: Radio-frequency signals used for wireless communication.
RFC (Request for Comments)RFC: Numbered technical document series published by the IETF and partner streams to specify internet protocols and practices.
RFC 5280 (X.509 PKI Profile)RFC 5280: IETF standard profiling X.509 v3 certificates and revocation lists.
RFC 5869 (HKDF)RFC 5869: IETF specification for HMAC-based Extract-and-Expand Key Derivation Function.
RFC 9106 (Argon2)RFC 9106: IETF specification for the Argon2 memory-hard password-hashing function.
RFID (Radio-Frequency Identification)RFID: Wireless identification using electromagnetic fields to power and read passive or active tags.
RGB - Red, Green, BlueRGB: A color model built from red, green, and blue.
RIP (Instruction Pointer Register)RIP: 64-bit x86_64 CPU register holding the memory address of the next instruction to execute.
RISC - Reduced Instruction Set ComputingRISC: A processor design style with simple, regular instructions.
RISC-V - Reduced Instruction Set Computing VRISC-V: An open processor instruction set.
RLL (Run-Length Limited)RLL: Line coding bounding the minimum and maximum number of identical bits between transitions.
RNG (Random Number Generator)RNG: Hardware or software source producing unpredictable or statistical random numbers.
ROB (Reorder Buffer)ROB: CPU hardware queue that lets instructions execute out of order while committing results in program order.
ROBOT (Return Of Bleichenbacher's Oracle Threat)ROBOT: Padding-oracle attack against RSA PKCS#1 v1.5 encryption in TLS.
RollbackRollback: learning reference and next steps
Rollback pointRollback point: A known-good state you can return to.
ROM - Read-Only MemoryROM: Memory that keeps its contents without power.
Root directoryRoot directory: The top of a filesystem's directory tree.
Root filesystemRoot filesystem: The filesystem mounted at the top of the system tree.
Root userRoot user: The all-powerful administrative account.
RootstockRootstock: the base operating system installed on a host beneath the Tamlinux scion
RoundingChoosing the nearest representable value when a number does not fit exactly.
RouterRouter: A device that forwards packets between networks.
RowRow: one record in a table, made of values for each column.
RPKI (Resource Public Key Infrastructure)RPKI: Cryptographic framework verifying which autonomous systems may announce IP address prefixes over BGP.
RPM (RPM Package Manager)RPM: Binary package format (.rpm) and tool used by Fedora, RHEL, and openSUSE.
RS-232 (Recommended Standard 232)RS-232: Classic single-ended serial port standard (+/-3 V to +/-15 V) used for consoles and modems.
RS-485 (TIA-485)RS-485: Differential multi-drop serial bus supporting long cables (up to 1200 m) and noisy environments.
RS256 (RSA PKCS#1 v1.5 with SHA-256)RS256: JWS/JWT algorithm identifier for asymmetric RSA signatures using SHA-256.
RSARSA: A classic public-key cryptosystem based on the difficulty of factoring large integers.
RSA-3072RSA-3072: RSA public-key cryptography using a 3072-bit modulus (~128-bit classical security).
RSA-OAEP (Optimal Asymmetric Encryption Padding)RSA-OAEP: Randomized, IND-CCA2-secure padding scheme for RSA encryption (RFC 8017).
RSA-PSS (Probabilistic Signature Scheme)RSA-PSS: Modern randomized RSA signature padding with tight security proof (RFC 8017).
RSS (Resident Set Size)RSS: Amount of physical RAM currently held by a process (excluding swapped-out pages).
RSSI (Received Signal Strength Indicator)RSSI: Measurement of incoming radio signal power (typically in dBm for Wi-Fi).
RTT (Round-Trip Time)RTT (Round-Trip Time): The elapsed time for a network signal or packet to travel from a sender to a destination and for the reply to return.
RunlevelRunlevel: A traditional numbered system state.
