Guide / Glossary A–Z / Terms beginning with R / RCS Universal Profile

RCS Universal Profile: the GSMA feature baseline that lets different carriers and clients offer interoperable RCS services.

The RCS Universal Profile is a common list of features that carriers and phone makers agree to support. It helps rich chat work across different networks.

UP 4.0, published in 2026, carries the value UP_4.0. A profile feature is only useful for a conversation when both sides support it.

GSMA RCC.71 defines the profile; RCC.07 defines client behaviour. UP 4.0 includes end-to-end encryption requirements for person-to-person content, but rollout depends on carriers, clients and regulation.
