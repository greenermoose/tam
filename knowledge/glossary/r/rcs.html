Guide / Glossary A–Z / Terms beginning with R / RCS (Rich Communication Services)

RCS (Rich Communication Services): a carrier chat service over IMS with capability discovery, group chat, file transfer and rich content.

RCS is a newer messaging service from mobile carriers. It can show when someone is typing, deliver read reports, and carry pictures or groups in a way that feels like a chat app.

Before a rich chat starts, the service checks which features both phones support. If they cannot both use RCS, the conversation may fall back to an ordinary short or multimedia message.

RCS clients follow GSMA RCC.07; interoperable features are collected in the Universal Profile, UP 4.0 in 2026. RCC.16 defines end-to-end encryption for person-to-person conversations using MLS; chatbot conversations and SMS fallback are outside that scope.
