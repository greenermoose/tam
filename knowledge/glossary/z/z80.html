Z80 (Zilog Z80)

An influential 1976 8-bit microprocessor that powered early personal computers, arcade cabinets, and decades of embedded systems.

In the late 1970s and 1980s, before modern multi-gigabyte PCs existed, the Z80 was one of the most popular brains inside home computers, video game consoles, and calculators. Its simple design was cheap to build and easy to program directly, and derivatives of it are still used today inside small controllers and retro-computing projects.

The Z80 powered machines running CP/M (such as the Osborne 1 and Kaypro), the ZX Spectrum, the Sega Master System, and—via a close custom cousin—the original Nintendo Game Boy. Studying Z80 assembly or running an emulator shows how software worked when a CPU had only a few kilobytes of RAM, no memory protection, and an 8-bit data bus.

Why did CP/M software written for the older Intel 8080 usually run on a Z80 without modification?

Zilog designed the Z80 to be binary-compatible with Intel 8080 machine code, using the same core opcodes while adding extra instructions and registers on top.

An 8-bit CISC processor running on a single +5 V supply with built-in DRAM refresh circuitry, the Z80 features an 8-bit data bus, a 16-bit address bus (64 KiB directly addressable, often bank-switched), and separate 16-bit I/O port addressing (IN/OUT). It extends the Intel 8080 ISA with a full duplicate shadow register bank (AF′, BC′, DE′, HL′ via EX/EXX for fast interrupt context switching), two 16-bit index registers (IX, IY), block-move/search instructions (LDIR, CPIR), bit-manipulation opcodes, and three maskable interrupt modes (IM 0/1/2) plus NMI.
