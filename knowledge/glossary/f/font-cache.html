Guide / Glossary A–Z / Terms beginning with F / Font cache

A font cache is a saved index of font files and their properties so programs need not rescan them each time.

Scanning every font on your computer each time an app starts would be slow. The system keeps a small index instead, like a library catalogue, and refreshes it when fonts change.

Fontconfig stores per-directory cache files under /var/cache/fontconfig for system fonts and ~/.cache/fontconfig for user fonts. Running fc-cache rebuilds them after installing or removing font files. A stale cache is a common reason a newly copied font does not appear in applications until the cache is refreshed.

Each cache entry records file metadata, face properties, language coverage and a charset bitmap for fast Unicode coverage tests. Fontconfig validates caches against directory timestamps and font file version numbers, and package hooks or timers usually refresh them. Caches are versioned and per-architecture; corrupt caches can be removed safely and rebuilt with fc-cache.
