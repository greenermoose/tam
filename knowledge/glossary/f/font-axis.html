Guide / Glossary A–Z / Terms beginning with F / Font axis

A font axis is a named, continuous setting in a variable font that changes the design of its letters.

Instead of separate bold and regular files, a variable font can have a slider for boldness. Each slider is an axis. Moving it changes the letters smoothly rather than switching to a completely different file.

Common registered axes are weight (wght), width (wdth), slant (slnt), italic (ital) and optical size (opsz). A font can also define custom axes, such as grade. Applications expose axes through controls like a weight slider; CSS uses font-variation-settings or higher-level properties such as font-weight.

Axes are declared in the fvar table with a tag, minimum, default and maximum value; avar can remap axis coordinates non-linearly. Along each axis, gvar stores TrueType glyph deltas and HVAR/VVAR store metric deltas, while CFF2 uses its own VarStore. Named instances give common presets; renderers clamp arbitrary coordinates to the declared range.
