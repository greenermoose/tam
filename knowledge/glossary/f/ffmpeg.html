Guide / Glossary A–Z / Terms beginning with F / FFmpeg

An open-source collection of programs and libraries for recording, converting, filtering, and streaming audio and video.

FFmpeg is a tool you can use to change media files. It can convert between formats, extract audio, resize video, or show what is inside a file.

The ffmpeg command builds a pipeline: it demuxes a container, decodes streams, applies filters, encodes, and muxes output. ffprobe inspects streams and metadata. You can copy streams to avoid re-encoding when you only need to change the container or metadata.

FFmpeg separates containers, codecs, and filter graphs. Practical media workflows involve timestamp/timebase handling, pixel/sample formats, color space/range, hardware acceleration, and codec trade-offs (quality, bitrate, latency, compatibility). Frequency-domain transforms such as FFT/DCT/MDCT appear in analysis and codec/filter internals.
