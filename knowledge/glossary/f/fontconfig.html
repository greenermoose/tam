Guide / Glossary A–Z / Terms beginning with F / Fontconfig

The Linux library and configuration system that discovers installed fonts and chooses the best match for applications.

You might have hundreds of fonts installed, and a program might ask for something general like 'a clean sans-serif font' or a specific name you do not have. Fontconfig is the behind-the-scenes librarian that scans font folders and picks the closest match—or a fallback—so text still appears.

Toolkits, browsers and terminals query Fontconfig rather than opening font files directly. fc-match shows which face resolves for a request, fc-list lists installed families and fc-cache rebuilds the cache. XML rules in /etc/fonts/conf.d/ and ~/.config/fontconfig/fonts.conf set generic aliases such as sans-serif and monospace, emoji preference and hinting.

If an application asks for a font that is not installed, why does text usually still render?

Fontconfig scores installed faces against the pattern and returns the closest match, with per-character fallback when the primary face lacks a code point.

Fontconfig implements a pattern-matching and property-rewriting pipeline (FcPattern, FcConfigSubstitute, FcFontSort) driven by prioritized XML rules numbered from 00 to 99. It serializes per-directory caches with charset bitmaps of covered code points and language coverage. Stale caches after manual file copies, rule-order conflicts and per-character fallback with mismatched metrics are common sources of surprising typography.
