Guide / Glossary A–Z / Terms beginning with F / Font face

A font face is one concrete style of a family, such as regular, bold italic or a particular weight.

A family such as Inter contains many faces: regular, bold, italic and so on. When a program says 'use the bold face' it means one particular member of that family, not the whole collection.

In CSS an @font-face rule declares where to fetch one face and which family, weight and style it belongs to; several rules can build a family from separate files. On Linux, Fontconfig matches a requested family plus weight and slant against installed faces and returns a file path. A variable font can supply many faces from one file by changing its axes.

OpenType does not store one family per face: name IDs 1, 2, 4, 6 and 16/17 carry family, subfamily, full, PostScript and typographic names, which can disagree. Fontconfig normalizes these into pattern properties before choosing a file. CSS font matching picks the closest face by weight and stretch, then the shaper applies its GSUB/GPOS features; a mismatch between declared and actual weight can trigger synthetic bolding.
