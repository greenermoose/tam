Guide / Glossary A–Z / Terms beginning with F / Font style

Font style describes whether a face is upright, italic or slanted, and is part of how applications select a font.

Fonts usually come in a normal version and an italic one. Italic letters lean and often have different shapes, not just a tilt. When you click the italic button in a document you are choosing a different font style.

CSS separates font-style (normal, italic, oblique with an optional angle) from font-weight (boldness) and font-stretch (width). True italics are drawn by the designer; obliques are slanted versions of the upright design. Fontconfig uses slant in its matching patterns, so requesting italic can resolve to an oblique face if no true italic exists.

OpenType records weight in OS/2.usWeightClass and slope in post.italicAngle, with italic flags in head.macStyle and OS/2.fsSelection. Variable fonts use the ital axis for a designed italic and the slnt axis for shear. Synthetic slanting does not redraw letter shapes and looks poor for calligraphic faces; bold and italic can also be combined in a single face.
