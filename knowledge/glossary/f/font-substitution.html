Guide / Glossary A–Z / Terms beginning with F / Font substitution

Font substitution is what happens when a program asks for a font that is not installed and another one is used instead.

If a document asks for a font you do not have, the text still appears because the system picks a similar font. That swap is substitution. It is why a document can look slightly different on another computer, even though the words are unchanged.

Fontconfig compares the requested family, weight and slant against installed faces and returns the best match; per-character fallback can also supply glyphs the chosen face lacks. Substitution is not the same as renaming a font: the document still asks for the original name. On Linux, fc-match shows which face would be chosen for a given request.

Fontconfig applies FcConfigSubstitute with config rules (alias, prefer, accept, reject) and then FcFontSort, which scores candidates by weighted pattern properties. Strong bindings override a requested property; weak bindings only bias it, and language and charset coverage influence per-glyph fallback. Substitution can mix faces with different metrics or baselines, so shaping must rerun per run rather than across a font boundary.
