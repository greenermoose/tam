Guide / Glossary A–Z / Terms beginning with F / Font

A digital collection of character shapes and spacing rules used to display text on screen or in print.

A font is the visual design of letters, numbers and symbols—like the difference between neat printed handwriting and bold block letters. Your computer uses font files to know what each character should look like and how much space to leave around it when drawing text in a document or terminal.

On Linux, fonts are usually scalable outline files such as TrueType (.ttf) or OpenType (.otf), installed under /usr/share/fonts for all users or /home/alex/.local/share/fonts for one account. Outline fonts store curves so the same file renders at any size; monospace fonts give every character the same width so columns align. A family groups related styles, and variable fonts can supply several faces from one file.

Why do terminals and code editors strongly prefer monospace fonts over proportional fonts?

Uniform advance widths keep characters in vertical columns, so indentation, tables and cursor positions stay predictable.

A font file maps code points to glyph IDs through cmap, stores contours in glyf (quadratic Béziers) or CFF/CFF2 (cubic Béziers), and holds advances in hmtx. Complex scripts use OpenType layout tables—GSUB for substitution and GPOS for positioning—applied by a shaper such as HarfBuzz before FreeType rasterizes with hinting and antialiasing. Variable fonts interpolate axes declared in fvar.
