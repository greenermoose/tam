Guide / Glossary A–Z / Terms beginning with F / Fleet

A set of machines maintained together under shared Tamlinux conventions and synchronized repository state.

A fleet is a group of computers—such as a desktop workstation and one or more laptops—maintained together so they stay consistent and easy to move between.

On Tamlinux, fleet tooling checks host status and keeps shared repository branches synchronized across machines without leaking host-specific hardware settings into public repos.

What should stay host-local in a multi-machine fleet?

Machine-specific hardware settings, local network subnets, and host-local pin commits stay on that host rather than being published to shared public branches.

Fleet management distinguishes shared cultivar source revisions (identical across hosts) from per-host runtime state, manifest digests, and rollback baselines recorded independently per hostname.
