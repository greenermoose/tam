Filter

A filter selects or changes the text it receives.

Novice definition

A command that selects or changes text it reads.

Learner definition

A pipeline stage that transforms or selects input, such as grep or sort.

Expert definition

A stream transformation with its own buffering, exit status and data/diagnostic channels; composition must account for all three.
