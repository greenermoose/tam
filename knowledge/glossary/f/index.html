Guide / Glossary A–Z / Terms beginning with F

Glossary definitions for technical terms and acronyms beginning with F.

Explore

Factoring algorithmAn algorithm that finds integer factors of a number, especially the prime factors of a composite integer.
Fallback routeFallback route: A startup path that avoids a failed component.
Fast Fourier Transform (FFT)An efficient algorithm for computing the Discrete Fourier Transform, typically in O(N log N) time.
FCM (Firebase Cloud Messaging)FCM (Firebase Cloud Messaging): Google's service for delivering small notifications and data messages to Android and other clients.
FEC (Forward Error Correction)FEC: Extra data that lets a receiver correct errors without retransmission.
FetchFetch: To retrieve an instruction or data.
FF (Form Feed, 0x0C)FF: ASCII 0x0C control character (Ctrl+L) used to clear the screen or advance a printer page.
FFmpegAn open-source collection of programs and libraries for recording, converting, filtering, and streaming audio and video.
Fiber OpticFiber Optic: a transmission medium that guides pulses of light through transparent glass or plastic fibers
FIDL (Fuchsia Interface Definition Language)FIDL: Strongly typed IPC schema language used by the Fuchsia Zircon microkernel.
FIDO (Fast Identity Online)FIDO: A standard for phishing-resistant authentication.
FIFO (First-In, First-Out)FIFO: A first-in, first-out queue.
FileFile: a plain definition and further detail
File descriptorFile descriptor: A small number that identifies an open file or stream.
File extensionFile extension: The suffix that hints at a file's format.
FilesystemFilesystem: a plain definition and further detail
Filesystem hierarchy (FHS)Filesystem hierarchy (FHS): The standard layout of Linux directories.
FilterFilter: learning reference and next steps
FingerprintFingerprint: A short value that identifies a key or person.
FIPS (Federal Information Processing Standards)FIPS (Federal Information Processing Standards): Public cryptographic and computing standards published by NIST, such as FIPS 197 (AES), FIPS 203 (ML-KEM), and FIPS 204 (ML-DSA).
FirewallFirewall: Software or hardware that filters network traffic.
FirmwareFirmware: Software stored on a device that controls it at a low level.
Fixed-pointA number format with an agreed, unchanging number of fractional bits.
FlagFlag: An option that is either on or off.
FleetFleet: A set of machines maintained together under shared Tamlinux conventions and synchronized repository state.
FLIT (Flow Control Unit)FLIT: Fixed-size packet unit used in modern high-speed interconnects (PCIe 6.0, CXL, NoCs).
Floating-pointA number format whose point can move by storing a significand and an exponent.
FLOTOX (FLOating-gate Tunnel OXide)FLOTOX: A floating-gate EEPROM cell that stores charge through a thin tunnel oxide.
Flow ControlFlow Control: a mechanism preventing a fast sender from overrunning a slow receiver with data
Focus (keyboard)Keyboard focus: learning reference and next steps
FoldFold: An interactive collapsible block in the tam pager used for quiz answers, hints, solutions, and first-time notes.
FontFont: A collection of character shapes and metrics.
Font familyFont family: A named group of matching font styles (regular, bold, italic) that share the same visual design.
FontconfigFontconfig: The Linux library that finds and configures fonts.
footfoot: A fast, lightweight Wayland-native terminal emulator used as the default terminal on Tamlinux.
Foreign keyForeign key: a column whose values must match a key in another table.
ForkFork: A personal copy of someone else's repository.
FORS (Forest of Random Subsets)FORS: Few-time hash-based signature scheme used inside SPHINCS+ / SLH-DSA.
Forward secrecyForward secrecy: A property ensuring that stealing a long-term key later cannot decrypt past recorded traffic.
Fourier transformA mathematical transform that represents a signal as a combination of frequencies.
FramebufferFramebuffer: a plain definition and further detail
FrameworkFramework: A reusable structure that calls your code at defined points in an application's life.
FramingFraming: Wrapping data in a structure with boundaries.
FREAK (Factoring RSA Export Keys)FREAK: 2015 TLS downgrade attack forcing servers and clients onto weak 512-bit export RSA.
FruitFruit: learning reference and next steps
FTDI (Future Technology Devices International)FTDI: Widely used maker of USB-to-UART/serial bridge chips (such as FT232R).
Full DuplexFull Duplex: a communication channel that supports simultaneous transmission in both directions
FUSE (Filesystem in Userspace)FUSE: Linux kernel module allowing unprivileged programs to implement custom filesystems in userspace.
Fused multiply-add (FMA)One operation that multiplies, adds and rounds only once.
