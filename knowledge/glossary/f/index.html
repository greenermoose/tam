Terms beginning with F

Glossary definitions for technical terms and acronyms beginning with F.

Explore

  • Fallback route — Fallback route: A startup path that avoids a failed component.
  • FEC - Forward Error Correction — FEC: Extra data that lets a receiver correct errors without retransmission.
  • Fetch — Fetch: To retrieve an instruction or data.
  • FF (Form Feed, 0x0C) — FF: ASCII 0x0C control character (Ctrl+L) used to clear the screen or advance a printer page.
  • Fiber Optic — Fiber Optic: a transmission medium that guides pulses of light through transparent glass or plastic fibers
  • FIDL (Fuchsia Interface Definition Language) — FIDL: Strongly typed IPC schema language used by the Fuchsia Zircon microkernel.
  • FIDO - Fast Identity Online — FIDO: A standard for phishing-resistant authentication.
  • FIFO - First-In, First-Out — FIFO: A first-in, first-out queue.
  • File — File: a plain definition and further detail
  • File descriptor — File descriptor: A small number that identifies an open file or stream.
  • File extension — File extension: The suffix that hints at a file's format.
  • Filesystem — Filesystem: a plain definition and further detail
  • Filesystem hierarchy (FHS) — Filesystem hierarchy (FHS): The standard layout of Linux directories.
  • Filter — Filter: learning reference and next steps
  • Fingerprint — Fingerprint: A short value that identifies a key or person.
  • Firewall — Firewall: Software or hardware that filters network traffic.
  • Firmware — Firmware: Software stored on a device that controls it at a low level.
  • Flag — Flag: An option that is either on or off.
  • FLIT (Flow Control Unit) — FLIT: Fixed-size packet unit used in modern high-speed interconnects (PCIe 6.0, CXL, NoCs).
  • Flow Control — Flow Control: a mechanism preventing a fast sender from overrunning a slow receiver with data
  • Focus (keyboard) — Keyboard focus: learning reference and next steps
  • Font — Font: A collection of character shapes and metrics.
  • Fontconfig — Fontconfig: The Linux library that finds and configures fonts.
  • Fork — Fork: A personal copy of someone else's repository.
  • FORS (Forest of Random Subsets) — FORS: Few-time hash-based signature scheme used inside SPHINCS+ / SLH-DSA.
  • Forward secrecy — Forward secrecy: A property ensuring that stealing a long-term key later cannot decrypt past recorded traffic.
  • Framebuffer — Framebuffer: a plain definition and further detail
  • Framing — Framing: Wrapping data in a structure with boundaries.
  • FREAK (Factoring RSA Export Keys) — FREAK: 2015 TLS downgrade attack forcing servers and clients onto weak 512-bit export RSA.
  • Fruit — Fruit: learning reference and next steps
  • FTDI (Future Technology Devices International) — FTDI: Widely used maker of USB-to-UART/serial bridge chips (such as FT232R).
  • Full Duplex — Full Duplex: a communication channel that supports simultaneous transmission in both directions
  • FUSE (Filesystem in Userspace) — FUSE: Linux kernel module allowing unprivileged programs to implement custom filesystems in userspace.
