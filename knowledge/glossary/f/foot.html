Guide / Glossary A–Z / Terms beginning with F / foot

A fast, lightweight Wayland-native terminal emulator used as the default terminal on Tamlinux.

foot is the default terminal window program on Tamlinux. It is built specifically for modern Wayland desktops so it opens quickly and uses very little memory.

foot reads its appearance and keybinding settings from ~/.config/foot/foot.ini (with Tamlinux theme colors applied by tam-theme-set-foot) and advertises TERM=foot.

Why is foot well suited to a keyboard-first Wayland workstation?

It runs natively on Wayland without XWayland, starts almost instantly, and supports modern keyboard protocols and server/client mode with minimal resource usage.

foot is written in C using Wayland protocols directly (wl_shm, xdg-shell, text-input-v3), supports Kitty keyboard protocol and OSC escape sequences, and uses its own terminfo entry (foot / foot-extra).
