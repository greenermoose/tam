Guide / Glossary A–Z / Terms beginning with F / Forward secrecy

A security property ensuring that stealing a long-term key later cannot decrypt traffic that was recorded in the past.

Imagine someone records all your encrypted phone calls today, hoping to break into your house next year and steal your master key to unlock them. Forward secrecy stops that: every single call invents a brand-new temporary key, uses it once, and throws it away when you hang up—so stealing the master key later only affects future impersonation, not yesterday’s secrets.

Modern protocols like TLS 1.3 and SSH achieve forward secrecy by running an ephemeral Diffie-Hellman key exchange (such as ECDHE with X25519) for each connection, using long-term keys only to authenticate the handshake—never to encrypt the session key directly. Older TLS RSA key-transport cipher suites lacked forward secrecy because the client encrypted the premaster secret with the server’s static RSA public key, meaning a later compromise of that private key unlocked all past captures.

If an attacker records your TLS 1.3 traffic today and steals the server’s private certificate key a year later, can they decrypt the recorded session?

No. In TLS 1.3, the server’s private key only signs the handshake for authentication; the actual session keys come from an ephemeral Diffie-Hellman exchange whose secret values were discarded once the session ended.

Forward secrecy (Perfect Forward Secrecy, PFS) requires that session traffic keys be derived solely from short-lived ephemeral key-exchange secrets (ECDHE, X25519, or post-quantum hybrid X25519MLKEM768) rather than static key encapsulation, and that ephemeral private scalars and key schedules be zeroized promptly on session teardown. Long-term identity keys (ECDSA, Ed25519, RSA-PSS) sign only the handshake transcript hash to prevent active MitM attacks. Subtle failure modes include unrotated session-ticket encryption keys (STEKS) in resumption—where a stolen ticket key decrypts past resumed sessions—and weak PRNG seeding producing predictable ephemeral nonces.
