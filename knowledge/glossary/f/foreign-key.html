Guide / Glossary A–Z / Terms beginning with F / Foreign key

A foreign key links a row in one table to a row in another table.

It is like writing the borrower number on a loan slip: the number must name a real borrower.

A foreign-key constraint prevents orphan links and can define what happens when the referenced row changes or is deleted.

Foreign keys enforce referential integrity inside the database. Cascades, deferred checks and circular references need careful design; some distributed stores omit them for scale.
