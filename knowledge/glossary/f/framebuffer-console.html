Guide / Glossary A–Z / Terms beginning with F / Framebuffer console

The framebuffer console is the kernel's full-screen text console, drawing directly into video memory.

When you switch to a text-only screen with Ctrl+Alt+F3, the framebuffer console is drawing those letters itself. It does not need a desktop environment or a graphical login to work, which makes it useful for recovery and early boot.

The framebuffer console uses a simple bitmap font to stamp character cells into the display framebuffer. Linux 6.12 ships 13 built-in fonts in lib/fonts/, selected at boot with fbcon=font: or chosen automatically from console size. Documented names include VGA8x8, VGA8x16, TER16x32 and ProFont6x11; a user font can be installed with setfont.

fbcon copies width, height, data and charcount from a font descriptor into the virtual console's vc_font; built-ins are used with userfont = 0. fbcon_set_font accepts user fonts of 256 or 512 glyphs through KDFONTOP, and fbcon_set_def_font restores a named built-in or calls get_default_font(xres, yres, blit_x, blit_y). CONFIG_FONT_SUPPORT gates the code and CONFIG_FONT_AUTOSELECT selects VGA8x16 when other fonts are disabled. KMScon is a separate userspace console.
