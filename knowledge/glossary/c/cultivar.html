Guide / Glossary A–Z / Terms beginning with C / Cultivar

In Tamlinux, a cultivar is each major + minor version of Tamlinux (for example, 0.6 or 0.7), named from tamarack tree varieties.

In horticulture, a cultivar is a cultivated variety of a plant selected and named for desirable traits. In Tamlinux, each major and minor release series—such as 0.4 (Incipiens), 0.5 (Blue Sparkler), and 0.6 (KBN WB)—is a cultivar. The Tamlinux software itself is the scion grafted onto a rootstock, and the cultivar names which release variety of that scion you are running.

Commands such as tam --version and tam inspect report the active Tamlinux cultivar name and version alongside individual component versions (like tam and its knowledge corpus). Patch releases within a cultivar (for example, 0.6.1, 0.6.2) refine that same cultivar rather than starting a new one.

What is the difference between a cultivar and the scion?

The scion is the Tamlinux software that installs on a rootstock; the cultivar is the named major + minor version of that Tamlinux release (such as 0.6 KBN WB).

Cultivar metadata identifies the deployed Tamlinux major + minor release series (e.g., KBN WB 0.6), whereas individual package and kernel versions report which upstream binaries and rootstock artifacts are present on disk. Separating cultivar identity from component versions lets users and tools reason about release milestones, reproducibility, and upgrade compatibility across rootstock transitions.
