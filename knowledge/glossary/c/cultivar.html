Cultivar

In Tamlinux, a cultivar is all the software in the Tamlinux release that allows the computer to be used effectively and efficiently by both humans and AI agents.

Think of grafting a fruit tree: the rootstock is the hardy trunk and roots, while the cultivar is the named variety grafted on top that produces the fruit you actually use. In Tamlinux, the rootstock is the kernel and core system software published by third parties, and the cultivar is the named workstation software built on top of it so everything works together smoothly. Tamlinux aims to keep the rootstock as small as possible while maximizing speed and efficiency.

The Tamlinux desktop and tool suite composed above the rootstock. Separating the cultivar from the rootstock lets the upper software suite stay consistent even when the underlying base changes: currently Tamlinux uses Arch Linux as its rootstock, with plans to migrate to Void Linux in future versions and to explore a microkernel later to shrink the rootstock’s code size and improve performance per watt.

Why does Tamlinux distinguish the cultivar from the rootstock?

Separating the user-facing desktop and tool suite (the cultivar) from the third-party kernel and core OS base (the rootstock) makes it possible to swap or shrink the underlying foundation—such as moving from Arch Linux to Void Linux or a microkernel—without redefining the top-level workstation experience.

The product configuration and packages selected for a workstation; component versions and installed cultivar metadata answer different identity questions. Package and kernel versions report which upstream binaries and rootstock artifacts are present on disk, whereas cultivar metadata identifies the composed release profile—which packages, patches, and integration choices were assembled together as a coherent target—which is essential when reasoning about reproducibility, configuration drift, and upgrade compatibility across rootstock transitions.
