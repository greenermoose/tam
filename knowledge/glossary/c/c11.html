C11

The 2011 revision of the ISO C programming language standard (ISO/IEC 9899:2011).

Before 2011, C had no built-in way for two parts of a program to run at the same time—programmers had to rely on separate add-on libraries for each operating system. C11 built multi-tasking and safer programming helpers directly into the language’s official rulebook.

On Linux, -std=c11 is widely used as a portable systems baseline supported by all modern GCC and Clang releases. It standardized <stdatomic.h>, <threads.h>, _Static_assert, anonymous structs and unions, and aligned_alloc, though Linux programs still commonly use POSIX threads (pthread) instead of <threads.h> for richer thread controls.

Why do many Linux C11 programs still use pthreads instead of C11’s <threads.h>?

<threads.h> is an optional C11 header and omits POSIX features such as thread attributes, cancellation, and rwlocks. On Linux, pthreads is universally available, battle-tested, and exposes full OS thread controls.

ISO/IEC 9899:2011 introduced a formal sequentially-consistent-by-default memory model with memory_order relaxations (_Atomic), _Thread_local storage duration, _Generic type-generic dispatch, _Alignas/_Alignof, and removed gets(). Optional bounds-checked interfaces in Annex K (__STDC_LIB_EXT1__) are omitted by glibc due to global constraint-handler ergonomics, and implementations may omit atomics or threads via __STDC_NO_ATOMICS__ and __STDC_NO_THREADS__.
