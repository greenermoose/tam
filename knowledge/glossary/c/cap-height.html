Guide / Glossary A–Z / Terms beginning with C / Cap height

Cap height is the distance from the baseline to the top of a typical uppercase letter.

Capital letters such as H and T all reach about the same height. That height, measured from the baseline they sit on, is cap height. It is a handy way to describe how big the uppercase part of a font looks, regardless of its point size.

Cap height is usually close to, but not the same as, the ascender height of lowercase letters like b and d; some fonts make capitals slightly shorter. Designers compare cap heights when combining fonts, because two fonts at the same point size can look very different. Logos and headings are often specified in cap height rather than point size.

OpenType stores the design cap height in OS/2.sCapHeight, in font units scaled by units per em; TrueType's hhea.ascent is a separate layout metric that commonly exceeds it. Rounded capitals overshoot the cap line slightly for optical alignment, and flat capitals may sit just below it. CSS cap units refer to this metric, while ex refers to x-height.
