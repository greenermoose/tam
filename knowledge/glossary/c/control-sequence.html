Control sequence

A multi-byte sequence starting with CSI (ESC [) that instructs a terminal to move the cursor, set colors, or clear lines.

A control sequence is a short hidden code sent to a terminal that tells it to do something visual—like turning text green or moving the cursor up—instead of printing those characters literally.

Control sequences are the most common family of ECMA-48 escape sequences, beginning with ESC [ followed by optional numeric parameters and a final command byte (such as m for text color).

What happens if a plain text viewer prints a control sequence without interpreting it?

You see raw characters like ^[[31m or [A in the text instead of colored words or cursor movement.

Defined by ECMA-48 §5.4, a Control Sequence consists of CSI (0x1B 0x5B), parameter bytes (0x30–0x3F), intermediate bytes (0x20–0x2F), and a single final byte (0x40–0x7E).
