Guide / Glossary A–Z / Terms beginning with C / CFF2 (Compact Font Format 2)

CFF2 is the OpenType table that stores cubic-Bézier outlines for variable fonts.

CFF2 is a newer way of packing the curves that make up letters inside an OpenType font. It lets one file hold many variations of the same letter, such as lighter or heavier versions, without copying the whole design again.

CFF2 extends the original CFF format with variation support: one charstring can be modified by a variation store driven by the font's fvar axes. Fonts using CFF2 normally carry the .otf extension and cubic curves inherited from PostScript, in contrast to TrueType's quadratic glyf outlines. Static OpenType fonts keep the older CFF table.

The four-byte table tag is CFF2. It simplifies the older format by removing charset, encoding and private-dictionary fields that duplicate SFNT data, and adds a VarStore of region-based deltas applied to charstring numbers and metrics. The hinter must handle outlines that change with axis coordinates; FreeType's CFF driver supports this, and Adobe Type 2 charstring operators remain the base instruction set.
