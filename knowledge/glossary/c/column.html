Guide / Glossary A–Z / Terms beginning with C / Column

A column is one named slot in every row of a database table.

In a table of books, the columns might be title, author and year; each row fills those slots.

A column declaration gives a type such as TEXT or INTEGER and can add constraints such as NOT NULL.

A column is an attribute in the relational model. Constraints, collations and types define which values are legal; storage width and alignment affect physical size.
