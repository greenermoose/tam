C23 (ISO C23)

The 2024 revision of the C programming language standard, adding modern safety and convenience features while removing obsolete syntax.

After a minor typo-fix edition in 2018, C23 is a bigger update to the C rulebook—bringing in clearer ways to write empty pointers, compile-time constants, and embedded data while finally retiring decades-old shortcuts that caused confusion.

Part of the C standards family; Tamlinux avoids requiring C23 yet because older rescue toolchains may not support it. When compiling with -std=c23 on newer GCC or Clang, you gain nullptr, true/false as keywords, typeof, and #embed for binary files, while old K&R-style parameter lists without types are rejected.

Why might code that compiled cleanly under -std=c17 fail to compile under -std=c23?

C23 removes K&R-style function definitions, changes empty parameter lists () to mean (void) rather than unspecified arguments, and reserves keywords like bool, true, false, and nullptr—breaking older code that used them as identifiers.

ISO/IEC 9899:2024 (__STDC_VERSION__ 202311L) introduces nullptr (nullptr_t), constexpr object definitions, typeof/typeof_unqual, standard [[...]] attributes, #embed, <stdbit.h> and <stdckdint.h> checked arithmetic, and mandates two’s-complement signed integer representation. It removes K&R function definitions and trigraphs, requiring migration care for legacy codebases and mixed-standard headers.
