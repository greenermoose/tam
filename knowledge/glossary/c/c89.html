C89 (ANSI C)

C89 (also called ANSI C) is the first official standard for the C programming language, published in 1989 so programs written in C would behave consistently across different computers and compilers.

Before 1989, every company that built a C compiler added its own rules and quirks, so code written for one machine often broke on another. C89 acted like an agreed-upon rulebook—similar to standardizing electrical plug shapes—so a program written on one computer could be compiled and run on many others without rewriting it.

Part of the C standards family, C89 formalized features that everyday C code relies on today: function prototypes (declaring parameter types so compilers catch mismatches), void * generic pointers, const and volatile qualifiers, and a standard library (<stdio.h>, <stdlib.h>, <string.h>). On Linux with GCC or Clang, you can still target this baseline using -std=c89 or -ansi. Unlike later standards, C89 requires variable declarations at the top of a block before any statements and does not support // single-line comments.

Why does compiling old C code with -std=c89 sometimes fail on // comments or mid-block variable declarations?

Because C89 only allows /* ... */ comments and requires all local variables to be declared at the start of a block before executable statements; // comments and mixed declarations were not standardized until C99.

Published as ANSI X3.159-1989 and ratified with only editorial renumbering by ISO as C90 (ISO/IEC 9899:1990), C89 replaced informal K&R C with a normative specification of translation phases, sequence points, and undefined versus implementation-defined behavior. Key language shifts from K&R C included value-preserving integer promotions (replacing unsigned-preserving rules), removal of implicit int parameter defaults when prototypes are present (while retaining old-style K&R definitions as obsolescent), and the <locale.h> and <signal.h> abstractions. Notably, wide-character support remained minimal until the 1995 Normative Amendment 1 (C95/AMD1), and compilers like GCC accept -std=c89 while still permitting GNU extensions unless -pedantic-errors is also passed.
