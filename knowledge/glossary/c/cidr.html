CIDR (Classless Inter-Domain Routing)

A way of writing an address together with the length of its network prefix, such as 192.168.1.26/24.

The prefix length tells you how much of an address names the network and how much names the machine. In 192.168.1.26/24, the first 24 bits describe the local network and the remaining eight bits identify a host. This replaced an older system where the network size was fixed by the first digits of the address, which wasted large blocks.

A /24 has 256 addresses, a /25 has 128 and a /30 has four. The netmask is the same information in dotted form: /24 is 255.255.255.0. In Python, ipaddress.ip_network('192.168.1.26/24', strict=False) prints the network, netmask and broadcast address. Routes use the same notation, and a router prefers the longest prefix that matches a destination.

How many host addresses are usable in a /24 network?

254. Of the 256 addresses, the all-zero address names the network and the all-one address is the broadcast address.

CIDR replaced classful addressing so that address blocks could be allocated in powers of two and aggregated into fewer routing table entries. A prefix of length n corresponds to the mask with the leading n bits set; the network address is the bitwise AND of an address and that mask. Longest-prefix match resolves overlapping routes, and a default route is the zero-length prefix. IPv6 uses the same notation, normally with a /64 prefix on a link.
