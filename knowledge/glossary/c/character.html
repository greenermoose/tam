Guide / Glossary A–Z / Terms beginning with C / Character

A character is a single unit of written text, such as a letter, digit, punctuation mark or symbol.

Every letter, number and punctuation mark you type is a character. A space is a character too, even though you cannot see it. The word 'cat' contains three characters, and an emoji can be one character even though it is built from several numbers inside the computer.

In computing a character is usually represented by a code point, but the two words are not interchangeable: one visible character may need several code points, as with a letter plus an accent. A font draws that character with one or more glyphs. Counting characters, bytes and visible symbols therefore gives different answers.

Unicode distinguishes characters (abstract units), code points (numbers), grapheme clusters (user-perceived units) and glyphs (drawn shapes). UAX #29 defines grapheme cluster boundaries; a flag emoji is two regional-indicator code points forming one cluster. In UTF-8 a character occupies one to four bytes, so byte-oriented APIs can split it; mainstream renderers operate on clusters for cursor movement and selection.
