Guide / Glossary A–Z / Terms beginning with C / Column-family database

A column-family database stores many rows with flexible columns grouped into families.

Think of a huge spreadsheet where each row can choose which columns it fills, and columns that are often read together sit together.

Cassandra and HBase are examples. A row key decides placement, and column families guide storage and access.

Column-family stores trade relational joins for partition-local reads and tunable consistency. Data modelling starts from queries, because a wrong row key spreads work across the cluster.
