Guide / Glossary A–Z / Terms beginning with C / COLR/CPAL (Color layers and palettes)

COLR and CPAL are OpenType tables that let a font draw colored glyphs from layered shapes and a color palette.

Some emoji and logos are colored. A color font can store several stacked shapes for one character plus a list of colors, so the same glyph can appear in different palette themes without separate image files for each.

COLR describes a glyph as layers of ordinary outlines in a drawing order; CPAL supplies palettes of colors that layers reference by index. Version 1 adds gradients and more complex composites. This differs from bitmap color tables such as CBDT/CBLC, which store raster images, and from SVG-in-OpenType, which stores vector markup.

The table tags are COLR and CPAL. Version 0 lists base glyph IDs and palette indices; version 1 adds a BaseGlyphList of paint records—solid fills, linear and radial gradients, transforms and component glyphs—that a renderer executes. CPAL stores numPalettes entries of numPaletteEntries BGRA colors. Shaping still maps characters to glyphs; the color layer stack is applied at rasterization time.
