Guide / Glossary A–Z / Terms beginning with C / Code point

A code point is the number that Unicode assigns to a character, written U+ followed by hexadecimal digits.

Unicode gives every letter, symbol and emoji its own ID number, written like U+0041 for capital A. That number is its code point. Different fonts can draw the same code point differently, but the number stays the same wherever the text is read.

A code point is an abstract number; UTF-8 turns it into bytes for storage, while a font's cmap table turns it into a glyph ID for drawing. One code point may map to different glyphs depending on context, and one visible character may use several code points, such as e plus a combining accent. Confusing these layers causes wrong character counts and broken search.

Unicode defines 1,114,112 code points from U+0000 to U+10FFFF in 17 planes; the two 1,024-value surrogate blocks in the first plane are reserved for UTF-16 pairs and are not scalar values. A code point need not have a glyph in every font: fallback and the missing-glyph box called tofu handle gaps. Normalization can change the code-point sequence for identical visible text without changing its meaning.
