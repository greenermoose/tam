Guide / Glossary A–Z / Terms beginning with C / Chromium

Chromium is an open-source browser project whose code is used by Chrome and by Electron desktop applications.

Chromium is the engine inside several browsers. You may not see its name in the window, but it is doing the work of reading and drawing the page.

Chromium uses the Blink page engine and the V8 JavaScript engine. Other browsers use different engines, such as Gecko in Firefox and WebKit in Safari.

Is Chromium the same product as Chrome?

No. Chromium is the open-source project. Chrome is a product built from it with additional packaging, branding and services. Electron bundles Chromium as a library rather than shipping the Chrome browser.

Chromium is organized around a browser process and sandboxed renderer processes, with separate services for network, storage and GPU work. Its release train supplies regular security fixes; applications that bundle it must track those updates.
