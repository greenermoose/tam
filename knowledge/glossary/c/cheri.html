CHERI (Capability Hardware Enhanced RISC Instructions)

A hardware CPU architecture extension that turns memory pointers into unforgeable capabilities carrying exact bounds and permissions.

Normally, a memory pointer in a program is just a raw street address—if a bug tricks the program into walking past the end of a house into the neighbor’s yard, the CPU lets it happen. CHERI attaches a tamper-proof keycard to every pointer that says which rooms you may enter and whether you can read or write, so the processor stops out-of-bounds access immediately.

Developed by the University of Cambridge and prototyped with Arm on the Morello board, CHERI brings hardware-enforced spatial memory safety (and optionally temporal safety) to existing C and C++ codebases with minimal source changes. Unlike software sanitizers such as AddressSanitizer—which add significant CPU and RAM overhead and are mostly used in testing—CHERI checks bounds in hardware on every pointer dereference.

What prevents a C program with a buffer overflow from overwriting a CHERI pointer’s bounds to grant itself wider access?

Every CHERI capability carries an out-of-band 1-bit validity tag in memory; any non-capability write (such as a buffer overflow) automatically clears that tag, invalidating the forged pointer.

CHERI extends 64-bit registers into 128-bit (+1 tag bit) compressed capabilities (c registers in CHERI-RISC-V or C0–C30 in Morello) encoding a 64-bit virtual address, compressed base/top bounds (using floating-point-like exponent/mantissa encoding with alignment constraints for large allocations), permissions (Load, Store, Execute, LoadCap, StoreCap), and an object type (otype) for sealing. Bounds are strictly monotonic—instructions like CSetBounds can only narrow, never widen, a capability—and an unforgeable hardware tag bit in DRAM (stored via tag-controller memory or ECC carving) is cleared on any raw data store, enabling deterministic spatial safety, compartmentalization without MMU context switches, and heap temporal safety via capability revocation (Cornucopia/CheriABI).
