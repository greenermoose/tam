Terms beginning with C

Glossary definitions for technical terms and acronyms beginning with C.

Explore

C standards (C89, C90, C99, C11, C17, C23)C standards: Family of ISO/IEC 9899 revisions of the C programming language.
C-stateC-state: A processor power-saving state.
C0 control codes (ASCII 0x00-0x1F)C0 control codes: The 32 ASCII control characters (0x00-0x1F) used for line control, signaling, and framing.
C1 (8-bit Control Characters)C1: Control character range 0x80-0x9F in 8-bit encodings, including single-byte CSI (0x9B).
C10 (Deepest CPU Package C-state)C10: Deepest idle power-saving state on modern Intel CPUs, cutting core and ring voltages.
C11C11: A version of the C programming language standard.
C17 (ISO C17)C17: 2018 bug-fix revision of the C11 programming language standard.
C23 (ISO C23)C23: 2024 C language revision adding nullptr, constexpr, #embed, and bit utilities.
C89 (ANSI C)C89: First standardized version of C, published by ANSI in 1989.
C90 (ISO C90)C90: First ISO/IEC standard for C (ISO/IEC 9899:1990), equivalent to C89.
C99 (ISO C99)C99: 1999 C standard adding stdint.h, inline functions, and designated initializers.
CAA (Certification Authority Authorization)CAA: DNS record specifying which Certificate Authorities are allowed to issue TLS certificates for a domain.
CacheCache: A small, fast copy of data kept close to the processor.
Cache lineCache line: The fixed-size block moved into a cache.
CAN (Cancel, 0x18)CAN: ASCII 0x18 control character (Ctrl+X) that cancels an in-progress escape sequence.
Canonical mode (cooked mode)Canonical mode: Default terminal input mode where the kernel buffers and edits a full line before sending it.
CapabilityCapability: A fine-grained permission a process can hold.
Carried patchCarried patch: A local fix kept until upstream includes it.
CBC (Cipher Block Chaining)CBC: Classic block-cipher mode that XORs each plaintext block with the previous ciphertext block.
CCA2 (Adaptive Chosen-Ciphertext Attack)CCA2: Security model where an attacker can query a decryption oracle both before and after seeing a challenge ciphertext.
CDH (Computational Diffie-Hellman)CDH: Hardness assumption that computing g^(ab) from g^a and g^b is infeasible.
CDR (Clock and Data Recovery)CDR: Receiver circuit extracting both timing clock and data bits from a single high-speed serial stream.
Certificate authorityCertificate authority: A trusted organization that signs digital certificates to vouch for public keys.
CFF (Compact Font Format)CFF: Compact outline font format used inside OpenType (.otf) fonts with cubic Bezier curves.
CFI (Control-Flow Integrity)CFI: Compiler and hardware mitigation that stops attackers from redirecting indirect jumps or returns.
Cgroup (control group)Cgroup: A kernel feature that groups processes for resource control.
Character encodingCharacter encoding: A rule that maps characters to numbers.
CheckpointCheckpoint: definition and recovery boundaries across system layers
Checkpoint numberCheckpoint number: A Snapper identifier within one configuration.
ChecksumChecksum: A short value used to detect changes in data.
CHERI (Capability Hardware Enhanced RISC Instructions)CHERI: Hardware architecture extending pointers with unforgeable bounds and permission capabilities.
ChipsetChipset: Support chips that connect the CPU to other components.
ChromaColor information carried separately from brightness in video.
Chroma subsamplingStoring color detail at lower resolution than brightness detail.
CIA (Confidentiality, Integrity, Availability)CIA triad: The three foundational security properties of information systems.
CipherCipher: A mathematical recipe for scrambling and unscrambling data using a key.
CircuitCircuit: a continuous closed loop that allows electric current to circulate
CISC - Complex Instruction Set ComputingCISC: A processor design style with rich, complex instructions.
Clean-room testingClean-room testing: Testing in a fresh, uncontaminated environment.
CLI - Command-Line InterfaceCLI: A text-based command interface.
ClipboardClipboard: A temporary place for copied data.
Clock signalClock signal: A regular timing pulse that coordinates digital circuits.
CloneClone: A full copy of a repository.
CMOS - Complementary Metal-Oxide-SemiconductorCMOS: A low-power transistor circuit family.
Color depthColor depth: The number of bits used to describe a pixel's color.
Color matrixA set of coefficients used to convert between color representations.
Color samplingMeasuring or storing color information at discrete positions.
Color temperatureColor temperature: A measure of how warm or cool white light looks.
CommandCommand: a plain definition and further detail
CommitCommit: A saved snapshot in version control.
CompilerCompiler: A program that translates source code into another form.
CompositorCompositor: A compositor is the program that draws windows on the screen and decides where they go.
ConcatenationConcatenation: Joining things end to end.
ContainerContainer: An isolated group of processes sharing the host kernel.
Context switchContext switch: Changing which task the processor is running.
Contrast ratioContrast ratio: The difference between the brightest and darkest parts of an image.
Control characterControl character: an ASCII code below 0x20 or the delete code 0x7F, often produced by the Ctrl key.
CoreCore: An independent processing unit inside a CPU.
COSMICCOSMIC: Rust-based Wayland desktop environment developed by System76.
CPA (Chosen-Plaintext Attack)CPA: Threat model where an attacker can obtain ciphertexts for plaintexts of their choice.
CPU - Central Processing UnitCPU: The processor that executes instructions.
CPU caches (L1, L2, L3)CPU caches: Multi-level on-chip SRAM hierarchy (L1, L2, L3) bridging fast cores and slower RAM.
CR (Carriage Return, 0x0D)CR: ASCII 0x0D control character (Ctrl+M, '\r') returning the cursor to column 1.
CRC - Cyclic Redundancy CheckCRC: an error-detecting checksum computed via polynomial division over a block of data
CRC-32 (32-bit Cyclic Redundancy Check)CRC-32: Standard 32-bit polynomial error-detecting code used in Ethernet, PNG, ZIP, and themes.
CRIME (Compression Ratio Info-leak Made Easy)CRIME: 2012 attack exploiting TLS-layer compression to recover session cookies.
CRT - Cathode-Ray TubeCRT: An old display technology using an electron beam.
CSI (Control Sequence Introducer)CSI: ESC [ (or 0x9B) prefix starting ECMA-48 parameterized terminal control sequences.
CSP (Content Security Policy)CSP: HTTP response header restricting which scripts, styles, and origins a browser may load.
CSPRNG (Cryptographically Secure Pseudorandom Number Generator)CSPRNG: Random-number generator whose output is unpredictable even if past outputs are observed.
CSS (Cascading Style Sheets)CSS: Style-sheet language controlling colors, fonts, and layout in browsers, GTK themes, and Waybar.
CTA-861 (DTV Video Timings)CTA-861: Standard defining digital video timings, InfoFrames, and EDID extensions.
CTAP2 (Client to Authenticator Protocol 2)CTAP2: FIDO2 protocol for communication between a computer/browser and a hardware security key.
CTLE (Continuous Time Linear Equalizer)CTLE: Analog receiver filter boosting attenuated high-frequency edges on long copper links.
CTR (Counter mode)CTR: Block-cipher mode encrypting an incrementing counter to produce a stream cipher.
CTS-HMAC (Ciphertext Stealing with HMAC)CTS-HMAC: Kerberos encryption type combining AES-CBC with ciphertext stealing and HMAC-SHA1/SHA2.
CultivarCultivar: learning reference and next steps
CUPS (Common Unix Printing System)CUPS: Standard modular printing service on Linux handling print queues, IPP, and printer drivers.
CurrentCurrent: the rate at which electric charge flows through a conductive path
CXL (Compute Express Link)CXL: High-speed cache-coherent interconnect layered over PCIe 5.0/6.0 for memory and accelerators.
