COSMIC is a Wayland-based desktop environment developed by System76 and written primarily in Rust.

A desktop environment is the visual workspace you see after logging in—your top bar, app launcher, window borders, settings app, and file manager. COSMIC is a modern open-source Linux desktop environment built from scratch by System76 to be fast, customizable, and reliable, with window tiling and theming built right in rather than bolted on with third-party extensions.

Unlike older desktops that began on X11 and later added Wayland support, COSMIC targets Wayland natively and uses its own compositor (cosmic-comp) alongside Rust-based applets and applications. Its panels, workspace behavior, and optional automatic window tiling are designed to work as a unified set without relying on fragile JavaScript shell extensions. For Linux users, it sits alongside GNOME and KDE Plasma as a full desktop environment rather than a standalone window manager.

How does COSMIC’s approach to features like tiling and panels differ from a standalone window manager?

A standalone window manager only arranges windows and leaves panels, settings, and applets to separate tools, whereas COSMIC integrates the compositor, panels, theming, and core apps into one cohesive desktop environment.

The COSMIC stack centers on cosmic-comp, a Wayland compositor built on the Rust smithay library, paired with shell components and applications written with libcosmic (an extension of the iced GUI toolkit). IPC and desktop integration rely on Wayland protocols (xdg-shell, layer-shell, cosmic-* extensions) and D-Bus portals (xdg-desktop-portal-cosmic) for screencasting, file pickers, and sandboxed permissions. Writing the compositor and shell in Rust eliminates common C/C++ memory-safety bugs (such as use-after-free) in privileged session code while sharing one toolkit across applets and settings.
