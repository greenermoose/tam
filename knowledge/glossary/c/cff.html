Guide / Glossary A–Z / Terms beginning with C / CFF (Compact Font Format)

A compact outline font format used inside OpenType .otf fonts that describes letter shapes with cubic Bézier curves.

Fonts store letters as mathematical curves rather than pixel grids so they stay sharp at any zoom level. CFF is a space-saving way of storing those curves inside an .otf font file, letting one file hold a detailed typeface without wasting disk space or memory.

Two outline flavors are common on Linux: TrueType .ttf fonts use quadratic curves, while CFF/.otf fonts use PostScript cubic curves. CFF supports subroutines—reusable fragments such as serifs or bowls—which shrink files for large character sets such as CJK. It pairs with standard OpenType layout tables for ligatures, small caps and kerning.

How do .otf (CFF) and .ttf (TrueType) files differ in how they represent glyph outlines?

CFF uses cubic Bézier curves from PostScript; TrueType uses quadratic curves, which need more control points for the same smooth shape.

CFF and its successor CFF2 live in the 'CFF ' or 'CFF2' SFNT table, encoding Type 2 charstrings in a compact stack machine with local and global subroutines. Its stems and blue zones are declarative hints, unlike TrueType's imperative bytecode. FreeType's CFF hinter snaps stems automatically at small pixels per em; CFF2 drops legacy PostScript dictionary fields in favor of SFNT mappings and VarStore variation deltas.
