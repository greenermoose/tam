Guide / Glossary A–Z / Terms beginning with C / Clamshell mode

Running a laptop with its lid closed while connected to an external monitor, keyboard, and mouse.

Clamshell mode lets you close your laptop lid and keep working on an external monitor without the computer going to sleep.

On Tamlinux, clamshell helpers check whether an external monitor is active before deciding whether closing the lid should disable the internal panel or suspend the system.

What should happen when you close a laptop lid with no external monitor attached versus with one attached?

With no external monitor, the system suspends or locks as configured; in clamshell mode with an external monitor active, the internal screen turns off while the external display stays awake.

Clamshell handling coordinates logind lid-switch events (HandleLidSwitchExternalPower/Docked) with compositor output state via tam-hw-clamshell and tam-hyprland-monitor-clamshell.
