CCA2 (Adaptive Chosen-Ciphertext Attack)

CCA2 (Adaptive Chosen-Ciphertext Attack) is a cryptographic security model in which an attacker can ask a system to decrypt chosen ciphertexts both before and after seeing a target encrypted message.

Imagine testing a locked safe by allowing a thief to slip any fake message through a slot and hear what comes out—even after you hand them the real locked message you want to protect (as long as they cannot just ask you to open that exact message). If the thief still cannot learn anything about what is inside your real message, the encryption passes the CCA2 test.

Real-world servers often act like partial decryption helpers—returning an error if padding is wrong, if a packet is malformed, or if a key fails to unwrap. An encryption scheme that only resists passive eavesdropping (CPA security) can collapse completely when an attacker probes it with modified ciphertexts. Modern public-key encryption and Key Encapsulation Mechanisms (KEMs), such as RSA-OAEP and ML-KEM (Kyber), are designed to achieve IND-CCA2 security so ciphertext tampering yields no useful information.

Why isn’t passive eavesdropping security (IND-CPA) enough for a server that decrypts incoming messages?

Because an active attacker can send modified ciphertexts to the server and observe errors, timing, or behavior differences—effectively using the server as a decryption oracle to recover secrets unless the scheme is IND-CCA2 secure.

In the IND-CCA2 game, a probabilistic polynomial-time adversary queries a decryption oracle Dec_sk(·) adaptively before receiving a challenge ciphertext c* = Enc_pk(m_b) (for random bit b and chosen m_0, m_1), and continues querying Dec_sk(c) for any c != c* before guessing b. IND-CCA2 implies non-malleability (NM-CCA2): no adversary can transform c* into a related valid ciphertext c'. Achieving it requires binding randomness and ciphertext integrity—via OAEP or Fujisaki–Okamoto (FO) transforms in KEMs, where implicit rejection on decapsulation failure prevents Bleichenbacher-style reaction oracles.
