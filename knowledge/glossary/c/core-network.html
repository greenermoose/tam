Guide / Glossary A–Z / Terms beginning with C / Core network

The core network is the part of a mobile network behind the cells and base stations. It holds subscriber records, tracks where a phone is registered and carries traffic toward its destination.

A phone's radio link reaches only a nearby cell. Everything after that handoff happens inside the carrier's core. The core knows which account the phone belongs to, where it is currently served and how to forward a message or a data connection.

The RAN (Radio Access Network) is the radio side; the core is the subscriber and routing side. Network functions such as the HSS (Home Subscriber Server) or UDM (Unified Data Management) keep identity and authentication data. An APN (Access Point Name) selects a data route through that core. A text may pass through several core systems before it reaches the receiving phone.

4G systems call the packet core EPC; 5G systems use the 5G Core, a service-based architecture described in 3GPP TS 23.501. User-plane functions forward traffic while control-plane functions manage registration, mobility and policy. This "core" is a network role, not the CPU core that executes instructions on a computer.
