Guide / Glossary A–Z / Terms beginning with X / X client

An X client is any application that connects to an X server using the X11 protocol.

The application asks the server to draw its window and reports when it wants keyboard or mouse input. The window manager is also an X client, but it has the special job of placing windows.

Most programs do not speak the protocol directly. They use Xlib, XCB or a toolkit backend that hides the difference between X11 and Wayland. On a Wayland session, an X client normally talks to XWayland.

Clients create resources such as windows, pixmaps and graphics contexts in the server, then exchange requests and events over a byte stream. Convention-based properties, not the core protocol alone, let a client cooperate with a window manager: see ICCCM and EWMH.
