Guide / Glossary A–Z / Terms beginning with X / xdg-shell

xdg-shell is the Wayland extension that turns a surface into an ordinary window.

A bare surface has no window behaviour. xdg-shell says whether it is a main window, a menu or a popup, so the compositor knows how to place and treat it.

An application creates an xdg toplevel for its main window. It may create popups for menus and tooltips. The compositor sends configure events with proposed size and state; the application acknowledges them when its next buffer is ready.

xdg-shell defines roles, state, seat and keyboard interactivity, window geometry versus surface geometry, and configure/acknowledge sequencing. It is an optional protocol global that clients bind from the registry. Compositors and toolkits must negotiate its version.
