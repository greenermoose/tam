Guide / Glossary A–Z / Terms beginning with X / XDG desktop portal

An XDG desktop portal is a service that lets applications ask the desktop for a file chooser, screenshot or other shared facility.

Instead of every application reading the whole screen, it asks the desktop through the portal. The desktop can show a chooser or ask your permission. This is why a screenshot tool may prompt you on a Wayland session.

Portals give applications a desktop-neutral way to request sensitive operations. Common interfaces include file chooser, screenshot, remote desktop, notification and secrets. The compositor or desktop supplies the implementation; user consent can be part of the request.

Portal clients speak over D-Bus to a frontend that selects a desktop-specific backend. Interfaces are versioned and negotiated, and results may be returned as file descriptors or URIs. Portals arose partly because Wayland deliberately does not give every client global screen or file access.
