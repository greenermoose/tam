Guide / Glossary A–Z / Terms beginning with X / X11

X11 is the older display protocol that lets applications draw windows through a separate X server.

An application called an X client asks the X server to draw lines, text and pictures. A window manager places the finished windows on the screen. X11 was the usual display system on Linux desktops for many years and still supports older applications.

X11 separates drawing from placement. Clients use Xlib or XCB to send requests. The server sends input events back. Conventions such as ICCCM and EWMH let clients and window managers agree on titles, focus and workspaces. On a Wayland desktop, XWayland supplies an X11 display for legacy clients.

X11 is a network-transparent request and event protocol. Core resources include windows, pixmaps, graphics contexts and fonts; extensions add rendering, shape, RandR and compositing. There is no atomic presentation contract equivalent to a Wayland surface commit, and a client with display access can often observe global input or pixels. Those boundaries explain much of the move to Wayland.
