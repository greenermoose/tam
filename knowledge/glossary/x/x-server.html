Guide / Glossary A–Z / Terms beginning with X / X server

An X server is the program that owns the screen, keyboard and mouse in an X11 session.

Applications send the server requests such as "draw this box" or "tell me when a key is pressed". The server carries out those requests and sends input events back. A separate window manager decides where windows go.

The DISPLAY environment variable tells clients which X server to contact. That server may be local, remote, or an XWayland instance running as a Wayland client. Seeing DISPLAY therefore does not prove the desktop session is X11.

X.Org is the common free implementation. The server serialises drawing requests from many clients, manages resources and delivers events. Its broad default access to input and windows is the isolation weakness that Wayland removes by making the compositor the single display and input owner.
