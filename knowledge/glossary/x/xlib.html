Guide / Glossary A–Z / Terms beginning with X / Xlib

Xlib is the traditional C library applications use to talk to an X server.

Instead of writing network messages by hand, a programmer calls Xlib functions to open a display, create a window and receive events. It is one way for an X client to use X11.

Xlib is synchronous in many operations, so a call may wait for a reply from the server. Newer programs often choose XCB, which is asynchronous and exposes protocol extensions directly. Toolkits normally hide both behind a widget API.

Xlib converts C calls into protocol requests and decodes events and replies. It predates XCB and remains widely linked, so older applications and bindings still depend on it. Its API mixes core protocol calls with extension helpers and does not provide a modern presentation contract.
