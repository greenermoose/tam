XDG (Cross-Desktop Group / Base Directory Specification)

A set of freedesktop.org standards defining where Linux apps store config, data, cache, runtime files, and default handlers.

XDG is a shared set of rules that keeps your home folder tidy by telling Linux programs to store settings in ~/.config, data in ~/.local/share, and temporary caches in ~/.cache instead of scattering hidden files everywhere.

On Tamlinux, XDG standards govern both directory locations (XDG_CONFIG_HOME, XDG_DATA_HOME, XDG_CACHE_HOME) and file-type associations (xdg-mime and mimeapps.list).

Where do XDG-compliant programs store per-user configuration files by default?

Under ~/.config (or the directory named by the XDG_CONFIG_HOME environment variable).

The XDG specifications from freedesktop.org cover Base Directory layout, Desktop Entry (.desktop) files, MIME applications associations, and xdg-desktop-portal IPC for sandboxed Wayland file pickers and screencasts.
