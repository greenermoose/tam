XWayland

A compatibility layer that lets older X11 graphical applications run inside a modern Wayland desktop.

XWayland is a translator that lets older Linux programs written for the X11 display system open windows normally inside a Wayland desktop.

When a legacy app does not support Wayland natively, the compositor starts XWayland on demand to host it. XWayland apps may look slightly blurry under fractional scaling compared to native Wayland apps.

Why might one older application look slightly softer on a scaled Wayland monitor than a native app?

Because it is running through XWayland, where legacy X11 scaling differs from native Wayland fractional-scale rendering.

XWayland runs a rootless Xorg server as a Wayland client, mapping X11 windows to wl_surface objects and translating X11 input, clipboard selections, and RandR queries through the compositor's XWayland bridge.
