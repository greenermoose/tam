Terms beginning with X

Glossary definitions for technical terms and acronyms beginning with X.

Explore

X.509X.509: The standard digital certificate format used by TLS, HTTPS, and public-key infrastructure.
X/OpenA former vendor consortium whose portability guides helped define Unix standards and later became part of The Open Group.
X3DH (Extended Triple Diffie-Hellman)X3DH: Asynchronous key-agreement protocol used by Signal and end-to-end encrypted messaging.
x86x86: The processor family used by most desktop PCs.
XBPS (X Binary Package System)XBPS: Fast independent package manager created for Void Linux.
XDG (Cross-Desktop Group / Base Directory Specification)XDG (Cross-Desktop Group / Base Directory Specification): A set of freedesktop.org standards defining where Linux apps store config, data, cache, runtime files, and default handlers.
XDP (eXpress Data Path)XDP: High-speed eBPF hook processing network packets in the NIC driver before kernel sk_buff allocation.
XML (eXtensible Markup Language)XML: Structured tag-based data format used by Fontconfig, SVG, and D-Bus introspection.
XMSS (eXtended Merkle Signature Scheme)XMSS: Stateful hash-based post-quantum signature scheme (RFC 8391).
XNU (X is Not Unix)XNU: Hybrid kernel powering macOS and iOS, combining Mach IPC, BSD layers, and I/O Kit.
XOR (Exclusive OR)XOR: Logic operation outputting 1 when inputs differ; foundational in digital adders, parity, and ciphers.
XSS (Cross-site scripting)XSS: A flaw where untrusted text becomes executable code in a web page.
XTS (XEX-based Tweaked-Codebook with Ciphertext Stealing)XTS: Block-cipher mode tailored for sector-level disk encryption.
XWaylandXWayland: A compatibility layer that lets older X11 graphical applications run inside a modern Wayland desktop.
