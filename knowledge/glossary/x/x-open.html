Guide / Glossary A–Z / Terms beginning with X / X/Open

A former vendor consortium whose portability guides helped define Unix standards and later became part of The Open Group.

X/Open was a group of computer companies that worked together to make Unix systems more compatible. They wrote guides describing how Unix programs should behave so software could run on different vendors' systems with fewer changes.

X/Open published the X/Open Portability Guide (XPG), which influenced Unix interfaces and command behavior. Its work fed into later standards such as POSIX and the Single UNIX Specification (SUS). In 1996, X/Open merged with the Open Software Foundation to form The Open Group, which now manages the UNIX trademark and the Single UNIX Specification.

X/Open's XPG specifications (including XPG4) defined XSI (X/Open System Interface) extensions beyond base POSIX, covering C interfaces, commands, and internationalization. XPG4v2 became a basis for UNIX 95 branding; later SUS versions consolidated POSIX and XSI. In modern feature-test macros, _XOPEN_SOURCE exposes X/Open/SUS interfaces in C libraries. Historically, "X/Open" names a standards body and specification lineage, not a current independent consortium.
