Guide / Glossary A–Z / Terms beginning with X / x-height

x-height is the distance from the baseline to the top of a typical small lowercase letter such as x.

The letter x reaches a useful height: most short lowercase letters stop there. That height tells you how big a font's small letters look. A font with a large x-height can look larger than another font at the same point size.

Designers use x-height to judge readability and to choose body text sizes; fonts with generous x-heights often read well on screens. It also sets the CSS ex unit, roughly the height of a lowercase x. Ascenders and descenders extend beyond the x-height, while capitals usually sit between x-height and ascender height.

OpenType provides OS/2.sxHeight for the design x-height, but older or CFF-only fonts may lack it, so applications sometimes infer it by measuring the x glyph outline. The value is in units per em and can differ sharply between fonts at equal point sizes. Variable fonts may vary x-height with an optical-size axis, changing apparent size without changing the declared point size.
