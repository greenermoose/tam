Guide / Glossary A–Z / Terms beginning with X / XCB

XCB is a C library that sends X11 protocol requests without waiting for each reply.

Like Xlib, XCB lets an application create windows and receive input through an X server. It is a lower-level building block, so most users meet it indirectly through a toolkit.

XCB's asynchronous design lets a program queue requests and check replies later. Extensions are generated from protocol descriptions, so newer X11 features are available without changing a central library API.

XCB speaks the wire protocol directly and exposes core requests and extensions through generated headers. Applications choose when to flush the connection and when to wait for a reply or event. Toolkits such as Qt have used it for X11 backends; on Wayland those backends use protocol objects instead.
