XDP (eXpress Data Path)

A high-speed Linux kernel hook that lets eBPF programs inspect, drop, or redirect network packets directly in the network driver before normal networking structures are allocated.

Normally, when a network packet arrives, the operating system wraps it in tracking paperwork and passes it through several layers of software before deciding whether to keep or block it. During a flood of junk traffic, all that paperwork slows the machine down. XDP acts like a bouncer standing right at the front door of the network card, turning unwanted packets away immediately before the system spends effort processing them.

Whereas nftables or iptables filter packets after the kernel has already allocated an sk_buff (socket buffer) and entered the network stack, XDP runs at the driver’s receive ring—making it ideal for DDoS mitigation, line-rate packet filtering, and fast load balancing. You attach an XDP program to an interface with tools like ip link set dev eth0 xdp obj prog.o, and can inspect attached hooks via ip link show or bpftool.

When would you choose XDP over nftables for dropping malicious traffic?

Choose XDP when packet rates are so high that allocating kernel sk_buff structures and traversing the full network stack exhausts CPU. XDP drops packets at the driver RX ring before allocation, whereas nftables is simpler for stateful, connection-tracked firewall rules at normal traffic rates.

XDP attaches a verifier-checked BPF_PROG_TYPE_XDP program to an interface’s RX queue. It operates on raw linear page frames (struct xdp_buff with data, data_end, data_meta) and returns one of five verdicts: XDP_DROP, XDP_PASS, XDP_TX (hairpin out the same NIC), XDP_REDIRECT (to another NIC, CPU via cpumap, or user space via AF_XDP zero-copy sockets), or XDP_ABORTED. Three attachment modes trade speed for compatibility: native driver mode (zero-allocation, requires driver support), offload mode (runs on SmartNIC hardware), and generic/SKB mode (runs after sk_buff allocation for testing). Multi-buffer XDP supports jumbo frames, though driver support and LRO/GRO interactions vary.
