Guide / Glossary A–Z / Terms beginning with X / XMPP (Extensible Messaging and Presence Protocol)

XMPP (Extensible Messaging and Presence Protocol): an open, federated protocol for instant messaging and presence.

XMPP is an open standard for chat. People can run their own servers and still exchange messages with people on other servers.

An address looks like an email address. Presence shows availability, and extensions add features such as message receipts.

RFC 6120 defines XMPP core and RFC 6121 defines roster and presence. Encryption is provided by separate profiles and extensions, not by the base protocol alone.
