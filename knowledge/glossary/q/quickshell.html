Guide / Glossary A–Z / Terms beginning with Q / Quickshell

A Qt 6 and QML Wayland shell toolkit used by Tamlinux to render its top bar and desktop plugins.

Desktops need a program to draw the top bar, clock, launcher, and pop-up widgets around your application windows. Quickshell is the toolkit that runs those interface pieces on Wayland, letting Tamlinux build its bar and plugins from readable QML files instead of compiling a separate program for every widget.

In Tamlinux, fred.* plugins run inside Quickshell via Launch.qml, anchoring panels to screen edges over Wayland wlr-layer-shell. Because Quickshell watches QML files and exposes live desktop services directly to QML, you can adjust layouts or inspect bar state without restarting your Wayland compositor.

Why does a status bar built with Quickshell use wlr-layer-shell instead of a regular Wayland application window?

Regular xdg-shell windows are tiled and managed like normal apps; wlr-layer-shell lets a shell surface anchor to monitor edges, reserve exclusive screen space, and stay above or below normal windows.

Quickshell embeds a Qt 6/QML runtime with native C++ singletons exposing Wayland zwlr_layer_shell_v1 surfaces, Hyprland socket IPC, PipeWire audio nodes, MPRIS D-Bus controls, and StatusNotifierItem system trays. Edge cases include multi-monitor hotplug surface teardown, exclusive-zone geometry conflicts, and UI frame drops if synchronous subprocesses are spawned on the QML thread instead of using async process or IPC models.
