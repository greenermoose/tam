Guide / Glossary A–Z / Terms beginning with Q / Qt

Qt is a cross-platform toolkit and application framework for building graphical programs.

Qt supplies buttons, menus, text fields and windows so an application does not have to draw them itself. KDE Plasma and many other Linux applications use it.

Qt Widgets use C++ classes and signals and slots. Qt Quick uses QML to describe a scene declaratively. On Linux, Qt backends can speak X11 or Wayland while application code stays largely the same.

Qt supplies an event loop, object model, rendering scene graph, input handling, styles and platform integration. A Wayland backend creates protocol objects, handles configure events and manages buffers. Native look and feel depends on platform plugins, styles and desktop services.
