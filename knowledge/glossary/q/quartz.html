Guide / Glossary A–Z / Terms beginning with Q / Quartz

Quartz is the graphics and windowing family beneath macOS application interfaces.

Applications draw windows into the macOS graphics system, which combines them on screen. A program built with AppKit uses Quartz without speaking a display protocol itself.

Core Graphics supplies drawing and window services, while Core Animation manages composited layers and animations. Metal accelerates much of the modern rendering path. This is a platform service, unlike Linux's separate Wayland protocol.

Quartz composes windows using an offscreen rendering model, so applications can draw independently and the system presents a combined image. AppKit's views and the responder chain sit above it; SwiftUI ultimately uses the same graphics stack.
