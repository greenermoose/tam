Guide / Glossary A–Z / Terms beginning with Q / Query plan

A query plan is the route a DBMS chooses through the data to answer a question.

It is like a route on a map: several roads reach the same destination, but one may avoid traffic.

Running EXPLAIN before a query shows whether the planner scans a table, uses an index or joins in a particular order.

Planners estimate row counts from statistics. Stale statistics, parameter changes or an unhelpful index can produce a poor plan; plans can change after upgrades.
