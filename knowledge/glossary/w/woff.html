Guide / Glossary A–Z / Terms beginning with W / WOFF (Web Open Font Format)

WOFF is a compressed file format that packages font tables for efficient delivery over the web.

Fonts used to be large downloads. WOFF wraps a normal font in compression so web pages can load it faster, much like a zip archive for font data. The browser unpacks it and uses the font normally.

WOFF 1.0 uses zlib compression on individual SFNT tables and adds a small header with metadata such as the font's name and licence. It supports TrueType and CFF outlines and keeps the same table structure, so conversion back to a plain font is straightforward. Browsers load WOFF files through CSS @font-face rules.

The WOFF header carries a signature (wOFF), flavor, length, number of tables and compressed directory entries with original checksums. Tables may be stored compressed or, when compression would not help, uncompressed. WOFF is an envelope rather than a new outline format: it preserves SFNT tables and has no effect on shaping or rasterization, though its compression reduces transfer size.
