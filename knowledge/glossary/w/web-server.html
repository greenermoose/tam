Guide / Glossary A–Z / Terms beginning with W / Web server

A web server is a program that listens for HTTP requests and sends back the page, file or data that was asked for.

When you type an address, a web server somewhere receives the request and sends the page back. It is the shop keeper behind the webpage you see.

A static server returns files such as HTML, CSS and images. An application server also runs code to build a reply. Every reply carries a status code and a content type.

What is the difference between a static file server and an application server?

A static server returns stored files with little or no change. An application server runs program logic, often reading a database, before deciding what to return.

Servers handle concurrency with processes, threads or asynchronous I/O. A reverse proxy may terminate TLS, compress replies and route paths to several application processes. Correct cache and security headers matter as much as the response body.
