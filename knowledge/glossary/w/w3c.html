W3C (World Wide Web Consortium)

The World Wide Web Consortium (W3C) is an international standards organization that develops open specifications for web technologies such as HTML, CSS, SVG, and WCAG.

W3C is the group that writes the shared rulebooks for the web. Just as standard electrical outlets let any plug fit into any wall, W3C standards let any web browser display pages and graphics built by any website in a predictable way.

W3C publishes formal specifications—called Recommendations—covering CSS styling, SVG vector graphics, WCAG accessibility guidelines, and web APIs such as WebAuthn. In day-to-day web and Linux documentation, W3C works alongside WHATWG, which maintains the living standards for HTML and the DOM; checking which group maintains a feature helps when reading official specs or browser-compatibility notes.

Why does it matter that W3C publishes open standards rather than one browser vendor owning them?

Open, royalty-free standards let independent browser engines (like Firefox, Chromium, and WebKit) implement the same behavior, preventing a single company from locking websites to one browser.

Founded in 1994, the W3C operates through working groups that advance specifications along a maturity track (Working Draft, Candidate Recommendation, Proposed Recommendation, and W3C Recommendation) backed by the W3C Patent Policy’s royalty-free licensing commitment. Under the 2019 W3C–WHATWG Memorandum of Understanding, WHATWG develops the living HTML and DOM standards while W3C endorses snapshots and focuses on CSS, SVG, ARIA, WCAG, and WebAuthn. Interoperability across Blink, Gecko, and WebKit is verified empirically through the shared Web Platform Tests (WPT) suite before a specification reaches Recommendation status.
