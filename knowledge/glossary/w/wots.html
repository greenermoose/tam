WOTS (Winternitz One-Time Signature)

WOTS (Winternitz One-Time Signature) is a post-quantum digital signature scheme built entirely from cryptographic hash functions, where each key pair can safely sign only one message.

Imagine a pad of single-use signature stamps: once you use a stamp on one document, part of its pattern is revealed, so using the same stamp a second time would let someone copy it to forge your signature. Larger signature systems bundle many of these single-use stamps together so you do not run out.

Because signing two different messages with the same WOTS key exposes secret hash-chain values and lets an attacker forge new signatures, WOTS is never used standalone for general signing. Instead, stateful hash-based schemes (XMSS, LMS) and the stateless NIST standard SLH-DSA (SPHINCS+) arrange WOTS+ one-time keys as leaves under Merkle trees.

Why can a WOTS key pair safely sign only a single message?

Each signature reveals intermediate nodes along the secret hash chains for that message’s digest; signing a second, different message exposes additional chain positions that let an attacker combine them to forge other digests.

WOTS/WOTS+ encodes an n-byte message digest plus a base-w checksum (preventing trivial forgery by advancing chains) into len base-w digits, hashing each secret key element up to w - 1 steps. WOTS+ replaces plain iterated hashing with keyed/bitmasked tweakable hash chains to eliminate collision-resistance assumptions and achieve multi-target security. The Winternitz parameter w (commonly 4 or 16) trades signature size—shrinking by a factor of log2(w)—against signing and verification cost, which scales as w - 1 hashes per digit.
