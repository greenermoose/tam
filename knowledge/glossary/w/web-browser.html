Web browser

A web browser is an application that fetches a web page and shows it as words, pictures and controls you can use.

Chrome, Firefox and Safari are browsers. You type an address, the browser asks for the page, and then it draws the page on your screen.

A browser combines an engine for page files with a JavaScript engine, storage for cookies and cached files, and controls such as tabs and a address bar. Each tab usually runs in its own area so one page cannot easily break another.

Does a browser store the web page itself?

It stores a local copy in its cache, but the page's real source lives on a web server. The browser may also keep cookies and site data separately; clearing the cache does not change the server's files.

Browsers implement the WHATWG HTML and DOM standards, CSS specifications and ECMAScript. A renderer parses markup, resolves styles, lays out boxes and paints layers; a browser process manages permissions, network access and sandboxed renderer processes.
