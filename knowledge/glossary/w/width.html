Guide / Glossary A–Z / Terms beginning with W / Width

Width describes how much horizontal space a glyph or a line of text occupies.

Every letter takes up space, even the blank area after it. In a monospace font all letters have the same width; in other fonts a narrow i and a wide w differ. The width of a line decides where text wraps.

Fonts record an advance width per glyph, and layout engines add those advances to place each following glyph. Kerning and OpenType positioning features can adjust the result. Designers also speak of a font's width axis, which makes letters wider or narrower without merely stretching them.

In SFNT fonts advances live in hmtx in units per em, with HVAR deltas for variable fonts; hmtx stores only a prefix of full entries and reuses the last advance for the rest. Terminal emulators assume a fixed cell width, so double-width CJK glyphs occupy two cells and combining marks occupy none. CSS ch uses the width of the digit zero.
