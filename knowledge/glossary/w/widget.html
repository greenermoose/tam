Guide / Glossary A–Z / Terms beginning with W / Widget

A widget is one reusable part of a graphical interface, such as a button, label, slider or text field.

Widgets are the pieces you see and use inside a window. A toolkit supplies them so an application can assemble an interface from ready-made parts.

Widgets are arranged in a hierarchy and a layout system. Each widget draws its own state and receives input events; application code reacts when a button is clicked or a value changes.

A widget typically has state, geometry, a paint step, an event handler and accessibility metadata. Qt Widgets, GTK widgets, QML items and web DOM elements are different implementations of the same broad idea. The compositor sees the finished surface, not individual widgets.
