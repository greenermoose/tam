Guide / Glossary A–Z / Terms beginning with W / Writing script

A writing script is a set of signs and rules for writing a language, such as Latin, Arabic or Devanagari.

English, French and German are all written with the Latin script. A script is the visible sign system, while a language is what people say and write with it. One script can serve many languages.

Script names help describe fonts and text: a font may support Latin, Greek, Cyrillic or Arabic. Scripts are often confused with writing systems, but a script is the sign repertoire and a writing system includes how those signs map to language. Unicode groups characters into script blocks, and shaping engines apply script-specific rules.

Unicode's Script property assigns each code point a script value such as Latn, Arab or Deva; Common and Inherited handle punctuation and combining marks. HarfBuzz chooses lookups by script and language system, because the same sign can behave differently in different languages. Fonts may include locl substitutions to provide regional forms for a script.
