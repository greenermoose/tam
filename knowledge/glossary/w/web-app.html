Web app

A website launched in its own dedicated browser window without normal browser tabs or address bars, behaving like a desktop application.

A web app is a website that opens in its own clean window—with its own icon in your launcher—so you can switch to it just like any installed desktop program.

Tamlinux provides tam-webapp-install and tam-webapp-remove to create or remove dedicated web-app launchers backed by your configured browser.

How does launching a site as a web app differ from opening it in a normal browser tab?

A web app runs in a dedicated, chromeless window with its own desktop entry and window identity, making it easy to tile and focus separately.

Chromium-based web apps launch with --app=<URL> and a matching .desktop entry under ~/.local/share/applications/ so the compositor can match their window class independently.
