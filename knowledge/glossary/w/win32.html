Guide / Glossary A–Z / Terms beginning with W / Win32

Win32 is the long-standing application interface for creating windows and handling input on Microsoft Windows.

A Windows program registers a window class, creates a window and responds to messages such as clicks and key presses. This is the platform layer beneath many older desktop applications.

USER manages windows and messages; GDI supplies classic drawing; the Desktop Window Manager composes the result. Modern frameworks such as XAML and WinUI still rely on the Windows windowing foundation.

Win32 is a broad API family rather than one library. A message loop dispatches events to window procedures, handles are kernel- or user-managed objects, and drawing uses device contexts. Unlike X11, the windowing model is supplied as part of the operating system platform rather than a separate network protocol.
