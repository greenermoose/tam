Guide / Glossary A–Z / Terms beginning with W

Glossary definitions for technical terms and acronyms beginning with W.

Explore

W3C (World Wide Web Consortium)W3C: International standards organization for web technologies such as HTML, CSS, SVG, and WCAG.
WakeupWakeup: An event—such as a timer firing, a network packet arriving, or a key press—that pulls a sleeping CPU core out of a low-power idle state.
WallpaperWallpaper: The background image or solid color displayed behind open windows on a graphical desktop.
WASI (WebAssembly System Interface)WASI: Capability-based POSIX-like system interface for sandboxed WebAssembly modules.
Watt (W)Watt (W): The standard unit of electrical power, equal to one joule of energy used per second (volts multiplied by amperes).
WAW (Write-After-Write hazard)WAW: Pipeline data hazard where two instructions write to the same register; eliminated by register renaming.
WaylandWayland: Wayland is the modern protocol Linux desktops use to draw windows on the screen.
WCAG (Web Content Accessibility Guidelines)WCAG: W3C guidelines for accessible text contrast and readable interfaces.
Web appWeb app: A website launched in its own dedicated browser window without normal browser tabs or address bars, behaving like a desktop application.
Web browserWeb browser: An application that fetches web pages and displays them as an interactive document.
Web serverWeb server: A program that answers HTTP requests with files or generated responses.
WebSocketWebSocket: A long-lived two-way connection between a browser and a server.
WEP (Wired Equivalent Privacy)WEP: Obsolete, broken 1997 Wi-Fi encryption protocol superseded by WPA2 and WPA3.
Wi-FiWi-Fi: The common wireless local-network technology.
WildcardWildcard: A pattern character that matches other characters.
Window managerWindow manager: Software that places and controls windows.
Word splittingWord splitting: the shell step that divides the results of an unquoted expansion into fields using IFS.
WorkspaceWorkspace: learning reference and next steps
WOTS (Winternitz One-Time Signature)WOTS / WOTS+: Hash-chain one-time signature used as a leaf primitive in XMSS, LMS, and SLH-DSA.
