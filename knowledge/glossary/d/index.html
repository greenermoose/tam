Guide / Glossary A–Z / Terms beginning with D

Glossary definitions for technical terms and acronyms beginning with D.

Explore

D-BusD-Bus: the message bus that lets Linux desktop programs discover services and exchange small messages.
DaemonDaemon: A background program that runs without a terminal.
DAG (Directed Acyclic Graph)DAG: Dependency graph with one-way arrows and no circular loops, used by Nix, Git, and build tools.
DANE (DNS-based Authentication of Named Entities)DANE (DNS-based Authentication of Named Entities): uses DNSSEC-validated DNS records to pin TLS keys.
Data lakeData lake: a store of raw data in its original formats, kept before deciding how to use it.
Data warehouseData warehouse: a central store of cleaned historical data organized for analysis.
DatabaseDatabase: An organized store of information that programs can query, update and recover.
Database indexDatabase index: an auxiliary structure that speeds up finding rows at the cost of extra writes and space.
Database management systemDatabase management system: software that creates, queries and maintains a database.
DB-9 (D-subminiature 9-pin connector)DB-9: a 9-pin D-subminiature connector commonly used for serial RS-232 ports and other legacy connections.
DC (Direct Current)DC: Electric current that flows in one direction.
DC1 (Device Control 1 / XON, 0x11)DC1: ASCII 0x11 control character (Ctrl+Q), used as XON to resume paused terminal output.
DC2 (Device Control 2, 0x12)DC2: ASCII 0x12 control character (Ctrl+R) reserved for device control.
DC3 (Device Control 3 / XOFF, 0x13)DC3: ASCII 0x13 control character (Ctrl+S), used as XOFF to pause terminal output.
DC4 (Device Control 4, 0x14)DC4: ASCII 0x14 control character (Ctrl+T) reserved for device control.
DCS (Device Control String)DCS: ESC P ... ESC \ sequence for terminal capability queries and device-level protocols.
DDC (Display Data Channel)DDC: A channel for controlling a monitor.
DDH (Decisional Diffie-Hellman)DDH: Hardness assumption that g^(ab) looks indistinguishable from a random group element given g^a and g^b.
DDR4 (Double Data Rate 4 SDRAM)DDR4: Fourth-generation mainstream system RAM standard (1.2 V, 64-bit channels).
DDR5 (Double Data Rate 5 SDRAM)DDR5: Current-generation system RAM adding on-die ECC, dual 32-bit subchannels, and on-DIMM PMIC.
DecodeDecode: Turning an encoded instruction or signal into meaning.
Decoupled versioningDecoupled versioning: Versioning the command and corpus separately.
Default handlerDefault handler: The application the desktop automatically launches to open a given file type or link scheme such as HTTP or PDF.
DEFLATEDEFLATE: Lossless compression algorithm combining LZ77 and Huffman coding (used in gzip, PNG, and HTTP).
Delivery receiptDelivery receipt: a report about a message delivery attempt, distinct from proof that a person read the message.
DenylistDenylist: a list of items that are explicitly blocked while everything else is allowed.
DependencyDependency: Something a program needs in order to run or build.
DeployDeploy: Deploy means delivering a recorded Tamlinux software assembly onto a machine through the packaging tools, not by copying a checkout by hand.
DeploymentDeployment: The step that makes a finished program available to its users.
Depollution (hazard removal before recycling)Depollution (hazard removal before recycling): taking hazardous parts out of e-waste before shredding.
Desktop environmentDesktop environment: A complete graphical desktop built from several components.
Desktop Window ManagerDesktop Window Manager: The Windows component that composes application windows for display.
Development prefixDevelopment prefix: A user-owned directory for test installs.
Device fileDevice file: A file that represents a hardware device.
Device nodeDevice node: A special file in /dev (such as /dev/ttyUSB0 or /dev/nvme0n1) that gives user-space programs an interface to a kernel hardware driver.
DFE (Decision Feedback Equalizer)DFE: Receiver equalizer subtracting post-cursor inter-symbol interference from previous bits.
DFS (Dynamic Frequency Selection)DFS: Wi-Fi 5 GHz mechanism that detects weather/aviation radar and vacates shared channels.
dGPU (Discrete Graphics Processing Unit)dGPU: A separate graphics processor with its own memory.
DHCP (Dynamic Host Configuration Protocol)DHCP: The protocol that hands out network settings automatically.
DHE (Ephemeral Diffie-Hellman)DHE: Diffie-Hellman key exchange using fresh temporary keys per session for forward secrecy.
Differential SignalingDifferential Signaling: transmitting a signal over a pair of wires using equal and opposite voltages
Diffie-HellmanDiffie-Hellman: A method for two parties to agree on a shared secret over a public channel.
Digital signatureDigital signature: A cryptographic proof created with a private key and verified with a public key.
Digital-to-analog converter (DAC)A circuit that turns a stored number into a physical voltage or current.
DIMM (Dual In-Line Memory Module)DIMM: A memory module that plugs into a motherboard.
DiodeDiode: a two-terminal electronic component that permits current flow in one direction only
Direct-to-deviceDirect-to-device: a satellite network serving an ordinary phone without a separate satellite terminal.
DirectoryDirectory: a plain definition and further detail
DisassemblerDisassembler: A tool that turns machine code back into assembly.
Discretionary Access Control (DAC)Discretionary Access Control: An access model where the owner of a resource decides who may access it.
Disk thrashingDisk thrashing: Excessive paging that leaves little time for real work.
Display managerDisplay manager: A graphical sign-in screen (such as SDDM) that authenticates a user and launches a desktop session.
Display mirroringDisplay mirroring: Showing the exact same desktop picture simultaneously on two or more screens instead of extending across them.
DisplayPortDisplayPort: a plain definition and further detail
DisplayPort link rates (RBR, HBR, HBR2, HBR3, UHBR)DisplayPort link rates: Standardized per-lane bit rates from 1.62 Gbps (RBR) to 20 Gbps (UHBR20).
Distributed file systemDistributed file system: storage that spreads files across many machines while presenting one filesystem view.
Distro (distribution)Distro: learning reference and next steps
DKIM (DomainKeys Identified Mail)DKIM (DomainKeys Identified Mail): a cryptographic signature that shows a domain took responsibility for a message.
DLE (Data Link Escape, 0x10)DLE: ASCII 0x10 control character (Ctrl+P) historically used to escape binary framing bytes.
DLP (Discrete Logarithm Problem)DLP: Math problem of finding x given g^x mod p, broken by Shor's quantum algorithm.
DMA (Direct Memory Access)DMA: Hardware that moves data without the CPU copying it.
DMA-BUFDMA-BUF: A Linux buffer-sharing mechanism used to pass GPU memory between subsystems.
DMARC (Domain-based Message Authentication, Reporting and Conformance)DMARC: a DNS policy that aligns SPF or DKIM with the visible From domain and requests reports.
DNAT (Destination Network Address Translation)DNAT: Firewall rule rewriting a packet's destination IP address or port (port forwarding).
DNS (Domain Name System)DNS: The system that turns names into IP addresses.
DNS-SD (DNS-Based Service Discovery)DNS-SD: using DNS PTR, SRV and TXT records to list and resolve named service instances.
DNSBL (DNS-based Blocklist)DNSBL (DNS-based Blocklist): a DNS-published list of addresses associated with unwanted mail.
DNSSEC (Domain Name System Security Extensions)DNSSEC: Cryptographic signatures on DNS records to prevent spoofing and cache poisoning.
DOCSIS (Data Over Cable Service Interface Specification)DOCSIS: Telecommunications standard for high-speed internet over coaxial cable TV lines.
Document databaseDocument database: a store whose records are self-describing documents such as JSON.
DOM (Document Object Model)DOM: A tree of objects representing a page that script can inspect and change.
DotfilesDotfiles: Personal configuration files and folders whose names begin with a dot (.) in a user's home directory.
Downcycling (lower-value material reuse)Downcycling (lower-value material reuse): turning material into something less valuable than the original.
DownstreamDownstream: A project or distribution that builds on upstream software.
DPCD (DisplayPort Configuration Data)DPCD: Register space inside a DisplayPort monitor read/written over the AUX channel during link training.
DPI (Dots Per Inch)DPI: Dots per inch, a measure of print or pixel density.
DPMS (Display Power Management Signaling)DPMS: A display power-saving standard.
DRAM (Dynamic Random-Access Memory)DRAM: The common type of main memory that needs refreshing.
DriverDriver: Software that lets the kernel control a device.
DRM (Direct Rendering Manager)DRM: The Linux kernel subsystem for graphics devices.
Dry runDry run: A rehearsal that reports what would happen without changing anything.
DSC (Display Stream Compression)DSC: VESA visually lossless, low-latency compression used over DisplayPort and HDMI for high-res/high-Hz modes.
DSN (Delivery Status Notification)DSN (Delivery Status Notification): a report that tells the sender whether a message was delivered or deferred.
DSO (Digital Storage Oscilloscope)DSO: Bench test instrument that samples and graphs electrical waveforms over time.
DSP (Digital Signal Processor / Processing)DSP: Specialized math processing (or dedicated chip) for filtering, equalizing, and decoding continuous signals.
DVFS (Dynamic Voltage and Frequency Scaling)DVFS: Power-management technique lowering CPU/GPU clock speed and voltage together when load is light.
DVI (Digital Visual Interface)DVI: A digital video connector that preceded HDMI.
DWARF (Debugging With Attributed Record Formats)DWARF: Standard debugging-information format embedded in ELF binaries mapping machine code to source lines.
DWDM (Dense Wavelength-Division Multiplexing)DWDM: Fiber-optic technique sending dozens of closely spaced laser wavelengths down one glass strand.
