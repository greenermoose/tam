Guide / Glossary A–Z / Terms beginning with D / Distributed file system

A distributed file system stores very large files across many machines but presents them as one shared filesystem.

It is one enormous drive built from many smaller drives, with copies kept elsewhere if one machine fails.

HDFS is a prominent example: a name node keeps metadata and data nodes hold blocks.

Such systems favour large sequential reads over small random writes. Block placement, replication and metadata-node durability determine resilience and throughput.
