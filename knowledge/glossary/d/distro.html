Distro (distribution)

A distro (short for distribution) is a complete Linux operating system assembled from the Linux kernel, system utilities, a package manager, and user applications.

If the Linux kernel is like a car’s engine, a distro is the finished car—complete with seats, controls, an installer, and a way to get software updates. Different distros pick different defaults and apps to fit beginners, servers, or developers, so you do not have to assemble an operating system from scratch.

Distributions package a kernel, C library, init system (often systemd), package manager (such as apt, dnf, or Nix), and desktop or server software into a coherent system, following either fixed/LTS release cycles or rolling updates. In Tamlinux, the operating system beneath the Tamlinux cultivar is called the rootstock rather than a distro.

Why can two Linux distros running the exact same Linux kernel version use completely different commands to install software?

The Linux kernel only manages hardware and processes; packaging formats, repositories, and package-manager tools are chosen independently by each distribution.

Distributions define ABI and packaging policy, filesystem layout conventions, C library selection (glibc vs. musl), init/service supervision, kernel patchsets, and security baselines (SELinux vs. AppArmor, signed repository metadata, reproducible builds). Fixed-release distros backport security fixes to frozen upstream versions to preserve ABI stability, whereas rolling distros track upstream heads continuously. While "distro" describes independent Linux distributions in general, Tamlinux specifically uses rootstock to describe third-party system software it installs upon.
