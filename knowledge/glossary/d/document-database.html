Guide / Glossary A–Z / Terms beginning with D / Document database

A document database stores each record as a complete document, often encoded as JSON.

It is like a folder of letters: each letter carries its own headings, and two letters need not use the same layout.

Applications read and update a whole document. Related data can be embedded to avoid a join, at the cost of duplicating it.

Document stores support indexes inside documents and flexible schemas, but transactions may be limited to one document or a small set. Query planners differ from relational optimizers.
