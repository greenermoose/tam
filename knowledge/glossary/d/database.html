Guide / Glossary A–Z / Terms beginning with D / Database

A database is an organized place to keep information so a program can find it again, change it and share it between visits.

A database is like a well-labelled filing cabinet. A program can ask for one folder, add a new one or change a record without rummaging through every paper by hand.

A relational database stores rows in tables and is commonly queried with SQL. Other databases store documents or key-value pairs. Backups and constraints help keep data correct.

Why keep important application data in a database rather than only in browser storage?

Browser storage belongs to one person and one device. A server-side database is shared under the application's rules, can enforce constraints and authorization, and can be backed up centrally.

Relational systems provide transactions with atomicity, consistency, isolation and durability. Indexes trade write cost for faster reads; replication improves availability but introduces consistency choices. Schema migrations change structure while existing data must remain valid.
