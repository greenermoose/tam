Guide / Glossary A–Z / Terms beginning with D / Default handler

The application the desktop automatically launches to open a given file type or link scheme such as HTTP or PDF.

A default handler is the program your computer picks automatically when you click a web link or open a PDF file, so you do not have to choose an app every time.

On Linux desktops, default handlers map MIME types (like application/pdf) and URI schemes (like https) to .desktop files in mimeapps.list; Tamlinux helpers such as tam-default-browser and tam-open use these mappings.

What determines which browser opens when you click a web link from a terminal or chat app?

The default handler registered for the http and https schemes in your XDG mimeapps.list configuration.

XDG MIME Applications Association resolves default handlers in precedence order across ~/.config/mimeapps.list, XDG_CONFIG_DIRS, and XDG_DATA_DIRS, queried or updated with xdg-mime default.
