Device node

A special file in /dev (such as /dev/ttyUSB0 or /dev/nvme0n1) that gives user-space programs an interface to a kernel hardware driver.

In Linux, hardware devices appear like special files inside the /dev folder so programs can talk to a keyboard, serial cable, or disk drive using ordinary file operations.

Character device nodes (like /dev/ttyUSB0 or /dev/input/event0) transfer streams of bytes or events; block device nodes (like /dev/nvme0n1) transfer fixed-size storage blocks.

Why is a missing /dev/ttyUSB0 node useful diagnostic evidence?

It shows immediately that the kernel has not enumerated the USB serial adapter or bound a driver to it, pointing to a cable, power, or driver issue before checking terminal settings.

Device nodes are inodes of type S_IFCHR or S_IFBLK carrying major and minor driver numbers, created dynamically on devtmpfs by the kernel and given permissions and persistent symlinks by udev rules.
