DDR5 (Double Data Rate 5 SDRAM)

DDR5 (Double Data Rate 5 SDRAM) is the current generation of system RAM, adding on-die ECC, dual 32-bit subchannels per module, and on-DIMM power management.

DDR5 is the newer generation of computer memory found in modern desktops, laptops, and servers. Compared to DDR4, it transfers data faster, regulates its own power directly on each memory stick, and includes basic self-checking inside every memory chip to catch tiny internal glitches.

Every DDR5 chip includes on-die ECC to improve internal cell reliability, but that is not the same as full system ECC: on-die ECC does not protect the wires between the RAM stick and the CPU, nor does it report errors to Linux EDAC. True end-to-end error protection still requires ECC DIMMs and platform support. Splitting each module into two 32-bit subchannels also lets the CPU serve two smaller memory requests in parallel.

If every DDR5 chip has on-die ECC, why do servers still need ECC DDR5 DIMMs?

On-die ECC only checks and corrects bits inside the DRAM die itself before data leaves the chip; it cannot detect bit flips on the memory bus or report errors to the OS. Full ECC adds extra bus lines (40-bit subchannels) and OS-visible reporting.

JEDEC JESD79-5 synchronous DRAM: 1.1 V VDD supplied by an on-DIMM PMIC, 4800–6400+ MT/s data rates, 16n prefetch (BL16), up to 32 banks across 8 bank groups, and two independent 32-bit (+8-bit optional ECC) addressable subchannels per DIMM—doubling concurrency while preserving a 64-byte minimum access granularity. Adds Same-Bank Refresh (REFsb) so one bank per bank group refreshes while others remain accessible. On-die ECC applies a 128-bit + 8-bit SEC code transparently inside the DRAM, meaning single-bit die corrections never increment kernel EDAC counters.
