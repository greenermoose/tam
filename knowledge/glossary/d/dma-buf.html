Guide / Glossary A–Z / Terms beginning with D / DMA-BUF

DMA-BUF is a Linux mechanism for sharing a buffer of memory between drivers and processes.

When an application draws with the GPU, the finished picture already sits in GPU memory. DMA-BUF lets it hand that picture to the compositor without copying it through ordinary CPU memory first.

On Wayland, the linux-dmabuf protocol passes a DMA-BUF file descriptor and layout information to the compositor. The compositor can then use DRM/KMS to present it. CPU-drawn alternatives use shared memory.

A DMA-BUF file descriptor carries a shared buffer exported by a DMA-BUF exporter such as a GPU driver. Importers map or bind it with their own offsets, strides and modifiers. Linux explicit synchronization uses fences so producers and consumers do not read or write the same buffer at the wrong time.
