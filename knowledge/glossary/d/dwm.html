Guide / Glossary A–Z / Terms beginning with D / Desktop Window Manager

The Desktop Window Manager, or DWM, is the Windows component that composes application windows into what the screen shows.

Each application draws its window, and DWM combines those windows with effects such as transparency and animation. It plays a role similar to a Wayland compositor, but it belongs to Windows itself.

Win32 applications create windows and receive messages; DWM renders the desktop from their surfaces. DirectComposition and Desktop Duplication expose parts of that composition pipeline to applications.

DWM runs as a system process and uses the graphics driver to present a desktop texture. Modern Windows desktop composition predates Linux's widespread compositing, so "Linux invented compositing" is incorrect; the important difference is where the interface boundary lies.
