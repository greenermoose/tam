DC2 (Device Control 2, 0x12)

DC2 (Device Control 2) is an ASCII control code (0x12, typed with Ctrl+R) originally reserved for controlling peripheral devices, and commonly used in Linux shells to search command history.

Early computers included a few generic "device control" codes so programs could switch attached hardware—like a printer or tape reader—into a special mode. Today those old hardware signals are rarely used, so terminal programs reuse Ctrl+R as a handy shortcut to search back through commands you typed earlier.

Part of the C0 control codes, DC2 (Ctrl+R) was left unassigned by ASCII for device-specific use. Unlike DC1 and DC3, it does not control terminal scrolling; interactive shells such as Bash (via GNU Readline) and Zsh bind Ctrl+R to incremental reverse history search.

Why does pressing Ctrl+R at a Bash prompt search history instead of controlling a hardware device?

ASCII left DC2 (0x12) unstandardized for vendor-specific peripherals, and interactive shells run the terminal in non-canonical mode so byte 0x12 passes straight to Readline, which binds it to reverse-search-history.

ASCII 0x12 (DC2, ^R), an ECMA-48 C0 control character with no fixed ISO/IEC 6429 action. In POSIX/Linux termios, 0x12 is the default value of c_cc[VREPRINT], which reprints the current input line when both ICANON and IEXTEN are enabled (for example in raw cat). Interactive line editors (Readline, ZLE, libedit) clear ICANON, bypassing VREPRINT so 0x12 is delivered to user space for bindings such as reverse-search-history.
