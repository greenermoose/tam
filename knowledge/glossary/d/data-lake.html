Guide / Glossary A–Z / Terms beginning with D / Data lake

A data lake keeps large amounts of raw files so they can be explored later.

It is a warehouse loading dock where parcels keep their original wrapping until someone needs them.

Data lakes often sit on an object store and use Parquet for analytical reads.

A lake without cataloguing, access control and file lifecycle rules becomes hard to use. Schema-on-read shifts validation from ingest to query time.
