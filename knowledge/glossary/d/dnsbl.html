Guide / Glossary A–Z / Terms beginning with D / DNSBL (DNS-based Blocklist)

A DNSBL is a blocklist of IP addresses or domains published through DNS queries.

The letters stand for DNS-based Blocklist. A receiving mail server can ask a shared list whether a connecting server has a bad reputation, much like checking a do-not-admit book before accepting a visitor.

For an IPv4 address such as 192.0.2.99, the query is 99.2.0.192.<list-domain>. An A record means the address is listed; its value is a flag, not a usable address. A TXT record often explains why. The older term RBL originally named a particular list.

RFC 5782 describes DNS-based blocklists using the older blacklist and whitelist terminology. Modern teaching prefers blocklist and allowlist. Listings are operational judgments, not proof of guilt: delisting policy, false positives and shared mail infrastructure matter before rejecting mail.
