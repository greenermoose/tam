DIMM - Dual In-Line Memory Module

A DIMM (Dual In-Line Memory Module) is a small circuit board carrying RAM chips that plugs into a motherboard memory slot.

A DIMM is the stick of short-term workspace memory you snap into slots inside a desktop computer. It has separate rows of gold contacts on both sides of its bottom edge so the motherboard can talk to all the memory chips at once. Adding or reseating DIMMs is one of the most common ways to upgrade a PC or fix a machine that refuses to start.

Desktops use full-size DIMMs with a 64-bit data path, while laptops use shorter SO-DIMMs to save space. Depending on the workload, DIMMs come as unbuffered (UDIMM) for consumer PCs, or registered/ECC (RDIMM) for servers that need higher capacity and automatic single-bit error correction. Populating matched slots across memory channels lets the controller interleave reads and writes for higher bandwidth.

Why does installing two identical DIMMs in the motherboard’s paired slots (such as A2 and B2) usually outperform putting them side by side on one channel?

Splitting the modules across two separate memory channels doubles the effective bus width available to the memory controller, increasing bandwidth compared with running both DIMMs on a single channel.

A JEDEC-standardized PCB assembly (e.g., 288-pin DDR4/DDR5) exposing parallel DRAM ranks over a memory channel, paired with an I2C/I3C SPD (Serial Presence Detect) EEPROM that reports timing parameters (CL, tRCD, tRP, tRAS) and XMP/EXPO profiles. DDR5 splits each DIMM into two independent 32-bit (40-bit with ECC) sub-channels and moves voltage regulation onto an on-module PMIC (1.1 V VDD). Server RDIMMs and LRDIMMs add a Registering Clock Driver (RCD) and data buffers to reduce capacitive load on address, command, and DQ lines, trading roughly one clock cycle of latency for much higher rank density.
