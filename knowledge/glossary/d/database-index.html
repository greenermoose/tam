Guide / Glossary A–Z / Terms beginning with D / Database index

A database index is a separate lookup table that helps a DBMS find rows without scanning the whole table.

It is the index at the back of a book: you pay extra pages to find a topic quickly instead of reading every page.

A query on an indexed column can be much faster, but every insert, update and delete must also change the index.

Common structures include B-trees, hash indexes and inverted indexes. A query plan shows whether the planner chose one; low-cardinality columns often gain little.
