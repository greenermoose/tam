Guide / Glossary A–Z / Terms beginning with D / Discretionary ligature

A discretionary ligature is a decorative joined shape that a font offers but does not apply automatically.

Some fonts draw certain letter pairs, such as st or ff, as a single flourish. You can turn that joining on if you like the look, but the font leaves it off by default because it is decorative rather than necessary for reading.

Discretionary ligatures are controlled by the OpenType dlig feature, while common expected joins like fi and fl use the standard liga feature. Designers enable dlig for display headings and disable it for body text, code and interfaces. The underlying text is unchanged: copying it still gives the original letters, because the join happens only in the glyph stream.

In GSUB, discretionary ligatures are ligature substitutions (lookup type 4) placed in the dlig feature; HarfBuzz enables them only when the application requests it. Because a ligature may span more than two glyphs, shapers must handle multi-input lookups and ligature component indexing for correct cluster maps. Mixing fonts can produce odd joins when fallback glyphs break a sequence that the primary font would have joined.
