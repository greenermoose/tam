DC3 (Device Control 3 / XOFF, 0x13)

DC3 (Device Control 3, also called XOFF) is an ASCII control code (0x13, typed with Ctrl+S) used in terminals to pause scrolling output.

When text is scrolling past too fast to read in a terminal, Ctrl+S acts like a pause button that freezes the screen until you press Ctrl+Q to continue. Because Ctrl+S means "Save" in most desktop programs, people often press it by habit in a terminal and think the window has crashed.

Part of the C0 control codes, DC3 acts as XOFF in software flow control (IXON). Pressing Ctrl+S pauses screen output without killing the running command; disabling flow control with stty -ixon lets Ctrl+S pass to editors or forward history search instead.

If you accidentally press Ctrl+S in a terminal, does it cancel the running command?

No. DC3 (0x13) only tells the terminal driver to pause sending output to the screen while IXON is enabled. The command keeps running until its output buffer fills, and pressing Ctrl+Q (DC1) resumes display.

ASCII 0x13 (DC3 / XOFF, ^S). In the Linux n_tty line discipline with IXON enabled, receiving c_cc[VSTOP] (default 0x13) sets the TTY stopped flag and halts driver writes until VSTART (or any character if IXANY is set) arrives. A foreground writer eventually blocks in n_tty_write() once the ring buffer fills (or returns EAGAIN under O_NONBLOCK). With IXOFF set, the kernel itself emits VSTOP upstream when its receive buffer nears capacity.
