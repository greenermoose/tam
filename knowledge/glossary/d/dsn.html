Guide / Glossary A–Z / Terms beginning with D / DSN (Delivery Status Notification)

A DSN is a machine-readable report about what happened to a message during delivery.

The letters stand for Delivery Status Notification. If a letter cannot be put in the recipient's box, the post office sends a note back to the sender explaining what happened.

A DSN can report success, temporary failure or permanent failure. It travels to the envelope sender recorded in Return-Path, which is not always the visible From: address.

RFC 3464 defines the DSN format and RFC 3798 defines message disposition notifications. SMTP extensions let a client request DSNs, but ordinary bounces also exist without negotiation. Because the envelope sender can be forged, unsolicited bounces to innocent addresses are a known abuse pattern called backscatter.
