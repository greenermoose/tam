Display manager

A graphical sign-in screen (such as SDDM) that authenticates a user and launches a desktop session.

A display manager is the graphical login screen that asks for your username and password when a computer starts and then opens your desktop.

Current Tamlinux cultivars use console-first login rather than a graphical display manager by default; you sign in at a text prompt and launch the graphical desktop with start or tam-desktop.

How does console-first login differ from using a display manager?

With console-first login, you authenticate at a plain text virtual console and start graphics explicitly; with a display manager, a graphical greeter starts automatically at boot.

A display manager runs as a privileged systemd service (display-manager.service), authenticates via PAM, opens a logind seat/session, and spawns the chosen Wayland or X11 session entry.
