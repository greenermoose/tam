Directory

A directory is a place for organizing documents and other stored information, often called a folder.

Novice definition

A place for organizing files and other directories; graphical desktops often call it a folder.

Learner definition

Directories form a tree. A directory entry gives a name to a file or another directory.

Expert definition

Directory entries map names to filesystem objects; permissions govern listing, creating entries and traversing the directory.
