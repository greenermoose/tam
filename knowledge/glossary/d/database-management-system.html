Guide / Glossary A–Z / Terms beginning with D / Database management system

A database management system, or DBMS, is the software that looks after a database for an application.

Think of a DBMS as a librarian: it keeps the records, knows where they are and enforces the rules for changing them.

A DBMS accepts queries, chooses how to run them, keeps indexes and enforces constraints. SQLite, PostgreSQL and MySQL are DBMSs with different shapes.

The DBMS separates logical requests from physical storage. Its query planner, storage engine, transaction manager and recovery log turn a statement into safe changes on disk.
