DOM (Document Object Model)

The DOM is a tree of objects that represents a web page while it is open, so JavaScript can inspect and change it.

The page you see is built from parts: a heading, a paragraph, a button. The DOM is the browser's family tree of those parts. Script changes the tree, and the browser redraws what you see.

A call such as document.querySelector('h1') finds a node. Setting textContent replaces its words with text. Using innerHTML with untrusted text can create an XSS flaw, because the text may be parsed as markup.

After script changes a heading, has the HTML file changed?

No. The DOM in memory changed, and the browser paints the new words. The source file on the server or disk stays the same unless the program explicitly saves it.

The DOM is a platform-neutral interface specified by WHATWG; an engine builds an internal document tree and exposes nodes to script. Changing geometry can force layout, while a colour change may only repaint. Shadow DOM creates scoped subtrees that ordinary selectors do not cross.
