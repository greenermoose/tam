KEM (Key Encapsulation Mechanism)

A public-key cryptographic primitive that generates a shared secret key and wraps (encapsulates) it in a ciphertext for a recipient.

A key encapsulation mechanism lets two strangers agree on a brand-new secret key over an open network by sealing a random key inside a mathematical envelope only the recipient can open.

Modern post-quantum standards such as ML-KEM use the KEM pattern (KeyGen, Encaps, Decaps) rather than older direct public-key encryption because it is cleaner and safer against chosen-ciphertext attacks.

How does a KEM differ from traditional public-key encryption?

Instead of encrypting an arbitrary user message directly, a KEM generates and wraps a fresh random symmetric key, which then encrypts the actual data.

A KEM is a triple of algorithms (KeyGen, Encaps, Decaps) targeting IND-CCA2 security (commonly via the Fujisaki-Okamoto transform), feeding its shared secret into a symmetric AEAD cipher via a KDF.
