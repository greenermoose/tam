Guide / Glossary A–Z / Terms beginning with K / Key-value database

A key-value database stores a value under a key and fetches it by that key.

It is a huge labelled set of boxes: you know the label, and you want the contents quickly.

Key-value stores are useful for caches, sessions and simple lookups. Values may be strings, lists or other structures depending on the product.

The interface is deliberately narrow, which helps low latency and scaling. Range queries, joins and secondary indexes may be absent or limited.
