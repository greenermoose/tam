Kernel space

Kernel space is the privileged part of a computer's memory where the operating system kernel runs and can directly control hardware.

Imagine a building with a secure control room. Only authorized staff can enter the control room because it has switches that affect the whole building: power, elevators, alarms, and locks. Kernel space is like that control room. Ordinary programs stay outside in user space, where they can do their own work safely. When they need hardware or a protected service, they ask the kernel through a controlled request.

On Linux, kernel space code runs with full hardware privilege. The kernel, device drivers loaded as kernel modules, and core subsystems such as scheduling, memory management, and file systems execute there. User-space programs cannot directly read kernel memory or touch device registers; they make system calls to request kernel services. This boundary protects the system: a bug in a normal program usually crashes only that program, but a bug in kernel-space code can crash or compromise the whole machine.

Why is kernel-space programming riskier than ordinary application programming?

Kernel-space code runs with full privilege and shares the kernel’s address space, so mistakes such as bad pointers, race conditions, or incorrect hardware access can corrupt the whole operating system instead of being contained to one process.

Kernel space executes at a privileged CPU mode (for example, x86-64 Ring 0 or ARM64 EL1) with access to privileged instructions, page-table control, interrupt handling, and device MMU/IOMMU configuration. The user/kernel boundary is enforced by hardware page-table permissions and mode transitions through syscall, exceptions, and interrupts; mitigations such as KPTI reduce information-leak exposure from shared mappings. Kernel-space programming therefore requires strict discipline around memory ownership, concurrency, preemption, and ABI stability: interfaces such as loadable modules, BPF, and driver frameworks trade extensibility for a large trusted computing base.
