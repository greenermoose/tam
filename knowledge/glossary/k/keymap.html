Keymap

A table translating physical keyboard scan codes or keycodes into characters and actions for a specific language or layout.

A keymap is the lookup chart that decides which letter appears when you press a physical key—for example, whether a keyboard types QWERTY, AZERTY, or accented characters.

Linux uses two separate keymap layers: kernel console keymaps (loaded with loadkeys for text TTYs) and XKB keymaps (used by Wayland compositors like Hyprland).

Why might your keyboard layout differ between a text virtual console and your graphical desktop?

Because the Linux console uses the kernel keymap (configured in /etc/vconsole.conf), whereas the Wayland compositor loads an XKB keymap.

Kernel keymaps map Linux evdev keycodes through modifier planes to keysyms/strings in drivers/tty/vt/keyboard.c, while graphical sessions compile XKB rules/models/layouts/variants via libxkbcommon.
