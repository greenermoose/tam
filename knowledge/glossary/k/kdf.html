Guide / Glossary A–Z / Terms beginning with K / KDF (Key Derivation Function)

A cryptographic algorithm that stretches a password or shared secret into strong, fixed-length encryption keys.

A key derivation function turns a human password or a raw shared secret into strong cryptographic keys suitable for locking files or securing network traffic.

Password KDFs (like Argon2id and scrypt) are intentionally slow and memory-hard to resist brute-force guessing, whereas key-expansion KDFs (like HKDF) quickly derive multiple session keys from an already high-entropy secret.

Why should you use Argon2id rather than plain SHA-256 to derive an encryption key from a user password?

SHA-256 is designed to be extremely fast, making offline password guessing easy; Argon2id intentionally consumes time and memory to slow attackers down.

KDFs fall into two classes: extract-and-expand PRFs (RFC 5869 HKDF) for high-entropy key material, and memory-hard password-based KDFs (RFC 9106 Argon2id, scrypt, PBKDF2) parameterized by salt, iterations, and memory cost.
