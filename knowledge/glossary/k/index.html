Terms beginning with K

Glossary definitions for technical terms and acronyms beginning with K.

Explore

  • KDC (Key Distribution Center) — KDC: Trusted authentication server (as in Kerberos) that issues session keys and tickets.
  • KDE (K Desktop Environment / Plasma) — KDE: Major open-source Linux community and Plasma desktop environment built on Qt.
  • Kernel — Kernel: a plain definition and further detail
  • Kernel module — Kernel module: A piece of kernel code that can be loaded at runtime.
  • KEX (Key Exchange) — KEX: Cryptographic handshake step where two parties establish a shared secret over an untrusted network.
  • KEXINIT (SSH Key Exchange Initialization) — KEXINIT: Initial SSH_MSG_KEXINIT packet advertising supported ciphers, MACs, and key-exchange algorithms.
  • Keybinding — Keybinding: A key or key combination that runs an action.
  • Keycode — Keycode: a number for a key, with different numbering in the Linux kernel and in XKB or Wayland.
  • Keysym — Keysym: the symbolic meaning of a key, such as a, A, Return or BackSpace, used by X11 and XKB.
  • KGDB (Kernel GNU Debugger) — KGDB: Linux kernel source-level debugger operating over a serial port or network.
  • Kitty keyboard protocol — Kitty keyboard protocol: Modern terminal key-reporting protocol using CSI code ; modifier u.
  • KMAC (Keccak Message Authentication Code) — KMAC: Variable-length MAC and PRF built directly on SHA-3/cSHAKE (NIST SP 800-185).
  • KMS - Kernel Mode Setting — KMS: Kernel-based display mode setting.
  • KPTI (Kernel Page-Table Isolation) — KPTI: Kernel mitigation against Meltdown that unmaps kernel memory while user programs run.
  • KVM (Kernel-based Virtual Machine) — KVM: Linux kernel hypervisor turning Linux into a Type-1 hypervisor using Intel VMX or AMD SVM.
