Guide / Glossary A–Z / Terms beginning with K

Glossary definitions for technical terms and acronyms beginning with K.

Explore

KDC (Key Distribution Center)KDC: Trusted authentication server (as in Kerberos) that issues session keys and tickets.
KDE (K Desktop Environment / Plasma)KDE: Major open-source Linux community and Plasma desktop environment built on Qt.
KDF (Key Derivation Function)KDF (Key Derivation Function): A cryptographic algorithm that stretches a password or shared secret into strong, fixed-length encryption keys.
KEM (Key Encapsulation Mechanism)KEM (Key Encapsulation Mechanism): A public-key cryptographic primitive that generates a shared secret key and wraps (encapsulates) it in a ciphertext for a recipient.
KerberosKerberos: Network authentication protocol using symmetric-key tickets and a trusted KDC for single sign-on.
KernelKernel: a plain definition and further detail
Kernel moduleKernel module: A piece of kernel code that can be loaded at runtime.
Kernel spaceKernel space: the privileged part of memory where the kernel and kernel modules run
KEX (Key Exchange)KEX: Cryptographic handshake step where two parties establish a shared secret over an untrusted network.
KEXINIT (SSH Key Exchange Initialization)KEXINIT: Initial SSH_MSG_KEXINIT packet advertising supported ciphers, MACs, and key-exchange algorithms.
KeybindingKeybinding: A key or key combination that runs an action.
KeycodeKeycode: a number for a key, with different numbering in the Linux kernel and in XKB or Wayland.
KeymapKeymap: A table translating physical keyboard scan codes or keycodes into characters and actions for a specific language or layout.
KeysymKeysym: the symbolic meaning of a key, such as a, A, Return or BackSpace, used by X11 and XKB.
KGDB (Kernel GNU Debugger)KGDB: Linux kernel source-level debugger operating over a serial port or network.
Kitty keyboard protocolKitty keyboard protocol: Modern terminal key-reporting protocol using CSI code ; modifier u.
KMAC (Keccak Message Authentication Code)KMAC: Variable-length MAC and PRF built directly on SHA-3/cSHAKE (NIST SP 800-185).
KMS - Kernel Mode SettingKMS: Kernel-based display mode setting.
KPTI (Kernel Page-Table Isolation)KPTI: Kernel mitigation against Meltdown that unmaps kernel memory while user programs run.
KVM (Kernel-based Virtual Machine)KVM: Linux kernel hypervisor turning Linux into a Type-1 hypervisor using Intel VMX or AMD SVM.
KWinKWin: The window manager and compositor used by KDE Plasma.
