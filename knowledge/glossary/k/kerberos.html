Kerberos

Network authentication protocol using symmetric-key tickets and a trusted Key Distribution Center (KDC) for single sign-on.

Novice definition

Kerberos is a network login system where a trusted ticket server lets you sign in once and prove who you are to other services without sending your password again.

Learner definition

In Kerberos, you authenticate with your password (for example via kinit) to get a TGT from the KDC, then exchange that TGT for service tickets over an untrusted network. Accurate NTP clock synchronization is required because tickets carry short validity windows.

Expert definition

Symmetric-key authentication protocol (Kerberos v5, RFC 4120) derived from Needham–Schroeder with timestamps: the Authentication Server (AS) issues a TGT, the Ticket-Granting Server (TGS) issues service tickets encrypted with CTS-HMAC (aes256-cts-hmac-sha384-192) or legacy keys, and replay caches cover the clock-skew window. See Network, Messaging, and Identity Security Protocols.
