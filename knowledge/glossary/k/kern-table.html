Guide / Glossary A–Z / Terms beginning with K / kern (Kerning Table)

The kern table is an older OpenType table that adjusts the spacing between specific glyph pairs.

Some letters look better a little closer together. The kerning table lists pairs and how much to move them, so AV does not have an awkward gap. It is a small but old part of font technology.

The table exists in Apple and Microsoft variants and is superseded by GPOS pair adjustments in modern OpenType fonts. Many shapers still read kern for older fonts. Kerning values are in font units and are applied after base advances from hmtx.

Format 0 stores a coverage-indexed set of pairs with signed kerning values; format 1 adds versioning and a different header. In modern fonts the same adjustments live in GPOS, where type 2 pair positioning handles classes and multiple lookups by script and language system. HarfBuzz prefers GPOS when present and may fall back to the legacy table; applying both would double-adjust.
