Guide / Glossary A–Z / Terms beginning with K / KMScon

KMScon is a userspace terminal console that renders text itself using kernel mode setting.

KMScon is an alternative text console that runs as an ordinary program rather than inside the kernel. It can draw a wider range of characters than the kernel's built-in console fonts and uses the graphics hardware directly.

KMScon is not part of the Linux kernel tree and does not use the CONFIG_FONT_* built-ins or setfont. It offers an 8x16 font backend, a Unifont backend for broad Unicode coverage and a Pango backend for scalable fonts, so shaping and color features are possible.

Because KMScon lives in userspace, its fonts load through its own backends rather than through KDFONTOP and fbcon; the kernel console font path is not involved. The Pango backend inherits fontconfig resolution and fallback, changing how grapheme clusters and combining marks appear compared with a fixed-cell kernel console. Its releases are independent of kernel versions.
