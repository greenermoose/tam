8-bit

8-bit means that eight bits are used as one unit, giving 256 possible patterns.

Eight switches can each be on or off, so together they have 256 combinations. A computer can use one combination for each small whole number, each basic text character or one part of a color. A group of eight bits is called a byte.

Eight unsigned bits hold 0 through 255. With two's complement they hold -128 through 127. If a result needs a ninth bit, the stored value wraps: 255 plus 1 becomes 0 in eight bits. The label 8-bit also describes hardware and software built around eight-bit registers, such as early home computers and small microcontrollers.

Why are there 256 patterns rather than 255?

Zero is one of them. Counting from 0 to 255 uses 256 values. The largest value is 255 because 256 would need a ninth bit.

In an instruction set, 8-bit names the natural width of data registers and arithmetic, not a rule that every value is eight bits. The MOS 6502 had eight-bit data registers but a 16-bit address bus, so it could address 65,536 memory locations while doing eight-bit arithmetic. A modern 64-bit processor still uses eight-bit bytes and can execute eight-bit operations; 8-bit mainly marks a historical ABI, a file format or a narrow data path. Audio samples, image channels and text encodings keep eight-bit fields even on wide machines.
