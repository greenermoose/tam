Guide / Glossary A–Z / Terms beginning with a number / 2FA (Two-Factor Authentication)

2FA (Two-Factor Authentication): requiring a second proof of identity in addition to a password or first factor.

2FA adds another check after a password. It makes it harder for someone who only knows the password to log in.

A common example is a password plus a code sent by text. A stronger example is a password plus a hardware key that is bound to the real site.

Factors are something you know, something you have and something you are. A texted code is a possession factor delivered through a network; it is not phishing-resistant. NIST SP 800-63B prefers phishing-resistant authenticators for higher assurance levels.
