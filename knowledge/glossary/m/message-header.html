Guide / Glossary A–Z / Terms beginning with M / Message header

A message header is the block of labelled lines at the top of an email that describes the message.

Headers are the lines above the message text that say who it is from, who it is for, its date and its subject. The mail client shows some of them; the rest help servers do their work.

Common fields include From, To, Date, Subject and Message-ID. Received headers are added by each server that handles the message. The visible From is different from the SMTP envelope sender.

RFC 5322 defines the Internet Message Format: header fields followed by a blank line and a body. Extension headers such as DKIM-Signature, Authentication-Results and ARC-* are layered on top. Header fields are text, so MIME encoded words handle non-ASCII values.
