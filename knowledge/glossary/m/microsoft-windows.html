Guide / Glossary A–Z / Terms beginning with M / Microsoft Windows

Microsoft Windows is an operating system family whose desktop supplies windows, input and drawing as part of the platform.

Applications show windows, respond to clicks and keys, and use common controls for buttons and menus. That sounds similar to a Linux desktop, but the software layers underneath are arranged differently.

Win32 is the long-standing application interface. USER manages messages, GDI supplies classic drawing, and the Desktop Window Manager composes windows for display. Newer frameworks sit above that foundation.

Windows integrates window management with the operating system rather than splitting it into a separate protocol like X11 or Wayland. Toolkits can still cross platforms, but native accessibility, input and shell integration follow each system's own interfaces.
