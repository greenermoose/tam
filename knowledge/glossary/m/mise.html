Guide / Glossary A–Z / Terms beginning with M / Mise

A user-local development tool and runtime version manager used on Tamlinux for user-installed CLI tools.

Mise is a tool manager that installs programming runtimes and user-level command-line tools inside your own home folder without needing administrator permissions.

On Tamlinux, pacman owns system packages, Make source installs own Tamlinux components, and Mise manages user-local tools such as developer runtimes and agent CLIs.

What is the boundary between pacman and Mise on Tamlinux?

pacman manages root-owned system packages under /usr, while Mise manages per-user tools inside your home directory without touching system files.

Mise shims or PATH activation select pinned tool versions per directory or globally under ~/.local/share/mise, isolating fast-moving user CLIs from the rootstock package database.
