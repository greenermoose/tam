Terms beginning with M

Glossary definitions for technical terms and acronyms beginning with M.

Explore

MAC - Message Authentication CodeMAC: A short tag made with a secret key to prove a message was not altered.
MAC addressMAC address: A hardware address for a network interface.
MAC2 (WireGuard DoS-mitigation cookie)MAC2: WireGuard handshake field carrying a rate-limiting cookie under heavy packet-flood load.
Machine codeMachine code: the binary instructions a processor executes
Major modeMajor mode: In GNU Emacs, the primary editing mode of a buffer that tailors syntax highlighting, indentation, and commands to one file type.
MakeMake: A classic build automation tool.
Mandatory Access Control (MAC)Mandatory Access Control: System-wide security rules enforced by the kernel that even resource owners cannot override.
ManifestManifest: A structured file describing the identity, version, files, and metadata of a package, plugin, or staged install.
MBR - Master Boot RecordMBR: The old disk partition table format.
MD5 (Message Digest 5)MD5: Obsolete 128-bit hash function completely broken for cryptographic collision resistance.
mDNS (Multicast DNS)mDNS: resolving names on the local link by multicast query instead of a configured DNS server.
MergeMerge: Combining two lines of development.
MESI (Modified, Exclusive, Shared, Invalid)MESI: Classic 4-state cache-coherence protocol keeping multi-core CPU caches consistent.
Meta keyThe Meta key: learning reference, hardware identity, and navigation role
MFA (Multi-Factor Authentication)MFA: Requiring two or more independent proofs of identity (knowledge, possession, or biometrics) to log in.
MINIXMINIX: Educational Unix-like microkernel OS created by Andrew Tanenbaum that inspired Linux and modern microkernels.
MiseMise: A user-local development tool and runtime version manager used on Tamlinux for user-installed CLI tools.
MITM (Man-in-the-Middle)MITM: Network attack where an adversary secretly intercepts and alters communication between two parties.
ML-DSA (Module-Lattice-Based Digital Signature Algorithm)ML-DSA (Module-Lattice-Based Digital Signature Algorithm): NIST's primary standardized post-quantum digital signature algorithm (FIPS 204), formerly known as CRYSTALS-Dilithium.
ML-KEM (Module-Lattice-Based Key-Encapsulation Mechanism)ML-KEM (Module-Lattice-Based Key-Encapsulation Mechanism): NIST's standardized post-quantum key encapsulation algorithm (FIPS 203), formerly known as CRYSTALS-Kyber.
ML-KEM-768ML-KEM-768: the ML-KEM parameter set targeting roughly NIST Category 3 post-quantum security.
MMU - Memory Management UnitMMU: The hardware that translates virtual addresses to physical memory.
MnemonicMnemonic: A short name for an instruction or operation.
Modal editingModal editing: Editing in which the meaning of a key depends on the editor's current mode.
Mode (permission)Permission mode: learning reference and next steps
Modifier keyModifier key: A key such as Shift, Ctrl, Alt, or Meta held down while pressing another key to change its meaning or trigger a shortcut.
modifyOtherKeysmodifyOtherKeys: xterm extension that encodes modified keys as CSI 27 ; modifier ; code ~.
MonospaceMonospace: A font whose characters have equal width.
MOSFET - Metal-Oxide-Semiconductor Field-Effect TransistorMOSFET: A transistor controlled by an electric field.
MotherboardMotherboard: The main circuit board that connects computer components.
Motion (vi)Motion (vi): A vi command that moves the cursor across text (such as w for next word or $ for end of line) and defines the span an operator acts on.
MountMount: To attach a filesystem to the directory tree.
Mount pointMount point: The directory where a filesystem appears.
MTU (Maximum Transmission Unit)MTU: Largest network packet payload size (typically 1500 bytes on Ethernet) sent without fragmentation.
MX LinuxMX Linux: Debian-based desktop distribution known for lightweight Xfce defaults and sysVinit/systemd flexibility.
