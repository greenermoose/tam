Guide / Glossary A–Z / Terms beginning with M / MTA (Mail Transfer Agent)

An MTA is the mail server role that accepts a message and relays it toward the next server on its route.

The letters stand for Mail Transfer Agent. It is like a sorting office: it reads the destination, puts the letter on the right outgoing route, and tries again later if that route is temporarily closed.

An MTA is both an SMTP server for the previous hop and an SMTP client for the next hop. It uses DNS to find the destination, queues messages when delivery fails, and retries according to local policy. It does not normally rewrite the message text.

RFC 5598 defines the MTA as the agent responsible for routing and transferring messages through the message handling system. A single product can combine several roles; RFC 5598 explicitly allows an MTA to include delivery functions. Trace headers record each hop, but the envelope is regenerated for each transfer.
