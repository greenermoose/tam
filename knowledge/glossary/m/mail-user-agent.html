Guide / Glossary A–Z / Terms beginning with M / MUA (Mail User Agent)

An MUA is the mail client: the program a person uses to compose, read and manage email.

The letters stand for Mail User Agent. A mail app on a phone, a desktop mail program and a webmail page are all MUAs. The mail server does the carrying; the MUA is the part you see.

An author MUA submits a message to a MSA, usually over authenticated SMTP. A recipient MUA retrieves mail from a message store using POP, IMAP or JMAP. It displays headers, decodes MIME parts and manages local or server-side folders.

RFC 5598 calls the user-facing agent the MUA and distinguishes the author MUA from the recipient MUA. A mailing-list server or automatic responder can act as a mediator: it is technically an MUA that re-posts a message rather than a pure relay. End-to-end encryption, when used, belongs in the MUA, not in the transport servers.
