Guide / Glossary A–Z / Terms beginning with M / Mutter

Mutter is the compositor and window manager used by GNOME.

Mutter places windows, draws GNOME's workspace view and presents the desktop. In a Wayland session it is also the display server, so it owns input and outputs.

GNOME Shell provides the top bar, overview and launchers; Mutter presents surfaces underneath. GNOME historically also supported X11 sessions, where Mutter acted as a compositing window manager above an X server.

Mutter implements the Wayland compositor role and GNOME-specific shell protocols. It coordinates surface commits, input seats and output state. A shell extension can run inside the same session, so extension faults can appear as display symptoms.

See GNOME, KDE Plasma and other desktops.
