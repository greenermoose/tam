Guide / Glossary A–Z / Terms beginning with M / Measure

Measure is the width a line of text is allowed to occupy before it wraps.

The length of a line in a book or on a web page is its measure. Very long lines are tiring to read because the eye loses its place; very short lines break words too often and chop the rhythm.

Typographers describe measure in characters per line, with roughly 45 to 75 considered comfortable for body text. In print, picas are traditional. Measure depends on type size, character width and column width, so changing the font changes how many words fit on a line.

Optimal measure depends on x-height and average advance width: a font with a large x-height supports a longer measure before the eye loses the line start. CSS constrains measure with max-width in ch units, based on the width of the digit zero. WCAG 1.4.8 requires that text at 320 CSS pixels width be readable without horizontal scrolling.
