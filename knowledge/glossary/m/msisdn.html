Guide / Glossary A–Z / Terms beginning with M / MSISDN (Mobile Station International Subscriber Directory Number)

MSISDN (Mobile Station International Subscriber Directory Number): the phone number used to address a mobile subscription.

An MSISDN is the phone number a person gives to friends. It is the visible address used for calls and texts.

When someone texts that number, the network looks up the current subscriber and serving system. Number portability means the number alone no longer identifies one carrier.

3GPP TS 23.003 distinguishes the MSISDN from the IMSI. The MSISDN follows ITU-T E.164 numbering; a lookup associates it with the subscription that currently owns it.
