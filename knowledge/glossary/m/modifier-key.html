Modifier key

A key such as Shift, Ctrl, Alt, or Meta held down while pressing another key to change its meaning or trigger a shortcut.

A modifier key does nothing by itself when tapped, but changes what another key does when held together—like holding Shift to type a capital letter or holding Meta to switch windows.

On Tamlinux, Ctrl handles commands inside applications, Alt provides secondary shortcuts, and Meta is reserved for desktop window and workspace management.

Why does Tamlinux reserve Meta for desktop shortcuts instead of Ctrl?

Keeping desktop chords on Meta avoids colliding with Ctrl shortcuts inside terminals, editors, and browsers.

Modifier keys update bitmasks in the compositor's XKB state (Shift, Lock, Control, Mod1/Alt, Mod4/Meta); terminals encode modified keys using CSI parameter bits or extended keyboard protocols.
