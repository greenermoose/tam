Guide / Glossary A–Z / Terms beginning with M / MIME (Multipurpose Internet Mail Extensions)

MIME is the set of rules that lets an email carry more than plain lines of ASCII text.

The letters stand for Multipurpose Internet Mail Extensions. MIME is what allows a message to include an image, a document or text in another alphabet without breaking the mail system that carries it.

A MIME message uses headers such as Content-Type and Content-Transfer-Encoding. A multipart message divides the body into parts, each with its own type. Common encodings include quoted-printable for mostly text and base64 for binary data.

RFC 2045 through RFC 2049 define MIME body structure, media types, encoded words for non-ASCII header text, registration procedures and conformance. MIME sits above the RFC 5322 message format: it says how to represent content inside the body, while SMTP carries the finished message as bytes.
