Guide / Glossary A–Z / Terms beginning with M / Mobile paging

Mobile paging is the radio step that wakes a phone which is idle so the network can tell it that a call, message or data connection is waiting.

A phone that is not actively sending or receiving can sleep to save power. The network still knows roughly which area it is in. When something arrives, the cells in that area send a short alert; the phone hears it, replies and gets the real message. That alert is the paging step.

Paging follows registration: the phone first tells the core network where it is, and the core later asks the RAN (Radio Access Network) to page it. A phone moves between cells, so the paging area can cover several cells rather than one. A missed alert leads to retries and can delay a message without losing it.

Tracking-area updates and paging procedures are specified in 3GPP TS 23.501 for 5G and in the LTE core specifications for 4G. Discontinuous reception lets a phone listen for paging messages only in configured cycles, trading wake-up latency for battery life. This paging is a radio reachability step, not the memory paging that moves blocks between RAM and storage.
