Guide / Glossary A–Z / Terms beginning with M / MySQL

MySQL is a widely used client/server relational database that stores records in tables and answers questions written in SQL.

A database server holds the data. Applications send requests to it and receive rows back, so several programs can share one store.

Its usual storage engine, InnoDB, adds transactions and row-level locking. Schemas, indexes, users and replication are the main things an application team manages.

InnoDB clusters rows by primary key, keeps a buffer pool of pages and uses a redo log for crash recovery. It implements multiversion concurrency control and locks; other storage engines make different durability and locking trade-offs.
