Matrix

A matrix is a rectangular arrangement of numbers in rows and columns.

A spreadsheet table is a matrix: each cell has a row and a column. A matrix can hold a picture's pixels, a set of measurements or instructions for moving points on a screen.

A matrix with 3 rows and 2 columns is called a 3-by-2 matrix. Multiplying a matrix by a vector mixes the vector's entries using the rows. Multiplying two matrices requires the inner dimensions to match: an m-by-k matrix times a k-by-n matrix gives an m-by-n result. Transposing swaps rows and columns.

Can a 3-by-2 matrix multiply a vector with 3 entries?

Not on the right. The vector must have as many entries as the matrix has columns, so a 3-by-2 matrix takes a 2-entry vector and produces a 3-entry result. Its transpose takes a 3-entry vector.

In storage, row-major order places a row's entries next to each other; column-major order does the same for columns. That choice affects cache behaviour more than the algebra does. Dense matrices store every entry; sparse formats store only nonzero entries plus indices. BLAS names include type and operation, such as DGEMM for double-precision general matrix multiplication. Factorizations such as LU, QR and Cholesky express the same matrix in forms suited to solving equations.
