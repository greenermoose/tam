Guide / Glossary A–Z / Terms beginning with M / Movable type

Movable type is a printing method that uses separate, reusable pieces of type for each character.

Instead of carving a whole page, you can build it from tiny metal letters, arrange them in a frame, ink them and print. Afterwards you take the letters apart and use them again. That is movable type.

It was developed in East Asia centuries before Gutenberg, who introduced a mechanical press and a system suited to European languages in the mid-fifteenth century. Type was cast from metal in standardized sizes, with a type case holding sorts by frequency. Compositors set text letter by letter and used spacing pieces to justify lines.

Each sort carries a raised, mirrored glyph at type height; a forme is locked in a chase and pressed against sheets. Casting systems introduced point and pica measurement traditions still used in typography. A fixed inventory of sorts explains why early fonts needed limited character sets and why ligatures and accented letters were cast as separate pieces.
