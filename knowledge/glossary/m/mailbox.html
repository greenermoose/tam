Guide / Glossary A–Z / Terms beginning with M / Mailbox

A mailbox is the place where delivered email is kept until the recipient reads it.

A mailbox is like a letter box with a door on the recipient's side. The delivery agent puts messages inside, and the mail client opens the box later to read them.

A mailbox may be a single file, a directory of message files, a database or a set of objects in a mail service. Folders and flags are metadata that a client such as IMAP can manage on the server.

RFC 5598 calls the long-term store the message store, whether it lives on the recipient's machine or a remote server. With POP the client often moves messages into a local mailbox; with IMAP or JMAP the canonical copy usually stays on the server.
