Guide / Glossary A–Z / Terms beginning with M / MX (Mail Exchange)

An MX record is a DNS record that tells a sending mail server which hosts accept mail for a domain.

The letters stand for Mail Exchange. When someone writes to a domain, the sender first asks DNS which mail exchange should receive the message, much like looking up which counter handles a particular street.

An MX record has a preference number and a host name. Lower numbers are tried first. RFC 5321 also defines an implicit MX at preference zero pointing at the domain itself when no MX record exists, provided that name has an address record.

RFC 5321 section 5.1 defines MX lookup. The MX target must be a fully qualified domain name that resolves to A or AAAA records; a CNAME at the MX target is outside that specification. MX is unrelated to the MX Linux distribution, which has its own glossary entry.
