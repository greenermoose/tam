Guide / Glossary A–Z / Terms beginning with M / Major mode

In GNU Emacs, the primary editing mode of a buffer that tailors syntax highlighting, indentation, and commands to one file type.

In Emacs, a major mode is the specialist personality a buffer puts on to match what you are editing—one for C code, one for Markdown notes, one for reading directories.

Each Emacs buffer has exactly one major mode at a time (plus any number of optional minor modes such as line numbers or spell-checking).

How many major modes can a single Emacs buffer have active at once?

Exactly one; switching to a new major mode replaces the previous major mode for that buffer.

An Emacs major mode defines a buffer-local keymap, syntax table, indentation engine, font-lock rules, and mode hook, typically inheriting from prog-mode or text-mode via define-derived-mode.
