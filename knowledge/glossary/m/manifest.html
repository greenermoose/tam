Manifest

A structured file describing the identity, version, files, and metadata of a package, plugin, or staged install.

A manifest is like a packing slip taped to the outside of a shipping box: it lists what is inside, which version it is, and what it needs to work.

In Tamlinux, desktop plugins carry a manifest describing their entry point and metadata, and source-install stages record a file manifest with SHA-256 digests for safe upgrades and rollback.

How does a manifest help during an upgrade or rollback?

By recording every installed file and its checksum, the installer can detect conflicts, remove obsolete files safely, and restore the exact prior state.

Tamlinux source-install manifests bind exact Git commits, destination paths, file modes, and cryptographic digests into a verifiable transaction record used by preflight, install, and recovery.
