Guide / Glossary A–Z / Terms beginning with M / MAP (Mobile Application Part)

MAP (Mobile Application Part): the signalling protocol used by mobile networks to query and update subscriber information.

MAP is one of the languages carriers use to ask about subscribers. It can ask where a phone is registered and help move a message toward it.

A message centre uses a location query before it sends a text to a roaming subscriber. That query is a mobile application part procedure.

3GPP TS 29.002 specifies MAP. It supports location management, authentication and short message transfer between network elements. MAP is a signalling protocol, not an application-to-person messaging API.
