MAC address

A MAC (Media Access Control) address is a hardware identifier assigned to a network interface so devices on the same local network can tell each other apart.

When your laptop and phone are both on the same home Wi-Fi, the router needs a way to hand each data packet to the right device. A MAC address works like a factory-stamped serial number on the network card, written as six pairs of letters and numbers (like 00:1a:2b:3c:4d:5e). Unlike your internet IP address, which changes whenever you join a different café’s Wi-Fi, the MAC address stays tied to your local network adapter—unless your device randomizes it for privacy.

A MAC address operates at Layer 2 (the link layer) on Ethernet and Wi-Fi, so it is only visible on the local broadcast domain—routers strip and rewrite Layer 2 headers at every hop. On Linux, you can view or temporarily change an interface’s MAC address with ip link show or ip link set dev eth0 address .... Modern NetworkManager and mobile OSes often enable MAC randomization during Wi-Fi scanning or per-network connections so public hotspots cannot track your hardware across locations.

Why doesn’t a remote web server see your laptop’s MAC address when you browse the internet?

MAC addresses are only used for hop-by-hop delivery on a local link. As soon as your packet reaches your home router, the router strips the original Ethernet/Wi-Fi frame header and wraps the IP packet in a new link-layer frame with its own MAC address for the next hop.

IEEE 802 specifies EUI-48 (6 octets) and EUI-64 (8 octets) addresses: the first 24 bits form the OUI (Organizationally Unique Identifier) assigned to the vendor, and the remaining 24 bits identify the NIC. Within the first octet, bit 0 (the I/G bit) marks unicast (0) vs. multicast/broadcast (1, as in ff:ff:ff:ff:ff:ff), and bit 1 (the U/L bit) distinguishes universally administered (0) from locally administered (1) addresses used by randomized MACs and virtual NICs. IPv4 resolves IP-to-MAC via ARP; IPv6 uses ICMPv6 Neighbor Discovery (NDP) and can derive interface identifiers from EUI-64 unless privacy extensions (RFC 8981) are enabled.
