Guide / Glossary A–Z / Terms beginning with M / Mail server

A mail server is a computer program or system that handles email on behalf of users or other servers.

A mail server is the far end of the email system that your mail app talks to. It accepts messages, passes them along, and keeps them until the person they are for reads them.

The phrase covers several roles: an MSA accepts new mail from clients, an MTA relays between domains, an MDA deposits mail, and a message store holds it. One installed package may perform more than one role.

"Mail server" is an operational umbrella term, not a single RFC role. RFC 5598 separates the MUA, MSA, MTA, MDA and message store precisely because products combine them differently. When diagnosing a system, name the role and the protocol before naming the product.
