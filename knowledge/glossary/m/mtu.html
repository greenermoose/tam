Guide / Glossary A–Z / Terms beginning with M / MTU (Maximum Transmission Unit)

The largest network packet size, in bytes, that a link can carry in a single transmission without splitting it up.

Think of MTU like the size limit on a single shipping box: if you want to mail a large set of items, you have to break them into boxes that fit through the carrier’s sorting slot. On most home and office networks, that limit is 1500 bytes per packet. If a packet is too big for a link along the way, it either has to be split into smaller pieces or dropped.

While standard Ethernet uses an MTU of 1500 bytes, VPNs, PPPoE links, and overlay tunnels add extra outer headers that shrink the usable payload MTU (for example to 1420 bytes for WireGuard or 1492 for PPPoE). Hosts rely on Path MTU Discovery (PMTUD) to learn the smallest MTU along a route: routers drop oversized packets that have the “Don’t Fragment” bit set and send back an ICMP “Fragmentation Needed” (IPv4) or “Packet Too Big” (IPv6) message. If an overzealous firewall blocks those ICMP messages, small pings work while large transfers or TLS handshakes mysteriously stall.

Why can a connection over a VPN work for small commands like ping but stall on large downloads or web pages?

Because the VPN header reduces the effective path MTU; if ICMP “Packet Too Big” errors are blocked, the sender keeps transmitting 1500-byte packets that are silently dropped along the tunnel.

MTU specifies the maximum Layer-3 IP datagram (header plus payload, excluding Layer-2 Ethernet/MAC framing and FCS) permitted on an interface; IPv4 mandates links support at least 68 bytes (576-byte minimum reassembly), whereas IPv6 requires a 1280-byte minimum link MTU and prohibits in-path router fragmentation. When PMTUD is broken by ICMP blackholing (RFC 2923), endpoints either fall back to Packetization Layer PMTUD (RFC 4821 / RFC 8899) or rely on TCP MSS clamping (iptables -j TCPMSS --clamp-mss-to-pmtu) to cap segment payloads at MTU − IP_hdr − TCP_hdr; jumbo frames (commonly 9000 bytes) improve throughput in data-center fabrics only when every L2 switch and L3 hop on the VLAN agrees on the higher MTU.
