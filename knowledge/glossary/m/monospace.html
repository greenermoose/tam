Guide / Glossary A–Z / Terms beginning with M / Monospace

A typeface in which every character occupies the exact same horizontal width.

In books and websites a narrow letter like i takes less space than w. A monospace font works like a typewriter or graph paper: every character gets an identical box. Columns of numbers, code indentation and text tables then line up cleanly down the page.

Terminal emulators, code editors and tools such as ls -l rely on uniform advance widths for alignment without tab stops. Programming monospace fonts often distinguish easily confused characters such as 0 and O, and some add coding ligatures for operators like !=; those joins keep the underlying characters and cell count. Gap-filling glyphs and icons must also be given one-cell widths.

Why does a table of numbers printed in a terminal misalign when pasted into a word processor?

A proportional font gives digits, spaces and punctuation different widths, so equal numbers of spaces no longer produce equal offsets.

Fonts set uniform hmtx advances across their core glyphs and usually flag isFixedPitch in post and proportion 9 in OS/2. Edge cases include double-width CJK characters occupying two terminal cells, combining marks with zero advance, emoji sequences and fallback glyphs whose height or baseline differs from the primary face. Terminals must clip, scale or allow overflow when a fallback breaks the cell assumption.
