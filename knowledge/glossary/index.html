Glossary A–Z

Look up a word or acronym, then follow its links to learn more.

Explore

  • A : AAD (Additional Authenticated Data) - AWG (American Wire Gauge)
  • B : Backlight - Byte
  • C : C standards (C89, C90, C99, C11, C17, C23) - CXL (Compute Express Link)
  • D : Daemon - DWDM (Dense Wavelength-Division Multiplexing)
  • E : EAP (Extensible Authentication Protocol) - Exit status
  • F : Factoring algorithm - FUSE (Filesystem in Userspace)
  • G : Gamma - GUI - Graphical User Interface
  • H : H.264 (AVC) - Hyprland
  • I : I2C - Inter-Integrated Circuit - IV (Initialization Vector)
  • J : JEDEC - JWT (JSON Web Token)
  • K : KDC (Key Distribution Center) - KVM (Kernel-based Virtual Machine)
  • L : L1 cache (Level 1 cache) - LZ77
  • M : MAC - Message Authentication Code - MX Linux
  • N : NAK (Negative Acknowledge, 0x15) - NXDOMAIN (Non-Existent Domain)
  • O : Object file (.o) - Owner
  • P : P-N Junction - PWM - Pulse-Width Modulation
  • Q : QAM (Quadrature Amplitude Modulation) - QWERTY
  • R : RADV (AMD Radeon Vulkan Mesa Driver) - Runlevel
  • S : .SRCINFO - systemd
  • T : TAGE (TAgged GEometric history length) - Twisted pair
  • U : UART - Universal Asynchronous Receiver-Transmitter - UWSM (Universal Wayland Session Manager)
  • V : VA-API - VTE (Virtual Terminal Emulator library)
  • W : W3C (World Wide Web Consortium) - WOTS (Winternitz One-Time Signature)
  • X : X.509 - XWayland
  • Y : YCbCr - YUYV
  • Z : Z80 (Zilog Z80) - ZRAM (Z in UNIX means compressed)
