Guide / Glossary A–Z / Terms beginning with T / TLSA record

A TLSA record is a DNS record that says which TLS certificate or public key a service should present.

TLSA is the name of a DNS record type, not an acronym to spell out. It is a signed note beside a service's name that helps another computer recognise the right server.

For SMTP the record appears under names such as _25._tcp.mail.example.com. It contains a usage, a selector, a matching type and the certificate association data.

RFC 6698 defines the TLSA record and RFC 7672 gives SMTP rules. DANE treats a bogus TLSA answer as a hard failure; silently ignoring it would defeat the pin. TLSA data needs a DNSSEC-validated answer to provide its intended trust.
