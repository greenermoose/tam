Guide / Glossary A–Z / Terms beginning with T / TTX

TTX is a utility that dumps a font's tables into readable text and can rebuild a font from that text.

Font files are hard to read directly. TTX turns their contents into a text file you can inspect, showing tables such as the character map and glyph outlines. It is part of the fontTools library.

Run ttx -l font.ttf to list tables, ttx -t cmap font.ttf to dump one table, and ttx font.ttx to compile back to a font. fontTools is widely used to inspect, subset and modify fonts in scripts as well as from the command line.

TTX serializes binary SFNT structures into an XML-like tree with numeric attributes and hexadecimal binary data, preserving enough information to round-trip a font. It can split tables into separate files with -s and control glyph naming. Checksums and offsets are recomputed on compilation, so the output is functionally equivalent but not byte-identical.
