Guide / Glossary A–Z / Terms beginning with T / TrueType

TrueType is a font format that stores glyphs as scalable quadratic curves with instructions for small sizes.

TrueType is one of the main font formats on computers. Its letters are described by curves, so a TrueType font can be used at any size without becoming blocky. It is the basis of many familiar .ttf files.

TrueType files use the .ttf extension and store outlines in glyf with offsets in loca. Apple developed the format in the late 1980s; Microsoft added extensive hinting and OpenType extensions. Many fonts use TrueType outlines in an OpenType container, and variable TrueType fonts add gvar deltas.

Outlines use quadratic Bézier curves with on- and off-curve point flags and implied midpoints between consecutive off-curve points. Glyph programs are bytecode run by a hinting interpreter such as FreeType's, operating in fixed-point pixel coordinates. Required tables include head, hhea, maxp, hmtx, cmap, name, post, glyf and loca.
