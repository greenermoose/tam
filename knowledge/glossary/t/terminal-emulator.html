Terminal emulator

A graphical program (such as foot) that draws a text terminal window and speaks classic terminal protocols inside a modern desktop.

A terminal emulator is the desktop window app—like foot on Tamlinux—that lets you run a text shell and terminal programs alongside your graphical windows.

The terminal emulator is separate from the shell running inside it: foot draws the characters and translates your keypresses into bytes, while bash reads those bytes and runs commands.

What is the difference between a terminal emulator and a shell?

The terminal emulator (such as foot) is the graphical window that handles display and keyboard encoding; the shell (such as bash) is the command interpreter running inside it.

A terminal emulator allocates a pseudo-terminal (PTY) master file descriptor, spawns a child shell on the slave side, parses ECMA-48/VT escape sequences from master reads, and renders the character grid via GPU or SHM buffers.
