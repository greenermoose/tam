Guide / Glossary A–Z / Terms beginning with T / Type 1

Type 1 is an older Adobe font format that stores glyph outlines as PostScript charstrings.

Before OpenType, many professional fonts were Type 1. They described letters with PostScript curves and included hints to keep them clear at small sizes. You may still see them in old archives.

A Type 1 font is usually split into a .pfb binary program and a .pfm or .afm metrics file. Type 1 supports a limited character set and cubic outlines; its hinting influenced the CFF tables later used in OpenType.

Type 1 charstrings use a stack machine with cubic Bézier operators and a private dictionary of hint and encryption data; a standard encoding maps character codes to glyph names, with an alternate encoding vector for extras. FreeType can load Type 1 fonts through its Type 1 driver, but modern workflows use OpenType/CFF, which keeps the charstring model without the old packaging.
