Terms beginning with T

Glossary definitions for technical terms and acronyms beginning with T.

Explore

TAGE (TAgged GEometric history length)TAGE: State-of-the-art CPU branch-predictor algorithm using multiple geometric history tables.
Tap-to-clickTap-to-click: A touchpad setting that treats a light finger tap as a mouse click without physically pressing the pad down.
TargetTarget: A systemd unit that groups other units into a state.
TCB (Trusted Computing Base)TCB: The set of hardware, firmware, and software components that must work correctly for a security policy to hold.
TCG (Tiny Code Generator)TCG: QEMU's cross-architecture dynamic binary translator for emulating foreign CPUs without KVM.
TCP - Transmission Control ProtocolTCP: A reliable, ordered network transport protocol.
TDX (Trust Domain Extensions)TDX: Intel hardware confidential-computing technology isolating guest VMs from the host OS.
TECO (Text Editor and Corrector)TECO: an early programmable text editor and character-oriented editing language influential in the development of Emacs.
Teletype (teletypewriter, TTY)Teletype: An old machine that typed and printed messages over a wire.
TERMTERM: The environment variable that names a terminal type.
TerminalTerminal: a plain definition and further detail
Terminal emulatorTerminal emulator: A graphical program (such as foot) that draws a text terminal window and speaks classic terminal protocols inside a modern desktop.
Terminfo (terminal information)Terminfo: A database of terminal capabilities.
TGT (Ticket-Granting Ticket)TGT: Initial Kerberos credential allowing a user to request service tickets without re-entering a password.
ThemeTheme: A coordinated set of appearance settings.
ThreadThread: A sequence of instructions that can run independently.
Threat modelThreat model: A structured description of what you are protecting, who might attack it, and how.
ThroughputThroughput: The rate data actually moves.
TilingTiling: learning reference and next steps
Time complexityTime complexity: How an algorithm's running time grows as input size grows.
TLB - Translation Lookaside BufferTLB: A cache of address translations.
tldr pagestldr: Community-maintained concise command cheat sheets focused on practical examples.
TLS - Transport Layer SecurityTLS: The encryption protocol that secures network connections.
TMDS - Transition-Minimized Differential SignalingTMDS: The signaling used by HDMI and DVI.
TOCTOU (Time-of-Check to Time-of-Use)TOCTOU: Race-condition bug where a resource changes between checking its permissions/state and using it.
TOFU (Trust On First Use)TOFU: Security model that accepts an unverified key on first connection and alerts if it ever changes later.
TOML (Tom's Obvious Minimal Language)TOML: Human-friendly INI-like configuration format with explicit types and tables.
ToolchainToolchain: The set of tools used to build software.
ToolkitToolkit: A library for building graphical interfaces.
TouchpadTouchpad: A flat pointing surface on a laptop.
TouchscreenTouchscreen: A display that senses touch.
TPM - Trusted Platform ModuleTPM: A chip that stores cryptographic keys and measurements.
TPM 2.0 (Trusted Platform Module 2.0)TPM 2.0: Hardware security chip specification (ISO/IEC 11889) for key sealing and measured boot.
TransientAn electrical transient is a short-lived change in voltage or current.
TransistorTransistor: a three-terminal semiconductor switch that controls electrical current using a voltage
Truth tableTruth table: A table listing every input combination and its output.
TTL (Transistor-Transistor Logic)TTL: Classic 5 V (or loosely 3.3 V) single-ended digital logic voltage levels used on board-level UARTs.
TTM (Translation Table Manager)TTM: Linux kernel DRM memory manager for discrete-GPU VRAM and system-RAM buffer placement.
TTY (Teletype)TTY: Linux terminal device abstraction (/dev/tty*) descended from physical teletypes.
TUI (Text User Interface)TUI: Full-screen interactive program that draws menus, panes, and forms inside a terminal.
Twisted pairTwisted pair: Two wires twisted together to carry signals.
