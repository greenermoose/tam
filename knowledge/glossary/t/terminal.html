Guide / Glossary A–Z / Terms beginning with T / Terminal

A text-based interface where you type commands for the computer and read the text output it sends back.

A terminal is like a text-message chat window between you and your computer: you type an instruction, press Enter, and it replies in words rather than buttons and icons. Many system tasks and remote connections are faster when you can type exact commands.

People say 'terminal' for two separate pieces: the program that draws characters and captures keystrokes, and the shell inside it that interprets commands. A full-screen virtual console is drawn by the kernel with a fixed bitmap font; a graphical terminal window shows a grid of character cells using a monospace font chosen through Fontconfig. Cells must be uniform for columns to align.

What is the difference between a terminal and a shell?

The terminal displays characters and passes keystrokes; the shell interprets what you type and launches commands.

Linux terminals span kernel virtual consoles, serial TTYs and graphical emulators backed by pseudo-terminals. The emulator parses control sequences into a cell grid and uses uniform advances from hmtx; kerning is normally off so cells stay aligned. Wide characters occupy two cells and combining marks none, and missing glyphs appear as tofu. The kernel console instead uses fixed bitmaps loaded with setfont and cannot shape text.
