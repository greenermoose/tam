Guide / Glossary A–Z / Terms beginning with T / Transaction

A transaction bundles several database steps so the database ends in a complete, valid state.

It is like moving house: either all the boxes arrive and the keys change, or you roll back to the old arrangement.

A transaction ends with COMMIT, which keeps the changes, or ROLLBACK, which discards them.

Transactions provide atomicity and isolation. Isolation levels trade stronger guarantees against concurrency; locks and multiversion control implement those choices.
