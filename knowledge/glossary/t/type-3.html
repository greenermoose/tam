Guide / Glossary A–Z / Terms beginning with T / Type 3

Type 3 is a PostScript font format in which each glyph can be a small program rather than a fixed outline.

Most fonts describe letters as curves. Type 3 goes further: each character can be a tiny drawing program, which allows patterns, color and other unusual effects. It is an old but very flexible idea.

Type 3 fonts were used for mathematical symbols, decorative marks and early color fonts. Because glyphs are programs, they can be slow and are not always well supported by rasterizers or PDF extraction. Modern color font tables such as COLR/CPAL replaced many of their uses.

A Type 3 font dictionary defines a CharProcs dictionary mapping glyph names to PostScript procedures executed within a glyph matrix, plus metrics and a FontBBox. Procedures may paint, clip and invoke other operators, so rasterizers must sandbox or restrict them; PDF supports Type 3 fonts, but text extraction and search can fail when glyphs have no simple Unicode mapping.
