Guide / Glossary A–Z / Terms beginning with T / TECO (Text Editor and Corrector)

An early programmable text editor and editing language, historically important as the environment where Emacs began.

TECO is an old text editor from the 1960s and 1970s. It is famous less because people use it today, and more because it influenced later editors. At MIT, programmers wrote TECO macros that grew into the original EMACS.

TECO (Text Editor and Corrector) started as a tape-editing tool and became a powerful but terse interactive editor. Its command language could be used like a programming language, which made it possible to build complex editing behavior from macros. That macro culture led to EMACS at MIT, where Richard Stallman and others turned collections of TECO commands into a self-documenting, extensible editor.

Why does TECO still matter if almost nobody edits with it now?

It is part of editor history. Understanding TECO helps explain where Emacs's idea of an extensible, programmable editor came from.

TECO provided a character-oriented editing model with a compact command language, registers, conditionals, iteration, and macro facilities. Its programmability made it a substrate for editor customization long before modern extension languages were common. The MIT EMACS lineage grew directly from TECO macros; later Emacs implementations, including GNU Emacs, retained the extensibility idea while replacing TECO with Lisp-based extension models. TECO is therefore a useful historical reference point when comparing "editor as tool" with "editor as programmable environment."
