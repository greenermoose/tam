Guide / Glossary A–Z / Terms beginning with T / TTC (TrueType Collection)

A TTC file packages several related fonts into one file, sharing tables that are identical between them.

Some font families ship as one big file holding several members, such as regular and bold. Because the fonts share common data, the collection is smaller than separate copies of each font.

TTC files are common for large families and CJK fonts, where many styles share glyph outlines. Applications select a face by index within the collection; Fontconfig and FreeType can enumerate the faces in a .ttc file.

The file begins with a ttcf tag, a version, a face count and an array of offsets to per-font table directories. Tables can be shared between directories, so offsets are absolute within the file. TTX can extract individual faces; subsetting a collection must rewrite shared tables carefully, and a DSIG signature covers the whole collection.
