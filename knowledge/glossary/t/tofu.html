Guide / Glossary A–Z / Terms beginning with T / TOFU (Trust On First Use)

TOFU (Trust On First Use) is a security model that accepts an unverified key on first connection and warns if it changes later. In typography, 'tofu' also names the empty box drawn for a missing glyph.

For keys, think of recognizing a neighbor's voice the first time they call and remembering it afterwards: a different voice later is a warning. For text, tofu is the hollow square you sometimes see instead of a character—a sign that the computer could not draw the symbol it was given.

OpenSSH uses key TOFU: the first connection saves a host key fingerprint, and later mismatches trigger a loud warning. Separately, when a font lacks a code point, the text system tries other installed fonts and finally draws the font's notdef box, called tofu in typography. Both meanings describe a visible signal that something should be checked.

What does a remote host identification changed warning tell you?

The server's current host key differs from the one saved on an earlier connection; either it was legitimately rebuilt or the connection is being intercepted.

In key TOFU, StrictHostKeyChecking=ask pins on first contact and accept-new pins only unseen hosts; SSH certificates anchor trust to a CA instead. In typography, tofu is the .notdef glyph reached through cmap fallback: HarfBuzz maps the missing code point, FreeType rasterizes the replacement outline, and cluster maps still point at the original text so copy and search work. Font coverage, not the encoding, usually causes the box.
