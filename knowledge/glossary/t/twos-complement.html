Two's complement

Two's complement is a way to write negative whole numbers so ordinary addition still works.

A fixed group of bits has only a limited number of patterns. Two's complement uses the leftmost bit to mark negative values and arranges the remaining patterns so that adding a number and its negative gives zero.

To write -5 in eight bits, start with 5 as 00000101, flip every bit to get 11111010, then add one to get 11111011. Adding 00000101 and 11111011 gives 00000000 if the ninth carry is discarded. Positive values look the same as unsigned values; only patterns with the leftmost bit set are read as negative.

Why is eight-bit 10000000 equal to -128 and not -0?

Zero has only one pattern, 00000000. That frees 10000000 to extend the negative range by one value, giving -128 through 127 from 256 patterns.

An n-bit two's complement value represents -2^(n-1) through 2^(n-1)-1. Negation is bitwise complement plus one modulo 2^n. Addition, subtraction and multiplication use the same low n bits as unsigned arithmetic; only overflow detection and right-shift semantics differ. Converting to a wider word needs sign extension, repeating the sign bit. Overflow occurs when adding operands of the same sign gives a result of the other sign, or when carry in and carry out of the top bit differ.
