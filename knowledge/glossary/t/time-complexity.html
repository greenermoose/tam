Guide / Glossary A–Z / Terms beginning with T / Time complexity

A measure of how the running time of an algorithm grows as the size of its input grows.

Time complexity tells you whether an algorithm stays fast as you give it more data, or slows down badly.

It is usually expressed with Big-O notation, such as O(1), O(log n), O(n), O(n log n), or O(n^2). It counts growth, not exact seconds, because exact time depends on hardware and implementation.

Time complexity is commonly analyzed in worst, average, or amortized cases over an abstract machine model. It abstracts constant factors and machine details, so empirical profiling remains necessary for real performance decisions.
