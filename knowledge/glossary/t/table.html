Guide / Glossary A–Z / Terms beginning with T / Table

A table is the relational way to store one kind of fact, such as a list of books or customers.

A table looks like a spreadsheet: each column has a name and each row is one entry.

In SQL, CREATE TABLE declares the columns and constraints. SELECT reads rows, and joins combine rows from several tables.

Formally a table is a relation: an unordered set of tuples over named attributes. Physical storage may use a heap or a clustered index, but SQL results are not ordered unless an ORDER BY clause says so.
