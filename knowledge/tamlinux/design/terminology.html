Plant names used in Tamlinux

This page explains the plant-inspired names used for parts of Tamlinux.

Names for the layers

The plant analogy names how Tamlinux fits onto a computer. It helps describe boundaries; it is not evidence that a planned feature is delivered.

  • Host: The physical hardware—your computer, its processor, memory, storage, and display.
  • Rootstock: The base operating system installed on a host (for example, Arch Linux, Void Linux, Windows, or macOS).
  • Bud: The initial, minimal Tamlinux package installed on a rootstock and used to install (or “grow”) the rest of the Tamlinux scion.
  • Scion: The Tamlinux software that installs on a rootstock.
  • Cultivar: Each major + minor version of Tamlinux (for example, 0.6 or 0.7), named from tamarack tree varieties.
  • Fruit: Applications that allow your computer to do useful things for you and your family.

In horticulture, a bud or shoot (the scion) from a named variety (a cultivar) is grafted onto a hardy rootstock so it can grow and bear fruit. In Tamlinux, Fred uses the same idea: a rootstock gets installed on a host, the Tamlinux bud gets installed on the rootstock, and then you use the bud to install the full Tamlinux scion, which bears fruit in the form of everyday applications. Our goal is to minimize the size of the rootstock and maximize its speed and efficiency. Currently Tamlinux uses Arch Linux as its rootstock, with plans to migrate to Void Linux in future versions and to explore a microkernel beyond that.

Use the analogy carefully

Follow the glossary links at level 2 for a technical model. Today’s initial bootstrap package is named tam-nut and is scheduled to be renamed tam-bud in Tamlinux 1.0.0; check the live system for what is actually installed.

Verify the real boundary

Follow level 3 definitions for limits. The analogy does not establish signing, immutability, portability or a working bootstrap. Those require the actual product design and implementation evidence.
