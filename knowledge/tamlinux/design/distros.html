Guide / Tamlinux / Design and philosophy / Rootstocks: Arch, Void, and antiX

A rootstock is the base operating system beneath Tamlinux; this page separates today’s working choice from the planned pilot and fallback.

What is a rootstock?

A Linux distribution provides the kernel, system libraries, and core package manager that make a computer boot and run. Tamlinux builds its own desktop and tools on top of an underlying base distribution, which Tamlinux calls the rootstock.

Why it matters

Knowing which rootstock is current, planned, or kept as a fallback ensures that package, update, and recovery instructions always aim at the right underlying system.

How to think about it

Think of the rootstock as the roots and trunk of a fruit tree, and the Tamlinux cultivar as the grafted branches on top. Keeping the two layers distinct makes it possible to change the base deliberately without redesigning the entire workstation.

New words

Rootstock
The underlying base operating system that Tamlinux builds upon (currently Arch Linux).
Cultivar
A named Tamlinux workstation release built on top of a rootstock.

Does a planned pilot prove it is installed?

No. A plan proposes a direction; host inspection supplies current evidence.

Engineering trade-offs behind the choices

Arch supplies current kernels, Mesa, Qt and Wayland protocols through pacman, but its systemd-centred design conflicts with the long-term minimal-rootstock goal. Void offers independent packaging with xbps and runit; antiX Core is the systemd-free fallback for low-resource hardware. A microkernel base remains research, not a delivered target.
