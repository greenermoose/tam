Displays and Monitors

This page explains how Tamlinux manages monitors, display scaling, multi-screen arrangements, and console brightness.

What is a display?

A display is a physical screen connected to your computer. Common connectors include HDMI, DisplayPort, USB-C, and internal laptop panels (eDP). The compositor draws your desktop across one or more screens.

Why it matters

Connecting a second monitor expands your workspace. Choosing the right scaling factor makes text sharp and comfortable to read on high-resolution screens without squinting.

How to think about it

Hyprland coordinates graphical windows across active monitors. When you plug in an external monitor, the desktop can extend or mirror your workspace. When you close a laptop lid with an external screen attached, clamshell mode keeps the session alive on the external screen.

New words

Resolution
The number of distinct pixels a display can produce, such as 1920×1080 or 3840×2160.
Scaling
A multiplier that resizes text and window elements so they appear comfortably sized on dense pixel grids.
Clamshell mode
Operating a laptop with the lid closed while an external monitor, keyboard, and mouse remain active.

Inspect and adjust your displays safely

Goal: you will be able to identify connected monitors and view their scaling factors without changing hardware settings.

Worked example

  1. Open a terminal and run tam-monitor list to see connected display connectors.
  2. Check the focused monitor's current scaling factor (captured on Bosgame Mini PC, 2026-11-06; your output will differ): 
    $ tam-hyprland-monitor-scaling
1
  3. To adjust scaling incrementally, pass up or down, then read back the updated factor: 
    $ tam-hyprland-monitor-scaling up
$ tam-hyprland-monitor-scaling
1.25
  4. Press Meta + Ctrl + D (or run tam-shell tamlinux-shell toggle fred.monitor) to toggle the display settings panel.

Try it

Run tam-hyprland-monitor-focused in your terminal. It prints the name of the monitor that currently holds keyboard focus.

If it goes wrong

Display scaling makes windows too large
Run tam-hyprland-monitor-scaling down or restore 1.0.
External screen does not activate on plug-in
Check cable seating and run tam-hyprland-monitor-watch or verify with tam-monitor list.

Adjusting brightness or display power triggers on-screen feedback through tam-osd.

Check yourself

Which command reports the scaling factor of the currently focused monitor?

tam-hyprland-monitor-scaling.

What tool provides console display control without requiring Hyprland?

tam-monitor.
