Storage Drives and Encryption

This page explains how to inspect storage drives, test disk read and write performance, and manage encryption passwords on Tamlinux.

What is a storage drive?

A storage drive keeps your operating system, programs, and documents permanently saved even when the computer is powered off. Modern systems use fast solid-state drives (NVMe or SATA SSDs) and removable USB flash drives.

Why it matters

Knowing your drive capacity and transfer speed helps detect failing hardware or slow cables. Full disk encryption protects your private documents if a laptop is lost or stolen.

How to think about it

Linux names physical disks as block devices in /dev (for example, /dev/nvme0n1 or /dev/sda). Before files can be read or written, a filesystem on the drive is mounted to a directory path. Encrypted disks require unlocking with a passphrase before mounting.

New words

Block device
A hardware device that moves data in fixed-size blocks, represented as a file under /dev.
Mount point
The directory location in your filesystem tree where a drive's contents appear.
LUKS
Linux Unified Key Setup; the standard specification for Linux disk encryption.

Inspect drives and measure performance

Goal: you will be able to display storage hardware information and test transfer throughput safely without administrative privileges.

Worked example

  1. Inspect host architecture and hardware identity (captured on Bosgame Mini PC, 2026-11-06; your output will differ): 
    $ tam-hardware
Architecture: x86_64
CPU:          AMD Ryzen 7 5700U with Radeon Graphics
Cores:        8 physical, 16 logical
Product:      EffiZen Series
Board:        ACB19D / Bosgame
  2. Discover drive device names and inspect disk and partition details (captured on Bosgame Mini PC, 2026-11-06; your output will differ): 
    $ lsblk -dno NAME,TYPE
nvme0n1 disk
$ tam-drive-info /dev/nvme0n1
/dev/nvme0n1 (953.9G) - KINGSTON OM3PGP41024P-A0 [vfat, unknown, ntfs, ntfs, crypto_LUKS, vfat(/boot), ext4(/data)]
  3. Measure disk read and write speeds with a non-destructive benchmark (captured on Bosgame Mini PC, 2026-11-06; your output will differ): 
    $ tam-disk-speedtest
disk KINGSTON OM3PGP41024P-A0
read 2850
write 1420

Try it

Find your block devices with lsblk -dno NAME,TYPE and pass a drive to tam-drive-info /dev/<name> in your terminal. It prints drive size, vendor/model, and partition mount points without modifying anything.

If it goes wrong

Drive info prints nothing or reports access denied
Ensure external USB drives are fully inserted and recognized by the kernel (check with lsblk).
Speed test takes too long
Press Ctrl + C to cancel the test safely; temporary benchmark files are cleaned up automatically.

To pick a drive interactively for backup or encryption tasks, use tam-drive-select.

Check yourself

Which command measures live disk read and write throughput?

tam-disk-speedtest.

What command prints drive size, model, and mount details when passed a device?

tam-drive-info.

Storage tools reference

CommandRole
tam-hardwareReport host architecture, CPU features, caches, and DMI identity
tam-disk-speedtestMeasure live disk sequential and random read/write speeds
tam-drive-infoPrint detailed size, model, transport, and mount information for a specified drive
tam-drive-selectInteractive terminal picker to select a drive with capacity and brand details
tam-drive-passwordUpdate encryption passphrase on a selected LUKS encrypted drive

All read-only diagnostic commands run cleanly as an unprivileged user. Passphrase changes with tam-drive-password interactively prompt for the existing passphrase before updating LUKS keyslots.
