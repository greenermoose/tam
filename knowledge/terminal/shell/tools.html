Tamlinux shell tools start terminals, TUIs, browsers and web apps, or focus an existing window when a new one would be noise.

Before this

Giving your computer written instructions

What are shell tools here?

Besides the interactive shell itself, Tamlinux ships small commands that start programs: a launcher, terminal UI helpers, and web-app wrappers. They keep launch paths consistent from the keyboard and menus.

Why it matters

You get one way to open a browser app or a TUI instead of hunting for each binary.

How to think about it

Menus call these commands; you can also run them from a terminal when scripting or debugging.

New words

TUI
Text user interface: a full-screen program in a terminal.
Web app
A site opened in an app-like browser window.

Choose the right launcher

Goal: find the TUI launcher in a fixed command reference

tam-launch-terminal: terminal window tam-launch-tui: open a TUI in a terminal tam-launch-or-focus: raise or start tam-launch-tui: open a TUI in a terminal tam-launch-terminal: terminal window tam-launch-tui: open a TUI in a terminal tam-launch-or-focus: raise or start A fixed reference separates starting from focusing. Use this when a script needs to start a terminal utility. Prefer focus when an existing window would do. Try cat commands.txt, then grep tam-launch-tui commands.txt.

What just happened

tam-launch-tui starts a terminal utility; tam-launch-or-focus raises an existing window. The output shown in this sandbox is a sample from fixed teaching data, not a reading from your machine. Menus are preferred for daily use because commands need exact arguments.

Try it

If it goes wrong

If a launcher says executable not found, check the target program with tam-cmd-present before changing wrapper files.
