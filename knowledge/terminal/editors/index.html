Guide / Terminals and shells / Classic text editors

Three text editors shaped how programmers work at a terminal, and two of them are still argued about.

ex edits by line number and command. vi puts a full screen in front of the same command language and adds modes. GNU Emacs takes the opposite approach: one modeless editor that runs named commands and can be extended while it runs. The Emacs versus vi debate is the long cultural argument that grew around the two philosophies.

Start here

If you only want to open, change, and save a file today, use the editor Tamlinux provides by default and read Opening and editing text files. Come back to this section when you meet a system where vi or Emacs is the editor already installed, need to edit files by command in a script, or want to understand why these programs still have devoted users.

Which editor is installed?

Tamlinux's baseline editor is micro, which uses familiar Ctrl + S and Ctrl + Q shortcuts. The editors in this section are optional packages. That is a Tamlinux default, not a judgement about the editors: each page says what its editor is good at and when another tool is the better choice.

Run these commands to see what your system has. None of them changes anything.

$ for editor in micro vi vim emacs; do printf '%-6s ' "$editor"; command -v "$editor" || echo 'not installed'; done
micro  /usr/bin/micro
vi     not installed
vim    not installed
emacs  not installed

Captured on an Arch-based Tamlinux system, 2026-11-16. Your output will differ if you installed one of these editors.
