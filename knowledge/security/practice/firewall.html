Guide / Security / Protect your computer / Checking and managing the host firewall

A host firewall decides which network traffic may reach services on your machine, so unused doors stay closed while needed connections continue to work.

Closing unused doors on the network

Whenever your computer joins a Wi-Fi or wired network, other devices on that network can probe your machine's numbered network ports. A host firewall drops unexpected incoming traffic while still letting your web browser and updates connect outward.

Why it matters

Default-drop incoming rules protect local services and shared workspaces from accidental exposure on untrusted networks.

How to think about it

Think of outgoing connections as requests you initiated yourself—replies to your requests are allowed back in automatically, while unsolicited knocks on closed ports are ignored.

New words

Firewall
A kernel filter that inspects packets and drops or allows traffic according to policy rules.
Port
A numbered endpoint (such as 22 for SSH or 443 for HTTPS) identifying a network service on a host.

Check yourself

Why check which firewall manages the host before adding a rule?

Two managers can give misleading states; a rule written in the inactive one will not take effect.

Reference

Linux packet filtering executes inside kernel Netfilter hooks (ingress, prerouting, input, forward, output, postrouting). nftables compiles human-readable rulesets in /etc/nftables.conf into register-based nf_tables VM expressions evaluated atomically in the kernel without full table-lock reloads.

How it works

Stateful rules rely on nf_conntrack, which tracks 5-tuple flows (src, dst, proto, sport, dport) and classifies packets as new, established, related (such as ICMP errors tied to an active flow), or invalid. Dropping ct state invalid early and accepting established,related before per-port checks keeps hot-path packet latency bounded.

Edge cases

Docker and the forward hook
Published container ports traverse the prerouting DNAT and forward hooks rather than host input. A host policy drop on input does not block container-exposed ports unless forward rules or 127.0.0.1 port bindings constrain them.
ICMPv6 Neighbor Discovery
Blocking all ICMPv6 breaks IPv6 NDP (nd-neighbor-solicit, nd-router-advert) and Path MTU Discovery, so inet family tables must permit essential ICMPv6 types explicitly.
Research frontier: How does XDP / eBPF packet filtering complement nftables at line rate?

XDP (eXpress Data Path) executes verified eBPF programs in the NIC driver before sk_buff allocation, enabling multi-million-pps DDoS drops and stateless mitigation ahead of the Netfilter stack.
