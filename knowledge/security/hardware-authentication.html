Guide / Security / Administrative privileges

Administrative privileges let a user change system-wide state, so authorization should be narrow, explicit and reversible rather than a permanent password-free shortcut.

What is administrative privilege?

Some changes affect everyone using the computer. Administrative privilege is the authority to make those changes.

Why it matters

A program with this authority can change system files and settings. Grant it only for a task you understand.

How to think about it

Your account is your everyday identity; administrator access grants additional authority. A temporary grant still gives broad power while it lasts.

New words

Privilege means permission to perform an operation. Sudo can run a command with another user's authority.

Goal: identify what a bounded privilege command reports before a container-related change.

Before you start: The sandbox is a local model. Command replies here are authored sample output, not readings from your machine. Nothing you type changes your system.

Sandbox

docker group configured: no tam-sudo-docker: available Exit status: 0 Sample: Docker group not configured; tam-sudo-docker available. Try tam-sudo-docker --configured first. Now try tam-sudo-docker to see the sample exit status. Try tam-sudo-docker --configured or tam-sudo-docker (or type help).

What just happened

The sample check distinguishes a configured group from the availability of a bounded command. A zero exit status is not proof that every privilege is safe; the scope of the allowed action still matters. These are authored replies.

Try it

On a real machine, read the command’s help before granting group access. Membership in docker can be equivalent to root, so it belongs in the same category as administrative privilege.

If it goes wrong

The sandbox does not answer a command
Type help to see the simulated commands, or use the command in the goal exactly as written. Press Esc to close the sandbox.
A file looks empty or missing
Use ls to list the prepared files, then cat clues.txt (or the named file above) to see the exact text.

Check yourself

Why is a bounded privilege command safer than a passwordless broad rule?

It authorises one narrow action and leaves less power available if a mistake or compromise occurs.

Security setup and privilege command family

CommandRole
tam-setup-security-sudoless-dockerAdd user to docker group after explicit root-equivalence confirmation
tam-remove-security-sudoless-dockerRemove user from docker group and restore sudo requirements
tam-sudo-dockerPredicate returning exit 0 when Docker requires sudo, exit 1 when accessible directly
tam-sudo-keepaliveMaintain an active sudo authentication token during long-running tasks
tam-sudo-passwordlessTemporarily activate bounded passwordless sudo for a specified number of minutes
