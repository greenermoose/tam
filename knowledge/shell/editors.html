Editors

This page explains how to open and change text files with Tamlinux editor helpers and common terminal editors.

What is an editor?

An editor is a program for reading and changing text: config files, notes, or source. Graphical and terminal editors both edit files; the shell helpers pick a sensible default.

Why it matters

Almost every setup task ends in an editor. Knowing one reliable path beats memorizing every binary name.

How to think about it

Prefer the packaged edit helper when a recipe says “open this file”; use a named editor when you already have a preference.

New words

Terminal editor
An editor that runs inside a terminal window (for example Micro or Vim).

Open a file for editing

Goal: you will be able to open a text file with the packaged edit path.

Worked example

  1. Query the configured default editor with tam-default-editor (or set it with tam-default-editor <editor>), and open files in it using tam-launch-editor <path>.
  2. Open a scratch file in your home directory, type a short line, save, and quit.
  3. If a desktop recipe opens an editor for you (for example clipboard practice), use Meta + V to paste into it.

Try it

Run tam-default-editor read-only with no arguments in a terminal to confirm which editor is active, then create and remove a temporary draft file under mktemp -d with tam-launch-editor --inline.

If it goes wrong

Changes vanished after closing the editor
Verify you saved with Ctrl + S (in Micro) or your editor's write command before quitting.
Wrong editor opened
Run tam-default-editor to inspect the configured identifier and adjust only if intended.

Review windows for plans and drafts may use Micro; that is a session preference, not a requirement for every file. Config editing uses tam-launch-config-editor when a recipe points at settings.

Check yourself

Which command resolves the default editor path?

tam-default-editor.

Editor-related commands

CommandRole
tam-default-editorResolve the default editor
tam-launch-editorOpen a file in the configured editor
tam-launch-config-editorOpen a config editor path
tam-capture-editEdit a screen capture (image path), not a text file

Terminal editors themselves (Micro, Neovim, …) are packages, not tam-* wrappers. Capture editing is covered under Screen capture.
