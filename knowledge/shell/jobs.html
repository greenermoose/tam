Processes, Jobs, and Signals

Every running program on Tamlinux is a process with a unique process identifier (PID). When you launch commands in an interactive shell, the shell organizes them into jobs.

Job control in the shell

You can move long-running tasks between the foreground and background without losing your shell session:

Background execution (&)
Append & to the command (e.g. make &) to start it in the background immediately, keeping your prompt active.
Suspend (Ctrl+Z)
Press Ctrl+Z to suspend the currently running foreground program, sending it a SIGTSTP signal.
List jobs (jobs)
Run jobs -l to inspect active background and stopped jobs in the current shell session.
Foreground (fg)
Run fg %1 to bring job number 1 back into the interactive foreground.
Background (bg)
Run bg %1 to resume stopped job number 1 in the background.
Disown (disown)
Run disown %1 to detach a job from the shell so it continues running even after the terminal window is closed.

Signals

Signals are asynchronous notifications delivered to processes by the kernel, the shell, or other programs:

SignalNumberDescription
SIGHUP1Terminal hangup; reloads configuration in many daemons
SIGINT2Interrupt from keyboard (Ctrl+C); polite request to halt
SIGQUIT3Quit from keyboard (Ctrl+\); halts and dumps core
SIGKILL9Unconditional immediate termination; cannot be caught or ignored
SIGTERM15Standard termination request; default signal sent by kill
SIGSTOP19Pauses execution immediately; cannot be caught or ignored
SIGCONT18Resumes execution of a paused process

Inspecting processes

Use ps aux or pgrep -l name to search for processes, and pkill name to signal them by command name. For dynamic live monitoring, run top or htop.
