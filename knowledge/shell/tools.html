Shell tools

This page explains how Tamlinux launches apps, wraps TUI programs, and opens packaged web apps from menus and chords.

What are shell tools here?

Besides the interactive shell itself, Tamlinux ships small commands that start programs: a launcher, terminal UI helpers, and web-app wrappers. They keep launch paths consistent from the keyboard and menus.

Why it matters

You get one way to open a browser app or a TUI instead of hunting for each binary.

How to think about it

Menus call these commands; you can also run them from a terminal when scripting or debugging.

New words

TUI
Text user interface: a full-screen program in a terminal.
Web app
A site opened in an app-like browser window.

Open the launcher and a TUI

Goal: you will be able to start an app from the launcher and recognize a TUI wrapper.

Worked example

  1. Open an empty terminal with Meta + Return (tam-launch-terminal in packaged bindings).
  2. Run tam-launch-tui --help and tam-launch-webapp --help to see the packaged wrappers.
  3. Prefer menus for daily use; use the commands when a binding or script needs an exact path.

Capture and toggle menus are separate: Meta + Ctrl + C (tam-menu toggle capture), Meta + Ctrl + O (tam-menu toggle toggle). See Screen capture and Desktop toggles.
